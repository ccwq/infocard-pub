核心差异：它不是“先搜到链接，再自己抓正文”，而是直接把搜索结果压成 LLM 可用的上下文。

Exa 提供 highlights（高亮片段）和 summary（auto/deep 模式 LLM 摘要），适合 Agent 直接消费。计费是 credits 模式：先用免费 credits，再按量充值或开自动充值。

Python 示例
from exa import Exa
from dotenv import load_dotenv
load_dotenv()

exa = Exa(api_key=os.getenv("EXA_API_KEY"))

# auto 模式：LLM 摘要 + 高亮片段
result = exa.search_and_contents(
    "latest AI agent research papers 2025",
    type="auto",
    num_results=10,
    text={"maxCharacters": 2000, "highlights": True}
)
# result.results[0].summary   ← LLM 生成的摘要（仅 auto/deep）
# result.results[0].highlights ← 高亮片段数组

# deep 模式：深度研究，返回完整摘要与引用
deep = exa.search_and_contents(
    "explanation of transformer attention mechanism",
    type="deep",
    num_results=5
)

# instant 模式：极速关键词搜索
fast = exa.search(
    "Hermes Agent framework",
    type="instant",
    num_results=20
)
JavaScript / TypeScript 示例
import Exa from "exa-sdk";

const exa = new Exa(process.env.EXA_API_KEY);

// auto 模式
const res = await exa.searchAndContents({
  query: "AI agent tool use benchmarks",
  type: "auto",
  numResults: 10,
  text: { maxCharacters: 2000, highlights: true }
});

// deep 模式
const deep = await exa.searchAndContents({
  query: "RAG vs fine-tuning cost comparison",
  type: "deep",
  numResults: 5
});
