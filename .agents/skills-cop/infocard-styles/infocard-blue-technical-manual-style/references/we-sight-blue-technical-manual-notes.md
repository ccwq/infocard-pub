# WeSight blue technical manual style notes

This reference records the adjustments that helped the WeSight card move from a warm paper look toward a true blue technical-manual look.

## What changed
- Keep the main visual language blue-white-gray; do not let warm paper or yellow gradients dominate the first fold.
- Use black top bars / black-head labels as anchors, but reserve blue for the main system color.
- Let red act as a narrow accent for warnings, dividers, or emphasis only.
- If screenshots still feel warm, shift the page background, hero bar, pills, section number blocks, and code-box framing toward cold blue tones before touching typography.

## Practical color hierarchy
- Primary: blue / navy
- Secondary: black / charcoal
- Accent: red
- Neutral: white / cool gray
- Avoid: gold, ochre, or parchment as the dominant hero tone

## Rebuild rule
- When the user says "rebuild" or "style conversion", preserve the full content bundle unless explicitly asked to expand or shrink it.
- Use a visible-text proxy check before and after the rewrite to catch accidental omission.

## Verification
- Browser vision should answer one question: does the first fold now read as blue technical manual, not warm paper?
- Mobile is acceptable only if the blue system remains legible at 390px and the content is not cropped.
