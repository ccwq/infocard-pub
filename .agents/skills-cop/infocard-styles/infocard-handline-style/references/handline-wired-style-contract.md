# handline wired-style card contract

## Session takeaway
When the user points to a reference image with **wired card + label + sticker-like border language**, that is not a minor decoration request. For `infocard-handline-style`, it means the main surfaces should carry a wired-style border language, while the editorial skeleton stays intact.

## Practical rules
- Use wired-style borders on major content surfaces
- Make labels / chips feel like stickers or hand-made tags
- Keep the editorial structure: title, quote band, process, columns, footer
- Preserve readability with dark text and strong contrast
- Prefer slight rotation / offset / shadow on cards and labels when it strengthens the hand-drawn feel

## What the session proved
- A pure CSS straight-border version felt too flat / too editorial
- Restoring the wired-style card and label language brought the page closer to the reference intent
- Both desktop and 390px mobile were visually acceptable after the restoration
