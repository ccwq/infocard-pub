# Black-head style session notes (2026-06-19)

## What worked
- Strong black header with white title + compact tech badges.
- White/paper body below the header; red is reserved for quote blocks, verdict blocks, and key numbering.
- High-density sections stay readable when separated by thin borders and whitespace rather than extra color.
- 8-item platform matrices work well as 4×2 on desktop and 2-column stacks on mobile.
- A single verdict block at the end helps this style feel like a field report, not a poster.

## Suggested page skeleton
1. Black header with badges, repo stats, and title.
2. Red-accent quote / mission block.
3. Core capability bullets with numbered circles (red / black / blue / green).
4. Dense grids for supported platforms or tools.
5. Workflow / installation / download channels.
6. Black verdict block with one-sentence judgment.
7. Thin footer with source links and metadata.

## Mobile notes
- Keep the header visible and high-contrast.
- Let 4-column grids collapse to 2 columns first; only go single-column when the content is text-heavy.
- Keep badges wrapping cleanly; do not shrink body text to compensate.
- Preserve one strong red accent line or quote bar; do not overuse red borders everywhere.

## Pitfalls
- Do not turn the whole body dark: the style is black-head, not full dark-mode.
- Do not use red gradients for the header; the header must be flat black.
- If the layout starts to feel noisy, reduce accent colors before reducing border strength.
