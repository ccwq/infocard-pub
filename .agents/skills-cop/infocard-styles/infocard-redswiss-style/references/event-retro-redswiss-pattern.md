# Event retro pattern for redswiss cards

This session used `infocard-redswiss-style` for a policy/event-briefing card rather than a tool catalog card.

## When to use
- The source is a public campaign, policy announcement, protest, open letter, or platform dispute.
- The desired output is a fact-heavy event retro, not a pure opinion piece.
- The story benefits from red/black severity, strong numeric callouts, and compact fact blocks.

## Recommended structure
1. **Red hero**: title + one-sentence alarm / thesis.
2. **Top metrics**: 3–4 hard numbers or dates.
3. **What happened**: concise factual summary.
4. **Why people objected**: 3-column stance blocks for key groups.
5. **Impact matrix**: who is most affected / what breaks.
6. **Action / conclusion**: the current state and what to do next.

## Visual rules
- Keep red/black dominant; do not introduce blue accents.
- Use dense, rectangular fact blocks.
- Use small dot markers or pills for categories.
- Prefer one sharp hero over many decorative widgets.
- Keep the page readable on mobile by collapsing grids to single-column stacks.

## Example labels from this session
- Rollout date
- Core demand
- What breaks
- Risk
- Conclusion / Action
