# infocard 内容扩充时的插入位置规范

## 两条硬规则

### 规则一：默认插入位置是"前面"，不是 footer
当用户说"增加内容"而没有指定位置时，新增内容块应插入到：
**step-grid（三步上手）之后、原有 PAGE 01 之前。**

这是因为：
- hero 和 step-grid 是入口认知层，读者看完能快速定位方向
- 原有 PAGE 01+ 是深度内容，越靠前越容易漏读
- footer 前插入容易被忽略，且打乱原有 PAGE 编号连续性

### 规则二：仅当用户明确要求才插入 footer 之前
只有用户说"加在最后"、"footer 前"、"末尾"时才插 footer 之前。
用户说"插入到前面"或"插到前面"时，必须执行规则一。

## 插入顺序如何影响 PAGE 编号

当新增 6 个卡片（PAGE 05-10）插入到 PAGE 01 之前时：

| 卡片 | PAGE 编号 | 位置 |
|------|-----------|------|
| hero + step-grid | — | 最前（固定入口）|
| 新增 6 卡片 | PAGE 05-10 | 新卡片自身编号连续 |
| 原 PAGE 01-04 | PAGE 01-04 | 保持不变（编号不变）|

新增卡片的 PAGE 编号从 05 开始（而不是 01），因为：
- 01-04 已存在且编号不应打乱
- 05 是现有 PAGE 编号序列外的第一个空缺
- 读者看到 PAGE 05 会意识到这是新加入的内容

**错误做法**：重新编号所有 PAGE（把原 PAGE 01 改成 PAGE 07），这会导致历史书签失效、外部引用断裂。

## 技术实现

在 HTML 中，新增 section 插入到：
```
</section>   ← step-grid 末尾（行 82 左右）
<section class="grid3">  ← 新增内容在这里
```

而不是：
```
</section>   ← 最后一组 grid3 末尾
<section class="grid3">  ← 错误：会插入到 footer 前
```

## 日期更新

当对已发布卡片做内容扩充时，更新 footer 日期为当前日期（格式：`YYYY-MM-DD`），表示本次修改。
