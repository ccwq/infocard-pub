# X / tool-list card density expansion

Use this when a user says an existing X / Twitter tool-list card is “too thin”, “not dense enough”, or “needs at least 2x more information”.

## Goal
Turn a directory-like summary into a decision card. Add information layers that help the reader decide what to try, how to combine items, and what the limits are.

## Minimum expansion layers
1. **One-line positioning**: what the thread/post is really recommending.
2. **Evidence blocks**: keep the original counts, claims, and standout facts.
3. **Per-item micro-notes**: for each listed tool/project, add role + best-fit use + watchout.
4. **Workflow bundles**: regroup long lists into 3–4 practical stacks.
5. **Who it’s for / not for**: make the boundary explicit.
6. **Trial order**: recommend the first thing to test, then the next step.
7. **Risk / trade-off**: explain the hidden cost of adoption.
8. **Decision line**: end with a clear conclusion, not a bare list.

## Density heuristic
If the first draft could be summarized as “here are the names and one short sentence”, it is not dense enough. Expand with structure, not repetition.

## Avoid
- Repeating the same summary in longer prose.
- Adding fluff adjectives instead of new layers.
- Turning the card into a catalog without guidance.
- Leaving the reader without a clear try-first order.
