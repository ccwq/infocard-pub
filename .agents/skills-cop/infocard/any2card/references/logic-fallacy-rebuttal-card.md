# 逻辑谬误 / 反驳卡模板（session note）

## 适用场景
- 用户要做“诡辩 / 谬误 / 反驳 / 辩论逻辑”类高密度信息卡
- 目标是让读者快速识别错误推理，而不是赢辩论
- 适合评论区、科普转发、学习笔记、辩论速查

## 推荐结构
1. **首屏结论**：这类诡辩常见的总毛病是什么
2. **识别框架**：先锁定义 → 再还原命题 → 再要证据 → 再给第三项
3. **分类块**：9 类高频诡辩，统一成“漏洞 + 反驳句式”
4. **通用模板**：4 句够用，避免长篇说教
5. **适用边界**：逻辑纠错不等于情绪压制

## 视觉建议
- 适合 `portrait`
- 建议用“技术手册红黑”或“精准型 / 档案卡片”骨架
- 第一屏放：标题、总判断、四步流程图、3 个关键判断
- 中段放：3×3 卡片网格，保证 9 类一眼扫完
- 底部放：四句反驳模板 + 使用边界 + 保存按钮

## 9 类高频诡辩的稳定写法
- **偷换概念**：同词异义 → 反驳：先锁定义
- **稻草人**：改写对方观点再打 → 反驳：复述原话再回应
- **假两难**：把连续光谱伪装成二选一 → 反驳：补第三项
- **人身攻击**：攻击人不答题 → 反驳：回到证据
- **诉诸权威 / 多数**：身份或人数替代证据 → 反驳：问方法与样本
- **以偏概全**：个例冒充总体 → 反驳：问样本边界
- **举证责任转移**：逼对方证明“没有” → 反驳：谁主张谁举证
- **循环论证**：结论当前提 → 反驳：遮住结论看前提是否独立成立
- **滑坡谬误**：跳过中间链条推到最坏结局 → 反驳：逐段问中间步骤

## 通用反驳句式
- “你这里的词是什么意思？”
- “你是在回应原命题，还是改写后的版本？”
- “你的中间证据链是什么？”
- “除了你说的两个选项，还有没有第三种可能？”

## 常见坑
- 不要把卡片写成“9 个名词 + 9 句空泛解释”
- 不要只做目录感，要做“错误点 + 反驳句式”双层结构
- 不要让图示抢正文；图示只负责把逻辑路径一次讲清
- 不要把“赢辩论”当目标，目标是“恢复命题对齐”
