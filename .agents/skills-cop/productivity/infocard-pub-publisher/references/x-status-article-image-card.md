# X status article-link + embedded-image card pattern

Session pattern:
- X status text may collapse to a single article URL while the article itself contains the actual claim and image.
- In this case, treat the article page as the primary source, not the bare status text.
- Resolve the canonical article title and author.
- Download the article/hero image locally under `docs/assets/images/`.
- Embed the image inside the card’s first fold or hero area; do not leave it as an external thumbnail.
- Caption the image with its role in the argument (e.g. "配图是论点本身" / "图示表达 task → split → verify").
- Keep the X status ID as the durable anchor and include the article URL in the source block.
- If the source image is the only place where the key wording appears, let that wording drive the card title/subtitle.
