# 心理学术语边界卡模式（session note）

适用于：用户要求“调查一个心理学词汇 / 心理学概念 / 维基上的术语”，并且最终要做成科普信息卡。

## 这类任务的第一步
不要把词先当成诊断结论。先拆成三层：
1. **词在中文里通常怎么被用**
2. **它在心理学里的正式/常见用法**
3. **它最容易和哪些词混淆**

## 词义边界模板
优先回答：
- 它是不是一个稳定词条？
- 它更像“正式术语”，还是“术语家族”？
- 它和投射、内化、外化问题、人格化有什么关系？
- 能不能一句话解释，而不把它说成病名？

## 信息卡写法建议
标题优先写成结论，例如：
- “人格外化不是外向，而是把内在冲突推到外部世界”
- “外化更像一组心理防御/行为模式，而不是单一诊断词”

正文固定保留四块：
1. 这词什么意思
2. 它和哪些词容易混
3. 常见表现是什么
4. 读者要怎么记住边界

## 证据优先级
1. 官方百科/权威词典
2. 大学课程讲义 / 教科书摘要
3. 学术论文或综述
4. 高质量科普
5. 其它转载

## 常见误区
- 把“外化”误解成“外向”
- 把“防御机制”写成病名
- 把“外化问题”与“人格外化”混为一谈
- 只给定义，不给边界

## 输出要求
- 用中文讲清楚
- 保留关键英文术语作为锚点（如 externalization / externalizing）
- 不要过度缩短到只剩一句话
- 需要一张科普信息卡时，标题必须是判断句，不是名词解释
