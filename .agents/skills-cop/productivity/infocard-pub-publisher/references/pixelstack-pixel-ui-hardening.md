# Pixelstack pixel UI hardening

Use this note when a pixelstack-family card already has a stable layout and the user wants the interface to feel more like an 8-bit panel.

## What to harden

- **Shells / panels**: keep the existing structure, but make the outer shell feel heavier and more mechanical.
- **Labels / tags**: add hard-edge sticker shadows so small labels read like physical UI stickers, not soft chips.
- **Small cards**: use stepped corners, consistent 2px/3px borders, and hard shadows.
- **Before adding more background texture**, harden the boundary language first. The border system is the main pixel signal.

## Practical rule

If the page already reads clearly, do not add more texture. Strengthen:
1. outer border
2. label edge
3. tag shadow
4. small-card corner

Then stop and re-check at 390px.
