# Prompt-only card boundary removal

Use this note when editing an infocard that is explicitly for prompt engineering / prompt-only use.

## Rule

If the user says the content is for prompts only and will **not** be used for real-world execution, do **not** add an ethical / usage boundary disclaimer section unless the user explicitly asks for one.

## Editing guidance

- Keep the card focused on the prompt content and its copy-paste utility.
- If a previously added ethics or usage-bounds block is present and the user asks to remove it, delete the block entirely and republish.
- Do not replace it with a softer disclaimer unless the user asks for an alternative.
- Preserve the rest of the card structure, copy buttons, and export behavior.

## Example trigger language

- “这全部是用来提示词用，不会用于真实拍摄”
- “把伦理表达边界这里移除掉”
- “只保留提示词内容”
