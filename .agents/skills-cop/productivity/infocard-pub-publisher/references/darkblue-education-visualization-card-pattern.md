# Darkblue 教育可视化信息卡模式

适用场景：AetherViz Master 这类“把抽象教学主题变成交互式 3D 课件网页”的项目。

## 路由判断

当来源仓库/页面具备以下信号时，优先路由到 `darkblue`：
- 教学主题输入
- 3D / 交互式课堂 / 课件网页
- 学习目标、原理讲解、公式、测验、播放控制
- 浏览器直接上课

## 版式优先级

首屏要体现“课堂工作台”而不是“普通工具介绍”：
1. 一句话判断
2. 关键能力 / 学科覆盖 / 技术栈
3. 真实界面截图作为证据
4. 教学模块拆解（目标、原理、公式、交互、测验）
5. 适用人群 / 边界

## 移动端验收

- 390px 截图必须检查横向溢出
- 底部导出/保存按钮不能压住正文
- 如果按钮会遮挡内容，改成正常流的底部全宽 CTA
- 以 full-page 截图作为最终证据，避免只看首屏

## 视觉证据

如果 README / demo 已经给出真实截图，优先把截图本身做成 hero 证据，而不是另起一张抽象封面图。
