# 原图固化与失真验收

## 适用场景
当信息卡里的证据图、原帖图、截图、对比图在发布后出现“模糊、失真、被裁切、被压扁、像缩略图”的情况时使用。

## 经验要点
1. **先查资产本体，不先怪布局。**
   - 先确认图片文件是否真的已经换成原图/高分辨率版本。
   - 用图片工具或脚本读取 `width × height`，对比原始来源尺寸。

2. **不要让证据图继续走缩略图链路。**
   - 如果原图被下载时带了 `name=360x360` / `name=240x240` 之类参数，发布时就会保留缩略图质量。
   - 需要时重新抓取 `name=orig` 或等价原图地址，再覆盖本地资产。

3. **图片展示样式优先保证“完整显示”。**
   - 证据图通常应使用 `width:100%; height:auto; display:block`。
   - 除非明确想做裁切封面，否则不要对证据图使用 `object-fit: cover` / 固定 `aspect-ratio`。

4. **发布后做双重验收。**
   - 先检查公共图片 URL 是否 200，且 content-length 与原图一致。
   - 再做页面截图确认：图像是否完整、比例是否正常、是否仍有方框裁切。

## 常见修复顺序
1. 替换为原图文件。
2. 改图片样式为完整显示。
3. 重载页面并重新截图。
4. 只有截图通过，才算修复完成。
