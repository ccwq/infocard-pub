# 社会热点类调查的信息卡发布模式

> 来源：山东钟先生三孩非亲生案（2026-06-01）
> 适用：舆论事件、婚姻家庭纠纷，社会新闻类调查信息卡发布

## 与 tech 类调查的核心区别

| 维度 | Tech 类调查 | 社会热点类调查 |
|---|---|---|
| 核实重点 | 版本号、发布时间、官方文档 | 多源交叉，时间线一致性、第三方回应 |
| 证据形态 | 截图、代码、Release notes | 媒体报道（多家）、当事人陈述、聊天记录截图 |
| 关联事件 | 同期有无竞品/同项目更新 | 同期有无同类案件（容易混淆） |
| 风险点 | 技术误读、版本误导 | 单方面陈述偏差、身份信息核实困难 |
| 发布节奏 | 可快（技术事实清楚） | 建议核实后再发（避免错误扩散） |

## 社会热点调查核实 SOP

### 第 0 步：确定唯一身份锚

社会事件中，同一个地区、同一类情节可能有多个独立事件。先用搜索交叉验证当事人姓名/地点/时间，确认"这是哪一起"。常见混淆案：山东青岛钟先生（12年·3孩）vs 山东淄博姜先生（22年·2子均非亲生）。

### 第 1 步：多源核实（最低 2 家不同媒体）

- 来源 A：主流媒体（《小莉帮忙》/ 澎湃新闻 / 腾讯新闻等）
- 来源 B：平台报道（微博/抖音/搜狐/网易等）
- 核对：时间线、关键数据是否一致
- 标注"存疑"：仅当事人单方面陈述、对方未回应的部分

### 第 2 步：区分事实层与推断层

| 层级 | 描述 | 标注方式 |
|---|---|---|
| 已核实事实 | 有多家媒体一致报道的客观数据 | 直接写 |
| 合理推断 | 当事人说法经逻辑印证，无反证 | 加"据报道"/"据当事人称" |
| 未核实项 | 单方面陈述、身份不明、对方拒回应 | 明确标注"未核实"/"存疑" |

### 第 3 步：打包发布（report.md + index.html）

对社会热点类，必须同时产出：
- `report.md`：调查全文，含核实结论、可信度评估、关联事件区分、法律分析
- `index.html`：高密度信息卡，首屏呈现：关键事实、鉴定结果、法律路径、关联事件对比表

## 信息卡特有模块（社会热点类）

1. **一句话摘要**：用警示色 banner 写明最核心发现
2. **关键数据卡片**：婚姻年数、子女数、DNA结果、发现方式
3. **时间线**：从相识到求助的完整年表
4. **法律分析**：相关法条 + 可维权路径
5. **关联事件对比表**：与同期同类事件的对照（防混淆）
6. **可信度核查**：来源分级标注（可靠/注意）

### 隐私保护规范

- 姓氏使用化名（如"钟先生"）
- 不暴露具体城市/区县（只写省+市）
- 视频截图、聊天截图等敏感媒体本地化存储后引用

## 舆情演变分析（可选，如用户要求"真香现象"）

热点事件传播规律：
1. **单点爆发**：当事人求助媒体 → 第一波报道
2. **同类扩散**：网友联想到自身经历 → 跟进事件出现
3. **情绪升级**：从同情到集体焦虑，从个案到制度讨论
4. **信息沉淀**：事实核实、法律解读进入常态

## 写作注意事项

- 不写"根据可靠消息"等模糊来源，必须写出具体媒体名+日期
- 法律分析须注明"非针对本案的法律知识引用，不构成法律意见"
- 避免标题党：用具体事实描述而非情绪化措辞
