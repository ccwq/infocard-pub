# Dense evidence card legibility notes (2026-06-09)

## What changed in this session
We expanded a Toyota cruise-control investigation card from a single-case narrative into a dense evidence card with:
- one first-fold verdict block
- a stats row
- multiple sample tiles
- a bottom source/reference zone

## Practical lesson
For dense investigation cards, legibility fails less often because of font size and more often because the layout packs too many bordered blocks into the same visual band.

### What worked
- Keep the first fold to: verdict + 3-4 stats + one short summary.
- Put the sample set into clearly separated tiles with enough gap between borders.
- Use 1-column stacking on mobile for sample tiles unless the cards are extremely short.
- Make the bottom source/reference section visually distinct from the evidence tiles.

### What to check when the card starts feeling “too busy”
- Adjacent borders producing a dark double-line effect.
- Box-shadow sitting too close to the next border.
- Stats/header blocks compressing the first fold.
- Too many sample tiles fighting for attention before the conclusion is visible.

### Recommendation
If a card needs 5+ evidence items, treat the layout as a two-layer structure:
1. one concise first-fold conclusion
2. one evidence grid below it

Do not let the evidence grid crowd the verdict block.
