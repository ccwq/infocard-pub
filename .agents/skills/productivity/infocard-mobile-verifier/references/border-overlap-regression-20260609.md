# Border overlap / 重线感回归记录（2026-06-09）

## 触发场景
- 多张信息卡共用同一套模板 CSS，首屏出现“线条重叠 / 边框发黑 / 角点像双线”的观感。
- 用户指出的具体位置通常是：
  - 统计卡（STARS / FORKS / FOCUS / THEME）左上角或卡片交界处
  - `01 / SHOWCASE` 区块与下方首个内容块的交界处

## 这次的共同根因
1. 多层容器都使用了实边框，且间距太紧。
2. `stats` 与 `section` 的外边距/内边距不足，卡片边框在视觉上贴得过近。
3. `box-shadow` 紧贴黑边，放大了“重线感”。
4. 在同模板批量产出的卡片里，这类问题往往是共享 CSS 级别的，不是单页内容问题。

## 经验性的修复方向
- 优先收紧模板级布局：给 `stats`、`section`、section 首块留出一致的外/内边距。
- 不要先改单个卡片文字或内容；先查 shared CSS 是否把边框、阴影和间距挤在一起。
- 若多个页面同症状，先修公共模板，再回头做单页验收。

## 验收要点
- STARS 卡左上角不出现明显双线。
- `01 / SHOWCASE` 与下方内容块交界不再出现明显重线。
- 首屏看起来是单线边框 + 合理留白，而不是多条边线挤在一起。
- 视觉上若仍“像双线”，先区分是：真实 border 叠加、shadow 贴边，还是背景网格/高对比造成的错觉。
