# Medium-Density Installation Guide Cards

Session note for publishing product/skill landing pages such as `tasteskill.dev`.

## When this pattern applies
- The source is a product site, skill site, or tool landing page.
- The user wants a **medium-density** card focused on onboarding, installation, and compatibility.
- The page is not a deep technical investigation; it is a practical “how to start” card.

## What to surface first
A strong first fold can stay compact if it contains:
1. **Title / one-sentence proposition**
2. **Four compact stats**
   - version or maturity
   - installation method
   - compatible tools/platforms
   - install name / primary entry
3. **A one-sentence conclusion** explaining what the project actually is

## Recommended section order
1. 核心判断
2. 安装方法 / 上手指南
3. 支持哪些工具 / 兼容矩阵
4. 版本选择 / v2-v1 / default-legacy decision
5. 官方入口与边界

## Density rule
- For medium-density pages, a **tight but readable** first fold is acceptable.
- Do not inflate whitespace just to make the page look emptier.
- If the key surfaces are visible and the page reads cleanly on mobile, preserve the density.

## Verification checklist
- Title visible and uncut
- Four stats visible in the first fold
- One-sentence conclusion visible
- Save/CTA button visible and discoverable
- No obvious mobile clipping or overlap
- The install method and compatibility info appear before less important detail
