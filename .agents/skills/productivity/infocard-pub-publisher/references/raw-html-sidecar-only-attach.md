# 原样附加 HTML 的 sidecar-only 发布模式

适用场景：用户明确要求“保持 HTML 代码不能改变，只是附加进仓库并关联到 list 页面”。

## 做法
1. **HTML 原样复制**到仓库目标路径，不做格式化、不改结构、不补脚本。
2. **仅新增/更新 sidecar**，用 sidecar 承载可索引元数据：
   - `title`：优先取 `<title>` 或首屏主标题
   - `desc`：优先取 `<meta name="description">`，其次取首段摘要
   - `tags`：从页面中的显式标签 / pill / chips 提取
   - `date` / `updated`：HTML 无显式时间时，可用源文件 mtime 作为入库时间
3. **重建 `_index.yaml`**，让首页 list 自动挂上新条目。
4. **验收时确认 HTML 比对一致**，证明“只附加、未改代码”。

## 关键约束
- 不要为了入库而改 HTML 文案、CSS 或 DOM 结构。
- 不要把“补元信息”误做成“重写页面”。
- 如果页面没有显式时间字段，别硬编发布时间；优先使用附件 / 源文件的可验证时间基准。
