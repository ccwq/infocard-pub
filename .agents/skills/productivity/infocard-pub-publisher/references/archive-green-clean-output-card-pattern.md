# archive-green clean-output card pattern

## When to use
- 轻量系统信息工具
- 清爽终端输出 / 开机状态摘要
- 低噪声、低定制、强调“看得清楚”的工具
- 页面公开信号以“干净、快速、简单配置”为核心时

## Visual DNA
- 暖米纸 / 纸感背景：`#f6f4ee` / `#fcfaf4`
- 橄榄绿主强调：`#5f7e62`
- 深绿次强调：`#4a6350`
- 细线分隔、瑞士网格、平直边框、少阴影或零阴影
- 字号偏小但层级清晰，强调可扫读而不是强设计感

## Narrative shape
1. 一句话定位：轻量、干净、快速启动
2. 公开信号：stars、语言、license、更新时间
3. 核心模块：常见字段 / 输出模块 / 配置项
4. 适用场景：终端首页、装机检查、系统概览
5. 结论：适合偏好低噪声终端界面的人

## Layout cues
- HERO + 一条 source bar + 两栏或上下分区
- 左侧：模块 / 字段列表
- 右侧：示意图 / 输出预览 / 结论
- 使用小型代码块展示 config / command，避免大段解释

## Mobile checklist
- 390px 无横向溢出
- 代码块能换行或可横向滚动且不撑破页面
- 预览图保持可读，必要时只留 1–2 张代表图
- 绿色点缀只做状态与重点，不做霓虹化

## Common mistakes
- 把它做成深蓝工作台或重装饰海报
- 把“干净输出”写成营销腔
- 预览图过多导致页面太重
- 配置说明太长，压过系统信息本身
