# Pixelstack continuation heuristics

Use this note when a user asks to continue iterating on an already-published `infocard-pixelstack-style` card.

## What worked in the pi-vcc session

- Keep the **content structure stable** first. Do not reframe the card when the user wants visual strengthening.
- Improve **one visual layer per iteration** and re-verify at **390px** after each change.
- The best ROI order observed in this session was:
  1. **Make the 5 semantic slices literally visible** inside the `5 个语义切片` block.
  2. Add **hard-edge pixel sticker shadows** to labels, small cards, and tags.
  3. Strengthen the **container corners / border language** with stepped pixel accents.
- The goal is to make the diagram more self-explanatory at a glance, not to add global texture everywhere.

## Practical cues

- If the user says “继续推进”, prefer a targeted visual upgrade over broad redesign.
- If the screenshot shows one block is visually flat, subdivide that block before touching other parts.
- Keep the mobile preview URL in the reply so the user can inspect the exact page immediately.
- After each edit: build, verify, screenshot 390px, review, then publish only if the screenshot stays readable.
