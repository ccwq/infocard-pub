# Pixelstack 主题选型与移动端验收

适用场景：当用户明确说 `infocard-pixelstack-style`、像素堆叠、pixel stack、8-bit 堆叠块、思考者小人、左侧消散箭头时。

## 主题识别
- canonical theme 文件：`theme/pixelstack.html`
- 视觉锚点：米纸底、深咖描边、橙色顶层块、蓝色/浅蓝堆叠块、思考者像素小人、左侧向上箭头、反直觉金句
- 主题核心不是“像素滤镜”，而是“层级叙事”：底层承载基础条件，上层承载抽象决策

## 使用规则
1. 先确认是否存在现成主题文件或主题 skill，再决定是否新建样式
2. 用户写出的风格名如果是口语化别名，优先映射到已存在的 canonical theme
3. 若用户要求在既有主题上做内容卡，保持主题骨架，不要把像素锚点改成普通信息图

## 移动端 / 长图验收
- 长页卡片优先用整页截图而不是只截首屏
- 手机截图建议使用更高 window-size 或 captureBeyondViewport，避免把底部推荐型号误判为“被裁切”
- 验收时要同时看：
  - 页面是否横向溢出
  - 底部关键推荐是否完整可见
  - 表格/推荐卡是否保持可读

## 常见坑
- 用户说的 `infocard-pixelstack-style` 不是必须的新 skill 名称，通常应当先找现有主题文件
- 先用主题骨架，再装内容；不要反过来把内容硬塞进别的视觉语言
- 长图验收如果首屏看起来“下方没内容”，先确认是不是截图高度不够
