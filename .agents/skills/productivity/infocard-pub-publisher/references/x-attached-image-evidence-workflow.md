# X 帖附图：证据图而不是风格参考

## 适用场景

当用户给出 X/Twitter 状态链接，并且同时附带一张或多张图片时，图片默认是**内容证据**的一部分，不是风格参考。

## 工作流

1. 先抓取帖子的公开文本、作者、互动数和可见链接。
2. 同时检查用户附图：
   - 视为原帖证据或补充信息
   - 不要默认当作“仅供参考的风格图”
3. 如果帖文文本较短、被截断或只剩标题，优先用附图 OCR/视觉识别提炼：
   - 图中标题
   - 关键数据/结论句
   - 章节标题/模块标题
4. 发布时：
   - 把附图本地化到 `docs/assets/images/<slug>/`
   - 在 HTML 首屏或证据区展示
   - 报告里同时写明原帖 URL 与图片已嵌入
5. 验收时：
   - 确认页面上的图像是本地资产
   - 确认图像承担的是“证据 / 内容”角色，而不是单纯装饰

## 常见坑

- 不要把用户附图自动降级为“风格参考图”
- 不要只靠帖文文字定题；图片里的大标题和数据可能才是主信息
- 不要把热链图直接发布到公网；先固化到仓库资产目录
