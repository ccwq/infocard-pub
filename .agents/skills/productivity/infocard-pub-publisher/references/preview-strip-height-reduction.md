# 预览区高度压缩：样例色块/预览条的局部缩高

适用场景：用户要求把信息卡里某个“颜色预览区域/样例预览区”的高度压缩到原来的固定比例（例如 1/4）。

## 经验要点

- 这类区域经常不是由一个统一 class 控制，而是多个内联 `height:48px` / `height:56px` 片段硬编码在若干 sample card 中。
- 不要只改外层卡片 padding、字号或整体 page height；优先定位该 section 内所有重复的 preview strip。
- 最稳妥的做法：
  1. 搜索目标 HTML 中的 `height:<N>px` 预览条片段
  2. 只缩该 section 的 strip 高度，不动全局色块网格
  3. 修改后再搜索一次原高度，确保已全部替换

## 验收习惯

- 用 `search_files` / `grep` 思维验证“旧高度”是否彻底消失。
- 若该 section 有多个示例块，必须同步修改所有重复项，避免视觉上只缩了第一块。

## 常见误区

- 把“预览区高度”误当成“整张卡片高度”。
- 只改 CSS class，但实际渲染用的是 inline style。
- 改了一个样例块，漏掉同 section 其余样例块，导致页面高度下降不明显。
