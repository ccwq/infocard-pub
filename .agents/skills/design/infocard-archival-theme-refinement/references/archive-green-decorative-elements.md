# Archive Green decorative-element notes

## Session takeaway
When adding decoration to a high-density Swiss / archival infocard, keep ornamentation at the edges of the system, not inside the content blocks.

### Good additions
- Thin rules, corner ticks, and section dividers.
- Small uppercase badges in the existing accent color.
- Low-opacity watermark text.
- Numbered anchors (`01`, `02`, `03`) and source bars.
- Narrow label strips or sealed tags that reinforce the grid.

### Avoid
- Large poster-like motifs that compete with the content.
- Multiple new accent colors.
- Heavy shadows, gradients, or rounded UI chrome.
- Decorative flourishes that interrupt reading flow or create a template feel.

### Selection rule
If the user says "add some decorative elements," ask which direction they want before changing the composition:
1. minimal / archival
2. editorial / label-heavy
3. stronger brand signal

Default for archive / Swiss layouts: minimal / archival.
