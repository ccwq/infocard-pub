# darkgreen-style creation note

## 背景

用户最初误说要基于 abtop 创建一张 darkblue 卡，随后纠正为：应该创建一个新的信息卡风格，名称为 `infocard-darkgreen-style`，并撤回错误命令导致的结果。

## 处理策略

1. **先撤回错误产物**：
   - 从 `infocard-pub` 回退最后一次错误发布提交
   - 删除新增的错误卡文件，避免仓库遗留

2. **再创建新风格**：
   - 不再围绕 abtop 内容产出页面
   - 直接创建新的 style skill：`infocard-darkgreen-style`
   - 定位为：深绿色监控工作台 / 终端状态总览 / 本地运行安全感

3. **风格约束**：
   - 深绿、墨绿、薄荷绿是主轴
   - 偏监控、仪表盘、状态条、终端感
   - 适用于 AI coding agent / CLI / TUI / 运行状态类信息卡
   - 不适合纸感、白板、海报、人物叙事类内容

## 关键经验

- 当用户明确要求“撤回错误命令导致的结果”时，应先回滚已发布内容，再开始新任务。
- 新 style skill 应与错误产物彻底分离，避免把临时讨论内容混进主题定义。
- 风格命名最好与视觉气质直接对应，便于后续复用和检索。
