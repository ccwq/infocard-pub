# Freelancer / 灵活就业卡重建记录（Color Material 风格）

## 这次重建的有效做法

- 将页面重构成 **3 段式 hero**：左侧主叙事、中间深色控制台、右侧深色摘要栏。
- 通过 **warm canvas + dark control plane + color material nodes** 建立 Color Material 识别感。
- 用 **统计条（stats strip）+ 章节编号 + 风险/结论模块** 稳住数据海报语义。

## 文字颜色修正原则

- 浅底卡片正文必须回到 **深色正文**（接近 `#0c1220` / `#20222b`），不要长期使用浅灰正文。
- 深色面板中的正文要使用 **偏暖的浅色**（接近 `#ece8dc` / `#f0ebe0`），避免纯白过亮。
- 标题、标签、数字都必须在截图里保持清晰分层；如果视觉验收里出现“发灰”“糊”“不够硬”，优先把颜色拉回高对比，不要只改字号。

## 验收方式

- 先用本地 HTTP 预览跑通页面，再做截图验收。
- 截图重点看：
  1. 首屏 hero 是否像材料面板式控制台海报
  2. 右侧摘要栏是否真有“深色锚点”
  3. 正文小字是否仍清楚
  4. 是否出现横向溢出或断裂

## 经验提醒

- Color Material 风格的重点不是“多装饰”，而是 **信息面板化**。
- 一旦正文颜色看起来偏灰，通常不是结构问题，而是 **文本对比度** 问题。
- 适合把“趋势、结构、风险、来源、证据节点”拆成控制台式模块，而不是普通长文卡。
