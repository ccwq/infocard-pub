# hardblue：内容边框与外层边框重叠的修复原则

## 现象

在 hardblue 信息卡里，常见的问题不是“边框不够多”，而是：

- 顶部 hero 条为了贯穿全宽，写了负外边距，结果压到 shell border 上
- section / card 的边框与外层 shell 边框间距太小，视觉上合并成一条粗线
- 左右边缘内容贴死外框，页面缺少呼吸感

## 根因

1. **负外边距撑满外框**
   - 典型写法：`margin:-14px -14px 0; width:calc(100% + 28px)`
   - 这会把内部条带强行压到外层边框上，导致边框合并感

2. **shell padding 过紧**
   - 外层 padding 太小，内部结构即使没有越界，也会显得贴边

3. **边框同色同粗 + 间距不足**
   - 外层 shell 与内部组件都用 2px/3px 黑边，若 gap / padding 不够，容易被看成一根线

## 修复顺序

1. 先增加 shell padding，确保页面有呼吸感
2. 再去掉 hero 条 / 装饰条的负外边距
3. 复核 section 和 card 是否仍然贴边
4. 最后用浏览器截图确认四边没有“粗线合并”错觉

## hardblue 的默认规则

- 顶部贯穿条可以满宽，但不要靠负外边距压线
- 内部卡片边框要和 shell 外框拉开间距
- 如果想要强视觉锚点，优先用颜色块、编号块、分区标题，而不是把边框叠到一起

## 验收

- 顶部条与 shell 外框之间存在稳定留白
- 底部 footer 不压 shell 边框
- 左右边缘不显得内容边框贴死外框
- 截图放大后，看不到内部边框和外框粘连成粗线
