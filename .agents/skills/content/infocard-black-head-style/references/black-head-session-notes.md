# Black-head style session notes

这次会话把 `ky-design-to-html-skill` 的信息卡从通用黑白编辑风，继续收束到 `infocard-black-head-style`。

## 已确认的风格规则
- 黑色页眉必须明确而稳定，先定黑头，再展开白纸正文。
- 红色是主强调色，优先用于：章节编号、标题锚点、顶边条、结论标签。
- 蓝绿只能做辅强调，主要承担状态 / 分类 / 工具标签角色。
- 正文应该更像白纸手册，而不是装饰海报。
- 章节卡需要编辑风层次：标题区 > 摘要区 > 正文区 > 补充区。

## 这次调整里修正过的坑
- 不要让红色同时承担太多角色，否则会变成“警示牌风”。
- 不要让蓝绿 chip / pill 亮度太高，否则会抢主视觉。
- 390px 窄屏下要减少同屏强调元素数量，尽量做到“一屏单焦点”。
- 黑底与白卡之间不要频繁硬切，优先用统一的卡片边框、留白和章节节奏收束。

## 实际验收信号
- 顶部黑头页眉保留。
- 章节编号最终采用“黑底 + 红字”方案。
- 正文卡片和结尾总结区都加入了更明确的红色编辑风（顶边 / 标题标识）。
- 蓝绿 chip / pill 已降饱和度，避免抢戏。
- 390px 视口下已通过页面级视觉验收。
