# handline wired-style card restoration note

## Historical note
This records the phase where the page briefly drifted too clean / too flat, before the wired-style card and label language was restored to the main surfaces.

## What fixed the feel
- keep major surfaces on a wired / hand-drawn card language
- keep labels and chips tactile, with visible border and slight rotation
- keep body text dark and readable on the paper background
- preserve the editorial skeleton, but let the cards look hand-made rather than flat UI blocks

## Current rule
- `wired-elements` / wired-style card language is core to handline
- labels and chips should feel like stickers / labels, not generic pills
- border contrast stays deep, not pale
- readability still wins over pure ornament
