# codegraph → graph-paper-style session note

## What was decided

- Reference site: `https://colbymchenry.github.io/codegraph/`
- Final theme name: `infocard-graph-paper-style`
- Theme slug: `graph-paper-style`
- Theme file: `theme/graph-paper.html`

## Visual translation

- Background: warm paper / off-white, not pure white
- Main motif: graph nodes + connecting lines as the primary visual, not decoration
- Typography: system sans for body, monospace for labels / paths / IDs
- Tone: research manual, explanatory, structure-first
- Accent: a restrained blue accent for key nodes or paths only

## Alignment outcome

The user chose the “graph-paper / knowledge-graph manual” direction after a short grill-me alignment:

- paper-like, not dark terminal
- long-form manual, not poster
- graph nodes as the main visual, not a side ornament
- generic graph-paper naming, not a site-specific brand lock-in

## Reusable lesson

When a user points to a reference site and asks for a new infocard style, use a short alignment interview before writing the theme:

1. choose visual family
2. choose layout skeleton
3. choose accent / texture level
4. decide whether the graph is the main visual
5. decide naming direction

Keep the result in the class-level style skill and reserve session-specific details here.
