# 调查 / 核查卡扩写阶梯

适用场景：舆情调查、事实核查、争议澄清、政策误读拆解、来源交叉验证。

## 推荐扩写顺序
1. 一句话结论先钉住，明确卡片站哪边。
2. 事实对照：主张 / 证据 / 状态拆开，区分已证实、证据不足、部分成立。
3. 常见误区：优先拆解"少花钱=没钱""少数偏差=普遍现象""政策语言=情绪标签"等误读。
4. 为什么这类说法容易流行：补体感、标签化标题、执行层差异、传播机制。
5. 官方到底怎么表述：把正式口径单列出来，和民间转述分开。
6. 实操核查方法：给读者一个可复用的后续核查步骤。
7. 最后结论：把可证实部分与边界条件合并为一句稳妥表述。

## 当用户明确说"信息量过小 / 太薄 / 还不够厚"
- 不要只把已有句子改长；先判断缺的是哪一层：事实、误区、背景、边界、方法、还是结论强度。
- 默认优先补：**常见误区 + 为什么容易流行 + 官方表述 + 实操核查方法**。
- 如果仍显得薄，再补时间线与证据链；不要反过来先堆时间线。
- 调查卡的密度标准不是"字数变多"，而是"读者能不能直接复述：官方怎么说、外界怎么误读、为什么会传开、下一次怎么查"。

## 补强优先级
- 篇幅不够时，优先补"常见误区"和"为什么这类说法容易流行"。
- 已有大量来源但结构松散时，先做分层，不要继续堆时间线。
- 已有结论但缺少边界时，补"少数偏差不等于全国普遍"的边界句。

## 反模式
- 只给来源列表和时间线，没有误区、传播机制和核查方法。
- 只加证据，不加结构，结果像案头记录而不像可转述卡。
- 把调查卡写成纯观点卡，失去可核查性。

## 模板复用安全规则（2026-06-01 经验）

当需要参考现有信息卡结构生成新卡时，**禁止整体复用 HTML 模板内容**：

- **正确做法**：提取参考卡的 CSS token（颜色/间距/字号）、布局骨架（stats/time/cards/footer）和主题参数，在新的 HTML 中重新组合内容。
- **错误做法**：把参考卡的 HTML 内容直接复制只换名字和日期——旧卡内容会残留到新卡，且若旧卡当事人/地区有误（如山东钟先生被当成陕西韦先生），新卡会继承错误。
- **验证要求**：发布前必须用 browser_snapshot/browser_vision 确认新卡内容与当事人/地区/事件时间完全匹配，不能只靠"改标题"宣称完成更新。

## 中等密度标准

- 韦神造谣案（8大谣言+4方辟谣+时间线+传播机制+真实背景）属于中等密度：每个模块1-2句精简概括，核心数据突出。
- 中等 vs 高密度：中等 = 一个模块1-2屏；高密度 = 5屏以上连续文字。
- "舆情/调研"类默认选瑞士红黑主题，portrait 比例。
