# 信息卡内容约定与常驻记忆归属

本参考保存已由用户明确确认的内容约束；不定义新发布入口，不覆盖架构契约的授权与视觉门禁。

- 默认中文：标题、章节、标签、说明和正文中文为主；英文README或dev/tool类别不是英文交付依据。品牌、命令、API、路径保留原文，命名对照保留中文源词。只有本轮明确指定英文版或英文受众才例外。
- 保留来源实质并重新结构化，不展示agent/创作/验收元话术；代码与正文高对比、移动端可读。
- 每卡独立选择完整主题骨架，依据内容、视觉语义、素材及近期分布记录候选和排除理由；只换accent或data-theme不等于换主题。详细主题机制归项目主题契约。
- “扩写”在用户明确指定该规格时采用初学者向、渐进阅读、可追溯素材；4倍基线按用户指定的当前卡或源文计算，不能推广成所有卡的默认长度，禁止编造实测。
- 已发布卡的翻译或纠错保留原slug/URL；线上变更依当前明确授权执行，不能以本地附件冒充原线上页面修复。
- 创建、主题、promotion、视觉、索引与部署流程以项目入口和当前契约为准；本参考不授权push，不定义例外放行轮数。

## 归属

内容与语言规则归本参考；主题实现归项目主题专业Skill；更新身份归项目update-vs-new契约；发布验收归项目Publish契约。全局Skill只路由到项目，不能继续维护另一套完整生成/发布链。
