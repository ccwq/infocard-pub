核心升级拆解

1. WebUI 视觉与对比度彻底重构 (Typography & Contrast Pass)

Dashboard 视觉体验进行了一次大面积的“排版与无障碍对比度”优化：

  • 去大写化与字体解放：移除了全局 root 节点强制所有页面应用的大写 (uppercase) 和 font-mondwest 字体样式，彻底消除了先前子页面需要繁琐手动 opt-out 的问题。
  • WCAG-AA 对比度对齐：使用强语义 Token 替换了原有的 Alpha 透明度叠加 text color，在 WebUI 的 7 套内置主题 下均达到了完美的无障碍对比度标准。
  • 排版微调：小于 12px 的碎字号全部提升为统一的 text-xs (12px)；引入 text-display (基于 @nous-research/ui@0.16.0) 重构了页面标题、侧边栏标题、分段过滤器等品牌 Chrome 的字体结构。
  • API 路径拓宽：支持插件路径携带斜杠（如 observability/langfuse），解决了 category-namespaced 插件在 Dashboard 开启/关闭时的前端路径 encode 与后端 reject 问题。

2. TUI WSL 极速输入与高度视口重绘 (TUI UX Refresh)

针对在 SSH、WSL 等高延迟或窗口拉伸场景下的体验缺陷进行了深度打磨：

  • 打字零延迟 (Input Burst Commit)：彻底改进了编辑器的字符收集机制，连续输入 (Typing bursts) 会被瞬间提交，消除了高延迟环境下打字时的字符多重粘连与缓存顺序错乱，大幅改善 WSL 下的输入流畅感。
  • 视口拉伸自适应 (Virtual Scroll Refresh)：完全重构了视口高度改变时的 virtual history scroll 重绘机制，彻底消除了 resize 终端后出现的一大片空白占位块。
  • Resize 防抖与吸底：在 100ms 缩放防抖时实时检查 stickiness，防止用户在手动滚动浏览历史时因 resize 窗口被粗暴地强制拉回最底端。
  • 响应式 ASCII Banner：ASCII 艺术 Banner 现提供 4 个级别的响应式降级（Wide、Mid、Narrow、Ultra-narrow），当宽度极窄时智能隐藏，最大化腾出纵向对话视野。
  • TTS 关不掉 Bug 解决：使用 /voice off 会原子化清除 HERMES_VOICE_TTS 环境变量，并于 status 栏增加直观的 [tts] 开关状态指示灯。
  • 斜杠命令截断修复：修复了 TUI 下 slash completion 下拉框在 Yoga Flex 布局下导致 /goal 末尾字母截断的 UI Bug。

3. 漏洞封死：GHSA-5qr3-c538-wm9j 远程代码执行防线

本周最硬核的安全审计成果，在三个层级上彻底解决并防范了恶意的 Dashboard Plugin RCE 漏洞：

  • 起因：FastAPI 后端 _mount_plugin_api_routes 会根据插件 manifest 里的 api 字段动态加载 Python 模块。此前可以通过绝对路径或 .. 目录遍历跳出沙箱引入并导入恶意代码。
  • 防线一（Validator）：在 discovery 阶段引入 _safe_plugin_api_relpath 深度过滤，所有绝对路径、遍历路径、或者跳出 dashboard/ 的路径一律 reject，且不再渲染其 Backend API badge。
  • 防线二（Filesystem Re-verify）：在 importlib 加载的最后一刻再次通过文件系统对解析后的绝对路径进行强交叉校验，形成二次纵深防御。
  • 防线三（项目级插件全面禁写后端 API）：完全禁用了 CWD 目录 ./.hermes/plugins/ 级插件的后端 API 动态导入！项目插件仅允许声明前端静态 JS/CSS，彻底斩断了“用户在恶意开源仓库目录启动 Hermes 导致直接被侵入”的终极隐患。
