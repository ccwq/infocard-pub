02推文没说的第一件事：插件从哪来

A微软条款禁死了这条路——FAQ 原引 Marketplace Terms of Use："Marketplace Offerings are intended for use only with Visual Studio Products and Services"。code-server 用的是 VS Code 开源核心（Code OSS），不允许访问微软扩展市场。
B替代品是 Open VSX（Eclipse 基金会运营）——主流扩展大多有，但覆盖不全、版本常滞后；装不了的去 GitHub Releases 下 .vsix 手动 --install-extension。从 VS Code 桌面版迁过来第一件事就是清点插件清单。
C同定位的官方备胎——微软自己有 "VS Code Server + code tunnel"（code tunnel 一条命令、走微软中继、能用官方市场），但网关在微软云上、公司项目未必允许。两条路线的选择本质是：插件生态（官方 tunnel）vs 自托管主权（code-server）。

03十分钟架起来：安装、改密、暴露

  1. 装——官方脚本一条命令（Linux/macOS/FreeBSD，自动识别包管理器，可先 --dry-run 预览）：curl -fsSL https://code-server.dev/install.sh | sh。Docker 党：docker run -it --name code-server -p 127.0.0.1:8080:8080 -v "$PWD:/home/coder/project" codercom/code-server（UID/GID 转发、配置挂 ~/.config）。npm：npm i -g code-server。还有 Helm/树莓派/Termux/Windows 全平台文档。
  2. 改密——配置在 ~/.config/code-server/config.yaml：改 password 字段后 sudo systemctl restart code-server@$USER；支持 hashed-password（argon2：echo -n "密码" | npx argon2-cli -e）。
  3. 暴露（三选一，安全性递减）——① SSH 端口转发（默认推荐，零暴露面）：ssh -N -L 8080:127.0.0.1:8080 user@服务器；② Let's Encrypt 正式域名：Caddy 两行配置或 NGINX + certbot，bind-addr 改 0.0.0.0:443；③ 自签证书（iPad PWA 需要，需在设备装证书）。
  4. iPad 化——Safari 打开后"添加到主屏幕"即成 PWA（全屏+手势）；文档有专章讲自签证书信任与 ctrl+c 已知问题的处理。
  5. 进阶——容器里用 Docker：挂 /var/run/docker.sock + 装 CLI；团队批量管理：上 coder/coder（注意 AGPL）；子路径/子域名代理前端项目（React/Vue/Angular/Svelte 各有专节）。

04它是谁：一段七年的历史

code-server 2019-02 就建仓了（比 GitHub Copilot 还早两年半），最初是个人项目（cdr），后归入 Coder 公司——商业模式是"开源核心 + 企业版平台"的经典打法。它的存在证明了"浏览器 IDE"这条路的真实需求：7.3 万星不是情怀票，是无数"在公司 Windows 上开发 Linux 项目""iPad 上救急改 bug""借机器写代码不想装环境"场景投出来的。2026 年的今天，它依然是这个赛道事实上的自托管标准。

版本节奏读法：code-server 本体功能极少新增——CHANGELOG 几乎每条都是"Update to Code 1.13x"+零星修复（如 4.138 修了代理重写 URL 丢失 query、4.139.1 修 --idle-timeout-seconds 校验）。这是对的：它是壳，VS Code 是核，跟进上游就是它的工作。

05冷静面与判断

四个折扣点：① 插件市场硬伤——依赖微软私有扩展（C#/Pylance 系官方语言包等）的项目会直接卡住，迁移前先查 Open VSX 覆盖；② 推文"重活全在服务器"成立的前提是网络稳定，WebSocket 断连在弱网下体验明显劣化；③ coder/coder 是 AGPL-3.0，SaaS 化使用有传染义务；④ 浏览器剪贴板/IME/快捷键与本地 IDE 仍有细节差异，重度键位党需要适应期。

判断：推文是罕见的"数字零误差"型安利，场景描述（装依赖十分钟、风扇狂转、电量掉比进度条快）真实到不像广告。code-server 的定位一句话：把开发环境从设备解绑到服务器——配 1 核 1G 的旧笔记本都行，iPad 秒变生产力。只要你的插件在 Open VSX 有货、网络过得去，它就是"写代码的地方从此是一个网址"的最短实现。
