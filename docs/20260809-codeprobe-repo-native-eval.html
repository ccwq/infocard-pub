这张卡先回答什么？
01 / 结构它把哪一层工程问题标准化？

01

已确认的核心事实

按官方文档、Release 或仓库 README 逐条落地。

FACT 01

事实 1

CodeProbe 从 merged PR/commit 重建 Agent-ready 任务，并记录已知正确提交作为 ground truth。

FACT 02

事实 2

可用测试脚本、oracle 或双重验证检查结果，并记录分数、成本、Token、延迟等指标。

FACT 03

事实 3

当前 README 将 Claude Code 列为 Supported、Copilot 为 Preview、Codex 为 Unsupported。

02

落地时不要混淆

把工具能力、项目自述和可验证边界分开。

BOUNDARY 01

边界 1

私有仓库的历史 PR 比公共榜单更接近团队真实工作。

BOUNDARY 02

边界 2

运行会执行自治 Agent 与挖掘出的第三方验证脚本，必须在容器中使用。

BOUNDARY 03

边界 3

脏工作区、浅克隆和缺少容器会阻断或污染评测。
