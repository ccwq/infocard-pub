01
Section One

它是什么

Prime Agent 是 PrimeIntellect（OpenR1 的发起方）开源的编程与研究 Agent，基于 pi（TUI）和 IPython 构建，核心是 RLM（递归语言模型）编程模型与 Continual Harness 自我改进机制。

RLM 编程模型

上下文作为变量（prompt-as-a-variable），工具与子智能体作为函数调用（programmatic tool/sub-agent calling），在持久 REPL 中以代码驱动 Agent 行为。

Continual Harness

增量改进型 Harness：通过 /refine 审查轨迹后，以小步证据驱动更新 supplemental 状态，支持快照回滚，始终保留 base system prompt 不变。

一切皆代码

文件操作、Shell、工具调用、子智能体、上下文管理均通过 Python 代码实现，IPython 是唯一的模型工具，无状态流式拼接。

内置子智能体

rlm(...) 原生支持并行或后台运行子智能体并程序化返回结果，支持 Agent 间直接消息通信，无需用户中转。

02
Section Two

核心内置能力

与 Claude Code、Codex CLI 不同，Prime Agent 强调持久化状态、子智能体协作与长期自主运行，而非单次会话交互。

/refine

Harness 改进

增量更新 supplemental prompts、记忆、Skill 描述、子智能体规格；记录历史，支持快照回滚。

/goal

长期目标

跨轮次持续追踪目标和进度，直到完成、暂停或清除。

/heartbeat

心跳机制

定时重入会话，支持 rlm_heartbeat 和 prime-agent schedule。

/autonomous

自主模式

在配置的 turn/token/time 预算内运行，支持用户定义质量门。

Daemon 持久化

后台连续

终端断开后 Agent、IPython 状态、子智能体保持运行，可随时 reattach。

Agent 间通信

直接消息

运行中的 Agent 和 retained subagent 可相互发现、交换消息、驱动工作。

Context 压缩

上下文压缩

自动压缩长轨迹，自动保留 subagent 状态，跨 turn 和终端保持进度。

Skills 系统

可执行 Skill

Skill 是可导入的 Python 包，内置 Skill Creator 可将工作流固化为项目或个人 Skill。

Section Three

快速上手

一行命令安装，首次启动后运行 /login 选择订阅或填入 API Key，即可在当前目录工作。

curl -fsSL https://app.primeintellect.ai/prime-agent/install.sh | sh # 安装 cd /path/to/project prime-agent # 启动（自动在当前目录工作） prime-agent agents # 浏览运行中 / 空闲 / 已保存的会话 prime-agent attach <agent> # 重新附着一个会话 prime-agent doctor [--fix] # 检查或修复后台服务 prime-agent update [--force] # 更新 prime-agent shutdown [--force] # 停止所有 Agent

首次认证

首次启动后运行 /login，选择订阅计划（ChatGPT、Codex Plus/Pro 等）或直接填入自定义 API Key Provider。Provider 配置支持多家 LLM 服务。

工作目录

Prime Agent 在当前目录工作，不建隔离沙箱。建议使用 disposable clone、clean worktree 或可检查/恢复的 checkpoint 启动。

04
Section Four

架构概览

基于 pi（TUI）构建，Daemon + Worker + Kernel 三层分离，IPython 提供持久化控制环境，Harness 状态在 Kernel 层持久。

Daemon 层

后台服务管理生命周期，处理 Agent 调度、session 持久化、worker 进程管理。终端断开后保持运行。

Worker + Kernel

Worker 承载 IPython 运行时；Kernel 持有持久状态（Harness、记忆、Skill）。Worker 重启后可恢复 Kernel 状态。

pi TUI

基于 pi 的终端 UI，提供 attach/detach、会话管理、命令交互界面。

rlm(...) 子智能体

在 IPython 中以函数调用方式触发：result = rlm("task", parallel=True)。支持 Retained Subagent——子智能体可在父 Agent 轮次结束后继续运行并返回结果。

rlm(task, parallel=True) retained subagent daemon-backed 消息通信

Section Five

风险与限制

⚠

非安全沙箱

Worker 和 Kernel 进程改善了生命周期隔离和恢复，但 不是安全沙箱。执行模型生成的代码等同于授予该代码用户级权限。

!

目录权限

Prime Agent 在当前目录工作，会修改文件。使用 disposable clone 或 clean worktree，避免污染重要项目。
