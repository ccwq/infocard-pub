03
12-CHAPTER PATH

从“看懂结构”走到“动手构建”

章节顺序按认知铺开：先建立内部模型，再进入检索、生成与训练。

01—03 / FOUNDATION

语言模型 → 词元 → Transformer

先回答数据如何流过模型，而不是先背 API。

04—07 / APPLICATION

分类、主题、提示与生成

把基础结构连接到可观察的任务行为。

08—10 / RETRIEVAL

语义搜索、RAG、多模态与嵌入

从生成模型扩展到检索和表示学习。

11—12 / TRAINING

表示模型与生成模型微调

最后进入训练与适配，而不是一上来调参。

04
HOW TO USE

推荐的最短上手路径

不需要先准备本地 GPU；官方建议优先通过 Google Colab 跑示例。

1

先读图，不急着复制代码

用章节中的图和文字建立词元、嵌入、注意力与 Transformer 的数据流直觉。

2

打开 Colab，逐格观察

README 为每章提供 Open in Colab 链接；先改变输入，观察输出，再回头解释机制。

3

按兴趣分叉到主题

想做知识库就进入语义搜索/RAG，想做适配就进入嵌入训练和微调章节。
