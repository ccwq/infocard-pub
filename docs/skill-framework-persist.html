01
CHAPTER · 结论

Skill 框架不会消失

Skill 不是一次性 prompt，而是长期存在的场景策略层。

✗

错误解读

AI Coding 不需要 Skill 框架了。

✓

正确理解

Skill 会一直存在，只会随着 Harness 的进化不断新老更替。

→

关键点

变化的是框架形态，不是这个层本身。

02
CHAPTER · 更替逻辑

SuperPowers → Matt Skills

Harness 进步之后，Skill 框架的职责也随之迁移。

SuperPowers

旧时代

Agent 还没有 /goal 这样的长程执行能力，Skill 框架承担了大量基础补位工作。

Matt Skills

新时代

Harness 更强以后，Skill 开始聚焦更垂直的流程，比如 grill-me、brainstorming。

04
CHAPTER · 案例

grill-me vs brainstorming

两条不同的需求对齐路径。

grill-me

BFS 追问

适合需求模糊、边界复杂、必须逐层确认的场景。

brainstorming

方向对齐

适合探索、创意、快速收敛到大方向的场景。
