@卡颂（X 账号）在 2026-07-27 发帖回应"Skill 框架将消亡"的观点，核心论点：Skill 框架不会消失，只会被替换。他指出 SuperPowers 出现时 Agent 还没有长程执行能力（/goal），现在很多人抛弃 SuperPowers 转投 Matt Skills 是因为 Harness 本身在进步。但 Harness 只能内置"先对齐需求再实现"这个流程，而"如何对齐"——是采用 grill-me 这样的 BFS，还是 brainstorming 这样的只对齐模糊方向——都是场景相关的，Agent 没法内置。Skill 框架负责的就是这个"场景相关层"，所以会一直存在。

01
CHAPTER · 错误解读 vs 正确理解

Skill 框架消亡论的问题

有人误读了 Matt Pocock 的文章，以为 AI Coding 不再需要 Skill 框架。

✗

错误解读

AI Coding 以后不需要 mattpocock/skills、superpowers 这样的 Skill 框架了。Harness 能替代一切。

✓

正确理解

Skill 框架会一直存在，只不过随着 Agent 发展不断新老更替。Harness 进化是驱动力，不是替代者。

02
CHAPTER · SuperPowers vs Matt Skills

新老 Skill 框架的更替逻辑

不是"旧的被淘汰"，而是"Harness 进化让新框架成为可能"。

SuperPowers已更替

SuperPowers 时代的 Agent 能力

SuperPowers 出现的时候，Agent 还没有 /goal 这样的长程执行能力。那时候的 Skill 框架要填补的空白比现在大得多。

  • Agent 缺乏长程记忆
  • 没有 /goal 长程执行
  • 上下文窗口有限
Matt Skills当前主流

Matt Skills 时代的 Agent 能力

现在很多人抛弃 SuperPowers 转投 Matt Skills，是因为 Agent Harness 本身在进步——有了更长的上下文、更强的 /goal 执行。

  • 长程执行能力成熟
  • Harness 内置了更多流程
  • Skill 框架可以专注于更垂直的场景
关键洞察：Harness 的进化不是"消灭 Skill 框架"，而是"让更先进的 Skill 框架成为可能"。每代 Skill 框架都比上一代更贴合当前 Agent 的能力边界。

04
CHAPTER · Skill 框架的本质

Skill 框架 = Agent 能力的"场景相关层"

它填补的是 Harness 和真实场景之间的空白。

Layer 1

Agent Core（Harness）

通用能力：理解、执行、长程记忆、/goal 执行。这是 Agent 自己的，不能被 Skill 框架替代。

Layer 2

Skill 框架

场景化策略：grill-me（BFS 追问）、brainstorming（模糊对齐）、tdd（TDD 流程）、diagnose（诊断流程）。这些是 Harness 没法内置的。

Layer 3

场景微调 / 模板

针对具体项目/领域的 prompt 模板、工作流约定。这是 Skill 框架之上的最后一层。

05
CHAPTER · 新老更替的方向

Skill 框架的演进规律

每一代 Skill 框架都更贴合当前 Agent 能力边界。

旧框架

SuperPowers 时代

要填补的大空白：长程记忆、上下文管理、工具编排基础。

当前主流

Matt Skills 时代

Agent 已有 /goal 长程执行。Skill 框架专注于更垂直的场景（grill-me / tdd / diagnose）。

下一代

未来 Skill 框架

当 Agent 有了更强的多模态、更长的上下文，Skill 框架会进一步专业化。场景化程度会更高。

06
CHAPTER · 典型 Skill 框架案例

grill-me vs brainstorming：两种对齐路径

Harness 内置"要对齐需求"，但具体怎么对齐由 Skill 框架决定。

BFS 追问

grill-me

Broad（广度优先）：把问题拆成最小子问题，逐个追问确认，不遗漏任何假设。适合：需求模糊、利益相关方多、必须对齐所有边界条件。

  • "你说的 X，具体指什么？"
  • "如果出现 Y 情况，系统怎么处理？"
  • "这个约束是必须的还是可以松的？"
模糊对齐

brainstorming

只对齐模糊方向：快速产出、允许偏差、迭代收敛。适合：创意类任务、方向探索、团队对齐初期。

  • "我们先出一个版本，看看方向对不对"
  • "这个方向可以，先往下走"
  • "这个方向偏差较大，需要调整"
Harness 能内置"要对齐"，但内置不了"用什么策略对齐"——这是 Skill 框架永恒的价值。
