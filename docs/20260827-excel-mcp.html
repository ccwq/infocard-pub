INSTALL · 安装与使用

安装方式

Windows + .NET 8 环境，需要本地安装 Microsoft Excel 2016 及以上版本。

方式一MCP Server

Claude Desktop / Agent 集成

{
  "mcpServers": {
    "excel": {
      "command": "dotnet",
      "args": ["ExcelMcp", "mcp"]
    }
  }
}
方式二CLI 直接调用

命令行操作 Excel

dotnet tool install -g ExcelMcp
excelmcp --help
excelmcp read-cell "Sheet1!A1"
excelmcp write-cell "Sheet1!B2" "Hello"
前置要求重要

系统要求

  • Windows 操作系统
  • .NET 8 Runtime
  • Microsoft Excel 2016 及以上（需启用 COM 自动化）
  • AI Agent 端需支持 MCP 协议（Claude Code、Codex、Copilot）
