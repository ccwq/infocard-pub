装进支持 AgentSkills 的 runtime 后，agent 即可响应自然语言指令生成演示。

🎤 演讲者模式

按任意幻灯片页的 S 键，弹出独立的演讲者窗口，包含四个可拖拽的磁性卡片：

  • 当前页预览 — iframe 逐帧同步，与观众视角像素完美一致
  • 下一页预览 — 提前掌握节奏
  • 逐字稿 — 每页 150–300 词，约 2–3 分钟演讲节奏
  • 计时器 — 全局时间可视化
两个窗口通过 BroadcastChannel 保持同步，切换页不刷新、无闪烁；每张预览卡都是独立的 <iframe> + ?preview=N 参数，与观众视角使用完全相同的 CSS、主题和视口。
逐字稿三原则
  1. 提示词，不是朗读稿：加粗关键词，把过渡句单独成段
  2. 每页 150–300 词：约 2–3 分钟演讲节奏
  3. 写得像说话：口语化，不是书面语

📌 边界说明
  • 生成的是 HTML 演示，不是 PPTX：适合发布会、技术分享、小红书图文、在线展示；不适合需要传统 Office 软件打开的场景。
  • 浏览器兼容性：依赖现代 CSS/JS 特性，建议使用最新版 Chrome / Edge / Firefox。
  • Canvas FX 有性能开销：粒子类效果在低端设备上可能卡顿，适合发布会舞台机，不建议投屏到老旧设备。
  • 本地离线使用需 clone 仓库：npx skills add 需要网络下载，完整离线使用需自行 git clone。
