03
NEW FEATURE · X 帖子称

V3 新能力①：AI 局部文字编辑

X 帖子称本次更新首次加入信息图局部编辑能力，支持高精度调整局部文字和整体风格

🔴 X 帖子宣称：SenseNova U1 V3 首次加入信息图编辑能力，支持高精度调整局部文字和整体风格，大幅提升图像编辑效率。

据 @GitHub_Daily 的 X 帖子描述，这是本次更新的核心突破——从"只能生成"升级为"可局部编辑"，使用户无需整体重新生成即可修改特定区域内容。

✏️ 局部文字调整
高精度局部文字修改

对图片中局部文字进行高精度修改，而非只能整体替换或重新生成整个信息图。

适用于：错误文字修正、内容更新、措辞优化等场景。

🎨 整体风格调控
对画面整体风格局部调控

在保留信息图核心结构的同时，对整体视觉风格进行局部调控和适配。

X 帖子称此功能大幅提升了图像编辑效率，相比传统手动编辑节省大量时间。

📋 编辑能力说明
验证状态与边界

Infographic 版本（2026.05.15）支持信息图生成；V2（2026.07）重点提升排版质量。

⚠️ "局部编辑已有信息图"（inpainting/editing）功能的具体实现细节和上线时间，公开文档描述有限，需进一步核实。

来源：GitHub commit · 腾讯内容平台文章

ADAPTIVE STYLE · 有文档支撑

V3 新能力②：文字风格自适应

AI 修改的文字内容自动适配原图设计风格与布局，此能力有 GitHub 官方示例文档支撑

■ 工作机制
文字自动适配原图风格与布局

经 AI 修改后的文字内容，会自动适配原图像的设计风格与排版布局，无需用户手动调整字体、颜色、位置。

用户可以在保留核心信息与结构的同时，更换视觉表达方式。

来源：GitHub 示例文档 u1_infographic_showcases.md
■ 文档交叉验证
GitHub 官方示例支撑

GitHub 示例文档（u1_infographic_showcases.md）展示了详细 prompt 和生成效果，描述了文本框布局、样式适配等能力。

README_CN.md 描述了用户可「保留核心信息与结构同时切换视觉表达」的能力，GitHub 示例展示了 5G-A、电信品牌等多个不同风格案例。

🛠 自动修正
自主调用编辑能力完成纠错

此能力依赖于局部编辑功能的成熟度（见上文第 03 节）。
