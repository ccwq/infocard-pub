Claude Code Templates 是面向 Claude Code 的生产级模板库：100+ 预置 Agent、命令、MCP 服务器、Hooks 配置，开源免费，npx 一键安装。
如果你从零搭建 Claude Code 工作流，这个模板库能帮你省几个小时。配套的 Analytics 监控面板 可视化 agent 调用链路与 token 消耗，Health Check 诊断安装状态。
