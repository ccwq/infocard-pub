GRID-3

三列卡片：标签 + 标题 + 要点

结论红蓝

硬核蓝手册强调什么

适合重型多章节手册、调查、观点拆解；视觉锚点更多、更厚。

  • hero-bar 三色
  • 编号块 + 编号
  • 风险顶部色带
版式多 grid

适合什么内容

长卡、多章节、5+ 段落、每段需要 3-4 段小卡的内容。

  • 调查复盘
  • 技术手册
  • 观点拆解
边界不适合

不适合什么

轻量卡片、贴纸 Q 风、纸感单格图卡都不适合硬核蓝手册。

  • Q 风贴纸
  • 纸感手作
  • 极简单图卡
02
MATRIX · 4 列

matrix：四组对照

适合 2×2 或 1×4 的对照、阶段、风险四象限。

01 / 出场

硬核蓝 vs Q 风

前者用 3px 黑边+编号块，后者在暖米纸上贴贴纸。

气质的差别比配色更深。

02 / 排版

网格 vs 自由

42px 网格底纹 + 多 grid；Q 风基本不画网格。

硬核蓝把"工程感"做成视觉骨架。

03 / 信息密度

高密度 vs 低密度

硬核蓝在 720 宽下塞 4 列 matrix；Q 风 2 列就算多。

一张卡的承载力不一样。

04 / 装饰

色块 vs 贴纸

红/蓝/黑纯色块当锚点；Q 风用贴纸和小图标。

前者像说明书，后者像笔记本。

03
RISK · TOP-COLOR

risk 顶部色带：data-accent 三色

risk 顶部 8px 色带 + 编号方块 + 标题 + 正文；red/blue/dark 三套。

1

结论 / 警示（红）

用红色顶部色带 + 红色编号块；适合"红线 / 风险 / 必须停"。

2

流程 / 中性（蓝）

用蓝色顶部色带；适合"步骤 / 分层 / 工具用法"。

3

黑底 / 总结

用黑色顶部色带；适合"最终结论 / 收口 / 黑头判断"。

04
GRID-2 + QUOTE-BLOCK

grid-2：双栏对照 + 蓝色 quote-block

硬核蓝手册的"成对内容"和"单条引文"标准组合。

适用场景

双栏对照标准用法

左栏"是什么"，右栏"不是什么"；或"成立 / 失真边界"。

  • 对照式分析
  • 边界说明
  • 真伪并列
最关键的一句：硬核蓝手册 = 同色系 + 更厚边框 + 多 grid + 大编号块 + 网格底纹。它不是新色系，是 blue-technical-manual-style 的"重装版"。

alert 变体 / 参数行 / mini-tag / 对比表

06
CODE · FOOTER-BLOCK · SAVE-FAB

代码块 + footer-block + 导出按钮

硬核蓝手册支持代码高亮（pre）、footer-block（收口说明）、以及 save-fab 导出按钮的完整样式。

// 代码块风格
# 硬核蓝手册配置
theme: "hardblue-style"
grid: [2, 3, 4]
accent: ["#d80018", "#1f63ff", "#111"]
min_font_size: 12
# 禁止事项
not_use_blue_hardblue: true  # 蓝黄绿辅助色只作状态标识

收口说明 · footer-block

硬核蓝手册适合重型多章节技术手册、调查、观点拆解。footer-block 是最后一个信息块，用于放"收口句"和"来源说明"。

  • 收口句：总结本卡的核心结论
  • 来源：说明数据来源或方法论出处
  • 边界：注明本卡的适用范围和局限性
