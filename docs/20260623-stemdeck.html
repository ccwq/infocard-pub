把一首歌拆成 6 轨，全部在本地完成

StemDeck 是免费、开源的音频分轨工具：拖入 MP3/WAV/FLAC 或粘贴 YouTube URL，用 Meta AI 的 Demucs htdemucs_6s 模型分离出人声、鼓、贝斯、吉他、钢琴、其他 6 条音轨，然后在 DAW 风格混音器里播放、独奏、调音量、导出。音频不上传，无需账号，无需订阅。

使用流程

从导入到导出

01 · 选轨

在导入栏点击 stem chips，选择要提取哪些轨（默认全部 6 轨）。

02 · 导入

粘贴 YouTube URL 或拖入 MP3/WAV，点击 Process。

03 · 处理

Uploading → Analyzing → Separating → Mixing，全程可取消。

04 · 混音

DAW 风格面板：Play/Pause/Stop，M 静音，S 独奏，Monitor 单独监听。音量推子拖拽，双击复位 0dB。

05 · 循环

在标尺上拖拽定义循环区段，点 Loop 启用。+/-/Fit 或 Ctrl/Cmd+滚轮缩放。

06 · 导出

Download Mix 导出选中音轨的混合 WAV；也可导出单轨 WAV/MP3。

键盘快捷键

Space 播放/暂停 · [ 后退 5s · ] 前进 5s · L 循环 · I 循环入点 · O 循环出点

可取消任务

处理中途可取消——runner 立即终止子进程、删除部分文件目录、回到就绪状态。

安装方式

三种安装

1. 预构建安装包（推荐）

# macOS StemDeck-macOS-arm64.dmg # Apple Silicon StemDeck-macOS-x64.dmg # Intel # Windows / Linux — 见 Releases

2. Web Server（macOS / Linux / Windows）

git clone https://github.com/stemdeckapp/stemdeck \ stemdeck && cd stemdeck ./run.sh setup # 安装 ffmpeg + uv + uv sync ./run.sh start # 启动 → localhost:8000

3. Docker

docker compose -f build/docker-compose.yml \ up --build
首次启动

桌面版首次启动会下载 Python 运行时（~500MB）、FFmpeg 和 Demucs 模型（~170MB）。后续启动跳过，秒开。

适用场景

练习（单独听人声/鼓）、转录（隔离某乐器后扒谱）、混音（提取素材重新编曲）、创作（采样某轨做新作品）。

技术栈

构建基础

分轨引擎

Demucs htdemucs_6s — Meta AI 开源 6 轨神经网络。自动检测 CUDA (NVIDIA) / MPS (Apple Silicon) / CPU。

后端

Python 3.12 + FastAPI，REST + SSE。uv 管理依赖。

桌面壳

Tauri v2（Rust/WKWebView on macOS，Rust/WebView2 on Windows）。

前端

原生 JS + Web Audio API，无框架、无构建步骤。波形用 <canvas> min/max 渲染。

音频处理

FFmpeg（转码/混音）、yt-dlp（YouTube）、librosa（BPM/调性）、pyloudnorm（LUFS）。

免责声明

StemDeck 是本地音频分轨工具，不是下载服务。不存储、不缓存、不分发任何音频。YouTube URL 通过 yt-dlp 提供，用户需确保有权处理相关音频并遵守版权和服务条款。
