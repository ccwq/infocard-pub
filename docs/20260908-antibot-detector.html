05隐私设计与边界

本地检测：全部在浏览器内完成，不收集上传任何数据；无内联事件处理器、无 unsafe-eval；MAIN / ISOLATED 世界正确隔离。

使用边界：这是检测与安全研究工具，告诉你"这个网站用了什么防护"，不提供绕过手段，不代表绕过行为合法；目标站点服务条款和法律边界由使用者负责。

许可证说明：NPOSL-3.0 允许个人和非商业免费使用；商业再分发需单独授权。

自动更新：Chrome Web Store 安装自动更新；手工安装需重新下载最新 Release 并 Reload 扩展。
