01 / 它能看到什么

验证码

reCAPTCHA、hCaptcha、FunCaptcha、GeeTest、Cloudflare Turnstile。

反爬系统

Cloudflare、Akamai、DataDome、PerimeterX、Shape Security、AWS WAF、Imperva、Kasada。

浏览器指纹

Canvas、WebGL、Audio、Font、WebRTC、Performance、Navigator、Storage 等采集手段，逐项标出。

置信度评分

每条检测结果带 confidence score，不是模糊提示；高置信命中提前退出，减少误报。

02 / 五层检测引擎

DOM 分析识别反爬脚本、特征类名与 HTML 元素
网络监控分析 Cookie、响应头与 URL 特征
Payload 分析检查请求体，支持 URL 模式与 HTTP 方法过滤
JS 钩子document_start 同步拦截指纹 API（Canvas/WebGL/Audio 等），钩子目标由检测器定义驱动
Window 属性检查全局作用域中的反爬对象

03 / 高级捕获工具

针对特定系统的专用采集：提取 reCAPTCHA / hCaptcha / Turnstile 的 SiteKey、Akamai sensor data、FunCaptcha 公钥、GeeTest challenge 参数；挑战中间页会在重向前自动抓取。

规则编辑器

检测规则完整增删改查：支持 Cookie / Header / URL / Content / DOM / Window / JS Hooks / Payload 八种方法，regex、整词、大小写可配，规则 JSON 导入导出分享。

性能设计

12 小时检测缓存 + 后台验证；正则 LRU 缓存提速 60-80%；按需收集数据；JS 钩子 2 秒不活跃超时、最长 8 秒窗口。

04 / 隐私与边界

隐私设计：全部检测在浏览器本地完成，不收集上传任何数据；CSP 合规（无内联事件处理器、无 unsafe-eval）；MAIN / ISOLATED 世界正确隔离；条件求值器预编译，不做 eval 或任意代码执行。
使用边界：这是检测与安全研究工具——它告诉你"这个网站用了什么防护"，不提供绕过手段，也不代表绕过行为合法。目标站点的服务条款和法律边界仍由使用者自己负责。
