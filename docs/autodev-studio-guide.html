AutoDev Studio 使用指南：从第一次建库到高级流水线

从安装、导入 Git 仓库、建立知识库开始，逐步配置 PM / Dev / QA / Review / PR。

适合第一次接触的开发者，也适合需要把多模型、成本、权限和修订循环纳入工程控制的高级用户。

01
CHAPTER · 入门

安装与第一次启动

Python 3.11+、git，一种模型来源即可。

Install

源码启动

git clone → cp .env.example .env → ./run.sh；默认 http://localhost:8017。

Power

至少一种模型来源

已有登录的 Claude Code / Codex / Cursor / Gemini CLI，或 API。

First boot

管理员密码

设置 ADMIN_PASSWORD；留空则生成随机密码并只打印一次。

Safety

先别开真实 PR

DEMO_MODE=true 默认只模拟 PR 阶段。

02
CHAPTER · 新手路径

五步跑通第一个任务

每一步都有可观察结果。

01

Knowledge

Git URL → Build knowledge base → Set active。

02

Models

Settings → Agent models，配置每个 stage。

03

Scope

描述功能，回答 PM 澄清问题，Draft tickets。

04

人工批准

Board 中批准 ticket；未经批准不碰代码。

05

Run 并观察

看 Dev → QA → Review → PR 的实时日志和成本。

03
CHAPTER · 模型配置

按阶段分配 provider 和 model

强模型给 Dev，便宜模型给 QA / Review。

Knowledge

知识合成

KNOWLEDGE_PROVIDER / KNOWLEDGE_MODEL。

PM

需求澄清

PM_PROVIDER / PM_MODEL。

Dev

代码实现

CODING_PROVIDER=auto，优先已登录 CLI。

QA

测试检查

QA_PROVIDER / QA_MODEL，独立于 Dev。

Review

差异审查

REVIEW_PROVIDER / REVIEW_MODEL，建议换模型家族。

Fallback

无 embedding 也能跑

RAG_EMBEDDINGS=tfidf。

04
CHAPTER · 高级知识库

语义 RAG、结构化视图与刷新策略

高级用户重点看成本控制和新鲜度。

Semantic

fastembed + Qdrant

bge-small，本地运行，首次约 90MB。

Fallback

TF-IDF

纯 Python、无额外依赖。

Views

结构化地图

architecture / modules / features / workflows / rules。

Refresh

刷新阈值

KB_FULL_REBUILD_FRACTION=0.25 或 FILES=100 触发全量。

05
CHAPTER · 高级流水线

修订循环、快速路径与成本

不是所有任务都走完整流程。

MAX_REVISION_ROUNDS

失败再回 Dev

QA/Review 明确 FAIL 时回 Dev，默认最多 2 轮。

FAST_PATH

小任务快速通道

单 ticket、grep 定位、小 diff、测试零失败才跳过 LLM QA/Review。

INCONCLUSIVE

错误不能算通过

Agent 出错且无 verdict 时不能静默放行。

06
CHAPTER · 安全与交付

什么时候可以打开真实 PR？

权限、分支、成本和宿主机风险一起检查。

Before

检查权限

确认角色、密钥加密、仓库可信。

Workspace

隔离目录

REPOS_DIR 使用无空格路径；clone + 独立 branch。

Tests

确认可运行

DEV_RUN_TESTS=true；无 runnable suite 不用 Fast Path。

Release

最后关闭 Demo

DEMO_MODE=false + gh 已认证 + OPEN_REAL_PR=true。

07
CHAPTER · 排障

常见问题快速定位

先区分知识库、模型、权限和流水线问题。

模型失败

先看 provider

API key、base URL、模型名和 CLI 探测。

检索为空

切换 TF-IDF

验证是否为 embedding/Qdrant 可选依赖问题。

PR 没创建

检查 Demo mode

默认 true；关闭后检查 gh 和 OPEN_REAL_PR。
