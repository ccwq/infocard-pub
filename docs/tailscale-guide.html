01
CHAPTER · 入门

初装与登录

把第一台设备接入 Tailnet。

Linux

一键安装

curl -fsSL https://tailscale.com/install.sh | sh → sudo tailscale up → 用浏览器账号登录。

macOS

brew install

brew install tailscale 或官网安装包。装好后菜单栏会出 Tailscale 图标，点登录。

Windows

winget

winget install tailscale，或官网 .exe，安装后系统托盘登录。

Docker

无守护

用 tailscale/tailscale 镜像，需 --network=host + /var/lib/tailscale 卷 + authkey。

02
CHAPTER · 状态

状态查看与连通性

进了 Tailnet 之后最常用的命令。

status

节点列表

tailscale status：所有节点、IP、在线状态、最后活跃时间。

ping

连通性

tailscale ping <host>：测两节点连通性，P2P 或 DERP 中继。

netcheck

网络体检

tailscale netcheck：DERP 中继、UDP/TCP 可用性、延迟。

03
CHAPTER · tailscale up

up 参数速查

所有高级能力都靠 up 的 flag 启动。

网络

路由与转发

--advertise-routes、--accept-routes、--exit-node

安全

身份与权限

--operator、--ssh、--accept-dns=false

命名

设备身份

--hostname、--netfilter-mode=off

常用组合

一次性起服务

sudo tailscale up --accept-dns=false --ssh --operator=ccwq --hostname=workstation

改运行时

tailscale set

sudo tailscale set --ssh=true --exit-node=auto。比 up 更细粒度。

05
CHAPTER · ACL

权限控制（ACL）

Tailnet 级别的访问控制，HuJSON 格式。

最小示例

全开

{ "acls":[{"action":"accept","src":["*"],"dst":["*:*"]}] }。所有设备互相访问。

限制 SSH
按用户组

仅管理员可 SSH

src: ["group:admins"] + dst: ["tag:server:22"]。普通用户连不上 22。

标签

tag:server

给节点打标签，ACL 按 tag 写策略，可读性更高。

生效

实时下发

控制台改 ACL 后立即生效，所有设备下次握手时拉取新策略。

06
CHAPTER · 路由

Exit Node 出口节点

让整个 Tailnet 共享一个出口 IP。

出口机

启用

sudo tailscale up --advertise-exit-node → 控制台批准。

客户端

使用

sudo tailscale set --exit-node=<name> 或 auto 自动选最低延迟。

验证

出口 IP

curl https://ifconfig.me，看出口 IP 是否已切到 Exit Node。

07
CHAPTER · 子网

Subnet Router 子网路由

让 Tailnet 访问某个本地内网。

路由器端

启用 IP 转发

echo net.ipv4.ip_forward=1 > /etc/sysctl.d/99-tailscale.conf && sysctl -p；广播子网 --advertise-routes=192.168.1.0/24。

客户端

接受路由

sudo tailscale up --accept-routes，然后 ping 192.168.1.1 应能通。

控制台

批准路由

路由广播需要在控制台批准才能真正生效。

用途

跨网段组网

把多个办公室 / 家庭 / 云 VPC 的内网通过 Tailscale 串成一个 Tailnet。

08
CHAPTER · MagicDNS

自动域名解析

不用记 IP，ping 名字即可。

域名

*.tailnet.ts.net

或 *.ts.net。每台设备自动获得 hostname.tailnet.ts.net。

用法

直接 ping

ping my-laptop / curl http://my-laptop:8080。

关掉

自定义 DNS

tailscale set --accept-dns=false，自接管 DNS 解析。

09
CHAPTER · 容器化

Headless / Docker / K8s

把 Tailscale 装进 CI / 容器 / 集群。

Docker

无守护容器

--network=host + --cap-add=NET_ADMIN + /var/lib/tailscale 卷 + /dev/net/tun 设备。

Auth Key

自动化登录

控制台生成 Reusable + Ephemeral + Pre-approved key，tailscale up --authkey=tskey-xxx。

K8s

Operator

tailscale-operator Helm / Kustomize 部署，Service 加 annotation 即暴露。

CI

临时节点

GitHub Actions / GitLab CI 用 ephemeral key 起 Tailscale 访问内网。

10
CHAPTER · 排障

常见问题速解

出问题先查这一节。

节点不通

ping + netcheck

tailscale ping <host>、tailscale netcheck 看 DERP 中继是否被防火墙挡。

DNS 失效

重新开启

tailscale set --accept-dns=true；tailscale status 看 MagicDNS 是否启用。

路由不生效

批准 + 接受

控制台批准 Subnet Router；客户端需 --accept-routes。

完全重置

清空状态

tailscale down && tailscale logout && rm -rf /var/lib/tailscale/*。
