02
OPERATION

三种操作方式

点击图标、右键菜单、直观反馈——三种操作覆盖所有复制场景。

操作一

点击图标

自动复制当前网页的标题和 URL（各一行），绿色对勾确认成功。无需弹出窗口。

  • chrome.tabs 获取当前标签页
  • Content Script 执行复制
  • Badge 显示 ✓
操作二

右键菜单

选择"用 EasyCopy 复制网页内容"，标题+URL+正文文本一次性提取，Markdown 格式。

  • 右键调用扩展菜单
  • 提取标题、地址、正文
  • 支持 Markdown 格式
操作三

直观反馈

图标上直接显示绿色对勾（✓）或红色叉号（✗），无需弹出窗口确认。

  • action.setBadgeText
  • setBadgeBackgroundColor
  • 视觉状态直观
03
TECH STACK

技术实现与安装方式

Manifest V3 + Chrome Extension API + Content Script + Badge API。

Manifest V3 技术栈

Chrome 扩展 API + Content Script

  • Manifest V3：使用 Chrome 最新扩展规范，Service Worker 替代 Background Page
  • Chrome Extension API：chrome.tabs 获取当前标签页信息
  • Content Script：注入网页 DOM 执行复制操作
  • Badge API：action.setBadgeText + setBadgeBackgroundColor 视觉反馈
安装方式

Chrome 扩展管理页面加载

  • Step 1：下载或克隆仓库到本地
  • Step 2：打开 chrome://extensions/
  • Step 3：开启右上角「开发者模式」
  • Step 4：点击「加载已解压的扩展程序」，选择仓库文件夹
