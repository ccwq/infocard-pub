📋 我去，这个浏览器插件一键把网页喂给 AI。作者是向阳乔木。拿网页内容问 AI 是每天都在做的事，但过程一直很笨：全选→复制→粘进对话框，发现没带链接，回去再复制一次，想加链接又得切回浏览器……EasyCopy 把这三种需求拆成了三种操作：点图标复制标题和地址，进剪贴板；走右键菜单，标题、地址和正文都能单独取。
01
三种操作方式
点击图标
自动复制当前网页的标题和 URL（各一行），绿色对勾确认成功
右键菜单
选择"用 EasyCopy 复制网页内容"，标题+URL+正文文本一次性提取
直观反馈
图标上直接显示绿色对勾（✓）或红色叉号（✗），无需弹出窗口
02
技术实现
Manifest V3 技术栈

Chrome 扩展 API + Content Script

Manifest V3
使用 Chrome 最新扩展规范，Service Worker 替代 Background Page
Chrome Extension API
chrome.tabs 获取当前标签页信息
Content Script
注入网页 DOM 执行复制操作
Badge API
action.setBadgeText + setBadgeBackgroundColor 视觉反馈
安装方式

Chrome 扩展管理页面加载

Step 1
下载或克隆仓库到本地
Step 2
打开 chrome://extensions/
Step 3
开启右上角「开发者模式」
Step 4
点击「加载已解压的扩展程序」，选择仓库文件夹
