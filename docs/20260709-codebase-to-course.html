一套把任意代码库转成交互式单页 HTML 课程的 Claude Code skill，面向会用 AI 搭软件但不一定懂工程的人。核心不是写文档，而是把"看代码"重组为一条可重复的课程生产线。
01 · 它解决什么问题

很多 AI 驱动开发者能把东西做出来，却未必真正看懂项目内部是怎么运转的。传统 README 太静态、太抽象、不面向非技术读者。

codebase-to-course 的解法：把仓库变成一个可滚动、可测验、可动画演示、可离线打开的交互式单页课程。目标人群是 vibe coders——会用 AI coding tools 搭软件，不一定有 CS 背景，更关心怎么做判断、怎么 debug、怎么识别 AI 在胡说。

02 · 四阶段生成链路
① 分析代码库
→
② 设计课程模块

③ 构建 HTML
→
④ 浏览器验收
阶段输入输出复杂度分流
① Codebase AnalysisREADME / 入口文件 / actors应用推断结论所有仓库必走
② Curriculum Design分析结论4–8 个模块结构所有仓库必走
②.5 Module Briefs复杂仓库结论并行写作指令包仅 fullstack / monorepo / 模块 6+
③ Build Coursereferences 资产 + 模块内容index.html所有仓库必走
④ Review & Openindex.html浏览器验收所有仓库必走
关键边界：skill 默认不先让用户审批 curriculum，直接内部设计再构建，把用户放在验收位而非计划审批位。
03 · references 资产（真正的课程引擎）

顶层几乎无代码，真正价值集中在 references/：

styles.css / main.jsUI 骨架，滚动导航、进度条、keyboard 交互。
_base.html / _footer.htmlHTML 结构模板，build.sh 直接引用不重生成。
interactive-elements.md定义翻译块、测验、群聊动画、数据流动画、glossary tooltip 写法。
content-philosophy.md每屏最多几句、至少 50% 可视化、quiz 考应用不考记忆。
design-system.mdwarm off-white 背景、Bricolage Grotesque + DM Sans + JetBrains Mono。
module-brief-template.md并行写作的中介层，含教学弧线、代码片段、交互元素说明。
04 · 五类强制交互元素

这些不是装饰，而是每门课程必须满足的质量门槛：

元素要求目的
code ↔ English 双栏每个模块至少一个让非工程师跟上代码逻辑
quizzes每个模块至少一个考应用而非记忆
group chat animation课程至少一处用对话模拟组件交互
message / data flow课程至少一处逐步展示消息/流量路径
glossary tooltips技术术语首次出现即触发hover / tap 看白话解释
05 · 使用方式 
1. 将 codebase-to-course 复制到 ~/.claude/skills/
2. 打开任意项目
3. 说: "Turn this codebase into an interactive course"

# 如果输入是 GitHub 仓库 URL
# skill 先执行: git clone <repo-url> /tmp/<repo-name>
# 再走分析 → 课程生成链路
06 · 适用边界
✅ 适合 已有代码仓库，想给非工程读者讲清楚内部结构；想把"项目怎么工作"做成交互课程；希望把 explainability 变成可重复生产流程。
❌ 不适合 只要一页静态介绍海报；只想要普通 README 扩写；不需要交互、测验和课程结构。
07 · 它像什么

它更像一个课程工厂模板，而不是单一 prompt。核心价值不在顶层 SKILL.md，而在 references/ 里的设计系统、交互组件、内容哲学和 build 资产——这使得它从"会写课程"升级为"能批量稳定产出同类课程"。

与 CodeGraph 对比：两者都在做代码知识重表达，但 codegraph 偏 agent 语义索引，codebase-to-course 偏人类学习体验。

codebase-to-course agent-skill education interactive-course vibe-coding claude-code

一句话结论：它把"看代码"重组为一种课程生产线。最稀缺的不是"生成漂亮页面"，而是把课程结构、视觉系统和交互教法一起模板化，让非技术读者也能顺着交互路径读懂代码。
