Built-in Skills · 14 Skills

每个失败模式一个技能

dev-lifecycle

强制经过需求、设计、计划、实现、测试和审查。阻止过早写代码。

verify

阻止没有最新测试/构建输出的完成声明。"完成"需要证据。

memory

跨会话、跨项目的本地可搜索知识库（SQLite + MCP）。

tdd

推动测试优先实现：新行为没有测试不上线。

structured-debug

要求复现 → 假设 → 修复 → 验证。调试不是猜测和乱改。

document-code

映射入口点、依赖和行为。现有代码不再不透明。

simplify

在代码发布前降低复杂度。实现不再变臃肿。

tech-writer

按新手用户清晰度审查文档。文档不再难以理解。

Slash Commands · 9 Commands

斜杠命令驱动工作流

/new-requirement

需求澄清

智能体先搜索记忆、询问范围、成功标准，创建 docs/ai/{requirements,design,planning}/ 文件后再动手。

/review-design

设计审查

按需求文档审查设计文档，发现缺口，提出修复建议，在任何代码写入前处理。

/execute-plan

执行计划

按 planning 文档逐项执行，每完成一项更新进度。verify 技能阻止没有证据的任务被标记完成。

/code-review

代码审查

按设计文档审查 diff，包括范围膨胀、缺失测试、边界情况，然后你再推送。

Architecture

项目结构与记忆

Project Structure

初始化后获得 .ai-devkit.json + 各智能体配置 + docs/ai/ 文档体系。

Memory (MCP)

本地 SQLite 记忆，跨会话保存决策、约定和修复经验。智能体可以搜索项目记忆。

Agent Console

实时 TUI 仪表盘，统一管理所有正在运行的智能体，不论来自哪个厂商。

Channels

通过 Telegram 接入运行中的会话，从手机操作智能体。ai-devkit channel start telegram。

Agent Control

ai-devkit agent list/send 列出跨提供方运行中的会话，向运行中的会话发送提示词。

Skill Registry

ai-devkit skill add <registry> <skill> 从 30+ 发布方拉取技能（Anthropic、Vercel、Supabase、Microsoft、Google）。

QUICK START · 30-SECOND SETUP
# 快速初始化（所有智能体）
$ npx ai-devkit@latest init

# 完整工程工作流栈（senior-engineer template）
$ ai-devkit init --template ./senior-engineer.yaml

# 列出运行中的会话
$ ai-devkit agent list

# 向运行中的会话发送提示词
$ ai-devkit agent send <session-id> "run the tests" --wait

# 通过 Telegram 接入会话
$ ai-devkit channel start telegram
