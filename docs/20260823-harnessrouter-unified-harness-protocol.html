STARTQuick take: test one task before integrating

HarnessRouter selects an agent runtime, not a different model. First run a harness in the Console; then call /v1/responses with that instance’s metadata.harness_id.

  1. Have Docker, about 4 GB disk, and a model-provider API key.
  2. Start locally with the loopback-only command; change the default Console password before exposing the instance.
  3. Connect the provider key, configure a harness, and confirm one task succeeds in the Console.
  4. Create a CE API key for your backend and send the documented request. Keep that secret server-side.
docker run -d --name harnessrouter \
  -p 127.0.0.1:3000:3000 \
  -v harnessrouter:/data \
  harnessrouter/harnessrouter

If you only need a model turn (messages in, completion out), use a model API. UHP is for the longer harness task lifecycle.

01What the abstraction changes

A harness already plans, calls tools, edits files, and reports results. Products otherwise reimplement how to launch it, continue its session, observe events, cancel work, and retrieve artifacts. UHP makes that task contract the integration boundary; it does not replace the model provider or promise identical behavior from every runtime.

02A real API call

After creating a key in the same CE instance’s Console, keep it in a backend environment variable. The request below follows the official README shape; use a model available through your configured provider. Never commit the key or expose it in browser code.

export HARNESSROUTER_BASE_URL=http://localhost:3000/api/harness

curl --fail-with-body -sS "$HARNESSROUTER_BASE_URL/v1/responses" \
  -H "Authorization: Bearer $KEY" \
  -H 'content-type: application/json' \
  -d '{
    "input":"Reply with exactly: it works.",
    "metadata":{"harness_id":"codex"},
    "model":"gpt-5.4-mini",
    "stream":false
  }'

Three credentials, three jobs

Provider key authorizes model requests. Console login is the local UI password (initially harnessrouter / harnessrouter). CE API key authenticates your product’s API calls. They are not interchangeable.

Make the first run safe

Keep 127.0.0.1:3000:3000 while using the initial login, change the password in Profile, then create a backend API key. For remote access, follow the official public-URL/TLS guide; never expose the default credentials.

The README says the Docker named volume preserves the database, files, installed CLIs, and workspaces across restarts. If port 3000 is occupied, map host port 3100 to container port 3000.

04Support is a tested slice, not a universal promise

The project README lists 26 harness bases. That is a declared inventory, not evidence that every harness works with every provider and model. The support matrix records selected combinations and scenarios—first turn, follow-up, model switch, artifact, and recycle—and marks failures or unrun cases. Some rows identify provider/model aliasing or unsupported API-shape combinations.

Before choosing a pair

Open the current matrix; check the exact harness, model, provider, and scenario you need. A pass in one column does not establish another column.

Run your own acceptance task

Test the task shape you will ship: first turn, continuation, generated file, cancellation, and retry behavior where relevant. Verify the artifact and session state—not only an HTTP success.

05Protocol maturity and runtime limits

UHP status

The protocol README identifies version 2026-10-19 as Draft standard. It publishes specification, schemas, and a runnable conformance suite. This card did not run that suite and does not claim HarnessRouter or another server independently passed it.

CE isolation

Console, Gateway, and Runner run in one container. Agent processes use per-session OS users and separate workspaces inside that shared container; this is not one separate container for each session. Do not treat it as Cloud’s isolated serverless sandbox.

Each installed Agent CLI keeps its own upstream license and terms; Apache-2.0 for Community Edition does not replace them. Review the official security guide before handling untrusted tasks, secrets, or public traffic.
