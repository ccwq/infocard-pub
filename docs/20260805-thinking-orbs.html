NINE STATES

9 种 Agent 思维状态

working
倾斜轨道粒子绕行，暗示持续运算
searching
扫描经线扫过大点球体，暗示信息检索
solving
色带混乱后扣回，暗示问题解决
listening
波纹从内向外扩散，暗示正在倾听
connecting
星群自连成线，暗示建立连接
weaving
三根丝线缠绕球体，暗示编织整合
composing
多段横带起伏摆动，暗示创作输出
breathing
光环缓慢形变呼吸，暗示待机等待
shaping
点线轮廓循环变形：圆→三角→方块

PURE JS SURFACE

不依赖 React 的底层 Canvas 引擎

除了 React 组件，还导出三个 power-user 入口，可在任何 Canvas 环境中独立使用，无需 React 上下文。

resolvePreset

给定 (state, size) 返回精确调参结果：speed / count / size，乘数来自 inkform 调参会话。

STATE_TO_MODE

9 种 state → 9 种渲染模式 key 的映射表：orbits / globe / rubik / wave / web / braid / ribbon / ring / morph

MODE_DRAWS

渲染器注册表：每个 ModeKey → 对应帧绘制函数。可用于自定义 Canvas 渲染或驱动自己的动画循环。

INSTALL & USAGE

React / Pure JS 两种接入方式

React 接入

npm install thinking-orbs
import {'{ ThinkingOrb }'} from 'thinking-orbs';

<ThinkingOrb state="searching" size={64} />
<ThinkingOrb state="listening" size={20} />

Pure JS / 自定义 Canvas

import {'{ resolvePreset, STATE_TO_MODE, MODE_DRAWS }'} from 'thinking-orbs';
// 获取参数
const r = resolvePreset('working', 64);
// r.speed, r.count, r.size
// 驱动自定义 Canvas
const draw = MODE_DRAWS[STATE_TO_MODE['working']];
draw(ctx, 0, r.width, r.theme, r.opts);

PROPS REFERENCE

完整 API 一览

Prop 类型 默认值 说明
state 'working' | 'searching' | 'solving' | 'listening' | 'connecting' | 'weaving' | 'composing' | 'breathing' | 'shaping' 'working' 动画状态，共 9 种
size 64 | 20 64 两套独立设计，不是简单缩放
theme 'auto' | 'dark' | 'light' 'auto' auto 自动三层检测；dark 强制浅色墨水（暗底）；light 强制深色墨水（亮底）
speed number preset 预设速度的倍率，乘数叠加在 baked speed 之上
paused boolean false 冻结在当前帧
aria-label string per-state default 覆盖每个 state 的默认无障碍标签
className string — 透传至 canvas 元素
style CSSProperties — 透传至 canvas 元素
data-* any — 所有 data-* 属性均透传至 canvas

PERFORMANCE & ACCESSIBILITY

纯 Canvas 2D · 无障碍 · 节电

2D Canvas Only

零滤镜 · 零 WebGL

只用 ctx.arc 画弧线，不使用 ctx.filter / SVG filter / WebGL。同一像素在 Chrome、Safari、Firefox 完全一致。Device pixel ratio 上限 2，低端设备友好。

ARIA + Reduced Motion

无障碍 + 节电

role="img" + per-state aria-label。prefers-reduced-motion 渲染静态代表帧。可视区域外和标签页隐藏时自动暂停（IntersectionObserver + Page Visibility API），恢复时相位保持对齐。
