PAGE 01

一句不是抬杠的提问

现在可以用 Codex app 的情况下，DSH 的优势在哪里呢？ 引自原文，群友提问

作者第一反应是定制化，随即被追问：定制 Agent 是不是都能用 Codex skills 实现？他承认：如果目标只是跑通，答案是可以，且门槛比一年前低很多。分歧在下一句：能跑通，不等于有一个能交给客户、在生产里长期活着的 Agent。

作者背景 astaxie：beego / DeepChat / TokenHub 作者，ThinkInAI 创始人，自述聚焦 Agent Harness 与 AI infra。其观点与 Harness 生态存在利益关联，本卡不把他的判断当作已证实优势。

VIEW · 作者的比喻
PAGE 02

精装房 vs 毛坯房

01
精装房 · Codex Skill

钥匙给你家具也有，skills 像再添两件自己的家具，当晚就能住。本质是在一个已定好的产品里加能力。

02
毛坯房 · DSH Harness

水电自己走、墙自己砌。预设、Profile、插件让你重新组合 Agent 本身：工具、权限、提示词、模型适配。

原文观点 这组比喻解释的是定位差异，不是性能差异。作者没有、也无法在文内证明 DSH 交付效果更好。

PAGE 03

Codex 不只是聊天窗口

官方文档核实 为避免虚假二元：Codex 同样能被程序调用和配置。

exec
codex exec 无头运行CI / 脚本里单次调用，正文案例正是这么接的。
>_
SDK
TS / Python SDK + app-server@openai/codex-sdk 线程续跑、流式事件；app-server 给自定义客户端。
⇄
CFG
逐线程可配置sandbox、审批策略、模型、网络开关、outputSchema 都能按线程设置。
⚙
const thread = codex.startThread({
  sandboxMode: "workspace-write",
  approvalPolicy: "never"
});
const turn = await thread.run("修失败的测试");
VERIFY · DSH 侧
PAGE 04

DSH 官方材料能证实什么

MIT
开源 · everything is a pluginDeepSeek AI 官方仓库，基于 Cordis 插件架构，MIT 协议。
§
WEB
npx @deepseek-ai/dsh webNode.js 一条命令起 Web UI（默认 127.0.0.1:3080）；另有 cli / desktop 应用与 ACP 接口。
↗
SDK
Python SDK 可嵌入pip 装 deepseek-harness-sdk（3.10+），从你自己的程序里 run 任务。
<>
ADP
模型适配可换默认 DeepSeek，官方文档支持其他提供方与自定义 OpenAI 兼容端点；llm-adapter 是插件。
⌁
from deepseek_harness import DeepSeekHarness
with DeepSeekHarness(profile="sdk-minimal", cwd=workspace,
                     dsh_home=home) as harness:
    r = harness.run("检查仓库并修复失败测试",
                    session_id="example-001")
print(r.final_response)

官方材料核实 以上均为 README 与 docs/user/guide 原文内容。Star 数 278,977 为截至 2026-11-12 实时 API 复核的时效数据。

DEV PREVIEW · 官方原话
!

README 原文警告：“THERE WILL BE COMPATIBILITY-BREAKING CHANGES.” 拿 DSH 当生产底座，先接受破坏性变更的预期。

安全边界 sdk-minimal profile 固定 danger-full-access，官方建议一次性 checkout 或容器运行；会话日志贡献器默认随请求上传日志事件（≤8 MiB/次），可配置关闭。给客户部署前这两条必须先读。

VERDICT · 分级结论
PAGE 09

能证实的和不能证实的

能证实：两边都有编程接口与配置能力（官方文档）；DSH 开源 MIT、插件级重组、Python SDK 嵌入（官方仓库）；DSH 仍是 developer preview（官方原话）。

不能证实：DSH 交付客户效果更好；那条飞书链路换成 DSH 会更好。作者自己也说：工具可以并存，不是站队。
