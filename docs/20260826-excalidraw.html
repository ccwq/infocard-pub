01
OVERVIEW

它是什么？

Excalidraw 是一个手绘风格的白板工具，专注于技术架构图、流程图和系统设计图的快速创作。

手绘风格 开源

核心特点

手绘风格视觉效果，传达"草图感"和"设计过程感"，让技术图表更易读、更有表达力。PWA 应用，支持离线使用和端到端加密实时协作。

  • 预置丰富图标库（AWS、Azure、K8s、数据库等）
  • 自定义形状库和组件
  • 本地存储 + 云端同步（可选）
痛点解决 效率提升

解决什么问题？

写技术文档最耗人的一步就是画图。Excalidraw 让用户只需描述系统结构，AI 就能生成专业的手绘风格架构图。

  • 告别手动拖拽排版
  • 一秒出图，一句话讲清楚系统
  • 直接嵌入文档、PPT、博客
02
EXPORT

四种导出格式

满足从技术文档到演示网页的全部场景需求。

SVG
矢量格式，无限缩放不失真，适合嵌入文档和网页
PNG
位图格式，通用兼容，适合截图分享和幻灯片
GIF
动画格式，适合演示系统流程和数据流向
HTML
交互式 HTML，嵌入网页后可继续编辑，适合现场演示

05
PROS & CONS

适用场景

明确适合与不适合的场景，帮助快速判断是否采用。

✓ 适合

适用场景

  • 技术架构图和系统设计图
  • 微服务、分布式系统拓扑图
  • 流程图、数据流图、ER 图
  • 技术文档和博客配图
  • PPT 和演示材料中的示意图
  • 团队实时协作白板
✗ 不适合

边界

  • 需要精确工程制图（用 draw.io 或专业 CAD）
  • 需要打印出版级精确线稿
  • 需要复杂 UML 时序图（用 PlantUML）
  • 需要实时数据看板（用 Grafana）
