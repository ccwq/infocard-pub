Tailcat：没有 Tailscale 的 Tailscale

Tailscale 官方出品，不用注册账号、不用装 VPN、不开端口、不改路由，两台机器发个短 token 过去，直接就连上了。WireGuard 端到端加密，像 netcat 但走 Tailscale 数据面。

官方Tailscale
Go用户态实现
MIT开源协议
WireGuard 用户态隧道 端到端加密 零配置 SOCKS5 代理 SSH 直连
! 安全特性（什么不改）
无需账号发 token 直接连
无需 VPN不走传统 VPN 隧道
无需端口开放NAT 穿透直连
无需 root用户态执行
不改路由不接管系统网络
不改 DNS系统 DNS 保持不变
WireGuard 端到端加密：直连走 WireGuard 隧道，打不通自动走 DERP 中继，全程加密不过明文。
→ 连接流程
机器 A 生成 token
→
发 token 给机器 B
→
机器 B 接受连接
→
WireGuard 隧道建立
DERP 中继兜底：两端都在严格 NAT 后面打不通直连时，自动走 Tailscale DERP 中继节点，不影响连接成功。
★ 连上之后能做什么

1. 文件互传

两台电脑之间直接传文件，不需要中间服务器，不走云存储。

2. 端口甩出去

把本地端口暴露给对端，直接访问本地服务。

3. SSH 直连

不需要公网 IP 或跳板机，token 验证后直接 SSH 进入对端机器。

4. SOCKS5 代理

对端机器作为 SOCKS5 出口，流量经 WireGuard 隧道加密转发。

5. 出口节点

流量从对端机器出口，实现 IP 伪装和跨境访问。

6. 浏览器传文件

浏览器内置文件传输能力，不用额外工具。

$ 快速上手 
# 安装（macOS）
$ brew install tailcat

# 机器 A：生成 token
$ tailcat serve
# 输出一段短 token，复制发给机器 B

# 机器 B：连接
$ tailcat connect <TOKEN>
# 连接建立后即可互传文件 / SSH / 代理
DERP 兜底：直连失败时自动切换到 DERP 中继，不需要手动配置。
注意事项：Tailcat 使用 Tailscale 的 DERP 中继服务器（第三方托管）。如果对中继节点完全零信任，可考虑完全自托管 Tailscale 控制平面，或使用纯点对点直连模式。工具本身是官方出品，开源透明。
一句话定位：像 netcat，但走 WireGuard 加密隧道；像 Tailscale，但不是 Tailscale。
