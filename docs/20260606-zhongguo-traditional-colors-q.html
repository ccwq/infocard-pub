📥 色卡使用方式

在线浏览

访问在线图库，点击任意色卡可打开高清 PNG 原图。

批量下载

使用 Release 中的 ZIP 文件一次性下载全部 742 张高清图片（~998 MB）。

色值参考

每个色卡附带 HEX / RGB / CMYK 色值，可直接用于设计工具和前端代码。

清单下载

完整 742 色清单（chinese-color-master-list.md）可单独获取，供程序化使用。
