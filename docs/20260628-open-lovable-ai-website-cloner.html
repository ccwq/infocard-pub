一句话定位
Open Lovable 是一个开源 AI 网站克隆工具：把任意 URL 的视觉结构还原成 React/Next.js 代码，配合 AI 对话迭代修改。工具本身完全免费（MIT），需自备 Firecrawl API key（网页抓取）和至少一个 AI 模型 key（Gemini 免费额度最充足）。
仓库状态
⚠️ 重要更新：仓库已从 mendableai/open-lovable 迁移至 firecrawl/open-lovable，由 Firecrawl 团队维护。当前版本 v3，最后提交为 7 个月前，活跃度较低。如需最新功能，建议关注 Firecrawl 主站（firecrawl.dev）。

安装与配置（4 步）
① 克隆仓库
使用 pnpm（推荐）或 npm / yarn 安装。
git clone https://github.com/firecrawl/open-lovable.git cd open-lovable pnpm install
② 配置 .env.local
必须配置：Firecrawl API key（网页抓取）。AI 模型 key 至少选一个。
# ================= REQUIRED ================= # Firecrawl：网页抓取（必需） FIRECRAWL_API_KEY=your_firecrawl_api_key # https://firecrawl.dev # ================= AI 模型（4 选 1）==================== GEMINI_API_KEY=your_gemini_api_key # aistudio.google.com 免费额充足 ✅ ANTHROPIC_API_KEY=your_anthropic_api_key # Claude OPENAI_API_KEY=your_openai_api_key # GPT-4o GROQ_API_KEY=your_groq_api_key # Groq 免费 # ================= 沙盒（2 选 1，默认 Vercel）==================== SANDBOX_PROVIDER=vercel # 默认：Vercel（需 vercel link + env pull） # SANDBOX_PROVIDER=e2b # 备选：E2B（需 E2B_API_KEY）
💡 零成本组合：Firecrawl 有免费 tier + Gemini 免费额 + Vercel 默认沙盒 = 完全零成本跑起来。
③ Vercel 认证（如选 Vercel 沙盒）
Vercel 沙盒默认用 OIDC Token，推荐本地开发时用：
vercel link # 关联 Vercel 项目 vercel env pull # 自动拉取 OIDC Token 到 .env.local # 或手动填（生产环境推荐）： VERCEL_TEAM_ID=team_xxxxxxxxx VERCEL_PROJECT_ID=prj_xxxxxxxxx VERCEL_TOKEN=vercel_xxxxxxxxxxxx
④ 启动
访问 http://localhost:3000，输入目标 URL，开始克隆。
pnpm dev # 打开 http://localhost:3000 # → 输入目标 URL → 开始克隆 → AI 对话修改 → 导出项目

Hermes Agent 工作流
🤖 典型场景：Open Lovable 克隆 + Hermes 审查修复
用 Open Lovable 快速生成前端骨架，用 Hermes Agent 审查和修复生成代码，形成「克隆 → 审查 → 修复 → 交付」的完整闭环。
# Step 1：Open Lovable 克隆目标网站 # → 打开 http://localhost:3000 → 输入 URL → 生成 React 项目 # Step 2：Hermes 用 CodexPro 读取生成的源码 # → 读取 pages/, components/ 目录结构 # Step 3：Hermes browser_navigate 对比原站与生成结果 # → 截图对比 → 发现差异 → 让 Open Lovable AI 修复 # Step 4：CodexPro / Hermes execute_code 修复源码 # → 替换字体 / 修复布局 / 补全响应式 # Step 5：pnpm build 验证构建 # → 交付最终 React 项目
💡 最佳实践：Open Lovable 擅长快速原型，Hermes Agent 负责质量把关。两者组合：速度 + 质量 + 零增量成本。

边界与局限
限制项 说明 规避建议
动态内容无法克隆 登录态、API 动态加载、数据库渲染页面 仅克隆静态展示层，业务逻辑自行补充
复杂交互还原有限 轮播、动画、复杂手势只能还原视觉框架 用 AI 对话逐步补全交互逻辑
版权法约束 克隆竞品代码结构用于商业产品有风险 仅作学习/原型参考，不要直接复制
活跃度较低 v3 最后维护 7 个月前，功能可能停滞 关注 Firecrawl 主站是否有新方案
大规模站点耗时 页面越多，抓取+生成时间越长 优先克隆核心页面，逐步扩展
