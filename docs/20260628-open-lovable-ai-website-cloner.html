收费策略详解
核心原则：Open Lovable 本身完全免费，但要让它跑起来，你需要自备三个 API 密钥。以下是各服务的实际费用结构和免费额度分析。
依赖服务 收费模式 免费额度 实际成本估算
🔥 Firecrawl API 按抓取页面数计费 免费版 500 页/月 单次克隆 ≈ 3-10 页，约 $0（免费额度内）
🛡️ E2B Sandbox 按执行时长计费 免费版 5 小时/月 日常开发够用；超出约 $0.02/分钟
🤖 OpenAI API 按 Token 计费 $5 新用户赠金 GPT-4o mini ≈ $0.15/次克隆；GPT-4 约 $0.5-2/次
🤖 Anthropic API 按 Token 计费 $5 新用户赠金 Claude 3.5 Sonnet ≈ $0.3-1.5/次克隆
🤖 Groq / Kimi API 按 Token 计费 Groq 免费；Kimi 有赠送 Groq 的 Llama/Gemma 系列完全免费，速度快
🤖 Google Gemini 按 Token 计费 免费版有配额 Gemini 1.5 Flash 免费额度充足
💡 最低成本方案：Groq（免费 Llama 3.3 70B）+ Firecrawl 免费版 + E2B 免费版 = 零成本跑通全流程。Groq 的免费层限制每分钟 30 条请求，日常克隆完全够用。
⚠️ 注意：克隆的网页只能还原静态布局和样式，无法克隆登录状态、数据库交互、动态 API 调用等后端逻辑。克隆结果仅作为前端原型参考，需要自行补充业务逻辑。
快速上手（4 步跑起来）
① 克隆仓库并安装
需要 Node.js 18+ 环境。
git clone https://github.com/mendableai/open-lovable.git cd open-lovable npm install cp .env.example .env
② 配置三个 API 密钥
至少需要 E2B、Firecrawl 和一个 AI 模型密钥。以下是最低成本配置方案（全部免费）：
# 必选密钥 E2B_API_KEY=your_e2b_key_here # e2b.ai 注册，免费 5h/月 FIRECRAWL_API_KEY=your_firecrawl_key # firecrawl.ai 注册，免费 500 页/月 # 三选一（推荐 Groq 完全免费） OPENAI_API_KEY=your_openai_key # gpt-4o-mini，$5 赠金够用很久 # ANTHROPIC_API_KEY=your_claude_key # claude-3-5-sonnet，$5 赠金 GROQ_API_KEY=your_groq_key # groq.com 注册，完全免费！
③ 启动服务
开发服务器启动后，浏览器打开 localhost:3000 即可看到 AI 对话界面。
npm run dev # ✓ Ready on http://localhost:3000
④ 开始克隆
在界面输入框粘贴任意网站 URL，例如 https://github.com，AI 自动开始抓取、分析并生成 React 代码。可通过对话实时调整样式和布局。
适用场景
🏗️ 快速原型开发
拿到竞品网站直接克隆，改改颜色和文案，几个小时就能出一个可演示的产品原型，适合给客户/老板看方向。
📚 前端学习参考
看到某个网站的布局很喜欢，克隆下来看清 header/footer/grid 的组件结构，比 F12 一点点拆源码高效得多。
🔄 旧站技术迁移
老系统想从 jQuery 迁移到 React，先用 Open Lovable 克隆出骨架，再逐步填充业务逻辑，降低重构成本。
🎨 设计稿还原验证
设计师出稿后，丢进 Open Lovable 快速验证还原度，减少前端开发返工。
局限与边界
限制项 说明 规避方法
动态内容无法克隆 登录态、API 动态加载内容、数据库渲染页面无法还原 仅克隆静态展示层，业务逻辑自行补充
复杂交互还原有限 轮播、动画、复杂手势交互只能还原视觉框架 用 AI 对话逐步补全交互逻辑
受版权法约束 克隆原站代码结构用于商业产品可能涉及版权风险 仅作学习/原型参考，不要直接复制商业竞品
依赖 API 费用 自备密钥，AI 模型调用有成本 用 Groq（免费）或 Gemini Flash（免费额充足）
大规模站点耗时 页面越多，抓取+生成时间越长 优先克隆核心页面，逐步扩展
