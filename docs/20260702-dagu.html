⚡ 本地优先 · 单 Binary

Dagu：轻量 DAG 工作流引擎

单 binary 跑 DAG、YAML 定义流程、无需 DB 或 broker。内置 shell / Docker / K8s / SSH / harness.run，AI Agent 可通过 MCP 直接管理 DAG。

⭐ 3,589 Go Linux / Mac / Win MCP 内置 MIT
▎一句话判断

如果只是想把 agent、脚本、数据处理、运维任务动态串起来，而不想搭 Temporal 级别的系统，Dagu 这种本地优先路线反而很舒服。单个 binary、YAML 写流程、带 Web UI，Claude Code / Codex 可通过 MCP 直接操作 DAG。

快速上手 SOP
1安装 Dagu

macOS / Linux：

curl -fsSL dagu.sh/in.sh | bash

brew install dagu · Win irm dagu.sh/in.ps1|iex

2写第一个 DAG
steps:
  - id: fetch
    run: curl -s api.github.com
  - id: parse
    run: python3 parse.py
    depends: [fetch]

depends 声明即成 DAG

3启动 Web UI
dagu start --ui

浏览器打开 localhost:8080

4CLI 启动
dagu start --param name=world

支持重试 / 条件分支

5AI Agent (MCP)

MCP 端点：

http://localhost:8080/mcp

Claude Code / Codex 等直连

6外部 Agent
- id: claude-task
  run: harness.run "claude --print plan.md"
  depends: [fetch]

Claude Code / Codex / Cline 均支持
