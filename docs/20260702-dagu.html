快速上手 SOP
1安装 Dagu

macOS / Linux：

curl -fsSL https://raw.githubusercontent.com/\ndaguadmin/dagu/releases/latest/install.sh | bash

brew install dagu 或 Windows irm ...| iex

2写第一个 DAG (YAML)
steps:
  - id: fetch
    run: curl -s https://api.github.com
  - id: parse
    run: python3 parse.py
    depends: [fetch]

depends 声明即成 DAG

3启动 Web UI
dagu start --ui

浏览器打开 http://localhost:8080

4CLI 启动 DAG
dagu start --param name=world

指定参数执行，支持重试 / 条件分支

5AI Agent 连接 (MCP)
# Claude Code / Codex 等 MCP 客户端配置：
# 端点: http://localhost:8080/mcp

Agent 可读状态、改 YAML、执行 / 暂停 / 恢复

6外部 Agent 接入

harness.run 把外部 coding agent CLI 接入流程：

- id: claude-task
  run: harness.run "claude --print plan.md"
  depends: [fetch]

Claude Code / Codex / Cline 等均可
