快速上手 SOP STEP 1–6
1安装
curl -fsSL dagu.sh/in.sh | bash

brew install dagu 或 Win irm dagu.sh/in.ps1|iex

2写 DAG
steps:
  - id: fetch
    run: curl api.github.com
  - id: parse
    run: python3 parse.py
    depends: [fetch]

depends 声明即成 DAG

3启动 UI
dagu start --ui

浏览器打开 localhost:8080

4CLI 启动
dagu start --param name=world

支持重试 / 条件分支 / 参数注入

5MCP 连接
http://localhost:8080/mcp

Claude Code / Codex / Gemini CLI 直连

6外部 Agent
- id: claude-task
  run: harness.run "claude --print plan.md"
  depends: [fetch]

Claude Code / Codex / Cline 均支持
