快速上手 SOP
1安装 Dagu
macOS / Linux 一行安装：
curl -fsSL https://raw.githubusercontent.com/dagucloud/dagu/main/scripts/installer.sh | bash
或 Homebrew：brew install dagu　｜　Windows：irm ...installer.ps1 | iex
2写第一个 DAG（YAML）
steps:
  - id: fetch
    run: curl -s https://api.github.com
  - id: parse
    run: python3 parse.py
    depends:
      - fetch
每个 step 是独立可执行单元，depends 声明依赖关系即成 DAG。
3启动并访问 Web UI
dagu start-all    # 启动调度器 + HTTP 服务
# 访问 http://localhost:8080
Web UI 展示 DAG 列表、运行状态、日志、重试和手动触发。
4启动一个 DAG
dagu start hello.yaml
# 支持参数传入：
dagu start etl.yaml --params '{"date":"2026-07-01"}'
手动触发 / Cron 调度 / Webhook 触发均支持。
5接入 AI Agent（Claude Code 等）
# Dagu 内置 MCP 服务，Claude Code 配置：
# MCP 端点：http://localhost:8080/mcp
# 能力：读取状态 / 修改 DAG / 触发执行
通过 gh skill install dagucloud/dagu dagu 装入 Claude Code 即可。
6接入外部 Coding Agent（harness.run）
steps:
  - id: code
    run: harness.run
    name: "claude-code"
    args: ["Generate data report"]
把 Claude Code / Codex 等 CLI 作为 DAG 一步执行，结果自动写入 DAG 日志。

MCP 集成（AI Agent 直接管 DAG）
Dagu 内置 MCP 服务，AI Agent 无需额外插件即可读写 DAG：
dagu_read — 查询 DAG 状态、历史运行、日志输出
dagu_change — 修改 DAG YAML（增删步骤、调整依赖）
dagu_execute — 触发 DAG 立即执行、暂停、恢复、取消
端点：Claude Code / Codex / Gemini CLI 等 MCP 客户端配置 http://localhost:8080/mcp 即可
部署模式
本地单服务器
dagu start-all 一台机器跑调度+执行，适合开发、个人自动化和小规模定时任务。
自托管（多 Worker）
Dagu Server + 分布式 Worker，支持横向扩展执行能力，适合团队私有部署。
Docker 单行启动
docker run --rm -v ~/.dagu:/var/lib/dagu -p 8080:8080 ghcr.io/dagucloud/dagu:latest
Kubernetes（Helm）
helm install dagu dagu/dagu，需要 RWX 存储类（如 NFS / EFS）存储状态文件。

典型使用场景
场景 Dagu 如何处理
ETL / 数据处理流水线 数据抽取脚本 → SQL / dbt → 数据处理 runbook，串联为可观测的持久化 DAG，含日志和重试。
Cron 和遗留脚本管理 将多步骤有依赖关系的复杂 cron 任务转为 YAML DAG，自动日志、重试和通知，告别裸 bash 脚本。
FFmpeg 视频转码 文件备份 → FFmpeg 多线程转码 → 上传，文件本地存储，无需外部数据库。
基础设施远程运维 通过 ssh 动作在多台服务器执行命令，日志集中、状态统一，无需跳板机脚本。
GitHub 驱动自动化 接收 GitHub Webhook 触发 DAG，在私有网络内运行自动化，不暴露公网服务器。
AI Coding Agent 流水线 harness.run 把 Claude Code / Codex 作为 DAG 一步执行，结果自动归档进 DAG 日志。
AI Agent 自管理（Dagu as MCP Server） Claude Code 通过 MCP 协议查询 DAG 状态、修改 YAML、触发执行，实现 Agent 驱动的工作流。
IoT / 边缘数据采集 传感器轮询 → 本地 ML 推理 → 数据预处理 → 备份 / 离线同步，全流程 Web UI 可视化。
