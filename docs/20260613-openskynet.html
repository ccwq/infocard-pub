「操作一次，永久重复。」— OpenSkynet 把 AI agent 变成永不疲倦的浏览器操作员，睡觉时也在跑。
传统 RPA / 爬虫

页面改版 → 选择器失效 → 人工修复 → 停机几小时。定时任务靠系统 cron，没有业务层记忆。

OpenSkynet

页面改版 → agent 自动感知并补丁 → 继续跑。内置记忆 + skills 系统 + 社区市场，一条龙。

核心特性
features
  • Learn by Showing — 演示一次浏览器操作，永久回放
  • Self-Healing — 页面变化时自动补丁，无需人工介入
  • 24/7 Scheduling — Cron 调度，睡觉时也在跑
  • Skills Hub — 社区技能市场，一键安装
  • Persistent Memory — 跨会话记忆用户偏好
