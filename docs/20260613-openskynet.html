OpenSkynet

Your 24/7 AI Terminator — 浏览器自动化平台，教一次，永久重复运行。支持 Skills 技能市场、Self-Healing 自修复与 24/7 定时调度。

Teach it once. It repeats forever. 24/7 Slavery.
📅 2026-05-28 · 距今 16 天 🔧 Monorepo · TypeScript + Python 🐳 Docker 支持

核心特性

  • Learn by Showing — 操作一次浏览器，永久回放
  • Self-Healing — 页面结构变化时自动补丁，无需人工介入
  • 24/7 Scheduling — Cron 调度，睡觉时也在跑
  • Community Skills Hub — 社区技能市场，一键安装
  • Persistent Memory — 跨会话记忆用户偏好

技术架构

模块技术栈职责
packages/appTypeScript + Radix UI + Tailwind + Electron桌面前端
packages/serverPython 3.11 + uv + Playwright浏览器自动化引擎
skills/JSON / Scripts可复用技能包
核心依赖：playwright · @radix-ui/* · tailwind-merge · uv · electron

安装方式

# 克隆 git clone https://github.com/sediman-agent/OpenSkynet.git cd OpenSkynet # 安装依赖 npm install && bun install # 启动后端 bun run backend # 启动 Electron（另一终端） npm run electron
Docker 部署：
docker-compose up # 访问 http://localhost:8080
