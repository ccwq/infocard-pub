KEY FEATURES · 核心能力

设计能力一览

从单屏生成到完整应用流，从草图解析到语音输入，Stitch 支持多种设计方式。

功能 标签 说明
自然语言设计 vibe design 用文字描述业务目标、用户感受或参考方向，AI 生成设计，无需专业术语
多屏幕同时生成 5 屏并发 一次性生成 5 个互相衔接的屏幕，保持设计语言一致，颜色/字体/组件风格统一
语音输入 Voice Input 对着画布说话，AI 实时给出设计批评、改稿建议，边聊边改
草图解析 Experimental 上传手绘草图/线框图，AI 解读并转化为数字 UI（需 Experimental 模式）
无限画布 Canvas AI 原生无限画布，支持文本/图片/代码任意输入作为上下文
设计 Agent Agent 设计 Agent 跨整个项目演进推理，Agent Manager 支持多任务并行探索
原型构建 Prototypes 用 Stitch 连接屏幕 → 点击"播放"→ 预览完整用户流程，无需额外工具
DESIGN.md 导出 Agent 友好 导出 agent-friendly Markdown 文件，可在其他设计/编码工具间传递设计规则

EXPORT & INTEGRATIONS · 导出与集成

导出 Figma / HTML / MCP / AI Studio

Stitch 充当设计工具 Bridge，可导出到多个生态，与现有工作流无缝衔接。

FigmaPaste to Figma

Figma 导出

一键将设计复制到 Figma 文件，作为可编辑 Frame，设计团队在 Figma 中进一步精修后交给开发。

HTML/CSS代码导出

代码导出

导出干净的 HTML + CSS，为前端开发提供高质量起点。不是生产级代码，但是良好结构的基础。

MCPAI Agent 集成

MCP Server 集成

通过 stitch-mcp（GitHub 121 stars）将 Stitch 能力接入 Claude Code、Cursor、Cline 等 AI 编码助手，用自然语言生成 UI 组件。

Google AI Studio

AI Studio

直接生成可分享链接，推送到 Google AI Studio 继续处理。

Google Antigravity

Antigravity

导出到 Google Antigravity，接入后端逻辑，一键发布上线。

Netlify / Bolt
更多导出

其他工具

导出菜单还支持 Netlify、Bolt、zip 格式，满足不同上线和协作需求。
