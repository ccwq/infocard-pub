CAPABILITIES · 核心能力

设计能力一览

从单屏生成到完整应用流，从草图解析到语音输入，按“输入—生成—迭代—交接”阅读。

功能标签说明
自然语言设计vibe design用文字描述业务目标、用户感受或参考方向，AI 生成设计，无需专业术语。
多屏幕同时生成5 屏并发一次性生成 5 个互相衔接的屏幕，保持设计语言一致，颜色、字体与组件风格统一。
语音输入Voice Input对着画布说话，AI 给出设计批评与改稿建议，边聊边改。
草图解析Experimental上传手绘草图或线框图，AI 解读并转化为数字 UI（需 Experimental 模式）。
无限画布Canvas支持文本、图片、代码作为上下文的 AI 原生无限画布。
设计 AgentAgent设计 Agent 跨整个项目演进推理，Agent Manager 支持多任务并行探索。
原型构建Prototypes连接屏幕后点击“播放”，即可预览完整用户流程，无需额外工具。
DESIGN.md 导出Agent 友好导出 agent-friendly Markdown 文件，在设计与编码工具间传递设计规则。
03
EXPORT & INTEGRATIONS · 导出与集成

设计工具 Bridge

把结果送进现有设计、编码与发布路径。

Figma Paste to Figma

可编辑 Frame

一键将设计复制到 Figma 文件，作为可编辑 Frame，设计团队可以继续精修后交给开发。

HTML/CSS 代码导出

前端起点

导出 HTML + CSS；不是生产级代码，JavaScript 与后端逻辑仍需另行开发。

MCP AI Agent 集成

接入编码助手

通过 stitch-mcp 将 Stitch 能力接入 Claude Code、Cursor、Cline 等 AI 编码助手，用自然语言生成 UI 组件。

Google AI Studio

继续处理

直接生成可分享链接，推送到 Google AI Studio 继续处理。

Google Antigravity

接入后端

导出到 Google Antigravity，接入后端逻辑并发布上线。

Netlify / Bolt

更多导出

导出菜单还支持 Netlify、Bolt 与 zip 格式。
