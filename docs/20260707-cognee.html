Core Operations

remember

永久存入知识图谱

摄入数据 → 认知化处理 → 自动构建本体与关系。数据持久化到图数据库。

await cognee.remember(text)
recall

智能召回

自动路由到最佳搜索策略（向量/图/混合）。支持会话级优先查询。

await cognee.recall(query)
forget

选择性遗忘

删除指定数据集或全部记忆。保持知识库精简、可控。

await cognee.forget(ds)
improve

持续优化

自动改进记忆质量、本体结构、关系准确性。记忆随使用进化。

await cognee.improve(ds)
Python Quickstart
# pip install cognee
import cognee, asyncio

async def main():
    # Store permanently in knowledge graph
    await cognee.remember("Cognee turns docs into AI memory.")

    # Session memory (fast cache, syncs in background)
    await cognee.remember(
        "User prefers detailed explanations.",
        session_id="chat_1"
    )

    # Query with auto-routing
    results = await cognee.recall("What does Cognee do?")

    # Session + graph fallback
    results = await cognee.recall(
        "What does the user prefer?",
        session_id="chat_1"
    )

    # Cleanup
    await cognee.forget(dataset="main_dataset")

asyncio.run(main())

Deployment Options

Cognee Cloud

托管服务

无基础设施维护，Sign up 即用。支持 await cognee.serve() 快速接入。

Modal

Serverless GPU

自动扩缩容，GPU 工作负载。bash distributed/deploy/modal-deploy.sh

Railway

简化 PaaS

原生 Postgres 支持，最简部署体验。railway init && railway up

Fly.io

Edge 边缘部署

持久卷，边缘节点。bash distributed/deploy/fly-deploy.sh

Docker

容器化

预构建镜像 cognee/cognee。docker compose up 开箱即用。
