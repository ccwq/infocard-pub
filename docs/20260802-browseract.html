ARCHITECTURE

技术架构

三层反爬架构 · 7 大 Agent 原生集成 · session 隔离

环境层

指纹欺骗

Stealth Chromium 提供新鲜指纹 + TLS 指纹旋转 + 代理轮换，绕过基础反爬检测。

执行层

CAPTCHA 破解

stealth-extract 单命令提取受保护页面内容；CAPTCHA 自动破解；browser open / state / click / input / scroll 等原子操作。

人工层

remote-assist

生成实时 URL，任意设备（手机/电脑）均可接管浏览器会话，Agent 自动恢复操作流程。

05
SETUP

安装配置

Skill 安装 → uv CLI → 可选 API key

安装步骤

完整流程

# Step 1: Agent 安装 Skill
# 告知 Agent：
# "Install browser-act. Skill source: github.com/browser-act/skills/tree/main/browser-act"

# Step 2: 安装 CLI（需 uv）
uv tool install browser-act-cli --python 3.12

# Step 3: 可选 API key（解锁 stealth/proxy/captcha）
browser-act auth login
browser-act auth poll

# 验证安装
browser-act --version
browser-act get-skills core --skill-version 2.0.2
前提条件

依赖

  • Python 3.12+
  • uv 工具管理器
  • Chrome/Chromium（chrome / chrome-direct 模式必须）
  • 可选：BrowserAct API Key（解锁 stealth 浏览器、代理、CAPTCHA 破解）
