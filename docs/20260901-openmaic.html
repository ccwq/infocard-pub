核心能力：一句话生成完整多智能体互动课堂

OpenMAIC（Open Multi-Agent Interactive Classroom）将任意主题或文档转化为沉浸式互动课堂体验。由多智能体编排驱动，一个 Prompt 即可生成完整课件、随堂测验、交互式模拟和 PBL 项目，由 AI 教师与 AI 同学共同演绎，支持语音朗读、白板绘图与实时讨论。

快速上手
git clone https://github.com/THU-MAIC/OpenMAIC.git
cd OpenMAIC
pnpm install
cp .env.example .env.local
# 填写至少一个 LLM API Key（OPENAI_API_KEY 等）
pnpm dev
# 打开 http://localhost:3000

推荐模型：Gemini 3 Flash（质量与速度最佳平衡）；本地无 API Key：使用 Lemonade 或 Ollama
