★项目概述

Cordis Mini 是用 ~600 行纯标准库 Python 代码教学性质的开源项目，目标是还原 Cordis / deepseek-harness 的 5 种核心 Agent 架构机制。无需真实 LLM API，内置 EchoAdapter（Fake LLM），直接运行。适合想理解 Agent 底层架构、插件系统、事件分发的 Python 开发者。

Agent 架构 插件系统 依赖注入 事件分发 副作用管理 教学代码
015 种核心机制
1
一切皆插件
Plugin System

所有功能类继承 Service 基类，通过 apply() 函数注册为插件。插件可叠加、替换，无需修改核心代码。

2
Context 是服务仓库
Service Registry

ProxyContext.__getattr__ 实现动态服务查找，所有服务挂载在同一上下文中，按名访问，无需 import。

3
inject 声明依赖
DI + Topo Sort

@inject 装饰器声明依赖，由 Loader._topo_sort 执行 Kahn 算法拓扑排序，保证加载顺序无环。

4
5 种事件分发
Event Dispatch

emit（广播）、parallel（并发）、serial（串行）、bail（短路）、waterfall（链式）。

5
注册即可逆副作用
Disposable Effects

fiber.effect 注册副作用，_disposables 逆序清理。资源用完即退，无需手动释放。

⚙
底层 Fake LLM
EchoAdapter

EchoAdapter 将输入原样返回，模拟 LLM 对话。无需 API Key，直接运行，降低学习门槛。
