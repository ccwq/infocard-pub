MINKE · DEEPSEEK HARNESS DESKTOP

把 Agent 工作从多个窗口，收拢成一个本地工作区

Minke 是 DeepSeek Harness 的独立社区桌面工作区：对话、项目文件、真实 PTY 终端、Browser、插件和 Session 状态围绕同一 Agent 会话组织。它的价值不只是“套壳聊天框”，而是把理解、修改、验证和远程继续工作放在同一个操作面上。

01

它到底解决了哪一种碎片化？

POSITION

对话旁边就是文件

Files 支持目录导航、语法高亮预览、编辑和 Diff。Agent 讨论代码时，不必在聊天窗口、编辑器和终端之间反复切换。

终端是真 PTY

Terminal 连接到 Minke 主机上的真实伪终端；手机远程访问时执行的命令仍发生在宿主机，不是浏览器里的模拟终端。

插件与会话共存

Plugins 支持 GitHub 发现、安装、状态检查、修复和移除；Session、主题、快捷键和日志导出也属于同一工作区。

03

远程访问：三条路线，默认选 HTTPS

REMOTE
01
Tailscale Serve HTTPS

推荐路线。同一 tailnet 的手机访问 HTTPS 地址，支持 PWA 安装；Harness 仍留在 loopback，不启用公网 Funnel。

02
Tailscale Direct IP

高级路径。绑定当前设备 Tailscale IPv4，流量仍经 Tailscale 加密，但使用 HTTP，不是浏览器 secure context。

03
Cloudflare Access

适合不想让手机加入 tailnet 的场景，需要 Cloudflare Tunnel、Access 应用和明确 allow policy。

04
PWA

打开 HTTPS 地址，选择 Install Minke；iPhone/iPad 使用 Share → Add to Home Screen，弱网显示连接状态。

# Minke 设置路径（README） Connections → Device access → Remote access → HTTPS Serve # 只在明确接受风险时处理 macOS 预发布 App quarantine xattr -dr com.apple.quarantine "/Applications/Minke.app"
权限提醒：远程 Web 页面可以启动 Agent、管理项目文件并使用宿主终端。只给可信 tailnet 成员或 Cloudflare Access 身份，不要把远程地址当普通公开网页分享。
04

本地模型与数据迁移：两条“减少重复劳动”的路径

LOCAL OPS

Loopback 模型发现

Minke 可发现 LM Studio、Ollama 和其它 loopback OpenAI-compatible 服务。可选生命周期管理按需启动支持的 runtime，但不接管已经运行的服务。

自定义数据目录

应用状态与浏览器 Session 数据留在本机 Minke 数据边界；README 指出桌面偏好位于 ~/.minke，数据目录可自定义。

迁移先预览再切换

迁移前预览 Sessions、插件和设置，去重相同文件，保留冲突与源目录；只有重启迁移成功后才完成切换，也可从干净数据目录开始。

05

首次使用：从一个本地项目跑通观察闭环

FIRST RUN

第一步 · 选一个低风险项目

先选可以回滚的本地项目，确认工作区路径、模型服务和 Agent 权限；不要第一次就把生产目录暴露给远程页面。

第二步 · 看清工具位置

  1. 对话里提出任务。
  2. Files 看变更和 Diff。
  3. Terminal 运行测试或检查。
  4. Browser/Plugins 只在需要时启用。

第三步 · 手机接管

先在桌面端确认 Tailscale Serve，再用手机打开 HTTPS 地址；验证继续对话、启动 Agent、查看文件和执行一条无破坏命令。

成功标准不是“网页能打开”，而是：连接状态清楚、权限边界可见、同一 Session 能继续、命令确实在宿主机执行、断线后不会把旧缓存伪装成新状态。
06

构建与排障：源码路径的真实前置条件

BUILD / DEBUG

源码构建前置

  • Git submodule support
  • Node.js 24+
  • pnpm 11.7.0
  • vendor/deepseek-harness 已 checkout
  • 平台原生编译工具链

命令顺序

pnpm run harness:stage pnpm start pnpm make

首次 checkout 或 Harness runtime contract 变化后重新 stage；make 会再次执行完整 runtime stage。

高频排障

  • macOS 不能打开：优先 Open Anyway，quarantine 命令只针对精确 App。
  • 渠道凭据不可用：检查 codesign 与 Keychain，不要删除 secrets。
  • 远程连不上：确认一条 route 已启用、手机和主机身份一致、HTTPS 地址来自 Minke。
07

安全边界与选择判断

BOUNDARIES
项目身份：Minke 是独立社区项目，不是官方 DeepSeek 产品；项目仍在活跃开发，功能、打包方式和本地数据 schema 可能变化。

远程边界：“不是远程桌面”不代表低权限；它提供真实文件和 PTY 能力，远程身份管理必须先于便利性。Tailscale Serve/Cloudflare Access 的私有访问配置不能省略。

更新边界：README 描述 updater 会校验 Release、文件大小和 SHA-256，但本卡不把这视为当前机器上的实测结果。
