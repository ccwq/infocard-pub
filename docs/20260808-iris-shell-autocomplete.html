01 · 它解决什么

把代码编辑器里的 IntelliSense 体验搬到 TTY，让 shell 输入有实时建议菜单

IRIS = Intelligent Real-time Input Suggestion。它不是按 Tab 才补全的传统 shell 插件，而是原生运行在 TTY 上的单个 Go 二进制：

  • 实时补全菜单：敲 git che 时弹出候选（checkout、cherry-pick 等），无需先按 Tab
  • 本地 / SSH / Tmux 全场景可用：直接挂在 TTY 之上，远程服务器和 Linux 虚拟终端都跑得动
  • 单文件本地 Go 二进制：不依赖 Electron、不开 GUI、不带后台守护进程、不上报任何遥测
  • 本地 AI 补全（可选）：接 Groq 云端或本地 Ollama，按 debounce 节流，不阻塞主线程

⚠️ README 仍标记为 beta，Windows 当前不在支持列表。

03 · 补全来源（README 原文）

IRIS 不是简单把 shell 内置补全再贴一层 UI。它会主动索引这几类来源，按你的实时输入给出候选：

A · Built-in spec

内置命令规格库

对常见命令（git、docker、kubectl、npm…）自带补全规格，按参数位置给出候选项。

B · Shell history

shell 历史记录

你过去敲过的命令会被索引，前缀匹配时直接列出来；切换到 history 模式只显示历史。

C · Aliases

shell alias

自动索引你的 alias，敲别名时也能给出对应真实命令的展开建议。

D · Files & Directories

文件 / 路径

路径前缀匹配继续补目录和文件；可在 UI 里关掉隐藏文件。

E · Git 分支感知

当前仓库的 git 状态

区分当前分支与远端/已合并分支，自动去重；可关掉跨分支污染。

F · AI suggestion（可选）

OpenAI-compatible provider

接 Groq（默认 llama-3.3-70b-versatile）或本地 Ollama（默认 qwen2.5-coder），按 debounce 触发。

04 · 安装方式（按场景挑）
Homebrew

macOS / Linux（最省事）

brew install versenilvis/iris/iris

装完会自动跑 iris setup，把 shell 集成代码注入对应 rc 文件。

官方安装脚本

无 brew 环境的通用方式

curl -sSL https://raw.githubusercontent.com/versenilvis/iris/main/scripts/install.sh | sh

脚本会按 uname 选 darwin_amd64/arm64 或 linux_amd64/arm64 拉 release tarball；优先装 /usr/local/bin，无权限则落 ~/.local/bin。

Go install

已经装 Go 1.24+ 的开发者

go install github.com/versenilvis/iris/cmd/iris@latest
包管理器（按发行版）

Arch / Debian / Fedora / Nix / asdf / aqua

yay  -S iris-autocomplete        # Arch
dpkg -i iris_linux_amd64.deb    # Debian/Ubuntu
rpm  -i iris_linux_amd64.rpm    # Fedora/RHEL
nix profile add github:versenilvis/iris   # Nix

asdf 走 asdf plugin add iris https://github.com/versenilvis/asdf-iris.git。

05 · Shell 集成（极薄）

安装脚本会往 rc 文件里加一行；如果你重置过 rc，手动补这一行即可：

# zsh  ~/.zshrc
eval "$(iris init zsh)"

# bash ~/.bashrc
eval "$(iris init bash)"

# fish ~/.config/fish/config.fish
iris init fish | source

⚠️ README 警告：同时跑 zsh-autosuggestions / zsh-autocomplete / atuin / flyline 这类补全插件会和 IRIS 抢键位与视觉，建议在装 IRIS 之前先关掉它们。

06 · 关键键位（默认）
快捷键行为
Shift+Tab显示 / 隐藏建议菜单
Tab接受当前选中建议
→接受 ghost text（淡色预测文字）
↑ / ↓候选条目上下移动；空 prompt 时浏览历史
Ctrl/⌘+R在 spec ↔ history 模式之间切换
Esc临时隐藏菜单（下次按键再恢复）
Enter关闭菜单并把当前命令送给 shell 执行
07 · AI 补全怎么接（可选）

在 ~/.config/iris/config.toml 里开启：

[ai]
enabled = true
provider = "groq"     # 或 "ollama"
debounce_ms = 400

[ai.providers.groq]
endpoint = "https://api.groq.com/openai/v1/chat/completions"
api_key_env = "GROQ_API_KEY"     # 推荐用环境变量，别明文写
model = "llama-3.3-70b-versatile"
timeout_ms = 3000

[ai.providers.ollama]
endpoint = "http://localhost:11434/v1/chat/completions"
model = "qwen2.5-coder"
timeout_ms = 5000

两点原则：① key 走 api_key_env 而不是 api_key；② debounce 在 400ms 量级，避免每敲一个键都打 API。

08 · 边界 & 注意事项
⚠️ 已知边界

beta 阶段 + 仅 Unix 系

  • 当前 README 标记为 beta，不排除破坏性变更
  • Windows 不支持（README 明示）
  • 需要 ANSI 颜色支持的终端模拟器
  • 已有 14 个 open issues，动手前先扫一遍
🔒 隐私边界

debug 模式会记录你敲的所有内容

  • 默认 debug=false，不要长期开
  • 调试日志写在 ~/.iris/crash.log
  • crash 时自动落盘，可用 iris crash-log 定位
  • AI provider 走你自己的 key，不上传到 IRIS 项目

IRIS 的最大价值不是"又多了一个补全工具"，而是把 Fig 那种 GUI 级 IntelliSense 体验重新拉回 TTY：单 Go 二进制、零遥测、跨平台 shell、SSH/Tmux 通吃。如果你在远程服务器、Tmux 窗格或者不想装 GUI 的工作流里频繁敲长命令，它值得先在容器里试一下，再决定要不要常驻。
