费曼分级
L1 → L5

费曼技巧的关键不是把所有话都降到儿童频道，而是根据听众的背景知识，调整信息密度、术语深度与对话方式。

先划边界： L1-L5 不是费曼本人提出的正式教育量表，而是中文互联网对“面向不同对象解释”难度的后设模型。本卡将模型与原始费曼技巧分开呈现。

五级不是“高低贵贱”，是沟通协议

同一个概念，换一个受众，讲法就要换一套。等级描述的是当前这次解释的接口，不是给人的智力贴标签。

L1把抽象物落到生活里

假想对象是 8 岁以下儿童，背景知识接近零。只讲一个核心概念，用自己的话、故事、图画和日常类比，避免术语与未经解释的数量级。

  • 适合：第一次接触、亲子科普、跨领域开场
  • 检查：对方能否复述，而不是只点头

L2从“能听懂”到“能追问”

假想对象是 13—18 岁青少年，已有基础知识和初步抽象能力。可以谈“怎么研究、有什么意义”，用实例或实验加深理解。

  • 适合：课堂启蒙、科普对话、概念辨析
  • 检查：能否提出自己的问题与观点

L3面向普通成人分享

假想对象是具有一般知识储备与大学生学习能力的成年人。可以深入研究方法，使用必要术语，但仍需保持清晰、逻辑和可跟随。

  • 适合：文章、演讲、产品说明、公共讨论
  • 检查：听众能否沿着论证复述因果链

L4与同领域研究生推演

受众有较深理论背景。信息量上升到研究方法、专业案例、前沿或边缘知识；例子仍有用，但不必把每一步都改写成生活比喻。

  • 适合：读书会、研究汇报、技术评审
  • 检查：边界条件、证据和方法是否经得起追问

L5与领域同行进行思想对话

双方都是同领域专业人士。重点从“教会对方”转向共同探讨前沿假设、底层逻辑、反例与新问题；行话通常不需要逐一解释。

  • 适合：论文讨论、专家会议、共同建模
  • 检查：是否产生新的问题，而不只是完成复述

KEY等级的真正变量

不是年龄本身，而是三件事：听众已有的背景知识、抽象理解能力、以及这次沟通想完成的目标。一个专家面对孩子，仍然应该切换回 L1。

  • 从 L1 到 L5：信息密度逐步上升
  • 从 L1 到 L5：单向教导逐步转向双向对话

同一主题，五种接口

以“记忆”为例：不改变核心事实，改变的是入口、抽象度和允许的追问范围。

级别开口方式信息密度对话目标
L1“大脑里的细胞会互相说话。”先用孩子熟悉的事物建立画面。一个概念 + 一个生活类比。让对方形成可复述的直观模型。
L2“如果把大脑的联结输入电脑，电脑会成为你吗？”允许抽象问题。概念 + 机制直觉 + 实例。激发问题和自己的观点。
L3“记忆如何依赖神经连接与信息提取？”给出清晰论证。概念、方法、必要术语。让成人沿着逻辑理解并应用。
L4“怎样绘制人的大脑地图？”进入研究设计。方法、案例、证据、边界。接受专业追问与复核。
L5“现有模型在哪些前沿条件下失效？”共同推演。底层假设、反例、未决问题。碰撞思想，生成新问题。

别把“没听懂”直接判成费曼失败

常见误读

“费曼技巧 = 必须把任何内容讲到 8 岁儿童都懂。”于是，成年人之间的技术讨论也被强行降维；听众一旦没听懂，就把责任全部推给讲者。

更准确的判断

先问：这次沟通的对象是谁？目标是教、分享，还是共同探讨？如果受众和目标没有对齐，问题不是“讲得不够白”，而是解释协议选错了。

把分级用起来：四步自检

01 / 定对象

写下真实受众，而不是笼统地说“大家”。

02 / 定目标

区分教会、分享、应用、评审或共同建模。

03 / 调密度

同步调整背景铺垫、术语、例子和反例数量。

04 / 看反馈

用复述、追问和反例测试理解，不用点头代替证据。
