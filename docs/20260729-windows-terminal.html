WINDOWS / CLI / PRODUCTIVITY

Windows Terminal

把 CMD、PowerShell 与 WSL 收进同一个现代命令行工作台。

01现代命令行终端

Windows 11 通常已预装；Windows 10 可从 Microsoft Store 或 GitHub 获取。

为什么值得用

多环境统一入口

在同一个应用中切换 CMD、PowerShell 和 WSL，减少窗口切换与配置分散。

多标签工作流

为不同项目、服务器或 shell 建立标签页，适合开发、运维和日常自动化。

GPU 加速渲染

利用硬件加速处理终端画面，并支持 Cascadia Code、主题与配置定制。

上手路径

Windows 11

开始菜单搜索 Windows Terminal；先确认默认 profile，再按需要调整字体、配色和启动目录。

Windows 10

从 Microsoft Store 安装，或前往 GitHub Releases 获取版本。

重度用户

将 PowerShell 自动化、WSL Linux 工具链与项目目录绑定到不同标签页。

适合谁

如果你经常同时使用 PowerShell、Linux 命令和 Windows 原生命令，Windows Terminal 是最稳妥的统一入口；它不是替代 shell，而是把多个 shell 组织起来。
# 查看当前 PowerShell 版本
$PSVersionTable

# 进入 WSL
wsl
