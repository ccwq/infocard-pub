# 专注领域 检查内容
1 拼写、语法与学术风格 拼写错误、语法问题、学术表达规范性、引用格式一致性
2 内部一致性与交叉引用 前后定义一致性、图表编号引用、变量命名统一、逻辑自洽
3 未支撑声明与识别完整性 未经证实的结论、因果关系过度声称、识别策略漏洞
4 数学、公式与符号 推导过程、符号一致性、单位使用、附录与正文公式对应
5 表格与图表 表格可读性、图表标注完整性、数值精度、图例清晰度
6 贡献度评估（对抗性） 创新点强度、与现有文献差异化、期刊适配度、贡献声明合理性
5 SKILLS

套件包含的五个 Skill

/review-paper

预提交 referee 报告

完整 6 Agent 并行审稿，生成结构化 referee 报告，输出到 PRE_SUBMISSION_REVIEW_[日期].md

6 agents · 完整评审
/review-paper-light

快速论文检查

2 Agent 快速迭代，聚焦贡献度、识别策略、因果声称和未支撑结论，适合提交前的快速自检

2 agents · 快速版
/review-paper-code

论文-代码可复现性审查

检查实证研究代码可复现性、paper-code 一致性、样本限制和固定效应对应，输出 code_review_report.md

代码 + 数据审计
/review-pap

Pre-Analysis Plan 评审

6 Agent 评审 PAP 的写作质量、规范完整性、识别策略、统计分析、注册适配度

6 agents · PAP 专用
/review-grant

Grant 提案评审

评审 Grant 提案的创新性、可行性、预算合理性、研究计划完整性

Grant 专用

本地部署四步走

①

安装 Claude Code

确保已安装 Claude Code 并配置好 ANTHROPIC_API_KEY，启用 general-purpose subagent。

②

下载 Skill 文件

创建命令目录并拉取 Skill 文件，或直接用 curl 一键安装到 ~/.claude/commands/。

③

进入论文目录

切换到你的 LaTeX 论文目录，Claude Code 会自动检测主 .tex 文件和代码目录结构。

④

激活 /review-paper

输入 /review-paper 或指定期刊如 /review-paper QJE，等待报告生成。

INSTALL · 一键安装 Skill
# 全局安装（所有项目可用）
$ mkdir -p ~/.claude/commands && curl -o ~/.claude/commands/review-paper.md \
$   https://raw.githubusercontent.com/claesbackman/AI-research-feedback/main/Skills/review-paper.md

# 项目本地安装（仅当前项目可用）
$ mkdir -p .claude/commands && curl -o .claude/commands/review-paper.md \
$   https://raw.githubusercontent.com/claesbackman/AI-research-feedback/main/Skills/review-paper.md

# 安装全部 Skill
$ for f in review-paper review-paper-light review-paper-code review-pap review-grant; do
$   curl -o ~/.claude/commands/$f.md \
$   https://raw.githubusercontent.com/claesbackman/AI-research-feedback/main/Skills/$f.md
$ done
USAGE · Claude Code 中的使用方式
# 基本使用：自动检测 .tex 文件
$ /review-paper                    # 通用高标准审稿
$ /review-paper QJE               # 指定 QJE 期刊视角
$ /review-paper JF path/to/main.tex  # 指定文件和期刊

# 快速检查
$ /review-paper-light              # 2 Agent 快速版
$ /review-paper-light path/to/main.tex

# 代码可复现性审查
$ /review-paper-code               # 默认：核心脚本
$ /review-paper-code path/main.tex path/code_dir full  # 全量审查

# Pre-Analysis Plan 评审
$ /review-pap                    # 默认 top-journal 标准
$ /review-pap AEA                # AEA 注册标准

FAQ

常见问题

Q: 这个 Skill 和通用 AI 润色工具的区别是什么？
不只是润色，是系统性的学术评审——模拟期刊审稿人的视角，检查逻辑漏洞、识别策略、数据一致性，而非语言流畅度。6 个 Agent 各司其职，覆盖人工审稿的所有维度。
Q: 支持中文论文吗？
Skill 主要面向英文 LaTeX 论文设计，但语言检测和逻辑评审能力对中文论文也有参考价值。图表说明、公式规范等检查同样适用，中文项目可尝试使用。
Q: 本地运行能保证文档安全吗？
完全本地运行。Claude Code 在本地执行，文档不经过任何第三方服务器。所有审稿过程和输出文件都在你的本地机器上。
Q: review-paper-code 支持哪些编程语言？
支持 Stata（.do）、R（.R）和 Python（.py）三种主流实证分析语言，自动检测代码目录结构，分析可复现性、路径、随机种子、依赖和运行顺序。
Q: 快速版和完整版怎么选？
提交前快速迭代用 /review-paper-light（2 Agent，约 5 分钟），正式提交前用 /review-paper（6 Agent，完整评审，约 15-30 分钟）。
Q: 可以和其他 Skill 配合使用吗？
可以。推荐工作流：论文写作 → AI-research-feedback 评审 → anti-vibe-writing 最终润色。先保证内容质量，再优化表达方式。
