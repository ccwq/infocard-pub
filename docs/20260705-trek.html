QUICK START · Docker 单命令启动
# 一行命令启动 TREK（推荐）
$ ENCRYPTION_KEY=$(openssl rand -hex 32) docker run -d -p 3000:3000 \
  -e ENCRYPTION_KEY=$ENCRYPTION_KEY \
  -v ./data:/app/data -v ./uploads:/app/uploads \
  mauriceboe/trek

# 访问 http://localhost:3000
# 查看初始管理员密码：docker logs trek

# 生产环境：Docker Compose 部署（含 SMTP / 反向代理）
$ git clone https://github.com/mauriceboe/TREK.git
$ cd TREK && docker compose up -d

# 可选：Helm 部署到 Kubernetes
$ helm repo add trek https://charts.liketrek.com
$ helm install trek trek/trek -n trek --create-namespace

# SSO / OIDC 配置示例（Google / Authentik / Keycloak）
ADMIN_EMAIL=admin@example.com    # 管理员邮箱
OIDC_ISSUER=https://your-idp.com   # OIDC 提供商地址
OIDC_CLIENT_ID=trek-client-id    # OAuth Client ID
OIDC_CLIENT_SECRET=***      # OAuth Client Secret

FAQ

常见问题

Q: 和 Wanderlog、TripIt 有什么区别？
核心区别是完全自托管——你的数据在自己的服务器上，不交月费，不被数据变现。所有功能都是开源的，可以自己修改和扩展。缺点是需要一点运维投入。
Q: 需要自己写代码吗？
不需要。Docker 一键启动，开箱即用，有种子管理员账号。如果需要 SSO 集成或插件管理，也只需要配置环境变量，不需要写代码。
Q: 数据存在哪里？安全吗？
数据默认存在运行服务器的本地目录（./data），可通过卷挂载自定义路径。支持 TOTP 2FA、Backup Codes、Passkeys（WebAuthn）和 AES 加密存储。
Q: 支持移动端吗？
是 PWA（渐进式 Web 应用），可从浏览器直接安装到 iOS/Android 主屏。Service Worker 支持离线缓存，地图瓦片和 API 响应均可离线查看。
Q: 可以不用 API Key 吗？
可以。地图支持 OpenStreetMap（免费，无需 API Key）。地点搜索默认用 OSM，如果需要 Google Places 照片/评分/营业时间，再申请 Google API Key。
Q: 可以接入 AI 吗？
内置 MCP Server，支持 OAuth 2.1 认证。AI 助手可以创建行程、规划日程、生成打包清单、管理预算。已有预置 prompt：trip-summary、packing-list、budget-overview。
