Claude Code
Harness 是 Claude Code 的团队架构工厂。用一句话描述任务领域，插件即可生成专业 Agent 团队 + 配套技能（6 种预定义架构模式）。适合复杂任务的多智能体协作编排。
⚡ 安装
① Marketplace
claude plugin marketplace add revfactory/harness claude plugin install harness@harness export CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1
② Direct 全局安装
cp -r skills/harness ~/.claude/skills/harness
📋 前置要求
  • ✓ Claude Code v2.x+
  • ✓ Agent Teams 实验标志
  • ✓ 网络访问 github.com
  • ✓ 持久化 export 的 Shell
🎯 触发方式
"build a harness for <domain>" → 하네스 구성해줘 → 自动生成 Agent 团队
🏗 6 种架构模式
Pipeline
顺序依赖任务，上游输出驱动下游输入
Fan-out / Fan-in
并行独立调查 → 结果整合，团队通信发挥最大价值
Expert Pool
按输入类型动态选调用专家，适合代码审查等
Producer-Reviewer
生成 ↔ 质检成对，实时反馈循环，最大重试 2~3 次
Supervisor
中央 Agent 动态分配任务，TaskCreate 共享工作列表
Hierarchical Delegation
递归向下授权，建议不超过 2 层
⚙ 执行模式选择
模式工具适用场景通信
Agent Teams ★默认 TeamCreate / SendMessage / TaskCreate 2+ Agent 协作者，交叉验证、实时反馈 Team 内直接通信
Sub-agent Agent(tool) 直接调用 单 Agent / 结果导向 / 轻量开销 仅返回主 Agent
Hybrid Phase 级别混用 并行收集(Sub) → 共识整合(Team) Phase 边界衔接

❓ FAQ
Q1: 和 Archon 有什么区别？
Archon 是运行时配置工厂（确定性配置），Harness 是团队架构工厂（Agent 团队结构）。同一 L3 层邻居，组合使用：Harness 设计架构 → Archon 部署运行时配置。
Q2: +60% 数字可靠吗？
作者实测 A/B（n=15，15 个软件工程任务）。每个引用都注明 n=15, author-measured, third-party replications pending。建议自己跑 2~4 周内部试点并测量自己的数字。
Q3: Claude Code 以外的运行时能用吗？
官方只支持 Claude Code。Codex 移植版已在 meta-harness 公开。跨运行时支持在路线图上。
