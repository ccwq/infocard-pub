## 原帖核心

想从零学习 Vibe Coding，不用买课，五个免费开源项目中选择一个合适的，可以打通从 AI 编程入门到工作流工程化的路径。

## 五个项目

1. `datawhalechina/easy-vibe`  
   三阶段：AI 编程小游戏、产品创意 + Web 原型、桌面应用与多 Agent 协作。适合零基础入门。

2. `tradecatlabs/vibe-coding-cn`  
   原帖 URL 为 `tukuaiai/vibe-coding-cn`，GitHub API 显示已重定向到 `tradecatlabs/vibe-coding-cn`。内容围绕 Prompt、Skill、Workflow，强调规划先行、模块拆分、接口在前。

3. `filipecalegario/awesome-vibe-coding`  
   Vibe Coding 资源总目录，覆盖浏览器工具、IDE、移动端 App、插件、CLI 工具。

4. `automata/aicodeguide`  
   AI 编程路线图，整理 Cursor 等工具栈、Prompt 控制 AI 的工作流、最佳实践、教程和博客。

5. `2025Emma/vibe-coding-cn`  
   用“道 / 法 / 术 / 器”解释 AI 编程，强调方向、架构、调试、工具组合、提示词库、上下文防遗忘与递归优化。
