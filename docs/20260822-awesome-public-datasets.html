整理规范与特点

✅ 精选整理

不是爬虫罗列，每条经人工审核
Topic-centric 分类，非简单字母排序
附原始来源链接，可直接溯源
包含数据规模、元数据格式说明

📋 数据集元数据规范

来源（博客/问答/用户反馈）
数据量级与格式（CSV/JSON/API 等）
是否免费 / 付费标注
更新频率与历史版本

📖 使用方式

浏览: 按领域目录索引，找到对应主题数据集条目
提交: GitHub Pull Request，附来源、数据量与质量说明
引用: 建议注明原始来源和维护者，尊重数据贡献者
订阅: Watch 仓库跟踪更新和新数据集收录
