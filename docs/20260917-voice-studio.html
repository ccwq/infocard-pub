04
API & INTEGRATIONS

OpenAI-Compatible API + MCP Server + Batch Queue

Integrate VoiceStudio into any AI workflow. OpenAI-compatible endpoint, MCP tools, and batch processing.

OpenAI-Compatible API

# POST /v1/audio/speech — OpenAI-compatible endpoint
curl -X POST http://localhost:3900/v1/audio/speech \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "voice-studio",
    "input": "Hello, this is a test of VoiceStudio TTS.",
    "voice": "default"
  }' \
  --output speech.mp3

MCP Server Tools

🎤 tts_speak

Generate speech from text. Specify engine, voice, language, and output format.

🔊 voice_clone

Clone a voice from a 3-second audio clip. Use the cloned voice for TTS in 646 languages.

✂️ transcribe_audio

Transcribe audio with WhisperX or any of 9 other ASR engines. Returns word-level timestamps.

🎬 dub_video

Full video dubbing: transcribe → translate → re-voice → export MP4.

📖 audiobook_convert

Convert EPUB or PDF to .m4b audiobook with multi-voice cast narration.

📋 batch_queue

Queue 50+ jobs with per-job progress bars. Monitor and manage batch processing.
