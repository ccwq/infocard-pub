01

书是什么：不是工具清单，是工作流拆解

作者宝玉（Jim Liu）把长期使用 Agent 的实战经验写成书，配套仓库开源所有技能和插图。

书的定位

一本 Agent 提效的"方法论+实战"书。

作者使用 Agent 辅助编程的经验积累，把常见工作流（采访→写作→分析→插图）拆解成标准步骤，配上对应的 Skill 和 Prompt。

配套仓库价值

仓库包含书中放不下或更适合在线查阅的内容：

  • 各章配图 + 对应 Prompt（生成本书所有插图的完整提示词）
  • 写作工作流技能的完整版（书末附录是简化版）
  • 章节示例代码与数据文件
  • 生成本书插图所用的 Skill 本身（可安装复用）

04

核心工作流：采访 → 写作 → 插图 → 发布

第5章的完整写作闭环，所有环节都有对应的 Skill 可以直接装上去用。

1
采访分析：interview-analysis → 提取关键论点 + 生成追问建议，不用自己读完全部录音。
2
采访写作：interview-writing → 生成结构化采访文章草稿，包含引言/正文/结语。
3
对抗性打磨：adversarial-polish → 两个 Agent 互相评审同一段文字，强化论点和表达。
4
插图生成：book-illustrator → 输入章节内容 → 完整插图 Prompt → 渲染配图（本书所有插图均用此 Skill 生成）。
5
周报输出：weekly-report → 输入要点 → 结构化周报，可直接发给领导或存档。
05

适合谁：不是给所有人的，边界要清楚

这本书和配套仓库有明确的适用边界，强行套用会失望。

✓ 适合

有写作/内容创作需求的开发者：用 Agent 辅助写采访、技术文档、周报

想系统化 Agent 工作流的人：不只是想用，还想把流程固化下来

需要可复用 Skill的团队：直接装 book-illustrator / weekly-report 改改就用

对 Agent 插图制作感兴趣：book-illustrator Skill 的完整提示词是开源的

✗ 不适合

零基础 AI 小白：书中不解释基本概念，默认读者知道 Agent 是什么

只想找工具清单：这本书讲方法论，不是 100 个工具推荐

不需要写作/内容创作：工作流核心围绕采访→写作展开，没有代码生成专项

没有耐心读实战书：66.9k ⭐ 说明热度高，但书本身有一定阅读门槛

最终判断：《图解 Skill》是把 Agent 提效从"感觉"变成"方法论"的一次系统化尝试。核心价值不是工具推荐，而是工作流的拆解和 Skill 化——把采访→写作→配图→发布每个环节固化下来，让其他开发者可以直接复用。

配套仓库最大的彩蛋是 book-illustrator Skill——生成本书所有插图的完整提示词全部开源，读完书还可以把这个 Skill 装到自己 Agent 里用。适合有内容创作需求的开发者快速落地。
