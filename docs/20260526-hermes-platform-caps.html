调查结论
飞书是多 Bot 接入最佳选择
飞书支持同一 Hermes 实例通过 channels.feishu.accounts 配置多个 Bot，每个绑定独立 Agent，实现"分工协作、各司其职"，社区教程最完整。
微信是唯一协议层限制"一账号一 Bot"的平台
iLink Bot API 的 OAuth2 扫码授权机制决定了一个微信账号同一时刻只能有一个有效 Bot token，无法通过配置绕过。需多账号只能用微信多开 + 多 Hermes profile 实例。
建议
如需多 Bot 协同，优先使用飞书；如必须用微信做入口，可用微信群聊（开启 group_policy）+ 飞书多 Bot 组合方案。
