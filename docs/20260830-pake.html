04两条构建路径

本地 CLI：一条命令起步

pnpm install -g pake-cli pake https://github.com --name GitHub

以上是 README 明确给出的基础示例：安装 CLI 后，把网页地址与应用名交给 Pake。高级示例还展示了自定义图标、宽高和隐藏标题栏等选项。

GitHub Actions：在线构建

README 将 Online Building 指向项目的 GitHub Actions 使用文档；适合不想在本机准备构建环境的使用者。具体工作流字段与权限，以仓库文档当前版本为准。

快速判断：只想把常用网站装成 App → 先看 Popular Packages；要改名字、图标或窗口 → CLI；不想配环境 → GitHub Actions 在线构建。

05适用边界与责任
  • ✓ 适合：把高频网页集中到独立窗口、减少浏览器标签切换、需要基础窗口与快捷键定制的场景。
  • ✗ 不保证：网页依赖登录态、系统通知、后台常驻、深度系统集成时，桌面 App 体验可能与原生应用或浏览器不同。
  • 许可证：GPL-3.0；README 另有 Pake Output Exception，分发或二次开发前应阅读仓库 LICENSE。
  • 责任边界：目标网站的服务条款、品牌使用、内容版权与分发责任由使用者承担。
