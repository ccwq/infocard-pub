02Demo — gsap-core

基础单目标动画 — gsap.to()

gsap.to(target, vars) — 动画至目标状态
gsap.to(".box", {
  x: 100,
  autoAlpha: 1,   // opacity + visibility
  rotation: 360,
  duration: 0.6,
  ease: "power2.inOut"
});

// from() — 从初始状态动画
gsap.from(".title", {
  y: -60,
  opacity: 0,
  duration: 0.8,
  ease: "back.out(1.7)"
});

// stagger — 批量错开动画
gsap.from(".card", {
  y: 40,
  opacity: 0,
  stagger: 0.1,  // 每张卡片延迟 100ms
  duration: 0.5,
  ease: "power2.out"
});

Easing 曲线速查

power 系列（最常用）

  • "power1.out" — 减速停止，自然
  • "power2.inOut" — 入场加速，出场减速
  • "power3.out" — 更有力度的减速
  • "power4.inOut" — 电影感平滑

弹性 / bounce

  • "elastic.out(1, 0.3)" — 弹簧回弹
  • "bounce.out" — 物理弹跳
  • "back.out(1.7)" — 先冲后回

特殊

  • "rough({ strength:1, points:20 })"
  • "slow(0.5, 0.8, true)"
  • "steps(8)" — 逐帧动画
03Demo — gsap-timeline

时间轴编排 — 精确控制动画时序

gsap.timeline() — 链式编排
const tl = gsap.timeline({ 
  defaults: { ease: "power2.inOut" }
});

tl.to(".panel-left", { x: -100, duration: 0.5 })
  .to(".panel-right", { x: 100, duration: 0.5 }, "<") // < = 与上一动画同时开始
  .to(".overlay", { autoAlpha: 0, duration: 0.3 }, "+=0.2") // +=0.2 = 等待 0.2s
  .add("reveal") // 标签
  .from(".content", { y: 30, opacity: 0, duration: 0.4 }, "reveal+=0.1")
  .call(myCallback); // 回调函数

// 控制方法
tl.play()        // 播放
tl.pause()       // 暂停
tl.reverse()     // 倒放
tl.restart()    // 重新播放
tl.seek("reveal") // 跳转至标签

Position Parameter 详解

相对定位

  • ">" — 上一动画结束点（最常用）
  • "<" — 上一动画开始点（同时开始）
  • "+=0.5" — 相对上一结束点再等 0.5s
  • "-=0.3" — 提前 0.3s 开始

绝对定位

  • 1.5 — timeline 1.5s 处
  • "reveal" — 标签位置
  • "reveal+=0.5" — 标签后 0.5s

嵌套 Timeline

  • 子 timeline 可嵌套进父 timeline
  • 父 timeline 控制子 timeline 的时间
  • 用 gsap.context() 统一管理
04Demo — gsap-scrolltrigger

滚动驱动 — ScrollTrigger 核心 API

ScrollTrigger — 滚动触发动画
// 基本滚动触发动画
gsap.from(".parallax-bg", {
  y: -80,
  ease: "none",
  scrollTrigger: {
    trigger: ".hero",
    start: "top top",    // trigger 顶部触达 viewport 顶部
    end: "bottom top",   // trigger 底部触达 viewport 顶部
    scrub: 1              // 1s 缓动同步滚动
  }
});

// scrub=true 时用 gsap.to()，不用 from()
gsap.to(".progress-bar", {
  scaleX: 1,
  scrollTrigger: {
    trigger: "body",
    start: "top top",
    end: "bottom bottom",
    scrub: true
  }
});

// Pinning — 固定元素
gsap.to(".sticky-panel", {
  scrollTrigger: {
    trigger: ".pin-section",
    start: "top top",
    end: "+=600",      // 固定 600px 滚动距离
    pin: ".sticky-panel", // 固定元素
    scrub: 1
  }
});

ScrollTrigger 核心概念

start / end 语法

  • "top top" — 触发器顶 → viewport 顶
  • "center center" — 中心对齐
  • "bottom 80%" — 底部对齐 80% 处

scrub 模式

  • scrub: 1 — 平滑跟随（数值=秒数缓动）
  • scrub: true — 即时硬同步
  • 不用 scrub 时：动画一次性播放（toggleActions）

toggleActions

  • "play none none reverse"
  • 依次：enter / leave / enterBack / leaveBack
  • 常用："play none none reverse"
05Demo — gsap-react

React 集成 — useGSAP hook

useGSAP — React 专用 Hook
import { useGSAP } from '@gsap/react';
import { gsap } from 'gsap';
import { ScrollTrigger } from 'gsap/ScrollTrigger';
gsap.registerPlugin(ScrollTrigger);

function HeroSection() {
  const containerRef = useRef(null);

  useGSAP(() => {
    // 创建 scoped context，组件销毁时自动清理
    const ctx = gsap.context(() => {
      gsap.from(".hero-title", {
        y: 60, opacity: 0,
        duration: 0.8, ease: "power3.out"
      });
      gsap.from(".hero-sub", {
        y: 30, opacity: 0,
        duration: 0.6, delay: 0.2, ease: "power2.out"
      });
    }, containerRef); // ← 关键：传入 scope

    return () => ctx.revert(); // cleanup
  }, { scope: containerRef });

  return (
    <div ref={containerRef}>
      <h1 className="hero-title">Welcome</h1>
      <p className="hero-sub">GSAP + React</p>
    </div>
  );
}

React + GSAP 最佳实践

gsap.context() 生命周期

  • gsap.context(fn, scope) — 包裹所有动画
  • ctx.revert() — 组件卸载时清理所有动画和 ScrollTrigger
  • 避免内存泄漏和动画残留

useGSAP vs useLayoutEffect

  • useGSAP 自动处理 SSR（window 不存在时跳过）
  • useLayoutEffect 可能导致 SSR 水合不匹配
  • 始终使用 @gsap/react 提供的 hook

常见错误

  • ❌ 在 useEffect 里直接写 gsap，不用 context
  • ❌ 不传 scope，导致全局污染
  • ✅ useGSAP(..., { scope }) — 必传
06Plugins & Utils

Flip Plugin

状态切换（如列表排序）时记录前后位置，自动补间动画，消除"跳变"。
gsap.to(el, { flip:{ true }) 或 Flip.getState() + Flip.from()

Draggable

拖拽交互，支持 type:"x|y|rotation|scroll"、边界约束、惯性 (InertiaPlugin)。

ScrollSmoother

平滑滚动替代原生滚动，配合 ScrollTrigger 使用，统一管理滚动交互。

Observer

跨浏览器观测 click/touch/keyboard/scroll 事件，无需依赖 jQuery，事件触发即执行回调。

MotionPathHelper

SVG 路径动画辅助，拖拽预览路径，自动计算 motionPath 参数。

gsap.utils — clamp / mapRange / random

gsap.utils.clamp(0, 100, val) 限制范围
gsap.utils.mapRange(a, b, x, y, val) 线性映射
gsap.utils.random([1,3,5]) 随机取值

07What AI Agents Learn

✅ 正确使用 transforms

gsap-skills 训练 Agent 使用 x/y/rotation/scale 而非 left/top/margin，确保 GPU 加速和 60fps。

✅ will-change 优化

何时添加 will-change: transform（动画开始前），何时删除（动画结束后），避免过早优化导致内存浪费。

✅ ScrollTrigger scrub vs toggle

区分 scrub（滚动同步）和 toggleActions（一次性触发的使用场景），避免混用导致性能问题。

✅ React cleanup 模式

训练 Agent 生成 gsap.context() + ctx.revert()，自动处理组件卸载时的动画清理。
