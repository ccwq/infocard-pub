Ghidra 是 NSA Research Directorate 创建并维护的软件逆向工程框架。它覆盖反汇编、反编译、图形化分析和脚本自动化，支持 Windows、macOS、Linux，以及多种处理器指令集和可执行文件格式。它能帮助你提出“程序在做什么”的可检验假设，但反编译结果不是原始源码，也不等于自动完成漏洞判定。

你有授权分析这个二进制吗？

授权：确认样本、设备、软件和网络行为在你的分析范围内。
版本：官方 README 提醒部分版本存在已知安全漏洞；先看 Security Advisories。
目标：静态分析可以帮助理解行为，不替代沙箱、动态分析、签名校验或人工复核。
01

它是什么：一套可交互、可自动化的 SRE 工作台

同一个项目同时服务人工 CodeBrowser 分析和批量脚本流程。

反汇编与反编译

将机器码映射为汇编与较高层次的伪代码，帮助定位函数、调用关系和数据流；名称、类型和结构需要分析者验证。

图形化与程序模型

用控制流、调用图等视图观察程序结构；图形是分析导航，不是“看一眼就懂”的完整行为证明。

脚本与扩展

用户可以用 Java 或 Python 编写脚本和扩展，重复执行命名、查询、导出或筛选；批量操作前先在副本上验证。

事实边界：README 确认 NSA 创建并维护、用于分析恶意代码和潜在网络/系统漏洞；这不表示每个样本都能被自动识别或修复。
02

安装：官方预构建包优先，先锁 JDK 与校验和

当前官方 release 为 Ghidra 12.1.3，tag 为 Ghidra_12.1.3_build。

01

安装 JDK 25

官方要求 64-bit JDK 25；先确认 java 版本。

02

下载 Release

下载 Assets 中的多平台 zip，不要下载 Source Code 代替安装包。

03

核对 SHA-256

12.1.3 官方 zip 校验和记录在 release 页面。

04

独立解压

不要覆盖旧安装；从 ghidraRun 或 ghidraRun.bat 启动。

# Linux/macOS 示例 java -version sha256sum ghidra_12.1.3_PUBLIC_20260817.zip unzip ghidra_12.1.3_PUBLIC_20260817.zip -d ./tools/ cd ./tools/ghidra_12.1.3_PUBLIC a ./ghidraRun # Windows：运行 ghidraRun.bat
安全提示：当前快照的官方 zip SHA-256 为 93a5d11a9ad510622acaaf908c556a7b9b764d338e78a7567f3689bf5081fd54；下载后应与你实际文件的 sha256 输出逐字比对。
03

第一次分析：从无害样本开始建立证据链

不要把可疑样本直接拖进日常工作机并执行；静态分析和动态执行要分开。

导入与分析

在隔离环境打开 Ghidra，创建项目，导入你有权分析的二进制，按架构/格式选择或确认加载器，再运行自动分析。

三处交叉检查

对照 Listing、Decompiler 和 Functions/Symbols；记录函数地址、调用方、字符串和控制流，不要只复制一段伪代码。

形成可回溯结论

每个结论写清样本 hash、Ghidra 版本、函数地址、证据视图和不确定性；导出报告前人工复核。

# 一个保守的分析记录模板 sample_sha256: <your-authorized-sample-hash> ghidra_version: Ghidra_12.1.3_build entrypoint: <address> observed: <listing/decompiler/call-graph evidence> claim: <what the evidence supports> uncertainty: <what remains unverified>
04

脚本自动化：把重复步骤变成小而可审计的动作

Java/Python 脚本适合查询、标记和导出；不适合无审查地改写样本或批量执行未知动作。

适合自动化

批量枚举函数、查找字符串引用、导出函数列表、给已确认的模式加标签、生成分析记录。

脚本验收

先对副本运行；限制输出目录；记录脚本版本、输入 hash、分析数据库和错误日志。

扩展入口

官方提供 GhidraDev/Eclipse 与 VS Code 相关开发路径，但开发扩展应基于完整构建的 Ghidra 安装。

# 贡献/构建 Ghidra 源码的官方路径 # 需要 JDK 25、Gradle 9.1.0+、Python 3.9–3.14、 # Linux/macOS 的 GCC 或 Clang + make # Windows 需要 Visual Studio/C++ Build Tools gradle -I gradle/support/fetchDependencies.gradle gradle buildGhidra
05

漏洞与恶意代码：工具强不等于结论自动成立

逆向结果需要上下文、动态证据、版本信息和人工判断。

静态结果是什么

函数、字符串、调用图、交叉引用和反编译伪代码是线索与证据片段；编译优化、混淆和缺少符号都会影响可读性。

动态分析不能省

需要行为确认时，使用隔离沙箱、网络控制、快照和最小权限；不要在生产网络直接执行未经确认的样本。

版本先行

README 明确存在已知安全漏洞提示；安装或升级前阅读官方 Security Advisories，不把 12.1.3 之外的旧版本当作安全。

社区 MCP 边界：GhidraMCP、ghidra-mcp 是社区项目，不属于本卡核验的 NSA/Ghidra 官方仓库功能。接入 AI 前另行审查权限、数据流和插件来源。
