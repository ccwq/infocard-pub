核心理念：最小平滑几何 = 可动画几何

Pixel2Motion 的核心洞察：用 3 个语义部件构成的 logo 动画流畅；用 400 个像素级描点堆出来的 logo 永远做不了专业动效。

最小平滑几何 IS 可动画几何。这不是"尽量忠实地描图"，而是"用最简单的可编辑几何解释这个 mark"。复杂度降低，动画质量才能提高。

03

三步工作流：从像素图到可交付动效

每个阶段有明确产出物和 QA 门禁，不是"生成一次就行"。

# Phase 1 — PIXEL：分析源图，写 motion brief # 分析语义部件：mark / wordmark / dot / swoosh / 容器 # 确定品牌运动个性词（如 "swift, precise, confident"） # 决定使用场景：splash（1200-2000ms）/ header（300-800ms）/ hover（150-300ms） # Phase 2 — VECTOR：拟合最小平滑几何 # 遵循复杂度阶梯（见下方），每步都要 overlay QA # 目标：最低复杂度通过视觉 QA，即停止升级 # Phase 3 — MOTION：Disney 12 原则编排 + 定量 QA # easing probe / ink-delta continuity sweep # Final Frame Contract：动画必须精确落在 QA 验证的静态矢量上
mark · wordmark · dot 语义拆分 IoU 优化 Disney 12 原则 Final Frame Contract easing probe ink-delta sweep
04

复杂度阶梯：从不选最高，只选刚好够用

每个 level 都是一个 QA gate，只有当 overlay 显示结构性失配时才升级。

5
Trace-derived paths 最后手段 仅用于不规则轮廓，简单几何无法解释的形状。Trace 输出是测量辅助，非最终成品。
4
Smoothed outline paths 在有真实形状变化的地方才增加节点。保持 G1 切线连续性，禁止噪声级手柄翻转。
3
Few-curve analytic paths 少量立方段处理平滑缎带、曲线、盾牌。闭环/自交的变宽缎带（∞ 标记、书法体）用 centerline-scaffold 配方。
2
Primitive composites 少数几个基础图形或蒙版的布尔组合。
1
Primitives 首选 圆形、椭圆、矩形、线段、简单弧、transform。从这里开始。

SVG 结构是语义化的

  • 自动识别 mark / wordmark / dot 等语义部件
  • 每个部件独立可寻址（CSS / JS 动画直连）
  • 不再需要手动描路径、调曲线
  • 路径数据干净，可直接用于生产

v2 新增能力

  • 自交 draw-on 编舞（split-fill）
  • 闭环变宽缎带拟合（∞ 标记）
  • 定量运动 QA（easing probe、ink-delta continuity sweep）
  • exact easing subdivision + tip glint
