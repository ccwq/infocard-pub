07 / 先读清楚边界，再谈“生产级”

教程定位不是官方安全承诺

公开范围：10 章源码拆解与 TS / Python 对照内容公开；但 README 明确说明教程主体为阅读型，配套 L00–L31 课程实战代码暂未公开，不能写成“全量可执行课程”。

官方权限：Pi 默认不内建文件系统、进程、网络或凭据访问权限限制系统，也没有内置权限弹窗。它使用启动进程的权限；需要更强隔离时，应配合 Docker、Gondolin、OpenShell 或其他容器 / 沙箱。

使用建议：把这套教程当作学习与工程设计参考。是否用于生产，要结合权限、沙箱、供应稳定性与组织治理，而不是把“生产级”理解为官方认证。

08 / 一条可执行的阅读工作流

从图像线索到源码验证

① 先建立地图

从 ch01 总览开始，按 M01–M10 走一遍，再回到三层架构确认每章位于哪一层。

② 选一条对照线

TS 追随官方实现语言；Python 作为概念对照。不要把教程 Python 版写成 Pi 官方 Python SDK。

③ 做一次边界审计

读工具、会话、上下文之后，专门检查权限与沙箱：运行用户是谁？文件 / 网络 / 凭据能触达什么？隔离由谁提供？

④ 最后再做工程判断

教程的价值在于把机制讲清楚，而不是替你完成部署治理。
