V1 → V2 COMPARISON

v1 vs v2 核心差异

❌ v1 的局限

  • 对话为主，Agent 需单独安装依赖
  • Claude Code / Codex 需手动配置
  • 知识库读取，Agent 无法写入
  • 长对话历史卡顿感明显
  • 大文件导入可能阻塞界面
  • 单窗口为主，多任务效率受限
→

✓ v2 的突破

  • 内置 Agent 运行时，零依赖启动
  • Code Mate 一键配置 Claude/Codex
  • Agent 可读写知识库（Wiki 模式）
  • 全新数据层，超长对话依然流畅
  • 异步导入，界面始终响应
  • 多窗口 + 分屏，多任务并行
