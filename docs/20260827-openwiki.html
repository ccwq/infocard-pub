OpenWiki = AI 持续更新的代码/知识 Wiki + Grounded Claims 证据链 + 自纠正闭环

OpenWiki 是 LangChain 开源的 CLI 工具（MIT，15.7k ⭐），为代码库或个人知识生成并维护一份 AI 编写、可探索的 Markdown Wiki。Agent 读取源码，综合链接式 Wiki 并在每次变更后保持最新；内置可视化工具供人类浏览。关键创新是 Grounded Claims——每个命题都携带版本化源码证据（精确到文件+行号区间），当证据变化或消失，OpenWiki 立即知道哪些声明需要确认、修订或撤回，而非静默失效。OKF v0.2 格式输出，支持 Claude Code、Codex、OpenCode 集成，开箱支持 12 家模型商和 9 种内置连接器，可通过 GitHub Actions / GitLab CI / Bitbucket Pipelines 自动更新。

02
LOOP · 四阶段

自纠正闭环详解

Grounded Claims 的核心价值：事实永远有据可查，过时信息自动发现并处理。

① 证据检查

每次更新时，OpenWiki 重新验证每个 Grounded Claim 的源码证据——文件是否存在、行号区间是否有效、内容是否匹配。

② 发现陈旧声明

证据变化（修改/删除/移位）→ 对应声明标记为“stale”。未找到证据的声明标记为“unresolved”。

③ 协调器处理

Page Worker 接收完整 Claim 集合，按优先级和依赖关系规划重新生成顺序，确保上下文一致。

刷新 / 修订 / 撤回：对于证据仍然有效但描述过时的声明，执行刷新；对于证据部分变化的声明，执行修订；对于证据完全消失的声明，执行撤回。全程状态可查可审计。

04
SUITABLE · NOT SUITABLE

适用场景

OpenWiki 适合需要持续维护的代码和知识文档，不适合一次性文档生成。

适用

适合的场景

  • ✓ 活跃代码库的架构文档维护
  • ✓ 多 Agent 协作项目的共享记忆
  • ✓ 快速演进的 API / SDK 文档
  • ✓ 个人知识库的持续整理
  • ✓ 团队知识传承与新人 onboarding
  • ✓ Claude Code / Codex 项目的上下文管理
不适用

不适合的场景

  • ✗ 一次性静态文档（用普通 md 生成即可）
  • ✗ 无版本控制的纯草稿阶段项目
  • ✗ 需要人工精确控制的官方文档
  • ✗ 不接入 Git 的单体文件项目
05
INSTALL · CONFIG · CI

快速上手

Node.js 22+，一行命令安装，两种模式（代码 Wiki / 个人 Wiki）。

// 安装
npm install -g openwiki

# 验证版本
openwiki --version
// 初始化代码 Wiki
# 在仓库根目录
openwiki --init

# 更新现有 Wiki
openwiki --update
// Agent 集成安装
openwiki integrations install codex
openwiki integrations install claude
openwiki integrations install opencode

# 集成后，在 Agent 中直接说：
# “Initialize this repository's OpenWiki”
// GitHub Actions 自动更新
# 复制示例 workflow
cp examples/openwiki-update.yml \
  .github/workflows/openwiki-update.yml

# push 时自动开 PR 更新 Wiki
# 仓库有变更 → 自动触发 → Wiki 同步
