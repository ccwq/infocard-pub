MODEL OVERVIEW

GPT-Image-2 四大核心能力

与 DALL-E / Midjourney 不同，GPT-Image-2 强调「单次 API 调用覆盖全流程」：生成 + 编辑 + 迭代 + 文字渲染一体化。

生成

Text-to-Image

从自然语言 prompt 生成照片级图像、插画、海报、UI mockup。

  • 支持宽高比控制
  • 支持透明背景
  • 支持批量生成
编辑

Image Editing

以文字指令修改已有图像：局部重绘 (inpainting)、扩展 (outpainting)、风格迁移。

  • 参考图 + 文字指令
  • 保持原图结构
  • 无缝衔接生成流程
文字

Text Rendering

在生成图像中精确渲染文字，区别于竞品普遍的文字崩溃问题。

  • 品牌广告语
  • 产品 TVC 分镜
  • 多语言支持
迭代

多轮对话式生成

通过对话迭代式精修图像：上一张图 + 文字反馈 → 下一张图。

  • 角色一致性
  • 风格渐进调整
  • 局部微调

04
PROMPT PATTERNS

生产级 Prompt 写作模式

仓库内 prompt 普遍遵循「场景锚点 + 细节规格 + 风格锚定 + 参数占位符」四段式结构，可直接变量替换后使用。

1

场景锚点 Scene

设定拍摄场景：便利店/体育场/咖啡馆……含具体地点、建筑、背景物件。决定画面的「故事感」。

2

细节规格 Spec

指定分辨率 (8K)、镜头参数 (Sony A7R IV, 35mm f/1.8)、光圈 (shallow DOF)、氛围 (cinematic color grading)。

3

风格锚定 Style

引用真实风格：Wimbledon broadcast / 35mm film / Chanel campaign，使 AI 输出锚定具体美学参照。

Argument 占位符模式：仓库 prompt 中大量使用 {argument name="xxx" default="yyy"} 占位符，可直接替换为品牌/产品名，快速生成品牌专属广告图，无需从头写 prompt。
Negative Prompt

负向提示词

广告创意类 prompt 普遍包含 Negative Prompt，明确排除水印、文字错误、塑料感皮肤、畸形手指等常见失败模式。

  • watermark, random text
  • plastic skin, extra fingers
  • AI-generated look
多图 Storyboard

多图分镜

Prompt 1 生成主图，Prompt 2 生成 9 宫格广告分镜脚本（15秒/9:16竖屏），两步完成完整 TVC。

  • Hero image → 分镜 board
  • 9-panel cinematic grid
  • 中文时间戳 + 场景描述
