02文章最有价值的东西：23 项任务的 prompt 方法论

作者把全部 prompt 原文贴出（这是本文的核心资产），四类任务各自验证一条能力曲线：动漫角色立绘+表情差分（一致性）→ 虚构品牌 NOVA 全套发布物料（文字渲染+RGBA+编辑）→ 服饰画册改色/角色三视图/四格分镜（结构控制）→ 周会看板/双语单词卡/旅行清单（密集文字）。文末四条注意事项全部可用官方文档佐证：

A尺寸写 size 参数，别写提示词——走 ModelScope API 时提示词里写十遍"横版"也无效；本地 diffusers 则对应七档固定分辨率（1:1 2048²、16:9 2752×1536、9:16 1536×2752…），分辨率不是任意的，要按档选。
B透明图要"明说"且到手验 alpha——官方推荐格式原话："This is an RGBA image with transparency. … The image has alpha channel and the background is transparent."（作者实测英文指令更听话；README 的 qwen 龙贴纸示例同款句式）。接触阴影要自己补。
C改图写清"哪里不许动"——文章案例：蓝灯改暖橙时逐项点名"外形/位置/角度/材质/文字/包装盒全部不变"；水墨改绘时锁"脸型/五官/眼型/发型轮廓"。与官方"circles/painted annotations/masks 局部编辑"能力配套。
D文字密集图必加"伪文字"负向约束——"绝对不要生成任务列表、表格、小字、其他数字、装饰性伪文字"。文章里唯一翻车预防提示：看板类图的伪文字是最大坑。

03五分钟上手：三条路（本地/白嫖/API）

  1. 零门槛试玩：ModelScope 模型页点"一键生成"进 WebUI，免费魔粒值够玩；或 HF Space Demo。
  2. 本地 diffusers（官方 Quick Start）：pip install torch>=2.4.0 transformers>=5.17 git+...diffusers accelerate pillow，然后 QwenImage21Pipeline.from_pretrained("Qwen/Qwen-Image-2.1", torch_dtype=torch.bfloat16)，默认 40 步；显存紧张 pipe.enable_model_cpu_offload()。完整管线下载约 33 GB。
  3. 低配党：Unsloth GGUF（去噪器）+ FP8 VAE + Qwen3-VL-8B 编码器（UD-Q4_K_XL 4-bit）跑 stable-diffusion.cpp/ComfyUI；Unsloth 实测 UD-Q4_K_XL 比 Q4_K_M 编码器 LPIPS 0.029/SSIM 0.959，速度还快 2.5s。
  4. Agent/程序调用：ModelScope 设置页建访问令牌写进环境变量，SDK 调用；size 参数传分辨率（见 02-A）。

生态 Day-0 全勤：ComfyUI 原生支持（Comfy-Org 兼容权重+示例工作流）、Diffusers PR #14804、vLLM-Omni（FP8/CUDA Graph/前缀 KV 缓存）、SGLang、LightX2V。ComfyUI 用户零迁移成本。

04架构一分钟：为什么 RGBA 和中文文字是原生强项

A64 通道 RGBA VAE——16× 空间压缩的自编码器带 alpha 通道，透明不是"后期抠图"而是生成管线原生输出；所以"编辑透明层/从照片抠主体"是同一模型的三件事。
BQwen3-VL 8B 当文本编码器——用 Qwen 家自己的视觉语言模型编码提示词与参考图，中文语义理解是"母语级"；这解释了"只写中文名就出角色"（文章的甘露寺蜜璃/波雅·汉库克案例）与海报中文一字不差的文字渲染。块级因果注意力：文本 token 因果、图像块双向。
CSingle-Stream DiT ×32 + Flow Matching——7B 去噪器单流结构省参数，混合粒度注意力+前缀 KV 缓存复用换推理效率；这也是 Unsloth 能把它压到 5GB 级还保持 LPIPS 0.029 的结构基础。

05冷静面与判断

四个折扣点：① 许可是 Qwen Research License——研究评估随意，商用要过法务，"开源"在 OSI 定义下不成立；② 榜单"冠军"是自家口径的"非专属第一"（总榜 16/17），Preliminary 票数尚未沉淀；③ "持平 Nano Banana 2"来自厂商自评 Bench（分差 0.46），等第三方横评；④ 显存宣传要读全——5.15GB 只是去噪器，完整管线 ~33GB 下载、量化后也要 10GB+ 级 VRAM。另：文章标题"22 个案例"与正文"23 项任务"自相矛盾，原文如此。

判断：这是"能力清单几乎全部兑现"的一次发布——RGBA 原生、10 参考图、中文文字渲染、改图锁区域，四件最实用的事官方文档与第三方实测（本文作者 23 项任务）能互相印证。对中文创作者，它是当前中文提示词友好度最高的图像模型之一；对商用团队，先解决许可问题再上车。值得记住的判断句：文章说"生图不是终点——一张图能作为下一张图的输入"，这正是 RGBA+局部编辑+多参考图组合后的工作流意义。
