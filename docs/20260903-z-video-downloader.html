Agent Skill · 视频下载

z-video-downloader

把视频下载变成一句话
工作流：链接 → 识别 → 策略 → 下载 → 报告

z-video-downloader 是 z-skills 中的专用视频下载 Skill，将下载任务交给支持 Skills 的 Agent（如 Claude Code、Codex），由其识别平台、选择策略并处理批量、断点续传、字幕、封面和元数据等任务。

支持的平台（公开资料声称）

YouTube Bilibili Vimeo TikTok 抖音 Instagram Facebook 微信视频号

* 平台支持范围以官方仓库说明为准；实际可用性与平台接口变更相关

支持的输入类型

mp4 webm mov mkv m4v flv ogv m3u8 mpd 直链

核心功能

单视频 / 批量

单次下载单个视频，或通过清单文件批量处理多个视频任务

断点续传

支持中断后恢复下载，避免大文件因网络问题重复下载

字幕 / 封面

下载视频字幕（可选格式）和视频封面图

元数据 / 历史

记录下载元数据并维护下载历史记录

m3u8 / mpd

支持 HLS (m3u8) 和 DASH (mpd) 流媒体格式下载

视频号链接

处理微信视频号分享链接格式

执行流程

1输入链接
2识别平台
3选择策略
4下载报告

用户提供视频链接 → Agent 识别来源平台 → 根据平台特性选择下载策略（如 yt-dlp 调用方式）→ 执行下载并输出报告。

与 z-web-pack 的边界

Skill职责
z-web-pack发现网页素材，仅记录 Source URL
z-video-downloader负责实际视频文件下载与保存
