01 What & Why

OpenDataLoader PDF 是一套面向 RAG/LLM 数据管道和PDF 无障碍改造的完整管线：本地提取 Markdown / JSON（带坐标）/ HTML，Hybrid 模式处理复杂页面，自动把未标注 PDF 变成 Tagged PDF，企业版再补 PDF/UA 导出。

2025-05 创立，2026-07 最新 commit 为"TOC detection"（目录检测），持续活跃。

03 Core Capabilities

📄 结构化提取

Markdown / JSON（带 bounding box）/ HTML，XY-Cut++ 阅读顺序，自动检测标题层级、列表、表格、图片坐标。

🤖 Hybrid AI 模式

复杂页、扫描件、无边框表格、LaTeX 公式、AI 图表描述，路由至 AI 后端，准确率 0.907。

♿ 自动标记 Tagged PDF

无标签 PDF → Tagged PDF（Apache-2.0），veraPDF 验证合规，PDF Association + Dual Lab 合作。

🛡️ AI 安全过滤

内置 Prompt Injection 过滤、页眉/页脚/水印自动过滤，输出纯净数据。

📖 TOC 目录检测

最新功能（v2.4.7 / 2026-05），自动识别 PDF 目录结构，保留文档层级。

☁️ 多语言 SDK

Python（pip）、Node.js（npm）、Java（Maven）三个 SDK，Java 11+ 运行时，LangChain 集成。

04 Quick Start 
# 安装（Python）
pip install -U opendataloader-pdf

# 基础提取
import opendataloader_pdf
opendataloader_pdf.convert(
    input_path=["docs/report.pdf", "docs/paper/"],
    output_dir="output/",
    format="markdown,json"
)

# Hybrid / 复杂文档（表格、公式、扫描件）
pip install -U "opendataloader-pdf[hybrid]"

06 Takeaway

OpenDataLoader PDF 是目前 RAG PDF 预处理的标杆方案：benchmark 第一（0.907）、本地 deterministic 模式快（0.015s/p）、Hybrid 模式对复杂文档准确、首个开源端到端 Tagged PDF 自动标记。支持 Python / Node.js / Java 三大生态，LangChain 直接集成。无障碍合规是全球趋势（EAA / ADA / Section 508），免费层已覆盖核心需求，企业版补齐 PDF/UA。⚠️ 商业产品竞争激烈（nutrient 速度更快），但 OpenDataLoader 在准确率和开源生态上优势明显。
