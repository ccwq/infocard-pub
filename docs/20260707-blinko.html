项目概述Overview

Blinko 是一款面向个人的AI 增强笔记工具，以「捕捉灵感瞬间」为核心设计理念。使用自然语言即可秒搜笔记内容——内置 RAG（检索增强生成）技术，让记忆检索不再依赖精确关键词。项目采用 TypeScript + Next.js + Tauri 构建，支持 macOS、Windows、Android、Linux 全平台，原生 Markdown 支持，完全自托管，数据 100% 归你所有。

核心特性Features
🤖
AI 增强检索
内置 RAG 技术，自然语言秒搜笔记，无需记忆精确关键词。告别传统笔记的「想起来在哪」困境。
🔒
完全自托管
数据完全存储在你自己部署的环境中，隐私 100% 自主掌控，不依赖任何第三方云服务。
📝
原生 Markdown
纯文本存储，完整 Markdown 语法支持，格式简洁，便于长期归档与跨工具迁移。
⚡
轻量高性能
Tauri 原生壳，体积小、启动快、资源占用低。卡笔记计灵感，即开即用。
📱
响应式全平台
支持 macOS、Windows、Android、Linux。桌面端 Tauri 原生，移动端 Web 响应式，一套部署全平台访问。
🐳
Docker 一键部署
一条命令完成全部部署，docker-compose 生产级配置内置，开箱即用。
AI 模型支持AI Providers
支持的主流 LLM
✅ OpenAI — GPT-4o / GPT-4o-mini / GPT-4
✅ Claude — Anthropic Claude 系列（Claude 3.5 Sonnet 等）
✅ Ollama — 本地开源模型（Llama 3 / Mistral / Qwen 等）
✅ MiniMax — 国产大模型（2026年新增）
✅ 硅基流动 / DeepSeek 等 OpenAI 兼容接口
RAG 检索工作流
1. 录入 — 笔记以 Markdown 纯文本存储
2. 向量化 — 自动 embedding 写入向量库
3. 检索 — 自然语言查询语义匹配 Top-K
4. 生成 — LLM 结合上下文生成精准答案

快速部署Deployment
🚀 一行命令快速部署（推荐）
curl -s https://raw.githubusercontent.com/blinko-space/blinko/main/install.sh | bash
# 方法一：Docker 一键启动 $ git clone https://github.com/blinko-space/blinko.git $ cd blinko && docker-compose up -d # 访问 http://localhost:3000 完成初始化 # 方法二：手动环境变量配置 $ cp .env.tmpl .env $ # 编辑 .env，填入 DATABASE_URL / REDIS_URL / LLM API Key $ bun install && bun run dev # PikaPods 托管部署（零维护） $ # 访问 https://www.pikapods.com/pods?run=blinko
环境变量要点
• DATABASE_URL — PostgreSQL 连接串
• REDIS_URL — Redis 连接串（可选/推荐）
• LLM_PROVIDER — openai | claude | ollama | minimax
• LLM_API_KEY — 对应 API 密钥
• NEXT_PUBLIC_BASE_URL — 部署域名
