Core Identity

项目定位与架构

MCP CLI 是 IBM 发布的 Model Context Protocol 命令行客户端，通过集成 CHUK Tool Processor、CHUK-LLM、CHUK-Term 三大底层组件，实现多 LLM 提供商统一接入、工具自动发现与执行、生产级 middleware（重试/熔断/限流）。

Architecture

三层核心架构

CHUK Tool Processor v0.22+ 负责工具执行 middleware；CHUK-LLM v0.17+ 统一 LLM 接口；CHUK-Term 提供跨平台终端 UI。

  • 工具：自动发现 + 名称自动适配
  • LLM：动态模型发现，无开销
  • UI：8 种内置主题
Performance

性能优化（v0.16+）

懒加载实现 52× 导入加速（735ms→14ms），CHUK-LLM 集成 llama.cpp 推理比 Ollama 快 1.53×。

  • O(1) 工具查找（替代 O(n) 扫描）
  • 线程安全客户端缓存（112× 加速）
  • 异步架构全程非阻塞

AI Virtual Memory

AI 虚拟内存

类 OS 分页机制管理对话上下文，支持三种模式：passive / relaxed / strict（模型驱动换页）。

  • --vm-budget：控制 token 预算
  • /memory：可视化 VM 状态
  • 多模态 page_fault（文本+图片）
  • /memory page <id> --download
Execution Plans

执行计划（DAG）

通过 chuk-ai-planner 创建可复用的工具调用图，支持并行批处理、变量传递、断点续跑。

  • /plan create · run · resume
  • --plan-tools：LLM 自主规划
  • Kahn's BFS 并行执行
  • ${var} / ${var.field} 变量解析
  • ASCII DAG 可视化（○/◉/●/✗）
MCP Apps

MCP Apps（SEP-1865）

MCP 服务器可向浏览器提供交互式 HTML UI（图表、表格、地图等），通过沙盒 iframe + WebSocket 桥接。

  • 自动检测 _meta.ui 注解
  • CSP 保护沙盒隔离
  • WebSocket 实时双向通信
  • 自动重连 + 消息队列
04
Security & Ops

安全与运维

生产级安全加固：凭证管理、日志脱敏、执行隔离、MCP Apps 安全防护

✅ Token 凭证安全

OS 原生凭证存储（macOS Keychain / Windows Credential Manager / Linux Secret Service），支持 HashiCorp Vault。Bearer Token / API Key / OAuth 自动脱敏写入日志。

✅ 执行安全

工具调用验证、超时保护、熔断器（Circuit Breaker）、服务器进程隔离、--disable-filesystem 文件访问禁用。

✅ MCP Apps 安全

沙盒 iframe、CSP 域名验证、XSS 防护（HTML 转义）、工具名 MCP Spec 校验、URL Scheme 限制（仅 http/https）。

⚠️ 依赖外部工具链

依赖 Ollama 本地模型（或云端 API Key）；llama.cpp 加速需 Ollama 端侧支持；Groq / Perplexity 需额外配置。

05
Quick Reference

快速上手

安装即用，默认无需配置；生产环境可扩展 Provider / Model / Server

Install

安装

基础安装 + MCP Apps 支持（浏览器 UI）：

  • pip install "mcp-cli[cli]"
  • pip install "mcp-cli[apps]"
  • pip install -e ".[cli,dev]" （开发）
Usage

三种运行模式

  • mcp-cli chat（默认·对话）
  • mcp-cli interactive（命令驱动）
  • mcp-cli server-name command（单次）
  • mcp-cli chat --dashboard（带 UI）
  • mcp-cli chat --vm --vm-mode strict
MCP Servers

连接 MCP Server

自动发现 + 手动指定：

  • mcp-cli chat --server sqlite
  • mcp-cli chat --server filesystem --server-args '{"allowed_dirs":["/tmp"]}'
  • mcp-cli --log-file ~/.mcp-cli/logs/debug.log
