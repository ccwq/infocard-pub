Tutti 是一个开源实时共享工作空间，把多个 AI Agent（Claude Code ↔ Codex ↔ Gemini ↔ OpenClaw）拉进同一个空间，上下文、文件、任务、App 输出全部实时同步，Agent 之间无需手动交接，开箱即用。

01 Core Capabilities · 核心能力
@
Big @ · 上下文全打通
在 Codex 中 @ Claude Code 的历史会话 / 文件 / App 调用 / 任务，无需复制粘贴。引用历史会话完整上下文，直接在对方的工作上继续构建。
⚡
Claude Code ↔ Codex 无缝切换
Claude 写完 API，Codex 直接 @ 接手前端开发，无需重新交代项目背景和架构决策。上下文零丢失，切换成本从十几分钟降到几秒钟。
🔗
Reference with "+" · 引用文件与输出
Agent 聊天框点击 "+" 引用本地文件或 App 生成的输出，任何 Agent 产生的内容都能被其他 Agent 直接使用，无需手动下载上传。
🎯
任务编排与多项目协作
Agent 之间共享工作视图，知道谁在做什么、任务是否冲突、该并行还是顺序执行。不同提供商的 Agent（Claude / Codex / Gemini / OpenClaw）可以协作不打架。
🧩
内置 App 生态 · 可供 Agent 调用
Tutti 自带应用中心：原型设计（UI/UX）、AI Canvas（生图）、文档、AI PPT。支持 Agent 直接调用，输出直接流入下一个 Agent 的工作流。
💰
复用已有订阅 · 不额外付费
Tutti 不替代你的 Agent，用你自己的 Claude Code / Codex / Gemini 订阅。Tutti 只是把它们拉进同一个工作空间，让信息流动起来，无需为每个功能单独付费。
02 Built-in Apps · 内置应用（Agent 可直接调用）
✏️
原型设计
UI/UX 原型设计工具，Codex 可 @ 调用，直接获得设计稿并接入开发，无需 Figma。
🎨
AI Canvas
AI 生图应用，支持图像生成、编辑、合成。你或 Agent 生成视觉素材后直接注入开发流。
📄
文档
结构化文档编辑，支持 Markdown 导出。Codex 起草后直接导出 HTML，产品 / 技术文档一气呵成。
📊
AI PPT
AI 生成 PPT，支持拖拽模块、手动编辑文字。为外部产品介绍、汇报快速生成演示文稿。
03 Use Cases · 典型使用场景
  • 1
    Claude Code 开发中切换到 Codex 接手
    Claude Code 完成 API 层后，Codex @ 引用该会话的完整上下文（接口定义、架构决策、文件结构），直接开始前端开发，无需你手工复述。
  • 2
    多 Agent 并行协作 · 任务自动分配
    你描述一个目标，Tutti 拆解成子任务，分配给最合适的 Agent（设计 / 文档 / 代码）。各 Agent 看到彼此的进度和输出，冲突自动避免或化解。
  • 3
    上下文无缝衔接 · 全流程不断档
    PRD 文档 → 设计稿 → 前端代码 → PPT 演示，每一步的输出都被下一个 Agent 直接引用，整条链路没有复制粘贴，没有上下文断层。
  • 4
    Tutti · VM：跨设备多人协作
    多层虚拟化技术将本地 Agent 状态实时同步到云端共享空间，多人跨设备协作，localhost 网站直接预览，Agent 任务可跨人指派。
04 Traditional vs Tutti · 传统方式 vs Tutti
维度 传统方式 Tutti
上下文切换 Agent A → Agent B 需要手工复制粘贴上下文，耗时 10–20 分钟，容易遗漏关键信息 @ 一下引用历史会话完整上下文，切换成本 ≈ 0
文件/输出共享 手动下载、上传、截图、粘贴；Agent 之间信息孤岛严重 点击 "+" 直接引用文件或 App 输出，所有 Agent 实时可见
设计 → 开发链路 设计稿需要 Figma 导出 → 上传 → 粘贴给开发 Agent，至少 3 步手动操作 Codex @ 原型设计 App → 生成 UI → 直接进入前端开发，0 步手动操作
多订阅费用 每个工具单独订阅：Claude Code + Codex + Figma + PPT 工具 + 生图工具 复用已有订阅，Tutti 本身免费，Agent 工具自选，0 额外月费
协作模式 你是 Agent 之间的"信使"：复制上下文、转述需求、协调冲突 你描述目标，Tutti 分配任务，Agent 自主协作，你是导演而非信使
任务可见性 每个 Agent 只知道自己的上下文，不知道谁在做什么 实时共享工作视图，Agent 知道彼此进度，冲突自动发现并解决
05 Quick Start · 快速上手
// 安装 Tutti（本地版）
# 克隆仓库
git clone https://github.com/tutti-os/tutti.git
cd tutti

# 安装依赖并启动
npm install
npm start

# Tutti · VM 云协作版（加入等待列表）
→ https://tutti.sh  # 注册获取邀请码
// Codex 中引用 Claude Code 的历史会话
# 在 Codex CLI 中：
@claude-code:session-2025-12-01 // 引用 Claude Code 某次会话的完整上下文
@claude-code:file-api.py   // 引用 Claude Code 产生的具体文件
@claude-code:task-design  // 引用任务状态，直接继续执行

# 或者让 Codex 直接指挥 Claude Code 做某事
@claude-code(app) "继续完成用户认证模块的单元测试"

# 引用 App 输出
+prototype-design/latest.png  // 引用原型设计 App 的最新输出
💡 工作流示例：PRD 文档 → @ 文档 App 起草 → @ 原型设计 App 生成 UI 稿 → @ Codex 接前端开发 → @ AI PPT 生成演示文稿。全程无需手工复制粘贴，所有上下文和输出在各 Agent 间自动流动。
