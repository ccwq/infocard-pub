ARCHITECTURE

双组件架构

MCP Server
uv run friday — FastMCP 服务端，SSE 传输协议，暴露工具集给 LLM 实时调用。
Voice Agent
uv run friday_voice — LiveKit Agents 语音管线，连接 MCP Server，通过自然语音触发工具。
工具注册
工具位于 friday/tools/，分为 web.py / system.py / utils.py，MCP 协议统一暴露。
PERSONA

贾维斯人格设定

系统提示词
server.py 声明："You are Friday, a Tony Stark-style AI assistant"
FRIDAY 人格
agent_friday.py 完整构建：calm / composed / precise / witty
语音输出
OpenAI TTS nova 女声，Sarvam STT 语音输入，LiveKit 实时管线。
PROJECT STRUCTURE

项目文件结构

入口文件
server.py（MCP Server）+ agent_friday.py（Voice Agent）+ main.py（CLI）
配置
pyproject.toml（uv 依赖）+ .env.example（环境变量模板）
工具模块
friday/tools/ — web.py / system.py / utils.py

friday/resources/（MCP Resources）
