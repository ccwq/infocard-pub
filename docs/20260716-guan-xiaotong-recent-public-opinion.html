03
EVIDENCE · A / B / C / U

证据分级

等级不是“谁更会传播”，而是来源是否能直接支持某一项可复核的陈述。

A / 原始发布

A 类：官方原帖

当事人或工作室官方账号原帖。本轮未取得可长期访问、可直接核验的原帖链接，因此不把摘要或截图升格为 A 类。

B / 媒体转引

B 类：本次已核实

主线程已直接读取的腾讯新闻页面对工作室声明的转引；仅用于归因声明存在与其内容。

C / 不采用

C 类：传播噪音

营销号、匿名爆料、截图、粉丝解读及私生活推断；不纳入事实，也不复述具体内容。

U / 未证实

U 类：不可下结论

任何私人关系事实，以及法律追责的后续程序与结果；当前材料不足以证实。

04
EDITORIAL GUARDRAIL

可写 / 不可写对照

把“公开回应”与“未经核实的私人生活叙事”隔离，避免因转述而二次扩散。

05
MECHANISM · RUMOR → RESPONSE → ASSOCIATION

舆情机制分析

这里分析的是信息如何被再关联，不评判或补写传言的具体内容。

1

传言进入传播链

私人生活叙事因未经核验仍具传播性，但其存在不等于内容为真，亦不应成为复述对象。

2

辟谣提供可核验锚点

公开声明使“当事方如何回应、拟采取什么措施”成为可归因信息；它不是关系状态的反向证明。

3

二次关联持续发生

后续讨论可能将新动态与旧传言连接。核查应只记录关联存在，不把关联解读为新的私人关系证据。
