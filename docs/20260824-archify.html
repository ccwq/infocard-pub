Archify

把代码库或系统描述，交给 Agent 生成可交互、可验证、可分享的技术架构图。它不只画静态框，还能表达 architecture、workflow、sequence、data flow 与 lifecycle 五类关系，并输出自包含 HTML 及 PNG / SVG / WebM 等格式。

这条推文分享了什么

Indie Fox 分享了 Archify：一个把项目架构变成可交互 HTML 的 Agent Skill。它可以分析代码、识别核心节点与节点关系；点击节点后查看详情，并用有限动画演示调用过程。

重点不是“再画一张图”，而是把架构阅读变成可搜索、可追踪、可复核的交互式视图。

它解决的痛点

  • 静态架构图难以探索节点和调用路径。
  • 大型代码库的组件关系不适合只靠文字阅读。
  • 架构变更可用 Before / Delta / After 做事实对照。
  • 验证器输出机器可读诊断，失败时定位到具体修复对象。

五种视图，按问题选模型

01

Architecture

组件、服务、存储、边界与主路径。

02

Workflow

审批、CI/CD、工具调用、分支和异常。

03

Sequence

API 调用、返回、缓存回退、异步轨迹。

04

Data Flow

数据源、转换、存储、消费者和治理边界。

05

Lifecycle

状态、重试、等待、取消和终态。

安装与初步使用

npx skills add tt-a1i/archify -g

# 然后向 Agent 提问
Use archify to map this repository's runtime architecture.

也可临时试用：npx skills use tt-a1i/archify@archify --agent codex。

配置与交付

  • 输入：自然语言系统描述，或带 revision 的代码库证据。
  • 生成：typed JSON IR。
  • 校验：schema、布局与确定性检查。
  • 交付：自包含 HTML；可导出 PNG、SVG、WebM、1200×630 分享卡。
  • 交互：节点搜索、路径追踪、角色对比、有限故事动画、明暗主题。
