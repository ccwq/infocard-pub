01 · 它是什么
Core Value
一句话

自托管的书签 + 笔记 + PDF + 图片收藏库，内置 AI 自动标签、摘要、OCR，支持 LLM Agent（OpenClaw/Hermes）通过 CLI 调用

核心价值
把"随手收藏、稍后阅读、随手归类"的全链路需求压缩到一个自托管优先的个人知识收件箱。阿拉伯语词源"كراكيب"意为零碎杂物。
适合谁
需要隐私优先、Agent 可调用的书签管理；厌倦了 Pocket/Raindrop 等闭源服务的技术用户、内容创作者与知识工作者。

07 · 快速安装
Quick Install
# 1. 创建目录 mkdir -p karakeep && cd karakeep # 2. 一键启动（v0.32.0） docker run \ -p 3000:3000 \ -v $(pwd)/data:/data \ ghcr.io/karakeep-app/karakeep:release # 首次访问： http://localhost:3000 # 演示账号： demo@karakeep.app / demodemo
