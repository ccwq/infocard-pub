# Agent Talk：让多个编码 Agent 通过插件协同通信

**⭐ Stars:** 108 | **许可证:** MIT | **版本:** v0.1.2 (2026-07-17)

**GitHub:** https://github.com/xhluca/agent-talk

## 概述
Agent-to-Agent 消息通信层：init / id / add / send / receive 生命周期

## 核心特性
- 多平台支持
- init/id/add/send/receive 技能
- 自动或 Pull 接收
- retalk CLI
- 安全消息路由
- 多 Agent 协同

## 快速上手
```
curl -fsSL https://antigravity.google/cli/install.sh | bash   # installs the `agy` binary
```
