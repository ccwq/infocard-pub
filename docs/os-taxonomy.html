1,590 个知识点 + 3,221 条依赖 = 一张可导航的学习地图

年龄

4–11

岁（美国 K-5 / 英国 Key Stage 1–2）

每个知识点都有 ageRangeStart 和 ageRangeEnd 字段。

知识点字段

topic 节点结构

  • id：稳定标识（mt_ 前缀）
  • type：CONCEPTUAL / PROCEDURAL / REPRESENTATIONAL / LANGUAGE / META
  • subject / domain：学科 + 领域
  • name / description：名称 + 通俗描述
  • ageRangeStart / ageRangeEnd：适用年龄
  • evidence：掌握证据数组
  • assessmentPrompt：家长检查问题（含 {{name}} 占位符）
  • standards：关联课程标准数组
依赖边字段

dependency 边结构

  • topicId：依赖方（dependee）
  • prerequisiteId：被依赖方（基础知识点）
  • strength："hard"（必须）或 "soft"（建议）
  • reason：一行文字说明依赖理由

反向边即为「解锁了哪些知识点」。

数据文件

JSON 数据文件

  • topics.json — 1.67 MB，所有知识点
  • dependencies.json — 697 KB，所有依赖边
  • curriculum-standards.json — 1.62 MB，源课程标准
  • clusters.json — 61 KB，183 个家长摘要
  • manifest.json — 校验信息 + SHA-256

主题标注

知识点类型系统

每个知识点有一个 type 字段，区分五类知识：

  • CONCEPTUAL — 概念理解（「光合作用的原理」）
  • PROCEDURAL — 程序性知识（「长除法步骤」）
  • REPRESENTATIONAL — 表征理解（「用数轴理解负数」）
  • LANGUAGE — 语言能力（「拼写规则」）
  • META — 元认知（「如何评估自己的理解」）

同时每个知识点有 centrality（0–1 分数），衡量该知识点在整体图谱中的枢纽程度。

⚠ 数据边界（刻意排除项）

本数据集不包含：语义嵌入（衍生数据，可重新计算）、儿童/用户个人信息（从未发布）、教学研究数据。

04
PREREQUISITE GRAPH · 先修依赖图

有向无环图（DAG）+ 硬依赖 / 软依赖区分

每条边都带一行理由说明，让依赖关系可解释、可验证，而不是黑盒。

必须先学

hard 依赖

若无此基础，后续知识点无法理解。例如：「分数乘法」hard 依赖「分数基本概念」。

{
  "topicId": "mt__00ZSLnB7p",
  "prerequisiteId": "mt_VBl1T1sFCM",
  "strength": "hard",
  "reason": "Must understand vibrations
  make sound before finding
  volume patterns"
}
建议先学

soft 依赖

有助于理解，但非绝对前提。例如：「面积计算」soft 依赖「乘法口诀」（已有基础即可）。

{
  "topicId": "mt_N8CpN1EJrP",
  "prerequisiteId": "mt_OtherTopic",
  "strength": "soft",
  "reason": "Knowing basic multiplication
  helps but is not strictly required
  for area concept"
}
家长摘要

183 个 Domain Clusters

每个（学科 + 领域 + 年龄段）组合都有家长友好的段落摘要，不需要教育学背景也能理解孩子应该学什么、为什么。

如「Science > Earth Science > Age 7–9」的领域摘要包含：核心概念、常见误解、家长对话提示。

05
USAGE · 使用方式

纯 JSON 数据，无需运行时依赖，加载即用

不绑定任何框架，直接 import JSON 文件即可构建学习路径分析工具、个性化推荐引擎或学情诊断应用。

import topics from './data/topics.json' with { type: 'json' };
import deps from './data/dependencies.json' with { type: 'json' };

// 建立 ID 索引
const byId = new Map(topics.topics.map(t => [t.id, t]));

// 查询某知识点的先修知识点名称
const topicId = 'mt_N8CpN1EJrP';  // "Building sentences"
const prereqs = deps.dependencies
  .filter(d => d.topicId === topicId)
  .map(d => byId.get(d.prerequisiteId)?.name);

// → ["Phonics basics", "Letter recognition", ...]

// 验证数据完整性
node scripts/validate.mjs

构建学习路径

给定目标知识点，从 DAG 反向追溯所有硬依赖，生成「从零到掌握」的学习路线图。

学情诊断

孩子已知哪些知识点？扫描 DAG 找到「卡住的地方」——某个未知知识点的前置知识缺口。

自适应推荐

基于 centrality 和 ageRange 字段，向用户推荐「下一步最值得学」的知识点，过滤已掌握的。

07
INTERACTIVE 3D · 交互图谱

withmarble.com/curriculum：点击任意知识点，追溯完整先修链

三维知识图谱：每个圆点是知识点（颜色 = 学科），高度 = 年龄，点击可展开完整依赖路径。

1

拖拽旋转

3D 图谱支持全方向旋转，查看不同学科簇的空间关系和高度分布。

2

滚轮缩放

缩放至只看某一年龄段或某一学科，识别密集区域和孤立节点。

3

点击节点

显示知识点详情（描述、掌握证据、年龄）和所有先修依赖（可继续追溯）。

「孩子卡在哪」问题的回答：给定某个知识点，在 DAG 中查找该节点的所有前置硬依赖，逐个检查孩子是否已掌握。第一个未掌握的节点即为「卡点」。
家长使用建议：用 3D 图谱和孩子一起探索——「你想学这个？那要先学会这个哦！」把抽象的依赖关系变成可触摸的学习目标。
