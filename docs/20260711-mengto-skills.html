06 设计哲学 Design Philosophy
01
"If it's good once, it should be reusable."
Prompts are Assets
存储prompts为文件 · 版本化管理 · 建立库 + stylecards
02
"The fastest way to consistent output"
Specs Beat Vibes
清晰约束 · 清晰层级 · "只改1-2处" 迭代模式
03
"Screenshots and examples carry more"
References Beat Paragraphs
字体/间距/颜色 · 布局节奏 · 图标风格 — 示例优于描述
04
"Good skills tell the agent exactly when to use them"
Skills are Operating Procedures
何时用（trigger）· 先做什么（steps）· 用什么默认值 · 避免什么错误
