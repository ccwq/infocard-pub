AUDIT MODES · 三种审计模式

⚡ 增强扫描 Scan → Triage

快速分析工具扫描结果并过滤误报，适合日常监控与初步筛查。

🧠 智能审计 Finding

深度挖掘高价值漏洞，适用于 CVE 挖掘和 0Day 研究。

🔍 综合审计 Scan → Triage + Finding

融合工具扫描与源码分析，开展全量审计，覆盖范围最广。

INTERACTION · 交互式审计

💬 审计完可追问

将完整审计过程作为会话上下文，用户可围绕审计结果继续追问：补充证据、解释攻击链、完善复现步骤或扩展漏洞分析。

📊 可视化审计追踪

集中展示活动日志、Agent Tree、工具调用、阶段进度、初步报告和审计会话，方便复盘每次审计的执行路径。

🗂️ 智能漏洞管理

Agent 自动提交漏洞，去重后结构化入库，漏洞管理模块统一维护，支持导出报告。

🔌 Skills 扩展

支持为不同 Agent 配置专属 Skills，灵活扩展各 Agent 能力边界。

DEPLOY · 一键部署

Docker 一行命令启动

# Linux / macOS / Git Bash（一行命令）
curl -fsSL https://raw.githubusercontent.com/larlarua/AutoCVE/v1.0.4/docker-compose.prod.yml \
  | docker compose -f - up -d

# 源码部署
git clone https://github.com/larlarua/AutoCVE.git && cd AutoCVE && docker compose up -d --build
