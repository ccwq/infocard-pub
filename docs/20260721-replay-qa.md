# Replay QA · 自主应用测试

## 概述

Replay QA 是构建在 Replay 时间穿越调试引擎之上的**自主应用测试工具**。只需指向任意 Web 应用 URL，它会自动完成：

1. 自主导航探索 Web 应用
2. 发现用户旅程（User Journeys）
3. 生成 Playwright 测试代码
4. 用 Replay Browser 执行并捕获完整运行时录制
5. 发现 Bug 后时间穿越定位根因，给出详细分析 + 修复建议

**无需现有测试套件，无需配置文件，无需手动复现步骤。**

> **来源**：[docs.replay.io/basics/replay-qa/overview](https://docs.replay.io/basics/replay-qa/overview) ✓ 已验证

---

## 核心功能

### 自主探索 + Playwright 测试生成
- AI 自动探索应用，无需预设路径
- 发现用户关键旅程，生成可执行的 Playwright 测试
- 测试即写即用，导入现有工作流

### 完整运行时录制（Replay Browser）
- 不同于视频或快照，捕获**完整浏览器运行时**
- 每个 DOM 变更、每个网络请求、每行 JavaScript 执行均记录
- 录制可在任意时刻暂停、回放、穿越

### 时间穿越调试（Time-Travel Debugging）
- Bug 发生时，从症状反向穿越录制，追溯至真正根因
- 不停留在表面报错——直达 Bug 源头

### 根因报告 + 修复建议
每份报告包含：
- 通俗语言根因说明（plain-language explanation）
- 症状 → 根因执行链追踪（trace）
- 含文件名和行号的代码修复方案

## 三种使用模式

### 1. 独立运行（Stand-alone）
只需提供一个 URL，全程自动完成。

| 特性 | 说明 |
|------|------|
| 配置 | 零配置，无需测试套件 |
| 探索 | AI 自主导航，发现用户旅程 |
| 测试 | 生成 Playwright 测试 |
| 调试 | 时间穿越 + 根因报告 |
| 修复 | 给出详细修复建议 |

> **官方文档**：`Give Replay QA a URL. It takes it from there.`

### 2. 连接 GitHub 仓库
安装 GitHub App，授权仓库后，代码每次变更自动触发测试，**无需 CI 配置或 Workflow 文件**。

| 触发条件 | 行为 |
|----------|------|
| 代码合并（main） | 对最新版本自动探索 + 运行测试，捕获回归 |
| PR 创建 | 每个 PR 触发独立测试运行，结果回写 PR 评论 |

- 完整 Replay 录制
- 时间穿越根因分析
- 修复建议（含文件和行号）

### 3. 交给 Coding Agent（REST API）
通过 `loop-qa.replay.io` REST API，Coding Agent 可驱动完整 QA 循环：

```
1. 通过 API 创建 QA 项目（传入 target_url）
2. 轮询项目状态（不自行触发探索/测试）
3. 对每个 Open Bug：读取根因报告 → 直接在代码库应用修复 → 通过 API 标记为 Fixed
4. 循环直到无 Open Bug
```

- OpenAPI 规范：`/api/v1/openapi.json`
- 认证：`Authorization: Bearer <token>`
- 本地应用：启用反向代理（reverse proxy）

## React + Source Maps 深度支持

| 特性 | 说明 |
|------|------|
| 组件树检查 | 深入 React 组件层级 |
| 渲染追踪 | render tracing，定位渲染问题 |
| Effect 分析 | 追踪 useEffect 执行链 |
| Source Maps | 失败回溯至原始源代码（而非编译产物），修复建议含正确文件名和行号 |

> **提示**：React 深度分析仅适用于 React 应用；非 React 应用无法享受此增强。

## CI 集成模式（Replay CI Agent）

适合已有 Playwright 测试套件的团队：

1. 安装 GitHub Bot（CI Agent）
2. 配置测试套件录制（`@playwright/test` + Replay）
3. CI 每次运行后自动产生 Replay 录制
4. 测试失败时，CI Agent 时间穿越录像，在 PR 下发布：
   - 通俗语言根因说明
   - 执行链追踪（symptom → cause）
   - 含文件和行号的代码修复建议

**无需复现步骤，无需日志考古——证据已在录制中。**

## ⚠ 风险 / 边界提示

| 风险 | 说明 |
|------|------|
| 产品线区分 | Replay Test Suites 已于 **2024 年 8 月停止服务**，与当前 Replay QA 为不同产品，请勿混淆 |
| 本地访问 | 若应用仅在 localhost，需启用**反向代理**（reverse proxy）才可连接 Replay QA |
| React 依赖 | React 深度分析要求应用本身使用 React 且开启 Source Maps，非 React 应用无此功能 |
| 仓库权限 | GitHub App 集成需仓库管理员授权，私有仓库需额外配置访问权限 |
| API 安全 | loop-qa.replay.io API 需 Bearer Token 认证，密钥须安全保管 |
