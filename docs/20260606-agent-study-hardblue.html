04
怎么学最划算

三条路线：新手、面试、做产品

这份仓库不是要求你按目录逐章背完，而是让你按目标选路线。

1

新手入门：先跑起来

先看 Ch0 环境搭建，再看 Ch1-3 的 Agent 基础。目标不是懂全部，而是先建立 ReAct / Function Calling 的直觉。

2

面试突击：抓高频考点

重点看 Ch7、Ch8、Ch10、Ch11、Ch18、Ch19、Ch26、Ch31。它们最容易对应“系统设计 + 协议 + 评测 + 安全”问法。

3

做产品：补工程化短板

把 Ch13/14/24/26/28/30 作为组合拳：服务化、持久化、可观测性、路由、缓存、可靠性，才像真实系统。

使用技巧

把课程当成“查询式学习资料”：先按目标找章节，再把章节代码跑一遍，最后回到面试题或对照图复盘。

什么时候不该用

如果你只想快速拼一个 demo，或者只是找零散 API 用法，这套课程会显得过重；它适合系统学习，不适合只拿答案。
