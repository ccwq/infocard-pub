Pi 扩展 · 模型路由

Pi-Bifrost

Pi 的智能模型路由扩展：自动识别任务复杂度，把任务交给最合适的模型——简单任务用便宜快速模型，调试与架构等复杂任务自动切换到 Frontier 模型。

自动路由 Circuit Breaker Regex + LLM 分类 预览命令
适用场景

同时使用多个模型或 API 的开发者；想让简单任务降本、复杂任务保持质量的用户。

01
路由规则

智能模型选择

Pi-Bifrost 支持多维度路由规则，自动识别任务类型并匹配合适模型。

按复杂度

简单任务自动降级

简单补全、润色、翻译等任务自动路由至性价比最高的模型，降低 API 调用成本。

  • 聊天补全
  • 文本润色
  • 简单翻译
按场景

调试 / 架构 → Frontier

涉及调试、架构设计、代码审查等复杂任务，自动切换至 Frontier 级模型，确保输出质量。

  • 代码调试
  • 架构设计
  • 代码审查
按配置

价格 · 速度 · 上下文

支持按 API 价格、响应速度、上下文长度等维度自定义路由规则，适应不同业务需求。

  • API 价格权重
  • 响应速度优先
  • 最大上下文长度
02
分类与断路

自动分类 + Circuit Breaker

两层保障：Regex + LLM 精准分类，模型连续失败自动触发断路。

Regex + LLM

智能任务分类

结合正则表达式规则和 LLM 语义理解，自动识别任务类型，无需手动配置每条 Prompt 的路由目标。

  • Regex 规则匹配
  • LLM 语义分类
  • 可自定义分类规则
断路保护

Circuit Breaker 机制

当某个模型连续失败达到阈值，自动将其从路由池中剔除，绕过故障模型，避免重复执行失败命令或修改文件。

  • 连续失败自动绕开
  • 避免重复执行
  • 故障恢复后自动恢复
03
预览命令

/bifrost preview

在执行前预览任意 Prompt 的路由目标，提前确认任务分配是否符合预期。

/bifrost preview <your-prompt>

预览效果示例：系统会输出该 Prompt 预计路由到的模型及其理由，方便在执行前调整路由规则。
