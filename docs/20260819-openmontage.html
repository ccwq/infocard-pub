OpenMontage 是 GitHub 上 4.8 万星的开源 AI 视频剪辑项目，可以直接跟 Claude Code、Cursor 这些 AI 编程工具说话，它会自己写脚本、找素材、配音、加字幕、合成，全自动一条龙。几个真实案例：60 秒皮克斯风格动画短片有剧情有运镜有 BGM 有动态字幕，总成本 1.23 美元；电影预告片氛围感拉满；耳机接口产品宣传片不到 1 美元。底层是 12 条流水线、100+ 工具、700+ Agent 技能文件撑着的。
工作流程

Claude Code 说句话 → 全自动一条龙

Step 1 · 写需求
自然语言描述视频主题、受众、时长、风格偏好
给参考视频也可以，Agent 自动分析
Step 2 · Agent 自主执行
调研 → 写脚本 → 分镜 → 生成素材 → 配音 → 剪辑 → 字幕 → 合成
每步有多点 self-review，质量门控自动拦截
Step 3 · 人类审批
proposal、cost estimates、各阶段出口审批
不是完全无人值守，是受控的生产系统

安装与使用
快速开始
# 克隆并安装
git clone https://github.com/calesthio/OpenMontage.git
cd OpenMontage
./install.sh

# 配置 AI 编程助手（推荐 Claude Code）
# 编辑 .env 填入 API Key

# 让 AI 自动拍一条视频
openmontage run "做一条60秒科普视频，主题是神经网络怎么学习，配音用女声"

# 导出最终成片
openmontage export --format mp4 --quality high
