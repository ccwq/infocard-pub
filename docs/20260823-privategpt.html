PrivateGPT

把本地模型变成可构建、可集成的 AI 应用：一个遵循 Claude API 模型的开源 API 层，而不是另一个模型运行器。

★ 57K+ starsApache-2.0API-firstOn-premise
01 · POSITIONING

先分清：它连接模型，不运行模型

你的应用 / Agent / UI业务体验与工作流
→
PrivateGPT API消息、工具、RAG、数据访问
→
OpenAI-compatible serverOllama · llama.cpp · vLLM 等
关键边界：PrivateGPT 不负责推理；通过 OPENAI_API_BASE 连接已运行的推理服务。只要实现 /v1/chat/completions 与 /v1/models，就能接入。
02 · API SURFACE

把 Claude API 习惯带到私有部署

▣ Messages

标准 messages API，覆盖 streaming、async/batch、token counting 与模型选择。

⌁ Knowledge

文件与 artifact 摄取、PDF/文档处理、embeddings、带 citations 的 retrieval 与 agentic RAG。

⚙ Tools

内置 web search、web fetch、code execution；支持 custom tools 与 MCP connectors。

▤ Data

数据库查询、SQL、CSV 与表格分析作为应用能力直接暴露，而非散落在脚本里。

◈ Agents

MCP、remote MCP、skills 与编排能力让本地模型成为可组合的应用后端。

◉ Workbench

内置 /ui 用于测试消息、上传文档、打开工具与 API Debugger；真正的产品是 API。

04 · DECISION GUIDE

适合谁？不适合什么期待？

适合：开发者与平台团队

  • 已有本地/私有推理服务
  • 想统一 AI 应用 API
  • 需要 RAG、工具、MCP、数据访问

不等于：一键模型平台

  • 不会替你下载或托管模型
  • 不替代 vLLM/Ollama
  • 硬件、并发与运维需另行解决

一句话判断

如果你缺的是“模型”，先选 inference server；如果你缺的是“把模型变成产品的 API 原语”，PrivateGPT 才是对应层。
