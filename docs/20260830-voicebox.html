一句话概述

做视频配旁白、录音转文字、AI agent 调用语音能力——Voicebox 把这一整套全部搬回本地，Tauri + Rust 实现，一个字都不往服务器传。

核心能力
语音合成（TTS）Qwen3-TTS · Chatterbox · Kokoro
语音转写（STT）Whisper 本地推理
音色克隆短音频样本训练自定义音色
全局听写任何输入框直接说话变文字
MCP ServerAI Agent 可调用播放/转写能力
平台支持macOS · Windows · Linux（需自编译）

快速上手
# macOS / Windows 下载安装 → brew install --cask voicebox # 或从 GitHub Releases 下载安装包 → open "https://github.com/jamiepine/voicebox/releases"
# Linux（需自编译） → git clone https://github.com/jamiepine/voicebox → cargo build --release → ./target/release/voicebox
⚠ Linux 目前没有预编译安装包，需从源码构建（Tauri + Rust 环境）。

隐私优先：所有处理均在本地完成，音频数据不离开你的设备。适合对数据安全有要求的场景（医疗、律师、企业内部）。
