FAQ

常见问题

Q: Codebase-Memory-MCP 和 LSP 是什么关系？
完全独立。自实现语法解析，不依赖 LSP 协议栈，避免了 LSP 的复杂性和版本兼容问题。
Q: ZSTD 压缩快照占用多少空间？
通常比原始 JSON 图谱小 8-13 倍。一个 100MB 的图谱压缩后约 8-12MB，可直接提交 Git。
Q: 新成员加入团队后如何使用？
直接 git clone 仓库，加载已构建好的 graphdb.zst 快照，无需重新索引，即时可用。
Q: 快照更新的频率是多少？
支持增量更新——代码变更后可只更新差异部分，无需全量重建，平衡了新鲜度和计算成本。
Q: 支持哪些 IDE 和 Agent 工具？
通过 MCP 协议接入，任何支持 MCP 的工具（如 Cursor、VS Code MCP 扩展、Claude Code 等）均可使用。
Q: 和 Codegraph 的核心差异是什么？
Codebase-Memory-MCP 是"预计算 + 快照共享"模式，Codegraph 是"实时监听 + 本地同步"模式。前者适合追求极致性能和低成本，后者适合需要复杂框架路由和实时性的场景。
