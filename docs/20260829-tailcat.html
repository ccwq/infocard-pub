网络工具 · 用户态 · BSD-3-Clause

Tailcat：像 netcat 一样，走 Tailscale 数据平面

不需要 Tailscale 账号、Root 权限或开放入站端口；用一次性连接 token 把两台机器接起来。

先记住边界：Tailcat 不使用 Tailscale control plane；连接元数据由双方通过 token 带外交换。

01 / 定位：临时、加密、用户态组网

它解决什么问题？

一端启动 listener，获得短连接 token；另一端把 token 交给 client。两端建立 WireGuard 端到端加密隧道，再把 TCP 端口、SSH 或 SOCKS5 流量送进去。

无需账号无需 root/admin不改路由/DNS

它不是什么？

不是完整的 Tailscale 组网控制面，也不承诺稳定的 CLI/API 或公共中继 SLA。它更像“把 netcat 搬到加密 P2P 数据平面上”。

02 / 工作原理：DERP 引导，UDP 直连优先

①Server
生成密钥
→
②打印
connection token
→
③Client
解析并握手
连接路径：双方先通过 DERP rendezvous，WireGuard 握手建立后，magicsock 用 STUN/UDP hole-punching 尝试升级到直连；直连失败时继续走 DERP fallback。 ping 会显示 via DERP 或直连地址。

03 / 安装与首次使用

安装

$ go install github.com/tailscale/tailcat/cmd/tailcat@latest
# 或直接运行 / 安装 Nix flake
$ nix run github:tailscale/tailcat
$ nix profile install github:tailscale/tailcat

最小首次使用

# 机器 A：监听并复制输出的 token
$ tailcat
# Server listening with new address: tc...
# 机器 B：把 token 作为参数连接
$ echo hello | tailcat tc...

04 / 核心命令：从端口到代理

端口转发 / SSH

# 暴露服务端 localhost:8080、8443
$ tailcat --serve=8080,8443
$ tailcat tc... 8080
# 无认证 SSH（或 --serve=22 代理系统 SSH）
$ tailcat --serve=no-auth-ssh
$ tailcat ssh tc... ls -la

SOCKS5 / ping / 直连

# 通过隧道访问服务
$ tailcat socks tc... curl http://server.tailcat:8081/
# 检查延迟与路径；10 秒内等到直连
$ tailcat ping --until-direct tc...
# 也可作为 exit node
$ tailcat --serve=exit-node
Token 提醒：token 区分大小写；它也可作为 SOCKS5 URL hostname（浏览器会把 hostname 小写化，因此不适合浏览器直接使用）。

05 / 安全边界：方便不等于默认安全

✓ 默认值得保留的保护

  • 默认 server 使用内存中的临时密钥；进程退出后 token 永久失效。
  • 流量端到端 WireGuard 加密；不需要 kernel TUN/TAP、系统路由或 DNS 改动。
  • 可用 --allow 限制 client 公钥；可自建 DERP，避免依赖公共中继。

✗ 必须主动防范的风险

  • 不要把连接 token、私钥或保存的 key 文件当作公开信息；拿到 token 的人可能连接服务。
  • 保存 key 会让地址跨重启继续有效；共享过该地址的人以后仍可能连接，除非加 allow 限制。
  • 不要用它误暴露公网服务；--serve=exit-node、端口转发和 no-auth SSH 尤其要限定使用场景。
  • 默认公共 DERP 是限速、无 uptime/吞吐 SLA 的 best-effort 服务。

06 / 适合与不适合

✓ 适合

临时跨 NAT 传输 stdin/stdout；临时访问内网 TCP 服务；远程排障与一次性 SSH；不想安装系统级 VPN 或申请账号的开发测试场景；需要自建 DERP 的小型受控网络。

✗ 不适合

需要稳定 API/线协议兼容性的生产平台；需要正式 SLA、审计和集中身份治理的企业网络；把公共 token 当作长期服务入口；需要浏览器 WebRTC 直连的场景（当前浏览器 demo 仅经 DERP relay）。
