一句话结论
FreeVideo 是开源的 MiniMax H3 本地推理引擎，官方声明最低 8 GB 显存加 16 GB 内存就能跑，速度靠自适应执行规划器换——8 GB 卡跑 10 秒 1344×768 的 Light 档要等约 10–22 分钟，这是官方社区表的数据，不是宣传口径。装之前有三件事必须先知道：它推理用的不是 H3 原版权重而是 OpenVDN 的 8 步派生权重（约 22.9 GB）；模型权重许可排除欧盟、英国、韩国、美国；开了 freevideo server --listen 0.0.0.0 的局域网访问默认不加密、任何拿到链接的人都能用。
核心要点

门槛是真的，速度是租的

8GB/16GB 是官方 README 中英首段原文。机制在执行规划器文档里：50 个 transformer block 按实时显存/内存预算决定常驻显存、pinned 内存（上限 22GB）还是每步从盘重读；最低工作集放不下会在加载前直接拒绝请求。

权重是派生的

推理下载的是 OpenVDN/vdn-minimax-h3-edge 的 FP8 包（约 22.9 GB），从 MiniMax H3 已发布权重出发加 frame-wise 线性注意力分支，生成用 8 步。官方 About 与致谢段原文明确，不是文章推断。

参考素材别按宣传预期

官方中文使用说明原文：参考图生成视频“目前仍是实验能力。能够运行不等于每次都能保持人物外观一致”。“参考视频动作跟着走”是文章转述，官方只承诺取 ≤15 秒等长片段、用时约两倍。

两条协议线

代码 Apache 2.0 随便用；模型权重走 MiniMax H3 Community License——全球授权但排除欧盟、英国、韩国、美国，另有再分发要求与用途限制（AUP）。文章只说“商用先读协议”，没点名四个地区。

阅读分流

到这里，装不装的第一层判断已经有了：门槛、权重真相、参考素材预期、许可边界。下面逐项展开四条安装路线与各自验收点、离线安装包、质量档与预览、社区实测表怎么读（含 3090 多版本对照）、更新节奏，以及对外监听的安全口径。要动手的人重点读 §02–§04 和 §07。

§01 / 权重真相：跑的不是 H3 原版

FreeVideo 官方 About 写明 built on OpenVDN's 8-step VDN-H3 model with Video DeltaNet's hybrid attention，致谢段感谢 OpenVDN 开源权重。VDN-H3 模型卡补充了细节：从 MiniMax H3 已发布的 transformer 权重出发，加一条 frame-wise 线性注意力分支和两个小 LoRA adapter（推理时合并入主干），生成用 8 denoising steps；论文 arXiv:2609.20744，权重 2026-09-06 发布。官方文本主体口径是“8 步”，“蒸馏”一词只在 SGLang cookbook 章节标题出现。

下载体积有官方数：FreeVideo 实际拉取的是 FP8 部署包 vdn-minimax-h3-edge，只下匹配格式约 22.9 GB / 21.4 GiB，文本编码器与视频/音频解码器另装；HF 与 ModelScope 同 payload，模型公开、无需 HF 登录（HF read token 仅可选用来减匿名限流）。H3 本体 33B 参数 dense 单流 Transformer，其中约 13B 在 AdaLN 分支、推理可不加载——文章“三百多亿参数”与官方一致。

归因：本节全部为官方一手（README、OpenVDN/MiniMax 模型卡）。int8 权重对应的具体仓库/格式官方文档未逐条写明，属未核实点。

§03 / 首次验收与失败排查（官方口径）

Windows 被杀软拦截

官方流程：先到 release 页核对 FreeVideo.exe 的 SHA-256（最新 release 带 SHA256SUMS.txt），一致再恢复文件，并且只把 FreeVideo 文件夹加入排除——不要顺手关掉杀软。

Mac 首次打开被拦

Mac 版未经苹果公证。官方流程：按 Mac 指南校验 SHA256 后“仍要打开”，只放行本应用、不动其他安全设置。前置条件容易漏：macOS 14+ 与 Xcode 命令行工具；M5 之前的芯片走 BF16，更慢。

请求直接被拒

执行规划器在显存连最低工作集都放不下时，会在加载 transformer 前拒绝请求并报告缺口。这不是故障：先关掉占显存的程序，或降低分辨率/时长再试。

Linux 起不来

驱动要 580+；AppImage 需要 2022 年以后的发行版。服务器上默认 ComfyUI 只接受本机连接，freevideo status|stop|restart 管服务；远程访问见 §09 的 token 口径。

验收的判定线很简单：安装器跑完 → 启动器里能看到模型下载进度或已就绪 → 提交一个最短的 5 秒 Light 档请求能出片。三步都过了才算装好；卡在哪一步对应上面四格排查。

§04 / 模型下载与离线安装

在线下载源为 HuggingFace、ModelScope、hf-mirror 等镜像（代码内可见 host 校验），模型公开无需登录。网络不好或要在内网机器装，走官方中文 README 挂的夸克网盘离线包：ZIP 不解压，直接拖进启动器。

完全离线需要四个模型包：视频模型、文本编码器、视频与音频解码器、采样缓存；新装 ComfyUI 的机器再加一个运行环境包（v0.3.12 起只导环境包时可选自动下载）。参考素材带音频的，另加可选的音频参考缓存包。夸克包内容本轮未下载核验，装前建议自行核对包内说明。

归因：官方中文 README 与 offline_packages.py、network.py 代码口径；离线包内容未验证。

§05 / 质量档与预览：先把等待成本压下来

四档质量

Light / Medium / High / Max（v0.2.0 起）。各档画质差异目前只有官方对比示例与文章截图，本轮无法独立验证“哪档够用”，选档应以自己机器的实测为准。

先看半分辨率预览

v0.3.2 起 preview first：先出半分辨率预览，满意再跑完整版。对 8 GB 卡尤其重要——预览几分钟就能否掉一个不合格的 prompt，省下整段完整渲染时间。

长视频也有官方上限：创作面板单次最多填 60 秒，一条视频最多 8 段，全用 10 秒以上段时整条约 110 秒；接缝处画面易变化，官方建议把切分点放在镜头切换处。v0.4.0 起支持 Claude Code/Codex 等 AI agent 自主出片和时间线编辑视图；v0.5.0 起 H3 Image 本地生图，最高 16 MP、8 GB 显存起。

归因：功能均为官方 News 与中文使用说明；画质结论未独立验证。

§06 / 参考素材：官方承诺到哪，宣传到哪

参考图＝实验能力

官方中文原文：“参考图生成视频目前仍是实验能力。能够运行不等于每次都能保持人物外观一致，清晰的正面图效果更稳定。”定位是内容出现在视频中，不规定哪一帧。

参考视频＝取 15 秒

官方只说明：只取与成片等长的一段，最长 15 秒，生成用时约为只用图片时的两倍。文章“动作就跟着视频走”官方无对应承诺，本卡不按保证能力写。

替换人物＝独立功能

有官方依据：源视频加人物图（最多 2 张，按画面从左到右对应），不能与首帧/尾帧同用，首次自动下载约 80 MB 模型，源视频至少 1 秒、无声源视频不能保留声音。

首尾帧与音频

首帧尾帧可同用，按输出画幅居中裁切；音频“原样使用”时成片直接用该声音、一次限一段。注意：首帧、尾帧和中间帧可以与参考图/参考视频同用，Mac 上暂不支持，只能保留一类；另按官方 Mac 指南，Mac 版当前仅支持文本提示、首帧输入与二采采样（preview first），参考素材能力以 NVIDIA 平台为准。

预期管理：涉及“人物一致”“动作迁移”的说法一律以官方限定为准——实验能力、不保证每次一致、参考视频仅取 ≤15 秒等长片段。想稳定复现同一人物，先用手头素材各跑一次预览验证，不要按文章描述直接排产。

§08 / 更新节奏与社区 LoRA

项目 2026-09-13 建仓，2026-10-02 官方宣布开源，最新 release v0.6.5（2026-11-19）。节奏可以官方 News 为准：v0.4.0（2026-10-13）加 AI agent 出片、超一分钟视频与时间线编辑；v0.5.0（2026-11-10）加 H3 Image 本地生图。文章“开源一个多月”截至核验日已约 7 周，轻微过时。

LoRA 两句话：官方支持 MiniMax H3 社区 LoRA，示例有 VHS、Looping Sketch Anime、Male POV（附同 prompt 同 seed 对照）；加速类 LoRA 不用装——产品内置文案明确“FreeVideo 的模型已经加速，无需此类 LoRA”，检测到原版加速 LoRA 会提示移除。

§09 / 许可、对外监听与网络边界
许可双轨：代码 Apache License 2.0；模型权重走 MiniMax H3 Community License Agreement——授权地域为全球但排除欧盟、英国、韩国、美国，域外使用未获授权，另有再分发要求（附协议、修改注记、NOTICE）与可接受使用政策（AUP）。安装器会以同口径提示。文章只写“商用先读协议”，没点名四个地区；在你所在地区是否可用，先对表再决定。
局域网监听：Linux 下默认 ComfyUI 只接受服务器本机连接，官方推荐 SSH 隧道（ssh -N -L 8188:127.0.0.1:8188）。freevideo server --listen 0.0.0.0 是用户主动开启的对外访问：生成带 token 的链接与二维码，任何拿到链接的人都能用，且连接默认不加密——官方建议仅在可信网络使用，或加 --tls-cert/--tls-key 走 HTTPS。文章只提了“给你一个局域网链接”，这两点必须补上。

隐私口径照官方说：“本地推理引擎”“本地运行”——生成过程在本地执行有官方依据；但仓库没有专门的隐私政策页，“素材不出本机”是文章归纳，不能当官方承诺。联网需求客观存在：模型与更新要从 HF/ModelScope/hf-mirror 下载，完全离线只有 §04 的官方路径。代码内未发现明显遥测上报端点，但未做全面网络审计，“无遥测”不能断言。

边界与行动 / 该不该用

满足这些条件再看

  • NVIDIA 卡显存 ≥ 8 GB（或 24G 统一内存的 M 系列 Mac），内存 ≥ 16 GB；
  • 能接受 8 GB 卡上 10 秒片等 10–22 分钟、Max 档按小时计的等待；
  • 所在地区不在权重许可排除名单内，接受 AUP；
  • 硬盘有 25 GB 以上余量放权重。

不必硬上的理由

  • 显存不足 8 GB：规划器会在加载前拒绝请求，装了也跑不起来；
  • 在欧盟/英国/韩国/美国：权重许可未授权域外使用；
  • 要稳定的人物一致性产出：官方明示参考图为实验能力，生产链路别押注；
  • 服务器对外提供服务：默认不加密的局域网模式撑不住公网场景。
  1. 按 §02 选路线安装，NVIDIA 用户先确认驱动 ≥ 580。
  2. 启动器里完成权重下载（约 22.9 GB）或拖入夸克离线包。
  3. 提交一个 960×544 / 5s / Light 的最短请求做首验，通过后再试 1344×768。
  4. 跑两三个 prompt 记下自己机器的真实耗时，再决定日常用哪档质量。
  5. 要远程访问先走 SSH 隧道；确需 --listen 0.0.0.0 时配 TLS 并只发链接给可信设备。
