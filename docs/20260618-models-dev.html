模型元数据 Schema（models/ 目录）
TOML → /models.json
字段 类型 说明 示例
name string 模型名称 GPT-5
family string 模型族系 ID gpt
release_date date 发布日期 2025-08-07
attachment bool 支持附件/多模态输入 true
reasoning bool 推理能力标记 true
tool_call bool 函数调用支持 true
structured_output bool 结构化输出 true
open_weights bool 开放权重 false
limit.context int 上下文 token 上限 400,000
limit.input int 输入 token 上限 272,000
limit.output int 输出 token 上限 128,000
modalities array 支持模态 [text, image]
benchmarks array 基准分数列表 MMLU / GSM8K
weights[] array 权重下载链接 HuggingFace
数据贡献流程
Community Driven

Step 1：在 providers/{provider}/models/ 目录按 TOML 格式添加模型文件。

Step 2：如需 Provider-agnostic 元数据，在 models/{family}/ 添加对应文件。

Step 3：使用 base_model 字段继承模型元数据，只保留 Provider 特定字段（如价格）。

Step 4：提交 PR，数据用于生成 API JSON 与 models.dev 页面。

快速接入
Curl Ready

拉取全量 API

curl https://models.dev/api.json

拉取模型元数据

curl https://models.dev/models.json

拉取完整目录

curl https://models.dev/catalog.json

拉取 Provider Logo

curl https://models.dev/logos/{provider}.svg
