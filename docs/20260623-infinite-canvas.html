无限画布：把 AI 创作装进同一个工作台

basketikun/infinite-canvas 是一款面向图片创作的开源工作台：把画布编排、AI 生图、参考图编辑、对话助手、提示词库和素材沉淀放在同一个界面里，适合连续探索视觉方案并反复迭代。

AGPL-3.0 Next.js + TypeScript 画布编排 本地保存 MCP / Agent
资料内容预览

一眼看懂：它不是单纯的图片生成器

它把创作流程拆成画布、节点、参考图、助手和素材库，让每次生成都能被组织、沉淀和继续编辑。

先搭画布，再让 AI 进入流程。
这张卡的重点不是“会生成图”，而是“能把生成图纳入工作流”。

项目定位

面向图片创作的开源工作台，不止是出图，更是组织创作过程。

核心功能

  • 无限画布：拖拽、缩放、连线、小地图、撤销重做
  • AI 创作：OpenAI 兼容接口 + 文生图 / 图生图 / 参考图编辑
  • 画布助手：围绕节点对话并把结果插回画布
  • 本地 Agent：用 MCP 连接 Codex / Claude Code
快速开始前提：Node / Bun 环境cd web && bun install && bun run dev
部署方式Vercel 或 Dockerdocker run --rm -p 3000:3000 infinite-canvas
