# 模式 关键实现
1 并行工具执行 工具调用的并发控制，结果合并后再决定下一步。支持 Bash / Web search / File read 等多种工具并行。
2 危险命令拦截 在执行 Bash 命令前扫描高危操作（rm -rf、git push --force 等），拦截或要求确认，防止破坏性操作。
3 三层上下文压缩 Token 接近上限时自动压缩：①消息摘要 ②历史摘要 ③关键信息保留。在长任务中保持上下文相关性。
4 长期记忆与规划 维护任务目标状态，跨多轮对话保持一致性。不只是记住说了什么，而是记住要做什么和做到了哪一步。
5 Skill 路由与执行 根据用户意图动态选择合适的 Skill（任务模板），支持自定义扩展，无需修改核心代码即可添加新能力。
6 会话状态管理 记录会话上下文、工具执行历史、决策理由，支持会话恢复和审计追踪。
7 模型适配层 统一的模型接口抽象，屏蔽 API 差异，让同一套代码跑在 OpenAI / Anthropic / DeepSeek / Ollama 等任意模型上。
