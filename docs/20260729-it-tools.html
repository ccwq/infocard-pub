IT-Tools

把常用开发工具装进本地，不用每次打开浏览器搜索。

07

开发者实用工具箱

JSON / UUID / Base64 / 正则测试等数十种工具，无广告，可离线。

涵盖工具类型

格式与编解码

JSON 格式化、Base64 编码/解码、URL 编解码、HTML 转义等。

生成与转换

UUID 生成、Hash 计算、颜色转换、时间戳换算、QR Code 生成。

测试与校验

正则表达式测试、JWT 解码、URL 解析、Cron 表达式预览。

为什么值得用

完全离线

在本地或内网环境运行，不需要把敏感数据发送到在线工具网站。

Self-Hosted

支持 Docker 一键部署，适合团队共享或私有化内网环境。

无广告

界面干净，没有弹窗、漂浮广告和追踪脚本。

部署方式

Docker 适合快速启动，Node/PNPM 适合本地开发调试，两者功能完全一致。
# Docker 部署（推荐）
docker run -d --name it-tools \\
  -p 8080:80 \\
  corentinth/it-tools:latest

# 或 Node/PNPM 本地运行
git clone https://github.com/CorentinTh/IT-Tools
cd IT-Tools && pnpm install && pnpm dev

适合谁

后端开发者

调试 JWT、转换时间戳、生成测试数据。

前端工程师

JSON 格式化、Base64 图片转换、正则表达式验证。

运维 / 安全

Hash 校验、Cron 表达式验证、URL 参数解析。
