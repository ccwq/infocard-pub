录制内容 — 完整会话全息图

01

会话生命周期

Start / End / 中断 / 上下文压缩，完整记录会话起止与所有关键状态变迁。

02

实时流式转录

通过 SignalR 后台进程实时流式传输对话内容，支持 SessionStart 时的持久化录制缓存（spool）。

03

子代理活动树

完整捕获所有 spawn 子代理及其各自的转录，形成树状调用关系图。

04

工具调用详情

每次工具调用含时间戳、参数与返回结果，支持错误提取（kcap errors）快速定位问题。

05

Token 消耗追踪

Input / Output / Cache token 计数，精确到每轮交互，适合成本分析与性能优化。

06

Git 上下文关联

自动关联仓库、分支、PR/MR，支持 PR 自动标签与 pull-request 审查报告。

CLI

常用命令参考

安装与设置
npm install -g @kurrent/kcap

自动下载 NativeAOT 二进制（macOS ARM64 / Linux x64+ARM64 / Windows x64）

初始化
kcap setup

交互式向导，发现租户、OAuth 登录、默认可见性配置、代理钩子安装

会话回溯
kcap recap <sessionId>

AI 生成摘要 + 每轮交互大纲；加 --full 输出完整转录；--chain 跨会话链

会话导入
kcap import --org <owner>

导入历史会话；--all / --org / --repo 限定范围；--claude / --codex / --cursor 等限定代理

本地代理
kcap run-agent claude --detached

在后台运行 Claude Code（daemon 托管），Ctrl-Q d 可断开会话而不中断代理

更新
kcap update

升级 CLI + 刷新所有代理插件（绕过 npm 11+ allowScripts 限制）

FAQ

常见问题

Q: 与 Kaplan-Meier 估计器有关吗？

完全没有。kcap-cli 全称为 Kurrent Capacitor，是 AI 编程代理的会话录制工具，与生物统计/生存分析无关。

Q: 数据存储在哪里？

会话录制发送到配置的 Kurrent Capacitor 服务器（私有部署或 Kurrent 托管）。本地仅存储配置、钩子脚本和 spooled 事件。可通过排除配置（excluded_repos）精细控制不上传的仓库。

Q: 支持哪些平台？

macOS ARM64、Apple Silicon、Linux x64/ARM64（含 Alpine/musl）、Windows x64。CLI 使用 NativeAOT 编译，无需 .NET 运行时。

Q: 如何实现断网容错？

SessionStart/SessionEnd 事件在服务器不可达时自动写入 ~/.config/kcap/spool/，下次钩子触发时重新发送，最多保留 30 天。

Q: 多租户/多服务器如何切换？

使用 Profiles 功能（kcap profile add），支持 --remote 模式按 Git 远程地址自动切换；也可用 .kcap.json 文件团队共享配置。

Q: 可否本地离线使用？

CLI 工具本身可离线安装和运行，但录制数据需发送到配置好的服务器（支持自托管），离线状态下 spool 本地待发送。
