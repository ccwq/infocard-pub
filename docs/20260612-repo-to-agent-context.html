Repo-to-
Agent-Context

一键把仓库变成 AI 可读、可更新、可验证的上下文包，解决 token 浪费和上下文丢失问题。离线优先，输出分层上下文，最小化无关上下文、误改和回归风险。

离线优先 分层上下文 L0-L3 Token 节省 57x 可验证闭环
Context Optimization Strategy
传统 RAG

盲目向量检索，输出冗长、token 消耗大，Agent 无法验证质量。

Repo-to-Agent-Context

结构化分层上下文 + Token 预算控制 + 验证闭环，Agent 可读、可验证、可复用。

为 coding agent 构建最小、可验证、带证据链的上下文包。

不只是"让 Agent 读懂仓库"，而是"让 Agent 在仓库里安全、可验证地完成任务"——围绕任务级上下文、变更影响分析、测试推荐、编辑边界与验证闭环构建。
01 · 扫描Scan Repo

离线扫描仓库、提取轻量代码结构、构建依赖图。

02 · 生成Build Context

按 L0-L3 分层生成 AGENTS.md 和 .agent-context/ 上下文包。

03 · 优化Token Savings

压缩比可达 57x，附 token 节省报告，支持真实 tokenizer 计数。

04 · 验证Validate

测试推荐、变更影响分析、编辑边界约束，验证闭环。

上下文分层
context layers
L0
AGENTS.md

最短操作规则，始终加载。含入口文件、必要命令和 .agent-context/ 索引。

L1
Summary + Onboarding

新任务开始时加载 repo-summary.md、onboarding.md、context-layers.md。

L2
Task + Run

具体任务包 runs/ 和 tasks/，处理任务时加载。

L3
Index + RAG + Graphs

深入分析、符号查询、证据追踪时按需加载。

CLI = repo-context init / build / validate / run / plan / pack / verify / impact / tests / benchmark / retrieve
核心能力
capabilities

输出结构artifacts

AGENTS.md + .agent-context/:

  • repo-summary.md · 模块摘要
  • key-files.md · 关键文件索引
  • module-map.md · 模块地图
  • dependency-graph.json/mmd
  • architecture.contract.json · 架构契约
  • token-savings.json · 节省报告

Token 控制budget

内置 chars-approx 估算 + js-tiktoken 真实 tokenizer：

repo-context build . --token-budget 80000

原始仓库 2.4M tokens → 上下文 42K tokens（57x 压缩）

验证闭环validation

  • repo-context validate · 验证上下文完整性
  • repo-context verify --diff · 变更验证
  • repo-context tests --diff · 测试推荐
  • repo-context impact · 变更影响分析
快速上手
quick start
NPX 一键生成npm
npx repo-to-agent-context build ./path/to/repo
本地源码运行dev
npm install && npm run build node dist/cli/index.js build ./repo
带 LLM 摘要llm
repo-context build . --llm
Agent 自动化agent
repo-context run "fix bug" . --type bugfix
支持 Agent = Codex / Claude Code / Cursor，可直接用自然语言让 Agent 调用此工具。
