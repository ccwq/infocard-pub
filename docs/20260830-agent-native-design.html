THE GAP

Mock 审批通过，不等于页面能用

标题在手机上折成三行、空状态变成灰框、320px 筛选栏溢出——这些问题往往不在设计文件里，因为文件只是屏幕的图片。

THE BET

把设计变成可运行的交付物

响应式来自真实 CSS 断点，表单可以提交，状态可以变化，导航确实能到达；你评审的页面就是后续导出的页面。

THE STACK

一份自包含文档

  • HTML页面本身就是源码
  • Tailwind样式可读、可继续修改
  • Alpine轻量交互真实执行
WORKFLOW

没有矢量画布的三步设计流程

像给同事写 brief 一样告诉 Agent 你要什么，再在浏览器里对着真实页面继续收敛。

01Describe用自然语言描述落地页、产品 UI、品牌方向或交互原型。
02Generate生成完整可运行文档，可并行比较多个方向。
03Refine用 tweak 控件或对话直接改 HTML 的文案、布局、颜色、间距和交互。
关键区别：对话操作的是底层 HTML，而不是一张平行的设计表示。预览、编辑与导出共用同一份源码，因此审批与交付之间没有额外翻译层。
DESIGN SYSTEM INTELLIGENCE

不是套一个 AI 风格，而是使用你的真实零件

DSI 索引组件、图标和设计 tokens，让 Agent 从既有原语出发生成，减少“看着合理但完全不像你的产品”的返工。

可接入来源DSI 做什么对生成结果的影响
已连接的 Builder 项目发现项目中的组件与文档从已有产品零件开始
公开仓库 URL索引组件和使用说明减少陌生字体、间距和按钮风格
公开 / 私有包读取包注册表内容；私有包可用 token让设计系统成为可检索资源
Figma + Markdown上传设计文件与补充用法说明把视觉资产和规则一起提供给 Agent
ARTIFACT TEST

审批前就能发现 staging 才会暴露的问题

Responsive

真实断点下检查 320px / 手机 / 桌面布局，不把溢出留给三周后的 staging。

Interaction

表单提交、状态切换和导航真实执行，不只看静态截图。

Empty state

因为页面可以被点击进去，空状态和错误路径也必须存在。

# 一个可迁移的自然语言 brief 目标：做一个团队知识库的空状态页面 约束：使用现有设计系统的按钮、间距和字体 token 验收：桌面 / 手机均不溢出；按钮可点击；空状态有下一步 CTA 输出：自包含 HTML；完成后列出未验证的交互与可访问性风险
EXPORT / LIMITS

它替代的是“设计到代码”的断层，不是所有设计工具

✓ 更适合

  • 可运行的网页原型和产品 UI 方向探索
  • 需要真实响应式和交互的评审
  • 想用自有组件和 tokens 生成初稿
  • 导出 HTML、ZIP 或 PDF 作为后续交付材料

✗ 不应过度期待

  • 它不是矢量原生工具，不能替代插画与图标创作
  • 组件是复制的 HTML，不是成熟的 canonical instance
  • 原型仍需翻译进业务框架和生产代码
  • 原生 App 的布局语言不是 CSS，适合继续使用传统工具
