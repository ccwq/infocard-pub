💡

项目定位

Muse Gadgets = Muse 个人 AI 助理的硬件接口层，Meta 官方开源。

🧩

双端 SDK

ESP32 开发板固件（屏幕+麦克风+喇叭+按钮）；Linux SDK（树莓派等，支持命令执行/文件读写/设备状态）。

📱

配套 App

Muse App 开启开发者模式，配对设备后按板子按钮确认接入。

🏠

Home Assistant

Linux 端可接入 HA，Muse 能管理家电（灯、开关、传感器等）。

⚠️

副作用警告

板子变砖、保修失效、破产（官方 README 原话）。

官方适配 20+ 设备hardware
🤖 M5Stack

M5Stack 口袋设备，官方首发适配之一，小巧堆叠式设计。

🔘 Waveshare

圆形 AMOLED 触屏，适合桌面展示 Muse 状态与回复。

📺 Seeed Studio

彩色墨水屏，功耗低，适合静态信息展示与装饰。

🔌 Muse Home Link

Meta 官方设备，USB-C 供电，接入家庭网络后控制电视、音箱。

ESP32 端典型功能

屏幕显示 Muse 发来的图片 / 按住按钮直接语音对话 / 内置麦克风 + 喇叭

Linux 端典型功能

执行系统命令 / 读写文件 / 查看设备状态 / 接入 Home Assistant

网友魔改案例community hacks
  • 📖 e-ink 阅读器 → Muse 小屏（MacStories 创始人 Federico Viticci）
    把 Xteink 墨水屏阅读器改成 Muse 随身小屏，Muse 取名 Calliope，屏幕显示 Calliope 形象+状态更新，可用 MagSafe 吸在手机背面翻过来看 Muse 在忙什么。原系统保留可切回看书。muse-pocket 程序已开源。
  • 🤖 闲置小机器人改造
    喊「Hey Muse」后回「Coming!」，机器人自己走过来，抱到书桌上还能接着聊。
  • 🎮 复古游戏掌机移植
    掌机任务菜单可随机要菜谱/听笑话/每日建议/让 Muse 画图，请求发到 Muse 对话，手机收回复。
接入四步setup
① 领 SDK Token

官网注册，获取 Muse Gadgets SDK Token

② 刷固件 / 装 SDK

官方适配板子刷固件；Linux 一行脚本完成安装

③ 开开发者模式

Muse App 开启开发者模式，添加设备

④ 按钮确认配对

按板子按钮确认配对，看不懂文档可交给 Claude Code / Codex 指导
