独立于具体Agent的可持续维护多端共享长期知识库基础设施——多智能体共享知识层

核心价值：解决知识库与特定Agent深度绑定的瓶颈缺陷——将分散异构数据标准化为跨Agent共享的Markdown文件，全局配置接入，实现多端一致的长期知识检索。

认证方式OAuth + API
运行模式个人 / 代码

🗄️ 个人模式

构建本地多源异构个人知识库系统，将分散数据压缩并标准化为跨Agent共享的Markdown文件，实现个人长期记忆。

  • Notion / Slack / Gmail / X 等多源摄取
  • 每日凌晨 2 点自动化增量更新
  • 手动定向检索更新

📦 代码模式

自动化为当前代码库构建标准仓库文档，通过在 agent.md 中注入前置读取指令实现检索对齐。

  • 自动分析代码库结构
  • 生成标准 AGENTS.md / CLAUDE.md
  • 支持 Codex / Claude Code / Hermes Agent
