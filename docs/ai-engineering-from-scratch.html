AI Engineering from Scratch：523 节全栈课程，教程本身即 Agent 技能

把 AI 工程从数学基础到生产部署拆成 20 个阶段，每个 lesson 交付一个可直接复用的 artifact（prompt / Skill / Agent / MCP 服务），并封装成 Claude Code / Codex 技能——本地智能体化身一对一导师。

不是视频课，不是 PDF，不是单向阅读。
课程本身是一套 agent skills：装好后 /start-learning 触发 10 题 placement quiz，映射你的已有基础到起始阶段，生成个性化 LEARNING.md。随后 /learn 每次推进一课（概念→数学→代码→测验）循环迭代。

覆盖语言：Python / TypeScript / Rust / Julia。许可证：MIT。11.1K forks，全部公开。
