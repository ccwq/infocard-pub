名字由来 — 致敬 Multics 操作系统
Multica = Multiplexed Information and Computing Agent

名字致敬 1960 年代的 Multics（Multiplexed Information and Computing Service）操作系统。Multics 开创了分时共享（time-sharing）的理念——让多个人同时使用同一台计算机。Multica 延续这一精神，让人和 Agent 共享同一个系统：Agent 不再是孤立的工具，而是系统中的"用户"，有自己的身份、任务队列和技能档案。视频中被音译为 "mkai" 或 "mtica"，文本中误认作 Mintlify，实际是 Multica——一个致敬分时共享先驱的 Agent 协作平台。

pgvector
向量检索扩展，支撑技能匹配和语义搜索。
关系存储
Issue、Agent、Workspace、Skill 全部关系化建模。
Agent Runtime: Local daemon

本地守护进程是 Multica 的运行时核心。它负责检测已安装的 Agent CLI、管理任务队列、转发 WebSocket 通信，并把执行结果写回数据库。守护进程与后端服务通信，但实际 Agent 进程在本地运行——这意味着你的代码不会离开机器，除非你显式配置云运行时。

安装与快速开始 — 三行命令起步
安装
# Homebrew (macOS)
brew install multica-ai/tap/multica

# macOS / Linux
curl -fsSL https://raw.githubusercontent.com/multica-ai/multica/main/scripts/install.sh | bash

# Windows (PowerShell)
irm https://raw.githubusercontent.com/multica-ai/multica/main/scripts/install.ps1 | iex

# 自托管（含服务端）
curl -fsSL https://raw.githubusercontent.com/multica-ai/multica/main/scripts/install.sh | bash -s -- --with-server

# CLI 核心命令
multica setup          # 初始化配置
multica daemon start   # 启动本地守护进程
multica daemon status  # 查看守护进程状态
multica workspace list # 列出工作区
multica issue create   # 创建 Issue（可分配给 Agent）
