💡 核心理念：Chat 不是工作发生的地方
📌 问题
聊天记录无法承载需要运行数天的状态。多人或多个 Agent 需要读写同一份数据时，Chat Thread 是门，不是房子。
✓ Lemma 解法
Pod 是共享工作空间：表格 + 文件 + 工作流 + 权限 + 审批，Agent 与人类读写同一套状态。
🔄 类比
Gamma（Prompt → 可编辑幻灯片）
Cursor（输出 → 编辑器 diff）
Lemma（Agent 输出 → Pod 中的表格行）
🏗️ Pod 核心原语（Everything is a Pod）
📊
Tables
带类型的可查询业务数据，含行级安全。leads、tickets、tasks、approvals。
📄
Files
Markdown 记忆库，结构化数据无法覆盖的内容。Agent 与人类均可读写。
🤖
Agents
LLM Worker，带角色、工具授权、隔离访问范围。不再是「访问一切」的万能 Agent。
🔀
Workflows
混合 Agent / 函数 / 决策 / 循环 / 等待 / 人工审批的图形。可由定时器、webhook、表格事件触发。
⚡
Functions
确定性逻辑，与 Agent 并肩工作。验证器、状态转换、动作触发——并非所有逻辑都需要 LLM。
🔐
Permissions
人与 Agent 的角色体系：Pod 级角色、表格授权、资源可见性、委托令牌。
✅
Approvals
工作流审批节点，暂停 → 路由给指定人 → 等待决策 → 恢复。在 App 内或 Slack 中完成。
🖥️
Apps
运营 UI，在 URL 上部署，基于同一套 Pod API 构建。单文件 HTML 或完整 React 应用。
💬
Surfaces
Slack / Teams / Gmail / Outlook / Telegram / WhatsApp，连接 Pod Agent，支持身份解析和会话关联。

⚡ 安装（Any CLI can work a pod）
bash — Mac / Linux
# 一行命令拉起完整本地栈
curl -fsSL https://raw.githubusercontent.com/lemma-work/lemma-platform/main/install.sh | bash
PowerShell — Windows
# Docker Desktop 已安装时
iwr https://.../install.ps1 | iex
🚀 Skill 安装（Claude Code / Codex / OpenCode / Cursor）
bash — 安装并认证
# 自动检测并安装到你的 Agent
uv tool install lemma-terminal
lemma skills install
lemma auth login

# 创建第一个 Pod（含起始表格 + Agent）
lemma pod create my-team --with-starter
lemma chat "what can you do in this pod?"
bash — 启动 Daemon（Agent 在 Pod 内运行）
lemma daemon start   # 本地 Claude Code / Codex 接入 Pod 任务队列
lemma daemon status # 查看 pid / 运行状态 / 日志路径
lemma daemon stop
