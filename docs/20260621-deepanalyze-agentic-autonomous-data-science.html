📖 为什么值得看

中国人民大学 + 清华大学联合出品，GitHub 4.2K ⭐，arXiv 已挂，全栈开源：模型权重（DeepAnalyze-8B）、训练代码、50 万条数据科学指令数据集（DataScience-Instruct-500K）全部开放。

被 2026 年中国大学生计算机设计大赛大数据主题赛指定为官方 Agent 引擎。

DeepAnalyze 是首个能够自主完成完整数据科学流程的 Agentic LLM——上传数据，给出目标，等报告。
一句话

DeepAnalyze 把数据丢进去就能得到一份分析师级别的研究报告：它自己完成数据清洗、特征工程、建模、可视化和报告撰写，不需要人工介入任何环节。

🛠 核心能力
完整数据科学流水线
数据准备→ 探索分析→ 特征工程→ 建模→ 可视化→ 报告生成
支持的数据类型
  • 结构化数据：数据库、CSV、Excel
  • 半结构化数据：JSON、XML、YAML
  • 非结构化数据：TXT、Markdown
Deep Research 模式

给定数据后自主进行开放式深度研究，最终输出分析师级别的研究报告（可导出 PDF）。

💾 GPU 显存配置推荐
显存模型版本最大上下文FP8 KV Cache
16GB8-bit 量化8,192✓
16GB4-bit 量化49,152✓
24GB原模型16,384✓
24GB8-bit 量化98,304✓
24GB4-bit 量化131,072✓
40GB原模型131,072✓
80GB原模型131,072—
显存 < 24GB 推荐 4-bit 量化 + FP8 KV Cache；显存 ≥ 40GB 可用原模型。

💻 Python 调用示例
from deepanalyze import DeepAnalyzeVLLM

prompt = """# Instruction
Generate a data science report.

# Data
File 1: {"name": "student_data.csv", "size": "16.0KB"}
File 2: {"name": "enrollment.csv", "size": "20.4KB"}"""

workspace = "/path/to/your/data/"

deepanalyze = DeepAnalyzeVLLM("/path/to/DeepAnalyze-8B/")
answer = deepanalyze.generate(prompt, workspace=workspace)
print(answer["reasoning"])
上传任意类型数据，指明任务类型或开放研究目标，DeepAnalyze 自动完成全流程并输出报告。

📌 边界说明
  • 量化精度损失：4-bit 量化版显存占用小但模型精度有所下降，高精度需求场景建议原模型
  • 代码执行安全：本地部署时代码在用户环境中执行，WebUI v2 的 Docker 沙箱提供隔离保护
  • 长上下文显存压力：131K 上下文需要 24GB+ 显存，16GB 用户建议量化版
  • API Key 限流：HeyWhale API Key 有用量限制，生产环境建议本地部署
