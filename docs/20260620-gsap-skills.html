⏱️ Timeline 模式

时间线优于链式 delay，用 position 参数精确控制相对时间。

const tl = gsap.timeline({
  defaults: { duration: 0.5, ease: "power2" }
});
tl.to(".a", { x: 100 })
  .to(".b", { y: 50 }, "+=0.2")
  .to(".c", { opacity: 0 }, "-=0.1");

📜 ScrollTrigger 模式

附加到 timeline 或顶层 tween，布局变化后调用 `ScrollTrigger.refresh()`。

const tl = gsap.timeline({
  scrollTrigger: {
    trigger: ".section",
    start: "top center",
    end: "bottom center",
    scrub: true
  }
});
tl.to(".panel", { x: 100 })
   .to(".panel", { rotation: 5, duration: 0.7 });

⚛️ React useGSAP 模式

始终使用 scope 限制作用域，cleanup 必须执行 `ctx.revert()`。

import { useGSAP } from "@gsap/react";
useGSAP(() => {
  gsap.to(ref.current, { x: 100 });
}, { scope: containerRef });
// 或 useEffect: ctx = gsap.context(()=>{...}, ref)
return () => ctx.revert();
