INSTALL · 安装方式
curl Homebrew winget scoop PowerShell

README 提供多平台安装：macOS / Linux 使用 curl 脚本，Windows 提供 PowerShell、Winget、Scoop 三种方案，另外也有源码编译方式。

# macOS / Linux
bash -c "$(curl -sLo- https://superfile.dev/install.sh)"

# Windows PowerShell
powershell -ExecutionPolicy Bypass -Command "Invoke-Expression ((New-Object System.Net.WebClient).DownloadString('https://superfile.dev/install.ps1'))"

# Windows Winget
winget install --id yorukot.superfile

# Windows Scoop
scoop install superfile

WHY IT MATTERS · 为什么它受欢迎

传统终端管理器

功能够用，但视觉单调、上手门槛高、个性化有限，常常只是“能用”。

superfile

把“能用”升级成“顺手 + 好看 + 可定制”，让终端文件管理不再像在黑盒里摸文件。

适合谁

天天泡终端、需要频繁文件操作、又不想牺牲审美和效率的重度命令行用户。
