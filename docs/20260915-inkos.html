INKOS · STORY CREATION AGENT PIPELINE

InkOS：把长篇小说交给一条可审计的 Agent 流水线

InkOS 用 10 个分工 agent、三层记忆和控制面文档管理长篇、短篇、剧本、互动影游与翻译创作。安装只要一条 npm 命令，但真正决定成稿质量的是“规划→编排→写作→审计→修订”这条链路怎么配置。

# 安装（要求 Node.js 22+）
npm i -g @actalk/inkos

# 建书（可传入创作简报）
inkos init my-novel && cd my-novel
inkos book create --title "书名" --genre xuanhuan --brief my-ideas.md

# 写第一章并回读证据
inkos write next 书名
inkos status && inkos review list 书名

# 验证控制输入（无需 API Key 即可跑 compose）
inkos plan chapter 书名 --context "本章聚焦师徒矛盾" --json
inkos compose chapter 书名 --json

# 守护进程 + 导出
inkos up -q
inkos export 书名 --format epub
使用边界

AGPL-3.0：修改或托管服务需遵守开源义务，商用前核对许可证。API Key 只存本机 .inkos/secrets.json，但内容会发送到你配置的模型服务商；涉密题材先评估数据流。生成内容版权归按平台与法律判断，审计机制降低而非消除连续性错误。Node.js 版本低于 22 时 SQLite 记忆库不启用。
