## 叙事主线
Models.dev 是 AI 工具链中的"模型黄页"：不是又一个模型评测站，而是把"哪里有模型、规格是什么、怎么调用"做成可程序消费的开放数据。社区共建 + TOML 格式 + 自动生成 JSON API，被 OpenCode 内部使用意味着数据质量有实际验证。适合接入 AI 工具的开发者参考。
