核心定位

Harness 位于 Claude Code 的 L3 Meta-Factory / Team-Architecture Factory 层——不是某个具体任务 Agent，而是生成其他 Agent 架构的工厂。它把自然语言需求转化为完整的 Agent 定义（.claude/agents/）+ 配套 Skill（.claude/skills/），Pick 六种预定义团队模式之一，自动组装协作流程。

Pipeline

Prod-Reviewer
生成 → 质量审查双角色
Supervisor
中央调度 → 动态分发
Hier-Delegation
自上而下递归委派
五阶段生成流程
1 领域分析 — 理解需求边界与复杂度
2 架构选型 — Agent Teams / Subagents 二选一
3 Agent 定义生成 — .claude/agents/
4 Skill 生成 — Progressive Disclosure 省上下文
5 集成 & 编排 — 数据传递 / 错误处理 / 验证

安装方式
# 方式一：Marketplace（推荐）
/plugin marketplace add revfactory/harness
/plugin install harness@harness-marketplace
# 方式二：手动全局安装
cp -r skills/harness ~/.claude/skills/harness
⚠ 需要 Claude Code 开启 Agent Teams 实验特性：
CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1
