DeepTutor：港大开源终身个性化AI辅导系统

把教材、论文、笔记全部喂进去，照着你的资料来深度辅导。支持解题、出题、研究报告生成、可视化与动态学习路径，Docker 自托管，Apache 2.0 开源。

⭐ 36.5K Stars Apache 2.0 Python + Next.js v1.5.14
一句话结论

适合需要个性化终身学习的教师、研究者和自学者；需要快速问答机器人的用户请绕行——DeepTutor 是深度学习工作台，不是聊天机器人。

⭐ 36.5K Stars · HKUDS 港大数据科学实验室出品 · 多引擎 RAG + 本地模型 + Skills + 长期记忆

DeepTutor 区别于普通问答机器人的核心在于：你拥有自己的教材和笔记。它将这些材料注入知识库，深度解题把推理过程一步步拆开；自动出题批改生成对症练习；复杂主题自动调研整理成结构化报告；抽象概念转成图表、动画、互动内容；记住你的进度和薄弱点，动态调整学习路径。支持 LlamaIndex、GraphRAG、LightRAG、PageIndex、Obsidian 等多种 RAG 引擎，以及本地模型、Skills 和长期记忆，Docker 自托管。

1

安装部署

推荐使用 PyPI 安装（需要 Python 3.11+ 和 Node.js 20+）。也支持 Docker、源码和 conda 方式。

方式 A · PyPI（推荐）
pip install deeptutor
deeptutor init
deeptutor start
Python 3.11–3.13 + Node.js 20+
方式 B · Docker
docker run -p 18792:18792 ghcr.io/hkuds/deeptutor:latest
一键部署，无需配置
方式 C · 源码
git clone https://github.com/HKUDS/DeepTutor
cd DeepTutor
pip install -e . && deeptutor init && deeptutor start
开发版，需自行配置
方式 D · conda
conda create -n deeptutor python=3.11
conda activate deeptutor
pip install deeptutor
隔离 Python 环境

安装后访问 http://localhost:18792。配置文件位于 data/user/settings/，可通过 DEEPTUTOR_HOME 环境变量自定义路径。

2

核心功能

💬

Chat · 深度辅导

接入知识库，调用工具、写笔记、咨询子 Agent，全程保留上下文。支持 deep_solve 逐步推理。

📖

Book · Living Books

将知识库转为互动阅读环境，章节含文字、测验、动画、概念图，每页有独立 Page Chat，可导出 Markdown。

📝

Quiz · 自动出题

根据薄弱点自动生成练习题，批改后动态调整学习路径，追踪进度和错题本。

🔬

Deep Research

复杂主题自动调研，整理成结构化报告，生成可视化图表和数学动画。

🧠

Memory · 三层记忆

L1 工作区镜像，L2 人工整理事实，L3 跨表面综合。全透明可审计，不依赖黑箱向量数据库。

🔌

Skills + MCP + CLI

支持 SKILL.md 技能、MCP 服务器、CLI 工具。EduHub 社区技能库一键导入，Agent-Skills 格式通用。

3

多引擎知识中心

知识库是 DeepTutor 的核心，支撑 Chat、Co-Writer、Book、Partner 等所有模块。

引擎类型适用场景
LlamaIndex本地向量 + BM25（默认）通用场景，开箱即用
PageIndexHosted，推理检索需要页级引用溯源
GraphRAG知识图谱复杂关系推理
LightRAG轻量图谱快速部署
Obsidian本地笔记库已有 Obsidian 用户
Tencent IMAIMA 库腾讯生态用户

文档解析支持：Text-only、MinerU、Docling（支持远程模式）、markitdown、PyMuPDF4LLM、LiteParse。

4

CLI 命令参考

命令说明
deeptutor init初始化工作区配置
deeptutor start [--home PATH]启动前后端（完整界面）
deeptutor serve [--port PORT]仅启动后端 FastAPI
deeptutor run "capability"单次运行（chat/deep_solve/quiz/deep_research/visualize）
deeptutor chat交互式 REPL
deeptutor kb list/create/add/search知识库管理
deeptutor skill search/install/listSkills 管理（支持 eduhub: 前缀）
deeptutor partner list/create/start/stopIM 连接 Partner 管理
Agent 接入提示：将根目录 SKILL.md 交给 Claude Code / Codex / OpenCode，它们会自动识别 deeptutor 工具界面。完整接入文档：deeptutor.info/docs/cli/agent-handoff
