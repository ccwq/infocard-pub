01
IDENTITY

它究竟是什么？

不是提示词模板，而是一个经过导演思维编排的自动化视频生产工作流。

产品形态

Codex 可安装 Skill

以 $directing-stickman-videos 启动，在 Codex 对话内完成全部流程，不需要独立应用或网页界面。

核心输入

一段文字 / 笔记 / 文章

用户粘贴任何形式的原始材料，Skill 提取核心信息、重构叙事弧线，再生成导演方案和提示词包。

生成目标

Gemini Omni Flash

六段独立提示词，每段约 10 秒视频片段，全部使用 Gemini Omni Flash 模型；最后缝合为一分钟完整视频。

02
TWO THEMES · THREE FORMATS

视觉系统与画面比例

同一份内容，可以选择完全不同的视觉语言和构图方向。

Light Theme

白底 · 黑火柴人

白色画布配黑色简笔人物，加上饱和强调色；适合教学、说明、演示类内容。

Dark Theme

黑底 · 白火柴人

黑色画布配白色简笔人物，对比更强烈；适合动机故事、视觉冲击力强的叙事。

9:16 · Shorts

竖屏构图

适合 YouTube Shorts、TikTok、Instagram Reels；强调纵向深度、中心剪影、堆叠揭示。

16:9 · 横向

宽屏构图

适合 YouTube 解释类视频、教程、视觉随笔；强调横向镜头运动与负空间。

1:1 · 方屏

社交信息流

适合社交媒体信息流、紧凑产品故事；强调强中心构图、放射状运动。

最多三色

强调色锁定

每个主题最多三种饱和强调色；所有提示词内的颜色约束保持一致，确保六段视觉统一。

角色锁定

人物一致性

六段提示词各自独立，但都包含角色轮廓、线条粗细、配色方案的完整锁定描述，避免跨段人物走形。

03
WORKFLOW

五步完成生产

每一步都设有确认节点，可以随时回退调整方向。

1
Paste — 粘贴原始材料

任何形式：段落文字、笔记要点、一篇文章、甚至一个话题描述。

2
Choose — 选择比例与主题

pick 9:16、16:9 或 1:1，再 pick Light 或 Dark 视觉系统。

3
Approve — 确认导演方案

Skill 先展示一份六场分镜方案：英文旁白英词数、BGM/SFX 方向、每场镜头运动、转场方式和视觉隐喻。此阶段必须明确批准后才能进入提示词生成。

4
Generate — 生成六个提示词

当前方案被批准后，Skill 输出六段自包含的 Gemini Omni Flash 提示词，每段 10 秒，含节拍时间表、负向约束和衔接说明。

5
Stitch — 缝合为完整视频

将六段分别生成的视频片段拼接为约 60 秒连贯视频，Skill 提供剪辑顺序、开头结尾匹配和 BGM 衔接指引。

关键设计原则：方案阶段与生成阶段分离；改变比例或主题会触发方案重新编排，而不是机械替换标签文字；每段提示词都重复完整的角色/音色/转场锁定，让片段可以独立生成。
04
WHAT YOU GET

每段提示词包含什么？

不是简单的"生成视频"，而是一份带约束的导演说明。

内容

约 130–150 词英文旁白

对应约 60 秒视频的完整英文配音脚本，包含开场钩子、递进解释和结尾回调。

场景节拍

每 2–3 秒一切

六场分镜，每场含镜头运动方式、视觉隐喻、环境变化、文字时机、互动元素和转场类型。

完整对话

英文字幕 + 参考译文

每场提供精确英文对话文本，以及参考中文翻译，便于对照脚本与画面。

自包含

无需共享上下文

每段提示词都包含角色描述、色板、语音方向、BGM、SFX、转场和负向约束；可以独立生成，不需要参考其他提示词。

衔接设计

开头结尾互相匹配

第一段结尾与最后一段开头有呼应设计，第六段结尾也留下与开头闭合的钩子，方便拼接后观感流畅。

生产锁定

Prompt 内置约束条件

负向约束（Negative Prompt）防止生成不想要的元素；每段独立，避免跨段风格漂移。

05
INSTALL

安装方式

纯 Skill 形式，无需 API Key 或 MCP 配置。

第一步

克隆仓库

git clone https://github.com/kaomei/stickman-video-director.git

第二步

复制 Skill 目录

cp -R skills/directing-stickman-videos "$CODEX_HOME/../.codex/skills/"
或手动复制到 Codex skills 目录。

第三步

启动

在 Codex 对话中输入：$directing-stickman-videos
粘贴你的原始材料，开始工作流。

无需 Gemini API Key、MCP 配置或外部依赖；Skill 运行在 Codex 对话内部，生成提示词后由用户在 Gemini Omni Flash 中手动执行视频生成。
