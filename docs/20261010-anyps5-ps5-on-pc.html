Core Identity

是编译器，不是模拟器

PS5 和 PC 都是 x86-64 架构，CPU 指令完全兼容，无需二进制翻译或指令仿真。

  • 无独立运行时进程
  • 无仿真层或虚拟机

What it does

三个转换步骤

工具链把 PS5 可执行文件「翻译」成 PC 可识别的原生程序：

  • ① Relinker：重链接为原生 ELF/PE
  • ② 系统库替换：PRX → .prx（AnyPS5 开源实现）
  • ③ Shader 转译：RDNA → SPIR-V → Vulkan

01 · Relinker

把 PS5 ELF 变成 PC 原生程序

Relinker（重链接器）是 AnyPS5 的核心组件，位于 core/relinker。它读取 PS5 的 ELF 可执行文件，将其转换为 Linux ELF 或 Windows PE 原生格式。

步骤操作
① --to-intel将 AMD-only 指令替换为 Intel 等价指令（可选，Intel 主机需要）
② RelinkerPipeline按 NID 读取 imports → syscall 检查 → 过滤未用 NID → 构建 SysV dynamic section
③ GuestModuleBuilder转换捆绑模块（bundled modules）为目标平台格式
④ PatcherLinuxElfPatcher 或 WindowsPePatcher 输出最终原生文件
关键概念：NID

PS5 函数不按名字导入，按 NID（Name ID，函数名的哈希值）绑定。Relinker 按 NID 解析 import，OS loader 通过 NID 找对应的 AnyPS5 开源 PRX 库导出函数。

02 · PRX 系统库

用开源实现替换 PS5 系统库

PS5 游戏依赖大量系统 PRX 库（类似 DLL），AnyPS5 在 core/libs/prx 提供了开源实现，编译为 .prx 共享库。这些库不含 PS5 专有代码，纯粹是重新实现相同接口。

如何导出函数

使用 APS5_EXPORT("<nid>", func) 宏将函数按其 NID 导出。未知的 NID 直接用字符串标识。Loader 按 NID 绑定 import 调用。

导入类型含义结果
implemented有开源实现✓ 正常调用
stub有导出但调用即抛异常⚠ 运行时报错
absent无导出 → Loader 失败✗ 启动失败
module标题自带库⚠ 需用户提供
03 · Shader 重编译器

RDNA Shader → SPIR-V → Vulkan

游戏 GPU Shader 是 PS5 的 RDNA 架构指令，PC 用 Vulkan，两者不兼容。AnyPS5 的 Shader 重编译器把它转成 SPIR-V（跨平台 GPU 中间表示），再交给 Vulkan 管线渲染。

Shader 编译管线

RDNA 字节码 → 控制流图构建 + 结构化分析 → RDNA → 中间表示（IR）→ SSA 优化 + 资源绑定处理 → SpirvBackend 输出 SPIR-V → （可选）SPIRV-Tools 校验优化 → Vulkan 管线创建。

命令缓冲执行

游戏发出命令缓冲（DCB / ACB）→ libSceAgcDriver / Submit → PM4 封包执行（状态设置 / 绘制 / Compute dispatch）→ 编译变体缓存（内存 + 磁盘 ShaderDiskCache，二次启动复用）。

Usage

上手指南

输入要求

干净的 PS5 ELF 可执行文件 + 捆绑模块放在 sce_module/（或 sce_modules/、prx/，三者不可同时缺少）。

场景命令
Linuxrelinker source/input.elf app.elf
Windowsrelinker --windows source/input.elf app.exe
Intel 主机加 --to-intel
Windows GUI加 --windows-gui
诊断依赖加 --windows-diagnostics
输出布局

app.elf / app.exe + libs/*.prx（AnyPS5 系统库） + app0/（资源 + 转换后模块）。

❗ 常见错误：Error 193

Windows error 193 = 找不到 DLL。你的 libs/ 里放错文件了——必须放 AnyPS5 的 .prx，不是 PS5 原版 .prx！

❗ Windows 内存限制

单标题最多 13,824 MiB 直连内存，Windows 系统会全额 commit，需要页面文件够大，否则报错。Linux 无此限制。

未用导入过滤（unused-filter）

0=保留全部   1=控制流+GOT 分析过滤   2=严格分析+压缩 PLT（不支持即报错）。

Exit Code含义
