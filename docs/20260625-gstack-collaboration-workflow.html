01 Token 最大化 — 用算力买回生命时间

⚡ 什么是 Token 最大化

定义：不计成本消磨算力与 Token，换取全面、深度的极度完整成果。

实质：用 Token 买回时间 — 向机器借用时间以延伸个人生命价值。

核心原则：消除对 Token 成本的吝啬。每日在算力上的投入，是换取超高生产力最划算的资产投入。

✗ 传统观念

  • Token 是成本，要压到最低
  • 一次性指令 + 最小上下文
  • 追求"差不多就行"
  • 人类手工补全低效环节

✓ Token 最大化

  • Token 是投资，追求 ROI
  • 全量上下文 + 深度迭代
  • 追求极度完整的成果
  • 机器包揽脏活，人类专注价值
💡 关键洞察

Garry Tan："每天花 2 美元在 Claude Code 上，远比雇实习生便宜，而且它不请假、不出错、24 小时待命。"

02 人置于环路 — 机器做脏活，人类控价值
规划阶段：CEO 审查 + 董事会时间
启动时先问：目标用户是谁？核心价值是什么？机器可以规划，但方向必须人类注入
设计审查：体验 × 工程双重门
涉及 UI 或开发者调用时，前置进行体验审查与工程审查 — 机器画图，人类把关
状态建模：先画上下文，再写代码
让 AI 在写代码前先画出数据流、用户动线及状态机 — 预载完整上下文，消除随机幻觉
执行：AI 角色演练（CEO/设计/开发/测试）
让 AI 同时扮演多重角色，人在每个角色切换节点做最终判断
验证：Playwright 自动化测试（80-90% 覆盖）
封装 Playwright 测试框架，保持 80%–90% 最佳覆盖率 — 机器验证，人类读报告

✗ 纯 AI 自主

  • AI 全权决策，人类旁观
  • 无边界探索，成本失控
  • 缺乏主观价值判断
  • 结果不可解释

✓ 人置于环路

  • 人类把控方向，AI 执行细节
  • 明确"非确定性"边界
  • 全局理解 + 核心需求注入
  • 主权保障：基于开源自建
03 伪技能与逻辑密度 — 重新定义生产力

📋 伪技能 = 执行清单

用自然语言 Markdown 编写非确定性意图 — 这不是"技能"，而是给 AI 助手的执行清单。

  • 格式：Markdown 结构化任务
  • 优势：人类可读、可版本化
  • 本质：用自然语言定义边界
  • 效果：减少 AI 随机发散

📊 逻辑密度衡量生产力

衡量生产力的核心不是代码行数（LOC），而是逻辑上的有效代码密度。

  • 原始 LOC 会被 AI 膨胀
  • 逻辑行 = 有意义的变更量
  • 11,417 逻辑行/天 = 810× 基准
  • 质量 > 数量，密度 > 体积
📐 技术约束原则

明确划分大语言模型处理的"非确定性范围"与 传统代码处理的"确定性 API 范围" — 让 AI 做它擅长的，让确定性代码做它可靠的。

05 主权保障 — 基于开源工具自建专属 AI 系统

🔐 为什么必须自主可控

数据主权：自己的代码、需求文档、提示词不能放到第三方服务器。

提示词主权：提示词是核心竞争力，必须私有化管理和迭代。

技术主权：基于开源工具链（Claude Code / Codex / nanostack）搭建，不依赖单一平台锁定。

✅ 推荐工具链

  • Claude Code / Codex CLI
  • nanostack（轻量级多代理）
  • GStack（YC 虚拟工程团队）
  • OpenClaw（Peter Steinberger）
  • nanostackconductor

🔧 关键基础设施

  • MCP（Model Context Protocol）
  • git worktree（并行隔离环境）
  • Playwright（自动化质量验证）
  • CLAUDE.md（项目宪法）
  • DESIGN.md（设计契约）
