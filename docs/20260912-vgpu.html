先判断：vgpu 解决的是哪一个问题？

如果你只需要完整场景图、模型加载、材质与后处理，成熟 3D 引擎仍然更直接；如果你要的是 Shader、粒子、流体、GPU Compute、Tensor 或数学可视化，vgpu 把常用 WebGPU 样板压缩成可组合入口。

适合：效果 / Compute / Shader

  • Fullscreen effect、Raymarching、流体、粒子
  • 显式 pass、target、frame 组合
  • 需要控制 bundle 预算

适合：跨运行时验证

  • 浏览器里渲染
  • Node + Dawn 做 headless GPU
  • Mock adapter 跑无 GPU 测试

不等于：完整 3D 引擎

  • 不自动替你组织 scene graph
  • 模型、材质、后处理仍需自己选模块
  • 浏览器仍需 WebGPU 支持

01 / 安装与类型
# 官方 README 使用 pnpm；项目要求 Node >=22 <23 pnpm add vgpu pnpm add -D @webgpu/types
02–04 / Browser 最小路径
import { clock, init, effect, frameLoop, surface } from "vgpu"; import waveShader from "./wave.wgsl"; const gpu = await init(); const canvasSurface = surface(gpu, canvas, { dpr: [1, 2] }); const wave = effect(gpu, waveShader, { set: { speed: 2 } }); const time = clock(gpu); frameLoop(gpu, (frame) => { wave.set({ time: time.time }); frame.pass(canvasSurface, wave); });
验收点：init() 只建立一个 Gpu context；后续入口都把它作为第一个参数。surface() 管理 canvas target 和 DPR，effect() 编译 fullscreen shader，frame.pass() 显式提交绘制。

WGSL 不再是孤立字符串

把 shader 拆成可以 import / export 的模块，构建阶段处理绑定、类型与 layout，减少手写声明错位。

模块化写法

// grain.wgsl import { hash2 } from "@vgpu/wgsl-std/hash"; export fn grain(uv: vec2f, time: f32) -> f32 { return hash2(uv * time).x; }

为什么重要

复用math / color / sampling / noise
类型WGSL reflection 对齐 binding
边界仍需理解 WGSL 与 GPU 资源模型

不要只在浏览器里“看起来能跑”

Node / Dawn

用 vgpu/node 创建 headless device，创建 256×256 target，执行 frame pass，再读取 pixels。

import { draw, frame, init, target } from "vgpu/node"; const gpu = await init(); const out = target(gpu, { size: [256, 256], format: "rgba8unorm" }); const tri = draw(gpu, { shader }); frame(gpu, f => f.pass(out, tri)); const pixels = await out.read(); gpu.dispose();

Mock / CI

vgpu/mock 提供确定性软件 adapter。同一套代码可以在没有真实 GPU 的测试环境里执行，适合把 shader / compute 纳入 CI。

无 GPU 测试确定性回归检查

把 Agent 当成文档操作员，而不是魔法编译器

官方把文档、示例检索和 shader 检查做成 CLI；这才是“Agent-ready”的可执行部分。

查文档 / 找案例 / 拉源码

npx vgpu docs cat getting-started.md npx vgpu docs find effect npx vgpu examples search "raymarching" npx vgpu examples pull <id> --out ./example

写完再检查

npx vgpu check ./shader.wgsl npx vgpu mcp npx vgpu mcp --project-from-cwd

公开文档还提供 agents.md、llms.txt、只读 Examples API 与 MCP endpoint；本卡不把远程服务可用性等同于本地已验证。

现实边界：公众号文章的“25KB”来自官方 README 的 gzip budget；它不是所有项目、所有 shader、所有 runtime 的固定包大小。默认分支是 canary，当前稳定 release API 返回 v0.4.1；安装时应以官方发布页和包版本为准。

选择路径

只做浏览器效果vgpu + surface / effect / frameLoop
要跑服务端 GPUvgpu/node + Dawn + target.read()
要进 CIvgpu/mock 先做确定性回归
要让 Agent 接手CLI docs + examples + check + MCP
要完整 3D 产品先评估成熟引擎，不要只因 25KB 就替换
