选型建议
选 Hermes

快速网页截图/填表/内容抓取

配合 AI 对话完成，不需要额外安装

需要 browser_vision 视觉分析能力

需要 browser_cdp 底层 CDP 调用

选 agent-browser

Claude Code / OpenCode / Cursor 集成

需要精细控制页面操作

多标签页管理、录屏等高级功能
