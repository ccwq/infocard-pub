项目概览
是什么

首个 C++ 源码级 Chromium 反检测浏览器。通过直接修改 Chromium C++ 源码并重新编译二进制，内置 57 个源码补丁，让浏览器指纹从底层就呈现为真实 Chrome，网站无法通过任何 JS 或 CDP 手段检测注入行为。

核心优势：一行代码替换 Playwright，完全兼容现有 Playwright 脚本，零迁移成本。

技术原理

直接修改 Chromium C++ 源码，重新编译二进制——这是与所有现有方案的代差核心：

• 57 个源码补丁让 Canvas / WebGL / TLS / Navigator 等指纹从底层就是"真实 Chrome"
• 无需任何 JS 注入，网站无法通过 CDP 检测注入行为
• 二进制固定，Chromium 版本更新后不易失效，维护成本极低
• 自动匹配代理 IP 时区和语言，时区伪装无需手动配置
