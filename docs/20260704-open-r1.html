TRAINING METHODS
两种训练方法
SFT

监督微调（Supervised Fine-Tuning）

用 R1 蒸馏的高质量思维链数据（CoT）对齐 GPT-4o/Claude 级别的推理质量。基于 Qwen2.5-Math-7B-RoPE-300k，5 epoch，lr=4e-5，max_seq=32768。

GRPO

组相对策略优化（Group Relative Policy Optimization）

DeepSeek 原创的 GRPO 是 PPO 的简化变体：对同一问题采样多组 response，按 group 相对 reward 排序更新策略，无需单独的价值网络，大幅降低训练成本。

DATA PIPELINE
数据生成流水线
数据源

NuminaMath-TIR / OpenR1-Math-220k

从 NuminaMath-TIR（数学竞赛难题）提取题目，作为 prompt 输入给 R1 生成带思维链的解题过程。

合成工具

Distilabel（Argilla）

开源数据标注 + 合成流水线，支持 vLLM backend，每个 prompt 生成 4-64 个 response（温度 0.6，top_p 0.95，max_tokens 8192-32768）。

过滤

Data Decontamination

用 8-gram 哈希去重训练集中与评测基准重叠的题目，防止数据泄露导致虚高的基准分数。

输出

思维链轨迹（Traces）

每个样本 = prompt + reasoning（含反思/回溯）+ final answer + reward signal，保存为 HuggingFace Dataset 格式。

EVALUATION
四大评测基准与结果对比

# GRPO 核心原理（简述）
# 1. 对同一 prompt 采样 G 个 response（如 G=16）
# 2. 计算每个 response 的 reward（如答案正确性）
# 3. 用 group 内相对排名更新策略：reward 高的 response 概率 ↑
# 4. 不需要单独的价值网络（Critic），比 PPO 轻量得多

DATA GENERATION · 用 Distilabel 生成合成数据（pipeline.py）
# 安装依赖
$ uv pip install "distilabel[vllm]>=1.5.2"

# pipeline.py（保存到项目根目录运行 python pipeline.py）
from datasets import load_dataset
from distilabel.models import vLLM
from distilabel.pipeline import Pipeline
from distilabel.steps.tasks import TextGeneration

prompt_template = """\
You will be given a problem. Please reason step by step, \
and put your final answer within \\boxed{}:
{{ instruction }}"""

dataset = load_dataset("AI-MO/NuminaMath-TIR", split="train").select(range(10))
model_id = "deepseek-ai/DeepSeek-R1-Distill-Qwen-7B"

with Pipeline(name="distill-qwen-7b-r1", description="...") as pipeline:
    llm = vLLM(model=model_id, tokenizer=model_id,
        extra_kwargs={"tensor_parallel_size": 1, "max_model_len": 8192},
        generation_kwargs={"temperature": 0.6, "max_new_tokens": 8192})
    text_generation = TextGeneration(llm=llm, template=prompt_template,
        num_generations=4,
        input_mappings={"instruction": "problem"})
    pipeline.run(dataset=dataset)

# 生成完成后推送到 HuggingFace Hub
$ distiset.push_to_hub(repo_id="username/numina-deepseek-r1-qwen-7b")

FAQ

常见问题解答

Q: GRPO 和 PPO 有什么区别？
GRPO（Group Relative Policy Optimization）是 DeepSeek 提出的 PPO 简化版：对同一 prompt 采样一组 response（G 个），按组内相对 reward 排名更新策略，不需要单独的价值网络（Critic），训练成本大幅降低，稳定性更好。
Q: OpenR1-Distill-7B 和 DeepSeek-R1-Distill-Qwen-7B 哪个更强？
在 MATH-500 上 OpenR1-Distill-7B（94.5%）略超 DeepSeek 报告（92.8%）。AIME2024 上略低（50.8% vs 55.5%），差距在 1-3σ 内，统计上可认为效果对齐。
Q: 为什么评测结果和 DeepSeek 报告有差异？
主要原因是每个 query 的采样 response 数量不同：DeepSeek 对 AIME 用 64 个，MATH-500 用 4 个。响应数量越多 pass@k 估计越稳定，方差越小。OpenR1 的选择与 DeepSeek 一致但随机性仍存在。
Q: 没有 8×H100 还能跑吗？
可以。7B 模型的 SFT 和 GRPO 单×H100 即可（调小 batch size）。32B 以上模型建议至少 8×H100 或用 DeepSpeed ZeRO-3 + gradient checkpointing 降低显存占用。
Q: Step 2（R1-Zero 纯 RL）的难点在哪？
需要大规模高质量的数学/推理/代码数据（不是蒸馏数据），以及设计有效的 reward function。DeepSeek 用了 millions 级别的数据从头 RL 训练，这是最难复现的部分。
Q: DeepSeek-R1 训练配方中最关键的是什么？
DeepSeek 技术报告指出三个核心：① 高质量可验证数据（带答案的数学/代码问题）；② GRPO 组内相对 reward 更新；③ 多阶段课程学习（先 SFT 激活，再 RL 强化）。Open R1 正在逐步复现这三者。
