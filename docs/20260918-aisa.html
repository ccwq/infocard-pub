01
SECTION 核心定位

AIsa 定位：Agent 经济体的统一 API 网关 + 自主支付层。

一句话：换一个 base_url，同时接入 50+ 模型、100+ 数据 API，Agent 可以自己付钱。

三个核心能力：

  • One API key：5000+ 接口，一个密钥全覆盖
  • Weighted routing：自动选择最优模型/接口
  • x402 协议：让 Agent 有自己的钱包，自主支付

02
SECTION 技术架构

三层架构：

  • Layer 1：Unified API Gateway（OpenAI-compatible /v1/chat/completions）
  • Layer 2：Weighted routing + Auto retries + Per-call metering
  • Layer 3：Agent Skills（42 可安装技能包）

支持协议：

  • OpenAI-compatible：SDK 直接换 base_url
  • A2A Agent Card：机器可读的服务发现
  • MCP（Model Context Protocol）：Claude Desktop / Cursor
  • x402：自主支付标准

09
SECTION 自主支付（x402 协议）

x402 = 机器可读的支付协议。

工作流：

  1. 用法币或 USDC 给 AIsa 钱包充值
  2. Agent 通过 x402 自主发起支付
  3. 每个端点都支持按调用量计费

核心价值：Agent 可以自己付钱，不需要人类介入小额支付（API 调用费）。

SECTION OpenAI-compatible 的实际含义

AIsa 的 OpenAI-compatible 完全兼容现有 SDK：

import openai

client = openai.OpenAI(
    api_key="YOUR_AISA_API_KEY",
    base_url="https://api.aisa.one/v1"
)

response = client.chat.completions.create(
    model="claude-sonnet-4-20250514",
    messages=[{"role": "user", "content": "Hello"}]
)

优势：无需修改应用逻辑，模型按调用量计费，无月费。

18
SECTION 适用边界与竞品对照

适用场景：

  • 需要多模型路由（Claude / GPT / Gemini / Qwen 随时切换）
  • Agent 需要自主获取外部数据（社媒/金融/搜索）
  • 需要自主支付能力（x402）
  • VibeCoding 场景下的快速 API 接入

不适用场景：

  • 只需要单一模型（直接用官方 API 更便宜）
  • 大批量稳定生产（供应商直签可能有折扣）

关键优势：250,000+ Agent 已在 AIsa 上运行，平台生态成熟。
