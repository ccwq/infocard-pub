最强 DeepSeek Harness 视觉插件，让纯文本模型拥有"看图"能力。

DeepSeek-V4、GLM 等主流模型是纯文本模型，无法直接理解图片。ModLens 是外挂视觉引擎，粘贴图片即可识别，无需先保存文件再传路径。它输出结构化 JSON：OCR 全文转录、阅读顺序版面区域、实体和关系列表——给模型具体证据，而不是让它凭印象瞎猜。

CORE FEATURES

为什么 ModLens 是纯文本模型的视觉外挂首选

不是返回图片描述，而是输出 OCR 文字、版面区域（按阅读顺序）、实体和关系列表。模型引用具体细节，而不是泛泛而谈。

🔌 一条命令装进 dsh

DeepSeek Harness 用户一条命令完成安装和配置，插件自动发现所有纯文本 DeepSeek/GLM 路由，为每个添加 (modlens vision) 包装项。

⚡ 零配置，零 daemon

无需本地代理 daemon、无需修改任何 harness 配置、不装任何钩子。卸载只需删除文件夹，一切恢复原状。

🌍 免费 Gemini 起步

复用机器上已有的 multimodal 模型。没有任何配置？Antigravity CLI 提供免费 Gemini 通道，5-10 秒完成一次图片读取。

INSTALL

安装方法

一条命令装入 DeepSeek Harness / 作为 Skill 注入各 Agent

# DeepSeek Harness（dsh）安装
npx -y @deepseek-ai/dsh plugin --profile web add @liustack/modlens@3.20.0

# 更新同一条命令（版本号命名防止 pnpm 11 缓存 24h 旧版本）
# 卸载：删除插件目录即可
作为 Skill 注入其他 Agent：发送以下命令给 Claude Code / Codex / OpenCode / Pi，它们会自动安装 ModLens skill 并接管视觉调用：
npx -y @deepseek-ai/dsh plugin --profile web add @liustack/modlens@3.20.0

NOTES & LIMITS

使用注意与限制

了解边界才能用好这个插件

🔒

依赖视觉引擎 API

ModLens 本身免费，但需要视觉引擎后端（Gemini/OpenAI/Anthropic）。免费 Gemini 有配额限制，高频使用需申请付费 key。

📦

仅限图片输入

ModLens 是视觉插件，不处理视频、音频或 PDF 页面；PDF 需截图后粘贴。

🧩

宿主兼容性

需宿主 Agent 支持 skill/plugin 扩展机制；老版本 Agent 可能不支持。
