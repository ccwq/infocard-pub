法律分析：欺诈性抚养
姜洪涛的三项诉求

• 撤销房产赠与：离婚协议中对长子的房产赠与并非基于真实亲子关系。

• 返还抚养费：22年抚养、教育、生活成本，均建立在错误的亲子认知之上。

• 精神损害赔偿：长期欺瞒、亲属联手、子女辱骂，构成巨大的精神创伤。

律师观点

• 这是典型的欺诈性抚养，并非普通婚内出轨纠纷。

• 私下亲子鉴定可作为个人证据参考，但司法认定仍以法院委托鉴定为准。

• 若存在故意隐瞒、共同转移财产、侵害父母权益等行为，法院可综合衡量责任。
