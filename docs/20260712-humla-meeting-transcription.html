本地优先，隐私可控

Humla 的核心设计原则：音频数据由你决定流向，不强制上云。

方式一

本地 Whisper 转写

Tauri 构建（Rust + Swift），Whisper 本地运行，音频永远不出电脑。macOS 13+ 系统要求。

方式二

OpenAI / Speechmatics

也可接入 OpenAI Whisper API 或 Speechmatics 云端服务，由你选择是否上云。

Granola 启发

AI 会议纪要

笔记与 AI 生成的纪要左右对照，两路录音谁说了什么一清二楚，不依赖任何会议软件。

两路录音 + 说话人区分

Humla 的核心 UX：笔记和 AI 纪要同步展示，不遗漏任何细节。

不依赖任何会议软件：不加入任何在线会议，直接录你自己的麦克风输入，单独录制参会者的声音通道。
功能说明
两路独立录音分别录制你自己的输入和参会者，两个通道完全独立
说话人区分自动识别两个通道的说话人，标注"我"和"对方"
notes 侧边栏原始转写文字，两路各自显示
summary 面板AI 生成的会议摘要、关键结论和 action items
per-note presets每个笔记可设置不同的 AI 摘要预设，灵活适配不同会议类型
