核心交付
02

两类结果

  • 文本摘要：标题与单行摘要。
  • YAML 格式化：优化版与未优化版。
  • 两版结果均需可被标准解析器解析。
文本摘要规则

标题生成

字数不超过 32 字，精准概括主题。

单行摘要

纯文本、不换行、不超过 240 字，首句即提供价值信息。

YAML 双版本策略
版本处理方式边界
未优化版保持原始逻辑与文本，仅做结构化编排。不额外补充目标、约束或最佳实践。
优化版在原始语义基础上补充目标、约束与最佳实践。合理推断必须服务于结构完整性，不得改变原意。

  将用户输入结构化为规范YAML，并补充合理细节

  semantic_integrity: 保持原始语义，不臆断
  parser_compatibility: 确保标准解析器可加载
  max_depth: 3层以内
best_practices:
  - 合理推断缺失目标，并标注推断项
  - 特殊字符使用单引号
  - 多行内容使用竖线语法
质量边界
不臆断：补充内容只能改善结构、约束和可复用性，不能虚构用户未提供的事实。
不混淆：优化版的新增字段与原始输入应可区分。
可解析：输出必须遵循 YAML 语法，避免缩进错误、未转义特殊字符和多文档歧义。
