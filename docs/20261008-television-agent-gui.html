一句话定位

Agent 能力已是 GUI 时代，交互却停在 MS-DOS。Television 把"一块屏幕"还给 Agent，用三件套让 artifact 持续可见、可持续修改、可持续回访。

01
为什么需要 Television

Agent 能力已经是 GUI 时代，交互却停在 MS-DOS

Claude Code 团队、Karpathy、Sam Altman、a16z 都在讨论：LLM 驱动的应用需要超越无限滚动文本流的界面。

聊天流问题界面断点

聊天流淹没 artifact

Agent 生成一份报告、一张图、一个网页——然后下一轮对话把它推到聊天深处再也找不回来。artifact 没有持久化，修改历史丢失。

  • 文档/图表/网页 → 一次过，不可持续
  • 多轮修改 → 无法回溯版本
  • 长期项目 → 信息碎片化
业界共识新隐喻

界面隐喻变革正在发生

Claude Code 团队博客、Karpathy、Sam Altman、a16z 都在讨论：LLM 时代需要超越"无限滚动聊天"的可视化界面，让 AI 输出真正可操作、可协作。

  • Claude Code 团队：GUI 化是 Agent 标配
  • Nous Research 已向 250+ 人 demo
  • 固定应用 → Skills 按需生成界面

S

server · 轻量常驻

装在 agent 同机，处理 agent 与 TV 客户端之间的通信。`tv serve --persist` 常驻，Node.js 24 + npm 11。

B

skills bundle · 指令集

安装时自动安装，教 agent 怎么创建和修改 artifact。agent 常会主动上屏，也可手动说「put that on my TV」。

C

client · 可视化界面

macOS 有 Electron 应用；任意平台可浏览器访问。Electron 版可加载外部网页（iframe），与 Web 应用交互。

03
Artifact 与 Channels

持久 · 可塑 · 可交互

Artifact 从静态可视化到可编辑文档到完整 vibe-coded web app；Channels 提供持久空间来收集、排列和回访。

持久

不像聊天记录

artifact 独立存在，不被后续对话淹没，持久化保存。

dashboard / 在线研究 / 长周期项目 / 文档协作

可塑

可持续修改

同一 artifact 可以在多轮对话中持续更新和迭代。

Agent 主动修改，或用户指令触发更新

可交互

不只是展示

形态从静态可视化到可编辑文档到完整 vibe-coded web app。

用户可以直接与 artifact 交互

Channels

持久空间组织

按 channels 组织 artifact：收集、排列、回访，形成持久工作空间。

类似标签页但不依赖聊天会话

适用场景

凡是不适合无限滚动文本流的任务

  • Dashboard：多指标持续展示
  • Agentic Coding：代码结构持续可见
  • Online Research：网页/数据持续追踪
  • 长周期项目：artifact 跨会话保持
  • 文档协作：与 agent 共同编辑
  • 与 Web App 交互：Electron 加载外部网页
不适合场景

Television 不是聊天替代品

  • 即时问答：直接聊天更高效
  • 简单指令：无需可视化
  • Windows：暂不支持
  • 无 skills 能力的 harness
04
安装三路径

macOS / 浏览器 / 源码

三种安装方式覆盖主流场景：macOS 直接下载应用、非 Mac 用实验性浏览器界面、或从源码构建。

路径 1 · macOS

直接下载应用

下载 macOS Electron 应用，安装后启动会引导连接 agent。最简单的方式。

  • 下载 macOS .dmg 安装包
  • 启动后自动引导连接 agent
  • 与聊天界面 sidecar 并存
路径 2 · 浏览器

实验性浏览器界面

非 macOS 用户的替代方案。贴下面这句话给 agent，它会帮你安装好并给出 URL。

路径 3 · 源码

从源码构建

需要 Node.js 24 + npm 11，git clone 后构建。

// 路径 2：给 agent 贴这句话，它会引导安装（非 macOS）
Read the entire Television admin guide at https://television.run/install.md and help me get Television installed.
git clone https://github.com/telepath-computer/television.git
# 需要：Node.js 24 + npm >=11.5 <12
cd television && npm install
npm run build
npm run link
# 常驻服务
tv serve --persist
⚠

✓

Electron 特殊能力

Electron 版可加载外部网页（iframe），可直接与 Web 应用交互。

05
官方 Skills 生态

可复用指令，按需生成界面

Skills 是可复用的指令集（可分享），官方已内置多个开箱即用的 Skills，每个 Skill 自动生成对应的可视化 artifact。

Calendar官方 Skill

周历 Calendar

从事件、计划、deadline 自动生成周历视图，持续追踪时间线。

  • 自动排版周历格
  • 事件时间线可视化
  • 多轮对话持续更新
Tasks官方 Skill

可勾选 Tasks

生成可勾选的任务列表 artifact，支持点击完成状态切换。

  • 可交互勾选框
  • Agent 持续更新进度
  • 跨会话持久化
Table官方 Skill

Airtable 风格 Table

生成 Airtable 风格的紧凑表格 artifact，适合结构化数据管理。

  • 多列数据表格
  • 紧凑布局
  • 支持多轮数据追加
Skills 可分享：Skills 是可复用的指令集合，用户可以创建自定义 Skills 并分享给他人。官方 Skills 只是起点，社区 Skills 生态正在生长。

总结 · Television 适合谁？

如果你用 Hermes / OpenClaw / Claude Code / Codex 跑需要可视化、持久化、可持续修改的任务——Dashboard、在线研究、长周期项目、文档协作、与 Web App 交互——Television 值得一试。

  • 想让 agent 的输出"上屏"而不是淹没在聊天流里
