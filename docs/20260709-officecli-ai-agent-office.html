01 Key Features · 核心亮点
渲染引擎

内置 HTML 渲染引擎

将 .docx / .xlsx / .pptx 高保真渲染为 HTML / PNG，无需依赖 COM 接口或 LibreOffice。Agent 看到渲染结果后才能精准修改。

公式解析

350+ Excel 函数本地解析

内置公式引擎，覆盖 SUM/VLOOKUP/INDEX/MATCH/XLOOKUP 等 350+ 函数，解析在本地完成，不依赖外部电子表格引擎。

MCP Server

原生 MCP Server 集成

内置 MCP Server，原生对接 Claude Code、Codex、Cursor 等主流 AI Agent 工具链。开箱即用，无需中间层。

路径访问

路径式元素访问

document.tables[0].rows[2].cells[1] 语法，比操作 XML 直观 10 倍。Agent 无需理解 OOXML 内部结构。

模板合并

模板填充 · 一对多

一份模板 + JSON 数据 = N 份定制化文档。批量生成合同、报告、证书，Agent 只需传入数据结构。

Resident Mode

常驻模式 + 批处理

启动常驻进程，多命令复用同一上下文；支持批量处理大量文件，适合报表自动化流水线。

# MCP Server 配置（Claude Desktop / Cursor 等）
officecli mcp --stdio

# MCP settings.json 示例
{
  "mcpServers": {
    "officecli": {
      "command": "officecli",
      "args": ["mcp", "--stdio"]
    }
  }
}

# Direct CLI — Agent 一行命令操控 PPT
officecli ppt create presentation.pptx \
  --template ./template.pptx \
  --data ./report-data.json

# Direct CLI — Agent 读取 Word 文档
officecli doc read contract.docx --format html
03 Three-Layer Architecture · 三层架构
层级组件说明
AI Interface MCP Server / CLI / JSON Output 面向 AI Agent 的标准化接口，输出 JSON 格式结构化数据
Core Engine HTML Renderer / Formula Engine / Template Merge 内置渲染引擎和公式解析，零外部依赖；Round-trip dump 学习现有文档
File I/O Word (.docx) / Excel (.xlsx) / PowerPoint (.pptx) 原生 OOXML 操作，无需 Microsoft Office，跨平台全支持

Round-trip Dump：Agent 可将现有文档 dump 为结构化格式（JSON/Markdown），学习文档风格后再生成新文档。 Resident Mode 允许 Agent 在同一进程内累积上下文，避免每次调用都重新初始化。
