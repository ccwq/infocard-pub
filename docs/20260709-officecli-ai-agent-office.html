01
Core Capabilities

为什么是 OfficeCLI？

传统方式让 AI 写 Python 代码调用 python-docx / openpyxl，改个颜色得重跑一遍。OfficeCLI 让 AI 直接操控文档，看见结果再迭代。

渲染引擎 MCP Server

内置 HTML 渲染引擎

将 .docx / .xlsx / .pptx 高保真渲染为 HTML / PNG，无需依赖 COM 接口或 LibreOffice。Agent 看到渲染结果后才能精准修改——所见即所得的 Agent 版本。

函数解析 本地化

350+ Excel 函数本地解析

内置公式引擎，覆盖 SUM / VLOOKUP / INDEX / MATCH / XLOOKUP 等 350+ 函数，解析在本地完成，不依赖外部电子表格引擎。结果以结构化 JSON 输出。

MCP 原生 Claude Code

MCP Server 原生集成

内置 MCP Server，原生对接 Claude Code、Codex、Cursor、OpenClaw 等主流 AI Agent。开箱即用，零改造，一行配置接入现有 Agent 工作流。

路径访问 模板合并

路径式元素访问 + 模板引擎

document.tables[0].rows[2].cells[1] 语法，比操作 XML 直观 10 倍。一份模板 + JSON = N 份定制化文档，批量生成合同、报告、证书。

02
Architecture

三层架构 · 零外部依赖

单二进制交付，Linux / macOS / Windows WSL 全平台支持，无需安装 Office。

AI Interface

MCP Server / Direct CLI / JSON Output — 面向 AI Agent 的标准化接口，输出结构化数据。

Core Engine

HTML Renderer / Formula Engine / Template Merge — 内置渲染引擎和公式解析，零外部依赖。

File I/O

Word (.docx) / Excel (.xlsx) / PowerPoint (.pptx) — 原生 OOXML 操作，无需 Microsoft Office。

# 三种 Agent 集成方式

# 方式一：MCP Server（推荐）— Claude Desktop / Cursor 等
officecli mcp --stdio

# 方式二：Direct CLI — 任意 Agent 直接调用
officecli ppt create presentation.pptx \
  --template ./template.pptx \
  --data ./report-data.json

# 方式三：路径式 API — Agent 精准操控元素
officecli doc update contract.docx \
  --path paragraphs[0] \
  --bold \
  --color #1a1a1a
03
Comparison

vs python-docx + openpyxl

为什么 AI Agent 应该用 OfficeCLI 而不是自己写 Python 脚本？

对比项 python-docx + openpyxl OfficeCLI
Agent 集成 需写 Python 脚本，3 套格式库 一行命令，3 种格式统一接口
MCP 支持 无，需自行封装 MCP Server 原生 MCP Server，开箱即用
排版预览 需 Excel 或 LibreOffice 才能预览 内置 HTML 渲染，Agent 实时预览
Excel 函数 无，公式原样保留无法计算 350+ 函数本地解析，JSON 输出
路径式访问 XML 节点操作，繁琐易错 document.tables[0].cells[1]，直观自然
Office 依赖 文件层面无依赖 零依赖，单二进制
跨平台 ✅ Linux / macOS / Windows ✅ Linux / macOS / Windows WSL

Use Cases

适用场景

从报表自动化到 Agent 工具链集成，OfficeCLI 让 AI 直接输出专业 Office 文档。

📄 报表自动化

无 GUI 服务器环境，定时生成 Excel 报表、Word 分析报告、PowerPoint 演示文稿，Agent 驱动全流程，零人工干预。

模板 + 数据 JSON = 批量定制化合同、证书、授权书。Resident Mode 高效复用上下文，适合大规模文档生产。

MCP Server 对接 Claude Code / Codex / Cursor / OpenClaw，让 AI 在编程任务中直接输出 Word 文档、Excel 数据表、PPT 演示文稿。
