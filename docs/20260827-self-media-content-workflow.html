5 APPROVAL GATES

强制人工确认，绝不自动群发

工作流在关键节点停下等待人工授权，每一步都有明确的肯定或修改指令。

①
Gate 1
方向确认

目标 · 受众 · 角度是否正确

②
Gate 2
平台确认

选哪个平台，为什么

③
Gate 3
标题确认

标题 / 封面文案审批

④
Gate 4
终稿确认

全文审校，通过后才发布

⑤
Gate 5
发布授权

明确授权后才执行发布

终稿确认 ≠ 发布授权：Skill 默认只创建草稿或手动发布包。即使终稿通过，也不会自动推送到任何平台。每次发布都需要独立的授权动作。

04
EVIDENCE FIRST

关键数字必须带来源

不编造数据、体验、收益、用户评价和测试结果。证据优先，区分事实 / 判断 / 推断 / 建议。

🚫

不编造成果

阅读量、涨粉、转化率、收益承诺 — 所有关键数字必须有来源。无法核实时，明确标注「未经核实」。

📋

区分四类断言

事实（可核验）→ 判断（基于证据的结论）→ 推断（逻辑外推）→ 建议（行动提议），标注清楚，不混用。

🔒

凭据自己保管

WECHAT_APP_ID 等敏感信息仅通过本地环境变量提供，不写入任何会被提交或分享的文件。
