01
CHAPTER · 选题与策划

选题与策划 · 4 个 Skill

视频生产第一步：决定做什么、怎么做。

选题Obsidian 选题卡

ra-选题

选题全生命周期管理。说"灵感 xxx"，在 Obsidian 建一张选题卡；说"深化一下"，去素材库和方法论里找资料写进卡里；说"给我 5 个选题"，拉对标账号近 3 天新作 + 自己号的高互动题材，按流量潜力排序推荐。

  • 说"做成视频"自动路由到视频工作台
  • 一题可同时立项视频 / 图文 / 文章
  • 卡片状态管理整条生产线
策划长片

ra-实操策划

B 站 / YouTube 上 8-15 分钟的实测教程策划稿：测试题组（附可粘贴 prompt）+ 结构时间轴（标注全身出镜段和画中画段）+ 出镜口播稿 + 录屏操作清单。

  • frontmatter status 字段管生产线状态
  • 结构化产出可粘贴 prompt
钩子7 种类型

ra-hook

短视频开头的钩子选型。7 种类型、3 大类（挂在内容上 / 挂在观众身上 / 挂在事件上），每种类型标了前提条件、句型模板和常见错误。

  • 管"选哪种钩子"
  • 写完钩子后由 dbs-hook 诊断质量
标题两段式

ra-video-title

视频标题生成。先锁定这条视频讲的是什么（一句话主题判断），再拆对标账号的标题共性，然后按两段式结构出 8-12 个候选标题，附 Top 3 推荐理由。

  • 洗稿阶段生成，附"标题候选"一节
  • 最终用哪个发布时人工挑，制作端不碰标题
02
CHAPTER · 内容创作

内容创作 · 5 个 Skill

从素材变成可制作的脚本。

调度器全自动

ra-video-wash-pipeline

视频洗稿调度器。给一个视频链接或本地视频文件，自动串起整条流水线：下载 → 提取逐字稿 → 洗稿改写 → 质量检查 → 排入待制作队列。

  • 串 8 个 Skill 一气呵成
  • 一条命令触发，自动串联
内部件Paraformer ASR

ra-逐字稿提取skill

从抖音 / 小红书视频里提取逐字稿。用去水印服务拿到源视频，再跑 Paraformer ASR 转写出带时间戳的文字稿。

  • 逐字稿是内部工作件，不外露
  • 源信息只存在选题卡和隐私区
5 道工序洗稿

ra-洗稿

拿到逐字稿后改写成新视频脚本。内部自动串：ra-人话 去 AI 味 → dbs-ai-check 扫 AI 痕迹 → dbs-hook 诊断钩子 → dbs-resonate 检查情绪共鸣 → ra-video-title 出标题候选。

  • 五道工序串完输出交接稿
  • 丢进待制作队列
硬禁清单去 AI 味

ra-人话

所有面向公众的中文稿件都过一遍它。硬禁清单：禁二元对比壳（不是 A 而是 B）·禁"真正/其实/本质上"伪洞察标记 · 禁冒号讲义腔 · 禁空泛焦点转移（更值得关注的是）。

  • 本帖原文就是用它的规则写的
  • 中文写作的统一守门人
公众号标准库

ra-公众号提取

从微信公众号链接里提取文章全文。用 MicroMessenger UA 绕过微信的第一层访问控制，拿到纯文本。不需要 API key，标准库就能跑。

  • 洗稿或选题需要读公众号文章时调它
  • 拉下原文交给下游 Skill

CHAPTER · 视频下载

视频下载 · 2 个 Skill

把互联网上的视频拉到本地。

主力下载多平台

ra-video-download

支持抖音 / YouTube / B 站 / Twitter(X) / 小红书。底层 yt-dlp，抖音优先走 TikHub 拿无水印源。

  • 下载默认存隐私区 .internal/
  • 不进成稿 / 不进归档 / 不进公开文档
辅助下载字幕烧录

xiaohu-video-download

  • 海外视频翻译场景用它比较多
  • 音频 + 字幕批量处理
04
CHAPTER · 配音

配音 · tts-skill（本地 IndexTTS2）

固定声线 + 速度契约 + 严守"不偷偷换云端"硬门。

核心约束：每次渲染留 voice_manifest.json，记录声线、参考文件 SHA-256、速度倍率、有没有 fallback。成片禁止任何云端 TTS fallback —— IndexTTS2 跑不起来就修环境，不偷偷换。
本地克隆IndexTTS2

tts-skill

本地 IndexTTS2 声音克隆，固定用作者录的无损 WAV 声线参考，平静语气，atempo=1.12 保持音高提速。

  • 数字人音频从这里出
  • 先出试听版，确认后才允许上传 HeyGen
硬契约不偷偷换

声音可追溯

voice_manifest.json 记录：声线 ID / 参考文件 SHA-256 / atempo 速度倍率 / fallback 状态。IndexTTS2 失败 → 修环境，禁止云端 TTS fallback。

  • 可追溯到具体声线
  • 角色一致性不被悄悄破坏

CHAPTER · 数字人

数字人 · heygen-digital-avatar

CLI OAuth + 付费前必先有用户确认的试听音频。

HeyGenDigital Twin

heygen-digital-avatar

HeyGen 数字人的生成和合成。默认用作者训练的 Digital Twin（黑 T 坐姿），圆形裁切放在视频左下角。

  • CLI OAuth 走网页套餐额度
  • 管认证 / 人物选择 / 生成参数 / 画面合成
硬门试听确认

付费前必先确认

硬门：付费生成前必须先有经过用户确认的试听音频。音频改了，确认失效。

  • 防止数字人声音不一致
  • 音频链路断开可自动复位

CHAPTER · 视频编辑

视频编辑 · 3 个 Skill

真人口播默认剪辑 · 通用编辑 · AI 剪口播。

默认剪辑口播

ra-local-talking-head-cut

真人口播的本地粗剪。火山引擎 ASR → 剪前校对 SRT + 不确定术语 → 停下等用户确认（确认前不动剪刀）→ 语义删减 → 压缩停顿 380-450ms → 保持源分辨率 + 帧率 → 响度 -16 LUFS → 逐切点视觉检测 → 最多 3 个克制转场。

  • MP4 还要再跑字幕 QC
  • 字幕没过不算完
通用多 take 选优

video-use

通用视频编辑 Skill。转写、剪辑、调色、叠加动画、烧字幕，什么类型的视频都能处理。

  • 与 ra-local-talking-head-cut 配合
  • 粗剪用 ra-local，多 take 证据从 video-use 获取
AI 剪FCPXML

AI剪口播

口播视频的转录和口误识别。用火山引擎转写，AI 标出口误，生成审查稿和删除任务清单，支持导出 FCPXML 给剪映或 Final Cut Pro。

  • 精细调整场景从粗剪接剪映
  • FCPXML 是交付契约
07
CHAPTER · 字幕

字幕 · 时间戳 + 外观两层

字幕分成时间戳和外观两层，各管各的；QC 不过就停。

时间戳火山 Doubao-ASR

ra-audio-to-subtitles

拿最终音频跑火山 Doubao-ASR，输出词级时间戳。产物 captions_words.json / captions.json / captions.srt。

  • 自动检查英文术语被拆碎 / 孤立碎片 / 连接词跨屏 / 阅读速度超标
  • 结果写 caption-qc.json，QC 没过就停不往下走
  • 硬规则：禁止按字数或场景时长估算字幕时间
外观 + 烧录4K 2 倍

skill-captions

字幕外观和烧录。默认 anchor-dark：STHeiti Medium 字体 · 炭灰半透明圆角底框 · 白色文字 · 固定底部锚点 · 4K 原生 2 倍重绘。

  • 先出代表帧预览 → 用户检查 → 全量烧录
  • 跑渲染质检 caption-render-qc.json

CHAPTER · 视觉与封面

视觉与封面 · 6 个 Skill

插画 + 注册风格封面 + 编辑风 + 拼贴动效。

插画小黑猫 IP

ian-xiaohei-cat-illustrations

小黑猫 IP 概念插画。通过 DashScope wanx 生成纯白手绘风格、带少量红橙蓝批注的知识点配图。生成的图不含文字，文字在渲染层加。

扩展插画不限猫

ian-xiaohei-illustrations

小黑猫插画的另一个版本，风格相同但不限于猫的形象，用于更广泛的概念可视化场景。

封面注册风格

skill-cover

封面生成 Skill，注册风格和双比例资产。支持多种预设封面风格，自动出图。

点阵编辑风

editorial-dot-cover

点阵编辑风封面。暖灰纸底 + 超大黑色中文标题 + 大量留白 + 点阵矢量图标。输出可编辑 SVG 和 PNG。

拼贴动效HyperFrames

editorial-collage-motion

半色调纸张拼贴动效。把参考图拆解成可编辑的拼贴规范，生成静帧和透明图层，再用 FFmpeg 或 HyperFrames 做"从空白背景逐件组装"的动画视频。

图解5:2 暖白

rn-cover-skill

编辑图解风封面。用标题和主题直接生成 5:2 暖白画布封面，不需要参考图。左侧大字排版、右侧每次重新生成概念图，输出可编辑 SVG 和 PNG。

CHAPTER · 制作调度与质检

制作调度与质检 · 2 个 Skill

总导演 + 复盘 + 硬契约。

总导演硬契约

ra-video-production-director

制作层的总导演。读交接稿契约，按需调用配音、字幕、动效、质检等下游 Skill。交接稿 frontmatter 是硬契约（比例 / 时长 / 声音 / 字幕风格），下游 Skill 的默认值不能覆盖契约。

  • 启动把项目从"待制作"移到"制作中"，防两台机器重复制作
  • 做完跑终检（画幅 / 分辨率 / 音视频流 / 抽帧）
  • 全部通过才允许归档到"已制作"
复盘资产入库

ra-复盘

视频发布后的数据分析和资产沉淀：取数 → 按互动率做爆款分级（R 级和 M 级）→ 归因（哪个环节做对了、哪个拖后腿）→ 沉淀资产（方法论 / 金句 / 案例 / 概念 / 课程灵感）→ 回写选题卡。

  • 每次复盘至少一条资产入库
  • R/M 级爆款分级用于选题反哺

CHAPTER · 视频动效 HyperFrames

视频动效 HyperFrames · 6 个 Skill

代码驱动的视频动效，专门跑 Anti-PPT 质量门。

动效导演Anti-PPT

rn-motion-director

把选题或脚本转化成动效视频概念：视觉隐喻、运动语法、场景节拍图，跑 Anti-PPT 质量门确保视频有运动感，不是在播幻灯片。

参考复刻逐帧

rn-motion-replica

从获授权的参考视频片段里，拆解布局、运动、时序和转场，构建一个原创的可编辑 HyperFrames 工程，附分析证据和最终 MP4 质检。

暗色 SaaS8 套场景

rn-dark-saas-video

暗色 SaaS 产品视频。黑色星空舞台 + 紫色底光 + 大字动效 + 渐变 CTA，8 套场景蓝图、3 种时长预设。

黑白打字机3 预设

rn-bw-text-opener

黑白打字机开场动画。纯黑背景 + 白色逐字打字 + 同步音效，3 种时长预设，附 Python 时序规划脚本。

复刻质检五级

rn-replica-qc

复刻质检。五级保真度评估 + 素材 / 运行时 / 交付三道全帧门。逐帧重放和参数化动效分别入库。

HARD GATES · 硬约束

5 簇硬门禁 · 系统能跑得通的关键

这套 Skill 不只是 Skill 列表，每个 Skill 都带一道硬门禁。

01

隐私与隔离

源信息（链接 / 标题 / 原文）只存在选题卡和隐私区。下载文件默认存 .internal/，不进成稿 / 不进归档 / 不进公开文档。

02

配音 / 数字人

付费生成前必须先有用户确认的试听音频，音频改了确认失效。每次渲染留 voice_manifest.json，禁止任何云端 TTS fallback。

03

去 AI 味硬禁清单

禁二元对比壳 · 禁"真正/其实/本质上"伪洞察标记 · 禁冒号讲义腔 · 禁空泛焦点转移。所有面向公众的中文稿件都过 ra-人话。

04

字幕时间硬规则

成片字幕必须从真实音频来，禁止按字数或场景时长估算。caption-qc.json 检查英文术语拆分 / 孤立碎片 / 连接词跨屏 / 阅读速度。

05

制作层硬契约

交接稿 frontmatter 是硬契约，下游 Skill 默认值不能覆盖。视频参数：保持源分辨率 + 帧率 · 响度 -16 LUFS · 停顿压缩 380-450ms · 最多 3 个克制转场。
