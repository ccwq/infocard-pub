Codex 十大必装 Skills：10 个技能分别解决什么

10 个 Skills 完整清单

full list
Superpowers
工程纪律 / 先测后写
01
原帖说法

让 Codex 像严格工程师一样干活：先写测试，再写代码，还会主动做代码检查，减少“看起来能跑、实际有坑”的情况。

适合

想把编码流程先拉回工程规范的人。

SuperClaude Framework
命令菜单 / 分析修 bug
02
原帖说法

给 Codex 增加一套常用指令菜单，用更简单的命令做分析、修 bug、写代码、优化项目、生成文档等任务。

适合

希望把复杂任务变成固定命令的人。

MiniMaxSkills
流程模板 / 前端全栈移动端
03
原帖说法

一套现成的工作流程模板，覆盖前端、全栈、移动端和文档写作，适合不知道怎么下指令的新手直接照流程让 Codex 干活。

适合

刚开始用 Codex、最需要“拿来就跑”的人。

Anthropic Official Skills
官方示例 / 学写法
04
原帖说法

官方示例技能库，主要用来学习“一个好 Skill 应该怎么写”，也适合拿来当模板改成自己的专属技能。

适合

想写技能、想学模板、想抄标准写法的人。

Vercel Agent Skills
前端检查 / React 规范
05
原帖说法

Vercel 官方的网页开发检查规则，特别适合 React 和前端项目，能检查页面性能、结构、可访问性和工程规范。

适合

做网页、做前端、做 UI 审查的人。

Planning with Files
长期项目 / Markdown 记录
06
原帖说法

让 Codex 用 Markdown 文件记录计划、进度和上下文，适合长期项目，避免聊着聊着忘记前面做过什么。

适合

长项目、多步骤、需要持续续接上下文的人。

Context Engineering Skills
上下文管理 / 记住与清理
07
原帖说法

教 Codex 更好地管理上下文：什么该记住、什么该总结、什么时候该清理，适合复杂项目，减少跑偏和重复沟通。

适合

对话长、任务多、需要控记忆的人。

Composio Skills
外部工具 / API 连接
08
原帖说法

帮 Codex 连接外部工具和服务，比如 GitHub、Notion、Slack、数据库等，适合想让 Codex 不只写代码，还能操作工具的人。

适合

想把 Codex 接到实际工作系统里的人。

Antfu Skills
方法论 / 学高手怎么写
09
原帖说法

学习高手如何设计 Skills，适合想进阶的人参考，看看优秀开发者是怎么把经验沉淀成可复用工作流的。

适合

不满足于“会用”，还想理解“为什么这样设计”的人。

Awesome Agent Skills
技能导航站 / 资源目录
10
原帖说法

一个大型 Skills 目录，收集了很多公司和社区做的技能，适合当“技能导航站”，需要什么能力时进去找灵感或模板。

适合

先找灵感、再找模板、再挑组合的人。

怎么装最顺

reading path
先装工程纪律
Superpowers + Vercel Agent Skills
先把“怎么写对、怎么检查对”立住，再谈扩展。
再装流程模板
SuperClaude + MiniMaxSkills + Planning with Files
让 Codex 知道下一步做什么、历史做过什么、如何续接上下文。
最后补连接与目录
Context Engineering + Composio + Antfu + Awesome Agent Skills
把“怎么管记忆、怎么接工具、怎么找模板”补齐，形成完整技能栈。

结论

这条帖真正有价值的地方，不是“列了 10 个名字”，而是把 Codex 的技能生态拆成了可装配、可学习、可迁移的工作流主线。

如果只想先装最有用的三类：先看 Superpowers、Planning with Files、Context Engineering Skills。
