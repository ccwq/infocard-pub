把“能不能跑”变成可解释的诊断报告

SomeStay07/claude-doctor-skill 用一套成熟度自适应的只读扫描，把 Claude Code 的配置、权限、工具链与运行风险压缩成行动清单。

六层诊断地图

从环境到交付

01 · Runtime

Node / Bun / Python 版本、PATH、OS、架构与资源余量。

02 · Claude

Claude Code CLI、settings、模型、认证状态与版本兼容。

03 · Project

仓库结构、CLAUDE.md、Git 状态、package manager 与脚本入口。

04 · Tools

MCP、hooks、skills、agents、插件与外部工具可达性。

05 · Security

权限、secret 暴露、命令注入面、信任边界与最小授权。

06 · Delivery

测试、日志、缓存、CI、网络与可复现交付的最后一公里。

成熟度自适应

同一工具，不同深度

Starter

先确认 CLI、认证、最小项目入口和安全边界；给出 3 个以内的下一步。

Builder

增加 MCP、hooks、依赖、测试与 CI 交叉检查；按严重度排序。

Power user

展开可复现性、权限漂移、性能信号、插件组合和自动化回归。

scan 只读，fix 授权

安全默认值

scan

只读读取版本、配置形状、状态与可达性。输出证据、风险等级和建议，不写文件、不安装依赖、不改权限。

fix

仅在用户明确授权后执行；先展示拟变更文件、命令、回滚方式，再逐项确认。敏感操作保持人工在环。

边界

不上传 secrets，不猜凭据；每条修复关联一个 check，完成后重新 scan 验证。

命令入口

可复制、可审计
claude-doctor scan
claude-doctor scan --json
claude-doctor scan --layer security
claude-doctor fix --check CHECK_ID --authorize
claude-doctor fix --dry-run
