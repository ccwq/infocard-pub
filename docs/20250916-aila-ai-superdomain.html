01痛点与方案

痛点：多 AI 工具各自为战

复制粘贴低效

同一问题要复制到 ChatGPT、Claude、Gemini 各自窗口，手动切换等待，效率极低。

选错模型漏信息

不确定哪个 AI 最适合当前任务，选了一个结果不满意，浪费一次完整对话机会。

无法横向对比

不同 AI 的回答风格、深度、准确度差异大，但无法同屏对比，只能靠记忆做判断。

方案：Aila 一问，多 AI 同屏作答

Ask Once, Get All

一次提问，ChatGPT / Gemini / Claude / Copilot / Perplexity / Grok / 通义千问等 20+ 模型同时响应，横向对比一目了然，不漏关键信息。

02核心功能
1-6 面板动态布局 全屏单 AI 模式 # 持续提示 / 快捷提示 Tab+Enter 提交 Switch 切换 AI JSON 自定义配置
动态面板布局

支持 1 / 2 / 3 / 4 / 6 面板同时显示。可按需扩展：单问题深度分析用 1 面板，横向对比用 6 面板。

全屏单 AI 模式

点击 AI 面板右上角的 AI 名称即可全屏放大该 AI 的回答，适合深入阅读某一模型的完整输出。

# 持续提示

输入以 # 开头的提示词将保持激活状态，不必每次重新输入，适合多轮对比同一主题的不同模型回答。

/ 快捷提示

输入 / 触发快捷提示列表，快速选择常用提示模板，无需每次手动输入完整提示词。

Tab+Enter 快捷提交

Tab 键切换焦点 + Enter 键提交，无需鼠标操作，保持键盘流输入体验。

JSON 自定义配置

通过 JSON 配置文件添加新 AI 模型入口、修改提示词模板、调整 API 参数，扩展性完全开放。

🎨 创意内容生成

同一创意提示同时发给 ChatGPT / Suno AI / Meta Image Generator，一次提问获得文案+音乐+配图的多模态内容组合。

07技术架构

.NET MAUI 跨平台框架

使用微软 .NET MAUI 构建，单一代码库同时编译为 Windows / macOS / Android 三平台应用。Windows 需 .NET 8 Runtime，macOS/Android 为独立二进制。

JSON 配置机制

通过 config.json 管理 AI 模型列表、API 端点、提示词模板。可添加私有模型、自定义 API Key 环境变量，实现完全可控的 AI 接入。

API 集成方式

各 AI 通过标准 REST API 调用（OpenAI 兼容接口为主），部分模型使用厂商专属 SDK。响应实时显示，支持流式输出（取决于模型端支持）。

08局限与注意事项
⚠️ 版本状态

最新版本为 v1.1（2024-03-24），距今已超过一年无新版本发布。功能迭代节奏较慢，部分新模型可能尚未支持。

⚠️ .NET 依赖（Windows）

Windows 版需提前安装 .NET 8 Desktop Runtime。macOS 和 Android 无额外依赖，直接安装运行。

⚠️ API Key 自备

部分模型需要自备 API Key（如 OpenAI、Anthropic、Gemini 等）。Key 管理在本地 JSON 配置文件中，需妥善保管。

⚠️ 无 macOS 独立安装包

当前仅提供 .pkg 安装包，未提供独立 App 包。对于部分 macOS 安全设置，可能需手动允许运行。
