01 / 为什么做这件事

知识停留在"看过/收藏过"层面，无法被调用

书、长视频、播客里的方法论往往没有被 AI 训练过，很难靠一次观看完整吸收。cangjie-skill 把这些内容变成可独立调用、可组合使用、可压力测试的 AI skill 工具包。

02 / 不是摘要，是结构化复用

压缩只是降维，结构化才是迁移

摘要、笔记、字幕整理只是压缩，不是结构化复用。cangjie-skill 区分哪些内容适合做独立 skill，哪些只适合做背景，对没有独立价值的内容进行淘汰。

03 / RIA-TV++ 七阶段流水线

Stage 1

整体内容理解

借鉴 Mortimer Adler 分析阅读法：结构、解释、批判、应用四步拆解，产出 BOOK_OVERVIEW.md

Stage 2

并行提取

同时派 5 个专项提取器：框架、原则、案例、反例、术语，从原文中提取候选方法论单元

Stage 3

三重验证筛选

2+ 独立佐证（跨域）、预测力（回答新问题）、非常识。通过率通常 25–50%

Stage 4

RIA++ 构造

R（引用）/ I（重写）/ A1（书中案例）/ A2（未来触发）/ E（可执行步骤）/ B（边界）六维结构化

Stage 5

Zettelkasten 链接

找出 skill 之间的依赖、对比、组合关系，生成 INDEX.md 和引用图

Stage 6

压力测试

为每个 skill 设计含诱饵题的测试用例（含跨 skill 混淆测试），未通过回炉重做

Stage 7

交付

生成面向读者的 DIGEST.md 精华长文，并把 skill 安装到 Claude Code / OpenClaw 的 skills 目录

RIA-TV++ 含义

名字拆解

RIA：赵周《这样读书就够了》便签拆书法（Reading/Interpretation/Appropriation）；TV：Triple Verification 三重验证；++：E（Execution）+ B（Boundary）面向 agent 执行扩展

05 / 适用场景

哪些内容值得蒸馏

书、长视频有字幕/转写文本、播客、访谈、演讲、课程、长文和资料集——只要内容存在可抽取、可验证、可迁移的方法论。

06 / 与 nuwa / darwin 的关系

三角生态

nuwa-skill 负责蒸馏"人"，cangjie-skill 负责蒸馏"系统性表达过的内容"，darwin-skill 负责让 skill 自动进化。三者互补。

使用边界：cangjie-skill 提升的是方法论的可调用性；skill 质量取决于原文方法论的完整度和可验证性。通过率 25–50% 是设计特性而非缺陷——它意味着大量无效内容被过滤，而非强行保留。蒸馏得到的 skill 仍需人工审核边界与适用场景。
