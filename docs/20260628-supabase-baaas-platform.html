基础使用 · 快速上手
1
创建项目
访问 supabase.com → Sign up → New Project → 选套餐（建议从 Free 开始）→ 等待 2 分钟初始化，拿到 SUPABASE_URL 和 SUPABASE_KEY。
2
安装 SDK / CLI
支持 JS/TS、Python、Flutter、Swift、Kotlin、C#。npm / pip / pub 安装一行搞定。
npm install @supabase/supabase-js # 或 pip install supabase
3
连接数据库 & 读写数据
Supabase 自动为每张表生成 CRUD REST API，无需手写后端。同时支持实时订阅数据库变更。
import { createClient } from '@supabase/supabase-js' const supabase = createClient(SUPABASE_URL, SUPABASE_KEY) // 插入数据 → 自动生成 API const { data, error } = await supabase .from('todos') .insert([{ title: '用 Supabase 快速搭后端', done: false }]) .select()
4
开启 Auth / Storage / Realtime
在 Dashboard 开启任意模块，Supabase 自动注入对应表、存储桶、策略，SDK 一行调用即可。
// 邮箱登录 const { user, session, error } = await supabase.auth.signInWithPassword({ email: 'user@example.com', password: 'password123' })
5
部署 Edge Functions / 开启向量能力
安装 Supabase CLI，部署 Deno 边缘函数；通过 SQL 一行开启 pgvector，立即支持 AI Embedding 存储与检索。
# CLI 部署 Edge Function supabase functions deploy my-function # 开启向量扩展（SQL Editor） create extension if not exists vectors;
