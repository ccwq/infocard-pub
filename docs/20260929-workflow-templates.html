ComfyUI 官方工作流模板库 Workflow Templates

ComfyUI 官方模板索引仓库：模板（templates）与蓝图（blueprints）分两条流水线，由 Python 脚本归一化、生成清单并同步进按媒体类型拆分的包；模板站用 Astro 静态生成，覆盖 11 种语言。

01

两条流水线，不是一条

模板走 scripts/sync/sync_bundles.py，蓝图走 scripts/sync/sync_blueprints.py；蓝图还有独立的导入脚本 scripts/blueprints/import_blueprints.py 做命名归一化与元数据生成。

02

蓝图用 ComfyUI 原生子图格式

blueprint 不是自定义 DSL，而是原生 subgraph 结构：顶层 definitions.subgraphs 里带 id / name / inputs / outputs / nodes / links。

03

版本号只有一个来源

版本写在根 pyproject.toml；贡献流程的最后一步是“改根版本号后提 PR”，避免包版本与内容漂移。

04

提交前必须复跑同步

README 明确要求：sync_blueprints.py 必须不产出任何改动，否则说明包与蓝图不一致——这是一致性门禁，不只是格式化。

05

CI 六项校验

JSON 语法、schema 校验、bundle 一致性、manifest 同步、缩略图、ComfyUI 节点兼容性。其中节点兼容性只作为信息性 PR 评论，不阻断合并。

贡献一个模板要走完的 5 步README · Option 1: Import from External Source

从外部 JSON 接入

  • 把 blueprint JSON 放进 blueprints/，文件名用 snake_case，例如 text_to_image_flux.json
  • 跑 import_blueprints.py 归一化命名、生成 index.json 元数据
  • 跑 sync_blueprints.py 同步到各包
  • 在 ComfyUI 里实测，并确认再次同步无 diff
  • 改根 pyproject.toml 版本号，提 PR

本地校验命令

  • python scripts/sync/sync_bundles.py — 模板与包同步
  • python scripts/sync/sync_blueprints.py — 蓝图与包同步
  • npm run validate:comfyui-nodes — 节点兼容性基线（需要本地已运行 ComfyUI）

按媒体类型拆包

包结构把核心、media_* 与 blueprints 分开，ComfyUI 只需装它真正用到的模板集合。

模板站是构建产物

Astro 静态生成 + 11 种语言，站点内容直接从仓库的模板与元数据派生。

缩略图纳入版本

webp 缩略图与蓝图同目录、可选但会被 CI 校验，保证索引页面有视觉可辨认性。

蓝图可复用为子图

因为走原生 subgraph 格式，蓝图能直接当成别人的子图节点组合进新工作流。
