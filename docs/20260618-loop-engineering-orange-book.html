01 · 这本书讲什么
plain-language guide

不是再教你写更好的 prompt

这本书的中心不是“提示词技巧”，而是把你的角色从“逐轮喂 Agent 的人”升级成“设计循环的人”。它强调：系统的外层循环，比单句 prompt 更重要。

它把外层系统拆成可执行部件

书里把循环工程放在更高一层，围绕自动化、工作树、技能、插件 / 连接器、子代理与记忆，讲清一个系统怎么自己跑起来、自己收敛、自己复盘。
