Dynamic Workflows 实际对应的 7 个模块

1 Subagents

把复杂任务拆给多个专门代理并行做。

2 Hooks

在关键节点自动触发测试、lint、校验等动作。

3 Background tasks

让长任务持续跑，不阻塞主任务。

4 Checkpoints

每次修改前自动存档，可 rewind，核心是可控试错。

5 Parallel tool use

Claude 可在同一轮里并发调多个工具，失败后还能再调度。

6 Tool Search / Programmatic Tool Calling

动态发现工具、在代码环境里编排调用。

7 Managed Agents

长会话、可恢复 sandbox、外置 session log，走向长时执行层。

和传统 workflow 的差别

传统 Workflow

  • 流程图预先写死
  • 顺序固定
  • 异常分支固定
  • 重点是稳定与可预测

Claude Dynamic Workflow

  • 目标给定，子步骤动态生成
  • 工具按需发现
  • 多代理并行协作
  • 失败后根据反馈改道
  • 带检查点与恢复机制
