核心定位

TokDoc 是 yaojingang/yao-open-tools 工具集中的本地文档管理器。用 Docker 或本机 Node 启动后，上传 HTML / PDF / Word 文件，自动生成本地短 URL 并提供页面内实时编辑（HTML）和自动版本快照。

适合个人笔记整理、内部文档分享、小团队知识库等不需要联网的私密文档管理场景。数据全部存储在本地 SQLite + 文件系统，无任何外部依赖。

安装入口

Docker 启动（推荐）
# 首次部署先复制配置 cp .env.example .env # 启动服务（默认端口 18082） docker compose up -d --build # 自定义端口 TOKDOC_HOST_PORT=8088 docker compose up -d --build
本机 Node 启动
npm install npm run dev # 打开 http://127.0.0.1:8080/
默认访问地址
http://127.0.0.1:18082/ # 文档索引页 http://127.0.0.1:18082/admin # 后台管理 http://127.0.0.1:18082/healthz # 健康检查
默认登录
# 用户名：admin 密码：tokdoc # 可通过 .env 修改初始账号 TOKDOC_INITIAL_USERNAME=admin TOKDOC_INITIAL_PASSWORD=your_password

核心功能

📝 HTML 实时编辑

访问 /f812c6?edit=1 直接在页面中修改标题、段落、表格，600ms 防抖自动保存，自动生成版本快照

📖 PDF / Word 阅读

PDF 以阅读器方式打开；Word (.doc/.docx) 自动转 PDF 再阅读，Docker 内置 LibreOffice + Noto CJK 字体

📁 目录批量导入

浏览器批量导入目录，自动同步 CSS/JS/图片等相对路径附件，写入 /page-assets/<uploadId>/...

🔔 目录监听

在"设置"填入容器可访问目录（如 /watch/html-inbox），保存后自动持久化监听并扫描入库

📊 访问统计

访问 /<slug> 自动统计访问次数，列表页显示目录名称后的访问计数

🗑️ 回收站

删除移入回收站，文件移至 data/trash/；可在回收站一键恢复，重新展示文档

数据目录

📦data/tokdoc.db — SQLite 数据库（文档元数据、账号、版本快照）
📁data/pages/ — 生成后的本地页面，文件名含日期、短码
📂data/uploads/ — 上传源文件副本（HTML/PDF/Word + 附件）
🔄data/versions/ — 自动保存的版本快照，支持恢复
🗑️data/trash/ — 回收站文件（已移出可访问路径）
📎page-assets/ — 运行时静态前缀，映射 uploads 内的附件
👁️html-inbox/ — 本地默认监听目录

适合 vs 不适合

✅ 适合

个人笔记整理、内部私密文档分享、小团队知识库、需要离线/内网部署的文档管理

⛔ 不适合

需要公网访问和多用户协作的文档平台、大规模内容管理、实时协同编辑

✅ 亮点

无外部依赖、纯本地存储；Docker 一键部署；Word 自动转 PDF；HTML 页面内直接编辑

⛔ 注意

本机 Node 启动若需 Word 转 PDF，需手动安装 LibreOffice；默认密码 tokdoc 需修改
