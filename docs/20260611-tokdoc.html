核心定位

本地私密文档管理器，数据不出本机

TokDoc 把文档管理做成一个完全本地运行的系统：上传 → 生成短 URL → 实时编辑 → 版本快照，全在本地 SQLite + 文件系统里完成

无需联网

🔒 完全本地运行

SQLite 数据库 + 文件系统存储，无任何外部依赖，数据完全在本地

LibreOffice

📖 Word → PDF 阅读

Docker 内置 LibreOffice Writer + Noto CJK 字体，Word 自动转 PDF 再阅读

版本快照

🔄 自动版本管理

每次保存生成快照，存于 data/versions/，通过 API 随时恢复任意历史版本

02
安装入口

Docker 一键启动，本机 Node 也支持

依赖 espeak-ng 和 ffmpeg，pip 或 Docker 两种启动方式

INSTALL · Docker 启动（推荐）
git clone https://github.com/yaojingang/yao-open-tools
cd yao-open-tools/tools/TokDoc
cp .env.example .env
docker compose up -d --build

# 自定义端口
TOKDOC_HOST_PORT=8088 docker compose up -d --build

# 默认访问
http://127.0.0.1:18082/          # 文档索引页
http://127.0.0.1:18082/admin     # 后台管理（admin / tokdoc）
npm run dev

本机 Node 启动

npm install && npm run dev → http://127.0.0.1:8080/

需要 LibreOffice 做 Word 转 PDF，或通过 TOKDOC_SOFFICE_BIN 指定路径

默认账号

登录信息

用户名：admin 密码：tokdoc

通过 .env 修改：TOKDOC_INITIAL_USERNAME / TOKDOC_INITIAL_PASSWORD

04
API 摘要

REST API 完整覆盖

文档 CRUD / 版本管理 / 监听目录 / 公开列表

后台 API

文档管理

  • GET /admin/api/pages — 文档列表
  • POST /admin/api/pages/upload — 上传文件
  • PATCH /admin/api/pages/:id/content — 更新内容
  • DELETE /admin/api/pages/:id — 删除文档
  • GET /:slug?edit=1 — 编辑文档
版本与监听

高级能力

  • GET /admin/api/pages/:id/versions — 版本列表
  • POST /admin/api/pages/:id/restore/:versionId — 恢复
  • GET /admin/api/watch-dirs — 监听目录列表
  • POST /admin/api/watch-dirs/:id/rescan — 重新扫描
  • GET /public/api/pages — 公开列表 API
