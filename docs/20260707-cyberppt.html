Workflow

六步工作流

Step 01 文档提取 从 DOCX、PDF、Excel 中提取事实和数字
Step 02 证据表构建 将提取内容整理成结构化证据表
Step 03 故事线比较 比较不同叙事角度，确定核心论点
Step 04 版式选择 从 8 种咨询风格中匹配最适合的配色版式
Step 05 逐页生成 主标题、正文、关键数字均可独立编辑
Step 06 检查关卡 文字溢出、数字出处、页面密度多重检查
Styles

8 种咨询风格配色版式

📊 数据驱动 适合市场分析、竞品研究等数据密集型报告
⚡ 问题导向 适合诊断分析、痛点挖掘等议题驱动型演示
🎯 战略规划 适合愿景描绘、战略布局等长期规划类提案
🔄 流程优化 适合运营改进、流程再造等效率提升类项目
💡 创新方案 适合新产品设计、业务创新等创意类提案
🤝 客户沟通 适合汇报沟通、客户培训等交流演示场景
📋 项目汇报 适合进度汇报、阶段总结等项目管理场景
🏆 竞标提案 适合招标比稿、方案竞标等专业展示场景
Editable

全方位可编辑

📝 主标题编辑 每一页的主标题均可独立修改，调整叙事重点和表达方式
📄 正文内容编辑 支持对正文内容进行精细编辑，确保信息传达准确
🔢 关键数字编辑 核心数据和关键数字可随时更新，保持内容时效性
QC

多重检查关卡

⚠️ 文字溢出检查 自动检测页面内容是否超出边界，确保排版美观
📎 数字出处检查 验证所有关键数据的来源标注，保证论据可溯源
📏 页面密度检查 评估每页信息密度，确保阅读体验和传达效率
Features

核心能力

✓ 多格式支持：DOCX、PDF、Excel 文档直接导入
✓ 结构化输出：从非结构化文档自动提炼结构化信息
✓ 故事线构建：辅助分析叙事逻辑，确定最佳表达路径
✓ 专业版式：内置咨询行业标准配色与排版规范
✓ 逐页可控：精确控制每一页的内容和呈现方式
✓ 质量保障：多维度自动检查，确保输出品质
Install

安装与使用

Codex 中激活
// 在 Codex 中安装 CyberPPT /skill install cyberppt // 或使用完整命令 /skill add https://github.com/crazyykhllc-bit/CyberPPT
基本使用
// 上传文档并开始生成 /cyberppt generate --input document.docx // 选择咨询风格 /cyberppt style --preset strategic // 导出 PPTX /cyberppt export --format pptx
