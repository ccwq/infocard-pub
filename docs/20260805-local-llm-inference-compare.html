⚠️ 边界与注意事项

速度对比为相对描述，实际性能受模型大小、GPU 型号、batch size 等因素影响。

量化方案各有精度/速度权衡，需根据场景选择。Q4_K 是大多数场景的推荐选择。

Ollama 底层使用 llama.cpp；vLLM 需要 CUDA 支持和足够显存。

✓ 选型原则：低配机器 → llama.cpp · 高吞吐生产 → vLLM · 快速实验 → Ollama

三者并非互斥，可根据场景组合使用
