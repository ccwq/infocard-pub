01

3 分钟上手：先收进库，再发给 Agent

最短路径不需要先理解全部工作区。先安装一个 skill，再明确部署目标。

① 安装到中心库

桌面应用从 Git 仓库、本地目录、`.zip` / `.skill` 或 skills.sh marketplace 导入。默认中心库是 ~/.skills-manager，可在 Settings 修改。

# 项目内 CLI 示例
npm run cli -- skills install vercel-labs/agent-skills@react-best-practices
npm run cli -- skills list

② 部署到具体 Agent

安装只改变中心库；部署才会把 skill 放入目标工具能读取的目录。可以一次指定多个 agent。

# 部署并检查状态
npm run cli -- skills deploy react-best-practices --agent claude_code --agent codex
npm run cli -- skills status react-best-practices
02

三种 Workspace：全局、项目与外部目录

同一套管理逻辑，作用域不同。

Global Workspace查看某个 Agent 全局 skills 目录里的实际内容，包括手工安装、未经过 Skills Manager 的 skill。
Project Workspace管理某个项目中的本地 skills，支持与中心库对照，并按 Agent 分配。
Linked Workspace把任意目录作为 skills root 管理；它是独立工作区，不参与全局 preset 同步。
03

Preset 与多工具同步

把“哪些 skills 给哪些 Agent”从手工复制变成可重复组合。

Preset 是一次性应用

把多个 skill 组成命名 preset，在任意 workspace 用 preset pill 批量启用或停用。应用 preset 是一次性复制，不是持续 live sync。

  • 可批量 enable / disable / export / delete；
  • 项目工作区也支持批量启停；
  • tags、source、Untagged 可用于筛选。

同步状态要看目标 Agent

Multi-tool sync 支持 symlink 或 copy。每张 skill 卡展示各 Agent 的部署状态，中心库状态与目标目录状态分开记录。

# 检查上游与批量更新
npm run cli -- skills check --all
npm run cli -- skills update --all
npm run cli -- skills adopt ~/.claude/skills --dry-run
04

Backup：跨设备同步，但 Secrets 留在本机

备份的是技能库状态，不是整台机器。

01连接GitHub device flow 或任意 Git remote。
02备份skills、tags、presets、per-agent toggles。
03合并按 skill 合并，冲突不覆盖本地版本。
04恢复快照可恢复，恢复前先保存当前状态。

不会离开本机

  • API keys / tokens
  • proxy settings
  • machine-specific wiring
  • 超过 100 MB 的 skill 默认排除
  • SQLite 数据库不进入 Git
05

让 Agent 管理 Skills Manager

v1.36.0 的重点更新：Agent 可以通过官方 skill 驱动 Skills Manager，而不是绕过中心库直接写 Agent 目录。

一次性设置，之后按普通 skill 管理

Dashboard 可以选择哪些 Agent 获得管理能力，应用会安装并部署 manage-skills skill。也可以独立安装：

npx skills add xingkongliang/skills-manager

这样可以保留来源、preset 归属、更新追踪和各 Agent 部署状态。部署若会覆盖 Skills Manager 不拥有的目录，会返回结构化 TARGET_CONFLICT 并保留原内容。

06

安装包、CLI 路径与开发者入口

普通用户下载 Release；开发者才需要 Rust、Node 和 Tauri 前置条件。

平台发行包

  • Windows：`.exe` / `.msi`
  • Linux：`.AppImage` / `.deb` / `.rpm`
  • macOS：`.dmg`

官方 Release 当前为 v1.36.0；具体架构和文件以 Release 页面为准。

CLI 与源码开发

应用启动时会把 CLI 发布到 ~/.skills-manager/bin/skills-manager-cli。手动安装到 PATH：

npm run cli:install
# cargo install --path src-tauri --bin skills-manager-cli --locked --force

源码开发需要 Node.js 20.19+ 或 22.12+、Rust 1.77.2+ 和对应 Tauri prerequisites。

07

安全边界与适用场景

它解决的是技能资产管理，不是替你判断每个 skill 是否可信。

适合

  • 多 Agent、多项目共用技能库；
  • 需要 preset、tag、版本追踪和批量部署；
  • 跨设备备份个人 skills；
  • 让 Agent 通过受控入口管理 skills。

不要跳过

  • 破坏性操作先使用 --dry-run；
  • remove 需要 --yes；
  • Git remote、PAT、proxy 和 keychain 权限要单独审查；
  • 第三方 skill 的内容与脚本仍需自行审计。
