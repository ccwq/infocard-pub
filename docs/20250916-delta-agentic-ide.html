01核心能力定位
持久态 Agent 上下文

与每次对话重置的 Copilot 不同，Delta 在整个项目周期内保持 Agent 状态，代码生成带项目记忆，不丢上下文。新成员打开项目，Agent 立即知道之前的所有决策。

内置工具调用

Agent 可直接调用浏览器、搜索引擎、文件系统等工具，不需要手动复制粘贴工具输出；结果自动回注到对话上下文，形成完整的推理链。

双向人机协作

Agent 提出方案后暂停等待人工审核；用户可以批准、修改或重定向，Agent 根据反馈继续执行。避免自主执行后才发现方向偏差。

自演进 Skill 系统

安装 Marketplace 技能或自定义技能，Agent 自动学习并在后续任务中调用，类似"学会使用工具"的能力积累，不需要每次重新教。

精细化代码理解

使用针对代码理解微调的模型，理解项目结构、依赖关系和架构模式，不是通用 LLM 的粗粒度代码补全。

本地优先 Privacy

项目数据默认保存在本地设备，不强制上传云端；企业场景可配置私有部署，满足数据合规要求。

各工具详解

Claude Code（Anthropic）

2025 年 2 月发布，终端原生 CLI，支持 macOS/Linux/Windows。通过 CLAUDE.md 文件持久化项目上下文是核心差异——文档化的项目规范不会随对话消失。v2.x 新增 Agent Teams（并行子 Agent）、Checkpoints（/rewind 编辑历史）、1M token 上下文窗口（Opus 4.6）。有 VS Code 扩展和 JetBrains 插件（v2.1.83）。

终端 Agent + 文档化记忆

Cursor（AI-first IDE）

VS Code 分叉（保留所有扩展和快捷键），AI 深度嵌入编辑器内核。Composer Agent 模式最自主：描述功能需求后自主规划→编辑→运行→修复→迭代。72% 代码接受率，内置 Tab 多行补全最强。缺点：$20/月，Agent 长序列可能跑偏，需人工干预。

最强自主编辑 + 精准补全

Windsurf Cascade（Codeium）

VS Code 分叉，Wave 13（2026）后 Cascade Agent 显著改进：15 文件重构任务单次完成（之前需多次人工干预）。Riptide 索引可在数秒内扫描上百万行代码。$15/月是最低成本方案，缺点：无 CLAUDE.md 等持久化机制，长任务性能会下降。

大代码库 + 性价比

GitHub Copilot

与 GitHub 生态深度集成，Issue → PR 自动化是独家能力。2026 年 1 月新增 Agentic Memory（项目洞察持久化预览）。$10/月门槛最低，适合 GitHub 工作流重度用户。Agent 模式比其他工具更保守（显式审批门控），适合企业合规场景。

GitHub 生态 + 企业合规

Delta 的差异化定位：Delta 区别于上述工具的核心是"跨会话持久 Agent 状态"——Claude Code 需要手动写 CLAUDE.md，Cursor/Windsurf 每次重启清零，Delta 的 Agent 上下文在项目生命周期内自动保持，无需每次重新说明背景。

04持久化上下文：CLAUDE.md 体系（Claude Code 对比）

Delta 的核心持久化机制与 Claude Code 的 CLAUDE.md 系统高度相似——理解这个体系对初学者选择工具至关重要。

CLAUDE.md — 层级结构（Claude Code / Delta 均支持）
# 全局设置（对所有项目生效） ~/.claude/CLAUDE.md # 项目级设置（仅当前项目生效） /project-root/CLAUDE.md # 目录级设置（仅子目录生效，优先级最高） /project-root/frontend/CLAUDE.md # 本地个人偏好（.gitignore，通常不提交） /project-root/CLAUDE.local.md
CLAUDE.md — 典型内容示例
# 项目架构 # 本项目使用 Next.js App Router，前端在 /app，后端 API 在 /pages/api # 构建命令 npm run dev # 开发 npm run build # 生产构建 npm test # 测试 # 代码规范 # - 使用 TypeScript strict 模式 # - 组件放在 /components，以 PascalCase 命名 # - API 路由返回统一 { data, error } 结构 # 工具限制 # - 禁止直接操作数据库，通过 API 层 # - 生产环境变更需通过 Code Review # 完成定义 # - 必须运行 npm test 并通过 # - 必须运行 lint 检查

CLAUDE.md vs Delta 内置持久化：Claude Code 需要手动编写 CLAUDE.md 并提交到仓库，Delta 的 Agent 状态自动保持，不需要每次重新写说明文档。Delta 更适合不想维护额外文档的团队。

05MCP 生态：Agent 的工具扩展

Model Context Protocol（MCP）是连接 Agent 与外部工具的开放标准。Claude Code 支持 1864+ MCP 服务器，Delta 亦通过 MCP 扩展能力。

内置工具（Delta / Claude Code）

Read / Edit / Execute（终端命令）/ Search / Browser / Web（网页抓取）/ Agent（子 Agent 委托）/ VSCode / Todo

常见 MCP 集成场景

数据库查询、CI 状态检查、API 文档搜索、Slack 通知、GitHub PR 操作、Figma 设计稿读取

MCP 服务器示例

filesystem、github、postgres、sqlite、memory（向量记忆）、fetch、puppeteer、Brave Search

Delta 的 MCP 支持

Delta 原生集成 Browser / Search / FS 工具，同时支持 MCP 协议扩展，可接入任何 MCP 服务器。

Claude Code — MCP 服务器添加
# 添加 MCP 服务器 claude mcp add filesystem # 本地文件系统 claude mcp add github # GitHub API 集成 claude mcp add postgres # PostgreSQL 数据库 claude mcp add memory # 向量记忆搜索 # 查看已安装的 MCP 服务器 claude mcp list

09Skill 系统：让 Agent 学会新能力

Skill 系统让团队把重复的工作流程封装成可复用模板，Agent 在相关任务中自动加载。Delta 和 Claude Code（通过 .claude/skills/ 目录）均支持。

什么是 Skill

一个 SKILL.md 文件，包含 Agent 指令、脚本、模板和示例。当任务匹配 Skill 触发条件时，Agent 自动加载并遵循其中的工作流。

Skill 使用场景

团队规范的代码审查流程、CI/CD 流水线操作、Docker / Kubernetes 部署流程、数据库迁移 SOP、API 文档生成流程。

Skill vs Snippet

Snippet 只复制代码片段，Skill 定义完整行为规范——包括前置条件、执行步骤、验证方式和错误处理。Agent 遇到相关任务时主动加载。

Skill 安全

自定义 Skill 可执行任意代码，只安装可信来源的 Skill；避免执行来路不明的脚本。建议通过代码审查后再引入团队 Skill。

Claude Code — 创建自定义 Skill
# 1. 启用 Skills 功能（VS Code 设置） { "chat.useAgentSkills": true } # 2. 安装 skill-creator npx skills add https://github.com/anthropics/skills \ --skill skill-creator # 3. 让 Agent 生成 Skill # 在 Claude Code 中输入： # "Create a skill that will use my project docs at /docs # and answer questions about the project architecture" # 4. 生成的文件结构 .claude/skills/my-project-assistant/SKILL.md
10许可证与边界
许可证

专有 / Freemium 模式；具体授权条款需查阅官方最新文档。

数据边界

本地优先不代表数据永不离开——确认企业部署方案的数据流和合规要求。

Skill 安全

自定义 Skill 可执行任意代码，来源可信才安装；避免执行来路不明的 Skill 脚本。

模型选择

Delta 默认使用自微调代码模型，也支持接入外部模型 API；不同模型能力有差异，验收时需确认。

工具组合建议：很多开发者同时使用多个工具——用 Cursor 做精确编辑，用 Claude Code 做自主任务，用 Delta 做跨会话记忆追踪。根据任务类型灵活切换，不要被单一工具绑定。
