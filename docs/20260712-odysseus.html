Odysseus 是一套自托管 AI 工作站，GitHub 超 82k Star，PewDiePie 参与开发。
Docker 一行命令跑起来，数据全在本地，支持本地模型（Ollama / llama.cpp）和 API 模型（Claude / GPT / Gemini）。
聊天、深度研究、文档编辑器、邮件、笔记、日历、任务管理——所有这些不再散落在不同工具里，全部统一在一个本地工作站中。

⚡
核心功能 · 一个工作站搞定所有
💬
Chat + Agents
本地/API 模型、工具调用、MCP、文件操作、Shell、Skill、记忆。Agent 模式支持多步任务执行。
🔬
Deep Research
多步网页调研，读来源网页，生成完整研究报告。支持多轮搜索和结果综合。
📄
Documents
写作优先编辑器，AI 编辑和建议。支持 Markdown、HTML、CSV 语法高亮，无需切换工具。
📧
Email
IMAP/SMTP 收件箱，摘要、标签、提醒、回复草稿。邮件工作流直接在工作站里完成。
📝
Notes + Tasks
笔记管理、提醒、待办列表、定时 Agent 任务。信息不再碎片化，统一索引。
📅
Calendar + CalDAV
日历视图、CalDAV 同步。任务和日历与笔记联动，工作流更顺畅。
🍳
Cookbook
硬件感知模型推荐、下载、部署。告诉你用什么硬件配置跑哪个模型最合适。
⚖️
Compare
盲测多模型并排对比与综合评估。用同一问题测试不同模型，直观看效果差异。
🔍
Web Search
内置网页搜索能力，深度研究模式调用。可配置搜索提供商。
🔐
Auth + 2FA
内置认证系统，支持两因素验证。数据本地存储，适合自托管场景。
🎨
Themes
多套主题切换，UI 定制化。支持暗色/亮色，满足不同视觉偏好。
🖼️
Extras
图库/图像编辑器、文件上传、预设模板、会话管理。
🧠
模型支持 · 本地 + API 混用
🍴 本地模型（Ollama）
支持 Ollama 托管的所有模型。Llama / Mistral / Gemma / Phi 等，Cookbook 里有硬件推荐。完全离线运行，数据不出机器。
☁️ API 模型（OpenAI 兼容）
OpenAI / Claude / Gemini / Groq / Mistral / Cohere 等 OpenAI-compatible API 直连。支持多 Key 轮换和自定义端点。
🦙 llama.cpp / GGUF
Cookbook 提供 llama.cpp 本地部署指南。适合有 GPU 的用户自己跑大模型，无需云端 API。
🚀
快速安装 · Docker 一行跑起来
bash — Docker 快速部署
# 1. 克隆仓库（dev 分支最新功能） git clone -b dev https://github.com/pewdiepie-archdaemon/odysseus.git # 2. 进入目录，复制环境变量配置 cd odysseus && cp .env.example .env # 3. Docker Compose 启动（自动构建 + 启动） docker compose up -d --build # 4. 打开浏览器访问 open http://localhost:7000 # 5. 首次管理员密码（容器启动后） docker compose logs odysseus | grep password
🛡️
安全 · 自托管注意事项
🔒 自托管安全建议
  • 保持认证功能开启，不要跳过初始密码设置
  • 敏感数据不要提交到 Git（.env 已包含在 .gitignore）
  • 不要把模型/服务端口直接暴露到公网
  • 详细配置见 docs/setup.md
📦 本地安装（可选）
  • 支持 GPU 配置（CUDA）加速本地推理
  • Windows / macOS 原生安装见 docs/setup.md
  • HTTPS 配置有完整指南
  • 高级配置：模型供应商、多 Key 轮换
