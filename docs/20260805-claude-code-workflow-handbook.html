⚙️ 关键配置项

permissions：read（只读）/ edit（默认）/ bypassPermissions（跳过确认，慎用）

dangerouslySkipOpponent：false（默认），true 时跳过安全提示，仅完全信任变更时使用

model：可通过设置指定特定 Claude 模型版本

maxTokens：控制单次输出长度上限

🧠 实操技巧 TOP 5

① 用 CLAUDE.md 定义代码风格、架构约束、禁止操作

② 大项目先用 /clear 重置上下文再开启新任务

③ Git 操作默认需确认，通过 settings 调整权限

④ --dangerouslySkipOpponent 仅在完全信任代码变更时使用

⑤ 配合 MCP server 扩展工具集（文件系统、搜索、数据库）

⚡ 边界与限制

Claude Code 是终端工具，无 GUI 界面。部分功能（如特定 model 支持）可能需要 Claude API 订阅。bypassPermissions 默认禁用，需显式开启。配合 MCP server 可扩展到文件系统、数据库、搜索等场景。

✓ 适用场景：日常开发加速 / 代码重构 / Bug 修复 / Git 工作流自动化

不适合：需要图形界面交互的场景 / 复杂多仓库协同（建议拆解为多任务）
