01为什么需要 AI Upscale痛点
传统插值的局限

bicubic / bilinear 放大只生成平滑像素，边缘模糊、纹理丢失、锯齿明显。放大 4 倍后图像质量肉眼可见下降。

AI 图片生成质量

Midjourney / Stable Diffusion 输出图通常分辨率固定（1024×1024），细节区域存在噪点，需要高清化才能用于印刷或大屏。

老照片 / 低分辨率

历史照片、监控截图、压缩过的网络图，单纯放大等于放大噪声。必须先降噪再增强，需要专用修复模型。

06D 类：开源 AI Upscale 模型（技术核心）开源模型

开源模型是整个生态的技术底层：Upscayl、chaiNNer、ComfyUI、Automatic1111 等工具都是在这些模型之上做封装。理解模型路线 = 理解整个生态。

Real-ESRGAN ⭐⭐⭐⭐⭐ [github.com/xinntao/Real-ESRGAN]
开源 36,791 ★ 事实标准

开源超分领域事实标准。生态辐射：Upscayl / ComfyUI / A1111 / 商业封装均基于此。Real-ESRGAN-x4 模型专门针对真实世界退化的低质量图片设计，支持降噪 + 放大同步处理。

Real-ESRGAN — 安装使用
# pip 安装 pip install basicsr realesrgan # 下载模型并运行 python inference_realesrgan.py -i input.png \ -n RealESRGAN_x4plus -o output.png # 模型列表：RealESRGAN_x4plus / RealESRGAN_x4plus_anime_6B
ESRGAN [github.com/cszn/ESRGAN]
老一代经典

上一代经典 CNN 超分模型，纹理恢复能力强，社区积累大量预训练模型（RRDB_PSNR、RRDB_GAN 等）。Real-ESRGAN 即基于 ESRGAN 改进。适合纹理优先场景。

SwinIR [github.com/JingyunLiang/SwinIR]
开源 5,512 ★ Transformer

基于 Swin Transformer 的图像修复模型，3 大任务：图像超分 / 降噪 / JPEG 压缩伪影去除。L 版本 Real-World SR 在多个 benchmark 超过 Real-ESRGAN，自然纹理恢复稳定。

HAT ⭐⭐⭐⭐⭐ [github.com/XPixelGroup/HAT]
开源 1,591 ★ CVPR 2023

Hybrid Attention Transformer，结合通道注意力 + 窗口自注意力，激活更多像素。HAT-L 在 Set5/Set14/Urban100 等 benchmark 领先 SwinIR 0.5-1dB。同任务预训练策略是其关键创新。适合研究部署。

SUPIR ⭐⭐⭐⭐⭐ [github.com/Fanghua-Yu/SUPIR]
开源 5,660 ★ 生成式超分

生成式超分（Generative Super-Resolution）。低清图片 → 视觉模型理解 → 扩散模型生成细节 → 高清图片。强项：人脸、艺术图、老照片。风险：可能产生原图不存在的信息。ComfyUI 有官方节点。

GFPGAN [github.com/TencentARC/GFPGAN]
开源 37,676 ★

人脸修复专用，腾讯 ARC 实验室出品。真实人脸保真度高，与 Real-ESRGAN 互补使用：Real-ESRGAN 放大整体 → GFPGAN 精修人脸。

CodeFormer [github.com/sczhou/CodeFormer]
开源 18,139 ★

人脸恢复，真实性和美化程度可调（Fidelity ↔ Colorfulness 滑块）。劣质条件（严重遮挡、极端光照）下鲁棒性优于 GFPGAN。含完整训练代码和预训练模型。

07E 类：Stable Diffusion / ComfyUI 高级工作流AI 工作流
ComfyUI ⭐⭐⭐⭐⭐ [comfy.org] · [github.com/Comfy-Org/ComfyUI]
开源免费 ~50,000+ ★ 工作流平台

AI 图片生产工作流平台，节点 / 图 / 流式架构。通过自定义节点（Custom Node）支持 Real-ESRGAN / HAT / SUPIR / SD Upscale / Ultimate SD Upscale 等所有主流模型和工作流。官方文档将 Upscale 作为标准工作流节点。AI 创作者必备工具。

Ultimate SD Upscale [github.com/ssitu/ComfyUI_UltimateSDUpscale]
1,559 ★ Tile+Img2Img

核心技术：Tile（切块）+ Img2Img（重绘）+ 拼接。切大图为小块 → SD 重绘每块 → 拼接回整图。适合：AI 艺术图超大尺寸输出（8K+）、细节增强。避免接缝是调参关键。

Tiled Diffusion
A1111 插件

大图分块生成（分块图生图），解决显存不足问题。配合 ControlNet Tile 使用可精确控制输出结构。适合 8K 以上分辨率输出。

Automatic1111 Upscaler 生态
A1111 插件集

Ultimate SD Upscale / ESRGAN 插件 / ControlNet Tile 组成 A1111 生态的放大方案。与 ComfyUI 相比，A1111 上手更简单，插件生态成熟。

企业级

不是单纯 Upscaler，而是完整图片基础设施：上传 → AI 处理 → 优化 → CDN → 展示。自动质量检测，按需触发 AI 增强。适合：大型网站、电商平台需要自动化全链路图片管理。

开发者

调用 Real-ESRGAN、SUPIR 等开源模型的云 API，Python/JavaScript/Go SDK 支持。开发者友好，按量计费，适合应用集成。

Replicate — 调用 Real-ESRGAN
import replicate client = replicate.Client(api_token="your-token") model = client.models.get("nightmareai/real-esrgan") prediction = model.predict(image="input.jpg", scale=4) print(prediction.output)
