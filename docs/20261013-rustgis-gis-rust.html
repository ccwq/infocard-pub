CHAPTER FOUR

12 层架构

L0–L6 crates 分层，从几何核心到 UI 前端，插件与 WebAssembly 并行

L0 rustgis-geom 坐标、范围、Web Mercator 投影、大地测量距离/面积、比例尺计算
L1 rustgis-data 要素/类型属性；GeoJSON、CSV、Shapefile；GeoPackage、GeoParquet、FlatGeobuf 提供方；SQL where 子句；栅格及坐标系统
L2 rustgis-map + rustgis-analysis 图层、符号化、标注、相机、底图；地理处理工具（基于 geo crate）
L2 rustgis-tiles Web 地图瓦片：XYZ/TMS/WMS、Mapbox Vector Tiles、MapLibre styles、瓦片缓存
L3 rustgis-render tiny-skia 渲染器、标注布局引擎、PNG 导出、字体处理
L3 rustgis-plugins 沙箱 WebAssembly 插件和插件注册表，支持从 plugins.rustgis.app 安装
L3 rustgis-geolibre GeoLibre 工具套件作为地理处理工具集成
L4 rustgis-engine 会话管理、撤销/重做、命令注册表、示例项目
L5 rustgis-assistant AI Assistant：通过自然语言命令行动的聊天 agent，每个更改可撤销
L6 rustgis-ui-egui Ribbon 前端 UI（可交换的 UI 层）
APPS rustgis / rustgis-cli / rustgis-web 三个应用入口：桌面 GUI、命令行 CLI、浏览器 WASM

cargo xtask ci 可运行格式化、clippy、测试和分层检查，确保架构分层合规。

CHAPTER SEVEN

316 条命令详解

每个 Ribbon 操作带唯一 id，可脚本化、CLI 执行、AI Agent 接管

gp.run
执行地理处理工具（countPoints / buffer / clip / merge 等）
layer.symbology
设置图层符号化（单一符号 / 唯一值 / 分级色彩 / 比例符号）
layer.label
配置标注（放置规则、比例范围、冲突处理）
share.exportMap
导出地图（PNG / PDF，指定 DPI）
data.open
打开数据文件（GeoJSON / Shapefile / GeoPackage 等）
data.save
保存为指定格式（GeoJSON / CSV / KML 等）
view.zoomIn / view.zoomOut
放大 / 缩小地图视图
view.pan
平移地图视图
map.bookmark
保存 / 管理书签和视图范围
render
渲染地图为图像（PNG/JPG，支持底图参数）
query.selectByAttr
按属性（SQL WHERE 子句）选择要素
query.selectByLoc
按位置关系（包含 / 相交 / 邻接）选择要素
edit.create
创建新要素（点 / 线 / 面）
edit.move / edit.rotate
移动 / 旋转要素
edit.merge / edit.split
合并 / 分割要素
raster.reproject
栅格重投影（任意 EPSG 代码）
raster.stretch
栅格拉伸（DRA / RGB / 分类 / 着色地形）
service.wms / service.wfs
连接 WMS / WFS 等 OGC Web 服务
tiles.addXYZ / tiles.addMVT
添加 XYZ 栅格瓦片或 Mapbox Vector Tiles 底图
ai.ask
自然语言查询数据或触发地图操作
undo / redo
撤销 / 重做上一个操作
commands
列出所有 316 条命令 id、参数和说明

全部 316 条命令通过 rustgis-cli commands 列出。每条命令均可通过 rustgis-cli 执行、在 notebooks 中链式调用，或由 AI Agent 通过 MCP 接管。

CHAPTER TEN

诚实与局限性

标注 ❓ 的为待验证信息，请以实际发布版本为准

❓ 待验证

项目极新，稳定性待验证

RustGIS 于 2026-10-10 才创建，2026-10-13 首次 push。虽然 push 活跃，但距离生产环境使用还有待社区验证。Bug 修复节奏、功能完成度未知。

❓ 门槛

Rust 1.90+ 源码构建门槛

从源码构建需要 Rust 1.90+ 环境 ❓（原文「Rust 1.90+」标注）。若系统 Rust 版本较低，需要手动升级工具链，这对非 Rust 开发者有一定门槛。

❓ 待验证

WASM 功能覆盖可能小于桌面版

WebAssembly 运行环境与桌面存在差异，部分依赖本地系统调用或大型库的功能可能受限。实际功能覆盖率需待 Web 版稳定后验证。

❓ 待确认

GeoLibre / Whitebox 许可兼容性

1,000+ GeoLibre 和 Whitebox 工具的许可协议与 RustGIS Apache-2.0 的集成方式尚未明确。插件层面的许可链需仔细审查。

❓ 观察中

AI 模型费用

AI Assistant 支持多模型，但使用 Anthropic / OpenAI / Gemini 等商业模型会产生 API 费用。Ollama 支持本地部署可规避，但需 GPU 资源。

✅ 无问题

示例数据：Natural Earth 公有领域

World Atlas 示例项目使用 Natural Earth 公有领域数据，与 Apache-2.0 许可证完全兼容，商业使用无风险。
