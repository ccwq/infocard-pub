UI Skills：把界面改造收敛成可路由的设计技能目录

ui-skills.com 不是单一教程页，而是一个公开可浏览的技能目录：先让 agent 跑 CLI 选对技能，再按无障碍、动效、前端工艺、界面质量等主题路由到最小可用技能集。

Astro v5.16.7Curated Skill Directory@ibelickOpenAI / Claude / Cursor
一句话判断

它的重点不是“把 UI 做得更花”，而是把 UI 工作拆成可安装、可路由、可检查的技能层，让设计工程师和 agent 直接选到正确入口。

01
核心定位

这是一个面向设计工程师的技能目录，不是单页教程

首页文案明确说它是“a collection of design-engineering skills”，目标是帮助 humans and agents create better interfaces；公开首页同时展示集合、主题、浏览入口与安装命令。

Collection

目录化，而非散装条目

首页首屏就把 skills 作为可选目录呈现，适合让 agent 按主题挑选最小上下文。

Route first

先路由，再改 UI

公开文案要求先运行 CLI，先决定用哪个 skill，再去动界面，而不是直接开改。

Design engineers

人和 agent 都是使用者

它同时面向人类设计工程师与 agent，所以 UI 目录本身就是工作流入口。

02
可见结构

公开页面已经把技能拆成主题、最佳实践和更多分类

浏览区可见 Browse、Topics、Best skills、More 四个一级分区，页面内列出 ui-skills-root、baseline-ui、fixing-accessibility、fixing-motion-performance、frontend-design、wcag-audit-patterns、emil-design-eng、react-doctor 等条目。

01 / 路由

ui-skills-root

按 topic、stack、intent 路由到最小有用集合。

这是入口技能，先选它再选别的。

02 / 清理

baseline-ui

修 spacing、hierarchy、typography 和小布局问题。

偏快速 polish，不是重建系统。

03 / 可访问性

fixing-accessibility

ARIA、键盘、focus、contrast、form errors。

UI 质量不是只有视觉。

04 / 动效

fixing-motion-performance

布局抖动、合成层、滚动联动、blur。

把动效性能单独成技，是工程化信号。

03
入口与边界

安装命令、GitHub 入口、话题入口都直接可见

首页直接提示 `npx ui-skills start`，并给出 GitHub、Skills、Registry、llms.txt、Accessibility、Motion、Systems、Visual、Interaction、Performance 等导航，说明它既是目录也是分发层。

入口CLI

最小行动路径

  • 先跑 CLI
  • 再按主题浏览
  • 再加载最小 skill
边界约束

技能目录，不是单一框架库

它没有把所有 UI 知识揉成一个大 prompt，而是拆成可安装、可组合、可替换的条目。

04
代表条目

最值得先看的，是“路由、修复、工艺”三类技能

从公开首页看，优先级最高的是入口 skill、基础 polish skill、无障碍与动效性能 repair skill，再往后才是更偏风格与工艺的 frontend-design、emil-design-eng、make-interfaces-feel-better。

入口

ui-skills-root

负责把问题路由到最小可用技能集。

修复

baseline-ui

适合快速去 slop、补齐基础秩序。

审计

wcag / accessibility

把可访问性作为第一类质量门禁。

工艺

frontend-design

强调 production-grade 设计和实现。

05
适合谁

适合“想把 UI 能力做成工作流”的团队

如果你要的是设计工程师手边可直接调用的能力目录，这个站点更像工作台；如果只想找一个单独教程，它就显得过于目录化。

1

适合

设计工程师、前端团队、AI coding tools 使用者、需要把 UI 质量拆成技能的人。

2

不适合

只想看一个单页教程、或不愿意按 CLI / 目录方式选技能的人。

3

判断

这是“UI 能力分发层”，不是一个普通设计博客首页。

06

公开页可见安装提示和主题导航；OG 图与站点标题也明确表明它是 design engineers 的 curated skill directory。
