GoDoxy

High-performance Reverse Proxy & Container Orchestrator

新生代神器，把高性能反向代理和容器编排拧成一股绳。反代、容器管理一条龙全包，性能直接怼满。专为 NAS 用户、Docker 玩家、自部署爱好者设计，无需复杂配置文件，开箱即用。

反向代理 容器编排 WebUI 管理 自动 HTTPS
一个工具解决两个痛点

告别 Nginx/Caddy + Docker Compose 的组合拳，GoDoxy 通过 Docker labels 或配置文件自动发现容器、热加载路由、管理 Let's Encrypt 证书，一条命令搞定全部。
