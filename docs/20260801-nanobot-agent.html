核心定位
What nanobot is
nanobot 是"能跑在树莓派上"的多 Agent 框架——不是 Claude Code 的替代品，而是本地场景下的轻量选择。

市面上主流 Agent 框架（LangGraph、CrewAI、AutoGen）往往预设了云端部署、大量内存和复杂依赖。nanobot 的设计哲学刚好相反：极低门槛、单机运行、必要功能不缺。

它的核心场景是：个人开发者或小团队在没有云端基础设施的情况下，想要一个本地可用的多 Agent 工作流系统。WebUI 让你不需要写代码也能配置 Agent，Python 原生让扩展成本极低。

快速上手
Get started
# 安装 nanobot（一条命令）
pip install nanobot-agent

# 启动 WebUI（默认 http://localhost:8080）
nanobot serve

# 或使用 CLI 创建多 Agent 任务
nanobot task create --name "research" --agents 3
nanobot task run research --query "调研最新 Agent 框架"

# 接入本地模型（Ollama）
nanobot config set model.provider ollama
nanobot config set model.endpoint http://localhost:11434

# 查看任务状态
nanobot task status research

# MCP 工具注册
nanobot mcp add filesystem --path /path/to/tools
