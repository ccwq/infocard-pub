02
核心命令
teamai init
OAuth 登录、关联仓库、注册成员、注入 Hooks
teamai pull
会话启动时自动触发，同步最新资源到本地 AI 工具
teamai push
推送本地变更到分支，创建 MR 供评审
teamai recall
BM25 + 图谱增强搜索团队知识库
teamai import
从目录 / GitHub / MR / 腾讯 iWiki 导入知识
teamai contribute
将 session 经验分享到团队仓库
teamai digest
生成团队周报
teamai doctor
诊断配置问题
teamai source
管理跨团队 Skill 订阅
03
安装方式
npm 全局安装
# 国际网络
npm install -g teamai-cli

# 腾讯内部网络（使用工蜂镜像）
npm install -g @tencent/teamai-cli --registry=http://r.tnpm.oa.com

# 初始化（关联团队 Git 仓库）
teamai init https://github.com/yourorg/teamai-harness
