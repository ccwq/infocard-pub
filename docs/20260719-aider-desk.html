INSTALL

安装与上手

快速安装

多平台安装方式

Download Release npm / npx Docker Homebrew Scoop (Windows)
  • npm i -g aider-desk 或 npx aider-desk
  • Docker: docker run hotovo/aider-desk
  • Homebrew: brew install aider-desk
前置要求

依赖说明

AiderDesk 基于 Aider CLI 运行，需确保：

  • Aider CLI 已安装 (pip install aider-chat)
  • 至少一个 LLM API Key（OpenAI / Anthropic / 本地 Ollama 等）
  • Node.js 18+（桌面 Electron 模式）
  • Docker（可选，容器模式）
