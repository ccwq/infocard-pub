v2 DESIGN PHILOSOPHY · 设计原则
PAGE 04

核心设计原则

01
Hero = Thesis

页面开头是最能代表项目气质的元素。标题/图像/动效/演示，选择最能承载的那一个。

02
Typography = Personality

字体对的选择传递页面的性格，而不是中性的内容搬运工具。配对要审慎。

03
NEW
Ground in the Subject

用项目本身世界的材料来设计。领域本身的语言、器物、符号，是独特性的真正来源。

04
Restraint = Confidence

大胆只在一个地方。让那个 signature element 成为唯一记忆点，其他都保持克制。

v2 PROCESS · 协作流程
PAGE 05

Brainstorm → Build → Critique

1
Brainstorm + Plan

Token 系统（4-6 个颜色）、字体角色、ASCII 线框图、Signature 元素。计划先于代码。

2
Critique before Build

对照 brief 审视计划：是否有成为通用答案的部分？是则修正，说清改了什么。

3
Build with Specificity

遵循计划，CSS specificity 要小心：类型选择器 vs 类选择器可能互相覆盖，导致 padding/margin 出问题。

4
Critique + Screenshot

截图审查，比文字更能发现问题。遵循香奈儿原则：出门前拿掉一件配饰。
