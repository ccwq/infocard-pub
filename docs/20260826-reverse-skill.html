AUTHORIZED SECURITY RESEARCH · SKILL ROUTER

reverse-skill

让 AI Agent 先判断目标与授权范围，再选择逆向、安全测试或 CTF 的正确工作流，而不是凭感觉乱试命令
一条主线：Scope → Route → Toolchain → Evidence → Report
1定范围
2选路线
3查工具
4留证据
5出报告
MITClient-neutral授权优先

它不是一个“逆向工具”

reverse-skill 是给代码 AI 使用的安全技能路由包：先识别 APK、二进制、前端 JS、固件、CTF 等目标，再把任务分到对应方法论、工具与证据链。

核心原则Route first

先路由，再执行

它把工具检测、案例初始化、时间线、Evidence→Finding→Path 和报告交接组织成可重复流程，减少 AI 猜命令和重复踩坑。

43路由规则
173回归案例
44核心模块
Scope Gate必须先授权

安全边界不是附录

项目定位于合法安全研究、教育、CTF 和对自有或明确授权系统的测试。未经授权的访问、扫描、利用、干扰和数据获取被明确禁止。

发布口径：卡片只介绍授权场景下的分析与测试流程，不把 EDR bypass、漏洞利用或攻击链包装成无条件可执行能力。
目标分流

按对象选择 Skill

  • APK / Android → jadx、apktool、Frida 路线
  • ELF / EXE / DLL / SO → IDA、radare2、Ghidra
  • 前端签名 / 加密参数 → JS reverse
  • 固件 / IoT → firmware-pentest
  • CTF / Pwn / LLM security → 对应专项模块
共享资产

让经验能被复用

tool-index.md 记录工具状态，field-journal 保存命令、陷阱与案例经验，routing.json 作为路由配置的单一事实来源。

支持 Claude Code、Codex CLI、Cursor、Cline、Windsurf、Kiro 等客户端；核心路由不依赖某个特定编辑器。

安装Linux / macOS / Windows

初步使用

git clone https://github.com/zhaoxuya520/reverse-skill.git
cd reverse-skill

# Linux / macOS / Kali：刷新工具索引
bash skills/scripts/refresh-tool-index.sh

# 先阅读全局规则与路由入口
cat RULES.md
cat skills/MASTER-ROUTING.md
适合

授权的 APK / 二进制 / 固件分析、前端请求研究、CTF、工具链整理、案例复盘与报告交接。

不适合

没有明确授权范围的目标、把路由包当作自动攻击平台、或希望跳过证据和审计直接生成结论的任务。
