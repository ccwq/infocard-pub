01 · 核心价值
Core Value
One sentence

把"先扫文件再理解代码"改成"直接查图谱再追踪调用链"，大仓库里更省 token、更少工具调用、更快。

无 CodeGraph 时
Agent 用大量 Read / glob / grep 做文件探索，每次提问都重新扫描，token 浪费严重。
有 CodeGraph 时
预索引完成后，Agent 直接查图谱回答架构问题，通常 0 次文件读取 即可。
~16% ↓ 费用
token 消耗平均降低。
~58% ↓ 工具调用
更少的 Read / grep 调用。
~22% ↓ 时间
平均任务完成更快。

04 · MCP 工具集
MCP Tools
核心 8 工具
工具用途
codegraph_explore批量返回相关符号源码（主力）
codegraph_trace追调用路径
codegraph_callers查谁调用它
codegraph_callees查它调用谁
codegraph_impact评估改动影响面
codegraph_search全局搜符号名
codegraph_context组合式构建上下文
codegraph_status索引健康度 / 待同步文件
自动同步机制
W
File WatcherFSEvents / inotify / ReadDirectoryChangesW 编辑后自动触发索引重建，默认 2000ms 防抖。
P
暂挂文件 BannerMCP 响应前置于 ⚠️ 警告，提醒 agent 直接 Read 待同步文件。
C
连接时 Catch-upMCP 重连时自动做 (size, mtime)+hash 对账，吸收离线期间所有编辑。
env
CODEGRAPH_WATCH_DEBOUNCE_MS=2000
CODEGRAPH_NO_DAEMON=0

06 · 常用命令
CLI Reference
索引与状态
index management
codegraph init -i     # 创建 .codegraph/ 并构建索引
codegraph index         # 单独构建索引
codegraph sync          # 手动触发同步（通常不需要）
codegraph status        # 查看索引状态 + 待同步文件
codegraph uninit        # 移除 .codegraph/（保留 agent 集成）
Agent 集成
agent integration
codegraph install       # 检测并配置所有支持的 agent
codegraph serve --mcp   # 启动 MCP server（供 agent 连接）
codegraph uninstall      # 移除所有 agent 集成
codegraph uninstall --target claude-code  # 移除单个 agent
caution
安装 CLI 后必须单独运行 codegraph install 才算完成 Agent 连接。只装 CLI 不运行 install，Agent 不会用到 CodeGraph。
