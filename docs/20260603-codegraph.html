01 · 核心价值
Core Value
What it does

CodeGraph 把代码库的语义关系预先索引为 SQLite 数据库，通过 MCP Server 让 AI 编程工具在回答架构问题时直接查询图谱，而不是用 grep/Read/find 反复扫描文件。

原理
传统模式下，Agent 每回答一个问题都会 spawn 出 Explore 子代理扫描文件，消耗大量 token。CodeGraph 把这个过程反过来——先建好图谱，Agent 一条 tool call 就能拿到入口点、调用关系和代码片段。
效果
在 7 个真实开源项目的基准测试中（VS Code / Excalidraw / Django / Tokio / OkHttp / Gin / Alamofire），有 CodeGraph 的 Agent 平均节省 16% 成本、47% tokens、22% 时间、58% 工具调用。

03 · 核心工具
Tools
codegraph_explore
通用探索工具，回答"X 是怎么工作的"、"X 的实现流程"、"X 如何到达 Y"。一次调用返回入口点、调用关系和代码片段。
codegraph_search
快速定位符号。按名称搜索全代码库，基于 FTS5 全文索引，毫秒级响应。
codegraph_callers / callees
追踪调用关系。调用链分析用于理解一个函数被谁调用、它又调用了什么。
codegraph_impact
修改前评估工具。追踪符号的所有调用方和被调用方，评估修改的影响半径。
04 · 特性亮点
Key Features
智能上下文构建
一次 tool call 返回入口点、关联符号和代码片段，不需要昂贵的探索子代理。
FTS5 全文本搜索
按名称快速定位全代码库任意符号，毫秒级响应，无需文件扫描。
自动同步
FSEvents/inotify/ReadDirectoryChangesW 文件监控，2000ms 防抖自动重索引，修改即同步。
20+ 语言支持
TS/JS, Python, Go, Rust, Java, C#, PHP, Ruby, C/C++, ObjC/Swift/Kotlin/Dart, Lua/Luau, Svelte, Liquid, Pascal/Delphi。
14 框架路由感知
Django/Flask/FastAPI/Express/NestJS/Laravel/Rails/Spring/Gin/Axum/ASP.NET 等 URL → handler 链路识别。
iOS / RN 跨语言桥接
Swift↔ObjC 桥接、React Native legacy bridge + TurboModules + Fabric、Expo Modules。

07 · 适合谁 / 不适合谁
Boundary
适合
1
大型代码库探索VS Code、Django、Rails 这种规模的代码库，问架构问题时节省效果最明显。
2
成本敏感的团队按 token 计费的场景，58% 工具调用减少直接转化为账单下降。
3
改代码前评估影响codegraph_impact 直接给答案，不需要人工梳理调用链。
4
多语言混合项目iOS + React Native、Swift + ObjC 混编，原有工具无法追踪跨语言调用链。
不适合
✗
小型单体代码库代码量少时，grep/Read 的开销本身不大，CodeGraph 优势不明显。
✗
需要 AI 帮你写新代码CodeGraph 只回答"代码是怎么工作的"，不生成新代码。
✗
纯创意/文案类任务没有结构化代码库可索引的场景。
