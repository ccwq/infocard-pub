colbymchenry / codegraph · semantic code intelligence

把代码仓库先变成图，再让 Agent 查图

CodeGraph 为 Claude Code、Codex、Cursor、Hermes Agent 等编码 Agent 提供一个本地预索引图谱层：先把仓库变成语义知识图，再用 MCP 工具直接查图回答架构问题，少扫文件、少跑 grep、少花 token。

Average win~16% cheaper · 47% fewer tokens · 22% faster · 58% fewer tool calls
Run mode100% local · self-contained runtime · no Node required for install
SupportedClaude Code / Cursor / Codex / OpenCode / Hermes Agent / Gemini / Antigravity / Kiro
pre-indexed graph mcp local-first code intelligence
Key claim

它不是“更强的 grep”。它是在仓库之上加了一层可查询的图谱，让 Agent 直接问结构、问依赖、问影响面。

01 · 图谱总览
repo → graph → mcp → agent
concept mapcore flow
它解决什么问题
把“每问一个架构问题就重新扫仓库”的模式，替换成“先建立图谱，再用图谱回答”。大仓库里最省的是文件读取和重复探索。
为什么这件事有效
CodeGraph 把符号关系、调用路径、影响面做成可查询对象；Agent 不需要从零开始摸索上下文，而是直接问图。
适合谁
维护大仓库、跨文件追调用、看架构影响面、想把编码 Agent 变成“先查图再行动”的团队。
noteCodeGraph 的重点不是“快一两次”，而是让重复回答架构问题这件事从扫描式探索变成索引式查询。
02 · 安装与接入
Install & wire up
Step 1 · 安装 CLI
macOS / Linux 
curl -fsSL https://raw.githubusercontent.com/colbymchenry/codegraph/main/install.sh | sh
Windows PowerShell 
irm https://raw.githubusercontent.com/colbymchenry/codegraph/main/install.ps1 | iex
npm 
npm i -g @colbymchenry/codegraph
importantCLI 是自包含安装包，不需要 Node.js。安装完要重新打开终端，命令才会出现在 PATH 里。
Step 2 · 连接 Agent
agent integration 
codegraph install
它会自动给这些 Agent 配置 MCP server：
Claude Code✓
Cursor✓
Codex CLI✓
OpenCode✓
Hermes Agent✓
Gemini✓
Antigravity✓
Kiro✓
warning安装 CLI 只完成第一步；不运行 codegraph install，Agent 仍然不会接入图谱。
Step 3 · 初始化项目
project init 
cd your-project
codegraph init
初始化时会创建 `.codegraph/` 并完成图谱构建；后续文件变化默认自动同步。

04 · 工具与能力
MCP tools · languages · boundaries
核心 MCP 工具
01
codegraph_explore主力工具：批量返回相关符号源码与上下文，回答“是什么、在哪里、和谁有关”。
02
codegraph_trace追调用路径，适合查链路和“从哪进来、往哪出去”。
03
codegraph_callers / callees分别查谁调用它、它调用谁，快速构建依赖关系图。
04
codegraph_impact / search / context / status影响面、全局搜索、上下文拼装与索引健康检查，构成完整的图谱操作层。

05 · 结论
Why it matters
一句话判断
如果你的问题经常是“这个仓库里谁调用谁、改这里会影响哪里、某段逻辑藏在哪”，CodeGraph 会把 Agent 的成本从探索仓库，变成查询图谱。
最适合的场景
大仓库、长期维护仓库、多人协作仓库，以及需要把 Claude Code / Codex / Cursor / Hermes Agent 变成“先查图再动手”的团队工作流。
