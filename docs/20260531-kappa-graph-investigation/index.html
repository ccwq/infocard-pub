Kappa Graph — κ(G)：具备“知识权重”与“证据追溯”的语义知识图谱

Kappa Graph (kg) 是一个将认识论 layer 增加到图谱之上的系统。它不仅存储知识，更通过 Grounding Scores 衡量知识的“重量”：支持力度、矛盾检测、分歧保留。让 AI 助手不仅能找到答案，更能知道答案有多稳。

不仅是存储，更是“认识论工具”

Kappa Graph 解决了 RAG 系统的痛点：无法衡量来源的可靠性。它通过 vertex connectivity (κ) 理论，计算每个概念的落地得分（-1 到 +1），区分“广受印证”与“单一来源/存在矛盾”的信息。

核心差异化

与 GraphRAG 不同，kg 原生支持数学化的矛盾检测与分歧保留。它不强行挑一个胜者，而是保留冲突证据供决策。同时具备基于 Rust 的内存加速引擎和 FUSE 文件系统挂载能力。

对标分析

vs alternatives
Kappa Graph (kg)

强调“确信度”

核心是衡量知识的稳固程度。保留矛盾，全链路追溯，支持文件系统挂载。适合审计、科研和高可靠任务。

GraphRAG / Vector DBs

强调“召回率”

旨在寻找相关信息或总结。通常不具备数学化的确信度计算，且容易在矛盾信息面前表现不稳。

推荐使用顺序

  1. 阅读 docs/concepts 理解落地得分逻辑
  2. 使用 ./install.sh 一键部署后端
  3. 安装 kg-cli 并集成至 AI 助手 (MCP)
  4. 通过 FUSE 挂载尝试 Unix 工具探索知识

适用场景

  • 合规审计：全链路证据追溯
  • 科研综述：识别观点分歧与支持度
  • Agent 记忆：基于确信度的决策基础
  • 文档管理：基于语义的 Unix 文件探索
