💡 核心理念

这五款插件代表三种自进化路径：元认知（super-hermes 自我反思）、数据驱动（hermes-dojo 性能闭环）、能力扩展（workspace/plugins/colleague-skill 功能叠加）。当别人还在用工具，你的 Hermes 已经在养一个会进化的数字助手了。

关系图：从观测到能力扩展

super-hermes（自评/反思） ─┐
hermes-dojo（性能/弱点） ──┼→ 发现问题 → 迭代改进
hermes-workspace（工作台） ─┤
hermes-plugins（编排/成本） ─┘
colleague-skill（蒸馏） ─────────→ 把经验固化为可复用 Skill

选择路径：先要自我反思选 super-hermes；要指标闭环选 hermes-dojo；要集中操作面选 workspace；要跨 Agent 与成本治理选 hermes-plugins；要知识迁移选 colleague-skill。
