DOCKER COMPOSE · 完整配置示例
# 1. 创建 .env 文件配置环境变量
# 2. docker-compose.yml 示例配置

services:
  migrate:
    image: ghcr.io/kanbn/kan-migrate:latest
    environment:
      - POSTGRES_URL=${POSTGRES_URL}
  web:
    image: ghcr.io/kanbn/kan:latest
    ports:
      - "${WEB_PORT:-3000}:3000"
    env_file:
      - .env
  postgres:
    image: postgres:15
    volumes:
      - kan_postgres_data:/var/lib/postgresql/data

# 3. 启动服务
docker compose up -d

FAQ

常见问题

Q: 需要什么硬件配置？
最低 1 核 CPU + 512MB 内存即可运行，推荐 2 核 + 1GB。Docker + PostgreSQL 镜像加起来约 200MB。
Q: Trello 导入支持哪些内容？
支持导入看板列表、卡片、标签、成员和评论。附件和检查清单根据情况部分支持。
Q: 支持多语言吗？
支持多语言界面，团队成员可选择自己的显示语言。
Q: 适合团队规模？
适合 1-50 人的中小团队使用，看板可见性和权限管理可满足大多数协作场景。
Q: 数据如何备份？
自托管方案下，PostgreSQL 数据目录备份即可。Docker Compose 方式可配合定时快照或数据库 dump 脚本。
Q: 和 Notion、Linear 比有什么优势？
kanbn 专注看板，不像 Notion 那样重，也不像 Linear 那样收费贵。最适合只需要简单看板管理的场景。
