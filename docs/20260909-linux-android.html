为什么旧手机不该吃灰01

背景 · 痛点 · 误区
你的旧手机比树莓派还强

一部三年前的骁龙835手机：CPU 多核性能大概是树莓派 3B+ 的两倍，内存通常 4-6GB，集成屏幕、电池、WiFi、4G LTE。放在抽屉里积灰，是对硬件资源最大的浪费。相比之下，树莓派 3B+ 现在售价仍要 35 美元，而旧手机几乎是零成本。

传统改造方案的坑

很多人试过把旧手机变成服务器或电脑，但传统方案要么需要 Root（解锁 bootloader 刷机，有变砖风险），要么需要另一台 PC（双系统需要用电脑引导手机），要么依赖云服务（数据上云，隐私和稳定性都有隐患）。这些门槛让大多数普通用户直接放弃。

linux-android 的核心理念

这个开源项目（MIT License）用一条脚本把整个改造流程自动化：你只需要在 Termux 里跑两条命令，手机就变成一台真正的 Linux 主机。全部在用户空间运行，不需要 Root 权限，不碰 bootloader，完全可逆。

两种截然不同的用法

这个项目提供两条完全独立的路径：如果你想要的是一台随身 Linux 桌面，它支持四种桌面环境（XFCE4、LXQt、MATE、KDE Plasma）；如果你想要的是 24 小时在线的智能家居中枢，它可以把 Home Assistant Core 跑在你的手机上。

路径一：Linux 桌面模式02

桌面环境 · 安装步骤 · GPU 加速
硬件要求

处理器必须是 64 位（arm64），这是运行 Linux 桌面环境的最低门槛，目前市面上大多数 2017 年以后出厂的安卓手机都满足。内存建议 3GB 以上，如果想体验 KDE Plasma 桌面，建议 4GB 及以上。存储需要预留 5-10GB 的可用空间。Qualcomm 骁龙系列芯片的 GPU 支持最好，可以利用硬件加速；其他芯片（MTK、Exynos 等）会自动回退到软件渲染，基本功能不受影响，只是图形性能较弱。

软件准备（关键）

必须从 F-Droid（f-droid.org）安装 Termux，一定不要从 Google Play 安装——Play 商店里的版本已经严重过时，无法正常运行 Linux 环境。同时还需要从 GitHub Releases 页面下载并安装 Termux-X11 应用。这两个 App 都需要在手机上授予相应权限（存储、相机等，按提示操作即可）。

⚠️ 安装来源至关重要：Google Play 版本的 Termux 停止更新多年，缺少关键依赖库，安装脚本会在中途报错。如果你的手机里只有 Play 商店版本，请先卸载，然后去 f-droid.org 下载正版。

完成上述准备后，就可以开始正式安装了。整个安装流程分以下几个步骤，每一步都有自动化脚本处理，我们只需要按照顺序执行命令即可。

  • 第一步：打开 Termux，运行防休眠命令。这一步很重要——Android 系统会在后台自动挂起不活跃的应用，如果不提前锁定，Termux 会在你安装过程中被系统杀死。
    $ termux-wake-lock
    这会请求系统允许 Termux 在后台持续运行。命令执行后会看到一些输出，确认没有报错即可。
  • 第二步：升级 Termux 内置包。新安装的 Termux 内部系统包可能不是最新版本，部分依赖库版本过低会导致后续安装脚本报错。
    $ pkg upgrade -y
    这一步耗时取决于你的网络状况，通常需要下载 200-500MB 的更新包，建议在 WiFi 环境下操作。
  • 第三步：下载 linux-android 安装脚本。脚本托管在 GitHub 上，我们用 curl 下载。
    $ curl -O https://raw.githubusercontent.com/mayukh4/linux-android/main/termux-linux-setup.sh
    下载完成后，当前目录下会出现一个名为 termux-linux-setup.sh 的文件。
  • 第四步：赋予脚本执行权限并运行。
    $ chmod +x termux-linux-setup.sh $ bash termux-linux-setup.sh
    脚本运行后会以交互式菜单的形式让你选择：想安装哪种桌面环境（XFCE4、LXQt、MATE、KDE Plasma），以及是否要安装 Wine 来运行部分 Windows 程序。选择完毕后，脚本全自动执行，中间无需人工干预。
  • 第五步：启动 Linux 桌面。安装完成后，脚本会在用户目录下生成两个控制脚本。
    $ bash ~/start-linux.sh
    执行这条命令后，Linux 环境就会在后台启动。然后打开手机应用列表，找到并打开「Termux-X11」App——你的 Linux 桌面就会出现在屏幕上。整个过程大约需要 10-30 分钟，主要取决于你选择的桌面环境（XFCE4 最快，KDE 最慢）。
  • 第六步（可选）：停止 Linux 环境。
    $ bash ~/stop-linux.sh
    如果需要暂时关闭 Linux 环境，运行这条命令即可，不会影响你的安卓手机原有数据。
安装了哪些东西？

脚本自动安装的组件包括：Ubuntu Linux 发行版（通过 proot-distro 容器）、X11 显示服务器（Termux-X11）、Mesa 图形库与 Zink Vulkan 后端（用于 GPU 加速渲染）、桌面环境（你选的那个）、Firefox 浏览器、VLC 播放器、Python 3 运行时、OpenSSH（用于远程访问）、Git 版本控制。如果安装时选择了 Wine，还会额外安装 Hangover + Box64 以运行部分 Windows x86 程序。

GPU 加速的原理解释

这是这个项目最有技术含量的部分。Linux 桌面要渲染窗口、管理图形界面，离不开 GPU 驱动。高通骁龙芯片使用的是 Adreno GPU，项目脚本会尝试加载「Turnip」开源 Vulkan 驱动——这是专门为 Adreno 系列设计的开源驱动，能够利用硬件能力做图形渲染。如果你的手机恰好是高通芯片，默认就会启用 Turnip + Zink（Mesa 的 Vulkan-on-Vulkan 方案），图形性能会比纯软件渲染强很多。如果不是高通芯片（联发科、华为麒麟、三星 Exynos 等），脚本会自动回退到软件渲染，基础功能照常使用，只是动画流畅度会差一些。

能做什么？

Linux 桌面模式适合以下场景：Firefox 浏览器浏览网页、VLC 播放本地视频和音乐、用 SSH 远程连接（用电脑操作手机里的开发环境）、学习 Python 编程（已有 Python 3 环境）、Wine 运行部分 Windows 小程序（不是所有程序都能跑）、运行 Samba 搭建小型文件服务器。

不能做什么？

GPU 加速体验取决于你的芯片：非高通芯片用户图形性能较差。最耗资源的桌面环境（KDE Plasma）建议在骁龙 835 及以上设备上使用。蓝牙在 Termux 环境里可能无法正常工作。如果你需要运行对图形性能要求高的专业应用，仍然建议使用真正的电脑。

路径二：Home Assistant 智能家居服务器03

HA Core · 本地化智能家居 · 24/7 常驻

💡 很多人不知道：你家里花几百块买的「智能」灯泡和插座，其实极度依赖厂商的云服务器。一旦断网，或者厂商服务器出问题，你的智能家居就变成了「智障家居」——你甚至无法远程开灯。本地化 Home Assistant 彻底解决这个问题。

Home Assistant（以下简称 HA）是目前最流行的开源智能家居平台，它能够把不同品牌的设备（飞利浦 Hue、TP-Link Kasa、小米、涂鸦等）统一管理在一个界面里，而且完全运行在你自己的服务器上，不依赖任何外部云服务。把 HA 跑在旧安卓手机上，相当于花零成本拥有了一台 24 小时不间断运行的智能家居中枢。

  • 第一步：下载 HA 安装脚本。
    $ curl -O https://raw.githubusercontent.com/mayukh4/linux-android/main/setup-homeassistant.sh
    这条命令把安装脚本下载到当前目录。
  • 第二步：赋予权限并运行安装。
    $ chmod +x setup-homeassistant.sh $ bash setup-homeassistant.sh
    脚本会自动通过 proot-distro 部署一个轻量的 Ubuntu 容器环境，并在其中安装 Home Assistant Core。整个安装过程是全自动的，但耗时会比较长——主要时间花在编译 numpy、cryptography 等 Python 依赖库上。安装时间从 15 分钟到 45 分钟不等，取决于你的手机 CPU 性能。整个过程你不需要做任何选择或配置。
  • 第三步：启动 Home Assistant。安装完成后，你会在家目录下找到一个启动脚本。
    $ bash ~/start-homeassistant.sh
    Home Assistant 会在后台启动。首次启动会比较慢，需要等待所有组件加载完毕。
  • 第四步：在浏览器里访问 HA 控制台。确保你的手机和电脑（或其他设备）在同一个 WiFi 网络下，然后打开浏览器，在地址栏输入：
    # 把 替换成你手机的局域网 IP 地址 http://<phone-ip>:8123
    你可以通过在 Termux 里运行 ifconfig 查看手机当前分配的局域网 IP 地址（通常是 192.168.x.x 格式）。第一次访问时，HA 会引导你创建管理员账户，按提示操作即可。
  • 第五步：让 HA 24 小时常驻运行（关键）。默认情况下，Android 系统会在应用进入后台一段时间后自动杀死它，导致你的 HA 在夜里悄悄停止。解决方案是使用 termux-wake-lock 阻止系统休眠，然后用 nohup 让进程在后台持续运行：
    $ termux-wake-lock $ nohup bash ~/start-homeassistant.sh > ~/hass.log 2>&1 &
    如果希望每次打开 Termux 时 HA 自动启动，可以把这条命令加入 ~/.bashrc 文件末尾：
    $ echo 'termux-wake-lock && nohup bash ~/start-homeassistant.sh > ~/hass.log 2>&1 &' >> ~/.bashrc
    这样每次打开 Termux，HA 就会自动在后台启动。把手机插上电源，放在家里角落，它就变成了一台永远不会关机的智能家居服务器。
支持哪些智能设备？

Home Assistant Core 内置超过 2000 种设备集成，涵盖市面上绝大多数主流智能家居品牌。以下是常见设备的连接方式：

设备类型品牌示例连接方式备注

⚠️ 已知限制：Home Assistant Core 无法通过 Termux 访问手机自带的蓝牙模块，所以蓝牙设备暂时无法使用。另外，Android 10 及以上版本会阻止应用程序读取 /proc/net/dev（用于设备自动发现），因此添加设备时需要手动输入 IP 地址，不能依赖自动发现功能。如果需要 Zigbee 或 Z-Wave USB 设备接入，需要使用专用的 USB 适配器，但这要求设备有 OTG 支持和 Root 权限。

HA Core vs HA OS 的区别

Home Assistant 有两种运行形态：HA OS 是专门为树莓派等设备优化的完整操作系统，包含完整的 Docker 容器管理、Supervisor 管理和各种官方插件。HA Core 则是一个纯 Python 应用，剔除了所有这些附加组件，只保留核心的自动化引擎。本项目运行的是 HA Core——这意味着它更轻量，但不支持那些需要 Docker 的插件（大多数用户用不到这些插件，自带的 2000+ 核心集成完全够用）。

技术深潜：为什么不需要 Root？04

proot-distro · Termux-X11 · GPU 渲染
proot-distro：用户空间里的 Linux 容器

proot-distro 是 Termux 提供的一个工具，它能在不借助 Root 权限的情况下，通过系统调用劫持和重定向，在用户空间模拟出一个完整的 Linux 发行版环境。简单理解：你的安卓内核依然运行安卓系统，但在它上面叠加了一层「假装的」Ubuntu 文件系统和命令行。对大多数 Linux 应用来说，proot-distro 提供环境和真正的 Linux 完全一样。

Termux-X11：把 Linux 桌面渲染到手机屏幕

X11 是 Linux 桌面环境使用的显示协议标准。Termux-X11 是一个运行在安卓端的 X11 显示服务器，它接收来自 Linux 容器内部运行的桌面环境程序的渲染指令，在安卓的屏幕缓冲区里绘制出窗口和界面。换句话说：Linux 桌面程序不知道自己跑在手机上，以为自己在向一台普通 Linux 电脑的显示器发送画面；而 Termux-X11 负责把这个「假装的」画面实时转译到你的手机屏幕上。

Mesa / Zink：开源 GPU 加速方案

Mesa 是 Linux 生态里最核心的图形库，Zink 是 Mesa 内置的一个 Vulkan 后端，能让不支持原生 OpenGL 的程序通过 Vulkan 接口运行。Zink 的特殊之处在于：它可以同时调用系统已有的 Vulkan 驱动（高通 Adreno 芯片有原生 Vulkan 支持），也可以回退到 CPU 软件渲染。linux-android 脚本正是利用 Zink，让没有原生 OpenGL 支持的 Linux 程序通过 Vulkan 路径复用 Adreno 的硬件加速能力。

Turnip：Adreno 的开源 Vulkan 救星

Turnip 是为高通 Adreno GPU 开发的开源 Vulkan 驱动。正常情况下，Linux 桌面程序需要厂商提供的专有驱动才能利用 GPU 能力，但 Adreno 在 Linux 环境里没有官方驱动。Turnip 团队通过逆向工程实现了基本的 Vulkan 支持，质量已经相当可用。linux-android 脚本在检测到高通芯片后会自动加载 Turnip，Adreno 600 系列及以上用户受益最多。

常见问题 FAQ06

选型建议 · 操作疑问 · 已知限制
问题答案
Play 商店的 Termux 可以用吗？不可以。Play 商店版本已停止更新，缺少项目所需的依赖库。必须从 f-droid.org 下载最新版本。
会不会把手机弄坏？不会。整个过程完全运行在用户空间，不触及 bootloader，不修改系统分区，不影响手机原有的安卓系统。
旧手机能带得动 KDE Plasma 桌面吗？骁龙 660 及以下建议选择 LXQt 或 XFCE4；骁龙 835 及以上可以尝试 KDE，体验会好很多。
两个模式可以同时运行吗？技术上可以，但资源消耗会比较大（两个 Linux 环境同时跑）。建议分开使用，按需切换。
手机发热和电池问题怎么处理？建议全程插电使用，不依赖电池。Termux-wake-lock 会让系统在息屏后仍然保持运行，手机会有明显发热是正常现象。
蓝牙设备能接入 Home Assistant 吗？目前不能。HA Core 通过 Termux 运行时，无法访问手机自带的蓝牙适配器。如果需要蓝牙设备控制，建议通过云端接入。
Android 10 及以上无法自动发现设备怎么办？在添加设备时手动输入智能设备的 IP 地址即可。大多数品牌的 App 里可以找到设备的局域网 IP，或者在路由器后台查看设备列表。
数据存在哪里？所有数据都在手机的内部存储里，没有云端同步。HA 的配置数据和历史记录会保存在 Termux 的用户目录下（~/.homeassistant/）。
