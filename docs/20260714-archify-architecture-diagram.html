`archify` 是个 Agent Skill，接入 Claude Code / Codex CLI / opencode，大白话描述你的系统，架构图立刻生成，支持 PNG / JPEG / WebP / SVG 导出。

Zero Design Skills

大白话 → 专业架构图

JSON IR → 多渲染器 → 自包含 HTML · 支持 JSON Schema 验证

💬 大白话描述需求
用自然语言告诉 Archify 你的系统结构，如"React 前端调用 Node.js API，后端 PostgreSQL + Redis"
🧠 生成 JSON IR
Archify 解析需求，生成结构化的 JSON 中间表示，包含组件、连接、边界等语义信息
🎨 多渲染器输出
渲染器生成自包含 HTML 图，支持深浅主题切换、JSON Schema 验证和迭代修正
📤 一键导出
PNG / JPEG / WebP 最高 4× 分辨率（无插值模糊），SVG 真矢量，剪贴板一键复制
