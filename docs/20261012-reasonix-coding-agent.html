②Reasonix 是什么

esengine / DeepSeek-Reasonix，35,769 ★，MIT 协议，一个本地运行的 DeepSeek-native AI 编程 Agent。

主开发语言已从 TypeScript 迁移到 Go（main-v2 分支为新默认）， TypeScript 版（main 分支）仅维护模式，不再新增功能。

  • 正经 agent 干活：读项目代码、改文件、跑命令和测试
  • 权限分级：可直接动 / 先问两类，可按工作区配置
  • 文件改动回退：改坏了不用 git 救命
  • 四种使用形态：桌面 Studio / 终端 / 浏览器 / VS Code
⚠️ 注意：main-v2（Go 重写）是当前开发主线，TypeScript 版（main 分支）仅维护，不建议在新项目使用 TS 版。

③四种使用形态

Reasonix 提供了从终端到桌面的多个入口，选择哪个取决于你的工作流：

  • Reasonix Studio（桌面应用）：Tauri 原生 GUI，多 tab，右侧面板显示本会话读/编辑的文件，底部有 cost/cache/token 仪表板。GitHub Releases 下载中（prerelease）。macOS 需 xattr -dr com.apple.quarantine 放行。
  • reasonix code（终端命令）：最核心用法，reasonix code [dir] 启动，带完整 agent 能力。另有 reasonix chat（纯聊天）、reasonix run "task"（一次性任务，流式输出）、dsnix 别名。
  • 浏览器 Dashboard：嵌入式 web 界面，随时查看当前会话上下文和状态。
  • VS Code + ACP 协议插件：在 VS Code 内通过 ACP 协议接入 Reasonix，适合不想离开编辑器的开发者。
选型建议：日常主力用 reasonix code；需要 GUI 盯状态用 Studio prerelease；VS Code 用户装插件；需要远程协作开 QQ Channel。

④三支柱架构

Reasonix 能在本地稳定高效运行，靠的是三个核心工程支柱：

  • Pillar 1 · 前缀缓存优先循环（Cache-first Loop）：DeepSeek 原生 prefix-cache 工程实现，而非偶发缓存。实测 435M input tokens，99.82% 缓存命中率，费用约 $12（DeepSeek v4-flash），对比无缓存约 $61。Claude Code / Cursor / Aider 均不适用此架构。
  • Pillar 2 · 工具调用修复（Tool-call Repair）：Agent 调用工具失败时自动修复重试，提升循环稳定性。
  • Pillar 3 · 成本控制（Cost Control）：/effort 旋钮调节投入力度，按需控制成本。
实测数据：435M tokens · 99.82% cache hit · ~$12 vs 无缓存 ~$61（DeepSeek v4-flash）。成本约为 Claude Code 的零头。

⑤安装与快速上手

前提：Node ≥ 22。跨平台：macOS · Linux · Windows（PowerShell / Git Bash / Windows Terminal）

  • npm install -g reasonix · 安装主体（TypeScript 版）
  • dsnix · 与 reasonix 完全等效的别名，方便高频输入
  • reasonix doctor · 健康检查，诊断配置问题
  • reasonix update · 升级自身
  • reasonix replay · 回放历史会话 transcript
  • reasonix diff · 查看 agent 改动差异
  • reasonix events · 查看事件流
  • reasonix stats · 会话统计（token / cost / cache）
  • reasonix index · 重建语义索引
  • reasonix mcp · MCP 服务管理
  • reasonix prune-sessions · 清理过期会话

配置文件位置：
· 全局：~/.reasonix/config.json
· 项目级：<project>/.reasonix/（优先级更高）
· 全量双语配置指南：官方配置文档

桌面客户端（Tauri prerelease）：
· macOS：下载后执行 xattr -dr com.apple.quarantine /Applications/Reasonix.app 放行 Gatekeeper
· Windows：SmartScreen 弹窗 → More info → Run anyway
· Linux：.deb 或 .AppImage 格式，GitHub Releases 下载

⑥核心配置选项

  • MCP Servers：支持 stdio / SSE / Streamable HTTP 三种传输方式，可接入各种 MCP 工具。
  • Skills：Markdown playbook，inline 模式（直接在对话中执行）或 subagent 模式（子 agent 独立运行）。兼容 Claude-format skills（.claude/skills/）。
  • Memory：project memory（项目级）+ global memory（全局）。类型：user / feedback / project / reference。
  • Hooks：PreToolUse / PostToolUse / UserPromptSubmit / Stop，精细控制 agent 行为时机。
  • Web Search：Bing 默认，可切换 Baidu AI / SearXNG / Metaso / Tavily / Perplexity / Exa / Brave / Ollama。
  • 语义索引：支持 local Ollama 或 OpenAI-compatible embedding 模型。
  • Checkpoint：自动 checkpoint，文件安全有保障。

⑦权限与安全机制

Reasonix 内置多层安全设计，防止 Agent 失控：

  • Shell Allowlist：per-workspace 白名单，Agent 只能在允许的目录和命令范围内执行 shell 操作。
  • 文件回退机制：改动自动 checkpoint，改坏了直接回退，不用靠 git 救场。
  • 权限分级：可设置哪些文件/目录可以直接改，哪些必须先问。
  • 非 git 救命的改动恢复：checkpoint 系统兜底，即使不在 git 管理下的文件也能恢复。
设计哲学：DeepSeek-only 是有意为之，不是缺陷——专注单一后端才能把 prefix-cache、权限、checkpoint 全部做深。

Tool-call Repair
Pillar 2 支柱：Agent 调用工具失败后自动诊断并修复重试，提升 agent 循环稳定性。
ACP 协议
Anthropic Code Protocol，Reasonix VS Code 插件使用的通信协议，让 Reasonix 与 VS Code 无缝集成。
