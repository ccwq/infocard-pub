PODCASTS · 播客精华
Latent Space — "Why Agents Keep Failing"

大多数 Agent 失败不是智能失败，是工具调用失败。系统在推理上没问题，但无法可靠地在正确时间调用正确 API。关键洞察：当 Agent 拥有超过 15 个工具时，工具选择准确率从 95% 跌至 60%。修复方案不是更聪明的模型，而是更好的任务级工具筛选。业界预测 2026 年 Agent 框架将从 50+ 收敛至 3-4 个赢家。

No Priors — "Scaling Laws Are Dead"

规模定律已死？新范式正在形成，EVAL 驱动的开发正在取代凭感觉的 Prompt 迭代。

工作原理 05

① 中心化 feed 每日抓取博客文章、YouTube 字幕、X 帖子

② Agent 一次 HTTP 请求获取 feed，无需任何 API key

③ Agent 按你的偏好重新混编内容（英文/中文/双语）

④ 摘要推送至 Telegram、Discord 或直接在聊天窗口显示

隐私：所有配置、偏好和阅读记录保留在本地设备。
