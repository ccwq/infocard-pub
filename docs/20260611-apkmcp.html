01
核心定位

不是又一个命令行工具，而是让 AI Agent 懂 Android 逆向

ApkMCP-Auto 的核心叙事是把 Android 逆向工程工具（MCP化）变成 AI Agent 可以调用的能力。你描述目标，Agent 决定调哪个工具、执行什么动作、自动生成报告。

Why it exists

传统 Android 逆向需要人操作 JADX、看 Smali、调 Frida、写报告。ApkMCP-Auto 的思路是：让 AI Agent 承担操作层，你只需要说"分析这个 APK 的广告 SDK 并给出去除方案"。

MCP 协议

把逆向工具变成 AI 可调用的 MCP 工具

每个工具都封装成 MCP Server，AI 助手通过标准 MCP 协议调用。不需要写胶水代码，只要配置 AI 客户端即可。

auto-report

自动生成 Markdown 分析报告

提示词模板 + MCP 工具链 → 自动生成结构化报告（广告分析/会员分析/加固分析/网络分析等）。

Windows only

专注 Windows 生态，面向国内逆向工程师

README 明确面向 Windows 10/11，内嵌 JRE，无需单独装 Java。上手路径对国内用户友好。

02
7 个 MCP Server

覆盖静态分析、动态插桩、设备调试、签名重打包全链路

README 明确列出了 7 个组件，每个都对应一个具体工具或能力维度，端口从 8651 到 8657。

JADX

JADX MCP Server

实时反编译、代码搜索、重命名、交叉引用分析、调试器集成。Java 版本，端口 8651。

APKTool

APKTool MCP Server

APK 解码/编码、Smali 浏览修改、资源文件管理、工作空间管理。端口 8652。

ADB

ADB MCP Server

设备连接、APK 安装卸载、日志捕获、Shell 执行、文件传输、截图。端口 8653。

Sign

Sign Tools MCP Server

密钥库生成管理、APK 签名（V1/V2/V3）、签名验证、zipalign 对齐。端口 8654。

Static

Static Analyzer

权限分析、字符串提取、URL/IP/API 端点识别、SDK 识别。端口 8655。

Diff

Diff Tool

APK 文件对比、Smali 行级对比、资源目录对比、通用文本对比。端口 8656。

Frida

Frida MCP Server

进程附加、JS 脚本注入、函数 Hook、网络拦截、内存操作。端口 8657。

03
安装与入口

三步上手：安装依赖 → 生成 MCP 配置 → 启动工具

README 给出了很清晰的上手路径：统一命令行工具 `apkmcp.py` 处理安装、配置和启动，不需要逐个手动配置每个工具。

installconfigstart

统一命令行工具（推荐）

python apkmcp.py install
python apkmcp.py config
python apkmcp.py status
python apkmcp.py start jadx
start_all_servers.py

批量启动脚本

python start_all_servers.py
python start_all_servers.py --servers jadx,apktool,adb

也支持 Windows 批处理脚本 start-servers.bat。

前置要求：Python 3.10+ · Java 17（内嵌在 tools/bin/jre）· Windows 10/11 · 建议 8GB+ RAM。JRE 已随工具包附带，无需单独安装 Java。
04
提示词模板

不只是工具集合，还带了"怎么用 AI 分析 APK"的提示词模板

README 单独列出了提示词模板部分，说明作者在设计时就考虑了"AI + 工具"协同工作流，模板覆盖广告去除、会员验证、加固识别、网络分析等场景。

广告分析

广告 SDK 识别和去除方案

AI 使用 Static Analyzer + JADX + APKTool 联合分析，生成去除广告的具体代码位置和修改步骤。

会员分析

会员验证机制分析

分析 APK 的会员验证逻辑，定位关键代码，给出逆向修改方案。

加固分析

加固识别和脱壳方案

识别加固类型（梆梆/爱加密/腾讯乐固等），结合 Frida 动态分析给出脱壳路径。

网络分析

网络通信分析

使用 Frida Hook 网络请求，提取 API 端点、加密逻辑和通信协议。

逆向分析

综合逆向工程报告

完整逆向分析报告，包含执行摘要、应用概况、详细分析、解决方案、风险评估。

05
适合 / 不适合

适合把 AI Agent 变成 Android 逆向助手，不适合纯手动操作场景

ApkMCP-Auto 的价值在于"AI + 工具协同"。如果你想用 AI Agent 做 Android 逆向，它是目前少有的 MCP 化开源路径；如果只是偶尔手动分析一个 APK，可能直接用 JADX 更直接。

适合

最适合的场景

  • 想用 AI Agent 做批量 APK 安全分析。
  • 需要 AI 辅助的 Android 逆向工程项目。
  • 想构建"提示词 → MCP → 工具 → 报告"自动化工作流。
  • 广告去除、会员验证、加固分析等重复性逆向任务。
不适合

不该硬用的场景

  • 只是偶尔手动分析一个 APK，不需要自动化。
  • 不需要 AI 辅助，纯靠人操作逆向工具。
  • macOS / Linux 环境（当前仅支持 Windows）。
