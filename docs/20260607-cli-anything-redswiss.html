01CORE VALUE · 为什么是 CLI
Today's Software Serves Humans. Tomorrow's Users will be Agents. — CLI 是人类和 AI Agent 共同的最佳接口：结构化可组合、轻量通用、自描述（--help 自动发现文档）、JSON 输出消除解析复杂度。
cli-hub list

浏览 Hub 全部可用 CLI

cli-hub search <query>

按关键词搜索

cli-hub install <name>

一键安装社区 CLI

cli-hub launch <name>

运行已安装 CLI

02QUICK START · 两种入口
// 入口一：人类工具包（pip）
pip install cli-anything-hub
cli-hub list          # 浏览全部 CLI
cli-hub install gimp  # 安装
cli-hub launch gimp   # 运行
// 入口二：Agent 工具包（npx skills）
npx skills add HKUDS/CLI-Anything --skill cli-hub-meta-skill -g -y

# 然后对 Agent 说：
# "Find appropriate CLI software in CLI-Hub and complete the task: ..."
