它解决什么

把“收藏很多”改成“只保留高表现内容”

很多 X 用户每天看到很多案例、增长技巧和 AI 经验，却很少真正沉淀。本 Skill 的目标是先按浏览量筛掉噪音，再把有价值的推文自动归档进 Obsidian，让收藏变成可复用知识资产。

content creators indie hackers product growth
工作流骨架

输入博主链接，沿真实链路自动保存

  • 1. 输入X 博主链接 / 多个博主列表
  • 2. 筛选按浏览量保留高表现推文
  • 3. 剪藏调用官方 Obsidian Web Clipper
  • 4. 归档自动写入 Obsidian 并长期沉淀
仓库信息

它是一个 Python Skill，面向内容采集

GitHub 元数据显示该仓库为 Python 项目、当前 16★、未声明 License；README 也强调支持 Chromium 系浏览器，并建议使用 Dia 浏览器。核心不是“做一个收藏夹”，而是做一个可持续的推文对标流水线。

前置要求

先把运行环境搭好，再跑采集

01

安装 Obsidian：先准备好 Vault，才能让 Web Clipper 有落点。

02

安装官方 Web Clipper：浏览器插件是自动保存的关键依赖。

03

登录 X 账号：Skill 读取当前浏览器登录态获取推文信息。

04

打开目标 Vault：确保剪藏后能直接进入正确的知识库目录。

一句话结论

这不是“收藏工具”，而是“高表现推文的知识资产流水线”

X To Obsidian Skill 的价值在于把 X 上的高浏览量内容变成 Obsidian 里的可检索素材库：它既保留社媒信号，又能把内容沉淀到长期知识系统中，适合做对标研究、选题拆解和长期观察。
