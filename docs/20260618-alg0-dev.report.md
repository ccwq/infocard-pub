## 卡片取舍
- 这张卡没有假装知道所有实现细节，只基于首页公开可见信号来写。
- 重点不是“多少算法”，而是“它把算法学习做成了播放器式交互画布”。
- graph-paper 风格适合它，因为：
  - 左侧目录 = 索引图谱
  - 顶部控制条 = 状态机 / 运行时
  - 多语言 + 40 路由 = 结构化知识网络

## 没有过度声称的部分
- 没写它背后仓库结构，因为当前任务是网站卡，不是仓库卡
- 没假设所有分类名称都在公开 DOM 中完整可见；有一部分是从可见路由集合推断
- `site.webmanifest` 当前返回 404，因此没有把 PWA 能力写成确定事实
