3
Zero-Config Startup

免 Key 启动机制

两条路径：Pinokio 一键傻瓜式 / 终端 npm install 开发者式 · 冷启动中位数 1.86s（M5/Chrome 时点采样）

🟢 Path 1：Pinokio 一键

装 Pinokio → Discover → Download from URL → 粘贴仓库 URL → Install → Start

启动器自动验证运行时、安装锁定依赖、找空闲本地端口、打开应用。完全零终端操作。

🟢 Path 2：终端安装

npm install → npm run doctor → npm run dev

macOS 可用 ./scripts/dev-fresh.sh 清 Vite 缓存并从 Keychain 拉取已配置 Key，同样零 Key 启动。

🔒 密钥安全存放

Pinokio → pinokio/ENVIRONMENT（应用忽略）
终端 clone → 仓库根 .env

写入前先设文件为 owner-only。密钥永不离开本机。服务端只绑定 localhost。

# 冷启动中位数 1.86s（M5/Chrome 时点采样，比较基线非硬件要求）
➜ npm run dev
  Local:  http://localhost:4173
  Node:  24.14.x 或 26.x（25 可用但 EOL，仅警告）
  Stack: Vanilla JS + CesiumJS + Vite

注意：不要在 Pinokio 8.0.40 原生 Configure 面板输入凭据——该版本不正确保存嵌套应用文件且会记录提交值。

Basemap Ladder

底图阶梯三档

从零配置 Esri+OSM 卫星底图，到免费 Cesium ion 出 Google Photorealistic 3D，再到 Google Maps key 计费路线

🟢 零配置

Esri + OSM 卫星底图

Esri World Imagery 卫星底图 + 免 Key 地形，2D。Esri 不可达时 OSM 自动接管。地形不可用时地球继续运行。

🟡 免费 ion Token

Google Photorealistic 3D 城市

Cesium ion 免费 Token 出 Google Photorealistic 3D 城市 + 世界地形。符合资格的个人非商用用途，遵循 ion 现行条款与配额。

🔴 Google Maps Key

Google 直连 + 地点搜索

同样 3D 但直连 Google + 应用内地点搜索。按量计费路线，所有 API Key 均通过服务端代理，浏览器不可见。

"切换夜视并打开航班图层" / "追踪那架飞机" → "进入驾驶舱"

Under the Hood

工程实现细节

7 条关键技术决策：无框架 Vanilla JS + CesiumJS + Vite，卫星 SGP4，大地水准面感知，安全代理

🛰️ 世界稳定图标航向投影

飞机和船只在每个相机角度都指向真实世界航向——逐帧屏幕空间航向投影。无旋转、无视口锁定。

📡 平滑运动与航位推算

实时数据每 15–30s 到达；地球渲染落后真实时间一个间隔并在已知定位点间插值；推算航位推算填补空隙。

🌍 SGP4 + GMST 卫星轨道传播

诚实的卫星：SGP4 传播 + 通过 GMST 实时校正锁定的轨道环。不漂移、不逐秒闪烁。

🏔️ 大地水准面感知实体高度

实体高度走真实垂直基准——对渲染地形网格采样，飞机停在停机坪、摄像头站在街角而非漂浮。

💰 精打细算的配额预算代理

付费数据源跑在缓存且预算受控的代理后——OpenSky 额度调节器、TomTom 每日瓦片预算、磁盘缓存 TLE。

🔐 SSRF 防护服务端代理

每个接触私钥的 API（OpenAI、AISStream、OpenSky OAuth、摄像头帧）都通过加固服务端代理，带 SSRF 防护、响应上限和净化错误。
