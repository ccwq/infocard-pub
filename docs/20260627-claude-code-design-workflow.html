模块一 · 初始化连接与授权

1

触发登录认证

在 Claude Code 终端输入 /design login，浏览器自动弹窗完成云端授权连接。整个认证流程无需复制 Token。

$ claude
→ /design login   # 触发浏览器授权弹窗
浏览器弹窗认证 无需手动配置 Token 首次配置一次
2

验证连接状态

登录完成后，通过 /design stats 确认三项状态：云端 Design System 列表加载、GitHub 仓库关联、当前设计上下文。

$ /design stats
Design System: 已连接 ✓
GitHub 仓库: 已关联 ✓
云端同步: 正常 ✓
/design stats 验证门禁 确保云端可访问
⚠ 前置要求：首次配置前确保网络可访问 claude.ai 云端服务，且 Claude Code 已升级至最新版本（含 2026-06 Beta 功能更新）。

模块二 · 快速创建 UI 与双向状态同步

1

自然语言描述 UI 需求

在 Claude Code 中附加具体需求描述（如"创建一个手机端设置页面，包含账号、安全、通知三个 Tab"），Claude Design 自动生成对应的 UI 结构与布局代码。

$ /design
# 自然语言输入需求
"创建一个手机端设置页面，
  包含账号、安全、通知三个 Tab，
  使用深色主题"
自然语言驱动 实时生成预览
2

浏览器内实时预览与深度微调

Claude Design 自动在浏览器中打开 UI 调试页面。两种微调方式：自然语言对话修改，或进入 edit 模式直接在属性面板调整颜色、字体、布局模式、元素间距。

# edit 模式中直接操作
字体: PingFang SC 14px
背景: #0c1430
间距: 16px 12px
圆角: 12px
像素级调整 edit 模式 所见即所得
3

代码同步到本地（Pull）

设计完成后，在 Claude Code 终端输入拉取指令，将设计端最新 UI 状态同步覆盖到本地代码文件（React / Tailwind / HTML 等）。

$ /design pull   # 拉取设计端最新代码
已同步:
  src/components/SettingsPage.tsx ✓
  src/styles/settings.module.css ✓
/design pull Design → Code 自动生成源文件
4

代码反哺设计规范（Push）

在 Claude Code 侧完成代码修改后，/design push 将变更回写至云端 Design System，使设计器中的组件规范与源码保持同步。

$ /design push   # 代码反哺设计系统
已更新云端组件:
  Button.tsx v2 ✓
  InputField.tsx v1 ✓
/design push Code → Design Design System 同步

模块三 · 存量项目接入与设计规范重构

1

提取现有项目为 Design System

在现有项目目录下执行 /design sync，Claude Code 自动扫描项目 UI 代码，提取样式规范、色板、组件接口，上传至云端 Design System 库。

$ cd ~/my-project
$ /design sync   # 提取为 Design System
扫描中... 提取样式规范
上传到云端 Design System ✓
/design sync Design System 提取 自动扫描 UI 代码
2

跨项目复用设计规范

在后续新项目中，直接指定复用已上传的 Design System，确保全局 UI 风格一致（颜色、圆角、间距、字体统一），无需重复定义基础组件。

$ /design load my-design-system
已加载:
  主色板 / 字体规范 / 圆角系统
  Button / Input / Card 组件库
跨项目复用 Design System 加载 一致性保障
3

深度逆向重构：GitHub 仓库 → 可视化 UI → 重构 → 导回代码

Claude Design 支持关联 GitHub 仓库（React / Swift / Vue 等），将已有项目代码逆向解析为可视化组件。在设计器中重构 UI 后，直接导回代码仓库，形成完整的逆向-正向闭环。

$ /design link github:owner/repo --branch main
# 关联 GitHub 仓库，自动逆向解析 UI 组件
✓ 识别 React 组件 12 个
✓ 解析样式规范 8 项
✓ 生成可视化组件图谱
/design link GitHub 逆向解析 可视化重构 React · Swift · Vue

系统约束与风险提示

🔒 MCP 协议依赖

双向打通依赖 MCP（Model Context Protocol）协议实现。需确保 Claude Code MCP 服务保持可用状态；MCP 连接异常会导致设计与代码同步中断。

🎨 复杂结构调整优先在 Design 界面

涉及布局模式、组件层级、响应式断点等结构性调整，优先在 Claude Design 可视化界面完成后再执行代码同步，以确保同步准确性。

🌐 网络环境要求

Design System 存储在云端，设计同步、GitHub 关联、Design System 拉取均需要稳定访问 claude.ai 云端服务。

📦 版本兼容性

2026-06 起 Claude Code 新增 /design 命令。旧版本仅支持基础功能，请升级至最新版以获取完整双向同步能力。
