03
TECH STACK

技术栈与架构

Python 3.10+ · uvx 包管理 · FastMCP 框架 · DashScope OpenAI 兼容 API · MCP 协议。配置统一写入 ~/.qwen-mm-plugins/config。

包管理

uvx

首次运行自动安装依赖，无需手动 pip。astral.sh/uv。

MCP 框架

FastMCP

工具自动注册，MCP Server 托管，零配置暴露工具。

Agent 协议

MCP + Skill

Skill 告诉模型"有哪些工具"，MCP Server 执行工具。

配置

~/.qwen-mm-plugins/config

KEY=VALUE 格式，GUI 和终端共享，一次配置全局生效。

系统工具

ffmpeg（必须）

视频抽帧、时长检测、格式转换。libreoffice（Office）。

可选工具

Blender / FreeCAD

薄客户端，无需在本进程内。QWEN_MM_AUTOLAUNCH=1 自动拉起。

Python 分发

pyproject.toml

单一分发 qwen-mm-plugins，含 extras/entries 点对点安装。

自托管

SAM3 GPU Server

CUDA + PyTorch，segmentation 专用，有运维成本。

安装命令
# 1. 安装 uv（必须）
curl -LsSf https://astral.sh/uv/install.sh | sh

# 2. 安装 ffmpeg（必须）
apt install ffmpeg   # Linux
brew install ffmpeg  # macOS

# 3. 一键安装 Qwen-MM-Plugins
curl -fsSL https://raw.githubusercontent.com/QwenLM/Qwen-MM-Plugins/main/install.sh | bash

# 4. 配置 API Key
# 获取：https://console.bailian.console.aliyun.com/
export DASHSCOPE_API_KEY="sk-xxxxxxxx"   # 视觉/语音
export SERPER_API_KEY="xxxxxxxx"         # 搜索（可选）

# 5. 验证安装
bash install.sh verify

# 6. Claude Code 中使用示例
# @dashboard.png 读取这个截图中的所有数字
# @report.pdf 总结第3页内容
# @meeting.mp4 转录并标注说话人

USE CASES

适用场景与最佳配置

按场景推荐 Capability 组合，区分"推荐"与"不推荐"边界。

✓ 最佳适配场景
AI 编程 Agent 增强

Claude Code / Codex 读取设计稿

让 Agent 读截图、Figma 导出图、报错界面、UI 设计稿，自动提取数字、文字、布局信息。

  • core（本地读取）+ api（vision_chat）
  • 典型场景：UI 验收、截图分析
隐私敏感文件

本地处理不上云

财务报表、医疗影像、内部文档，用 core 本地读取，完全不调用云端 API，零费用。

  • 仅 core 能力，无需任何 API Key
  • 适合金融、医疗、法律场景
3D / CAD 自动化

Blender + FreeCAD 集成

Agent 驱动 Blender 做自动化建模、材质分配、渲染；或 FreeCAD 做参数化 CAD、FEM 分析。

  • blender：22 个工具，支持 Cycles 渲染
  • freecad：草图→拉伸→STEP/STL 导出
长视频理解

video-memory 分层记忆

2 小时课程/会议自动建分层语义图，用自然语言问答记忆内容。首次构建调用 DashScope。

  • build_memory：首次自动建索引
  • query_memory：自然语言记忆问答
✗ 不推荐场景
1

需要最强推理深度

Claude Sonnet 4.6 配 extended thinking 更适合复杂图像分析。Qwen-VL 在 benchmark 验证上不如竞品。

依赖 OpenAI 生态

GPT-4o + OpenAI 生态更成熟，Qwen-MM-Plugins 依赖阿里云，供应商锁定是风险。

3

需要 SLA 生产环境

v0.x 阶段，无正式 Release Tag，无生产验证。稳定性未经大规模验证。
