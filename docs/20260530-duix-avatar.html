01 · 它是什么
Core Concept
一句话

Duix Avatar 是一个真正开源的 AI 数字人/虚拟人工具包，主打 离线视频生成 与 数字人克隆：用户可在本地用文字或语音驱动虚拟形象，完成口型同步、视频合成和多语言脚本输出。

核心价值
把传统昂贵的数字人制作流程压缩到本地可运行的开源框架中，强调隐私、离线与可复用生产能力。
适合谁
适合内容创作者、教育培训、法律/医疗讲解、企业宣传与需要批量生成口播视频的团队。
02 · 关键特征
Highlights
离线运行
不依赖云端在线推理，强调本地私密性与可控性，适合对数据安全敏感的场景。
形象与语音克隆
支持捕捉人物外观与声音特征，围绕人像/音色/口型联动构建数字分身。
多语言脚本
README 声称支持 8 种语言，面向跨语言内容生产与国际化演示。
Key signal该项目不仅是“能生成视频”，更像一个把 训练、语音合成、视频合成、客户端交付 串起来的完整数字人生产管线。
03 · 部署门槛
Install
Windows / Ubuntu 双路径
01
Windows 10 + Docker + WSL需要 D 盘、C 盘大空间，以及 NVIDIA 驱动。
02
Ubuntu 22.04 + Docker + NVIDIA Toolkit通过 docker-compose 启动服务，强调 GPU 环境准备。
03
本地客户端安装包Windows/Ubuntu 都提供桌面端安装方式，门槛不是零。
资源预算
磁盘30GB+ / 100GB+（文档建议）
GPUNVIDIA 显卡 + 驱动
容器Docker / docker-compose
依赖Node.js 18、多个镜像
门槛判断
更像一套“本地生产线”，不是轻巧的 SaaS 演示；如果你没有 GPU、Docker 或足够磁盘，体验会大幅下降。
