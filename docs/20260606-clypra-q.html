🛠️ 技术栈

Tauri 2 React 19 TypeScript Tailwind CSS 4 Vite 7 Rust FFmpeg Zustand

前端 React 19 + Tailwind CSS 4，后端 Tauri 2 + Rust，通过 FFmpeg CLI 处理音视频，Zustand 管理全局状态。

📥 安装方式

平台 安装方式 备注
macOS brew install AIEraDev/tap/clypra 自动绕过 Gatekeeper
Windows x64 MSI 安装包 SmartScreen 遇阻点"更多信息→运行"
Linux AppImage chmod +x 后运行
源码构建 git clone → npm install → npm run tauri build 需 Node.js 18+、Rust、Cargo
⚠️ 注意：需预装 FFmpeg（非 macOS）或使用 Tauri sidecar。API Key 需在 .env 中配置（文本特效/模板/Lottie 动画），勿提交 .env 到版本库。

🏗️ 项目结构

📁 目录

  • src/components/editor/ — 核心编辑器组件（时间轴/预览）
  • src/components/screens/ — 全屏视图
  • src/store/ — Zustand 状态管理
  • src/lib/ — 共享工具和 FFmpeg 逻辑

📦 状态管理（Zustand）

  • timelineStore — 时间轴结构（轨道/片段）
  • playbackStore — 播放同步和播放头
  • projectStore — 媒体资产和项目设置
  • uiStore / settingsStore
