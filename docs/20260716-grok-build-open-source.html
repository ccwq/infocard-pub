官方声明

声明必须保留归因

原文转引 xAI/SpaceXAI 声称早期 beta 的 retention 默认设置后来改变，并称此前保留的数据将被删除、提供 local-first 路线。

这不是本卡对删除完成或隐私效果的独立审计。

边界警报

源码痕迹不能单独证明具体用户数据曾上传了什么、运行时何时触发上传，或官方所称删除是否已经完成。

因此，本卡不把用户个案报告写成独立证明，也不把“开源”写成隐私保证。
