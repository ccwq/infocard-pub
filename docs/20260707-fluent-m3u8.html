Fluent-M3U8 是一款专为流媒体下载设计的桌面应用，基于 PySide6 与 QFluentWidgets（QFluentWidgets 是 QSS 实现的 Fluent Design 组件库），提供与 Windows 11 Mica 风格一致的现代 UI。支持 M3U8（HLS）与 MPD（MPEG-DASH）双协议，内置多线程加速与任务管理，适合国内视频网站、在线课程、会议录播等多种场景。

03 QUICK START · 快速上手
# Step 1 · 创建 conda 环境并安装依赖
conda create -n fluent-m3u8 python=3.11
conda activate fluent-m3u8
pip install -r requirements.txt
Step 2 · 下载 FFmpeg 和 N_m3u8DL-RE
# 从 https://ffmpeg.org & https://github.com/nilaoda/N_m3u8DL-RE/releases 下载
# 将 ffmpeg.exe 和 N_m3u8DL-RE 放入项目 tools/ 目录
Step 3 · 启动应用
python Fluent-M3U8.py
