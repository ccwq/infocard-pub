QUICK START · 快速安装
# 克隆仓库
$ git clone https://github.com/ai4s-research/open-science.git
$ cd open-science

# 一键安装（macOS / Linux）
$ ./scripts/install.sh

# Windows
$ ./scripts/install.ps1

# 配置模型 API（编辑 .env）
OPENAI_API_KEY=sk-...
ANTHROPIC_API_KEY=sk-ant-...
# 或使用本地 Ollama
OLLAMA_BASE_URL=http://localhost:11434

# 启动
$ opencode --skill openscience

FAQ

常见问题

Q: OpenScience 和 Claude Science 是什么关系？
OpenScience 是 Claude Science 的开源替代实现，保留核心科研工作流能力，同时提供数据本地存储、模型自由选择和完整可复现性。两者功能目标相似，但 OpenScience 强调开源、透明和数据自主。
Q: 数据真的完全保存在本地吗？
是的。所有研究数据、代码、Agent 操作记录、生成的图表和报告都保存在本地工作目录。平台不强制上传任何数据到外部服务器。
Q: 支持哪些模型？可以本地部署吗？
支持 OpenAI、Anthropic、Ollama（本地部署）、LM Studio 及任何 OpenAI-compatible API 端点。通过配置 .env 文件自由切换，无需修改代码。
Q: 医学循证模式覆盖哪些数据源？
整合 ClinicalTrials.gov、PubMed、FDA 数据库、NMPA 文档等，支持指南查询、RCT 检索、药品说明书和监管文档的结构化整理。
Q: 352 个 Skills 可以自定义添加吗？
可以。OpenScience 的 Skills 体系支持自定义扩展，可以基于已有 Skills 克隆修改，也可以从头编写新 Skill，沉淀到本地知识库中复用。
Q: 和 MCP 工具生态兼容吗？
兼容。OpenScience 支持 Model Context Protocol，可以接入现有 MCP 工具生态，扩展数据源和自动化能力。
