What is gstack?

gstack 是 Y Combinator 现任总裁 Garry Tan（曾联合创办 Posterous、Palantir 早期工程师、YC 内部社交网络 Bookface 缔造者）开源的 AI 编程工具工厂。它把 Claude Code 变成一个虚拟工程团队——一个人扮演 CEO、设计师、工程师经理、QA、发布工程师、安全官等 23 个专家角色，全部通过斜杠命令调用，全部免费，MIT 许可。

Garry Tan 自己在 2026 年以 11,417 条逻辑代码变更/天的速率运行，是 2013 年（YC 时期建造 Bookface）的约 810 倍。2026 年前四个月的产出已经超过整个 2013 年全年。

⚙️ 架构特点

Bun + TypeScript，支持 Windows（WSL/Git Bash），自动检测 Claude Code/Codex/Cursor/OpenClaw 等 10 种代理，零代码改动添加新代理。

Why It Matters · 为什么值得关注

Karpathy 说"我十二月以来基本没手动敲过代码"——gstack 是 Garry Tan 对"一个人怎么做到一个二十人团队的事"的回答。Peter Steinberger 的 OpenClaw（GitHub 247K stars）证明了单人 AI 代理可以跑出工业级产出。gstack 在此基础上更进一步：结构化流程（Think → Plan → Build → Review → Test → Ship → Reflect）让并行成为可能——Garry Tan 自己在 Conductor 上同时跑 10-15 个并行冲刺，每个冲刺各自扮演完整工程团队。

与其说 gstack 是工具集合，不如说是 工程方法论的可执行版本：它把 YC 20 年沉淀的"怎么造船"变成了 23 个斜杠命令，任何有 Claude Code 的人都可以免费使用。
