VoxCPM 调查：VoxCPM2 是最新主线，面向多语言 TTS 与声音克隆

结论先行：OpenBMB/VoxCPM 不是“单点 TTS demo”，而是围绕 tokenizer-free TTS、音色设计、可控声音克隆、CLI、Web Demo、生产部署 组织起来的完整项目。公开信息一致指向：VoxCPM2 是最新主线，并且要求 Python 3.10+。

一句话判断
VoxCPM 的核心卖点不是“文本转语音”本身，而是把 连续语音表征、多语言合成、音色设计 和 可控克隆 放进同一条产品线里；VoxCPM2 则是当前最明确的主线版本。
它到底是什么

仓库结构说明它不是单点脚本

  • README 里有 Python API、CLI、Web Demo、Nano-vLLM、vLLM-Omni。
  • pyproject.toml 定义了标准包名 voxcpm 与 voxcpm.cli:main 入口。
  • 说明它既能做本地实验，也能走服务化部署路线。

VoxCPM2 的主线卖点

  • 2B 参数，30 种语言，48kHz 输出。
  • 支持 Voice Design：只靠文字描述创建新音色。
  • 支持 Controllable Voice Cloning：参考音频 + 风格控制。
我怎么判断
README / docs
官方 README 直接把 VoxCPM2 定义为 latest major release，并列出完整能力：多语言、音色设计、克隆、48kHz 输出。
PyPI / 运行门槛
PyPI 当前版本为 2.0.3，requires-python >=3.10；这意味着它是标准 Python 发行包，但运行门槛不低。
GitHub API
仓库元数据给出 Apache-2.0、Python、speech-synthesis、voice-cloning 等 topics，项目边界清晰。
工程化程度
从依赖、CLI、Demo 到生产部署示例都已给出，说明项目已经在往“可用系统”演进，而不是单纯论文附码。
适合谁

适合

  • 多语言 TTS 产品开发
  • 声音克隆 / 音色设计实验
  • 需要 API / CLI / Web Demo 的工程化落地
  • 想接入 Nano-vLLM 或 vLLM-Omni 的服务栈

不太适合

  • 只想“马上随手装一下”的低门槛用户
  • 没有 Python 3.10+ / PyTorch / CUDA 环境的人
  • 不想处理模型下载与推理部署的人
  • 只需要基础朗读、不需要克隆能力的人
结论
如果把 VoxCPM 看成一条产品线，它现在已经覆盖了“模型—工具—Demo—部署”全链路；其中 VoxCPM2 是当前最明确的主线版本。它适合做更高阶的多语言语音合成、音色设计和可控克隆，而不仅是普通朗读。
