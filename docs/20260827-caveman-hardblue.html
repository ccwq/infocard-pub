01
双组件架构

Skill（输出）+ Proxy（输入）= 双向令牌压缩

Caveman 由两个独立组件构成，分别解决输出和输入的令牌浪费问题

输出压缩Skill

Caveman Skill

让 Agent 用 caveman 风格回答——简短、直接、精确，代码和错误信息 byte-exact 保持可运行

  • 平均输出令牌：1214 → 294（节省65%）
  • 10项任务平均基准测试
  • 支持 Claude Code、Codex、Cursor、Gemini CLI 等30+ agents
  • 安装：npx skills add JuliusBrussee/caveman
输入压缩Proxy

Caveman Proxy

本地代理在请求发出前压缩内容（JSON、日志、代码、diff、搜索结果），原文存本地磁盘，需要时精确恢复

  • 输入令牌减少 33.2%（54次 Claude Code 基准）
  • 18/18 精确答案检查全部通过
  • 本地字节精确恢复，无信息损失
  • 注意：输入每轮多出约1000 token（压缩层开销）

05
核心理念

"why use many token when few token do trick"

caveman 的哲学：用更少令牌做更多事，保持模型强大，压缩上下文窗口

keep your agent, brain big, context small

模型能力越来越强，但上下文窗口有限；caveman 让 AI 专注关键信息，减少冗余

专注 压缩 省令牌
字节精确 · 无损恢复

Proxy 压缩后原文存本地磁盘，需要时精确恢复——代码、错误信息、JSON 完全一致
