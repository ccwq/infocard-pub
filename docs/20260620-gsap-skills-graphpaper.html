Core Code Patterns · 核心代码模式
⏱️ Timeline 模式（gsap-timeline）

时间线优于链式 delay，用 position 参数精确控制：+=0.2（相对加）、-=0.1（相对减）、<（对齐前一个）、>（排在前一个之后）。

📜 ScrollTrigger 模式（gsap-scrolltrigger）

附加到 timeline 或顶层 tween：start: "top center"、end: "bottom center"、scrub: true。布局变化后调用 ScrollTrigger.refresh()。pinning 和 scrub 配合做视差滚动。

⚛️ React 模式（gsap-react）

始终使用 scope 限制作用域：`useGSAP(()=>{...}, {scope})` 或 `gsap.context(()=>{...}, ref)`，cleanup 必须执行 `ctx.revert()` 防止内存泄漏。
