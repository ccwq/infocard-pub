Core Code Patterns · 核心代码模式
1 · Timeline（gsap-timeline）const tl = gsap.timeline({ defaults: { duration: 0.5, ease: "power2" } }); tl.to(".a", { x: 100 }) .to(".b", { y: 50 }, "+=0.2") // 相对加 0.2s .to(".c", { opacity: 0 }, "-=0.1") // 相对减 0.1s .to(".d", { scale: 1.2 }, "<") // 与前一个对齐
2 · ScrollTrigger（gsap-scrolltrigger）gsap.registerPlugin(ScrollTrigger); const tl = gsap.timeline({ scrollTrigger: { trigger: ".section", start: "top center", end: "bottom center", scrub: true // scrub 绑定滚动 } }); tl.to(".panel", { x: 100 }) .to(".panel", { rotation: 5, duration: 0.7 }); // 布局变化后：ScrollTrigger.refresh();
3 · React useGSAP（gsap-react）import { useGSAP } from "@gsap/react"; import { gsap } from "gsap"; useGSAP(() => { gsap.to(ref.current, { x: 100 }); }, { scope: containerRef }); // cleanup：return () => ctx.revert();
4 · Performance（gsap-performance）// ✅ 正确：transform 优于 layout props gsap.to(el, { x: 100, transform: "translateX(100px)" }); // ❌ 错误：layout props 触发布局重排 gsap.to(el, { left: 100 });
