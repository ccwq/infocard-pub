02
Deploy

快速部署

两种方式：Docker 一行命令，或 Yarn 源码构建

🐳 Docker（推荐）

无需 Node 环境，一行命令启动：

bash
# 拉取并运行
docker run -d \
  --name web-check \
  -p 3000:3000 \
  --restart always \
  lissy93/web-check

# 或使用 docker-compose
version: '3.9'
services:
  web-check:
    image: lissy93/web-check
    restart: always
    ports:
      - "3000:3000"
访问地址

启动后浏览器打开 http://localhost:3000 即可使用

📦 Yarn 源码构建

克隆后本地构建（需要 Node.js）：

bash
# 克隆仓库
git clone \
  https://github.com/Lissy93/web-check.git
cd web-check

# 安装依赖
yarn install

# 构建并启动
yarn build
yarn serve
环境要求

Node.js ≥ 18，推荐使用 Yarn 而非 npm

04
Pros & Cons

优势与局限

客观看待工具能力边界

✅ 优势

  • 完全免费，开源透明，数据不上传
  • 自托管，数据主权在自己手里
  • 20+ 检测维度覆盖完整
  • Docker 一键部署，无依赖
  • 无需注册、无 API Key
  • 持续活跃维护（500+ commits）

⚠️ 局限

  • 部分 API 依赖外部服务（需网络可达）
  • 未登录，无法做登录态下的检测
  • 大规模批量扫描受速率限制
  • 不支持 JavaScript 渲染后的内容
  • 端口扫描仅覆盖常见端口范围
  • 不提供漏洞利用或 POC 生成
