看到这里已足够判断去留；下面是输出机制、安装前提、提示词和六条限制。

01 · 用机器解释概念

缓存键在数据不变时跳过重复计算，被比作弹子锁：弹子对齐，锁才转动。一个 GPU 上下文服务多个画布，被做成龙门绘图仪：一个打印头依次处理 16 个孔位。

Raptor 2 示例中，发动机与台架由 SVG 绘制，尾焰用 WebGL 着色器计算；鼠标悬停可将发动机拆成 11 个组件。

纯 SVG / 等距

用四种明暗和前后图层表现立体零件，附实时读数；可输出 HTML、SVG 或 React/Next.js 组件。

SVG + WebGL

着色器放在 SVG 前后图层之间，用于火焰、水波等效果。

真 3D · beta

零件在三维空间转动；作者说仅在一个示例和一个测试图上验证过。

02 · 安装与自检

Skill 要求 Node 20.10 以上；安装用的 skills 命令行要求 Node 22.20 以上。自检需本机 Chrome 或 Chromium 进行无头截图。

npx skills add wheresryan22/anatomy -g

安装时可选 Claude Code、Antigravity、OpenCode、Codex、MiniMax Code。Codex 沙箱可能拦截无头浏览器，需按 README 配置相应权限。

03 · 提示词三原则

说概念和真实数字：给尺寸、数量、速率或阈值，让它自己构思机器。

有具体机器就直说：写清名称和哪些部分需要动。

交代用途：指定独立 HTML、SVG 或 React 组件，以及亮色或暗色。

04 · 三个中文提示词

相机光圈

/anatomy 做一个相机镜头光圈的工作原理演示：8 片光圈叶片围成圆孔，拖动光圈环，孔径从 f/1.8 平滑收到 f/16，旁边跟一个实时光圈值读数。一束光从镜头前方照进来，孔越小光柱越细。纯机械质感，浅色主题，输出一个能直接打开的 HTML 文件，界面文字用中文。

手压发电手电筒

/anatomy 做一个手压式发电手电筒的演示：侧面有个压柄，按住不放会带动齿轮组和飞轮加速转动，飞轮带动发电机，灯泡随之亮起来（灯光用 WebGL 光晕实现）；松手后飞轮靠惯性再转一会儿，灯慢慢暗下去。侧面做成透明的或者去掉外壳，要能看见齿轮咬合。深色主题，独立 HTML 文件，中文标注。

杆秤

/anatomy 做一杆老式杆秤的演示：秤钩上挂一个 2 kg 的砝码，可以拖动秤砣在秤杆上滑动，秤杆绕着提绳上下倾斜，拖到平衡位置时秤杆恢复水平，读数窗口显示称出的重量；点一个按钮把砝码换成 5 kg 的，平衡点明显外移。秤杆上要画出刻度。浅色主题，独立 HTML 文件，中文标注。
05 · 泼冷水：六条限制

1. 慢且耗额度。普通图 30–90 分钟，大图可能几小时；Skill 免费，模型调用可不免费。

2. 不是图表库。没有坐标轴和数据曲线，数字主要出现在读数和零件尺寸中。

3. 题材有限。不画人和精确地图；不能变成机械装置的抽象概念效果可能打折。

4. 讲解偏弱。零件转动不等于讲清原理，初学者可能还需要配套说明。

5. 工程精度别当真。发动机插图是示意，不应当作工程设计依据。

6. Codex 权限。沙箱可能拦截无头 Chrome 自检，需按项目说明配置权限。
