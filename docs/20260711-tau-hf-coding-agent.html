1
三层边界：AgentHarness / CodingSession / TUI
AGENT HARNESS
可复用的脑子，与前端完全解耦
不依赖 Textual / Rich / CLI / 配置文件。可接入任何前端：CLI、TUI、API、自定义渲染器。
事件流是唯一契约
async for event in harness.prompt("...")
核心层只发事件，前端负责消费和渲染。
CODING SESSION
coding agent 环境上下文
工具注册（read/write/edit/bash）、会话管理（JSONL 持久化）、项目上下文注入（AGENTS.md / .tau/）。
会话持久化
~/.tau/sessions/（JSONL）
append-only 历史记录，支持恢复和分支。
TUI（前端之一）
Textual 构建的交互式终端界面
消费 AgentHarness 发出的事件流，渲染为实时终端 UI。TUI 只是tau_coding的一部分，不是核心。
非交互模式
tau -p "summarize this repo"
one-shot print mode，适合脚本和 CI。
KEY INSIGHT
tau_agent 不知道任何前端细节，只负责：
消息构建 → 调用模型 → 解析 tool call → 执行工具 → 循环

前端（CLI / TUI / API）消费 事件流，架构边界清晰。

3
可配置项一览
配置维度 配置方式 说明
model /model 或 ~/.tau/catalog.toml 运行时切换模型，支持任意 catalog.toml 中声明的模型
provider /login openai / /login openai-codex Provider 认证，支持 OpenAI / Anthropic / OpenRouter / HF / 自定义端点
tools Python AgentHarness(tools=[...]) 内置 read / write / edit / bash；支持扩展自定义 async 函数
skills AGENTS.md / .tau/ / .agents/ 项目级指令和 prompt 模板；slash commands；运行时注入上下文
sessions ~/.tau/sessions/（JSONL） 持久化会话，支持 resume、branch；上下文可手动或自动压缩
renderers Rich / plain text / JSON / transcripts / 自定义 Provider-neutral 事件渲染，渲染器可替换
4
教学定位差异：Tau vs Claude Code / Codex / SWE-agent
维度 Tau Claude Code / Codex SWE-agent
核心目标 教学：完整演示 agent 结构，可通读 生产：最强的本地 AI 编程工具 研究：软件工程任务自动化基准
代码可读性 ⭐⭐⭐⭐⭐ 每一行都有文档，可单独阅读各包 ⭐⭐ 不公开源码，闭源黑盒 ⭐⭐⭐ 代码量大，理解门槛高
架构透明度 三层边界清晰，事件流是唯一契约 隐藏实现，API 黑盒 混合架构，文档相对完善
学习价值 直接对应「coding agent 从零实现」教材 学会使用，不能学会构建 偏任务评测，非教学导向
工具规模 小而完整：read/write/edit/bash 核心集 丰富：MCP 生态、Git、文件系统增强 评测集固定工具，不扩展
安装复杂度 uv tool install tau-ai 一行完成 npm / curl / brew 多方式 Python 环境 + 依赖配置
Tau 的教学优势：不是「我要做一个比 Claude Code 更好的产品」，而是「我要让你理解 coding agent 是什么」。当你读完 tau_agent 的源码，就有了完整的心智模型——再去用任何生产级 agent，都能更清楚地知道它在做什么、为什么这样做。
