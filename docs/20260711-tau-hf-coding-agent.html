Tau 是一个可以读懂的 Coding Agent，专注教学，不追求功能堆砌。

不同于大型生产代码库，Tau 的设计目标是可读性。你可以直接阅读源码，理解 coding agent 的完整架构：消息、工具、事件循环、会话持久化、流式输出。

01
三层架构

tau_coding → tau_agent → tau_ai

三层边界清晰，每层职责单一，可独立测试和替换。

Layer 1

tau_ai

将各模型提供商的 API 接口翻译为 Tau 的统一流接口。不关心 agent 逻辑，只负责通信。

Layer 2

tau_agent

可移植脑：消息、工具、事件、循环、会话原语。核心不依赖 Textual、Rich 等渲染库。

Layer 3

tau_coding

真实应用：CLI、TUI、文件/shell 工具、配置、会话持久化。调用 tau_agent 的能力。

核心边界说明
AgentHarness = 可移植脑不依赖任何前端，可在任何 Python 环境运行
CodingSession = 编码环境文件读写、命令执行、项目上下文管理
TUI = 前端之一Textual 构建，事件驱动，前端不侵入核心
02
核心特性

终端运行 · 持久会话 · 流式输出

Tau 以 Python 包发布，安装即用，无需克隆仓库。

安装

pip install tau-ai

uv 工具安装（推荐）或 pipx / pip，Python 3.12+。

uv tool install tau-ai
tau --version
使用

cd my-project && tau

进入项目目录，直接运行 tau，持久会话跨命令保留上下文。
