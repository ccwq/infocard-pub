# 语雀会不会凉？王记者调查报告

**调查日期**：2026-05-29  
**协作角色**：王记者（调查复盘） / 希尔（情报采集） / 鹰眼（技术与产品研判）  
**问题意识**：用户问“语雀这个笔记是不是要凉了”，需要核查产品历程、最新动态、组织与舆情信号，并给出可验证判断。

---

## 0. 结论先行

**公开信息暂不支持“语雀马上要凉 / 即将停服 / 已无人维护”的强判断。**

更准确的判断是：

> **语雀仍在线、仍有产品与 AI 生态更新，短期停服风险低；但 2023 年长时间故障、创始人离开、团队/战略地位传闻、用户迁移讨论和强竞品压力，构成中等风险。它不像“快死了”，更像“仍在活跃自救，但信任与增长势能已经不如巅峰期”。**

### 风险评级

- 短期停服风险：**低**
- 产品停止维护风险：**低到中**
- 用户继续流失风险：**中**
- 口碑 / 信任修复压力：**中高**
- 被集团内部协同产品边缘化风险：**中**
- 长期竞争力风险：**中**

---

## 1. 判断框架：什么才叫“要凉了”

本报告把“要凉了”拆为三类信号：

### 1.1 强信号：能直接指向停服或停止维护

包括：官方宣布停服/下线/迁移；核心入口关闭；付费体系停止；更新日志长期停摆；官方要求用户导出数据；重大故障后无复盘无赔偿；团队完全解散且无继任。

**本次未发现这类强信号。**

### 1.2 中信号：产品还活着，但战略、口碑或增长承压

包括：重大故障导致信任受损；创始人/核心负责人离开；团队规模和业务线变动传闻；更新频率下降；迁移和替代方案讨论增多；飞书/钉钉/Notion/Obsidian/思源等竞品持续挤压。

**本次发现多项中信号。**

### 1.3 弱信号：只能说明焦虑或竞争，不能证明快关停

包括：社区吐槽、个别用户迁移、某些插件归档、用户问“是不是倒闭”。这些可作为舆情样本，但不能单独推出结论。

## 2. 语雀历程时间线

### 2015–2016：从蚂蚁 / 支付宝内部知识库需求孵化

多篇媒体报道描述，语雀源自蚂蚁集团和阿里巴巴内部文档协同需求，是支付宝技术团队从 2015 年开始内部孵化的云端知识库；也有报道称 2016 年在蚂蚁体验技术部创新机制中由玉伯团队主导问世。

### 2018：正式对外提供服务

媒体报道普遍提到，语雀在 2018 年正式对公网提供服务，定位为文档与知识库工具，面向个人、团队和企业。

### 2019：举办语雀知识大会，提出“新一代 Office”叙事

语雀官方博客保留“语雀知识大会，定义新一代 Office”的页面，说明其曾以知识管理 / 新一代办公套件进行品牌表达。

### 2021–2022：走向独立 BU、推出移动端

外部报道提到，2021 年蚂蚁成立智能协同事业部，语雀作为重点产品独立 BU 运作；2022 年 2 月语雀正式推出 iOS / Android 移动端。

### 2023：创始人离开蚂蚁；10 月发生长时间故障

2023 年 4 月，语雀关键创始人玉伯离开蚂蚁。2023 年 10 月 23 日，语雀发生长时间服务故障，成为产品信任的重大转折点。

### 2024–2026：AI 化、MCP/插件生态、知识库问答继续推进

官方博客和 GitHub 公开仓库显示，语雀仍在围绕 AI 写作、Tbox 超级智能体、DeepSeek、知识库问答、MCP、Claude Code Plugin / AI Ecosystem 等方向更新。GitHub `yuque/yuque-ecosystem` 在 2026-05-27 仍有 commit。

## 4. 负面信号：为什么用户会觉得它“要凉”

### 4.1 2023 年长时间故障是核心信任折损

2023 年 10 月 23 日，语雀出现长时间服务故障。媒体报道显示：

- 语雀在线文档和官网无法打开。
- 故障持续约 8–10 小时。
- 语雀称原因是数据存储运维团队升级操作中，新运维升级工具 bug 导致华东地区生产环境存储服务器被误下线。
- 语雀强调用户数据未丢失。
- 赔偿方案包括向个人用户赠送 6 个月会员，空间用户另行制定方案。

对于笔记和知识库产品来说，可靠性是底层信用。一次接近全天工作时段的故障，足以让高价值用户开始考虑备份和迁移。

### 4.2 创始人离开与团队传闻削弱“长期确定性”

公开报道显示，语雀关键创始人玉伯 2023 年离开蚂蚁，后加入飞书，再于 2024 年从飞书离职创业。

另有科技媒体 / 转载文章提到“创始人离职、团队骤减、险被钉钉合并”“两次生死局”等说法。由于这类信息非官方披露，本报告把它列为**中等可信度的外部观察**，不能当作确定事实；但它会加重用户对语雀战略地位的疑虑。

### 4.3 用户迁移和替代方案讨论真实存在

社区中存在多类迁移/替代讨论：

- V2EX 2025 年帖子中，有用户称语雀无法访问，并表示“语雀不稳定了，准备迁移到飞书了”。
- 博客园有用户发布“语雀迁移至 Obsidian”的实践文章。
- 阿里云开发者社区文章讨论语雀停机后，本地笔记 Obsidian、思源笔记等方案。
- 搜索结果可见“语雀迁移 Notion”“语雀数据迁移完全指南”“语雀 / Notion / FlowUs / 飞书云文档批量导出”等内容。

这些都说明用户对“可导出、可备份、可迁移”的需求变强。

但注意：迁移讨论不等于大规模流失。笔记工具天然有迁移生态，不能只凭个案断言“凉了”。

### 4.4 一个插件仓库被归档，但不能孤立解读

GitHub API 核验：

- `yuque/yuque-plugin`
  - archived: true
  - pushed_at: `2026-02-26T13:34:22Z`
  - 描述为“语雀 Claude Code Plugin — 一键集成语雀 AI 能力”

这表明一个旧插件仓库在 2026 年被归档。负面解读是某个项目废弃；中性解读是迁移/整合到 `yuque-ecosystem`。由于 `yuque-ecosystem` 仍活跃，本报告倾向把它视为**生态整合信号**，而不是语雀整体衰退的强证据。

## 5. 竞品压力：真正的长期风险

语雀面对的不是单点故障，而是办公文档与个人知识管理赛道的结构性挤压。

### 5.1 企业协作侧

飞书文档、钉钉文档、腾讯文档、石墨文档拥有 IM、会议、审批、组织通讯录、项目协作等一体化入口。语雀作为独立知识库工具，如果不能成为组织默认入口，就容易被超级 App 内置文档挤压。

### 5.2 个人知识管理侧

Notion、Obsidian、思源笔记、FlowUs、Logseq 分别在国际化、离线本地、块编辑、开放生态、双链等方向形成心智。语雀的优势是中文体验、团队知识库与阿里背书，但在个人知识管理生态里并非不可替代。

### 5.3 AI 知识库侧

文档工具正在被“知识库 + 智能问答 + Agent 工作流”重塑。语雀布局 AI、Tbox、MCP 是正确方向，但它面对的是 Notion AI、飞书智能伙伴、企业 RAG 平台和各种 Agent 知识库工具的夹击。

## 8. 王记者最终判断

如果用户问“语雀是不是要凉了”，我会这样回答：

> **不是马上要凉。公开证据看，语雀官网、帮助页、博客仍在线，GitHub AI 生态仓库 2026 年 5 月仍有更新，没有官方停服或停止维护公告。**
>
> **但它确实有中等风险：2023 年长时间故障对信任伤害很大；创始人离开和团队/合并传闻让长期确定性打折；用户迁移到飞书、Obsidian、Notion、思源的讨论真实存在；而企业协作和 AI 知识库赛道竞争更激烈。**
>
> **所以更稳妥的策略不是恐慌迁移，而是做两件事：继续使用可以，但必须定期导出备份；如果你的知识库承载关键业务，至少准备飞书/Notion/Obsidian/思源之一作为备选迁移路径。**
