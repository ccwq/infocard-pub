帖主自述为 turbo0.com、blob0.com 创始人，正在做 pencil0.com（帖源 JSON 自述，未独立核验）。原帖明确「知名组件库就不推荐了」，只收小众但有特色的：手绘纸张、贴纸、黏液、Agent 工作台等。

把清单核完之后，几点平衡

组件库和设计 SKILL 不是同一层的东西。Looseleaf、PlopUI、Inkra 这类解决「风格皮肤」，Agent 工作台组件解决「场景模块」，但布局、排版、信息层级、品牌一致性这些设计判断，组件库给的是素材，不替你做决策。两者不互斥，帖主的原话也没有为「做出特色」以外的场景兜底。

「用组件库就够了」在成本上不完全成立：8 家里 3 家含付费层，AffectUI Pro 买断 249 美元起，Prestige All Access 79 美元（促销价），BoardUI 有 10 个 Pro 模板付费。

成熟度参差：goopUI 只有 16 Star、PlopUI 29、Inkra 55（均为 2026-11-08 观测），goopUI 的文档页当轮抓取返回 500；而 Solid Glass 已有 2041 Star。生产可用性需要自行评估。

01Looseleaf

kevintngo.github.io/looseleaf

官方自述「shadcn/ui, drawn by hand」：123 个组件是真实可访问的 React 代码（React 19 / Tailwind v4 / Radix，MIT），与 shadcn/ui 同 parts 和 props，经 shadcn registry 用 CLI 复制进项目；另有 300+ 手绘图形，官方称组件通过 axe 测试 6,500+。

安装npx shadcn@latest add @looseleaf/button
许可MIT
Star544（2026-11-08）
作者Kevin T. Ngo（官网署名）

帖主说法「纸张纹理、胶带、手绘图表，还有完整页面区块」：纸张纹理与手绘图表对得上官网演示，「完整页面区块」与官方 15 个 categories 相符；「胶带」当轮首页未见，PlopUI 那边倒有 washi tape。

02PlopUI

plopui.com

安装npm i @plop-ui/react

按需求选型

先看你要什么

  • 要手绘纸张感（图表、日历、整页区块）：Looseleaf，shadcn 同构、CLI 复制即用
  • 要贴纸活力（马克笔字、squish 按钮）：PlopUI，npm 一行装
  • 要铅笔淡彩（含日历、地图）：Inkra，README 自带可发给 AI 的 setup 指南
  • Vue / Nuxt 栈想要特色质感：goopUI（8 家里唯一 Vue 优先，注意 Star 最低、文档当轮不可达）
  • Agent 工作台（运行状态、工具调用、审批、diff）：Solid Glass（玻璃质感、Star 最高）、AffectUI（组件最全、Pro 买断）、BoardUI（仪表盘和模板向，免费层 MIT）
  • 落地页动画（hero、pricing、testimonials 区块）：Prestige UI，20 个免费组件可先试
两种安装模式，先分清再动手

npm 依赖

npm i @plop-ui/react、npm install @inkra/react 这类是装进 package.json 的运行时依赖，随包升级，需要跟随上游版本。

shadcn registry / copy-paste

Looseleaf、AffectUI、Prestige UI 走 shadcn CLI：源码被复制进你的仓库，之后归你改，没有运行时包要跟。AffectUI 和 BoardUI 还提供 MCP 安装，agent 在对话里就能浏览组件并写入源码。

goopUI 的安装命令当轮未获取到，文档页恢复后再补；Solid Glass 的安装入口当轮也未抓到。

付费提醒：3 家含付费，具体在这些项

AffectUI：40 个组件免费开源（MIT），其余属 Pro，一次性买断 249 美元起（官方自述）。Prestige UI：Free 层 20 个组件；140 个 blocks 与模板需 All Access，一次性 79 美元，官方标注为促销价、12 月 1 日起 99 美元，且不退款。BoardUI：免费层 MIT 含 chat starter，另收 10 个 Pro 模板，具体价格官方页面当轮未展示。其余 5 家（Looseleaf、PlopUI、Inkra、goopUI、Solid Glass）当轮未见付费迹象。
