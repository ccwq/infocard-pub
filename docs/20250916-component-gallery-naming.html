01痛点 · AI 为什么总是"跑偏"
❌ 你可能这样说

"帮我做一个弹窗"

AI 给出 Modal，但你不确定是 Dialog / Popup / Alert 的哪种形态

❌ 你可能这样说

"加一个下拉菜单"

AI 返回的是 Select，但你实际需要的是 Combobox 还是 Dropdown？

❌ 你可能这样说

"加载用闪光效果"

AI 以为你要 CSS animation，实际你的意思是 Spinner / Skeleton

❌ 你可能这样说

"顶部菜单栏"

可能是 Navigation Bar、Header、Toolbar 或 Top App Bar，含义完全不同

✓ 关键洞察：同一 UI 元素在不同设计系统中有不同叫法。AI 听到"弹窗"，但它不认识这个中文词对应的精确英文组件名——说错名字，AI 第一次就跑了。

03为什么命名对 AI 沟通至关重要

一个精准的英文组件名 = AI 直接输出正确实现。一次说对，少走弯路。

# ❌ 模糊 → AI 猜测，容易跑偏 user: 帮我做一个弹窗表单 ai: (给出 Modal，但可能是 Dialog 的形态) # ✓ 精准 → AI 一击即中 user: Create a Modal component with a form inside # → Modal = 模态弹窗，ai 知道需要 overlay + focus trap + close user: Build a Select dropdown with searchable option # → Select = 可搜索下拉，ai 知道是 listbox pattern user: Add a Spinner to indicate loading state # → Spinner = 旋转加载环，ai 不会给你 Skeleton 或 Progress

component.gallery 的核心价值：当你需要某个 UI 元素时，去网站搜中文 → 对应找到英文名 → 用英文名告诉 AI。比翻设计系统文档快 10 倍。

例如：想找"手风琴"？Gallery 告诉你 → Accordion，别名 Arrow toggle / Collapse / Disclosure / Expander
