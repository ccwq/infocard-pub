RICOUI DESIGN

用 DESIGN.md 保存可复用的视觉上下文

RICOUI 是围绕 DESIGN.md 的 local-first 设计系统工作台；品牌参考、设计 token 和说明以可读、可版本化 Markdown 组织。

核心判断：DESIGN.md 的价值在于把颜色、字体、间距和组件决策变成 Agent 与人都能复用的上下文。

一个 DESIGN.md 应该回答什么

视觉 token

颜色、字体、间距、圆角、阴影和尺寸等可执行值。

设计理由

不仅写“是什么”，还说明为什么这样用、哪些场景不要用。

可移植性

Markdown 既能被人阅读，也能作为 AI 设计/编码工具的上下文。

版本与审查

通过 Git 保存变更，预览、检查和交付都围绕同一份规格。

使用品牌参考时

把它当作独立整理的起点，不当作官方规范；最终仍应回到品牌官网、产品现状和授权要求核对。

来源与边界

品牌资料是非官方学习参考，不代表品牌授权或官方指南；当前公开仓库列出 69 个品牌，数量和内容会变化。
