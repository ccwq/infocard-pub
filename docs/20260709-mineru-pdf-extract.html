核心能力：PDF → Markdown 一键提取
MinerU 将任意 PDF（文本型/扫描版/乱码）自动识别类型后，提取结构化内容并导出为 Markdown/JSON，是 AI 语料清洗的核心工具。

02
技术架构：模型层 + 解析引擎
MinerU 采用多模型流水线：布局检测 → 区域识别 → 内容提取 → 阅读顺序恢复 → 格式输出。
模型层
  • 布局检测：DocLayout-YOLO_ft, YOLO-v10_ft, LayoutLMv3_ft
  • 公式检测：YOLOv8_ft（定位行内/块公式）
  • 公式识别：UniMERNet（图像 → LaTeX）
  • OCR：PaddleOCR（84 种语言）
  • 表格识别：PaddleOCR + TableMaster / StructEqTable
  • 阅读顺序：规则引擎（非专用模型）
2.x / 2.5 新增能力
  • 复杂长数学公式，中英文混合方程式解析
  • 旋转表格、无边框表格、跨页表格识别
  • 印章文字识别（针对中国文档圆形印章）
  • VLM 架构（12 亿参数，超越通用模型）
  • 多语言混合识别（中文/英文混排）
03
三种解析引擎：按需选型
pipeline
CPU 或 6G 显存 GPU
个人日常使用，轻量级文档处理
vlm-transformers
8G 显存 GPU
学术论文、复杂版式、深度理解场景
vlm-vllm
8G+ 显存 GPU
企业级批量处理，加速 20-30 倍
04
安装与使用
pip install mineru
# 或 uv
uv pip install -U "mineru[core]"

# Web API
mineru-api --host 0.0.0.0 --port 8000

# Python SDK
from mineru import pipeline
result = pipeline("your.pdf")
result.save("output.md")
