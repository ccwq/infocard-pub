口径② · 软件行业I65

西安A股中证监会归类为 I65 软件和信息技术服务业 的纯软公司极少。天润在严格口径下是第①名（若含易点天下宽口径则第②）。

西安软件I65 · 第1名

西安的资本版图不是靠软件撑的，软件就业靠的是华为西研所等非上市机构。

口径③ · GIS同赛道

注册地=陕西 + A股上市 + 主营含测绘/GIS/遥感/空间信息 → 天润是唯一标的。真正的竞争对手在全国：超图软件、中科星图、航天宏图。

陕西A股 · 唯一 全国第2梯队

壁垒在测绘甲级资质+西北政企关系；短板在利润体量和全国平台化能力。

西安软件产业为什么A股软件公司这么少

Layer 1 · 外巨头西安基地

华为西安研究所（2万+人）、中兴西研、中软国际、软通动力、海康威视西研。

贡献最大体量就业和产值，但非西安本地上市公司。

Layer 2 · 本土精品（少数上市）

葡萄城（低代码平台，陕西最大软件出口，未A股）、易点天下（301171，主业AdTech非纯软）、天润科技（920564，北交所，唯一GIS纯赛道）、美林数据（新三板，工业大数据）。

Layer 3 · A股真实底色

煤(陕西煤业)→军工(航发/西飞)→光伏(隆基)→有色(金钼)→电力装备(西电)

最终判断

天润科技的价值不能只用"西安市值排名"衡量，应该看：时空信息基础设施赛道的政策红利（实景三维中国 · 低空经济 · 数据要素）× 西北区域壁垒 × 北交所小市值弹性。它的天花板不在于西安本地竞争（几乎没有），而在于能否把项目制生意做成可复制的平台能力。
