01Monetize · 内容赚钱

AiToEarn 最核心的目标：帮助每一位创作者赚钱。创作者在平台出售内容完成商家推广任务，结算以结果为导向。

CPS

Cost Per Sale

按成交额结算，成交才付费，商家风险最低。

CPE

Cost Per Engagement

按互动量结算，点赞/评论/收藏均可计入。

CPM

Cost Per Mille

按播放量结算，千次播放结算，适合品牌曝光。

05MCP · Claude / Cursor 接入

AiToEarn 支持所有兼容 MCP 协议的 AI 助手。在 Claude Desktop 或 Cursor 的 MCP 设置中配置即可，无需部署，在 AI 助手中直接使用。

Claude

Claude Desktop MCP

在 claude_desktop_config.json 添加 MCP 服务器配置，Claude 中直接调用 AiToEarn。

Cursor

Cursor MCP 配置

在 Cursor 的 MCP 设置中添加地址和认证 Header，Cursor 中直接使用 AiToEarn 功能。

06Docker · 三命令私有化部署

3 条命令搞定私有化部署，无需手动安装数据库。配置 Relay 后可借用官方凭据完成各平台 OAuth 授权。

git clone https://github.com/yikart/AiToEarn.git
cd AiToEarn
docker compose up -d
