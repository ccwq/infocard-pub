01 · 项目定位
Overview
What it is

轻量级终端优先 AI-native 开发工作台。基于 Tauri 2 + Rust + React 19 构建，集原生 PTY 后端、WebGL 渲染、AI 侧栏（支持 BYOK 或全离线模型）、代码编辑器、文件浏览器、Git 可视化和 Web 预览于一体。约 7–8 MB，无遥测，不需注册账号。

核心定位
不是另一个 Electron 包装，而是一个把「终端 + AI + 编辑器」三个工具融进同一窗口的开发者工作台。
核心卖点
真正跑在你自己 API key 上的 Agentic AI，无需注册、无需代理、响应快、可离线、本地模型优先。

03 · 核心功能
Features
终端

06 · 安装方式
Install
Releases 下载
最新版安装包在 GitHub Releases 页面，Terax 会自动从那里更新。
Linux AUR
yay -S terax-bin
Arch Linux 用户可从 AUR 安装，追踪最新版。
Windows 首次启动
未做代码签名，首次运行 Windows 会显示"Windows protected your PC"，点「更多信息」→「仍然运行」即可。
Windows Shell 优先级
1
pwsh.exePowerShell 7+
2
powershell.exeWin PS 5.1
3
cmd.exe降级兜底
Linux 渲染问题
Wayland 下如遇渲染异常，先试
WEBKIT_DISABLE_DMABUF_RENDERER=1
再尝试 .deb / .rpm 包，GTK 栈更稳。
源码构建
# 前置：Rust + Node 20+ + pnpm pnpm install pnpm tauri dev # 开发 pnpm tauri build # 构建 # 类型检查 pnpm exec tsc --noEmit # Rust 检查 cd src-tauri && cargo clippy --all-targets --locked -D warnings cd src-tauri && cargo test --locked
WSL 一等公民
WSL 不是包装子进程，而是作为独立工作区环境直接集成，和本地 Windows 环境并列选择。
07 · 适合谁 / 不适合谁
Boundary
适合
1
重度终端用户习惯在终端里跑所有事，想要 AI 加持但不换工具。
2
注重隐私的开发者不想把代码和项目上下文送给第三方服务器。
3
本地模型用户已经在用 LM Studio / Ollama，想在桌面环境里直接调 AI。
4
轻量工作台需求不想开 VS Code + 终端 + 浏览器三个窗口。
不适合
✗
GUI 优先的开发者Terax 的定位是终端增强，不是通用 IDE。
✗
需要完整调试能力没有内置调试器，主要面向写作和轻度编码。
✗
追求图形化 Git 操作Git 功能聚焦基本操作，复杂 rebase / bisect 建议用专门的 Git GUI。
