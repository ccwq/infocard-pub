## 五、结论

### 5.1 两案的共性

1. **流量收割**：都成为自媒体/舆论场的流量入口
2. **信息失真**：真相与谣言混杂，公众难以辨别
3. **公众围观**：大规模社会讨论，缺乏深度思考

### 5.2 结构性问题

1. 平台算法激励造谣行为
2. 媒体核实机制薄弱
3. "正能量"叙事被滥用包装谣言
4. 公众媒介素养不足

### 5.3 建议

1. 平台加强谣言识别与拦截
2. 媒体强化新闻核实流程
3. 官方及时回应避免谣言扩散
4. 公众提升信息辨别能力
