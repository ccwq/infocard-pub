风险提示

官方额度白嫖风险

蚂蚁百灵/Ling、Muse、Cloudflare 的免费额度均有每日/每周上限，长期高频使用可能触发风控或配额清零。建议记录用量并设置阈值告警（见 Tip 2）。

Cookie 同步安全边界

导出 session cookie 到 Bot/Muse 意味着第三方获得你的登录态。仅同步只读或低权限账号，切勿同步银行/支付等高风险站点的 cookie。

代理/IP 合规性

回国代理和落地 IP 方案需遵守当地法律法规。部分平台对代理 IP 有明确禁令，可能导致账号风控。

muse2api 稳定性

295★ 开源反代项目，需关注官方更新和配额变化。反代链路增加延迟和单点风险，生产环境建议监控可用性。
