HumanLayer Skills：给 Claude Code 用的技能包

为 Claude Code 量身定制的 TypeScript 技能集合，一键安装，MIT 许可

512 Stars TypeScript MIT Claude Code
概述

humanlayer/skills 是由 HumanLayer 团队维护的 Claude Code 技能库，收集了 5 个经过实战验证的 Claude Code 扩展技能。所有技能均可通过 npx skills add 一行命令安装，开源免费（MIT），适用于代码质量提升、React 开发、Agentic 工作流设计等多个场景。

核心技能（5 个）
技能名称 用途说明
improve-claude-md
自动分析并改进 CLAUDE.md 文件，提升 Claude Code 对项目规范的理解与指令遵循准确度。
narrow-react-prop-types
将 React 组件的 prop types 收窄至仅覆盖实际使用的代码路径，减少冗余类型定义，增强类型安全。
build-iterated-agentic-loop
基于 GitHub Actions 构建迭代式 Agentic Loop，定义触发条件、工具调用与终止条件，实现自动化持续运行的工作流。
design-control-loop
设计控制循环系统，涵盖传感器（Sensor）、控制器（Controller）、执行器（Actuator）和扰动（Disturbance）四大组件的建模方法。
show-me
用图表、代码形态草图与 HTML 可视化解释复杂概念，适合技术分享、文档编写和代码演示场景。
安装方法

每个技能均可独立安装，先安装技能管理器，再按需添加单个技能：

npx skills add humanlayer/skills --skill improve-claude-md
npx skills add humanlayer/skills --skill narrow-react-prop-types
npx skills add humanlayer/skills --skill build-iterated-agentic-loop
npx skills add humanlayer/skills --skill design-control-loop
npx skills add humanlayer/skills --skill show-me
适用场景
代码质量审查 improve-claude-md 强化项目规范，减少 AI 辅助开发中的偏离。
React 类型安全 narrow-react-prop-types 精简 prop types，消除死代码路径。
自动化 CI/CD build-iterated-agentic-loop 在 GitHub Actions 上跑持续 Agent 工作流。
系统设计建模 design-control-loop 提供控制理论的工程化实践框架。
技术内容创作 show-me 用可视化方式讲解复杂概念，提升文档可读性。
快速上手
  1. 确认已安装 Claude Code CLI（npm install -g @anthropic-ai/claude-code）
  2. 进入你的项目目录，选择一个需要的技能
  3. 运行安装命令，如 npx skills add humanlayer/skills --skill show-me
  4. 在 Claude Code 中触发技能，例如 /show-me 或按提示操作
  5. 根据输出结果迭代你的代码或文档
