支持的微调方法与集成

方法原理VRAM适用场景
LoRA低秩矩阵分解，仅训练 A/B 矩阵12-24 GB全精度下游任务微调
QLoRA4-bit NF4 量化 + LoRA6-10 GB消费级 GPU 快速微调
DoRA权重分解 + LoRA，精度更高同 QLoRA对精度要求高的任务

集成推理引擎

  • ✅ vLLM：导出为 vLLM 兼容格式，高速推理
  • ✅ Ollama：导出 Modelfile，本地部署
  • ✅ ColossalAI：多卡/多节点分布式训练
  • ✅ GGUF：导出为 llama.cpp 格式
DoRA 需要 Unsloth Pro 许可证（$20/mo）或申请学术免费许可。
⚠️ 注意事项
📦 模型兼容性
新发布模型可能需要等待 Unsloth 适配后再使用。
🔧 微调上限
QLoRA/LoRA 本质上仍是轻量化微调，全量参数微调效果更好但需要更多资源。
💰 Pro 许可
DoRA 和部分高级功能需要 Unsloth Pro；开源版本已覆盖大多数场景。
