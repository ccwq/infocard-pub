01为什么选择 Unsloth

Unsloth 专注于速度与显存效率，通过定制反向传播内核和动态量化实现比主流框架快 2-5 倍的训练速度。

核心优势：手工优化的 Triton 内核 + 4-bit 量化 + 梯度检查点，使消费级 GPU（24GB）也能微调 70B 模型。

04QLoRA 单卡微调
from unsloth import FastLanguageModel
from unsloth import FastLanguageModel, SFTTrainer
from transformers import TrainingArguments

model, tokenizer = FastLanguageModel.from_pretrained(
    model_name = "unsloth/Qwen2.5-7B-bnb-4bit",
    max_seq_length = 2048,
    load_in_4bit = True,
)
model = FastLanguageModel.get_peft_model(model, r=16)

trainer = SFTTrainer(model=model, train_dataset=dataset,
    args=TrainingArguments(per_device_train_batch_size=2,
        num_train_epochs=3, learning_rate=2e-4,
        fp16=True, output_dir="outputs"))
trainer.train()
