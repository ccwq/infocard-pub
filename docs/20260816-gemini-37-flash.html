04适合谁，不适合谁

适合

需要长上下文、多模态输入、工具调用和较低 token 成本的 Agent / coding / knowledge-work 工作流。

谨慎

对延迟、稳定性、地区可用性、价格长期锁定或 benchmark 外推有严格要求的生产系统。

不要这样写

不要把“击败更大模型”写成无条件结论；应绑定任务、评测版本、对比模型与官方口径。

05来源与证据边界

本卡以 Google 官方博客、Google DeepMind Model Card 和 Google Cloud 官方文档为事实来源；社交帖子仅用于发现选题，不作为性能证明。
