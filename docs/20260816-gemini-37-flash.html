MODEL BASELINE

规格底座：先确认能不能接入工作流

以下字段来自 Google Blog、DeepMind Model Card 与 Google Cloud 文档。

输入与上下文

支持文本、图像、音频、视频输入；上下文窗口最高 1M token。

  • 最大输出 64K token
  • 长文档与多模态任务可用

Thinking 配置

支持 customizable thinking configurations，用于在质量、成本和延迟之间取舍。

  • 不是固定“全力推理”模式
  • 实际参数以 API 文档为准

工具能力

官方 Cloud 文档列出 Search/Maps grounding、代码执行、function calling、URL context 和 computer use preview。

  • 不同渠道能力可能不同
  • Preview 不等于稳定 GA

PRICE WINDOW

价格是时间函数，不是永久属性

促销窗口结束后，单位 token 成本翻倍，必须写进选型卡。

2026-12-31 前

$0.75 / 1M input
$3.75 / 1M output

2027-01-01 起

$1.50 / 1M input
$7.50 / 1M output

计算总成本

不要只看 token 单价；还要计入重试、工具调用、上下文缓存、并发和人工复核成本。

LIMITS & OPERATIONS

适合 Agent，但不等于免维护

模型能力提升不能替代系统级重试、校验和权限设计。

生产边界

官方 Model Card 仍列出 hallucination、偶发 slow/timeout、知识覆盖不均等限制。对 Agent 工作流，应保留重试、结果校验、工具权限和人工接管。

input → thinking budget → tool call → result validation → retry / human approval
