Pain Point · 痛点

原始 HTML 含大量无关内容：广告 / 导航栏 / 脚注 / Cookie 弹窗，通常占上下文 70–90%。

Claude / Cursor 的 WebFetch 直接拉原始页面，Token 消耗高、内容噪声大，AI 难以准确理解核心内容。

Core Value · 核心价值
curl.md 是什么

将任意网页 URL 转换为纯净 Markdown，自动去除广告、导航、样板代码。专为 AI Agent 设计，减少 70–90% Token 消耗。

Integration · 集成方式
Claude Code 集成
Terminal 
# 安装插件（Claude Code CLI）
claude plugin marketplace add wevm/curl.md

# 注册完成后自动获得：
# ├── MCP tool: fetch (URL → markdown)
# ├── Slash skill: /curl-md:fetch
# └── WebFetch hook: 自动重定向到 curl.md
fetch tool 输入参数 
{
  url: string          // 必填，目标 URL
  objective?: string    // 可选，告知 AI 关注什么
  keywords?: string[] // 可选，重点关键词
  mode?: 'rush' | 'smart'  // rush=快速，smart=深度
  fresh?: boolean   // 可选，强制刷新缓存
}
