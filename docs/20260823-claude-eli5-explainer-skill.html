Core定位

大多数 AI 工具让你更懂一个话题；ELI5 Skill 让你更擅长解释任何事。 它把 Claude Code 从「术语输出机器」变成「会讲通俗故事的解释者」—— 22 条斜杠命令，覆盖学习、写作、团队 onboarding、自我理解验证全场景。

源自 Anthropic Claude Code 团队工程师 Thariq Shihipar 的内部方法论， 由 kavyabhand 实现为开源 Skill。 三个 Hook 注入规则，AI 在每轮对话中自动保持通俗风格，不会「漂移」。

OAuth 示例 — 4个层级的类比对比
/eli5 — 5岁
想象你有一把信箱钥匙。OAuth 就是一把超小特制钥匙，只能打开信箱，打不开房子。你把它交给邮递员，但他永远进不了你家。
/eli-teen — 15岁
你知道在 App 里能「用 Google 登录」吗？OAuth 就是让这个过程work的东西。Google 给 App 一个特殊腕带——入场通行证，不等于你拥有这个场馆。
/eli-adult — 聪明外行
OAuth 让你在不分享密码的情况下，授权一个 App 访问另一个服务。想象停车代客钥匙：他能泊车，打不开手套箱。
/eli-expert — 医生视角
想象转诊信。你的全科医生不会把完整病历发给专科——只发一封授权转诊，写明需要什么。OAuth 就是这样：限定范围、限时、不暴露全部信息。
学习工具 — 5条命令
命令功能
/eli-compare X vs Y同域并排比较：同一类比域、一个关键差异、一个「选X场景 / 选Y场景」
/eli-prereqs [topic]真实学习路径 — 不是「先学编程基础」，而是真正的前置知识清单
/eli-teach [topic]苏格拉底式问答 — 通过提问引导你自己发现答案，记得更牢
/eli-quiz2~3 道分级测试题，每次一道，用 ELI5 风格反馈
/eli-recap本会话概念摘要，保存到 .claude/eli5-concepts.json，供未来 session 复用
格式变体 — 3条命令
命令功能
/eli-brief [topic]3 句话，每句 ≤20 词 — 安全发给老板 / 客户 / 董事会
/eli-tweet [topic]≤280 字符；显示字符数；140 字符挑战。说不清楚 = 没真正理解
/eli-tldr [topic]恰好 3 条 bullet：是什么 / 为什么重要 / 关键点。无散文。
工作流工具 — 4条命令
命令功能
/eli-pr读取 git diff main...HEAD，生成 PR 描述（给 manager / PM / 设计师）
/eli-commit读取 staged changes，写 commit message — 专注 why，不只是 what
/eli-remember保存自定义类比到 custom-analogies.md，每次 session 最优先查表
/eli-save导出本 session 所有解释到 eli5-notes.md
/eli-doc扫描代码库，写 ELI5.md — 全员可读的 codebase 术语表
/eli-doc --team同上，加「新成员入门」章节，commit 到仓库
8条行为规则 — 每次响应必须遵守
1
类比优先 — 从不定义，总是类比
2
消灭术语 — 替换需要解释的词，不解释它们
3
短句 — 每句只含一个想法
4
保持准确 — 更简单不等于更错误
5
具体 > 抽象 — 食物/玩具/建筑，不用「系统」和「范式」
6
不居高临下 — 禁用 "simply" / "obviously"
7
持久性 — 每轮响应保持风格直到关闭；漂移是 bug
8
安全第一 — 破坏性/不可逆操作用通俗语言警告

项目级自动激活

在项目根目录放一个 .eli5rc 文件，eli5-mode 自动激活，无需每次输入命令。 支持配置默认层级、专家领域、passive_mode（每轮自动解释陌生术语）和 proactive（主动提示最陌生的词）。 

# .eli5rc
level=eli-adult
passive_mode=true
proactive=true
