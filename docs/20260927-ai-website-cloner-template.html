10
核心特性 · KEY FEATURES

像素级还原的五大技术支柱

Chrome MCP + Git Worktree + Visual Diff + AGENTS.md 单一真相源 + 多平台同步

🔬

精确 CSS 提取

Chrome MCP 调用 getComputedStyle() 提取每个 DOM 节点的精确像素值，确保还原度。提取设计 Token（颜色/字体/间距）写入 docs/research/。

🌲

Git Worktree 隔离

每个区块独立 worktree 并行构建，无冲突。Builder Agent 接收完整规格文档（CSS 值/状态/行为），无需猜测，保证代码质量。

👁️

视觉 Diff 验收

合并 worktree 后自动运行视觉对比，对比原始网站截图，量化还原度。确保每个区块在像素级与原站一致。

🔄

多 URL 并行（v0.3.0）

一条命令克隆多个网站，每个 URL 分配独立输出目录，并行处理大幅加速大规模采集任务。

✅

CI 自动验证

GitHub Actions 自动运行 lint + typecheck + build，任何 PR 或 push 均触发验证，确保代码质量不退化。

🔧

TARGET.md 精细控制

可选配置文件，控制克隆页面范围、保真度级别、排除范围、克隆后自定义计划。不填则默认像素级还原首页。
