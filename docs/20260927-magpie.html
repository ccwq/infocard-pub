什么是 Magpie？

一个菜单栏应用 + TUI + CLI，点一下就切换 AI Agent 的模型配置。Claude Code 配 Anthropic、Codex 配 DeepSeek、OpenCode 配 Kimi——各 Agent 的模型配置集中管理，本地网关自动路由。配置修改是原子写入（只改一个 key，注释/格式全部保留）。

🚀 5 步快速入门

初学者

1安装 Magpie

macOS / Linux / Windows 均可，一行命令搞定。桌面端 <15 MB，CLI 端 <7 MB。

curl -fsSL https://usemagpie.ai/install.sh | sh

或从 usemagpie.ai 下载安装包。macOS 已签名公证，Windows/Linux 首次运行需确认。Go 源码编译：go install github.com/yetone/magpie@latest

2打开菜单栏或 TUI

安装后 Magpie 自动出现在菜单栏（macOS）或系统托盘。点击图标即弹出面板。

magpie # 菜单栏图标 + 窗口同时打开 magpie tray # 仅菜单栏图标（开机自启推荐） magpie tui # 纯终端界面（SSH / 服务器场景）

3添加 Provider（API 密钥）

Preset 供应商只需粘贴密钥。Magpie 从不读取 shell 环境变量中的密钥。

magpie provider add deepseek sk-xxxxxxxxxxxx magpie provider add openai sk-xxxxxxxxxxxx magpie provider add ollama # 本地模型，无需密钥

4切换任意 Agent 的模型

模型名格式为 provider/model（如 deepseek/deepseek-chat）。Magpie 自动刷新供应商支持的完整模型列表。

magpie claude deepseek/deepseek-chat # Claude Code 切 DeepSeek magpie codex gpt-5.6-sol # Codex 切 GPT-5.6 magpie gemini auth api-key # Gemini CLI 切换到 API Key 认证

5保存为 Profile（一键切换全套）

Profile 保存所有 Agent 的当前模型配置。一键切换时，所有 Agent 模型同步更新。

magpie save work-setup # 保存当前完整配置 magpie use work-setup # 一键切换到该 Profile

⚡ 路由分组（Routing Groups）

多 Key 聚合

路由分组把多个模型（来自不同供应商）组成一个逻辑模型名 group/<name>，请求自动在成员之间路由。

smart（默认）
优先选配额最快用完的供应商，负载均衡
order
第一个模型直到无法回答，才切换下一个
rotate
每个对话轮次轮换到下一个成员
usage
优先使用调用次数最少的 Key
magpie groups
列出所有路由分组（含自动发现的）
magpie group add "Opus anywhere" models=claude/claude-opus-5-5,copilot/claude-opus-5 routing=order stays=session
创建自定义路由分组（Claude Opus + Copilot Opus 兜底）
magpie group set opus-anywhere routing=usage
修改现有分组的路由策略
magpie claude group/opus-anywhere
让 Claude Code 使用路由分组（通过网关）

stays= 参数：auto（默认，保持到供应商缓存失效）/ session（整个会话）/ turn（每轮切换）/ off（每次请求轮换）

🔑 订阅共享机制

核心价值

Claude Code 订阅 → 其他 Agent

Magpie 读取 Claude Code 的 OAuth 凭据（macOS Keychain 或 ~/.claude/.credentials.json），驱动本地 claude CLI 生成。Anthropic 将其视为 Claude Code 原生流量，系统提示词不触发第三方审查。

Pi / OpenCode 等 Agent 自动走这条路径，无需额外配置。

Codex / Copilot / Devin → 其他 Agent

Codex 读取 ChatGPT 登录（~/.codex/auth.json），Copilot 读取 GitHub 登录（~/.config/github-copilot/apps.json），Devin 读取自身认证（~/.local/share/devin/credentials.toml）。Magpie 定期刷新 token 并写回原位置，不额外存储。

Gemini CLI → Google 账号透传

读取 ~/.gemini 的登录状态直连 Google Code Assist API。若 Google 不再向个人账号开放，Magpie 会自动引导用户使用 Google Cloud 项目认证（需命名项目名）。

💾 备份与跨机器迁移

AES-256 加密
完整备份（含密钥）默认
# 导出完整备份（含所有 Provider API 密钥） magpie backup # 输出文件：magpie.magpie-backup # 导入时需要输入创建时设置的密码短语 magpie restore magpie.magpie-backup
不含密钥的备份更安全
# 备份不含密钥（服务器环境变量等留空） magpie backup --no-keys ~/backup-no-keys.magpie-backup # 导入：Provider 恢复，但不含密钥 magpie restore --no-agents b.magpie-backup # Agent 保持原样，仅恢复 Provider 和 Settings

备份内容：Provider（含密钥，默认）/ 模型图示 / Settings / Profiles / 所有 Agent 模型配置 / Library（指令集 / MCP 服务器 / Skills，单文件 >2MB 跳过）。加密：AES-256-GCM，密钥派生：PBKDF2-SHA256。管道输入密码时，第一行为密码短语。

❓ 常见问题与解决

排障指南
Agent 没有出现在 TUI 列表中？
Magpie 只显示已安装或已配置的 Agent。请确认 Agent 已安装并运行过一次（会自动生成配置文件）。部分 Agent 需要先执行一次初始化命令才会创建配置文件。
Provider 添加成功但模型列表为空？
运行 magpie provider models <name> 强制刷新模型列表。若仍为空，检查 API 密钥是否正确、账户是否有余额、供应商是否支持当前地区。
Claude Code 订阅被识别为第三方流量？
Magpie 通过本地 claude CLI 驱动 Anthropic 请求，系统提示词作为用户上下文传递，理论上不触发第三方分类。若仍有问题，确认 claude CLI 已安装并完成 OAuth 登录（claude login）。
Profile 切换后 Agent 模型没变？
Agent 在启动时读取配置文件。运行中的 Agent 会话保持当前模型；新建会话才会读取新配置。重启 Agent 进程以应用最新 Profile。
路由分组只有部分成员被调用？
检查 stays= 参数。smart 模式下，若第一个 Key 配额充足，后续 Key 不会被使用。改为 order 或 usage 可强制轮换。
macOS 菜单栏图标不显示？
运行 magpie tray 确认托盘模式可用。Linux 需要 WebKitGTK 4.1 支持。Windows 检查系统托盘区域是否有隐藏图标。
