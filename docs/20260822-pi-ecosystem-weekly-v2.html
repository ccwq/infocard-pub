小技巧：思考按需化

将思考（Thinking）从强制开销变成按需工具调用——在高频、轻量任务（如代码补全、简单重构）中禁用 Thinking；在复杂推理、多步规划时显式启用。

效果：实测在 DeepSeek V4 Flash 下，思考按需化可进一步提升缓存命中率，因为每次请求的 Prompt 前缀更稳定、更容易被缓存命中。
