1 一句话定义
Lertaro 是一款以 LocalSystem 后台服务 + NTFS USN Journal 低级索引驱动的 Windows 本地文件搜索工具，通过零提权 WPF UI 与全局键盘钩子实现秒级呼出与子毫秒级检索，同时提供视频/音频实时预览与 Flow Launcher 插件生态支持。
2 解决了什么问题
Everything
免费开源，搜索快，但无全局启动热键，只能最小化到托盘，每次需手动呼出
Lertaro: 双击 Ctrl 随时呼出，热键全局响应
Listary
Premium 收费，不支持视频/音频播放，仅显示文件信息，无动作菜单
Lertaro: 免费开源，Alt+P 直接播放视频/音频
两者共同痛点
无插件生态（Everything）、无磁盘透视（Listary）、无收藏夹直达、无 Treemap
Lertaro: Flow Bridge + Treemap + 收藏夹 + 动作菜单
3 架构详解 — 三层分离设计
后台服务
LocalSystem
Lertaro.Service — 核心索引引擎
以 LocalSystem 身份运行于 Windows 服务层，直接读取 NTFS USN Journal 与 $MFT 表，跳过文件系统过滤驱动实现零开销低级索引。通过命名管道（Named Pipe）向用户态 UI 进程提供高速只读搜索查询接口，服务与 UI 完全隔离，UI 崩溃不影响索引服务持续运行。
NTFS USN Journal $MFT 低级读取 Named Pipe IPC LocalSystem
用户态 UI
零提权
Lertaro.App — WPF 交互界面
标准用户会话 WPF 应用，以普通用户身份运行，无需任何提权请求。承载快速搜索栏（双 Ctrl 触发）、全功能搜索窗口、设置中心、插件加载器、动作菜单、收藏夹与历史记录模块。支持模糊搜索、文件操作、QuickLook 集成、LocalSend 本地网络分享。
WPF / .NET 10 零提权 QuickLook LocalSend
键盘钩子
Win32
Lertaro.HookHelper — 全局热键注册
使用 Win32 SetWindowsHookEx 安装全局低级键盘钩子（WH_KEYBOARD_LL），在系统层面捕获双击 Ctrl 组合键并触发 UI 呼出。钩子由独立 DLL 实现，与主进程解耦，确保热键在任意应用前台均可响应，无需额外后台进程或系统托盘图标。
Win32 Hook API WH_KEYBOARD_LL 双击 Ctrl 检测 无托盘依赖
4 核心功能详解
🔍
文件与文件夹搜索
双击 Ctrl 呼出搜索栏，关键词毫秒级返回结果。支持 NTFS USN Journal + MFT 低级索引实现子毫秒查询，支持模糊搜索。动作菜单提供快速查看与预览入口。100% 本地运行，零遥测数据上传。
USN Journal 模糊搜索 零遥测 动作菜单
▶
文件预览 Alt+P
按 Alt+P 预览任意文件或文件夹。支持视频/音频实时播放（竞品唯一支持），图片、文本、PDF 预览，QuickLook 集成，LocalSend 本地网络分享。预览内容无需离开 Lertaro 窗口即可操作。
Alt+P 视频播放 音频播放 QuickLook
🔌
插件系统
Flow Launcher Bridge 原生接入 Flow Launcher 插件社区，支持 flow install <name> 一键安装。官方 .NET 10 C# SDK（Lertaro.PluginSdk）可开发自定义插件。内置插件：窗口切换、翻译（tr）、进程管理、网页搜索、快速直达、内容搜索（cs）。
Flow Bridge C# SDK Python 3.12 Node.js v20
⭐
收藏夹
可收藏文件、文件夹与网址。双击 Ctrl 呼出搜索栏时，第一屏即显示收藏内容，无需输入关键词即可快速访问常用路径。收藏项支持分组管理，与历史记录分离，保证隐私与效率兼得。
文件收藏 网址收藏 首屏直达
📊
磁盘透视 Treemap
内置磁盘空间可视化 Treemap，直观展示各目录占用空间比例，快速定位大文件与无用文件夹。区别于 Everything（无此功能）与 Listary（无此功能），是日常磁盘清理与空间管理的实用入口。
Treemap 磁盘分析 空间清理
⚙
其他功能
历史记录（自动保存搜索与访问轨迹）、快速面板（Jump List 集成）、原生文件对话框停靠（文件另存为时自动挂载 Lertaro 快速访问栏）、窗口切换插件、进程管理。功能覆盖从搜索到操作完整闭环。
历史记录 Jump List 原生对话框

8 局限性
❌
仅支持 Windows — 无 macOS、Linux 版本，无法跨平台使用
⚠
.NET 10 运行时门槛 — 用户需下载安装约 1GB 运行时包，对首次接触 .NET 的用户有一定心理与时间成本
⚠
ARM64 需确认支持状态 — 文档显示 ARM64 构建存在，但 Windows ARM 生态的 .NET 10 运行时覆盖度待验证
⚠
