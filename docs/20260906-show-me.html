show-me：用最小最清晰的图，把复杂话题直接看懂

/show-me 命令 · 7 种输出格式 · 4 大核心场景
核心定位：把复杂话题压缩为最小最清晰的视觉结构，一眼看穿本质
一句话说明

对话中遇到复杂概念、系统架构、流程变更时，一句 /show-me 直接生成结构图、伪代码或信息图，把文字说不清的关系和路径可视化出来。

AI 可视化 结构压缩 多格式输出 Hermes 原生 Skill
1对话中触发
2AI 分析话题

安装与触发方式

show-me 是 Hermes Agent 内置 Skill，无需额外安装任何插件。在对话中直接发送斜杠命令即可触发。

在 Hermes 对话窗口输入：
/show-me [你关心的复杂话题]

示例：
/show-me RAG 的检索-生成流程
/show-me MCP 协议的调用链路
/show-me 这个 PR 改了什么

7 种输出格式详解

01 Pseudocode 伪代码

展示算法逻辑或条件判断流程，适合解释「什么时候做什么」的核心逻辑。

02 Call Tree 调用树

展示函数/模块之间的调用层级，适合理解复杂代码的运行时控制流。

03 Component Tree 组件树

展示 UI 组件结构与状态/模块边界，适合 React/Vue 等前端架构分析。

04 File Tree 文件树

展示目录结构与各文件职责，适合大型项目的架构概览与重构规划。

05 Mermaid 时序图

展示组件交互、数据流或控制流，适合分布式系统与 API 调用链分析。

06 Diff 变更对比

展示新增/删除的逻辑块，适合代码 review、PR 讲解与重构前后对比。

07 HTML Artifact 信息图 / 幻灯片

当概念过于密集、Mermaid 无法承载时，生成完整的 HTML 可视化页面（图表、信息图、迷你幻灯片），支持桌面端和移动端，并自动用浏览器打开。可一键截图用于传播。

4 大核心场景

01

找选题：让信息自己冒出角度

丢入新闻、产品更新或行业事件 → 画出事件背景、关键角色与影响路径 → 识别出值得写的角度。适合自媒体创作者快速从海量信息中定位切入点。

02

生成可截图传播的视觉素材

用 HTML Artifact 输出信息图或迷你幻灯片 → 用于文章配图、社媒截图、课程讲解或内部分享。产出的 HTML 可直接在浏览器中打开并截图，无需设计工具。

03

理解复杂 AI 概念：先看过程，再啃技术

Agent / RAG / MCP 等满是术语的话题 → 展示运行流程与数据流 → 先看懂过程再啃技术解释。适合快速建立认知框架，再深入细节。

04

学习复杂 AI 工具：画完整工作流

AI 工具功能多、操作路径深 → 画完整工作流（第一步做什么 / 在哪里配置 / 结果如何进入下一步）→ 从入门到掌握不再迷路。

其他适用场景

场景说明
解释复杂机制如浏览器缓存策略、数据库事务隔离级别，用流程图代替长篇文字
梳理系统或项目结构接手遗留代码库时快速建立全局视图
看懂流程和变更在代码 review 或技术方案讨论中，用 diff 精确表达变化
整理内容和知识将散乱的信息点归类为结构化的树状或流程图

适用与不适用

✓ 适合

  • 需要快速理解复杂系统的整体结构
  • 代码 review 需要精确定位变更点
  • 学习新工具需要建立操作路径地图
  • 需要生成可传播的视觉内容
  • 需要把抽象概念具象化给团队讲解

✗ 不适合

  • 简单事实性问答（一个数字或一句话能说清的）
  • 需要实时交互的数据可视化（如动态图表）
  • 已高度图形化的数据需要二次加工
  • 纯文本创作或文案撰写
