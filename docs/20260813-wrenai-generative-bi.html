一句话定位

2026-08-05 @海洋馆馆长 CycleDecoded

WrenAI 是一个专门给 AI Agent 打造的 Generative BI（生成式商业智能）引擎——在数据库和 AI 之间塞了一层"业务语义理解"层。不管是 PostgreSQL、ClickHouse、Snowflake 还是 BigQuery，连上就能直接让人话变成准 SQL 和可视化图表。

核心卖点

5 大差异化能力

通吃 20+ 种数据库

PostgreSQL、ClickHouse、Snowflake、BigQuery、MySQL、MongoDB、DuckDB 等主流数据源全部支持，一键打通不挑食。

业务上下文语义层

MDL（Modeling Definition Language）建模定义语言，AI 不再瞎猜表结构，查询零幻觉，指标口径精确。

自动出可视化图表

说句人话直接生成漂亮仪表盘，不需要数据分析师手动画图。

无缝对接 AI Agent

通过 MCP Server 或 SDK 与 Claude Code、Cursor 等主流 Agent 工具无缝集成，开箱即用。

完全开源可私有化

敏感数据不外流，支持本地部署，企业内部 BI 场景完全自主可控。

技术架构

Open Core 模式

MDL 语义层

建模定义语言（Models、Columns、Relationships、Views、Cubes、Metrics），row/col 级别访问控制。

Engine（Apache DataFusion）

基于 Apache DataFusion，Rust 实现高性能执行引擎。

Memory & Examples

LanceDB 向量存储，混合检索，历史 SQL 样本学习。

Agent SDK

wren-langchain（LangChain/LangGraph）、wren-pydantic，Python 集成。

Open Core 边界：MDL 语义层 + governed text-to-SQL + MCP Server + CLI + 22+ 连接器全部 Apache-2.0 永久免费；高级分析和托管服务属于商业版。
