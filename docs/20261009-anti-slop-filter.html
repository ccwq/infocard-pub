AI 味是什么

1界面无真实数据——sparkle logo、beta pill、假终端、编造的数字，一个都不放
2文案用 emoji 当列表符号，写无意义填充内容，连破折号都拿来当标题
3代码里加 ===== 分隔线，写复述代码的注释（"This function adds two numbers"）
鱼皮推文三条规矩具象化 AI味识别 过滤器

38 条强制规则 · 三层 Gate

Hard Gate

零容忍

任何产出必须满足，否则直接 FAIL。包括：无真实数据不放数字、不用 emoji 做列表符号、不写无意义填充文案。

Purpose Gate

目的核查

内容是否存在真实目的？是否删掉了"看起来像 AI 写的"但没有意义的部分？

Quality Locks

质量锁

在 Hard Gate 和 Purpose Gate 之后，用三个旋钮——ENERGY / RHYTHM / MOTION——把结果从"干净"变"活"。

Delivery Gate · 发布前必过

1规则全部过一遍，产出 PASS / FAIL 报告
2FAIL 项必须修复，再出最终报告
3FAIL 数量为零才能发布

Liveliness Toolkit · 活起来

ENERGY能量密度
RHYTHM节奏韵律
MOTION动态留白

三个旋钮调节，不是风格选择器——把结果从"干净"变"活"，但"活"不等于"AI 味"。

两种使用模式

During

边建边过滤

项目开发过程中实时过滤，建完即出 Delivery Gate 报告。适合新项目。

After

审计已有产出

输出编号问题清单 → 你批准修哪些 → 跟进报告。适合清理已有 AI 输出。

默认每次会话问一次，可用 npx antislop-ai --mode during 保存偏好到 ~/.config/antislop/settings.json。

⚡ 边界提醒

过滤器不能发明方向。 结果呆板 ≠ 过滤器失效，是缺方向（DESIGN.md）。antislop 自己永远不会美化——它只负责去丑，去掉之后是什么，由你决定。
