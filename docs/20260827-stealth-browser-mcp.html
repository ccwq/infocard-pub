OVERVIEW · 一句话概述

Stealth Browser MCP 是什么

定位浏览器自动化框架

反爬克星 + AI Agent 专用

基于 nodriver（无头 Chrome 驱动）+ 真实 Chrome 内核，在 AI Agent 场景中直接硬闯 Cloudflare 和 Queue-It 等反爬验证，而非依赖代理池或打码服务。

核心差异真实浏览器

不是 Selenium / Playwright

不依赖 WebDriver，不注入 JS 特征；使用 nodriver 直接控制 Chrome，行为与真实用户浏览器一致，反爬系统难以识别为自动化。

CAPABILITIES · 核心能力

97 个工具，覆盖全自动化链路

从基础页面操作到底层 CDP 命令，从 UI 克隆到网络拦截，可按需裁剪至 20 个精简工具集。

精简版工具数量

可裁剪至 20 个工具

完整 97 工具集适合复杂场景；按需裁剪到 20 个精简版，降低 AI Agent 上下文消耗，适合简单自动化任务。

技术栈nodriver

nodriver 底层驱动

nodriver 是无头 Chrome 的 Pythonic 封装，不依赖 Selenium/Playwright 的 WebDriver 协议，无自动化特征，是绕过反爬的关键。

INSTALL · 安装与使用

安装方式

开源项目，可直接 Clone 代码使用；MCP 集成需配合 Claude Desktop 或其他支持 MCP 的 Agent。

方式一GitHub Clone

直接拉取源码

git clone https://github.com/vibheksoni/stealth-browser-mcp
cd stealth-browser-mcp
pip install -e .  # 或 pip install nodriver 等依赖
方式二MCP 集成

Claude Desktop 集成

{
  "mcpServers": {
    "stealth-browser": {
      "command": "npx",
      "args": ["-y", "@vibheksoni/stealth-browser-mcp"]
    }
  }
}
工具集配置可自定义

精简工具集（20 个）

如果完整 97 工具集对 Agent 上下文消耗过大，可在 MCP 配置中声明只启用部分工具：

{
  "tools": ["navigate", "click", "type", "screenshot",
            "cdp_send_command", "clone_element",
            "intercept_request", "get_cookies"]
}
