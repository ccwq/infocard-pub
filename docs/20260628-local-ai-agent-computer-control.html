🧠 主脑模型 · 35B GGUF 量化版
Qwen3.5-35B-A3B MoE
选用 Qwen3.5-35B-A3B MoE 架构（总参数 397B，激活仅 17B，稀疏激活率 <4.3%），配合 Q4/Q5_K_M GGUF 量化，推理成本媲美 20B 级模型，同时保持强力指令跟随与工具调用能力。适合 Agent 任务编排、长上下文和复杂推理。
MoE 稀疏激活 Q4/Q5 量化 GGUF 格式 工具调用 1M Token 上下文
👁️ 视觉核心 · ~800MB 轻量模型
多模态感知
为 OpenClaw 提供屏幕理解能力的轻量视觉模型，负责解析 UI 界面、识别按钮和输入框、定位验证码、理解图像内容。全程本地运行，无网络传输，响应速度快。
屏幕截图解析 UI 元素识别 图像内容理解 验证码检测 全网反向图片搜索
⚙️ 推理引擎 · llama.cpp
GGUF 本地推理
llama.cpp 是本地推理 GGUF 模型的标准引擎，支持 NVIDIA CUDA 和 AMD HIP 两种后端，适配从 4GB 到 24GB 显存的各种消费级显卡。通过 ./server 启动 HTTP API 服务，OpenClaw 通过标准 OpenAI 兼容接口接入。
GGUF 模型加载 NVIDIA CUDA AMD HIP OpenAI 兼容 API 上下文长度可配

部署最佳实践
① 底层环境配置
根据显卡类型选择对应版本 llama.cpp，然后依次下载主模型和视觉模型文件，放入指定目录。
# NVIDIA 显卡 → 下载 CUDA 版 llama.cpp # AMD 显卡 → 下载 HIP 版 llama.cpp # 地址: https://github.com/ggerganov/llama.cpp/releases # 下载 Qwen3.5-35B-A3B GGUF 量化模型（Q4_K_M，约 20GB） # 推荐从 hf-mirror.com 国内镜像下载（速度更快） wget https://hf-mirror.com/Qwen/Qwen3.5-35B-A3B-GGUF/resolve/main/qwen3.5-35b-a3b-q4_k_m.gguf # 下载 ~800MB 轻量视觉模型 wget https://huggingface.co/***/vision-model.gguf
💡 国内加速：用 hf-mirror.com 或 modelscope.cn 替代 HuggingFace 下载，速度可达 MB/s 级。用 aria2c -x 16 -s 16 多线程下载大文件更稳定。
② llama.cpp 推理服务启动
将 GGUF 模型文件放入 llama.cpp 模型目录，启动本地 HTTP API 服务（OpenAI 兼容接口），供 OpenClaw 调用。
# 启动 llama.cpp HTTP 服务（NVIDIA CUDA 示例） ./server \ -m qwen3.5-35b-a3b-q4_k_m.gguf \ -c 8192 \ # context 长度 --port 8080 \ --host 0.0.0.0 \ -ngl 99 # GPU 加载层数（99=全加载） # 验证服务正常 curl http://localhost:8080/v1/models
③ 安装 OpenClaw 并接入本地模型
安装 OpenClaw，通过 onboard 向导配置 API 指向本地 llama.cpp 地址，并显式开启视觉模块。
# 安装 OpenClaw（Node.js 22+ 环境） npm install -g openclaw@latest # 运行初始化向导（选择 Advanced 模式自定义模型） openclaw onboard --flow advanced # 关键配置步骤： # 1. Provider → 选择 "Custom" # 2. Default Model → 填入本地模型 ID（如 qwen-35b） # 3. API 地址 → 填入 llama.cpp 服务地址 # http://localhost:8080/v1/chat/completions # 4. ⚠️ 显式开启视觉模块： # 在配置文件中添加： # vision.enabled = true # vision.model = "本地视觉模型路径"
⚠️ 关键约束：必须显式开启视觉模块（vision.enabled = true），否则 AI 无法解析屏幕截图，无法实现 UI 定位、验证码识别、以图搜图等核心能力。
④ 启动并使用
启动 OpenClaw，通过 Web 界面、飞书、Telegram 或微信发送自然语言指令，AI 代理开始接管电脑。
# 启动 OpenClaw openclaw start # 打开 Web 界面 # 访问 http://localhost:3000 # 或接入飞书（需配置飞书机器人） # 修改 ~/.openclaw/config.yaml: # channels: # feishu: # enabled: true # app_id: "your-app-id" # app_secret: "your-secret"

局限与风险
限制项 说明 规避建议
硬件门槛 至少需要 6GB 显存才能跑 9B 模型，35B 需 20GB+ 先用 9B 模型验证思路，再按需升级显卡
模型质量差距 量化 GGUF 在指令跟随、JSON 稳定性上弱于 GPT-4o / Claude 用官方 GGUF（非社区魔改），避免 distilled/uncensored 后缀
视觉模型配置复杂 需手动下载、放置、显式开启视觉模块 参考部署步骤第③步，确认 vision.enabled=true
首次部署耗时 模型下载 + 环境配置可能需要数小时 用国内镜像（hf-mirror / modelscope）加速下载
权限风险 OpenClaw 拥有系统命令执行权限，需注意配置文件 tool.profile 设置为 full 仅在受控环境开启；生产环境建议限制
