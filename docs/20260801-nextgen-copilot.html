▌Copilot Agent 模式能做什么

🔍 理解整个项目

  • 跨文件上下文感知
  • 理解代码库架构和依赖关系
  • 识别分散在各文件的相关逻辑
  • 减少"局部补全"导致的全局不一致

🔧 执行多步任务

  • "修复这个 bug"→自动定位→修改→验证
  • "添加单元测试"→找到相关模块→生成→运行
  • "生成 API 文档"→扫描所有端点→输出

🔄 跨会话持久化

  • 记住之前的修改意图和上下文
  • 新会话中无缝衔接上次的进度
  • 从"每次都是新对话"到"持续的工作记忆"

▌为什么这个趋势值得关注

🎯 编程的民主化

  • "帮我完成这个任务"降低了编程门槛
  • 非程序员可以用自然语言驱动代码生成
  • 编程教育从"学语言"转向"学工作流"

⚖️ 专业 vs 通用之争

  • Cursor = 专用 AI IDE（All-in-one）
  • Copilot = 嵌入式集成（已有工作流不变）
  • 两者都在互相渗透：Copilot 做 IDE，Cursor 做 Agent

📈 市场影响

  • Cursor ARR 超过 $500M（2024）
