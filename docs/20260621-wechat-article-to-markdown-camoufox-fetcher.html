📖 为什么值得看

微信公众号文章抓取最烦的不是解析 HTML，而是微信的反检测和页面结构飘忽。这个工具直接把 Camoufox 融进抓取链路：先拿到文章，再清洗成 Markdown，图片下沉到本地，代码块也尽量保留语言标签。

它的定位很明确：把公众号长文变成可检索、可归档、可再加工的内容资产。

抓文章只是开始，真正值钱的是把内容变成结构化 Markdown。
一句话

wechat-article-to-markdown 是一个带 Camoufox 抗检测抓取的公众号文章转 Markdown 工具：提取标题、公众号名、发布时间、原文链接，下载图片到本地 images/，并把 code-snippet 转成带语言标记的 Markdown 代码块。

🛠 核心能力
能力说明
抗检测抓取使用 Camoufox 规避公众号页面的自动化检测
元信息提取标题 / 公众号名称 / 发布时间 / 原文链接
Markdown 转换把文章 HTML 结构清洗成干净 Markdown
图片本地化下载图片到 output/
/images/ 并重写链接
代码块保真处理微信 code-snippet，尽量保留语言 fence
AI Skill 集成自带 SKILL.md，可直接安装进 agent runtime
🔄 流程
❌ 手工复制公众号文章
  • 排版乱
  • 图片丢失
  • 代码块格式崩坏
  • 后续难检索 / 难归档
✅ 工具链输出
  • 抓取 → 清洗 → Markdown
  • 图片下载到本地
  • 代码块语言保留
  • 输出可直接进知识库 / 笔记系统
输出目录固定为 output/<article-title>/，方便批量归档与二次处理。
📦 安装
推荐安装
uv tool install wechat-article-to-markdown

# 或
pipx install wechat-article-to-markdown
源码安装
git clone git@github.com:jackwener/wechat-article-to-markdown.git
cd wechat-article-to-markdown
uv sync
💻 使用示例
CLI
wechat-article-to-markdown "https://mp.weixin.qq.com/s/xxxxxxxx"

# 或
uv run wechat-article-to-markdown "https://mp.weixin.qq.com/s/xxxxxxxx"

# 兼容入口
uv run main.py "https://mp.weixin.qq.com/s/xxxxxxxx"

🧪 测试
场景命令

真实公众号 E2EWECHAT_E2E_URLS=... uv run --with pytest pytest -q -m e2e -s
E2E 依赖网络与浏览器运行时，仓库把它放进手动 GitHub Actions 工作流。
🤖 作为 AI Skill

项目自带 SKILL.md，可直接作为 AI Agent Skill 安装，支持 Skills CLI 和手动安装两条路。

npx skills add jackwener/wechat-article-to-markdown

手动安装也很直接：把 SKILL.md 放进 ~/.claude/skills/wechat-article-to-markdown 即可。

📌 边界说明
  • 依赖 Camoufox：公众号反检测抓取能力来自 Camoufox，抓取链路对浏览器和网络条件有要求。
  • 网络可用性：E2E 测试和实时抓取都需要网络；离线只能处理已抓取好的 HTML。
  • 不等于全站镜像：它的目标是内容提取和转换，不是完整爬取公众号站点。
  • 输出后还要再加工：适合进笔记、知识库、RAG 索引，不是最终发表版排版工具。
