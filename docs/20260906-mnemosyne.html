01 概述

Mnemosyne 是零依赖的本地 AI 记忆层，为 LLM Agent 提供长期记忆能力。采用 SQLite 后端（内置 sqlite-vec + FTS5 向量引擎），无需任何外部服务，数据完全留在本地。支持 BEAM 三层记忆架构（Working Memory / Episodic Memory / Scratchpad），自动 consolidation，混合检索精度达 98.9%。

BEAM 架构 零依赖 SQLite 本地 MCP Server 离线可用

02 核心架构

Mnemosyne 遵循 remember → recall 的完整记忆生命周期：

remember() ──► working_memory ──► sleep() consolidation
                                                   │
                                                   ▼
                            episodic_memory ◄──────┘
                                │
                                ▼
                            recall()
working_memory episodic_memory scratchpad sleep() 自动压缩 sqlite-vec 向量 FTS5 全文

05 快速上手

pip install mnemosyne
import mnemosyne

# 初始化
m = mnemosyne.Mnemosyne()

# 添加记忆
m.remember("用户偏好深色主题", metadata={"type": "preference"})

# 检索记忆
results = m.recall("用户的视觉偏好是什么？", limit=5)

# 手动触发 consolidation（平时自动进行）
m.sleep()
