01
What it is

CodePilot 是什么

官方自述是一个多模型 AI agent desktop client。它从 coding tool 发展为通用 AI agent 工作台，核心是把 provider 接入、workspace、技能、会话和桥接能力统一到桌面端。

你会得到什么

一个可直接运行在 macOS / Windows / Linux 上的桌面客户端，用你的 API key 连接不同 provider，而不是被单一平台绑死。

它解决什么问题

把“模型选择、上下文切换、会话续接、权限确认、技能复用、通知和任务调度”放进同一个地方，减少在多个工具之间来回切。

02
Quick start

首次使用：下载还是源码构建

官方给了两条路：大多数人直接下载 release；开发者可从源码运行 Electron + Next.js。Linux 官方说明更偏向源码构建或发行包选择。

Path A：下载 release

最省事。下载对应平台安装包，启动后先到 Settings > Providers 配置 API key，再开始对话。

Path B：源码开发

开发入口是 npm install 后运行 npm run electron:dev。适合二次开发或想看内部实现的人。

官方下载分发

macOS 有 Apple Silicon / Intel；Windows 提供安装包；Linux 可用 AppImage / deb / rpm，具体以上游 release 为准。

03
Core capabilities

核心能力：provider、MCP、workspace、bridge、scheduler

真正的重点不是“能聊天”，而是它能把多个 agent 能力拼成工作流：模型接入、技能扩展、个人助理、跨端桥接、生成式 UI 和定时任务。

Provider layer

17+ provider

支持 Anthropic、OpenRouter、Bedrock、Vertex、Kimi、Moonshot、MiniMax、Volcengine Ark、Ollama、LiteLLM 等。

Capability layer

MCP + Skills

可接 stdio / sse / http MCP server，并挂接可复用 skills 或 marketplace 里的扩展。

Workspace layer

Assistant Workspace

把 persona、memory、onboarding 和日常检查点放到助理工作区里，让助手记住偏好。

Ops layer

Bridge + Scheduler

可连 Telegram、Feishu、Discord、QQ、WeChat；还能用 cron/interval 安排周期任务。

04
Concrete usage

配置与使用：从 Provider 到会话恢复

官方 README 里最明确的操作路径，就是先配置 provider，再启动对话。功能上还强调 pause / resume / rewind、split-screen 和 session persistence。

配置边界

  • 在 Settings > Providers 填入你自己的 API key
  • 可以切换不同 provider / model
  • 本机直连 provider，不经过 CodePilot 中转

使用方式

  • 多 session 并行，互不干扰
  • 可回放 / rewind 到任意 checkpoint
  • 支持从 Claude Code CLI 导入历史会话

06
Suitable vs unsuitable

适合什么场景，不适合什么场景

CodePilot 适合做“AI 工作台”，不适合被描述成纯聊天客户端或把未核验的性能宣传写成结论。

✓ 适合

  • 想统一接入多个 AI provider 的个人或小团队
  • 需要 workspace、memory、skills、scheduler 的重度用户
  • 想把聊天、任务、通知、跨端桥接放进一个桌面客户端

✗ 不适合

  • 只想要一个最轻量的单 provider 聊天界面
  • 不愿意自己管理 API key 或本地工作区
  • 需要完全官方托管、无需本地安装的云端 SaaS
