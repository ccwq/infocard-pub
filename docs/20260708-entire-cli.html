CAPTURE · 记录内容

Prompts

完整 Prompt 记录

Responses

COMMANDS · 核心命令
命令作用
entire enable在当前 Git 仓库启用 Entire（安装 Git hooks）
entire enable --agent <name>非交互式指定 Agent（如 cursor / claude / codex）
entire status查看当前 session 状态
entire agent添加或移除 Agent hook
entire configure更新非 Agent 设置（遥测/hooks/Checkpoint remote）
entire session resume <branch>恢复指定分支的最新 Checkpoint，继续工作
entire clean --force清理当前 Commit 的孤立数据
entire disable禁用 Entire（Git hooks 移除，代码历史不动）
entire doctor诊断 Entire 配置和连接状态
AUTO SUMMARIZE · 自动摘要

Commit 时自动生成 AI 摘要

当 Claude CLI 已安装并认证，Entire 在 commit 时自动生成摘要：捕获意图、结果、教训、摩擦点和未完成项。

requirements: claude 命令在 PATH 中可用。摘要生成非阻塞，失败只记录日志，不阻止 commit。

VS BEFORE · 对比

❌ 无 Entire（现状）

  • Agent 干了什么、为什么这么改，全靠记忆
  • 新成员加入，看不懂某段代码的历史
  • Agent 跑偏了，只能手动 reset
  • 团队多人用 Agent，commit 历史没有任何上下文
  • "这段 CSS 为什么这么写？"——查不到了
  • 无法审计 Agent 的行为边界

✅ 有 Entire

  • 每条 commit 附带完整 prompt/response 记录
  • 新成员看到从 Prompt → Change → Commit 的完整路径
  • 随时 Rewind 到任意 Checkpoint，恢复到正确状态
  • 团队共享 Agent session，分支隔离，互不污染
  • "当时为什么这么改？"→ 查 Transcript
  • Session 数据存单独分支，主线 Git 历史干净
