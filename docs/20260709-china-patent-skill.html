FEATURES — CONFIRMED

已核实核心功能

5 项功能均已在源码层面确认存在，文件路径明确，README 原文引用可查。

✅ 已核实

① 自动扫描 · 专利点挖掘

按优先级读取文档和代码（专利文档 → 详细设计 → 核心实现 → 系统设计），自动挖掘可专利技术点。Office 文件（.docx/.pptx）强制转 Markdown 再扫描。

  • 对应文件：prompts/project_scan.md + prompts/patent_points_analyzer.md
  • 支持 .docx / .pptx 转换（tools/docx_to_md.py / pptx_to_md.py）
  • 支持 .go 等多种语言代码扫描
  • "自动"程度依赖调用 Agent（Claude Code / Cursor）
✅ 已核实

② 国知局联网查新检索

优先调用国知局·中国专利公布公告站（epub.cnipa.gov.cn）；异常或无果时降级 Google 学术 / Patents WebSearch。

  • 对应文件：tools/cnipa_epub_search.py + prompts/prior_art_search.md
  • 依赖 playwright（可选）：pip install playwright && playwright install chromium
  • ⚠️ 实际运行效果 / 检索精度未经实测验证
✅ 已核实

③ mermaid 系统框图 + 流程图

交底书强制使用 fenced mermaid 生成系统框图和流程图（PNG），禁止 ASCII 文字框图。节点标签须简短中文/数字，避免 ①②③。

  • 对应文件：prompts/disclosure_builder.md §7.2 & §7.4
  • 本地 mmdc 渲染，不依赖外网 PlantUML
  • ⚠️ mermaid 图实际视觉效果未经截图核验
✅ 已核实

④ 导出 Word

mermaid 渲染完成后默认生成同名 .docx 文件。Word 中以 PNG 图为准，无需再附 ASCII 框图。

  • 对应文件：tools/mermaid_render.py + tools/md_to_docx.py
  • 使用方式：python3 tools/mermaid_render.py -i "草稿.md" -o "时间戳.md"
✅ 已核实

⑤ 迭代修改支持

补材料、纠错均在原稿基础上继续，不推倒重来。每次交付生成带新时间戳的文件，不覆盖旧稿；修订对话记录追加到 交底书修订对话记录.md。

  • 合并（merger）：补充材料、扩展方案 → prompts/merger.md
  • 纠正（correction）：纠错、参数调整 → prompts/correction_handler.md
  • 修订日志：每次迭代追加 → tools/iteration_dialog_log.py
  • 上下文管理：prompts/iteration_context.md

04
INSTALLATION

安装使用方法

克隆仓库后按顺序安装依赖，然后在 Claude Code / Cursor 中加载 SKILL.md。

1

克隆仓库

git clone https://github.com/handsomestWei/patent-disclosure-skill.git
2

安装 Python 依赖

pip install -r requirements.txt
3

安装 Node.js 工具（mermaid-cli）

npm install -g @mermaid-js/mermaid-cli
4

可选：安装 playwright（国知局查新依赖）

pip install playwright && playwright install chromium
5

在 Claude Code / Cursor 中加载 SKILL.md，按对话引导完成交底书生成。
