Rakazo

开源 Grok Bot 替代品：自带模型和沙盒，本地跑通完整 AI 代理产品——每个 bot 拥有独立线程、实时 Linux 桌面、记忆和派生能力。

沙盒方案对比
Docker（默认）
本地快速 / 单机自托管
本机 Docker 容器作为 Linux 桌面，沙盒 supervisor 控制本地 Docker daemon，适合信任的单机环境。
E2B
公网 / 多用户部署
E2B 远程桌面，通过 E2B SDK 提供隔离沙盒，需要 E2B_API_KEY，机器不保留数据主权。
Daytona
公网 / 多用户部署
Daytona 远程桌面，通过 Daytona SDK 提供隔离沙盒，需要 DAYTONA_API_KEY。
实时电脑桌面亮点

bot 的沙盒是带浏览器的 Linux 桌面，你可以随时接管操作：登录网站、控制浏览器、操作文件。释放后 bot 保持会话继续干活，不会中断。

本地运行
setup commands
# 1) 复制环境变量
cp .env.example .env

# 2) 配置 .env（必填）
BETTER_AUTH_SECRET=<随机字符串>
ENCRYPTION_KEY=<随机字符串>
OPENROUTER_API_KEY=<你的 Key>
# 或者在 UI 上直接粘贴 API key，跳过 .env 配置

# 3) 启动 Postgres（Docker）
docker compose --env-file .env \
  -f infra/compose/docker-compose.yml up postgres -d

# 4) 安装依赖 + 初始化数据库
pnpm install && pnpm db:generate && pnpm db:migrate && pnpm sandbox:build

# 5) 启动全栈（API + Worker + Web + Supervisor）
pnpm dev

# 6) 打开产品
http://127.0.0.1:5173

# 健康检查
curl http://127.0.0.1:3100/health
