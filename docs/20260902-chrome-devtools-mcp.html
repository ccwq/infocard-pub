Chrome DevTools MCP

让编码 Agent 看见真实浏览器

官方 MCP server 通过 Chrome DevTools 提供导航、输入、截图、网络、调试、性能、扩展和 PWA 能力。

核心判断：它不是“自动点网页”的黑盒，而是把 DevTools 能力以 MCP 工具形式开放给编码 Agent。

工具面

输入与导航

click、fill、type、navigate、new page、wait 等浏览器交互。

观察与调试

evaluate script、console、snapshot、screenshot 和网络请求查看。

性能

可启动 trace 并分析性能洞察，也能运行 Lighthouse 审计。

扩展与 PWA

支持扩展安装/重载/触发动作，以及 PWA 状态与安装管理。

部署时别漏掉的两件事

第一，MCP 客户端能检查和修改浏览器中的数据，不能把敏感页面直接暴露给不受信任的 Agent。第二，usage statistics 默认开启，需要按组织政策决定是否关闭。

来源与边界

官方支持 Google Chrome 与 Chrome for Testing；它会把浏览器内容暴露给 MCP 客户端，敏感数据和 usage statistics 必须单独评估。
