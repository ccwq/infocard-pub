01从需求到落地的四个判断
01

为什么放到本地？ 🔒

核心诉求是降低云 API 费用并保护隐私。适用场景包括本地 Agent 开发、代码辅助、文档翻译与自动化处理。

成本控制隐私本地工作流
02

先按显存选模型 🧠

QWable-v1：基于 Qwen 基座，融合 F5 与 GPT-v5 数据蒸馏微调；建议 24GB 显存（RTX 4090/5080）。
Qwen-9B：面向轻量文本转换与基础任务。

QWable-v1Qwen-9B模型选型
03

量化不是越大越好 🎚️

QWable-v1 推荐 Q4_K_M 或 Q5/Q6。Qwen-9B：12GB 显存选 Q6 以下，16GB 显存可选 Q8。按显存严格匹配，避免上下文增长导致 OOM。

Q4_K_MQ5/Q6Q8
04
