02

核心能力

Markdown 本地存储

笔记保存为普通 .md 文件，可用任意编辑器打开和编辑。无专有格式，无云服务依赖，数据完全自主掌控。

多 Agent 共享上下文

Codex、Claude Code、OpenCode、Hermes 等多个 Agent 连接到同一套笔记，共享背景、决策和结果，无需每次从零开始。

MCP + CLI 双协议

通过 MCP（Model Context Protocol）Server 连接主流 AI 编码工具，或通过 CLI 脚本直接调用。

Agent 结果写回笔记

Agent 执行结果可直接写回 Markdown，保持上下文持久化。下次调用时 Agent 自动获得完整历史。

07

判断

✅ 核心价值

Flowix 填补了"AI 笔记"与"Agent 记忆系统"之间的空白。它不是又一个 Markdown 编辑器，而是第一个把本地 Markdown 文件真正变成 Agent 可持续工作上下文的工具。

✅ 差异化定位

Notion、飞书解决的是人类协作；Flowix 解决的是 Agent 记忆。与其让 Agent 每次从"失忆"开始，不如让它从你已有的笔记中恢复上下文。

⚠️ 适用边界

Flowix 最适合的场景：单人多 Agent、长期项目背景积累、需要跨会话持续推进的工作流。如果只需要简单的人类笔记，Notion/飞书更成熟；如果已有自定义 Agent 记忆系统，Flowix 可能与现有方案重叠。
