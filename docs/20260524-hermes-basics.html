Hermes Agent

基本概念速查

核心术语 · 交互模式 · 工具集 · 工作流

01

Agent / 角色

每次对话绑定一个 Agent 角色，拥有专属的 system prompt、人格设定和可用工具集。角色定义决定行为边界。

role: assistant / orchestrator / leaf
02

Skills / 技能

可复用的技能单元，存储为 SKILL.md。技能描述触发条件、步骤、命令和避坑指南，Agent 启动时自动加载匹配技能。

skill_view(name) → load & execute
03

Memory / 记忆

持久化存储，分为 User Profile（用户偏好）和 Agent Memory（跨 session 积累的环境事实）。工具调用自动注入上下文。

memory: add / replace / remove
04

Tools / 工具

Agent 执行能力边界。内置工具有 terminal、read_file、patch、web_search、browser_* 等；还可通过 MCP 协议扩展自定义工具。

MCP: configure in config.yaml
05

Cron / 定时任务

定时触发 Agent 任务。Job 包含 prompt、schedule、skills 清单，运行时加载完整上下文后自主执行，结果可推送至指定平台。

cronjob: create / list / remove
06

Delegate / 委托

父 Agent 将子任务分发给独立 Agent 进程并行处理。子 Agent 有独立 session 和工具集，结果汇总后返回父 Agent。

delegate_task: goal / tasks[]
07

Channels / 渠道

多平台消息接入（Telegram、QQ、飞书等），消息经 Channel → Agent 处理后，按配置路由回指定平台，形成完整对话闭环。

channels: home / origin / all
08

Session / 上下文

每次对话为一个 Session，Agent 可在 session 内搜索历史（session_search）、构建上下文窗口。跨 session 信息写入 Memory。

session_search: query / browse
