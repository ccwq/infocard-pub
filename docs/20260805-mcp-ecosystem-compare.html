规范/SDK
MCP（Model Context Protocol）是由 Anthropic 主导的开放规范，让 LLM 与外部工具、数据源安全交互。

规范以 TypeScript 定义（附 JSON Schema），MIT License；David Soria Parra 与 Justin Spahr-Summers 联合创建。官方 Servers 聚合仓库（modelcontextprotocol/servers）已达 89K+ Stars，覆盖 Filesystem / Git / Memory / Slack / Google Drive / Sentry / Brave Search / Fetch 等场景。Claude Desktop 原生支持，Cursor / Windsurf / Zed / JetBrains 等主流 IDE 均有集成。

★ 快速选型决策树

需要什么语言的 SDK？

Python → python-sdk（最活跃）

TypeScript/JS → typescript-sdk

Go → go-sdk · C# → csharp-sdk

Java → java-sdk · C++ → cpp-sdk

需要什么类型的 Server？

文件系统 / Git 操作 → 官方 servers

记忆管理 → Memory Server

Slack / Google Drive → 官方 servers

搜索 / Fetch → Brave Search / Fetch

⚠ 边界与注意事项

MCP 是开放规范，非 Anthropic 独有——任何 LLM Provider 均可接入。

Stars 数据来自 GitHub API（2026-08-05），第三/社区 Server 数量无官方精确数字。
