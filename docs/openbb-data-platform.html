01它是什么 · 不是什么

统一入口

官方定位是 Open Data Platform：面向分析师、量化、数据工程师与 AI agent 的数据访问和分析层。

不是数据供应商

OpenBB 连接多类 provider；具体覆盖、授权、限流与价格取决于各数据源，平台不保证所有数据免费。

不是投资建议

它提供检索、转换与分析工具，不替你验证数据质量，也不对交易结果负责。

03从代码到工作台 · 四个接入面

Python SDK

安装包后通过 from openbb import obb 调用统一入口。

Workspace / Excel

面向研究与表格用户的工作台体验；不要把它误读成 provider 的数据授权。

MCP / REST API

给 AI agent 或服务端接入；API 进程可用 openbb-api / openbb-platform-api。

pip install openbb from openbb import obb # 扩展：pip install "openbb[all]" # 服务端：openbb-api / openbb-platform-api
04边界先看清 · 再接数据
关键成本不是 pip install。
不同 provider 可能要求独立 API key、注册、特定协议或付费订阅；免费层、商业使用权、历史数据深度、速率限制和再分发边界都要单独核对。OpenBB 是集成与分析平台，不承诺每个数据源免费可用。
层级你得到什么你仍要负责什么
OpenBB 平台统一 Python / API / 工作台入口版本兼容、部署与安全
Provider行情、宏观、新闻或文件数据key、协议、费用、限流、授权
你的研究流筛选、指标、量化或 agent 调用数据质量、回测偏差、投资判断
05适合谁 · 先做什么

分析师

先选 1–2 个 provider，验证字段、时间粒度和授权，再把研究动作固化。

量化 / 数据工程

先做 provider 对照与缓存策略，确认异常、限流、重试和数据血缘。

AI agent

先收窄 MCP / REST 工具面与权限，避免让 agent 直接触碰未审计的数据源。
