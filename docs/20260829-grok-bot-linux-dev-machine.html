🎯 一句话理解

Grok Bot 背后是一台真正的 Linux 云服务器——聊天框是遥控器，SSH + Tailscale 连上本地终端才是的正确用法，7×24 后台任务 + VS Code / Cursor 直接开发，体验接近本地虚拟机。

01 连接步骤
  • 1
    两端加入同一 Tailscale 私有网络
    本地安装 Tailscale 并登录账号，与 Grok Bot 服务器加入同一个私有网络，两条命令完成内网握手。
  • 2
    本地终端 SSH 直连
    用自己惯用的终端、VS Code 或 Cursor 直接 SSH 连上这台云主机，用户名为 box，文件统一存在 /workspace。
  • 3
    7×24 后台任务
    关掉网页、合上笔记本，云端依然在跑自动化爬虫、编译任务，不中断。
  • 4
    本地工作流集成
    scp 传文件、rsync 同步代码——不再需要笨拙地在网页聊天框里复制粘贴几十行代码。
02 三种玩法
  • 🖥️
    本地终端直接控制
    用 VS Code / Cursor 连接，像操作本地虚拟机一样丝滑。
  • ⚡
    7×24 后台冲刺
    网页关了、笔记本合上，自动化任务在云端持续运行不中断。
  • 📁
    本地工作流整合
    scp / rsync 无缝衔接，不再靠复制粘贴传递代码。

03 前提条件
  • 需要 Grok Bot 账号（Grok 订阅）
  • 本地安装 Tailscale 并登录
  • 两端（Tailscale 账号 + Grok Bot）在同一 Tailscale 网络下
  • 服务器用户名固定为 box，工作目录 /workspace
