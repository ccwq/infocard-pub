核心 The Core Idea · 核心思想
Apple Design 的核心：「当界面与我们思考和运动的方式对齐时， 它就不再感觉像一台电脑，而开始感觉像是我们身体的无缝延伸。」

流体界面 = 从屏幕当前值出发 + 继承用户速度 + 预测动量方向 + 任意时刻可抓取反转。 弹簧（Spring）是实现这一切的工具，因为弹簧天然具备可中断性和速度感知。

Apple 将设计定义为服务四个人类需求：安全感/可预测性 · 理解力 · 成就感 · 愉悦感。 以下每条原则都服务于其中之一。

01-08 Gestures & Motion · 手势与动效

① Response · 消除延迟

指针按下即响应，非释放后响应。按钮在按压瞬间高亮，拖拽内容跟随指针，pointerdown 触发视觉反馈。延迟出现时，直接感瞬间崩塌。

② Direct Manipulation · 直接操控

1:1 指针追踪：拖动内容与手指/鼠标位置完全对齐，无延迟、无吸附感。松开后才触发动作动画。

③ Interruptibility · 可中断性

最重要的原则。动画在任意时刻可被手势中断并反向执行。弹簧天然支持。避免使用 transition（不可中断），用弹簧替代。

④ Behavior over Animation · 行为优先

用弹簧而非 ease-in-out 缓动。弹簧天然具备可中断性和速度感知，ease-in-out 则是固定曲线，无法感知手势速度。

⑤ Velocity Handoff · 速度交接

拖拽松开时，将手势速度「交接」给弹簧动画。测量释放瞬间的指针速度，作为弹簧初始条件，让动画方向和幅度与手势意图一致。

⑥ Momentum Projection · 动量预测

动画到手势「即将到达」的位置，而非当前松手位置。通过速度矢量预测终点，让界面「预判」用户意图。

⑦ Spatial Consistency · 空间一致性

元素移动路径对称，动画起点与物理原点对齐。拖出再弹回的元素应回到原位，保持空间参照物稳定。

⑧ Directional Hints · 手势方向暗示

界面元素暗示手势方向：分页指示器、弹性回弹方向、内容露出方向，让用户「读懂」可交互方向。

09-14 Feel & Material · 手感与材质

⑨ Rubber-banding · 弹性边界

拖到边界时施加反向弹性阻力，松开后弹回。弹性系数随拖拽距离增大而增大，产生「受阻但可继续」的物理感。常见于下拉刷新、边缘滑动。

⑩ Gesture Feel Checklist · 手感检查清单

按压 → 跟随 → 吸附 → 弹性 → 动量，完整链路自检。确保每步响应时间 <16ms（60fps），手感清单见 Skill 原文。

⑪ Frame-level Smoothness · 帧级流畅

60fps 最低要求，优先使用 transform/opacity 实现动画。JS 动画用 requestAnimationFrame，避免 setTimeout / setInterval 造成的帧抖动。

⑫ Materials & Depth · 材质与深度

半透明材质传达层级关系。毛玻璃、阴影、模糊叠加创造「浮层感」，区分前景内容与背景容器，符合人类对物理深度的直觉。

⑬ Multimodal Feedback · 多模态反馈

动效 + 音效 + 触觉反馈（Haptics）协同。视觉运动时配合短促音效或触觉轻震，强化「操作成功」的感知确认。

⑭ Reduced Motion · 无障碍动效

尊重 prefers-reduced-motion 媒体查询：减少/禁用非必要动画，提供等效静态替代。服务前庭功能障碍用户，是基本无障碍要求。

15-17 Typography & Foundations · 排版与基础

⑮ Typography · 排版光学

光学尺寸（Optical Sizing）：小字号使用较粗笔画和较大间距，大字号使用较细笔画和较紧间距。font-optical-sizing: auto 自适应调整。

⑯ 8 Design Foundations · 8 条设计基础原则

反馈（Feedback）、空间一致性（Spatial Consistency）、循证美学（Evidence-based aesthetics）、清晰度（Clarity）、层次（Depth as metaphor）、意图（Intent）、比例（Proportion）、一致性（Consistency）——Apple Human Interface Guidelines 的底层逻辑。

⑰ Process · 设计流程

从用户目标出发，而非从视觉效果出发。设计服务于：安全感/可预测性（Safety）、理解力（Understanding）、成就感（Achievement）、愉悦感（Joy）。每次加动效前先问：它服务哪个需求？

💡 Spring vs Transition · 弹簧 vs 过渡 
/* ❌ 错误：ease-in-out 无法感知手势速度，不可中断 */
transition: transform 300ms ease-in-out;

/* ✅ 正确：弹簧天然可中断、速度感知、任意时刻可抓取 */
/* Motion / Framer Motion 示例 */
const spring: { type: "spring", stiffness: 300, damping: 30, mass: 1 };

/* velocity 交接：拖拽释放时将速度传给弹簧 */
onPointerUp: (e) => {
  const velocity = getPointerVelocity(e); // 释放瞬间速度
  animate(element, { x: predictedTarget }, { ...spring, velocity });
}

/* prefers-reduced-motion：无障碍降级 */
@media (prefers-reduced-motion: reduce) {
  * { transition-duration: 0.01ms !important; animation-duration: 0.01ms !important; }
}
