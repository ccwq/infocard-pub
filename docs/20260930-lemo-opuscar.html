PIPELINE 管线

PIPELINE 管线五轨并行 · 页面即函数
画面 = render(t)

每支片是一个暴露契约的 index.html：window.DUR 总时长、window.render(t) 确定性画帧、READY 资源就绪、EV 声音事件、TEXTS(t) 供 readcheck 用的可见文本。headless Chrome 逐帧截 JPEG，video.mjs 以 --workers 3 并行出 video.mp4。确定性三禁：禁 Date.now()、禁无种子随机（lib.js 提供 mulberry/hash）、禁跨帧状态。

CANVAS 2DTHREE r170WEBGL2
配音双引擎 + 逐句校验

英文走 Kokoro（本地离线、多音色，af_/am_ 美音 bf_/bm_ 英音）；中文走 edge-tts 的微软神经音色（晓晓/云希等），效果更好但必须联网。tts.py/tts_zh.py 逐句出 WAV 与时长表；asr_check.py 用 faster-whisper 把每句转写回来与脚本比对，--lang zh 按字比对，不一致就重生成直到 exit 0，同时产出 word timings 给字幕对轴。

KOKORO 离线edge-tts 需联网
配乐：采样器 + 物理建模

sampler.py 播放免费采样库里的真乐器（VSCO 2 CE、VCSL、FreePats、Karoryfer、Salamander 钢琴），配乐写成事件序列 (时间,乐器,音高,时值,力度,声像)；古琴/琵琶/三味线/班卓这类拨弦走 pluck.py 的 Karplus–Strong 物理建模；芯片音乐与 drone 用 numpy 合成、零下载。低频纪律：20–120 Hz 压到其余频段 −3 dB，pad 不低于 MIDI 48。

CC 采样库KS-STRING
拟音与混音

sfx.py 程序化合成拟音（点击、whoosh、闷响、纸张、雨噪底），由 window.EV 驱动，声音精确落在帧上。mux.sh 收尾：ffmpeg 两遍 loudnorm 到 −14 LUFS + 真峰值限制 + 颗粒（浅底少加，像素/矢量风不加），失败即非零退出。配音先压缩再平衡，人声高于音乐约 10 dB。

FOLEY-ON-EV2-PASS NORM
一条 timeline 驱动一切

段落、速度、节拍、剪辑点写进同一个 timeline.js（SECS/HIT 导出），配乐、混音、字幕、检查脚本读同一组数字；多支 demo 自带 cuecheck.py，把每个视觉 hit 与音乐 cue 对表，目标 0 ms。字幕用 srt.py 导出 .srt，同时把带样式的字幕烧进页面——字幕设计本身就是风格的一部分。

SINGLE-SOURCECUE=0ms
为什么逐帧截屏快

TECHNIQUE.md 点名三件事：JPEG 截屏（不是 PNG）、每个 worker 独享一个浏览器、胶片颗粒放在 ffmpeg 里加而不是画进页面（画进页面会让每帧都不可压缩）。3D 走 three.js r170 + WebGL2，物理景深与 GTAO 以 2× 渲染再降采样；正交相机要手动换深度pass函数，否则景深静默失效。

REVIEW 验收

REVIEW 验收机器四查 + 人眼一遍
contact sheet 两遍起步

still.mjs --range 每 1–2 秒抽一帧，sheet.py 拼成总览表，至少完整过两遍；关键动作（交接、跌倒、碰撞）再出 0.2 秒间隔的帧条逐格看。这是照搬自专业动画的 dailies 习惯，用来抓「单帧都对、连起来不对」的动作断裂。

DAILIES×20.2s STRIPS
成片上的三条硬检查

ffmpeg ebur128 复测响度（要 −14 LUFS）；blackdetect 抓黑场空白帧；有配音的成片再用 whisper 转写一遍确认语音与脚本一致。最后一步不可省：完整速度、开着声音、像观众一样看一遍。readcheck.mjs 另外在渲染期就保证每条字幕停留 ≥1.8 秒且不短于朗读时长 +0.6 秒。
