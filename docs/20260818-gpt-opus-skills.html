/grill-me
研究追问 · 需求澄清
在动手前先向用户连珠炮式追问，把需求里的模糊地带全部暴露。把"差不多"变成"清楚明白"。
research
🎨
/taste-review
设计评审 · 品味校准
用明确的品味标准审视设计输出，确保风格、调性、细节都符合预期，而不是只做形式检查。
design
⚛️
/vercel-react-best-practices
React 质量 · Vercel 规范
引入 Vercel 的 React 最佳实践，检查组件模式、性能模式、可访问性和代码组织是否达标。
frontend
✂️
/simplify
内容精简 · 去除冗余
把车轱辘话和无效修饰全部删掉，只保留对读者有实际价值的内容，让输出更干净更有力。
writing
✅
/test-app
端到端验证 · E2E 测试
运行完整的端到端测试，验证应用在真实环境中是否按预期运行，确保功能不被"表面完成"。
testing
