01
WHAT IS IT

从 URL 到完整设计系统

designlang 用 headless Chromium 访问任意 URL，逐元素读取 computed style，在本地生成完整的 W3C DTCG Token 体系，覆盖所有主流前端与设计工具格式。

核心

读 Live DOM，非截图

直接读取浏览器渲染后的 computed style，不依赖截图、PDF 或设计文件，确保提取结果与视觉效果完全一致。

  • CSS 变量、CSSOM computed value
  • hover / focus / active 状态
  • 4 断点响应式分析
DTCG Token

W3C DTCG 三层架构

输出完整的 DTCG Design Token 层级：primitive（原始值）、semantic（语义标签）、composite（组合别名）。

  • primitive.json / semantic.json / composite.json
  • 与 Figma Variables / Style Dictionary 兼容
  • --tokens-legacy 回退旧版 flat 格式
免费

无 API Key，MIT 许可

无需注册、无需 Key、无速率限制。所有生成物归你所有，可商用、可修改、可 fork。

  • MIT License
  • npm install -g designlang
  • npx designlang <url> 免安装

03
CLI COMMANDS

grade · battle · remix · clone · mcp

除默认提取外，designlang 提供丰富的设计分析与转换命令，覆盖评分、对比、重设计、代码生成、Token 监控等全流程。

grade

生成可分享的 HTML Design Report Card（--format html|md|json|svg|all --badge --open）

battle

双 URL 头对头评分对比（--format html|md|json|all --open）

remix

6 种风格重设计（--as brutalist|swiss|art-deco|cyberpunk|soft-ui|editorial --all --list --open）

clone

从提取结果生成可运行的 Next.js 启动器，一键启动完整项目。

pack

打包所有输出为完整 design-system 目录（--with-clone --open）

score

7 维度 A-F 评分 + 柱状图（品牌、可访问性、一致性、对比度、响应式、排版、运动）

watch

定时监控设计变化，检测 Token 漂移。

visual-diff

两 URL 视觉对比 HTML diff（v9 新增）。

theme-swap

围绕新品牌主色重新配色（--from --format html|md|json|tokens|all --open）

brand

生成完整品牌指南全书，13 章节（--format html|md|json|all --open）

lint

审计本地 Token 文件（.json/.css），CI 就绪（v9）。

fidelity

克隆站 vs 原站像素差异 + 运动保真度评分（--min --motion-runtime）。

启动 stdio MCP 服务器，向 Cursor / Claude Code / Windsurf 等 AI 编程工具暴露 Token、Region、Components、Contrast Pairs 等 MCP 工具与资源。

05
DIFFERENTIATION

竞品对比：为什么 designlang

现有方案多为截图识别或单一格式导出。designlang 在方法论、覆盖度、开放性三个维度全面领先。

读 live DOM vs 截图识别：designlang 读取 computed style，不依赖视觉 AI 识别，精度更高、结果更确定、无 GPU 依赖。
全量 DTCG Token 层级：primitive → semantic → composite 完整链路，其他工具通常只输出 flat token。
多平台同时 emit：iOS SwiftUI、Android Compose、Flutter、WordPress 一条命令全部生成，无需分平台多次运行。
Claude Code 插件 + MCP Server：不是单纯的提取工具，而是 AI 编程工作流的设计系统基础设施，40+ agent 支持。
