先说结论

官方可核的是“35B 总参数、每 token 激活 3B、MoE、支持多模态与 Agentic Coding”。

“越狱版”更像社区衍生命名，不应直接当作官方模型名称。

风险提醒

不要把“6G 显存可跑”理解成固定真相；它通常依赖极端量化、CPU offload 和更高内存预算。

图示强调的是证据分层：官方开源权重、社区本地部署、以及“越狱版”这类标题包装是三件不同的事。
01核心判断
Qwen3.6-35B-A3B 值得关注，不是因为“越狱”两个字，而是它把 35B 的总参数压缩成 3B 激活，公开资料里又同时具备 Agentic Coding、长上下文和多模态能力。
02官方线 vs 社区线

官方线

阿里通义实验室开源，公开新闻与转载一致指向 MoE、35B/3B、智能体编程、多模态。

社区线

本地部署教程、量化包、Unsloth / GGUF / llama.cpp 文章把它扩展成“能跑、好跑、低门槛”的本地模型。

标题线

“越狱版 / uncensored / aggressive”更像传播标题，不能直接等同于官方发布名。
