psmux/pmux/tmux三命令同义
真正的原生 Windows tmux — 不依赖 WSL，不使用 Cygwin/MSYS2，直接调用 Windows ConPTY，用 Rust 重写完整 tmux 语义。

psmux 从零构建，读取你的 .tmux.conf、支持 tmux themes、83 条命令、140+ 格式变量、53 个 vim copy-mode 键位。PowerShell 7+ / cmd.exe 即开即用。可与 Claude Code agent teams 无缝集成，teammate 自动分配到独立 tmux pane。

06 vs 传统 tmux · Windows 原生 vs WSL/WSL2
维度 ★ psmux
Windows 原生		 WSL 下的 tmux WSL2 下的 tmux
终端层 Windows ConPTY 原生 WSL ptty（转发层） WSL2 Hyper-V VM
依赖要求 无需 WSL ✓ 需安装 WSL 需安装 WSL2 + Hyper-V
PowerShell 集成 原生集成 ✓ 跨系统调用，性能损耗 VM 网络转发，延迟更高
鼠标支持 ConPTY 直连，完整支持 SSH 转发，鼠标受限 部分支持，延迟明显
启动速度 毫秒级 ✓ WSL 冷启动 1–3 秒 WSL2 冷启动 2–5 秒
内存占用 Rust ~10 MB WSL 底层 ~50 MB+ WSL2 VM ~200 MB+
tmux.conf 直接读取 ✓ 需 WSL 路径 需 WSL 路径
Claude Code agent teams 无缝集成 ✓ agent teams 需额外配置 agent teams 需额外配置

08 快速上手

基本命令

psmux # 启动新 session
psmux new -s work # 命名 session
psmux ls # 列出 session
psmux attach -t work # 附加 session
psmux --help # 显示帮助

常用快捷键（C-b）

C-b c # 新建窗口
C-b " # 水平分 pane
C-b % # 垂直分 pane
C-b z # pane 全屏
C-b d # 脱离 session
