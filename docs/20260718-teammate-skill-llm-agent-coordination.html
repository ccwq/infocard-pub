02
问题：隐性知识随人员离开而流失
Problem: Tribal Knowledge Walks Out
痛点场景
  • 资深工程师离职 — 没有交接文档、没有运行手册，只剩沉默
  • 远程同事跨时区协作 — 想询问意见但不想打断其工作流
  • 共创者转向新方向 — 带走了每一个未写下来的决策逻辑
  • 新成员 onboarding — 面对代码库但不理解背后的设计原则
teammate.skill 的解题思路
  • 将历史 Slack / GitHub / 邮件 / 文档作为输入材料
  • AI 分析工作风格与技术标准（双轨分析）
  • 生成可版本化、可纠正、可导出的 Agent Skill
  • 用 /{slug} 随时调用 — 不打扰同事，不丢失上下文
03
双轨建模：工作能力 + 五层人格
Dual-Track Model / Work Skill + 5-Layer Persona
Track A — Work Skill

覆盖队友负责的系统与技术栈、代码审查标准、工作流与隐性知识。

  • 系统与架构熟悉度
  • 代码风格与评审重点
  • 工作流与决策习惯
  • Tribal knowledge
Track B — 5层 Persona

将人格特质逐层建模：

  • L1 硬规则 / 底线要求
  • L2 身份认同 / 角色感
  • L3 表达方式 / 语气偏好
  • L4 决策模式 / 判断框架
  • L5 人际风格 / 协作方式
调用时组合

README 描述的调用顺序：

1Persona 决定语气与态度
->
2Work Skill 执行任务
->
3以该队友声音输出

注：「像本人」为项目方描述，非独立验证结论

安装与调用：从零依赖开始
Usage / Install, Create, Invoke

Claude Code：

git clone <repo> .claude/skills/create-teammate
# 或全局：~/.claude/skills/create-teammate
依赖（可选）
# 自动采集器可选依赖
pip3 install -r requirements.txt
# 当前 requirements.txt 仅声明：slack_sdk>=3.0
# 基础 Skill 本身无需任何依赖
斜杠命令速查
/create-teammate [name]创建新队友 Skill
/list-teammates列出所有已创建队友
/{slug}以完整 Persona + Work 调用
/{slug}-work仅 Work Skill 能力
/{slug}-persona仅 Persona 人格
/compare {a} vs {b}10维度对比 + 场景模拟
/export-teammate {slug}导出为 .tar.gz 便携包
/update-teammate {slug}追加新材料
/teammate-rollback {slug} vN回滚到指定版本
/delete-teammate {slug}删除队友 Skill

边界：可验证的生成流程，不等于真实人格复制
Boundary / Workflow vs. Marketing Promise
可核实的事实
  • 仓库确实提供 SKILL.md 入口、双轨提示词、数据源采集/解析脚本
  • 10种数据源接入（Slack/GitHub/Gmail/Teams等）
  • 提供版本管理、回滚、导出与隐私扫描工具
  • README 明确写出命令与用法
  • knowledge/ 目录默认不随 git 和导出包包含
需归因于项目方的表述
  • 「AI Skill that actually works like them」— 项目方能力主张，无独立验证
  • 「Writes code in their style / Reviews PRs with their standards」— 项目方描述
  • 「3/3 passed」质量示例 — 流程设计示例，非实证通过率
  • 「自动检测并修复 PII」— 项目方描述，privacy_guard.py 仅有限正则规则
  • MyClaw.ai「one-click deploy / always-on」— 第三方托管描述
使用边界（research-b 识别）

隐私与授权

  • 采集 Slack/GitHub/邮件需资料主体与组织授权
  • Token 应遵循最小权限原则
  • 真实数据不得出现在公开信息卡中

导出与分享

  • 使用 --include-knowledge 可能包含 PII
  • 导出前应先用 privacy_guard.py 扫描
  • 建议人工复核后再分享
08
结论：把交接材料转成可演化的工作模型
Conclusion / A Versioned Working Model
teammate.skill 的可核实价值
  • 用标准 Agent Skill 格式和提示词模板整理多源工作材料
  • 生成 Work Skill + Persona 两类可调用产物
  • 提供调用、对比、更新、版本回滚、隐私扫描和导出的完整工具链
  • 无需 Token 即可用 JSON/文件方式使用基础功能
  • 跨 OpenClaw / Claude Code / AgentSkills 平台
适用范围与局限性
  • 适合：知识提炼、决策模拟、代码风格学习、远程协作辅助
  • 不适合：对离职同事意识、记忆或判断力的等价替代
  • 质量取决于材料覆盖度、解析结果与后续人工纠正
  • 生成的 Skill 是工作流工具，不是人格复制品
一句话定位

把交接材料转成可演化的工作模型 — 用 Agent Skill 格式保存技术标准、沟通风格与决策逻辑，随时通过斜杠命令调用。
