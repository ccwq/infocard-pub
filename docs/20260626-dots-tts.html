一句话结论

dots.tts 把音色复刻的门槛压到了"几秒录音"：上传少量音频，即可生成保留音色特征的跨语言TTS语音，还能把原说话人的情绪风格一并迁移过去——不只是翻译，连撒娇、伤心这类语气也会一起搬过去。技术路线是全连续自回归（非离散token），在Seed-TTS-Eval和MiniMax 24语言基准上均达到开源SOTA。

核心能力

3秒音色复刻

仅需几秒录音即可提取说话人音色特征，无需长音频或额外注册流程。

跨语言情绪迁移

支持英/法/韩等多语言朗读，同时把原音频中的撒娇、伤心等情绪风格一起迁移过去。

全连续自回归架构

2B参数骨干，配语义编码器+LLM+自回归Flow-Matching声学头，全程48kHz，无离散token。

开源SOTA

Seed-TTS-Eval平均性能最佳；MiniMax 24语言基准speaker相似度83.9，开源最高。

本地部署

整合包含MF版模型，无需额外下载权重，8GB显存可跑。

商用友好

Apache 2.0许可证，个人和商业使用均无限制。
