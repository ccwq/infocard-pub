# oh-my-pi / omp 信息卡报告

## 来源
- X 帖：`https://x.com/sitinme/status/2061054344402030907`
- GitHub 仓库：`https://github.com/can1357/oh-my-pi`
- 官网：`https://omp.sh`

## 关键事实
- 这是一个面向终端的 AI 编程代理，不是单纯聊天壳。
- README 明确写出：`A coding agent with the IDE wired in.`
- 公开材料强调的能力包括：
  - 40+ 模型/服务商
  - 32 个内置工具
  - 13 项 LSP 操作
  - 27 项 DAP 操作
  - 代码执行、网页/PR/issue/PDF 读取、搜索、子 Agent
  - Windows 支持
  - 可继承 Cursor / Cline / Codex / Claude / Windsurf 等规则配置

## 原帖主张
原帖的核心判断是：
- 它不是又套一层 ChatGPT
- 更像把终端、IDE、调试器、浏览器、搜索、子任务 Agent 装进一个命令行
- 重点在于把 AI 编程从“对话”升级到“工作台”

## 适合发布的卡片结论
- 它的价值不在单个模型，而在完整操作面。
- 它适合做本地 AI 编程代理、CLI/IDE 集成、调试器联动、并行子任务的参考实现。
- 如果只需要聊天，不需要工具链，这个项目会显得过重。
