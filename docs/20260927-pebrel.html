🚀 5 步安装与配置

初学者

1安装字体（必须）

AI 品牌标识、程序图标和 Powerline 提示符依赖 Maple Mono Normal NF CN（Nerd Font，含 CJK）。字体在安装包内的 fonts/ 目录。

# Windows: fonts/MapleMonoNormal-NF-CN-Regular.ttf # 双击安装，或双击后按"安装"按钮 # 安装后重启 Pebrel，图标才完整显示

2下载安装包

从 GitHub Releases 下载对应平台的包。Windows 提供 Installer（.exe）和 Portable（.zip 便携版）。macOS/Linux 为 Preview 测试版。

# GitHub Releases: # https://github.com/Kuddev/pebrel/releases/latest # 或访问 https://github.com/Kuddev/nebula/releases（历史版本）

3Windows 启动注意

首次运行可能触发 SmartScreen（未签名）。点击"更多信息"→"仍要运行"。macOS 若提示"无法验证开发者"，需在"系统设置 → 隐私与安全性"中点击"仍要打开"。

# Windows 便携版：解压后保持目录结构完整 # runtime/ 包含 AI 通知和 ConPTY 辅助组件 # 不要单独移动 pebrel.exe

4初始化 Lua 配置

Pebrel 内置 Lua 5.4 运行时，支持热重载。初始化后会在配置目录生成带注释的模板。

pebrel config init --language zh-CN pebrel config check # 无 GUI 语法检查

5启用 AI Hook（Windows）

Windows 版首次启动自动安装 Claude Code / Codex Hook。配置切换器重写文件时会自动重新安装（监控配置目录）。

# 手动移除 Hook（不常用） nebula setup-ai --remove # 验证 Hook 是否激活 # 启动 Claude Code，观察 Pebrel 标签页图标是否为 Anthropic 星标

🔐 会话持久化详解

核心能力

窗口关闭 = 分离，非终止

关闭 Pebrel 窗口时，所有 PTY（Claude Code、代码编译、SSH 会话）保持在常驻 mux 进程中。再次打开 Pebrel，窗口重新 attach——进程状态、滚动历史、对话进度全部保留。

冷启动恢复

若常驻进程被系统终止（重启 / 崩溃），下次启动仍可从自动快照恢复标签页布局和每个标签的工作目录。内置崩溃循环检测，防止反复重启。

单实例模式

第二次启动 Pebrel 会自动将窗口 bring to front，而不是新建窗口。可与常驻模式独立使用：即使设为非后台运行，多次点击图标也只激活已有窗口。

工作区布局保存

可保存多套工作区布局（含标签页顺序、分屏结构、每个面板的 cwd）。AI 对话恢复功能需要 CLI 支持 session identity（Claude Code / Codex 支持）。

🔗 SSH / SFTP 完整能力

远程工作区

SSH 认证方式

支持私钥、加密密钥密码短语、Windows Credential Manager 存储的密码、keyboard-interactive（含 MFA）。主机密钥验证走标准 known_hosts。同一主机二次开标签复用已有连接。

SSH Config 兼容

主机别名、用户名、端口和私钥路径均从 ~/.ssh/config 读取。支持 ProxyJump（跳板机）和 ProxyCommand。

# ~/.ssh/config 示例 Host dev-server HostName your-server.example.com User your-user Port 22 IdentityFile ~/.ssh/id_ed25519 ProxyJump bastion

SFTP 传输

从任何已保存的 SSH 主机打开远程文件抽屉，复用已有认证连接。功能：浏览 / 上传 / 下载 / 文件夹传输 / 创建 / 重命名 / 递归删除 / 传输进度和取消。

WSL 特殊支持

WSL 和 SSH 标签页复制时保留当前工作目录。WSL 远程 Hook 可通过私有 OSC 桥接回本地侧边栏和通知系统。

🤖 AI CLI 工作流详解

Claude + Codex

真实品牌标识

运行 Claude Code 时侧边栏显示 Anthropic 星标，运行 Codex 显示 OpenAI 花标，并跟随主题色调变化。其他程序显示 Nerd Font 图标（gemini / copilot / git / vim / cargo 等）。

实时状态信号

Claude Code Hook 事件精确控制状态：提示词提交→旋转动画；回复完成→圆点+通知；等待输入→通知携带消息内容。Codex 通过 notify 的 --chain 模式接入。

Claude 回复阅读器

捕获的 Claude Code / Codex 回复自动在 Markdown 阅读器中打开，支持 Markdown 语法、LaTeX 公式、源码高亮和本地图片预览。

剪贴板图片处理

复制到剪贴板的图片自动保存为 PNG 文件，本地 / WSL / SSH 会话均适用。行内终端图片依赖 CLI 支持 OSC 1337 协议。

Hook 自愈机制

Hook 首次启动自动安装。若配置切换器重写了 settings.json，目录监控器会自动重新安装对应 Hook。按环境隔离：其他终端中的 Claude Code 不受影响。

通知时长配置

通知时长可在设置中精细控制：默认 / 5 秒 / 10 秒 / 30 秒 / 90 秒 / 手动关闭。默认行为：短通知 5 秒，消息横幅 90 秒，更新提示手动关闭。

📄 Markdown + LaTeX 阅读器

文档能力

支持文件格式

原生打开 Markdown（.md）、JSON 和纯文本文件。支持 GFM（GitHub Flavored Markdown）：表格、任务列表、代码块、链接、引用。

图片来源

支持远程 http(s) URL、data: URI、绝对路径，以及相对文档自身位置的相对路径。README 常见的徽章行、logo、内嵌截图均可正确渲染。

中文软换行

按 CommonMark 规范处理软换行（相邻换行合并为空格），但相邻 CJK 字符直接相连，中文段落不会出现其他阅读器常见的缝隙。

原生 LaTeX 公式

行内 $...$ 和块级 $$...$$ 公式全部由 Rust 解析和布局，使用 Latin Modern Math 字形通过 GPU 绘制，无需 WebView、JavaScript 或外部 TeX 进程。

行内公式：$E = mc^2$ 块级公式： $$ \int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi} $$

🖥 Shell 体验增强

开箱即用

Ghost-Text 补全

fish-shell 风格的 dim 提示，显示命令历史和文件系统路径补全建议。按 → 或 Tab 接受。

持久化历史

命令历史以 JSONL 格式存储在 %APPDATA%\Pebrel（Windows），跨会话共享，含前缀提示。

Powerline 提示符

内置渐变色 Powerline 提示符，显示 Git 分支和时钟。支持 PowerShell 和 Git Bash，无需安装插件。

路径处理

未加引号的 cd D:/Program Files 自动处理。环境变量赋值自动加引号。ls 显示颜色和可点击的 OSC 8 超链接。

❓ 常见问题与解决

排障指南
首次运行界面图标显示异常？
请先安装随附字体 Maple Mono Normal NF CN（双击 fonts/ 目录下的 .ttf 文件安装），重启 Pebrel 后图标完整显示。若字体已安装仍有问题，检查系统字体目录权限。
Claude Code Hook 没有激活？
确认 Windows 版 Pebrel 正在运行（macOS/Linux 尚不支持 Hook）。在 Pebrel 中启动 Claude Code，观察标签页是否显示 Anthropic 星标。若未显示，手动运行 nebula setup-ai --remove 再重启 Pebrel。
macOS 提示"无法验证开发者"无法打开？
前往"系统设置 → 隐私与安全性"，滚动到底部点击"仍要打开"。这是 ad-hoc 签名包的正常安全提示，非恶意软件警告。
通知一直不消失？
在设置中修改通知时长：默认 / 5s / 10s / 30s / 90s / 手动关闭。注意区分 Pebrel 通知和系统通知——系统通知不受 Pebrel 设置控制。
LaTeX 公式渲染失败？
公式解析有明确上限（宽公式自动收缩到阅读列宽度，解析失败时显示原文）。确认公式语法正确（$...$ 行内 / $$...$$ 块级）。不支持的符号会降级显示为原始文本。
Lua 配置热重载不生效？
确保配置文件中包含 require 'pebrel' 和 pebrel.config_builder()。通过 require 加载的模块才参与热重载；直接编辑 TOML 文件需重启。语法错误时保持上一份有效配置不中断。
