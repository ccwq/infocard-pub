QACMAN：把文字变成可玩的 QR 迷宫

QACMAN 不是普通二维码生成器：它把输入文字编码成一个可扫码的迷宫，同时让你在迷宫里玩 Pac-Man 风格的吃点游戏。生成、试玩、截图、录制，再把当前迷宫嵌入自己的网页。

01 / HOW IT WORKS

它把二维码和游戏地图放在同一个结构里

文字是入口

页面说明迷宫由输入文字生成。文字不是装饰，而是二维码编码后的数据来源；改变输入，应该重新生成并重新测试。

模块是地图

二维码由许多黑白模块组成。游戏路径会在这些模块中被精心“挖”出来，让玩家可以移动，同时尽量保留扫码所需结构。

纠错是缓冲

页面标注使用 Level-H error correction。通俗说，它给部分受损或被遮挡的数据留出恢复空间，但不是任何破坏都能修复。

重要：“可玩”不等于“永远可扫”。输入长度、路径复杂度、屏幕亮度、缩放、拍摄角度和遮挡都会影响实际识别。

03 / SCAN TEST

怎样做一次可靠的扫码验收

1. 输入短文本并生成迷宫 2. 在当前屏幕暂停，确保二维码完整显示 3. 调整亮度，避免反光和浏览器 UI 遮挡 4. 用另一台设备扫描，不要只用生成页面自己的预览 5. 记录：能否识别、识别出的文本是否完整、需要几次尝试 6. 再逐步增加文本长度，找出你的实际可用边界
通过：识别成功且文本完整。
观察：需要调整距离、亮度或角度才能识别。
失败：多次尝试仍不能识别；缩短文本或换设备再定位原因。
04 / EMBED

把当前迷宫放进自己的网页

01 · 生成先在 QACMAN 中生成你想展示的迷宫，并确认游戏与扫码都正常。
02 · Embed This Game打开页面的嵌入区域，查看当前迷宫的分享方式。
03 · Preview用 Preview 检查嵌入效果，确认尺寸、控制和移动端表现。
04 · Copy Code使用 Copy Code 获取嵌入代码，再放进你有权限修改的网站。
发布前：重新从嵌入页面扫码一次；不要默认嵌入代码会永久有效，也不要把未知来源脚本直接放进高敏感站点。
05 / USE CASES

它适合做什么，不适合做什么

活动互动

把活动口号、彩蛋或短提示做成可玩的扫码入口，适合现场屏幕和社交分享。

作品展示

把一个短文本变成互动 Demo，让作品集不止展示截图，还能让访客实际操作。

课堂实验

用于解释二维码模块、纠错和数据编码之间的关系，再通过实测观察遮挡和识别边界。

不适合

不应把它当作高可靠支付码、身份凭证、生产级票据或没有实测就承诺“任何手机可扫”的二维码服务。

内容边界

不要输入密码、API key、个人隐私或不应公开的内部信息；二维码会把输入内容带入分享和展示流程。

版权边界

页面使用 Pac-Man 风格玩法表达创意；商业发布前应自行检查品牌、角色、素材与嵌入页面的授权边界。
