什么是 Autoresearch Karpathy 2015 原型
Modify

Agent 修改一个实验脚本（train.py / config.py / design.py）。

Verify

运行固定预算实验，从 stdout、指标、渲染图中读取结果。

Keep / Discard

保留胜出方案，回退失败改动，继续下一轮循环。

Repeat

迭代累积，探索空间越来越大，质量持续提升。

Autoresearch 闭环生命周期
modify → verify → keep / discard → repeat
M
Modify

改一个核心文件（train.py / design.py / config.py），只改一处。

V
Verify

运行固定预算实验，从 stdout / 指标 / 渲染图读取结果。

K
Keep / Discard

指标胜出则保留，失败则回退，不做主观评价。

R
Repeat

继续下一轮，探索空间逐步扩大，质量随迭代累积。
