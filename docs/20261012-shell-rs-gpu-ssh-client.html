ShellRS — Rust/GPUI 跨平台 SSH 客户端

since2006/shell-rs · 244★ · GPL-3.0 · Rust · v0.1.9 · 2026-10-12

一句话定义

Rust 编写、GPU 全渲染的原生跨平台 SSH 客户端，将 Xshell 主机管理、标签终端、WinSCP 双栏 SFTP、端口转发 整合进一个窗口，采用 Zed 编辑器同款的 GPUI 渲染框架，全程无需 Electron。

Rust GPUI 渲染 非 Electron Xshell 主机管理 WinSCP 双栏 SFTP 端口转发 AI Agent CLI 免费开源 GPL-3.0
解决了什么问题
痛点macOS 无 Xshell
痛点Electron 卡顿
痛点WinSCP 无替代
痛点堡垒机难对接
  • macOS/Linux 用户长期没有能对标 Xshell 的主机管理 + 标签终端组合工具，Termius 功能完整度不足。
  • Electron 类终端应用内存占用高（一个实例常占 300MB+）、启动慢（3-5秒）、字体渲染在 HiDPI 屏幕发虚。
  • WinSCP 的双栏 Commander 布局是运维工程师的行业标准，跨平台场景下无可替代产品。
  • 堡垒机（JumpServer 等）场景下，需要 ssh:// / sftp:// 协议深度集成，Xshell 的 -url / -newtab 参数在非 Windows 平台无法使用。
  • Claude Code、Codex 等 AI Agent执行远程命令时需要明文密码或私钥文件，存在凭据泄露风险。
  • 端口转发场景下，大多数客户端只有文本配置，没有可视化拓扑图，无法直观看到本地端口→跳板机→目标主机的流向。

五大核心功能

1. 主机管理（Xshell 风格）

分组任意嵌套、支持搜索与拖拽整理。连上后自动识别远程系统（Linux/Debian/Ubuntu/CentOS 等）并显示徽章。支持多级 SSH 跳板链，HTTP/SOCKS5 代理。兼容 ssh:// / sftp:// 链接直接呼出 ShellRS，可配置为 Xshell/WinSCP URL 处理程序的替代品。

2. 标签终端

多标签，标签可拖成左右/上下分屏。标签栏实时显示连接延迟（毫秒级 Ping 值）。支持选中复制、右键菜单打开外部 CLI。终端、SFTP、端口转发三个视图可并排显示。

3. SFTP 双栏（WinSCP 风格）

Commander 双栏布局，沿用 WinSCP 列、路径标签、书签、快捷键（F5/F2/F7/F8…）。栏间高亮多选拖动。传输进行中可继续发起新任务。断线自动重连（1s→3s→10s 递进），重启后可恢复断点。内置编辑器：双击远程文件直接改，图片和 Markdown 可预览。

4. 端口转发

支持本地（-L）、远程（-R）、动态（-D，SOCKS5/SOCKS4）三种模式。每条转发配有实时连线示意图 + 入口/出口说明文字。独立 SSH 连接，断线自动重连（最多3次）。可设为随 ShellRS 启动自动开启。

5. 右侧栏工具（仅 Linux 主机）

系统监控（CPU/内存/磁盘）、进程列表、systemd 服务管理、Docker 容器状态、网络连接（ss/netstat）。读取和操作走当前终端的 SSH 连接，无需再次输入凭据，也不产生额外 SSH 会话。

三种登录凭证方式

密码 输入密码，存系统钥匙串
无密码 走 SSH Agent → 默认密钥
保存凭据 凭据存钥匙串，本地无明文

SFTP 断点续传机制

断线后自动重连序列：1 秒 → 3 秒 → 10 秒，三次重试失败后停止。下次连接时 ShellRS 从断点位置继续传输，不从头开始。传输队列允许在已有传输进行中继续发起新任务，无需等待。

端口转发三种模式

-L 本地转发 本机端口 → 跳板 → 目标主机端口
-R 远程转发 远端端口 → 跳板 → 本机端口（反向）
-D 动态转发 本地 SOCKS5/SOCKS4 代理，灵活路由

GPU 全渲染终端也走 GPU，非 Electron

GPUI（GPU Interactive）是 Zed 编辑器使用的 GPU 加速 UI 框架，由 Rust 编写。与 Electron 的Chromium + WebView2 架构完全不同：Electron 需要运行一个完整的浏览器引擎（约 200MB+ 内存），而 GPUI 直接与 GPU 交互绘制界面，终端文字渲染也走 GPU，无需 DOM/CSS 布局引擎。

自动更新机制

ShellRS 内置更新检查程序，装好后即进入静默轮询模式。检测到新版本后在后台下载，用户下次启动时自动升级，无需手动干预。相比 Xshell 需要手动下载覆盖安装，体验更接近现代 SaaS 应用。

AI Agent 集成

shellrs CLI — Agent 的安全远程执行管道

Claude Code、Codex、OpenCode 等 Agent 可通过 shellrs 命令行工具使用已保存的主机连接执行远程命令、上传和下载文件。Agent 侧不需要明文存储密码或私钥，凭据全部由 ShellRS 保管。

密码对 Agent 完全不可见：ShellRS 代为完成 SSH 握手，Agent 只拿到 stdout/stderr 执行结果。堡垒机场景支持 --terminal 模式，复用已有 SSH 通道，不额外建立新连接，避免二次认证。

凭据存储在系统钥匙串（macOS Keychain / Windows Credential Manager / Linux Secret Service），本地数据库不含密码明文。

shellrs CLI 常用命令

sshrs connect --host my-server
sshrs exec --host my-server -- "df -h && free -m"
sshrs upload --host my-server --local ./dist.tar.gz --remote /opt/
sshrs download --host my-server --remote /var/log/app.log --local ./app.log
sshrs list-hosts
sshrs forward --host jump-server --local 8080 --remote server.example.com:80
sshrs terminal --host bastion --terminal

与 AI Coding 工作流的结合方式

  • Claude Code / Codex 执行远程部署：在 .claude/projects/ 或项目脚本中调用 sshrs exec，Agent 获得远程服务器的读写能力，无需在项目配置中存储密码。
  • 批量服务器操作：在 sshrs list-hosts 返回的主机列表上循环执行 sshrs exec，实现多机并行操作，Agent 代码量大幅减少。
  • 文件上传部署：用 sshrs upload 将构建产物直接推送到目标服务器的指定目录，无需 rsync 或 scp 配置。
  • 日志回捞：用 sshrs download 将远程日志拉回本地，供 Agent 分析错误堆栈。
提示：堡垒机（JumpServer 等）场景下，--terminal 模式复用已有通道，不触发二次 MFA/OTP 验证，体验更流畅。

各平台安装步骤

  • Windows：下载 exe 安装包，双击运行。如首次安装遇到 SmartScreen 拦截提示，点击"仍要运行"（安装包未签名）。安装完成后 ShellRS 自动注册为 ssh:// / sftp:// URL 处理程序。
  • macOS：下载 dmg，挂载后将 ShellRS.app 拖入 /Applications 文件夹。首次运行若提示"无法验证开发者"，在系统偏好设置 → 隐私与安全性中手动允许。安装包已签名并通过 Apple 公证（notarized）。
  • Linux：下载 AppImage 文件，赋予执行权限（chmod +x ShellRS-*.AppImage），双击运行。无需安装，不依赖系统包管理器。

覆盖 Xshell/WinSCP URL 调用

在 ShellRS 设置 → URL 处理程序中，配置 Xshell 和 WinSCP 的可执行文件路径。配置完成后，系统中点击 ssh:// 或 sftp:// 链接将自动由 ShellRS 接管，不再触发 Xshell/WinSCP。该配置兼容 Xshell 的 -url <url> 和 -newtab <url> 参数格式。

局限性
注意：右侧栏工具（系统监控、进程、Docker 等）仅支持 Linux 主机，macOS 和 Windows SSH 连接场景下不可用。
  • Windows 未签名：安装包无数字签名，SmartScreen 首次运行会拦截，需手动点击"仍要运行"。这对企业批量部署和安全合规场景不友好，是当前最大的企业落地障碍。
  • ARM64 支持未明确：macOS Apple Silicon（M1/M2/M3）和 Linux ARM64 设备上的兼容性尚未得到官方确认，潜在用户需自行测试。
  • SFTP 目录同步/搜索仍在路线图：批量文件同步（类似 rsync 的镜像模式）和远程目录全文搜索功能尚在开发中，复杂运维场景可能需要额外工具配合。
  • 社区规模有限：244★ 为较新项目，中文文档和中文社区支持仍在建设中，遇到问题可能需要阅读英文 issue 或阅读源码。
  • 版本 0.1.9，仍非正式版：正式版（v1.0）发布前，API、配置文件格式、功能集可能继续调整，大规模生产环境使用前建议锁定版本。
  • 无会话录制/回放：与 Termius 的 Snippets 功能或 Xshell 的会话日志相比，ShellRS 目前不支持操作录制和回放。
