把一张白板静图，变成可控的手绘过程

whiteboard-animator 接收一张白底、马克笔风格的成图，识别墨迹组件，把文字逐字写出、轮廓沿笔迹描出、色块用刷子填满，再输出 MP4。它不是“给照片加滤镜”，而是一条从像素分解、绘制顺序到时间轴和音频卡点的渲染流水线。

Python 3.10+CPU onlyFFmpeg音频节奏MIT134★ API 快照

先判断输入能不能成功

最适合白纸背景、平涂颜色、清晰墨迹和有限元素的知识图。照片、渐变、纹理纸面和彩色背景不在推荐范围。

输入PNG/JPG 白板风格图片，可选 WAV 配音
处理组件识别 → 人类式排序 → 笔迹 reveal → FFmpeg
输出静音或带配音 MP4，多图多音频可拼接
01

安装：Python 包之外，还必须有 FFmpeg

SETUP

系统依赖

先安装 ffmpeg 和 ffprobe，它们是系统可执行文件；安装一个名为 ffmpeg 的 Python 包不能替代它们。

# macOS brew install ffmpeg # Ubuntu / Debian sudo apt update && sudo apt install ffmpeg # 验证 ffmpeg -version ffprobe -version

Python 环境

python -m venv .venv source .venv/bin/activate python -m pip install whiteboard-animator

Windows PowerShell 用 .venv\Scripts\Activate.ps1 激活。项目要求 Python 3.10+。

可选 Gemini 能力

基础渲染无需 API key。只有 --detect-regions 需要 Gemini extra 和 GOOGLE_API_KEY；也可以手写 region JSON，避免外部调用。

pip install 'whiteboard-animator[gemini]'
安装验收：在运行 whiteboard-animate 的同一个终端中，ffmpeg -version 与 ffprobe -version 都能返回版本信息。

03

核心流水线：它如何决定“先画什么”

ENGINE
阶段引擎动作你能观察到的结果失败时优先查
1. 找墨迹每块非白色连通区域成为组件；CRAFT ONNX 文本检测器判断哪些是文字文字走逐字书写，图形走轮廓/填充背景是否足够白；文字是否和图形粘连
2. 排顺序容器在内容前，形状在标签前，文字按阅读顺序，小点附着到字形更像人从外到内、从形状到说明的绘制习惯复杂图没有 region plan 时顺序可能只是启发式
3. 分配时间默认按面积平方根分配 slot；region plan 改用文本/面积加权大色块不会简单霸占全部时间配音语速变化不能仅靠估算解决
4. 生成笔迹骨架从真实端点展开；闭合轮廓沿路径行进；填充先轮廓再 sweep/brushV 从尖端开始，X/网格按连续笔路径出现输入是否真的有可追踪的线条
5. 写视频新完成像素只提交一次，渐隐像素逐帧混合，再交给 FFmpeg得到 MP4 或多场景拼接视频编码器、输出目录权限和扩展名
04

配音与时间轴：音频长度不是逐字对齐

AUDIO

无音频

whiteboard-animate scene.png \ --duration 8 -o scene.mp4

整张图默认在场景前 70% 绘制，最后停住到 8 秒结束。

单张图 + 配音

whiteboard-animate scene.png \ --audio scene.wav -o scene.mp4

绘制在音频结束前完成，完成画面保持到声音结束。

多图多段音频

whiteboard-animate a.png b.png c.png \ --audio a.wav b.wav c.wav -o lecture.mp4

按输入顺序拼成一节课；每段图片与对应音频位置要对齐。

节奏边界：region plan 是基于标注字符和框面积的时间估计，不会分析语音或生成 spoken-word timestamps。停顿、语速变化和句子长短不均可能造成画面领先或滞后；需要精确 cue 时，使用低层 Python API 的 element_plan 显式传入 start/end。
05

Region Plan：复杂讲解图的可控方案

CONTROL

什么时候需要

默认启发式顺序适合简单图；当讲解顺序必须和旁白严格对应，给每个区域写 label、role、object、reveal_order、box、annotation 和 reveal。

坐标规则

box 使用 0–1000 的归一化坐标，原点在左上角。标注字符权重约 70%，框面积约 30%；所有 annotation 为空时退回面积。

示例

{ "label":"sun", "role":"main_concept", "reveal_order":1, "box":{"ymin":120,"xmin":40,"ymax":620,"xmax":380}, "annotation":"Photosynthesis starts with sunlight", "reveal":"fill" }
whiteboard-animate scene.png --audio scene.wav \ --regions scene.regions.json -o scene.mp4 # 可选：让 Gemini 提议区域，再保存方案 whiteboard-animate scene.png --audio scene.wav \ --detect-regions --narration "..." --save-regions -o scene.mp4

07

排障：按现象定位，而不是盲目重跑

DEBUG

找不到命令

确认虚拟环境已激活且安装包的 Python 与当前 shell 相同。仍失败时运行：

python -m whiteboard_animator.cli scene.png \ --duration 8 -o scene.mp4

FFmpeg 编码失败

检查 ffmpeg -encoders 是否包含 libx264；用 --verbose 查看渲染阶段。输出必须是已有可写目录中的 .mp4。

OpenCV 编译失败

尝试兼容的预编译 wheel：

python -m pip install \ --only-binary=opencv-python-headless \ whiteboard-animator

若没有 wheel，换到 OpenCV 支持的 Python/平台组合。

文字被当成图形

确认 CRAFT 模型能加载；若模型缺失，引擎仍会运行，但会把文字当普通笔迹处理。

绘制顺序不对

复杂图改用 region plan 显式给出 reveal_order；不要只在 prompt 里描述“按人类习惯”。

输入像照片

这是输入不匹配而非命令错误。换成白底、平涂、马克笔风格图；项目明确不推荐渐变、纹理和有色背景。

08

适用边界、隐私与许可证

BOUNDARY
适合：知识类视频、课件讲解、白板风格流程图、带旁白的多场景课程。

不适合：照片、复杂渐变、纹理纸张、彩色背景、需要精确语音逐字时间戳的制作；除非你自己提供精确 element_plan 并接受额外开发。

外部服务：基础渲染 CPU-only、无 API key；Gemini region detection 是可选外部能力，需要 GOOGLE_API_KEY。不要把 key 写入代码或提交仓库。

模型与素材：随包约 83MB 的 CRAFT ONNX 模型来自 CRAFT-pytorch（MIT）；你的图片、旁白、字体和课程素材仍需自行确认使用权。

许可证：whiteboard-animator 仓库 MIT；这不自动授予 Kinoslide、第三方模型或输入素材的权利。
