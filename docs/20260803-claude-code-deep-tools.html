01定位

Claude Code 是 Anthropic 官方 CLI 编程助手，将 Claude 模型能力直接集成到终端，提供文件编辑、Git 操作、Bash 执行、浏览器控制等工具。

一句话区别：Copilot = IDE 里的自动补全建议。Claude Code = 坐在你终端里的有记忆的 AI 程序员——能读写文件、跑测试、debug、提交代码。
02结构化日志

Claude Code 支持三种日志输出格式，适应不同场景。

Pretty（默认）

claude
# 人类可读，高亮色

交互式终端使用

JSON

claude --output-format json

程序解析、日志收集

Stream

claude --output-format stream

实时管道、LLM 再加工

JSON 输出片段
{
  "type": "assistant",
  "message": {
    "content": [{"type": "text", "text": "这段代码实现..."}]
  },
  "usage": {"input_tokens": 1204, "output_tokens": 342}
}

# 日志位置：~/.claude/logs/
03智能调试器

Claude Code 的 Debugger 不是传统断点调试器，而是语义感知的智能调试：用自然语言描述问题，Claude 自动定位可疑代码、运行验证、给出修复建议。

智能调试示例
# 方法 1：对话中调试
claude
# > 这个函数在高并发下返回 500，帮我找原因

# 方法 2：直接通过 CLI 调试
claude --debug "修复 auth.py 中的 race condition"

# 方法 3：分步调试模式
claude --debugger --file server.py
局限：Claude Code Debugger 依赖模型推理，不能真正暂停执行或读取运行时栈（需配合 IDE + Debugger 插件）。
04MCP 模型上下文协议

MCP（Model Context Protocol）是 Anthropic 提出的标准化工具调用协议，让 Claude Code 可调用任何外部工具与数据源。

现有 MCP 服务

  • Filesystem：读写本地文件
  • Git：提交/分支/差异
  • PostgreSQL / SQLite
  • Slack / Linear / GitHub
  • 浏览器（Playwright CDP）
  • 搜索（Tavily / DuckDuckGo）

配置示例

# ~/.claude.json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y","@anthropic/mcp-server-fs"]
    },
    "github": {
      "command": "uvx",
      "args": ["mcp-server-github"]
    }
  }
}
05CLAUDE.md 与安全模式

CLAUDE.md：项目上下文注入

CLAUDE.md
# 项目：我的 API 服务
## 技术栈
- 后端：FastAPI + PostgreSQL
- 前端：React + TypeScript
## 代码规范
- 使用 async/await，避免 .then()
- 测试覆盖率 > 80%
## 常用命令
- make dev：启动开发服务
- make test：运行测试

安全模式

默认模式

每个危险操作需确认 - 生产环境

--dangerously-skip-permissions

跳过确认 - CI/CD 自动化

--resume

从上次对话继续 - 长任务恢复

!风险提示
成本
Claude Code 使用 Claude 3.5 Sonnet+ API。重度使用每月可能 $50-200。
权限
--dangerously-skip-permissions 允许 AI 执行 rm -rf 等危险操作，生产环境慎用。
幻觉
不熟悉代码库时可能生成错误修改。务必 review diff。
