01

定位：Claude Code 是什么？

Claude Code 是 Anthropic 官方发布的命令行编程助手，直接集成 Claude 模型能力到终端，提供文件编辑、Git 操作、Bash 执行、浏览器控制等核心工具。

一句话区别

Copilot = IDE 内的补全建议。Claude Code = 有记忆的 AI 程序员，坐在你终端旁边，可以读写文件、运行测试、调试、提交代码。

02

结构化日志：Pretty / JSON / Stream

Claude Code 支持三种日志输出格式，适合不同场景。

模式命令适用场景
Pretty（默认）claude（无参数）人类阅读，彩色高亮
JSONclaude --output-format json程序解析、日志收集
Streamclaude --output-format stream实时管道、LLM 二次处理
# JSON 模式：适合 CI 集成和日志收集 claude "解释这段代码" --output-format json --verbose # 输出片段 { "type": "assistant", "message": { "content": [{"type": "text", "text": "这段代码实现了..."}] }, "usage": {"input_tokens": 1204, "output_tokens": 342} }
日志位置：所有交互记录存储在 ~/.claude/logs/，可配置保留策略，方便回溯 AI 决策过程。
03

内置 Debugger：超越 print 的智能调试

Claude Code 的 Debugger 不是传统断点调试，而是基于语义理解的智能调试：通过自然语言描述问题，Claude 自动定位可疑代码、执行验证、给出修复建议。

# 方式1：在对话中直接调试 claude # > 这个函数在高并发时返回 500，找一下原因 # 方式2：直接命令行调试 claude --debug "fix the race condition in auth.py" # 方式3：启动调试模式（step-through） claude --debugger --file server.py
限制：Claude Code Debugger 依赖模型推理，无法真正暂停程序执行或读取运行时栈（需 IDE + Debugger 插件）。
04

MCP：Model Context Protocol

MCP（Model Context Protocol）是 Anthropic 提出的标准化工具调用协议，让 Claude Code 可以调用任意外部工具和数据源。

已有 MCP Server

  • ✅ Filesystem（读写文件）
  • ✅ Git（commit/branch/diff）
  • ✅ PostgreSQL / SQLite
  • ✅ Slack / Linear / GitHub
  • ✅ Browser（Playwright CDP）
  • ✅ Search（Tavily / DuckDuckGo）

配置方式

# ~/.claude.json { "mcpServers": { "filesystem": { "command": "npx", "args": ["-y","@anthropic/mcp-server-fs"] }, "github": { "command": "uvx", "args": ["mcp-server-github"] } } }
SDK：官方提供 TypeScript / Python SDK，可快速构建自己的 MCP Server。
05

CLAUDE.md 与安全模式

CLAUDE.md：项目级上下文注入

# CLAUDE.md 示例 # 项目：我的 API 服务 ## 技术栈 - Backend: FastAPI + PostgreSQL - Frontend: React + TypeScript ## 代码规范 - 使用 async/await，禁止 .then() - 测试覆盖率 > 80% ## 常用命令 - `make dev` 启动开发服务 - `make test` 运行测试

安全模式

模式行为适用场景
默认模式每个危险操作需用户确认生产环境、安全要求高
--dangerously-skip-permissions跳过确认，直接执行可信自动化、CI/CD
--resume从上次对话继续长任务恢复
CI/CD 集成
claude --dangerously-skip-permissions \ --output-format json \ "Review this PR for security issues"
06

推荐工作流

1
新建项目 → 写 CLAUDE.md
定义项目规范、技术栈、禁忌操作。
2
启动开发 → claude --resume
开启长对话，让 Claude 理解代码库全貌。
3
调试 → 直接描述问题
"这个函数在 X 条件下崩溃了" → Claude 自动定位并修复。
4
PR Review → JSON 模式
claude --output-format json "review PR #42"
⚠️ 注意事项
💰 成本
Claude Code 使用 Claude 3.5 Sonnet+ API，高强度使用月费用可能达 $50-200。
🔒 权限管理
--dangerously-skip-permissions 模式下 AI 可直接执行 rm -rf 等危险命令，生产环境慎用。
🐛 幻觉风险
Claude Code 可能在不了解代码库时生成错误修改，建议每次执行前 review diff。
