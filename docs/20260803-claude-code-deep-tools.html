01POSITIONING

Claude Code is Anthropic official CLI coding assistant. It directly integrates Claude model capabilities into the terminal, providing file editing, Git operations, Bash execution, and browser control tools.

One-line distinction: Copilot = autocomplete suggestions in IDE. Claude Code = AI programmer with memory sitting next to your terminal — can read/write files, run tests, debug, commit code.
02STRUCTURED LOGGING

Claude Code supports three log output formats for different scenarios.

Pretty (default)

claude
# Human-readable, color highlight

Interactive terminal use

JSON

claude --output-format json

Program parsing, log collection

Stream

claude --output-format stream

Real-time pipeline, LLM re-processing

JSON output fragment
{
  "type": "assistant",
  "message": {
    "content": [{"type": "text", "text": "This code implements..."}]
  },
  "usage": {"input_tokens": 1204, "output_tokens": 342}
}

# Log location: ~/.claude/logs/
03SMART DEBUGGER

Claude Code Debugger is not traditional breakpoint debugging, but semantic-aware smart debugging: describe the problem in natural language, Claude auto-locates suspicious code, runs verification, provides fix suggestions.

Smart debugging examples
# Method 1: debug in dialogue
claude
# > This function returns 500 under high concurrency, find the cause

# Method 2: direct CLI debug
claude --debug "fix the race condition in auth.py"

# Method 3: step-through debug mode
claude --debugger --file server.py
Limitation: Claude Code Debugger relies on model reasoning, cannot actually pause execution or read runtime stack (requires IDE + Debugger plugin).
04MCP MODEL CONTEXT PROTOCOL

MCP (Model Context Protocol) is Anthropic proposed standardized tool-calling protocol that lets Claude Code invoke any external tool and data source.

Existing MCP Servers

  • Filesystem: read/write local files
  • Git: commit/branch/diff
  • PostgreSQL / SQLite
  • Slack / Linear / GitHub
  • Browser (Playwright CDP)
  • Search (Tavily / DuckDuckGo)

Configuration

# ~/.claude.json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y","@anthropic/mcp-server-fs"]
    },
    "github": {
      "command": "uvx",
      "args": ["mcp-server-github"]
    }
  }
}
