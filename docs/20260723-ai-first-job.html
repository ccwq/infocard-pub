01 / SIGNAL

早期信号：入口岗位比资深岗位更脆弱

但不是“所有年轻人都失业”

Stanford / ADP

基于美国大规模雇佣与薪资记录的研究发现：22–25岁劳动者在高AI暴露职业中的就业相对下降约13%，同一职业中的更有经验年龄组没有出现同幅度下降。

NBER w33777

为什么是入口？

  • 初级岗位包含更多可标准化任务。
  • 企业把这些岗位同时当作生产岗位和训练场。
  • AI能让一个新人更快产出，也可能让企业少招培养型新人。

关键限制

就业下降不能直接等同于AI造成的失业。利率、科技行业裁员、疫情后招聘回调、外包周期和岗位分类变化都可能共同作用。

核心判断：“初级岗位先承压”是较有证据支持的早期信号；“AI已经消灭第一份工作”则是尚未完成的强结论。
02 / TASKS

AI改写的是任务包，不一定是职业名称

从做任务，转向验收任务

容易被压缩的任务

  • 资料整理、初稿和格式化报表
  • 样板代码、简单脚本和低复杂度修复
  • 基础翻译、标准客服和重复性研究
  • 按既定流程执行的中间产物

更难被完全替代的能力

  • 定义问题与拆解目标
  • 验证事实、代码和隐藏依赖
  • 理解组织、客户和业务上下文
  • 对结果、合规和风险负责
经验悖论：如果企业要求新人“已有经验”才能直接交付，而AI又减少培养型岗位，新人获得第一段经验的渠道会变少。这个机制值得追踪，但目前不能用单篇报道证明已经普遍发生。
03 / COUNTER-EVIDENCE

生产率提升，不等于岗位按比例消失

任务、工具和工作环境决定结果

对新手的提升

NBER客服研究覆盖约5,000名客服人员，AI助手使平均生产率提高约14%，新手/低技能员工提升约35%。这说明AI也可能降低学习曲线，而非只做替代。

NBER Generative AI at Work

增强仍多于自动化

Anthropic Economic Index样本中，约57%的使用被归为增强，约43%为自动化。该比例不是整个经济的失业预测。

Anthropic Economic Index

复杂代码的反例

METR对熟悉真实开源仓库的开发者研究发现，2025年早期工具组完成任务时间反而约增加19%。大型代码库中的验证成本会抵消生成速度。

04 / VERDICT

结论：第一份工作正在变窄，还是正在变形？

最稳妥的表述：AI正在让第一份工作的训练结构和招聘门槛发生变化，年轻人在高AI暴露职业中出现早期冲击信号；是否演变成广泛的初级岗位净消失，取决于企业把生产率收益用于扩张、提质还是减员。
研究日期：2026-07-23 · 来源：Stanford Digital Economy Lab / NBER / Anthropic / METR
证据边界：公开研究支持“任务重组和年龄梯度”，不支持统一的“AI替代率”或“一个Agent等于数名员工”等宣传数字。
