AI-CLI · TERMINAL · GENERATION

从终端直接生成图像和视频

ai-cli.dev 是一个多模型 CLI：终端里直接做文本、图像、视频生成；支持多模型并行比较，管道式输入输出，并通过 Vercel AI Gateway 访问 OpenAI / Anthropic / Google / Black Forest Labs / ByteDance 等模型。

01
WHY IT MATTERS

让生成任务也变成 Agent Loop 的一部分

生成不是终点，而是流程中的一个节点：文本→图像→视频→保存/复用，全部可以被脚本化。

多模型比较

同一 prompt 可并行跑多个模型，再按结果挑最好的。

管道化

文本、图片、视频都能和其他命令串联，形成 shell workflow。

终端优先

无需切网页或 GUI，Agent 可以直接在 CLI 里完成生成任务。

02
WHAT IT SUPPORTS

文本、图像、视频，一套命令语义

核心卖点不是“某一个模型”，而是统一的命令行表达方式和多模型访问层。

Text

解释 / 生成 / 改写

对着 git diff、提示词或文本直接输出结果。

Image

文生图 / 多模型并行

支持短名自动解析，适合快速对比风格。

Video

图生视频 / 生成视频

把图像链到视频生成流程中。

Gateway

通过 AI Gateway 统一接入

覆盖 OpenAI、Anthropic、Google、BFL、ByteDance 等。

03
ENTRY POINTS

三种用法：CLI、管道、比较

最适合 Agent 的地方，是它把“生成任务”做成了一套天然可组合的命令。

CLI

npm install -g ai-cli，然后直接在终端发起生成。

全局安装终端生成

TRADE-OFFS

Agent 用它的价值在于：可脚本化、可比较、可串联、可复用。
