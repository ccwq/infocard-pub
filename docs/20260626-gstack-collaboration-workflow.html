核心理念
⚡
Token最大化
不计成本消磨算力换取全面深度成果。用Token买回时间，向机器借用时间以延伸个人生命价值。每天在算力上投资是换取超高生产力最划算的资产投入。
🧑‍🔬
人置于环路
机器负责海量数据和重复枯燥的脏活，人类负责需求、主观能动性与核心价值把控。全局理解与核心需求判断必须由人类注入——这是不可替代的。
📋
伪技能与代码密度
用自然语言Markdown写非确定性意图，就像给助手写执行清单。衡量生产力的核心是逻辑上的有效代码密度，而非单纯的代码行数。
🔐
主权保障
基于开源工具搭建专属个人AI系统，确保掌控自身数据与提示词。不依赖封闭平台的锁死风险。
GStack 五步协作工作流
1
CEO 审查 · 董事会时间 规划阶段
启动时先拷问目标用户与核心价值——这卡解决什么问题？谁能从中受益？与其他方案比优势在哪？确保所有工作都锚定真实需求。
2
设计审查 前置环节
涉及 UI 界面或开发者调用时，前置进行体验与工程审查。让 AI 同时承担 CEO、设计师、开发、体验、测试等多重角色做交叉验证。
3
状态建模 写码前必做
让 AI 在写代码前先画出数据流、用户动线及覆盖状态机，预载完整上下文。减少返工，提升代码质量与可维护性。
4
自动化测试 质量保障
封装 Playwright 测试框架以自动完成浏览器质量验证。保持 80%~90% 的最佳覆盖率，大幅降低回归风险。
5
角色演练 · 多视角复盘
交付前让 AI 同时扮演多重角色（CEO 审查价值 → 设计师审查体验 → 开发审查实现 → 测试审查覆盖率），系统性消灭盲区。

约束与最佳实践
🎯
明确确定性边界
明确划分大语言模型处理的「非确定性范围」与传统代码处理的「确定性 API 范围」。AI 负责理解意图与生成策略，API 负责执行与返回可靠结果。
💰
消除 Token 成本吝啬
每天在算力上的投资是换取超高生产力最划算的资产投入。不应为省 Token 而牺牲成果的完整性和深度——机器的时间比人的时间便宜得多。
🛡️
基于开源搭建专属系统
基于开源工具（Claude Code、Codex、Playwright）搭建专属个人 AI 系统，确保掌控自身数据与提示词，避免平台锁定与隐私风险。
