LangChain 官方 AI Agent 文档 CLI 工具

为 AI Agent 自动生成并持续维护高质量代码文档的 CLI 工具。运行 openwiki 一键生成，openwiki --update 自动刷新最新变更，让 Agent 始终拥有最新、最准确的代码上下文。

核心价值：解决 AI Agent 在陌生代码库中"读不懂、改不对"的问题——自动生成 AGENTS.md / CLAUDE.md，让 Claude Code、Codex 等工具真正理解你的项目结构与开发规范。

02核心功能详解

① 交互式 CLI

  • 一键分析代码库结构
  • 自动识别模块边界与依赖
  • 生成结构化文档（API 说明、架构图）
  • 支持增量更新，只刷新变更文件

② 多 LLM 支持

  • OpenAI GPT-4 / GPT-4o
  • Anthropic Claude 3.5 / 3.7
  • OpenRouter（聚合多模型）
  • Fireworks AI 等

③ CI/CD 自动 PR

  • GitHub Actions 一键集成
  • 代码变更触发自动文档更新
  • 自动提交 PR，无需人工介入
  • 内置防循环冲突机制

④ AGENTS.md / CLAUDE.md 智能注入

  • 自动追加 Agent 工作指令
  • CLAUDE.md：Claude Code 专用
  • AGENTS.md：通用开源 Agent 标准
  • 避免手动维护"AI 说明书"文档
LangSmith 集成： 设置 LANGCHAIN_TRACING_V2=true 与 LANGCHAIN_API_KEY，openwiki 的每次 LLM 调用均自动上报 LangSmith，支持查看 token 消耗、延迟、错误率等指标，实现文档生成过程的全链路可观测。
03AGENTS.md vs CLAUDE.md 核心区别
维度CLAUDE.mdAGENTS.md
提出者Anthropic（Claude 官方）开源社区（Multica）
适用范围Claude Code 专用通用（OpenCode / Cursor / Codex 等）
定位Claude Code 项目说明书跨工具 AI Agent 上下文标准
文件位置项目根目录（默认）根目录或子目录均可
openwiki 处理针对 Claude Code 优化注入通用 Agent 指令自动追加
openwiki 的区别处理： 工具检测当前 Agent 类型（Claude Code vs 其他），智能选择注入目标文件。Claude Code 优先写 CLAUDE.md；OpenCode / Cursor 等写 AGENTS.md。两者可共存，openwiki 支持同时维护。
04CI/CD 自动 PR 与防循环冲突

openwiki 的 CI/CD 集成设计了一个关键的"守护检查"机制来避免文档循环冲突：

冲突场景

  • Agent 修改代码 → 触发 CI
  • CI 运行 openwiki --update
  • 文档 PR 被 Agent 再次读取
  • Agent 误认为新文档是变更，重新触发 CI

openwiki 的解法

  • PR body 中注入签名标记（commit hash）
  • CI 触发前检查最近一次 PR 是否来自 openwiki
  • 若文档变更 diff 仅为 openwiki 生成内容，跳过重跑
  • 使用 openwiki --ci-safe 标志开启此模式
GitHub Actions 示例工作流： on: push [main] pull_request
使用 openwiki --ci-safe --pr 模式，仅在纯代码变更时触发文档更新，文档变更不再触发循环。
