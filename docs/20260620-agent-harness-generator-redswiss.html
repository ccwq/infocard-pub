02核心卖点
仓库到 Harness 的工厂

从 GitHub URL 或空白起步，自动生成品牌化、可治理的 Agent Harness。

浏览器端完成

无后端、无安装，数据不离浏览器，适合演示、构建与验证。

可发布产物

输出 npm 可发布的 zip 包，带有你自己的命名、品牌和 CLI。

多宿主支持

Claude Code、Codex、Hermes、OpenClaw、pi.dev、RVM 等宿主统一适配。

MCP + Skills + Policy

把工具、技能、命令、策略、记忆都纳入同一个治理面板。

自进化循环

支持 Darwin Mode / evolve，靠实测改进配置而不是冻结模型假设。

03工作流链路

1. 评分再构建

先 score repo，再决定是否 scaffold，避免盲目开工。

2. 生成 Harness

根据模板、宿主和治理策略生成可执行目录结构。

3. 本地验证

用 harness validate / doctor 校验配置、工具、权限与安全边界。

4. 以 npm 发布

把生成结果打包成组织内可复用的 npm 依赖或 CLI。
