01
核心定位
What it is
agents marketplace 不是替代某个 coding agent，而是成为所有 coding agent 的"插件路由器"。
市面上已有 6 大 coding agent 工具（Claude Code、Codex CLI、Cursor、OpenCode、Copilot、Gemini CLI），但它们的插件体系各自封闭。wshobson/agents 这个项目做的是：建立一个统一的插件市场，让用户在一个地方发现、对比、安装跨平台的 Agent 插件，而不需要分别去每个工具的生态里搜索。

核心价值：降低插件发现成本，统一评分标准，让插件开发者一次开发、多平台复用。

插件类型地图
What plugins do

🔍 搜索与发现类

全库代码搜索、语义搜索、上下文感知检索，加速代码定位。

📝 代码生成类

模板生成、测试桩生成、文档生成、类型推导，提升编码速度。

🧪 测试与验证类

单元测试生成、集成测试、回归测试、边界条件检测。

🔧 重构与优化类

代码重构、性能优化、安全扫描、依赖分析。

📚 文档与知识类

README 生成、API 文档、变更日志、知识库同步。

🤖 CI/CD 集成类

自动 lint、format、build、deploy，与 GitHub Actions 联动。

插件选择决策树
How to choose

选择插件前的 3 问

Q1.你的主要 coding agent 是哪个？→ 确定目标平台（Claude Code / Codex / Cursor...）
Q2.你需要解决什么类型的问题？（搜索 / 生成 / 测试 / 重构 / 文档 / CI）→ 缩小插件类型范围
Q3.该插件是否跨平台？→ agents marketplace 可一次搜索多平台版本
05
快速上手
Get started
# 安装 agents marketplace CLI
npm install -g @agents/marketplace

# 搜索跨平台插件
agents search semantic search --platform all

# 查看某个插件详情
agents info codebase-indexer

# 安装到指定平台
agents install codebase-indexer --to claude-code

# 查看已安装插件
agents list --platform codex

# 跨平台对比同一功能插件
agents compare test-generator --platforms claude-code,codex,cursor
