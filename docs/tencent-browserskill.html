01核心能力

  • 复用登录态：Agent 直接使用你已登录的网站，无需维护测试账号
  • 不打断工作：浏览器任务在独立的 Agent Window 运行，不影响你的正常浏览
  • 人类介入：遇到验证码、登录、确认弹窗时，Agent 可请求人工接管后继续
  • 无锁定：不绑定特定模型、框架或 harness，任何能调用 shell 的 Agent 均可使用

02支持 Agent

  • Cursor / Claude Code：主流 AI 代码编辑器
  • Codex / OpenClaw：OpenAI / OpenClaw 系列
  • CodeBuddy / WorkBuddy：腾讯自研 Agent 产品
  • Pi / Hermes Agent：其他 shell-capable Agent
  • 通用：任何能调用 shell 的 AI 智能体
