Workdsh

AI Native Desktop Workbench

基于 DeepSeek Harness 的本地优先 AI 工作台，六大核心模块覆盖项目、资料、专家、技能、连接器与成果管理，让 AI 工作流在本地桌面高效运转。

本地优先 DeepSeek Harness SkillHub 市场 桌面端安装
DSH 原生功能全保留 + 开放插件生态

模型、工具、会话、/ 命令和 @ 引用等 DeepSeek Harness 原生能力完整保留，同时接入 SkillHub 技能市场与 DSH 社区插件生态，支持 Windows / macOS / Linux。
