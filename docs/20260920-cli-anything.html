CLI-Hub 命令

pip 安装
pip install cli-anything-hub 安装 Hub
cli-hub list 浏览全部
cli-hub install <name> 安装 CLI
cli-hub search <keyword> 搜索包
cli-hub info <name> 查看详情
cli-hub update 更新 Hub
cli-hub uninstall <name> 卸载 CLI
