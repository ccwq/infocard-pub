Yazi 用 Tokio 异步处理所有 IO 任务，所有文件操作均并发完成无阻塞渲染。内置完整键位速查，导航/选择/文件操作/搜索/过滤/排序/多标签/任务管理全覆盖。适合高频 CLI 文件操作和远程服务器管理。

01
核心能力

异步 IO + 多格式预览 + 现代特性

Tokio 异步运行时 + Rust 编译器优化，所有 IO 操作并发执行。内置 Virtual Filesystem、DDS 消息、CSI u 鼠标支持、OSC 52 剪贴板等现代终端协议支持。

Virtual Filesystem

虚拟文件系统层

统一抽象文件系统，支持本地磁盘、网络存储（SMB/FTP/SFTP）、压缩包（ZIP/TAR.GZ/RAR）直接浏览，无需解压到临时目录。

  • SMB/FTP/SFTP 网络挂载
  • ZIP/TAR.GZ/RAR 内嵌浏览
  • Git 虚拟视图
Data Distribution Service

DDS 消息系统

ya emit 命令行工具可发送 DDS 事件，实现 Yazi 与外部脚本的双向通信。如 ya emit cd /path 让外部脚本控制 Yazi 跳转目录。

  • ya emit cd /path
  • ya emit select file.txt
  • ya emit reveal /path/to/file
Package Manager

Lua 插件包管理器

内置 ya pkg 命令管理插件，支持从 GitHub 安装、社区插件包、本地路径。ya pkg upgrade 一键升级所有插件。

  • ya pkg add owner/plugin
  • ya pkg add owner/repo:subdir
  • ya pkg upgrade
CSI u · OSC 52

现代终端协议支持

CSI u（鼠标跟踪）和 OSC 52（剪贴板操作）原生支持，无需配置即可在 iTerm2/SKitty/WezTerm/Ghostty 等现代终端中获得完整鼠标交互和剪贴板同步。

  • CSI u：鼠标单击选中/打开文件
  • OSC 52：y/d 复制内容自动写入系统剪贴板
  • 默认启用，无需额外配置
多格式预览

终端内直接预览所有格式

图片（iTerm2/SKitty/WezTerm 六像素）、视频（FFmpeg 首帧缩略图）、PDF（pdftoppm）、音频（ID3 标签）、代码（内置高亮），无需外部工具。

  • iTerm2 InlineImage 协议
  • FFmpeg 视频缩略图
  • 内置 200+ 语言语法高亮

INSTALL + CONFIG

安装与配置

零依赖单二进制，macOS/Linux/Windows 全平台支持。Shell wrapper 让退出后自动 cd 到最后目录。

安装方式

多平台安装

macOS: brew install yazi
Linux: cargo install --locked yazi
Windows: scoop install yazi
Arch: pacman -S yazi
直接下载： GitHub Releases 预编译二进制
Shell Wrapper（重要！）

退出后自动 cd 到目录

Bash / Zsh:
function y() {
  local tmp="$(mktemp -t yazi-cwd.XXXXXX)"
  command yazi "$@" --cwd-file="$tmp"
  IFS= read -r -d '' cwd < "$tmp"
  [ "$cwd" != "$PWD" ] && builtin cd -- "$cwd"
  rm -f -- "$tmp"
}

ya CLI + DDS

ya 命令行工具

ya 内置插件管理和 DDS 消息发送，支持外部脚本控制 Yazi 行为或获取当前状态。

插件管理

ya pkg — Lua 插件包管理器

  • ya pkg add owner/plugin — 安装插件
  • ya pkg add owner/repo:subdir — 安装子目录插件
  • ya pkg delete owner/plugin — 卸载插件
  • ya pkg list — 列出已安装插件
  • ya pkg install — 从 package.toml 安装所有
  • ya pkg upgrade — 升级所有插件
DDS 消息

ya emit — 双向通信

  • ya emit cd /path — 让 Yazi 跳转到目录
  • ya emit select file.txt — 选中文件
  • ya emit reveal /path/to/file — 聚焦并选中
  • ya emit open /path — 打开文件

配置文件：~/.config/yazi/yazi.toml，导出默认配置：yazi --dump-config

10
对比竞品

Yazi vs Ranger / NNN / LF

选择 Yazi 的理由，以及它与竞品的核心差异。

性能

Yazi vs Ranger

Yazi 快 10 倍，异步无阻塞。Ranger Python 单线程，大目录卡顿。

启动速度

Yazi vs NNN

Yazi ~50ms 冷启动，NNN ~20ms。NNN 更轻，但预览能力弱。

预览能力

Yazi vs LF

Yazi 内置多格式预览，LF 依赖外部工具脚本。

插件生态

Lua vs Shell 脚本

Yazi Lua 插件比 Ranger Python 更结构化，比 LF shell 更安全。
