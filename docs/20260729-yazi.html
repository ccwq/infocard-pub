CLI 文件管理 · Rust + Async IO

Yazi

极速终端文件管理器。Rust + Tokio 异步 IO，支持图片/视频/PDF 终端预览，Vim 按键，插件生态。可与 FZF、Ripgrep 组合，适合高频 CLI 操作和远程服务器管理。

Rust Async IO Vim Keys Preview
插件生态 FZF 集成 跨平台 零配置
一句话定位：Ranger 的 Rust 继任者，比 ranger 快 10 倍

Yazi 用 Tokio 异步处理所有 IO 任务：文件搜索、压缩包遍历、Git 状态批量查询全部并发完成，无阻塞渲染。适合需要高频文件操作、频繁远程 SSH 的开发者。

异步 IO 多线程预览 Vim 键位 插件系统
01
CORE PERFORMANCE

为什么比 Ranger 快 10 倍

Tokio 异步运行时 + Rust 编译器优化，所有 IO 操作并发执行，CPU 密集任务多线程处理。

性能核心

Tokio 异步 IO

文件列表、压缩包遍历、Git 状态查询全部异步并发，无阻塞主线程。

  • Tokio 异步运行时
  • 文件 IO 非阻塞
  • 批量操作并发
预览多线程

多线程预览解码

图片、视频、PDF、压缩包预览使用独立线程池，不影响导航流畅度。

  • Image/thumb 子系统
  • FFmpeg 视频缩略图
  • PDF 页面渲染
插件生态

插件与脚本

内置 Lua 插件系统，支持自定义预览、快捷键、主题和功能扩展。

  • Lua 插件 API
  • 自定义快捷键
  • 主题系统
02
TERMINAL PREVIEW

终端内直接预览所有格式

无需打开外部程序，Yazi 内置预览图片、视频、PDF、音频、压缩包、代码高亮。

图片预览

iTerm2/SKitty/WezTerm 六像素格式，支持 EXIF 旋转。

视频预览

FFmpeg 提取首帧缩略图，MP4/MKV/AVI 等格式，无需播放器。

PDF 渲染

pdftoppm 渲染 PDF 页面为图片，终端内直接查看文档内容。

压缩包浏览

直接解压遍历 ZIP/TAR.GZ/RAR 内容，无需先解压到临时目录。

代码高亮

代码语法高亮

内置代码文件语法高亮，无需外部工具，支持 200+ 编程语言。

音频

音频元数据

显示 MP3/FLAC 等音频文件的 ID3 标签、时长、采样率等元数据。

VIM KEYBINDS + INTEGRATION

Vim键位

Vim 风格操作

h/j/k/l 导航，w/b 跳词，/ 搜索，c/d/y/p 快捷操作，: 命令行模式。

  • c — 复制 / y — 剪切 / d — 删除

FZFRG

与 FZF + Ripgrep 配合

Yazi 内置文件搜索命令可调用 FZF，RG 搜索结果可直接在 Yazi 中打开文件。

  • fzf — 模糊搜索文件
  • rg — 全局内容搜索
  • smart-sort — 智能排序
04
INSTALL + CONFIG

安装与配置

零依赖单二进制，macOS/Linux/Windows 全平台支持，配置文件位于 ~/.config/yazi/。

安装方式：
macOS: brew install yazi ffmpegthumbnailer pdftoppm
Linux: cargo install yazi
或者直接下载预编译二进制（GitHub Releases）
依赖

可选依赖（预览增强）

ffmpegthumbnailer（视频）、pdftoppm（PDF）、jq（JSON）、fzf（模糊搜索）、ripgrep（内容搜索）。

  • ffmpegthumbnailer
  • poppler-utils (pdftoppm)
  • fzf + ripgrep
05
YAZI vs OTHERS

对比 Ranger / NNN / LF

选择 Yazi 的理由，以及它与竞品的核心差异。

性能

Yazi vs Ranger

Yazi 快 10 倍，异步无阻塞。Ranger Python 单线程，大目录卡顿。

启动速度

Yazi vs NNN

Yazi ~50ms 冷启动，NNN ~20ms。NNN 更轻，但预览能力弱。

预览能力

Yazi vs LF

Yazi 内置多格式预览，LF 依赖外部工具脚本。

插件生态

Lua vs Shell 脚本

Yazi Lua 插件比 Ranger Python 更结构化，比 LF shell 更安全。
