Section One

核心能力

异步 IO + 多格式预览 + 现代终端协议支持

⚡ 异步 IO

  • 全异步架构，并行预加载文件
  • 非阻塞 UI，响应毫秒级
  • 协程驱动，高效利用系统资源

🖼️ 多格式预览

  • 图片：auto XV / sixel / kitty / iterm
  • 视频：ffmpegthumbnailer 帧缩略图
  • PDF：pdftoppm 逐页渲染
  • 音频：专辑封面 + 时长元数据
  • 压缩包：内容列表预览

🔌 现代特性

  • CSI u：Unicode 终端光标支持
  • OSC 52：系统剪贴板访问
  • Shell 扩展：zsh / bash / fish 补全
  • Lua 插件：完全可定制行为
核心快捷键总览
Enter进入目录 / 打开文件
Esc返回上级 / 取消操作
q退出 Yazi
g跳到列表顶部
G跳到列表底部
:执行 Shell 命令
Ctrl+c复制文件路径到系统剪贴板（OSC 52）

导航快捷键

h/j/k/l 基础移动 + Vim 风格词移动 + 跳转命令

导航快捷键
h进入父目录
j向下一项
k向上一项
l进入子目录 / 打开文件
b跳到当前词首（Vim 风格）
w跳到下一词首（Vim 风格）
e跳到当前词尾（Vim 风格）
ge跳到上一词尾（Vim 风格）
g g跳到列表第一项（配合 g i 使用）
G跳到列表最后一项
Ctrl+d向下滚动半页
Ctrl+u向上滚动半页
F进入父目录（替代 h）
f进入子目录（替代 l）
z将当前项居中显示
yy复制当前文件路径（与导航无关，放这里便于发现）

Section Three

选择快捷键

Space / x / v 选择模式 + af/ag/aF/aG 范围选择

选择快捷键
Space选择 / 取消选择当前文件
x切换当前项的选择状态
v进入范围选择模式
af选中所有文件（add files）
ag取消选中所有文件（add gaps / unselect all）
aF选中父目录所有匹配项
aG选中根目录下所有匹配项

使用提示

基础选择

  • Space 逐个选择文件
  • v 进入可视模式后用 j/k 选范围
  • x 快速切换单个文件状态

批量选择

  • af 全选当前目录所有文件
  • ag 取消全部选择
  • aF 选中所有兄弟文件
  • aG 从根目录全选
04
Section Four

文件操作

p 粘贴移动 / y 复制 / d/D 删除 / r/R 重命名

文件操作快捷键
p粘贴已复制的文件（mv 操作）
y复制文件到剪贴板
d将文件移入回收站（可恢复）
D永久删除文件（不可恢复）
r重命名当前文件
R批量重命名（支持正则）

操作说明

复制 & 移动

  • y 复制文件路径（配合 p 粘贴）
  • p 将复制的文件移动到当前位置
  • 复制的文件会进入 Yazi 内部剪贴板

删除 & 重命名

  • d 删除到系统回收站
  • D 永久删除，需二次确认
  • r 单文件重命名
  • R 批量重命名，支持捕获组替换

Section Five

路径复制

cp / cf / yy 三种路径复制方式

路径复制快捷键
cp复制当前文件完整路径
cf复制当前文件名（不含路径）
yy复制当前文件路径（与 cp 等效）

cp — 完整路径

  • 复制绝对路径
  • 如：/home/user/doc/file.txt
  • 粘贴后可直接使用

cf — 文件名

  • 仅复制文件名部分
  • 如：file.txt
  • 方便重命名 / 搜索场景

yy — 等效 cp

  • 与 cp 完全等价
  • Vim 用户习惯用法
  • 复制后显示已复制路径

Section Six

过滤 / 搜索

内联过滤 + 外部搜索 + 正则匹配 + 大小写控制

过滤 / 搜索快捷键
Ctrl+f打开内联过滤输入框
Ctrl+s调用外部搜索工具（fzf / ripgrep）
/打开正则搜索输入框
?反向搜索（搜索不匹配的项）
n跳到下一个搜索匹配项
N跳到上一个搜索匹配项
Alt+c切换大小写敏感模式

搜索模式说明

内联搜索

  • Ctrl+f 输入即过滤
  • / 正则表达式搜索
  • ? 反向搜索（隐藏匹配项）
  • n/N 跳转匹配项
  • Alt+c 切换大小写

外部搜索

  • Ctrl+s 调用系统搜索工具
  • 默认使用 fzf 或 ripgrep
  • 可自定义为任何 CLI 工具
  • 适合全文检索场景

Section Seven

排序

sort 菜单 + 一键排序快捷键 sz/sg/sr/sd

排序快捷键
sort打开排序选项菜单
sz按文件大小排序
sg按修改时间排序
sn按文件名排序（name）
sr按文件名反向排序
sd按扩展名排序

排序维度

  • sz Size — 文件大小
  • sg modified — 修改时间
  • sn name — 文件名升序
  • sr name reverse — 文件名降序
  • sd extension — 扩展名

排序菜单

  • sort 打开交互式菜单
  • 可组合升序 / 降序
  • 可按多个维度次级排序
  • 排序结果记忆到会话

Section Eight

多标签 / 任务

tab 新标签 / t 新建目录面板 / o 面板打开

多标签 / 任务快捷键
tab创建新标签页
t在当前面板新建目录视图
o在新面板中打开当前目录
Tab在相邻标签页之间切换
W关闭当前标签页（wide）
Alt+h将当前标签页向左移动
Alt+l将当前标签页向右移动

标签页操作

  • tab 新建空白标签页
  • W 关闭当前标签页
  • Alt+h/l 调整标签顺序
  • 最多支持 10 个标签页

面板操作

  • t 当前面板分裂为二
  • o 新面板打开同级目录
  • 支持水平 / 垂直分屏
  • 各面板独立导航

Section Ten

架构特性 / 竞品对比

ya CLI / DDS 消息系统 / Virtual Filesystem + Yazi vs Ranger / NNN / LF

DDS 消息系统 / Virtual Filesystem

DDS 消息总线

  • Decentralized Data Store
  • 跨插件无状态通信
  • 事件驱动架构
  • 支持异步订阅 / 发布

Virtual Filesystem

  • 抽象文件系统接口
  • 支持插件扩展存储后端
  • FTP / SFTP / WebDAV 透明访问
  • 本地 / 远程统一体验

Lua 插件生态

  • 完整 Lua 5.4 运行时
  • 插件可注册 DDS 处理器
  • 覆盖所有核心功能
  • 插件市场：ya-plugin-*

Shell 执行

:command

在 Yazi 底部输入框执行任意 Shell 命令

:!ls -la

带 ! 前缀立即执行

$var & 环境变量

Shell 扩展支持环境变量展开

:!echo $PWD

支持所有 Shell 变量
