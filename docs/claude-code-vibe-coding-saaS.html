什么是 Vibe Coding？

Vibe Coding 是一种用自然语言驱动 AI 生成代码的编程方式，核心理念是"见 (see) → 说 (say) → 跑 (run)"三步循环——你描述意图，AI 写代码，你验证效果。2025 年 11 月被《柯林斯词典》评为年度词汇。

💡
"fully give in to the vibes, embrace exponentials, and forget that the code even exists"
— Andrej Karpathy，OpenAI 联合创始人 / 特斯拉前 AI 主管，2025 年 2 月 3 日 Jobs Talk

各工具角色详解
🐙
GitHub
代码仓库 · 版本控制

创建私有仓库存储项目代码，Claude Code 在此读写代码。所有协作都在 GitHub 进行。

🗄️
Supabase
后端即服务 · 数据库 + 认证

PostgreSQL 数据库、用户注册登录、实时订阅、文件存储。无需写后端代码，API 直接调用。

▲
Vercel
前端部署 · 自动发布

连接 GitHub 后，每次代码提交自动构建并发布网站。免费套餐足够初期使用。

💳
RevenueCat
内购 · 订阅变现

统一管理 App 内购买，封装 Apple StoreKit / Google Play Billing，月收入 $1,000 以内免费。

I've set up a handful of people that have absolutely zero technical skills to build mobile apps. Here's how I set them up: Go create claude account → create a private GitHub repository → create Supabase account → create Vercel account → create RevenueCat account → open terminal → teach them how to cd to desktop → clone repo → cd into repo → install Claude Code via terminal → tell Claude to install all CLIs and MCPs → tell Claude to create a blank NextJS app + UIKit app monorepo → tell Claude to prefer ShadCN, 21st Dev, framer motion → tell Claude to route all API calls through web app → if they have any questions, ask Claude!

💡 零成本起步

月收入 $1,000 以内，Supabase + Vercel + RevenueCat 三大件几乎可以零成本维持。Apple 开发者账号是唯一强制付费项。

技能要求
  • ⌨️会用终端：cd / ls / clone / npm/pnpm 基础命令
  • 🗣️能用自然语言描述需求（中文或英文均可）
  • 🔍能识别并描述 UI 问题（"这个按钮歪了"）
  • 🔑会用浏览器操作各平台管理后台
  • 📱有 Mac 电脑（iOS 开发必需）+ Apple 开发者账号

无需会写代码

所有代码生成、CLI 安装、MCP 配置、API 路由、样式选择均由 Claude Code 自动完成。你只需提问和验证。

⚠️ 注意事项

⚠️ 风险提示

  • AI 生成代码可能存在 bug 和安全漏洞，需人工审查
  • Claude Code MCP 调用外部服务有安全风险，避免暴露密钥
  • 设计审美依赖 AI，无设计经验可能导致 UI 质量不稳
  • iOS App Store 审核严格，AI 生成代码可能违反苹果政策
  • 收入超过 $1,000 后 RevenueCat 开始收费（1.5%）
  • Mac 是 iOS 真机调试/上架的必需条件
