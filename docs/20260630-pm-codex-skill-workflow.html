03
Skill 工程 · 4 项经验

把 Skill 当 SOP 沉淀

AI 不是替你思考，而是替你稳定地不漏想。这 4 条经验决定了 Skill 能不能从"能用"升级到"耐用"。

拆测试点 · 8 个固定维度

主流程 / 边界 / 异常 / 状态

把"拆测试点"这件事先拆成固定维度，避免 AI 漏想并发、幂等、状态联动：

  • 主流程 · 条件分支 · 边界值 · 异常提示
  • 状态流转 · 数据一致性
  • 权限 · 并发 · 幂等
  • 恢复 · 回退 · 重试
Skill 构建 · 四阶段

试错 → 抽取 → 封装 → 喂养

不要一开始就写完美 SOP。先让 AI 犯错，记录所有 Bad Case，再沉淀成文件体系：

  • 阶段一：直接让 AI 画，效果随机，发现边界
  • 阶段二：从失败中提炼规范
  • 阶段三：组织成文件体系，变成可复用能力
  • 阶段四：每次喂坑添加规则，SOP 越用越强
SVG vs ASCII

线稿是可编辑的代码，不是文本

ASCII 原型产出"文本"，调整某个字段位置要重新整段改写；SVG 线稿是"代码"，字段位置、样式都能逐字段迭代。

  • 低保真线稿即可跑通需求评审
  • 字段位置、说明文字、布局都能改
  • 提示词：/ui-ux-pro-max 给我设计一个 ios 端的登录界面,用 SVG
真实陷阱 · Bad Case

AI 不会主动告诉你它会哪里犯错

Aron 在画登录页时连续踩 3 个坑，全靠手动对比才暴露出来：

  • 价格幻觉：编造 \$49 / \$149，需求未给线上数据源
  • 字符幻觉：文本里出现 \n，Figma 根本不支持
  • 风格失控：默认画紫色渐变分屏布局
