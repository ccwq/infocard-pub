Simul-Whisper 实时流水线

基于 SOTA 同步语音研究：Simul-Whisper（AlignAtt）+ Streaming Sortformer（说话人分离）+ NLLW（同声传译），每个音频块精确一次编码，常量计算。

① 输入 麦克风 / 音频流 / 文件
② ASR 引擎 Whisper / Faster-Whisper / Qwen3-ASR / …
③ 说话人分离 Streaming Sortformer → 分角色稿
④ 同声传译（可选） NLLW → 200 语言实时译文
⑤ 输出 REST / WebSocket / OpenAI SDK
1
开会做纪要终于可以"边说边出字"——WhisperLiveKit 把会议录音整理从苦活变成自动流。

传统方案：录音结束才能转写，一段没有断句的文字全靠回忆去猜谁说了哪句，整理一场两小时会议经常要再花一小时。WhisperLiveKit 基于 Simul-Whisper、Streaming Sortformer 和 NLLW 三项 SOTA 研究，实时处理音频流，说话人自动分离，跨语言会议边说边出译文，数据完全留在本地。

核心技术

  • Simul-Whisper（SOTA 2025）：AlignAtt 策略实现超低延迟转写
  • Streaming Sortformer（SOTA 2025）：实时说话人分离
  • NLLW（SOTA 2025）：基于蒸馏 NLLB-200 的同声传译，覆盖 200 种语言
  • Qwen3-ASR-causal（2026）：每块音频精确一次编码，常量计算，append-only 文本输出
  • AlignAtt4LLM（IWSLT 2026）：基于解码器的同声翻译，注意力门控提交

为什么不用普通 Whisper 批量处理？

Whisper 设计用于完整语音片段，不适合实时小块音频。逐块处理会丢失上下文、截断音节、产生碎片化转写。WhisperLiveKit 使用前沿同步语音研究实现智能缓冲和增量处理。

ASR 引擎支持矩阵

苹果 MPS / 纯 CPU / NVIDIA 显卡各有对应配置

引擎 硬件支持 主要能力
Whisper GPU 多语言转写，OpenAI 官方模型
Faster-Whisper NVIDIA CTranslate2 加速，FP16/BF16，显存占用更低
MLX Whisper Apple MPS 苹果芯片优化，MLX 推理后端

NVIDIA Canary 通用 覆盖 25 种欧洲语言，词级时间戳

API 接口与兼容性

从别家迁移过来基本不用改代码

三种接口同时提供

  • OpenAI 兼容 REST：POST /v1/audio/transcriptions，curl / Python SDK 直接调用
  • Deepgram 兼容 WebSocket：实时流式，参数兼容 Deepgram SDK
  • 原生 WebSocket：ws://localhost:8000/asr，低延迟自定义集成

Python 示例

# OpenAI Python SDK 调用
from openai import OpenAI
client = OpenAI(
    base_url="http://localhost:8000/v1",
    api_key="unused"   # 本地服务无需密钥
)
with open("meeting.wav", "rb") as f:
    transcript = client.audio.transcriptions(model="base", file=f)
print(transcript.text)

# WebSocket 实时流
# ws://localhost:8000/asr?language=zh&diarize=true

安装与运行

pip 安装，开箱即用，后端支持多人同时使用

快速启动

pip install whisperlivekit

# 启动服务器（浏览器访问 http://localhost:8000）
wlk --model base --language en

# 指定引擎与模型
wlk run whisper:large-v3

# 文件转写（无需服务器）
wlk transcribe meeting.wav

# 生成字幕
wlk transcribe --format srt podcast.mp3 -o podcast.srt

# 模型管理
wlk models                    # 查看已安装模型
wlk pull large-v3             # 下载模型
wlk bench                     # 基准测试速度和精度

硬件配置参考

  • NVIDIA 显卡：推荐 CUDA 12.x + PyTorch，支持 Whisper/Faster-Whisper/Qwen3-ASR，显存建议 8GB+
  • 苹果芯片（MPS）：MLX Whisper 原生支持，无需额外配置
  • 纯 CPU：Qwen3-ASR 支持纯 CPU 推理，适合低资源场景
