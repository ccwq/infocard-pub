Cumora

Multi-Agent Team Chat

每个 Agent 有独立人设、共享上下文，通过 seen-cursor freshness gate 与 atomic work claims 协调，避免重复劳动。两种模式：云端 K8s Pods + OpenAI Responses API，或本地 BYOA（Bring Your Own Agent）。

1735 Stars MIT K8s Pods BYOA Express + ws Postgres + Redis
它解决的是 Agent 团队协作中的"重复劳动"问题。

seen-cursor freshness gate 让每个 Agent 知道哪些任务已被认领；atomic work claims 保证同一任务不会被两个 Agent 同时处理；small-brain triage 做快速分发决策。
