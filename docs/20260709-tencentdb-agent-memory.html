02 Core Architecture · 核心架构：分层 + 符号化

长期记忆分层（L0 → L3）：

L3 Persona · 用户画像层
跨会话用户偏好、工作流习惯、输出格式偏好。每天 48% → 76% 精准识别。
L2 Scenario · 场景块层
从对话日志中提炼可复用的解决方案模式和场景上下文（SOP / 工具惯例）。
L1 Atom · 原子事实层
对话日志中提取的原子化事实片段，作为场景块和用户画像的底层基础。
L0 Conversation · 对话日志层
原始对话记录，上下文窗口底部存档。按需检索，不主导推理。
记忆金字塔：L0 对话日志 → L1 原子事实 → L2 场景块 → L3 用户画像（来源：TencentDB-Agent-Memory 仓库）

03 Integrations · 支持的 Agent 平台
平台集成方式安装方式要求
OpenClaw 官方插件，零配置启用 openclaw plugin install @tencentdb-agent-memory OpenClaw ≥ 2026.3.13
Hermes Gateway 插件侧 Docker（绿色部署）或附加到现有实例 Hermes ≥ 0.3.4
其他 Agent SDK / 手动集成 NPM: @tencentdb-agent-memory/memory-tencentdb Node.js ≥ 22.16 
// OpenClaw 零配置启用（默认开启长期记忆）
openclaw plugin install @tencentdb-agent-memory
# 编辑 ~/.openclaw/plugins.yaml 启用：
plugins:
  @tencentdb-agent-memory:
    shortTerm:
      enabled: true
      mermaidCanvas: true
    longTerm:
      enabled: true
