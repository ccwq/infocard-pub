📌 项目定位
X @the_osps · Personal Context Gateway A modular, local-first infrastructure that exposes your personal data — files, notes, browser history, code activity, conversations — as unified semantic context via the Model Context Protocol (MCP). Any AI agent can plug into this and instantly know you.
🎯 解决的问题
每个 AI Agent 都要重新了解用户背景，token 浪费严重、上下文噪声大。Memory-MCP 把个人数据统一索引，Agent 接入即「懂你」。
🔧 技术路径
ChromaDB 向量语义搜索 + Neo4j 知识图谱双引擎，LangGraph 统一编排多源查询，FastAPI HTTP 网关 + MCP stdio 双入口。
🛡️ 隐私保证
100% 本地运行，无需任何云 API。嵌入、搜索、图谱全在本地处理。数据目录 git-ignored，凭证文件永不提交。

🧠 知识图谱特性
🔎 graph_search
查询实体及其所有关联关系，在 Neo4j 图谱中检索命名实体（人物、技术、项目、主题）。
🔗 find_connection
找两个实体间的最短路径，理解概念之间的关联距离。
📊 graph_stats
查看节点/关系统计，了解知识图谱的规模与覆盖度。
🧬 ingest_file
将文件内容提取为实体后写入 Neo4j，支持正则结构化抽取（无需 LLM）。
👤 实体识别
正则 + 模式匹配：识别人名（大小写规则）、技术词（56 个关键词库）、主题（MD 标题）、项目名、任务（checkbox）。
📈 增量图谱
增量索引：只处理新增或修改文件，不做全量重建，manifest 记录文件修改时间。
🚀 快速上手
步骤命令说明
1. 克隆安装git clone https://github.com/Shaktisinhchavda/memory-mcp.git && cd memory-mcp && uv sync需要 uv 包管理器
2. 配置cp .env.example .env默认配置开箱即用
3. 添加笔记echo "# My Ideas" > data/notes/ideas.md放入 Markdown 笔记
4. 索引笔记uv run python scripts/index_notes.py增量索引到 ChromaDB
5. 启动图谱docker compose up -d运行 Neo4j 容器
6. 构建图谱uv run python scripts/build_graph.py从笔记提取实体到 Neo4j
7. 运行 MCPuv run python core_mcp/server.pyMCP stdio 服务（Claude Desktop 用）
8. HTTP 网关uv run uvicorn gateway.server:app --port 8000FastAPI HTTP 网关，Swagger 文档在 /docs

❓ FAQ
Q: 和其他 Memory MCP 有什么不同？
不是单一功能 MCP，而是个人数据全链路整合平台。25 工具 + 6 种数据源 + 统一 LangGraph 网关，从笔记语义搜索到知识图谱路径查找全覆盖。
Q: 是否需要云服务？
完全不需要。嵌入模型（sentence-transformers）、ChromaDB、Neo4j 全在本地运行。唯一可选的是 Google Calendar OAuth（一次性配置）。
Q: 支持实时同步对话吗？
不支持实时同步。Claude 和 ChatGPT 需要导出 JSON 后放入 data/conversations/ 目录。README 说明了这是 API 限制导致的导出依赖。
Q: 增量索引是怎么工作的？
scripts/index_notes.py 和 scripts/build_graph.py 维护 manifest 文件记录每个文件的修改时间，只有新增或变化的文件才会被重新处理。使用 --force 可以强制全量重建。
Q: 实体抽取准确吗？
当前使用正则 + 结构化模式（词数、大小写、关键词库）做启发式抽取，无需 LLM。README 建议对精度要求高的场景可替换为 spaCy NER 或 LLM 抽取器。
