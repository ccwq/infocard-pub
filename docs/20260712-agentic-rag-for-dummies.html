用 LangGraph 把企业级 RAG 做成傻瓜包：分层索引、对话记忆、查询澄清、人类介入、多路并发，MIT 开源，Colab 一键跑。

Agentic RAG 是 RAG 的进化版：不再是简单的检索+生成，而是由 Agent 驱动的多阶段查询处理系统。LangGraph 负责协调状态图，实现复杂的多路并发推理。

01
分层索引

Child Chunk 精准 + Parent Chunk 完整

文档切分两次：小块精准检索，大块提供上下文。兼顾搜索精度和答案生成的上下文丰富度。

Child Chunks

小块精准匹配

小尺寸固定块，用于向量检索。精准定位答案所在段落，支持 reranker 重排序。

Parent Chunks

大块完整上下文

基于 Markdown 标题（H1/H2/H3）切分的大段。检索命中小块后，返回对应的大块用于生成。

02
四阶段查询处理

对话记忆 → 查询改写 → 查询澄清 → 并发推理

维护滚动摘要 + 最近对话历史，保留连续性而不无限膨胀上下文。

Stage 1

对话理解

维护滚动摘要 + 最近对话历史，保留连续性而不无限膨胀。

Stage 2

查询改写

将指代（"那个问题"）和省略还原为完整查询语句。

Stage 3

查询澄清

检测歧义查询，暂停询问用户细节——人类介入机制。

Stage 4

并发推理

LangGraph 协调多路 Agent 并行处理子任务，聚合结果后回答。
