02
MATRIX · MEMORY IS CONDITIONAL

量化与硬件：先做容量预算

文件大小只是起点；权重、KV cache、运行时开销与并发共同决定可用显存。

运行点优先格式容量判断适用任务警告
24GB GPUQ4 / 低上下文先留出运行时与 KV文本、代码、短视觉输入不要直接承诺 262k
48GB 级别Q5 / FP8更宽松的上下文预算多模态 Agent、长文档仍需按后端实测
80GB 级别BF16 / FP8适合服务化试验高质量、多并发探索吞吐随 batch 变化

24GB GPU · Q4

低上下文起步，文本/代码/短视觉输入；必须保留 KV 与运行时余量。

48GB · Q5 / FP8

适合多模态 Agent 与长文档探索，但仍要按后端实测。

80GB · BF16 / FP8

可做服务化试验；并发、batch 与上下文仍会改变吞吐。
