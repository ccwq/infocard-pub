01 · 核心概念
Core Concepts
One sentence

GSAP 通过 Tween（单次动画）和 Timeline（时间轴）组织动画，插件扩展能力，所有插件现已 100% 免费。

三核心架构
T
Tween（补间）单次动画，从 A 点到 B 点。
L
Timeline（时间轴）顺序组织多个 Tween，按时间排列。
P
Plugin（插件）扩展能力：ScrollTrigger、Flip、MotionPath。
插件注册规则
必须在使用插件能力前调用 gsap.registerPlugin(...)。不注册则插件不生效。
minimal workflow 
import gsap from "gsap";
import ScrollTrigger from "gsap/ScrollTrigger";
gsap.registerPlugin(ScrollTrigger);
gsap.to(".box", { x: 200, rotation: 45, duration: 1, ease: "power2.out" });
02 · Tween 四兄弟
Tween Methods
to()
从当前状态 → 目标状态
from()
从初始状态 → 当前状态
fromTo()
显式声明起止状态
set()
立即设置值，无动画
常用参数
参数说明
duration动画时长（秒）
delay延迟执行
ease缓动函数
repeat重复次数，-1=无限
yoyo来回播放
stagger批量错峰（each 毫秒）
paused创建时暂停（需 .play() 触发）
生命周期回调
callbacks 
onStart: () => console.log("start")
onUpdate: () => console.log("progress")
onComplete: () => console.log("done")
onReverseComplete: () => ...
stagger example
每项间隔 80ms，方向从 start
stagger 
gsap.from(".item", {
  opacity: 0, y: 20,
  duration: 0.4,
  stagger: { each: 0.08, from: "start" }
});
03 · Timeline 位置语法
Timeline Position
时间位置符号
符号含义
"+=0.3"当前末尾延迟 0.3s
"-=0.2"重叠前一个 0.2s
"<"紧随前一个开始
">"前一个结束后
"<0.2"前一个开始后 0.2s
">-0.1"重叠前一个 0.1s
addLabel("name")在时间轴上打标记
Timeline 实例
timeline example 
const tl = gsap.timeline({
  defaults: { duration: 0.5, ease: "power2.out" }
});
tl.from(".hero-title", { y: 30, opacity: 0 })
  .from(".hero-sub", { y: 18, opacity: 0 }, "<0.1")
  .from(".hero-cta", { scale: 0.92, opacity: 0 }, ">-0.1")
  .addLabel("ready");
Timeline 控制
timeline controls 
.play()        // 播放
.pause()       // 暂停
.reverse()     // 倒放
.seek("label") // 跳到标记
.seek(1.5)     // 跳到 1.5s
.progress(0.5) // 设置进度 0-1
嵌套 Timeline
子 timeline 可以作为父 timeline 的一步插入，实现模块化组合。
04 · 高频 Recipes
Recipes
1 · ScrollTrigger 滚动驱动
scroll-driven animation 
gsap.registerPlugin(ScrollTrigger);
gsap.to(".feature-img", {
  y: -80, ease: "none",
  scrollTrigger: {
    trigger: ".feature",
    start: "top bottom",
    end: "bottom top",
    scrub: true  // 绑定滚动进度
  }
});
2 · Flip 布局切换过渡
flip layout transition 
gsap.registerPlugin(Flip);
const state = Flip.getState(".card");
document.querySelector(".grid")
  .classList.toggle("is-expanded");
Flip.from(state, {
  duration: 0.45,
  ease: "power2.inOut",
  absolute: true
});
3 · matchMedia 响应式
responsive animation 
const mm = gsap.matchMedia();
mm.add("(min-width: 768px)", () => {
  const ctx = gsap.context(() => {
    gsap.from(".sidebar", { x: -40, opacity: 0 });
  });
  return () => ctx.revert();
});
// viewport 改变时重新生效
window.addEventListener("resize",
  () => gsap.matchMediaRefresh());
4 · 鼠标跟随 quickTo
mouse follow 
const moveX = gsap.quickTo(".cursor","x",{
  duration: 0.18, ease: "power3.out"
});
const moveY = gsap.quickTo(".cursor","y",{
  duration: 0.18, ease: "power3.out"
});
window.addEventListener("pointermove", e => {
  moveX(e.clientX);
  moveY(e.clientY);
});
05 · 插件速查
Plugins
ScrollTrigger
滚动驱动动画，接触视口时触发，支持 scrub / pin / toggleClass。
key apis 
ScrollTrigger.create()
ScrollTrigger.refresh()
ScrollTrigger.getAll()
ScrollTrigger.killAll()
Flip
DOM 布局切换过渡，拍摄旧状态 → 执行布局变化 → 从旧状态动画到新状态。
key apis 
Flip.getState(targets)
Flip.from(state, opts)
Flip.to(state, opts)
MotionPathPlugin
沿 SVG path 或 canvas 路径运动，支持沿任意曲线轨道行进。
motion path example
motion path 
gsap.to(".ball", {
  motionPath: {
    path: "#track", align: "#track",
    alignOrigin: [0.5, 0.5],
    autoRotate: true
  },
  duration: 2, ease: "power1.inOut"
});
其他插件

ST
SplitText文本拆分 chars/words/lines 做批量动画
06 · 适用场景
Use Cases
适合
1
UI 交互动画按钮反馈、菜单展开、模态框过渡。
2
滚动动画视差、进度条、视差元素、滚动触发动效。
3
SVG 路径动画描边路径、沿轨道运动、图形变换。
4
React / Vue 集成gsap.matchMedia 处理 SSR，React 18+ 兼容。
不适合
✗
纯 CSS 可完成的效果简单的 fade / slide 用 CSS transition 更轻量。
✗
3D 场景Three.js / Babylon.js 类 3D 渲染场景用 WebGL。
✗
高性能 Canvas 游戏需要 requestAnimationFrame 全控制的游戏场景。
