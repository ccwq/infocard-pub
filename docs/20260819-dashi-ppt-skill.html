工作流程

AI 生成 → 浏览器改 → 导出 PPTX

Step 1 · 描述需求
告诉 Agent 主题、受众、页数、内容重点、视觉偏好
Agent 调用 dashi-ppt skill 生成 HTML PPT
Step 2 · 浏览器直接改
每一页自带编辑控制台，不满意的地方直接在浏览器里改
所见即所得，无需重新生成
Step 3 · 一键导出 PPTX
导出成真实可编辑的 PPTX 文件，程序直接使用
离线打开、可翻页、格式保留

安装方式
一条命令安装（推荐）
# 国际网络
npx chuspeeism/dashi-ppt-skill

# 国内网络（npmmirror）
npx --registry=https://registry.npmmirror.com dashi-ppt-skill

# 查看检测到的安装位置
npx dashi-ppt-skill list

# 指定安装目录
npx dashi-ppt-skill --dir ~/.agents/skills/

# 手动安装：克隆仓库
git clone https://github.com/chuspeeism/dashi-ppt-skill
