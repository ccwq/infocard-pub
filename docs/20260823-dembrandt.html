■ 是什么：一行命令，还原设计系统

定位

开源 CLI 工具，通过 Playwright 渲染真实页面，从 DOM 计算样式中提取设计 Token，支持多种输出格式，直接用于设计系统或代码生成。

核心价值

不用 Figma 插件、不用手动整理——给一个 URL，就能拿到颜色、字体、间距、阴影、动效、组件、图标、响应式断点等完整设计语言。

技术栈

Node.js + Playwright + DOM API，MIT License，零商业依赖。

■ 工作原理：渲染 → 计算 → 评分

1
Playwright 渲染

真实浏览器渲染页面，执行 JS，加载字体与图片

2
DOM 样式遍历

遍历所有元素，收集 computedStyle，提取颜色/字体/间距/边框等

3
置信度评分

对每个 Token 评分，过滤噪音，返回高置信度结果

4
多格式输出

JSON / Tailwind / DTCG / brand-guide / design.md

为什么用 Playwright？很多设计工具只能抓静态 HTML，但真实页面的字体、颜色、阴影往往通过 CSS 变量、calc()、JS 注入——Playwright 能拿到渲染后的实际 computed value。

■ 提取能力矩阵

Token 类型 说明 输出格式
颜色（Color）主色、辅色、背景、文字、边框、渐变HEX / RGB / HSL
字体（Typography）字体族、字号、字重、行高、字间距CSS / Tailwind token
间距（Spacing）内边距、外边距，归纳为设计系统尺度数值 + 单位
边框（Border）宽度、样式、圆角、颜色CSS token
阴影（Shadow）box-shadow、text-shadow，分层归纳shadow token
动效（Animation）transition、animation、缓动函数duration / easing
组件（Components）按钮、卡片、导航等模式识别JSON 结构
断点（Breakpoints）响应式断点与对应布局特征CSS media query
图标（Icons）SVG 内联图标、icon font 提取SVG / sprite

■ 命令行用法

基础提取

dembrandt dembrandt.com

仅输出 JSON

dembrandt url --json-only

保存到文件

dembrandt url --save-output

DTCG 格式

dembrandt url --dtcg

暗色模式

dembrandt url --dark-mode

移动端渲染

dembrandt url --mobile

慢速动画

dembrandt url --slow

品牌指南

dembrandt url --brand-guide

Design.md

dembrandt url --design-md

深度爬取

dembrandt url --crawl N

WCAG 可访问性

dembrandt url --wcag

Tailwind 输出

dembrandt url --tailwind
安装：npm install -g dembrandt — 全局安装，无需项目依赖。

■ 安装与快速上手

npm install -g dembrandt
dembrandt dembrandt.com
dembrandt https://example.com --json-only --save-output
注意：darkblue 不是有效主题。dembrandt 支持暗色模式抓取（--dark-mode），但这是指提取暗色主题页面的 Token，而非输出报告主题色。

■ 输出格式对比

格式 用途 对应 Flag
JSON程序化消费、设计系统存储--json-only / --save-output
DTCG（Design Token Community Group）跨工具互操作，Style Dictionary 等--dtcg
Tailwind Config直接注入 Tailwind CSS 项目--tailwind
Brand Guide品牌视觉规范文档--brand-guide
Design.mdMarkdown 格式，人类可读的设计文档--design-md

■ WCAG 可访问性检查

颜色对比度

自动检测前景/背景颜色对比是否满足 WCAG AA（4.5:1）或 AAA（7:1）标准。

文本大小

检查最小字体大小是否达到可访问性要求。

交互元素

按钮、链接等可交互元素的尺寸与间距是否满足触摸友好标准。
