02neo-mcp 是什么
MCP 桥接器：编辑器 ↔ 远程 AI 工程师

neo-mcp 是 MCP（Model Context Protocol）服务器，将 Claude Code / Cursor / VS Code 等编辑器直接连接到 Neo 远程 AI 工程师引擎。提交任务后，远程 Agent 执行，结果文件直接写入本地 workspace，不经过任何中间存储。

11 个工具

任务提交 / 状态查询 / 消息拉取 / 反馈发送 / 暂停 / 恢复 / 停止 / 集成管理

本地执行

Daemon 运行在本地机器，生成文件直接落 workspace，无远程存储

多编辑器支持

Claude Code / Cursor / VS Code / Windsurf / Zed / Continue / Codex CLI

Token 上限

单次输出约 20,000 tokens，长任务自动分片

03neo-mcp 核心工具（11 个）
工具名作用典型场景
neo_submit_task 向 Neo 引擎提交任务，返回 task_id 发起代码生成 / 重构 / 文档任务
neo_list_tasks 列出当前活跃和历史任务 查看所有在途任务
neo_task_status 查询单个任务当前状态 轮询任务进度
neo_get_messages 拉取任务执行过程中的消息流 实时看 Agent 思考过程
neo_send_feedback 向 WAITING_FOR_FEEDBACK 状态的任务发送人工反馈 批准方案 / 修改指令 / 重定向方向
neo_pause_task 暂停正在运行的任务 临时中断，等待确认
neo_resume_task 恢复已暂停的任务继续执行 确认后继续自动执行
neo_stop_task 终止任务（TERMINATED 状态） 任务跑偏，立即停止
neo_list_integrations 列出当前已配置的外部集成 查看已连服务
neo_add_integration 新增外部服务集成（如 GitHub / HuggingFace） 扩展 Agent 能力边界
neo_test_integration 测试集成连通性 验证配置是否正确
neo_remove_integration 移除已配置的集成 清理失效配置
任务状态流转
RUNNING → WAITING_FOR_FEEDBACK → PAUSED → COMPLETED / TERMINATED

WAITING_FOR_FEEDBACK 是核心人机协作节点：Agent 在关键决策点暂停，等待人工确认后才继续。发送 neo_send_feedback 推进流程。

04neo-mcp 安装与配置
Step 1 — pip 安装
# 安装 neo-mcp pip install neo-mcp # 验证安装 python3 -m neo_mcp --help
Step 2 — 获取 API Key
# 访问 heyneo.com/dashboard 获取 API Key # 格式：sk-v1-... # 妥善保管，不要提交到 Git
Step 3 — MCP 注册（Claude Code）
# 方式 1：直接调用 neo-mcp 命令 claude mcp add --scope user neo \ -e NEO_SECRET_KEY=sk-v1-YOUR_KEY -- neo-mcp # 方式 2：显式 python3 调用 claude mcp add --scope user neo \ -e NEO_SECRET_KEY=sk-v1-YOUR_KEY -- \ python3 -m neo_mcp # 验证注册成功 claude mcp list
⚠️ 注意事项

API Key 通过 -e NEO_SECRET_KEY=... 注入环境变量，不要硬编码在命令历史中。建议配合 .zshrc alias 或密钥管理工具使用。

11注意事项
Token 上限 20K

单次输出约 20,000 tokens。长任务自动分片，需多次轮询 neo_task_status 获取完整结果。

WAITING_FOR_FEEDBACK 机制

Agent 在关键节点暂停等待人工反馈。不响应则任务持续等待，不会超时自动继续——需主动调用 neo_send_feedback 推进。

新 Session 才加载工具

neo-mcp 工具在 Claude Code 新会话启动时加载。如遇工具不可用，先退出再重新进入，或运行 claude mcp list 检查注册状态。
