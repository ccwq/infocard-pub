核心差异
Query Loop vs Thread/State · 委派验证模型
最核心的差异在于：Claude Code 用 Query Loop 做控制流，而 Codex 用 Thread/State。这是两种完全不同的 Agent 运行时的根本分歧。

Claude Code · Query Loop

工具模型：沙箱 + Policy 分层

验证：委派验证模型
扩展：API-first + 外部 Hook 集成
