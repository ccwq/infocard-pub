「搜索即高亮，滚动无卡顿」
Dataset Viewer 是一款面向大数据场景的本地轻量文件浏览器，基于 Tauri + React 构建，专注解决大文件秒开与高效检索问题。

当你需要查看几十 GB 的数据集时，传统工具往往卡顿或直接崩溃。Dataset Viewer 通过 Rust 后端的分块懒加载与异步流式 IO，让 88 GB 文件实现秒开、顺滑滚动；内置毫秒级搜索，支持关键词定位与高亮；无需解压即可直接浏览 ZIP/TAR 压缩包内容；针对 Parquet、Excel、CSV 格式做了专项优化；还支持 WebDAV、云存储和 HuggingFace 数据集直连。界面支持深色/浅色模式切换与多语言。

技术背景：Tauri + Rust

Rust 后端负责文件 IO 与分块调度，React 前端负责渲染与交互，Tauri 桥接两端。相比 Electron，体积更小（~10 MB 安装包），内存占用更低，启动更快。

03
使用方式 · HOW TO USE

快速上手 & 云存储接入

本地文件直接打开，云存储通过 WebDAV 或 HuggingFace 数据集 URL 直连。

本地文件

直接拖拽或文件选择器打开本地文件，支持超大地文件即开即浏览。

压缩包浏览

打开 ZIP 或 TAR 压缩包，无需解压，直接流式浏览内部文件列表与内容。

云存储（WebDAV）

配置 WebDAV 端点 URL，直接浏览远程服务器上的数据文件，适合 NAS 或私有云场景。

HuggingFace 数据集

输入 HuggingFace 数据集名称或 URL，Dataset Viewer 直接从 HF Hub 拉取并展示数据，无需本地下载。

界面特性

深色 / 浅色模式一键切换，多语言界面（英文/中文等），简洁无广告。
