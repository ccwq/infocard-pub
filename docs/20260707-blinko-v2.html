项目描述

Blinko 是一款专为灵感捕捉而生的 AI 增强笔记工具。用 Tauri 构建，采用原生 Markdown 编辑体验，支持自然语言 AI 检索（OpenAI / Claude / Ollama），数据完全自托管，Docker 一键部署，响应式覆盖 macOS、Windows、Android、iOS 全平台。

# notes # AI search # Markdown # self-hosted # open source # productivity # Docker # Ollama
亮点功能
🤖
AI 增强检索
用一句话把想要的内容搜出来。内置 RAG（检索增强生成）引擎，支持 OpenAI、Claude、Ollama 等主流 LLM，无需标签分类，自然语言直达笔记。
🔒
完全自托管
所有笔记和数据存储在自己的服务器或本地设备上，不依赖任何云服务，数据 100% 自己掌控，隐私安全无忧。
✍️
原生 Markdown
写得快，排得好，分享也方便。支持完整 Markdown 语法，实时预览，碎片化记录灵感，大幅提升写作效率。
⚡
轻量高性能
Tauri 架构带来极低的资源占用，启动快速，运行稳定，对硬件要求低，一台小机器甚至树莓派都能流畅运行。
📱
响应式全平台
界面自适应 macOS、Windows、Android、iOS 设备，桌面端原生应用，移动端自适应布局，随时随地记录与查阅。
🐳
Docker 一键部署
一行命令拉起完整环境，装好就能用。官方提供 PikaPods 一键托管，零运维门槛，快速拥有自己的专属笔记服务。
技术栈
TypeScript Next.js Tauri Rust Docker SQLite Node.js RAG / Ollama OpenAI API Claude API

Blinko 基于 Tauri 2（Rust 后端 + Web 前端）构建，前端采用 Next.js + TypeScript，数据存储在本地 SQLite，配合 RAG 引擎实现 AI 语义检索，可接入 OpenAI、Claude 或本地 Ollama 模型。

快速部署
$ curl -s https://raw.githubusercontent.com/blinko-space/blinko/main/install.sh | bash

# 或手动 Docker 部署
$ docker run -d \
  --name blinko \
  -p 3000:3000 \
  -v ~/blinko_data:/app/data \
  blinkospace/blinko:latest

# 访问 http://localhost:3000
