它解决什么问题

同一句“手绘风、温馨一点”，换一个模型或换一次生成，画风可能就漂移。handraw-style 把风格选择改成可复用的编号系统：先从画廊挑一个风格编号，再给出带风格名称的中文与英文提示词，让不同主题尽量沿用同一套视觉气质。

核心工作流

  1. 先浏览风格画廊，按类别和样图判断视觉方向。
  2. 记录一个风格编号，例如 041；编号成为团队共享的视觉短名称。
  3. 输入“风格编号 + 主题”，生成带风格名称的中英文提示词。
  4. 把提示词复制到手头的生图模型；如果模型无法仅凭风格名称稳定复现，再补充对应样图。
  5. 把选定编号写入内容生产规范，后续文章、公众号和社媒配图沿用。

内容规模与组织方式

  • 公开介绍显示，项目整理了 216 种手绘风格，每种风格有编号和样图。
  • 风格被组织为 7 大类，覆盖国际社论漫画、国际绘本、日本当代插画、中国当代插画等方向。
  • 编号降低了沟通成本：团队不必反复描述“像哪位作者”，而是共享一个可检索的风格入口。
  • 输出同时包含中文和英文提示词，便于在不同模型或不同工作流中复用。

为什么要按能力决定是否传参考图

直接上传参考图可能让模型同时锁定主体、构图和风格，反而限制主题变化。更稳妥的策略是先判断当前模型能否仅凭风格名称画出目标气质；可以时只传文字，无法稳定复现时再传对应样图。这样把参考图当作风格校准工具，而不是默认的构图模板。

适合场景与边界

  • 适合公众号、小红书和文章配图，需要长期保持统一视觉气质的个人或团队。
  • 适合把“审美偏好”沉淀成编号规范，减少每次重新试错。
  • 不等于自动保证不同模型输出完全一致；模型能力、提示词长度和参考图处理仍会影响结果。
  • 使用第三方艺术家风格或样图时，应关注授权、署名和平台政策，不要把编号系统误当作版权许可。
