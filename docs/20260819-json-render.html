是什么

json-render 是 Vercel Labs 推出的生成式 UI 框架：AI 生成 JSON spec，你的组件渲染 UI。不是 iframe、不是 markdown、不是生成代码——AI 只决定结构，组件完全受你控制。

01
四步工作流
1
定义 Catalog
声明 AI 可用的组件、props schema、actions
2
自然语言 Prompt
告诉 AI 你想要什么 UI，如"展示销售仪表盘"
3
AI 生成 JSON
输出被 Catalog 约束的 Spec，结构完全可预测
4
组件渲染 UI
Registry 映射 JSON → 你的原生组件，流式渲染
Catalog 示例

定义 AI 可用的组件和 Props

@json-render/core
import { defineCatalog } from '@json-render/core';
import { schema } from '@json-render/react/schema';
import { z } from 'zod';

export const catalog = defineCatalog(schema, {
  components: {
    Card: {
      props: z.object({ title: z.string() }),
      slots: ["default"],
    },
    Metric: {
      props: z.object({
        label: z.string(),
        value: z.string(),
        format: z.enum(["currency", "percent", "number"]).optional(),
      }),
    },
  },
  actions: {
    navigate: { params: z.object({ href: z.string() }) },
    submit: { params: z.object({ data: z.record(z.string()) }) },
  },
});

关键概念

Catalog / Registry / Spec 三层分离

Catalog
声明 AI 可用的组件、actions、validation functions
这是 AI 和你的 App 之间的契约
Registry
将 Catalog 类型映射到平台特定实现
React 组件在 Web，React Native Views 在 Mobile
Spec
AI 生成的 JSON 输出，平坦的元素树
带类型 props、children、data bindings、visibility conditions
SpecStream
流式 Spec 推送，边生成边渲染
每个 JSONL patch 实时更新 UI
高级能力

Data Binding · Visibility · Generation Modes

$state 绑定
props 绑定运行时 state，$item / $index 遍历数组
双向输入绑定，组件状态完全受控
Visibility 条件
基于 state 条件显示/隐藏元素
AI 生成条件 UI，无需写逻辑代码
Standalone 模式
全页面生成 UI
适合全新的页面级生成
Inline 模式
对话中嵌入生成 UI
适合 Chat 界面里的动态卡片

安装与快速开始
安装
# 克隆并安装依赖
git clone https://github.com/vercel-labs/json-render
cd json-render
pnpm install

# 或 npm 安装核心包
npm install @json-render/core @json-render/react

# 启动示例
pnpm dev
