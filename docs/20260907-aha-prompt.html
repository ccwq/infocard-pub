04Prompt 记录与迭代规范
记录项示例为什么重要
模型Seedance / GPT Image 2 / Minimax H3模型能力和 prompt 语法不能默认互换。
输入素材参考图、视频、音频是否被使用参考素材改变模型对主体和构图的理解。
生成设置比例、时长、分辨率、种子、变体数不记录设置，就无法解释两次结果的差异。
修改点只改主体、镜头、光线还是限制词单变量迭代才能形成可复用经验。
验收结论哪些要求通过，哪些失败，下一步改什么把"灵感收藏"变成可执行的创作记录。
05常见失败与排查
现象先检查下一步
复制后结果完全不同模型、输入素材、比例和时长是否一致恢复 baseline，只改一个变量。
视频动作跳变时间线是否过密、镜头是否互相冲突减少镜头数，明确起点、动作和终点。
人物或产品漂移参考图、主体描述和每个镜头的身份锚点减少新描述，重复关键身份特征。
文字 / Logo 错误模型文字能力、输入图和品牌授权生成结果当草稿，后期人工校正，不直接用于正式发布。
声音不符合预期是否写明音色、节奏、环境声和禁止音乐先单独验收音频，再判断整体视频。
找不到合适 prompt是否只按关键词搜，没按模型/媒体/场景筛选回到模型目录和分类页，先选工作流再选句子。
06权利与安全边界

平台内容：公共 prompt 可免费浏览和复制；商业使用需确认具体授权条款，部分 prompt 可能有使用限制。

生成结果权利：生成内容的版权归属取决于模型供应商协议和适用法律，平台不提供法律保证。

第三方风险：包含人物、品牌、商标或版权素材的 prompt，生成结果用于商业用途前需自行评估法律风险。

模型供应商条款：各模型（OpenAI、Google、Minimax 等）的服务条款对生成内容的商业可用性有不同规定，使用前需分别确认。
