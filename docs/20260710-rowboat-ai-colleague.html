01 问题定义：AI 同事为什么记不住
😤
每次开局重新喂料
AutoGPT、BabyAGI 等每次任务都从零开始，昨天的上下文全部丢失，无法跨任务积累。
🔒
数据必须上云
大多数 AI 助手要求数据上传到第三方服务器处理，隐私敏感场景（公司内网、客户数据）完全无法使用。
🧩
工具之间互相割裂
邮件、会议、Slack、文档分散在各个平台，AI 无法跨平台建立关联，知识永远是碎片化的。

04 模型选择：免费白嫖 or 强力云端
🖥️

完全免费，数据全在本地，支持各类开源模型（Llama 3、Qwen、Mistral 等），零 API 费用。

💾
LM Studio
桌面端本地模型运行器，支持 GGUF 格式模型，图形化调参，本地推理完全离线。

Hosted 模型
接入 OpenAI、Anthropic、Google 等云端 API，适合需要更强推理能力的复杂任务。
高性能
05 vs 竞品：为什么 Rowboat 不一样
✅ Rowboat
记忆永久本地知识图谱，跨任务积累
数据Markdown 本地存储，100% 隐私
模型Ollama 完全免费，或自选 API
集成MCP + Composio + 邮件 + 会议 + Slack
自动化后台静默运行，定时 + 事件触发
❌ AutoGPT / BabyAGI
记忆每次任务从零，无跨任务积累
数据通常需要 API key，数据上传云端
模型仅支持 OpenAI 等云端 API
集成工具少，邮件/会议无原生支持
自动化无后台静默模式，纯手动触发
06 快速启动 
git clone https://github.com/rowboatlabs/rowboat
cd rowboat
npm install

# 首次启动（自动打开浏览器配置）
npm start

# 连接 Ollama 本地模型
# 在设置中填写 Ollama 地址（默认 localhost:11434）
Google 服务配置：
执行 Google setup 文档指引，接入 Gmail + Calendar + Drive。Rowboat 不会存储你的 Google 凭据。
本地模型推荐：
Ollama 默认端口 11434，首次使用需先运行 ollama serve。
MCP 配置~/.rowboat/config/composio.json
数据存储~/.rowboat/（Markdown 文件）
