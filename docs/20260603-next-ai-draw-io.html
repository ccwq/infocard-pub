核心功能
Core Features
01

自然语言图表生成

直接用自然语言描述需求，AI 自动生成 draw.io 格式的图表。Transformer 架构、云架构、流程图、RAG 架构均可。

  • 支持英文 / 中文 / 日文 Prompt
  • 输出标准 draw.io XML
  • 可导出 SVG / PNG / PDF
Prompt 示例：Transformer architecture with animated connectors
02

MCP 协议接入

作为 MCP Server 运行，支持 Claude Desktop / Cursor / VS Code 等主流 AI 开发工具直接调用图表生成能力。

  • npx 一键安装
  • Claude Code CLI 直接集成
  • 支持 MCP Tools 批量生成
npx @next-ai-drawio/mcp-server@latest
03

图像 → 图表复制

上传现有图表或截图，AI 自动理解并重新生成 draw.io 格式文件。适用于旧图迁移和格式升级。

  • 支持 PNG / JPG / SVG 上传
  • 保留原始布局和样式
  • 批量转换多个文件
适用场景：旧 Visio 图迁移 / 论文插图重绘
04

PDF / 文档图表化

上传 PDF 或文本文件，AI 自动提取内容并生成对应架构图、流程图、数据流图。

  • 自动解析 PDF 文本块
  • 支持技术文档白皮书
  • 保留引用关系和层级
适用场景：方案评审 / 技术文档可视化

05

云架构图专项

专为 AWS / GCP / Azure 架构图设计，支持组件图标自动识别、连线标注、区域分组。

  • AWS 组件库自动渲染
  • GCP BigQuery / Cloud Run 等
  • Azure 微软云全组件
  • 多云混合架构支持
Prompt 示例：Serverless architecture using AWS
06

AI 推理过程可视化

对于支持模型（GPT o1/o3、Gemini、Claude 等），可展示 AI 生成图表的推理思考过程。

  • 显示模型思考链路
  • 便于审核图表生成逻辑
  • 支持调试 Prompt 策略
适用场景：模型评估 / Prompt 优化迭代
07

版本历史追踪

每次 AI 编辑自动生成版本快照，支持随时回滚到历史版本，避免误操作导致图表丢失。

  • 全量版本快照
  • 一键恢复任意版本
  • 版本对比差分显示
适用场景：团队协作 / 多人编辑场景
08

动画连接器

支持在图表元素之间生成动态箭头和动画连线，让架构图、流程图具备动态演示效果。

  • Transformer 数据流动画
  • 时序图动画连线
  • 导出 GIF / MP4
Prompt 示例：Animated transformer connectors diagram
MCP 接入配置
Claude Desktop / Claude Code
mcpServers 配置
{
  // Claude Desktop ~/Library/Application Support/Claude/claude_desktop_config.json
  "mcpServers": {
    "drawio": {
      "command": "npx",
      "args": ["@next-ai-drawio/mcp-server@latest"]
    }
  }
}
Claude Code CLI
claude mcp add drawio -- npx @next-ai-drawio/mcp-server@latest
