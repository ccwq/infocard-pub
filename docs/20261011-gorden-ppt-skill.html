核心技术

非破坏性编辑原理

edits.json 字段驱动 python-pptx build，模板 layout 完整保留，不覆盖背景/版式

🏗️ 什么是非破坏性编辑

传统 PPT 生成工具"填内容 → 覆盖版式"；GordenPPTSkill 是"读模板 → 只改文本 → 输出"。模板的背景、版式、图形元素全部保留，只替换文字节点。

非破坏性Layout 保留Text-only

📄 edits.json 示例

{ "slides": [{"index": 0, "elements": [ {"placeholder": "title", "text": "2026 Q1 工作汇报"} ]}] }
为什么重要？ 传统 AI PPT 工具会覆盖背景、破坏排版、丢失字体信息。
GordenPPTSkill 只用 shape.text_frame.paragraphs[0].text = "新文字" 替换文本节点，模板的母版（master）、版式（layout）、背景（background）完全不受影响。结果像专业设计师做的真实 PPT，而非 AI 随意拼接的图。

术语表

核心概念解释

edits.json / python-pptx / 非破坏性编辑 / Skill 自动更新 / 微软雅黑 / 非商业使用

edits.json

GordenPPTSkill 的核心输入文件，JSON 格式，描述在哪一页的哪个占位符填什么文字。Agent 只需生成这个文件即可，不需要写代码。

python-pptx

Python 库，用于程序化创建和编辑 PowerPoint 文件（.pptx）。GordenPPTSkill 基于此库实现非破坏性编辑，只替换文本节点，不改变模板的母版、版式和背景。

非破坏性编辑

编辑策略：只修改文本内容，保留模板的背景图、版式布局、颜色主题、字体样式不变。与"覆盖式生成"（AI 随意拼接）相对，结果更像专业设计师做的真实 PPT。

Skill 自动更新

GordenPPTSkill 内置的增量更新机制：updates.json 记录变更列表，manifest.json 记录每文件 SHA256，scripts/update.sh 对比并下载增量更新。相当于 Skill 像软件一样可以自动升级模板库。

微软雅黑字体兼容

模板大量使用「微软雅黑」（Microsoft YaHei）字体。用户需确保本地安装，或通过 fontconfig 配置备选字体（如 Noto Sans CJK），否则中文显示可能降级。

非商业使用

当前许可证为 NOASSERTION（无明确授权），明确禁止商业用途、二次分发。个人学习研究可用，商业场景需联系作者（微信 duge360）获取授权或定制私有模板。
