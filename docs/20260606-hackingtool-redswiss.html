03 · 安装方式
一键安装（推荐）

curl 一行命令

curl -sSL https://raw.githubusercontent.com/Z4nzu/hackingtool/master/install.sh | sudo bash

自动处理依赖、clone、venv 和启动器配置。

手动安装

git clone + python3

git clone https://github.com/Z4nzu/hackingtool.git
cd hackingtool
sudo python3 install.py
hackingtool

适合有特殊路径或隔离环境需求的用户。

Docker 部署

隔离环境跑全套工具

# 构建
docker build -t hackingtool .

# 推荐用 Compose
docker compose up -d
docker exec -it hackingtool bash

# 停止
docker compose down

06 · 边界与注意事项
⚠️ 法律边界

仅限授权测试，禁止未授权使用

README 明确声明"For authorized security testing only"。在未获得明确书面授权的系统上使用这些工具，可能构成刑事犯罪。

使用前必须：获得书面渗透测试授权书、明确测试范围和免责条款、遵守当地法律法规。
