06 快速上手 SOP
curl -fsSL https://get.casaos.io | bash
STEP 1
准备硬件：树莓派 4 / NUC / 旧笔记本（1GB+ RAM，8GB+ 存储），安装 Debian / Ubuntu 或 Raspberry Pi OS
STEP 2
运行安装脚本：SSH 登录后执行上方命令，30 秒自动完成 Docker + CasaOS 全部部署
STEP 3
打开 Web UI：浏览器访问 http://[设备IP]:80，默认账号 admin
STEP 4
挂载硬盘：在 UI 的「存储」→「磁盘」里挂载外接 USB 硬盘作为主存储
STEP 5
安装应用：进入「应用商店」，搜索 Jellyfin / Immich / Nextcloud，点「安装」坐等启动
STEP 6
远程访问：开启CasaOS内置的 Cloudflare Tunnel 或 Tailscale Zero-Trust，无需公网 IP 即可外网访问
# 完整卸载（如需重来）
curl -fsSL https://get.casaos.io/uninstall.sh | bash
