last30days
Skill

把 Reddit、X、YouTube、Hacker News、Polymarket 和 Web 的近 30 天信号并行拉齐，再由 agent judge 合成 grounded summary；它不是传统搜索结果页，而是一个研究“人们最近怎么说”的信号引擎。

传统搜索 vs last30days
传统搜索

先看网页排名，再猜人群怎么想；信息常常是编辑筛过的、延迟的、零散的。

last30days

先找 Reddit / X / YouTube / HN / Polymarket 的实时参与，再把高频信号合成一份研究 brief。

输出形态

不是链接堆，而是可直接给人看的结论、对比、风险和下一步动作。

“Google aggregates editors. /last30days searches people.”

它把平台里的 upvotes、likes、views 和 real money 变成可比信号，再交给 agent 去归纳：这件事最近到底热不热、谁在说、说法有没有共识。
01 · 搜索面平台并行

Reddit、X、YouTube、HN、Polymarket、GitHub、Web 同步开搜，避免单一来源偏见。

02 · 评分面按人群参与打分

用 upvotes、likes、views、real money 之类真实参与度，而不是只看 SEO 排名。

03 · 合流cluster merging

同一件事出现在多个平台时先合并，再提炼 “best takes” 与共同判断。

04 · 交付一份 brief

结果不是搜索列表，而是一页 grounded summary，支持 plain text 和 shareable HTML brief。

为什么值得用
why this exists
A
先看“人们最近怎么说”

它特别适合需要快速摸清社媒风向、社区共识和争议点的场景，而不是只查官方文档。

B
把临时信号变成可复述判断

从碎片化帖子、长视频、评论和预测市场里提炼出能给同事复述的短结论。

C
把研究前置到行动前

见人、见客户、看项目、追热点、做工具对比前，先跑一轮 last30days，减少盲区。

一句话定位：Google 给你“网页”，last30days 给你“近 30 天的人群信号”。
v3 的新东西
what changed in v3

Shareable HTML briefsemit=html

可以把研究结果保存成自包含的 HTML brief，适合 Slack、Email、Notion 或离线阅读，不需要原始 markdown。

Intelligent searchentity resolve

先识别人物、社区、产品和话题，再决定去搜哪些平台；不是关键词暴力搜索，而是实体驱动的预检索。

Best Takessecond judge

在相关性之外，再用幽默、机锋、传播性去筛选最值得分享的句子，最后一屏更像“结论 + 记忆点”。

Single-pass comparisonsvs mode

比较多个对象时不再串行跑三次，而是一次并行展开，适合 OpenClaw vs Hermes vs Paperclip 这种对照任务。

变化的核心：从“多平台搜一下”升级成“先理解实体，再聚合人群信号，最后输出能直接转述的研究 brief”。
适合谁 / 不适合谁
fit & boundary
适合good fit

会前准备、销售前调查、工具对比、热点追踪、旅行/活动前风向判断、追一个新 topic 的一手社区意见。

不适合not for

单纯查一个稳定事实、只看官方文档、需要严格法务/合规证据链的场景；它更像研究助理，不是裁判系统。
