01三条管线 · PIPELINES

从「录屏将就」到「逐帧确定性」到「多模型协作」

claudevideo.org 把 374 个案例归成三条管线，区别在时序控制精度与工作量。计时敏感就上管线二；要人物实拍就叠管线三。

管线做法适用 / 短板
① 一枪页面 + 录屏让 Claude 出一个自包含动画 HTML，浏览器打开直接录屏最快，一句话 showreel 的天然形态；时序看机器脸色，默认无音频
② Agent + 渲染框架Claude Code 建项目：HyperFrames（HTML→MP4）或 Remotion（React→MP4），逐帧确定性截取30 秒每次都精确 30 秒，改动即重渲染；产品发布视频多用 HyperFrames，AI 叙事史、角色短片多用 Remotion
③ 多模型协作Claude 当导演写脚本与动画；ElevenLabs/Kokoro/Gemini TTS 配音，音乐模型或代码生成配乐，图像/视频模型补实拍，FFmpeg 拼装长片与商业成片；难点是同步——先生成配音读回时间戳，再对着时间戳写动画
WHY IT WORKS

为什么效果出乎意料

动效设计的本体就是布局、字体、缓动曲线、时序——恰好是 CSS 和 JS 能精确表达的东西。Claude 见过海量前端代码；Opus 5.5 的变化按创作者说法是品味：节奏、缓动、克制感看起来是「设计出来的」而不是「生成出来的」。

引爆全网的 86 连变体

02推文四打法核验 · VERIFIED RECIPES

①② UI 动效与 3D 质感：推文声明逐条对官方素材

RECIPES ① · UI MOTION

Dribbble 级 UI 动效与产品演示

载体 HTML + CSS + SVG。推文称「用弹簧公式算动画，用 Python 提前抓音频节拍，光标每次点击拖拽踩在拍子上，干翻 AE 调关键帧」——对应 Remotion 的 spring() 物理弹簧与 claudevideo.org 管线三的「音频节拍时间戳回喂」实操；弹簧参数即品味词汇：低 damping=弹、高 damping=稳、高 stiffness=脆。

RECIPES ② · 3D & SHADER

电影感 3D 与显卡质感

Three.js + WebGL 着色器，零模型文件：代码直接在空间里搭 3D Logo、粒子云、老电视扫描线、胶片颗粒，镜头 360 度推拉摇移。代码画的是形状、文字与几何体——这正是官方明确的能力边界内（几何/文字/3D），不含实拍。

RECIPES ③ · COMMERCIAL

商业短片：视频模型 + 代码包装

推文称「最成熟的商业成片方案」：人物写实动作交给视频模型（如 Grok 出绿幕人物），背景、3D 动效、文字排版、分屏交给代码抠像合成——对应官方管线三「图像/视频模型补 code 画不好的部分」，两头各拿所长：写实与可控全都要。

RECIPES ④ · LONG FORM

几分钟科普长片：Remotion 编排

在 Claude Code 里用 Remotion 编排多场景分镜（Sequence 组件），配 TTS 语音与代码合成配乐，几千帧动画自主跑通。官方提醒：超过一两分钟，连贯性靠你给结构——场景清单、脚本、风格指南。

04代码词典 · 核心 API 与感受词对照

你只需要说「感受」，Claude 负责翻译成数学

CORE API

Remotion 四件套

useCurrentFrame() 帧号从 0 起算；useVideoConfig() 取 fps/时长/宽高；interpolate(frame,[0,15],[0,1],{extrapolateRight:'clamp'}) 线性映射；spring({frame,fps,config:{mass,stiffness,damping}}) 物理弹簧。组件加 <Sequence from={60} durationInFrames={90}> 即分镜编排。

FEEL → MATH

感受词翻译表

bouncy 弹 = 低 damping spring；smooth/professional 顺 = 高 damping；snappy 脆 = 高 stiffness；floaty 飘 = 慢速轻动；punchy 冲 = 快进略过冲。你说「标题打字太慢」Claude 改 charFrames 3→2——技术细节全程不碰。

COST MODEL

按 token 计费，不按秒

15 秒自包含动画 ≈ 几千到几万 output token，$20/M 单价下是几美分；订阅额度内即免费。成本随迭代涨：Remotion 项目多轮预览修改可达几十万 token；配音/音乐/图像模型各自另计。

ECOSYSTEM

全家桶周边

Claude-Code-Video-Toolkit（Remotion+Manim+Playwright 录屏+FFmpeg 后期）；digitalsamba toolkit（/video /record-demo /brand 命令 + 9 复用组件 + 7 转场 + 品牌 profile）；wshuyi/remotion-video-skill（场景化 + TTS 自动 timing）；Manim 插件走 3Blue1Brown 风数学动画。

TERMS

词汇表

确定性渲染：框架控制时钟，逐帧「画第 1 帧→截→画第 2 帧→截」，不吃实时播放性能。Composition：Remotion 的视频定义 = React 组件 + 宽高/fps/帧数元数据。绿幕抠像：视频模型出纯色背景人物，代码按色键抠除换背景。HyperFrames：HTML/CSS/可 seek 的 JS 动画 → MP4 的确定性框架，自带 coding agent skills。弹簧动画：用质量/刚度/阻尼三参数模拟物理减速，比手调关键帧更接近真实运动。
