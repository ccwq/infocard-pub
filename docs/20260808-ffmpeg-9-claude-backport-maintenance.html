02 · RELEASE BRANCH
L1 POLICY

Backport 是受约束的维护动作

A
选择性 cherry-pick官方说明 release branches 只从开发分支挑选变更；开发分支会更快获得修复、功能和安全补丁。
B
只收 bug fixFFmpeg 的公开 backport policy 要求 release branch 回移只限 bug fixes，不得增加或删除 API。
C
FATE 必须通过候选回移仍需经过项目测试门槛；“发现候选”与“获准进入 release”是两个不同动作。
