6 大核心功能：
① HTTP hooks 直连 Claude Code — 零延迟事件流
② Codex rollout tailing — ~/.codex/sessions/**/rollout-*.jsonl
③ 交互画布 — pan/zoom/点击节点查看详情
④ 多会话追踪 — tabs 管理并发 session
⑤ Timeline + Transcript — 完整执行时间线 + 文件热力图
⑥ JSONL replay — 指向任意事件日志回放或实时监控
