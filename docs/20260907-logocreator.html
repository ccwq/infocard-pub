QUICK START

三步上手

从获取 API Key 到生成第一张品牌标志，只需三步。完全免费，无需注册。

获取 Key

获取 Together AI API Key

在 together.ai 获取免费额度或付费 Key，LogoCreator 使用 Flux 模型驱动图像生成。

提示：Together AI 有免费试用额度，个人使用足够。
安装

安装并配置

克隆仓库，设置 API Key 环境变量，运行服务即可。

git clone https://github.com/Nutlope/logocreator
cd logocreator
export TOGETHER_API_KEY="your-key"
npm install && npm run dev
生成

输入品牌名并生成

在浏览器中打开，输入品牌名称，一键生成多种风格方案，选择满意版本下载。

支持 SVG、PNG 多种格式导出，直接用于产品和营销。
