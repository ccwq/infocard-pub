让 Agent 面对模糊 PRD，向隐藏规格的 User Agent 提问，再在容器中实现项目并接受四类评测。

01

已确认的核心事实

按官方文档、Release 或仓库 README 逐条落地。

FACT 01

事实 1

项目 README 宣称包含 480 个匿名任务、12 种编程语言和交互式 Oracle。

FACT 02

事实 2

Agent 可在查询预算内向隐藏规格的 User Agent 澄清缺失需求。

FACT 03

事实 3

评分包括动态测试、结构相似度、Critic Review 与交互质量。

02

落地时不要混淆

把工具能力、项目自述和可验证边界分开。

BOUNDARY 01

边界 1

这类基准测的不只是代码生成，还测需求发现和提问质量。

BOUNDARY 02

边界 2

README 同时提供 lite/full 模式；不要把默认 smoke test 当成全量 480 任务结果。

BOUNDARY 03

边界 3

配置中的模型、网关和权限示例仅用于说明，不能把凭据写入项目。
