01 一种玩法 · 给一个人的公司组一支 Agent 队伍

打开 Memory Hub，建一个 Team：让一个 Owner（人）加三个 Agent 角色，由 Agent Memory 让经验留在队伍里。 

Tiny but Serious Inc.
├── 👤 You · 定目标 / 做判断
├── 🔭 Scout · 查资料 / 找机会
├── 🛠 Builder · 写代码 / 做产品
├── 🧪 Reviewer · 测试 / 挑毛病
└── 🧠 Agent Memory · 让经验留在队伍里

先招人，然后配装备（不同 Loadout）

情报侦察

经验复利：不同角色、不同 Loadout。少给噪音，多给完成工作真正需要的记忆。"公司可以很小，经验可以一直复利。"
02 四类记忆资产 · 不是聊天记录仓库

RAG 解决"能查到什么"。Team Memory 还要解决"谁可以用、哪个版本有效、应该给哪个 Agent"。所有产出都被统一登记为 Memory Asset。

🧠 Chat Memory

L0→L3 自动沉淀

保留偏好、事实、决策和交互历史。L0 Conversation → L1 Atom → L2 Scenario → L3 Persona，逐层生长。每个 Agent 创建时自动获得独立记忆。

用户偏好 跨会话

⚡ Skill

带版本 / 资源 / 触发边界

从对话和工具调用中提炼可复用 Skill（不只是 Prompt）。排障、Review、上线检查——练会一次，全队可用。

可复用 可分享

📖 Wiki

文档 + 链接图谱

产品文档、设计方案、运维手册生成结构化页面与链接图谱（灵感来自 Karpathy LLM Wiki）。Agent 用 /v3/tools/list + /v3/tools/call 按需检索。

结构化 可下钻

🔗 CodeGraph

代码符号 / 调用 / 影响路径

索引文件、符号、调用关系与影响路径。Agent 可搜索、查 callers/callees，改代码前先做 impact analysis。基于 colbymchenry/codegraph。

预索引 影响分析
Memory Hub 资产面板：Owner / 版本 / 状态 / 可见性 / 团队分配（来源：TencentDB-Agent-Memory）
03 可见性 ACL · 共享经验，不共享隐私

新 Chat Memory 和 Skill 默认 private。分享是明确动作，不是默认泄漏。

可见性语义典型用例
private 只有 Owner 可读，团队管理员也不例外 个人草稿、未发布 Skill
team 团队成员可读，Owner / Admin 管理 团队规范 Wiki
restricted 通过 User / Role / Agent ACL 精确授权 跨部门共享但限人
agent 同团队 Agent 的定向装配 把"架构 Wiki"分给所有开发 Agent
04 技术实现 · 沉淀 / 装配 / 按需调用

TencentDB Agent Memory 不追求"存下所有东西"，而是解决三个问题：什么值得留下、谁可以使用、下一次怎样少拿但拿对。

① 记忆不是平铺记录，而是逐层生长

层级保存什么主要用途
L0 Conversation原始对话与完整上下文核对原话、时间和来源
L1 Atom事实、偏好、约束、事件精确召回可执行信息
L2 Scenario项目/场景知识块快速恢复一个工作场景
L3 Persona长期画像、稳定模式让 Agent 迅速进入用户语境

② 记忆不是全局 Prompt，而是 Agent 的 Loadout

Memory Hub 通过 Fixed Binding + ACL 决定 Agent 能带走哪些资产：先按 Team / User / Agent 和可见性缩小权限范围，再按当前问题召回。换 Agent 或换框架，只需重新装配，不必重新训练。

③ 知识不整库注入，而是按需调用

文档被整理为可搜索的 Wiki；代码库被索引为含文件、符号和调用关系的 CodeGraph。Agent 先通过 /v3/tools/list 发现能力，再用 /v3/tools/call 读取相关页面、源码或影响路径。文档和代码平时只是可用工具，需要时才进入上下文。

技术实现总览：沉淀（L0–L3）→ 记忆资产 → Memory Hub → 按身份装配到 Agent

06 安装与集成 · 一键起 + 多平台接入

一次拉起完整三件套（memory-core + memory-hub + proxy），打开 Panel: http://localhost:8125。 

# 一键部署（README 推荐命令）
git clone https://github.com/TencentCloud/TencentDB-Agent-Memory.git
cd TencentDB-Agent-Memory/deploy/global-images
cp .env.example .env
$EDITOR .env       # 填入两组 LLM 参数（memory 组 + proxy 组）
./start-all.sh   # 一键起；结束后打印可直接复制的 claude 命令

注意事项（README 原文）：
  • Wiki 和 CodeGraph 异步构建，需要等待一定时间才能 ready。
  • CodeGraph 当前优先支持公开 HTTPS 仓库；私有仓库和 SSH 凭证接入仍在完善。
  • Hub 已支持人工绑定资产；全自动记忆路由仍在迭代。
  • 更广泛的跨框架迁移仍在 Roadmap 中。
