01 核心能力
OmniRoute 是什么：一个统一的 AI 网关，将 237 个 LLM 提供商汇聚到单一端点。通过智能路由、请求去重、缓存和令牌压缩，让开发者用最少的成本调用最强的模型。
237 提供商聚合：从 OpenAI、Anthropic、Google、Cohere 到上百家小众提供商，一个 API Key 打天下
90+ 免费额度：内置免费层发现，每月汇总约 1.54B 免费 Token 配额，无需逐个注册
令牌压缩 95%：通过上下文压缩、请求合并和智能路由，将令牌消耗降至原消耗的 5%
Claude Code / Codex：原生集成，配置 OMNIRETE_* 环境变量即可直连，无需改动代码
OpenAI 兼容 API：提供 OpenAI 风格的 /v1/chat/completions 等端点，零成本迁移
安全多层防护：CORS → Authz → Guardrails → Rate Limiter → Circuit Breaker

06 竞品对比
vs One API：OmniRoute 更侧重令牌压缩和免费层发现，One API 更偏向多渠道管理和计量
vs PortKey：PortKey 偏向企业级可观测性，OmniRoute 更偏开发者友好和免费额度聚合
vs OpenRouter：OpenRouter 是云服务，OmniRoute 是自托管方案，数据完全自主
vs 逐个注册：手动注册 237 个平台需要数周；OmniRoute 一个端点聚合，免费层自动发现
