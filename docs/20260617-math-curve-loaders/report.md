# Math Curve Loaders 图集报告

## 核心判断
这是一个把数学曲线参数化为加载动画图库的页面，不是单个 loader demo。

## 关键事实
- 原站点包含 21 个图形。
- 可收敛成 8 个家族：custom rose trail、rose curve、Lissajous、lemniscate、hypotrochoid / spirograph、butterfly、cardioid / heart、spiral / Fourier。
- 页面自带 EN / 中文切换和外部链接入口。
- 我把每个图形单独截图并本地化，便于做一页对比卡。

## 结论
最值得复用的是它的参数系统：不是抄某一张图，而是抄“公式 → 形态”的映射方式。
