修改 .env 中三行配置即可切换后端。覆盖免费层、本地部署和商业 API 三种场景。

提供商免费层速度最适合

一行切换：改 PROVIDER_BASE_URL、PROVIDER_API_KEY、PROVIDER_MODEL 三个环境变量。除 Ollama 外所有提供商共用同一套配置模板。

PROVIDER_API_KEY=sk-...

04
ARCHITECTURE

工作原理：代理层的协议桥接

Claude Code 认为自己在和 Anthropic API 通信。实际上 Backdoor 在本地做了实时协议翻译。

Step 1
Claude Code 发送请求到 localhost:8082
Step 2
Backdoor 接收请求，从 Messages API 格式翻译为 OpenAI chat completions
Step 3
转发到选择的提供商（DeepSeek/Groq/Ollama/...）
Step 4
流式回传：结果实时翻译回 Anthropic SSE 格式。工具调用、delta、token 计数全部透明。
HousekeepingShort-circuit

内部请求本地短路

Claude Code 的部分内部请求（quota 探测、标题生成等）被 Backdoor 识别并在本地拦截，不消耗你的提供商配额。免费层用户特别受益于此。

TroubleshootingCommon

常见问题速查

  • Proxy failed to start — 端口 8082 被占用，改 PORT=8083
  • Model not found / 404 — PROVIDER_MODEL 名称不正确（例：DeepSeek 用 deepseek-chat）
  • 响应慢 — 切换到 Groq，最快推理 + 免费层
  • 查看日志 — 检查 proxy.log；为空则直接运行 uv run uvicorn server:app
