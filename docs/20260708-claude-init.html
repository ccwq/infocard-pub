01
WHAT IT IS

它不是 Claude 汉化补丁，而是一套完整的中文开发工作台

claude-init 起源于 2025 年 7 月 Claude Code 在国内社区兴起的时期，定位为「Claude Code 项目初始化工具」，通过预置中文指令、三层上下文架构、MCP 集成和 Hook 脚本，把 Claude Code 打造成适合国内开发者的工作流。

一句话：如果你苦于读英文文档、搞不懂 Claude Code 的配置复杂度、需要开箱即用的中文 AI 编程体验，claude-init 是目前最完整的中文套件之一。
02
INSTALL

一键安装，三步上手

项目提供 install.sh 和 setup.sh 两套脚本，自动完成配置写入、模板复制和 MCP 服务注册。

STEP 1克隆仓库：git clone https://github.com/cfrs2005/claude-init.git
STEP 2运行安装：bash install.sh 或 bash setup.sh
STEP 3进入项目目录，启动 Claude Code 即可。
OR直接复制 templates/.claude 目录到你的项目根目录。

04
CONTEXT7 + GEMINI

Context7 和 Gemini 集成详解

Context7 MCP Server（upstash/context7）通过实时抓取官方文档解决 LLM 知识过时问题；Gemini 深度咨询提供国内可访问的 AI 模型补充。

Context7 是什么

基于 MCP 的文档检索服务，直接从 GitHub/官方文档站拉取当前版本文档和代码示例，按库版本匹配，减少「幻觉 API」。

claude-init 集成方式

在 .claude.json 中预置 context7 MCP 配置，用户提问时加「use context7」，AI 自动拉取最新文档再作答。

Gemini 深度咨询

通过 Hook 脚本接入 Gemini API，提供国内可访问的深度技术咨询能力，作为 Claude 的补充。

安全扫描

自动化 Hook 脚本和安全扫描功能，在代码生成过程中进行基本安全检查。
