把多个 Coding Agent 放进一个工作台，但先核对 Harness、Neovim 与平台边界

Farcaster 是一个原生、键盘优先的桌面工作空间：它围绕已有的 Codex、Pi、OpenCode、Cursor、Claude Code 和 Antigravity 构建，把每个会话的 Agent、编辑器与终端放在同一条操作路径里。它不是新的 Agent harness，也不会替你安装、登录或保证每个 harness 的能力完全一致。

先回答三个问题

你要统一的是界面，还是执行能力？

一：你使用的 harness 是否已有安装与登录？
二：Neovim 是否在 PATH，且你愿意让它成为审核中心？
三：你的平台是否有对应 build，且能接受 early-stage 软件的缺口？
01

先理解定位：Farcaster 是编排工作台，不是“又一个 Agent”

它把不同 harness 的会话、终端、编辑器和共享工具放在一起；实际执行仍由对应 harness 与模型提供方负责。

Session row

每个会话可以理解为 agent | editor | terminal 一行；会话间切换、恢复、关闭和新增由工作台统一管理。

Neovim center

变更文件可在改动行打开；可把 transcript 打开为临时 Markdown，也可从选中代码发送上下文给当前/其他/新会话。

Shared tools

可选 MCP server 提供 Workgraph 任务依赖、Worker Tools 跨 harness 协作，以及 submit_review 快速审查入口。

不要混淆：统一 UI 不等于统一功能。官方 harness 表显示 Cursor 没有 Fork/Steer/Compact/Usage，Claude 通过 claude -p，Pi 通过 RPC；差异取决于适配器和已安装版本。
02

平台与前置：先下载，再确认 Agent 能真正启动

官方当前 release 页面提供 macOS ARM64 与 x86_64 Linux build；README 没有承诺 Windows build。

01

选平台

确认 release 是否有你的架构；macOS build 是 ad hoc signed、未 notarized。

02

装 harness

Farcaster 不替你提供 Claude/Codex/Pi 等 harness；先各自安装并登录。

03

装 Neovim

要用内嵌终端里的 Neovim，确保 nvim 在环境 PATH。

04

跑一会话

先创建单一 session，确认 Agent、Editor、Terminal 三者都能操作，再开并行任务。

session resume、images、stop、queued follow-ups、model selection、reasoning effort、MCP servers、approvals 和 tool activity。

04

共享工具：Workgraph、Worker Tools、Review 各自解决什么

可选 MCP server 默认不是“自动替你协作”；先理解工具边界再决定是否打开。

WORKGRAPH

持久任务关系

创建任务与依赖，让结构跨越单个 Agent session；它描述任务图，不等于自动完成任务。

WORKER TOOLS

跨 harness 调度

创建和沟通不同 harness、provider、model 的 Agent session；成本、权限和结果仍需人工控制。

REVIEW

把审查落到 Neovim

submit_review 带文件、行范围和说明，用户通过 quickfix list 定位；这是导航能力，不是自动批准。

# 交互操作的验收思路（示例，不是 Farcaster CLI 命令） 1. 新建一个 session 2. 让 Agent 修改一个可回滚的小文件 3. 在 Neovim 打开 changed file 与对应行 4. 从选中代码发送上下文到另一个 session 5. 用 submit_review 提交待审范围 6. 人工检查 diff、测试和权限后再决定是否采纳
05

键盘优先的验收：先记四个入口，再扩展快捷键

F1/F2/F3 用于 Chat/Editor/Terminal，Ctrl+Tab 循环视图，F4 打开 action picker。

会话

mod+n 新建、mod+number 跳转、mod+w 关闭 surface/session、mod+shift+a 恢复。

上下文

mod+shift+m 设置 provider/model/effort；mod+shift+h 选择 harness；mod+shift+s 设置 sandbox。

Neovim / terminal

Ctrl+G 激活两秒 leader；随后 e 到 editor、t 到 terminal、v 打开 transcript、n 新建 session。

冲突边界：Linux 上 Ctrl/Alt 快捷键可能被终端或桌面保留，因此 Farcaster 使用 mod/leader 两套入口；不要假设 macOS 快捷键在 Linux 原样可用。
