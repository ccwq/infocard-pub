VS TRADITIONAL · 对比传统方式

AI 读取 DESIGN.md vs 人工 CSS

❌ 传统方式（将被淘汰）

  • 设计师手动导出 Figma Token
  • 工程师对照 Figma 截图写 CSS
  • 组件样式与设计稿经常偏差
  • 需要反复沟通、对齐、再调整
  • 品牌色值靠复制 Hex，字体靠猜
  • 暗色模式要单独维护一套变量
  • 多端适配要写大量媒体查询
  • 维护成本随组件增加指数上升

✅ DESIGN.md + AI（现在）

  • 直接复制品牌 DESIGN.md 到根目录
  • 对 AI 说"用这个设计系统构建页面"
  • AI 精确读取颜色/字体/间距/组件规则
  • 零偏差——来自品牌真实设计系统
  • 包含完整的暗色模式 token
  • Do's and Don'ts 自动约束 AI 行为
  • 包含响应式断点和触控策略
  • "人类只需给 AI 递设计规则书"
"工程师不再是'实现设计'，而是'给 AI 递设计规则书'"
