abtop

Like htop, but for AI coding agents。一个终端监控仪表盘，用来实时查看 Claude Code、Codex CLI 等会话的 token、上下文窗口、速率限制、子进程和端口占用。

Rust + Ratatui + Crossterm 构建，支持 JSON snapshot、tmux 跳转、主题切换和本地只读监控，不需要 API key。

Rust Ratatui Claude Code Codex CLI OpenCode MIT
把分散的 agent 状态压进一个 TUI

适合在多会话并行时监控 token、context、rate limit、git 状态与子进程；也适合快速发现哪个 agent 卡住、哪个端口没关、哪个会话快触发配额。

核心能力

features
多 Agent 统一监控
核心

一个界面看多个 Claude / Codex / OpenCode 会话，避免在多个终端窗口里来回切换。

Token / Context / Quota
重点

实时展示 token 消耗、上下文占比与 rate limits，便于判断是否需要切上下文或暂停任务。

子进程 / 端口 / Git
排障

能发现 agent 是否留下了后台进程、端口和脏工作区。

JSON / tmux / Theme
集成

支持 JSON snapshot、tmux pane 跳转以及多主题切换。
