它解决的不是"画图"，而是"让架构图永远和代码同步"

LikeC4 是一种架构描述语言，也是配套的工具链。代码改了，架构图自动更新，不需要再在 Figma 里手动拖框。

核心定位：Architecture as Code — 把架构设计当成代码来维护，版本化管理、自动生成、CI/CD 集成全部打通。

02

C4 Model 是什么：把架构分层说清楚

LikeC4 从 C4 Model 借鉴了分层抽象的思想，同时比 C4 更灵活。

L1 · Context
系统边界 整个系统与外部参与者的关系，一句话交代系统做什么
用户视角
L2 · Container
容器 / 应用 核心应用和技术选择，数据库、微服务、前端 SPA 都在这层
开发者视角
L3 · Component
组件 每个容器内部的关键组件和它们之间的交互
架构师视角
L4 · Code
代码 具体类、接口的实际实现（可选，仅关键部分）
工程师视角
比 PlantUML / Mermaid 更好：LikeC4 支持实时预览、热更新和 VSCode 插件，不需要等渲染引擎出图；比手动画图更好：代码变了图自动变，不存在版本落后的问题。

快速上手：三步看到第一张图

npm 全局安装后，两个命令出图。

# 1. 安装 CLI npm i -g likec4 # 2. 在项目目录初始化 likec4 init # 3. 启动实时预览 likec4 dev # 导出静态文件 likec4 export --format svg likec4 export --format png
likec4 dev likec4 export likec4 format VSCode 插件 Playground MCP Server

06

适用场景：谁应该用 LikeC4

不是所有项目都需要架构图，但需要的地方用 LikeC4 能省大量维护成本。

场景 1
微服务 / 多模块项目
几十个服务之间的调用关系，手动画根本跟不上代码变化。
场景 2
新人 onboarding
一张图胜过千言万语，LikeC4 让图始终是最新的。
场景 3
架构文档自动化
CI/CD 里跑 likec4 export，文档永远是最新状态。

值得用的信号

  • 代码结构经常变
  • 团队 5 人以上
  • 有新人需要快速了解系统
  • 架构文档是评审材料
  • AI Agent 需要读懂代码结构

可能用不上的情况

  • 单体项目，结构一目了然
  • 短期一次性脚本
  • 已经有成熟的可视化工具链
