## V3 新能力①：AI 局部文字编辑

> ⚠️ **X 帖子宣称**：SenseNova U1 V3 首次加入信息图编辑能力，支持高精度调整局部文字和整体风格，大幅提升图像编辑效率。
> 
> 此处区分"X 帖子称"与"已验证事实"。

据 @GitHub_Daily 的 X 帖子描述，这是本次更新的核心突破——从"只能生成"升级为"可局部编辑"，使用户无需整体重新生成即可修改特定区域内容。

### 局部文字调整

对图片中**局部文字**进行高精度修改，而非只能整体替换或重新生成整个信息图。适用于：错误文字修正、内容更新、措辞优化等场景。

### 整体风格调控

在保留信息图核心结构的同时，对整体视觉风格进行局部调控和适配。

### 验证状态

Infographic 版本（2026.05.15）支持信息图生成；V2（2026.07）重点提升排版质量。

> ⚠️ "局部编辑已有信息图"（inpainting/editing）功能的具体实现细节和上线时间，公开文档描述有限，需进一步核实。

## V3 新能力②：文字风格自适应

> ✅ **有文档支撑**：此能力有 GitHub 官方示例文档（u1_infographic_showcases.md）支撑。

经 AI 修改后的文字内容，会**自动适配原图像的设计风格与排版布局**，无需用户手动调整字体、颜色、位置。

用户可以在保留核心信息与结构的同时，更换视觉表达方式。

### 品牌换皮场景

X 帖子描述的核心价值：同一份内容，可适配**不同品牌、不同主题、不同传播场景**。

| 场景 | 说明 |
|------|------|
| 品牌换皮 | 同一信息图内容适配不同品牌视觉规范 |
| 多语言适配 | 保持排版不变，内容替换为不同语言 |
| 活动主题切换 | 节假日/促销主题快速替换视觉风格 |
| 数据更新 | 数字/日期更新，保持整体风格一致 |
