快速启动
# 1. 环境准备（Ubuntu 22.04 / CUDA 12.8） conda create -n livetalking python=3.12 conda activate livetalking pip install torch==2.9.1 torchvision==0.24.1 torchaudio==2.9.1 \ --index-url https://download.pytorch.org/whl/cu128 pip install -r requirements.txt # 2. 下载模型（夸克云盘 或 Google Drive） # 放置 wav2lip256.pth → models/wav2lip.pth # 解压 wav2lip256_avatar1.tar.gz → data/avatars/wav2lip256_avatar1/ # 3. 启动服务（WebRTC 模式） python app.py --transport webrtc --model wav2lip --avatar_id wav2lip256_avatar1 # 4. 浏览器打开 → http://serverip:8010/index.html # 点击"开始连接" → 在文本框输入文字 → 数字人实时播报
核心 API
方法端点说明
POST/human文本驱动，支持 echo（直接复读）和 chat（LLM 对话）两种模式；返回 sessionid 用于后续音频驱动
POST/humanaudio音频文件直接播放，数字人朗读给定音频内容，无需文本转换
POST/human/stream流式响应，支持打字机效果实时输出 TTS，数字人口型同步跟进
GET/human/{sessionid}/status查询会话状态，判断当前数字人是否正在播报或处于空闲
POST/human/interrupt强制打断当前播报，用于观众提问打断场景，立即停止当前 TTS + 口型推理
GET/admin/stats全局监控：当前并发会话数、GPU 推理 FPS（inferfps）、推流 FPS（finalfps）
系统架构分层
层级组件说明
接入层WebRTC / RTMP / 虚拟摄像头多协议输出，WebRTC 延迟 <200ms；RTMP 支持抖音/B站/YouTube 推流
API 层/human · /humanaudio · /human/stream · /human/interruptHTTP REST，接入简单；每个连接分配唯一 sessionid，支持多用户并发
逻辑层LLM 引擎（Qwen 等）· TTS（EdgeTTS / GPT-SoVITS / CosyVoice / 腾讯云）模块化插拔，新增 TTS 服务只需修改 registry.py；支持声音克隆
推理层Wav2Lip · MuseTalk · ER-NeRF · UltralightGPU 推理，inferfps ≥ 25 才算实时；插件机制 via registry.py 可扩展新模型
渲染层Mel 频谱提取 → 口型推理 → 视频贴回音频特征同步提取，口型区域平滑贴回原始高清视频
适用场景
🛒
虚拟主播 / 直播带货
24小时无人直播，LLM 自动生成带货话术，配合动作编排实现自然表现；支持弹幕互动打断
💬
AI 数字人客服
接入企业知识库，用户语音提问，数字人实时回答，支持打断重说，降低人工客服成本
📚
在线教育 / 培训
教师数字分身录制课程，或通过 API 驱动数字人讲师实时授课，支持批量文案生成视频
🔊
智能语音助手
结合智能音箱或 APP，调用 /human 接口驱动数字人进行语音对话交互
🖥️
大屏讲解员
展厅大屏、活动现场数字人讲解员，自动播报预设内容，支持 API 触发切换讲解段落
📱
短视频批量制作
调用 /human + /record 接口，批量提交文案生成数字人出镜视频，无需真人拍摄
核心能力
🎤
声音克隆
输入少量音频即可克隆相似音色，支持实时切换不同音色；兼容 EdgeTTS、GPT-SoVITS、CosyVoice
✋
实时打断
观众提问时数字人立即停止当前播报，重新响应新问题，交互感接近真人对话
🎬
动作编排
静默时自动播放自定义视频动作片段，避免数字人呆立；支持编排切换逻辑
⚡
多并发
支持多个数字人实例并行运行，互不干扰；CPU 决定静默并发数，GPU 决定同时说话并发数
👤
自定义形象
上传视频自动生成数字人形象；支持全身视频拼接（ernerf）；/avatar.html 在线生成
🔌
前端 API
HTTP 接口简单易用，前端可直接对接；/admin.html 管理后台实时监控会话与 FPS
