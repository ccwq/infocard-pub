01 6 个组件库速览
01 · 动效
beUI
页面总觉得缺少"生命力"？beUI 的动画超级平滑，可直接复制到项目中使用，立刻让界面活起来。
动效组件
02 · 面板
BoardUI
做后端、数据看板或 Agent 产品？BoardUI 能省去大量从零搭界面的时间，开箱即用。
数据面板
03 · 3D
ThreeUI
不想从零学 Three.js 但想给网站加 3D 或 WebGL 效果？ThreeUI 提供现成方案，直接集成。
WebGL / 3D
04 · 功能动效
Fluid Functionalism
不做满屏花哨效果，而是深入探索动画如何真正提升界面可用性——专注于功能驱动的动效设计。
可用性动效
05 · 组件库
Watermelon UI
大量可直接用于真实项目的组件和完整页面，适合浏览找灵感——一刷就是几小时停不下来。
完整页面
