04参与方式
入选标准

网站或 App

必须是可直接使用的网站或 App，不能是开发者工具或论坛型网站。

贡献方式

PR 或 Issue

发 Pull Request 或 Issue 即可申请加入，欢迎把自己的项目加进来。

写好介绍语很重要：❌ AI 视频生成工具 → ✅ 无需剪辑经验，3 步生成竖屏短视频
