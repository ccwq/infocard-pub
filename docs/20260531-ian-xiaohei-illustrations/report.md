# Ian Xiaohei Illustrations：将文章认知锚点转化为“小黑”手绘配图的 Codex Skill

**调查对象**：GitHub 仓库 `helloianneo/ian-xiaohei-illustrations`

**一句话结论**：这是一个专门为 AI Agent（如 Codex）设计的视觉生成技能，它不追求华丽的商业插画，而是通过“小黑”这一荒诞工作者 IP，将文章中的抽象判断、流程和隐喻转化为极简、高辨识度的 16:9 手绘解释图。

## A. 简报

### 1) 这个仓库是什么？
- **核心定位**：一个 Codex Skill，用来指导 AI Agent 为中文内容（文章、博客、Notion 等）生成正文配图。
- **视觉 IP**：**“小黑”**。特征为黑色实心、白点眼、细腿、无表情。它不是装饰物，而是参与系统运转的“荒诞工作者”。
- **设计哲学**：不只是“配图”，而是“把文章里的一个关键认知动作画出来”。

### 2) 视觉风格 DNA
- **布局**：16:9 横版，大量留白（主体占 40%-60%）。
- **底色**：纯白背景，无渐变，无纹理。
- **线条**：黑色手绘线稿，细线，轻微抖动感。
- **强调**：少量红、橙、蓝色的中文手写批注（字数极短）。
- **小黑参与度**：小黑必须承担核心动作；如果去掉小黑画面仍成立，则视为设计失败。

### 3) 产出物清单
- **Shot List**：为整篇文章规划 4-8 张图的方案（位置、主题、意思、结构类型、标注词）。
- **最终图片**：保存为 PNG，通常位于项目 assets 目录下。
- **隐喻重构**：从Workflow、系统局部、前后对比、角色状态、概念隐喻等维度重新发明物理隐喻。

### 4) 适合谁用？
- **推荐**：写中文技术/方法论文章、做知识型内容、希望稳定复用一套视觉语言的 AI Builder。
- **不推荐**：需要商业 KV、复杂架构图、或可爱表情包风格的用户。

## B. 核心工作流

1. **内容解析**：读取文章，提取认知转折、流程结构或适合视觉化的段落。
2. **方案规划**：输出 Shot List，每张图只锚定一个核心观点。
3. **物理隐喻发明**：用低科技、怪诞但成立的方式表达抽象概念（如“想法压机”、“信任桥”）。
4. **图像生成与自检**：调用图像模型，按 QA Checklist（白底、小黑参与、标注词等）进行审查。

## D. 最终判断
`ian-xiaohei-illustrations` 是目前 AI 辅助内容生产领域中，极少数能将“内容理解”与“统一视觉 IP”深度绑定的开源工具。它为“一人公司”或“AI 驱动的创作者”提供了一种成本极低但品牌识别度极高的标准化配图方案。
