让 AI 承担“视觉规划”的任务

该仓库的核心价值在于把“文字理解”与“视觉隐喻”标准化了。它不追求华丽，而是追求“认知效率”，适合需要高产出、统一品牌风格的 AI 驱动创作者。

视觉 DNA

核心原则是：小黑必须参与核心动作。如果去掉小黑画面仍然成立，说明设计太装饰了。配图包含少量红、橙、蓝色手写标注，强调怪诞感与清爽感。

1 极简线稿 2 认知锚点 3 荒诞隐喻 4 标准 IP

核心工作流

workflow
1. 内容解析
提炼
A

提取文章中的认知转折、方法分层、系统局部或适合视觉化的隐喻段落。

2. 规划 Shot List
构思
B

为每张图锚定意思、结构类型（Workflow/对比/地图等）及小黑的动作建议。

3. 隐喻发明
创意
C

重新发明一种低科技、怪诞但成立的物理隐喻（例如用压机表达思考过程）。

4. 生成与自检
交付
D

按 QA Checklist 检查：白底留白、非 PPT 感、小黑深度参与、中文标注短促。

适合谁用

  • 写中文技术、方法论文章的人
  • 做知识型、AI 工作流内容的创作者
  • 想把抽象判断画成具体隐喻的人
  • 用 AI 复用一套品牌视觉语言的人

特别说明

小黑不是吉祥物，而是认真的荒诞工作者。示例图仅用于校准风格，不建议直接照抄构图，应根据文章内容重新发明隐喻。
