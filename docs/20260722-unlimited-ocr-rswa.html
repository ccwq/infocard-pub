📋 问题 vs 方案
✕
传统 OCR 痛点
  • 分页切割处理 → 跨页表格断裂、阅读顺序错乱
  • KV Cache 线性增长 → 文档越长，速度越慢，显存爆炸
  • 多页 PDF 多次调用 → 上下文割裂，无法建立跨页语义关联
✓
Unlimited OCR 方案
  • 端到端连续解析 → 100页 PDF 一次处理，保持全局上下文
  • R-SWA 恒定 KV Cache → 不随文档长度线性增长，显存可控
  • 跨页结构保持 → 表格、公式、阅读顺序全部完整保留
