🔌 接口配置
# 启动 llama-server（OpenAI 兼容接口） ./llama-server -m models/minicpm5-1b-q4.gguf -c 131072 -fa --host 127.0.0.1 --port 8080 # 本地访问端点 http://127.0.0.1:8080/v1/chat/completions # API Key（本地闭环，可填任意占位符） sk-local # 深度思考模式（开启 extra thinking） -y 2 # 控制 thinking token 长度
⚠️ 已知约束
1B 小模型高复杂度任务限制

1B 参数规模在处理高度复杂多任务时，需强制开启深度思考模式以保障正确率。简单任务可关闭以获得最高吞吐量（200+ tokens/s）。

高级扩展：配合第三方可视化客户端（如 Open WebUI）接入网络搜索，可实现多步骤全自动 Agent 深度研究。本地闭环 + 联网搜索 = 完全可控的本地 AI 助手。
