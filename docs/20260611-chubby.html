适合 vs 不适合

✅ 适合

需要批量转录多平台视频/播客的内容创作者 · 用 Obsidian 管理知识库的用户 · 需要行业情报监控的从业者

⛔ 不适合

需要实时直播字幕的场景 · 需要商业级高精度转录的服务 · 不使用 Obsidian 的知识库用户

✅ 亮点

11 个 skill 覆盖视频 / 播客 / 公众号 / 知识库全链路 · 一键 setup.sh 安装 · Agent 直接加载

⛔ 注意

视频下载依赖 yt-dlp，部分平台需额外 cookie 配置 · 部分 skill 需 DeepSeek API Key
