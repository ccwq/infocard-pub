一条命令覆盖三种任务：文本生图、参考图编辑（可多张 -i）、掩码修补（-m PNG alpha：不透明保留、透明重绘）。

GENERATE→EDIT→MASK
COREMULTI-REF
API 路由

生图走 POST /v1/images/generations；编辑走 /v1/images/edits（multipart，OpenAI Cookbook 官方接口）。

RESTmodel=gpt-image-2
质量预算

没有独立 budget 参数，--quality 就是预算旋钮：low 草稿批量 → medium 探索 → high 最终稿/中文文本/图表。

3-LEVELCOST
尺寸规则

1k/2k/4k/portrait 等简写或 16px 倍数字面量；最大边 3840、比例 ≤3:1、总像素 655k–8.3M。

--input-fidelity 在 gpt-image-2 会被拒，CLI 本地直接丢弃；--moderation 默认 low 便于探索，可切回 auto。

COMPATdefault low

3-FALLBACKuv/uvx

get-prompt-from-image 是纯 prompt 工程：用 agent 自带视觉能力反推提示词，不碰 Image API、不花生图费用。

FREEVISION
中转站开箱即用

CLI 构造裸 OpenAI()，base URL 走 SDK 原生约定 OPENAI_BASE_URL，中转站零改动。需确认中转支持 gpt-image-2 系模型 ID。

RELAY-OK/v1 结尾
双变量同序读取

OPENAI_API_KEY 与 OPENAI_BASE_URL 读取顺序一致：进程环境 → ./.env → ~/.env，已设进程变量优先不被文件覆盖。

3-LEVELNO-OVERWRITE

04PROMPTING 方法官方指南七条
先结构再目标

背景/场景→主体→关键细节→限制条件，并写明预期用途（广告/UI 原型/信息图）。

S-001
一致性>语法

短句、段落、JSON 风格、指令式、标签式都行；生产建议用易浏览的模板。

S-002
具体+质量线索

写材质、纹理、媒介；要照片感直接写 photorealistic，别堆形容词。

S-003
文本加引号

要出现在图里的标语、价格、汉字都用直引号括起，不要换种说法。

S-004
先定宽高比

提示前定 1:1 / 3:4 / 16:9 等，并在文本里强化，不只靠 --size。

S-005
一主角原则

复杂场景一个明显主体，其余做配角细节。

S-006
密集文本用 high

内嵌文字、密集图表、小标签、多面板一律 quality=high，中档明显掉效果。
