倪海厦12门课倪海厦是中国台湾著名中医师，其课程体系涵盖《伤寒论》《金匮要略》《黄帝内经》《针灸大成》等经典，是目前最系统化的中文中医教学体系之一。该项目将这12门课全部结构化进 Claude Code Agent Skill。
