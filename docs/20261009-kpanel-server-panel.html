01
BEGINNER

什么是服务器面板？为什么需要它？

KPanel 是科技 lion 开发的开源服务器面板，支持 Docker / Compose 管理、轻量集群、AI 文件审批。简单说，它就是让你不用背命令行，就能可视化管服务器——装软件、配网站、看日志，一条命令都不用记。

服务器面板

一个 Web 界面管整台服务器

传统管服务器靠 SSH 输入命令。面板把常用操作变成网页按钮，点一点就执行，降低了门槛，减少了敲错命令的风险。

DockerCompose

容器优先设计

KPanel 以 Docker 为核心生态，支持 Compose 项目管理，适合想用容器化方式部署服务、不想污染系统环境的用户。

AI文件审批

AI 加持的文件安全

AI 文件写入审批功能会跟随真实的 Compose 源，在写入前进行审查，减少人为误操作带来安全风险。

03
NEW FEATURES

核心新功能逐个拆解

每个功能按「是什么 → 对谁有用 → 怎么理解」三层展开。

新功能 ①Compose 删除安全

Compose 项目删除：删得安心，备份在手

删除 Compose 项目时，配置文件自动保留为重命名备份，数据卷可单独选择是否处理。这意味着：删项目 ≠ 删数据，随时可以恢复。

是什么
删除 Compose 项目时，配置自动备份，数据卷独立可选处理
对谁有用
经常测试新服务、想随时回退的自托管用户
教学意义
「删了能找回来」——降低试错成本，鼓励探索
怎么理解
类似回收站，但由系统自动处理，不用手动备份
新功能 ②docker run 命令透明化

每个容器都能看到它的「出生命令」

每个容器卡片现在显示当初创建它的完整 docker run 命令，secrets 变量自动打码（隐藏敏感值）。学习 Docker 命令的好工具，也是排查问题的利器。

是什么
容器详情页展示完整 docker run 命令，secrets 值自动脱敏
对谁有用
正在学 Docker 的初学者 · 想审查生产配置的运维人员
教学意义
点一个按钮就能看到命令，不用再到处搜索「怎么启动 XX 容器」
安全设计
密码/API Key 等 secrets 自动打码，不会明文暴露
新功能 ③统一文件传输管道

上传 · 跨主机传输 · URL 下载——一条管道搞定

三种文件获取方式（本地文件、远程主机、URL 下载）共用一条持久接收管道，支持分块校验、断点续传、取消操作，完成后可选择结果处理方式。

是什么
上传 + 跨主机传输 + URL 下载统一入口，支持断点续传
工程价值
大文件传输不怕断网；分块校验保证文件完整性
对谁有用
管理多台服务器、需要迁移数据的管理员
断点续传
传输中断后可从断点继续，不用从头传，节省时间和带宽
新功能 ④Office 预览编辑

文件管理器内置 Office 文档预览

支持预览和编辑 DOCX / XLSX / PPTX，新增「新建」菜单，无需下载到本地再上传。

类似 Google Docs 的在线编辑体验，但文件存储在你自己服务器上。

新功能 ⑤备份健康告警

备份也有人管，自动检查状态

备份中心新增健康状态检查与告警机制，支持 opt-in（用户主动开启）面板登录告警通知。

备份失败主动通知，不用等到恢复数据时才发现备份早就坏了。

新功能 ⑥

手机桌面模式

支持分页、分组文件夹、小组件页面，手机上也能高效管理服务器。

新功能 ⑦

公开分享主题

可整页接管分享，适合将面板主题分享给团队成员或对外展示。

新功能 ⑧

延迟图表升级

新增中位数 + 范围带显示，更直观地看到响应时间的分布区间。

04
SAFETY NET

升级安全机制：自托管用户最关心的安全网

自托管意味着你对自己的服务负责。升级失败不恢复，是最大的噩梦。KPanel 1.25.0 为此设计了完整的防护机制。

自动冷备份

升级前，系统自动备份

点击左下角版本号 → 版本更新 → 一键升级，升级前系统自动执行冷备份（冷备份 = 将当前系统状态完整复制保存）。

不需要手动操作，不依赖用户记得备份。

失败自动回滚

升级出错？自动退回旧版

升级过程中遇到任何异常，系统自动回滚到升级前的版本和数据状态，保证服务始终可用。

设置 + 数据，全部保留，不丢失。

升级流程安全机制 一键操作 · 全自动
步骤 1: 用户点击「一键升级」 步骤 2: 系统自动执行冷备份（静默完成） 步骤 3: 执行升级 步骤 4a: 升级成功 → 完成 ✓ 步骤 4b: 升级失败 → 自动回滚到冷备份 → 服务恢复 ✓
OpenWrt 稳定性修复

路由节点不再「失踪」

OpenWrt 风格路由节点在面板重启后不再从列表中消失——之前是一个已知 bug，现在已修复。对使用 OpenWrt 的用户影响最大。

05
GETTING STARTED

初学者上手路径

从零开始，5 步完成首次升级或安装。

1
找到版本号入口
在 KPanel 面板左下角找到当前版本号（显示为 vX.X.X 格式）。
2
点击「版本更新」
点击版本号后会弹出更新选项，选择「版本更新」。系统会自动检查新版本。
3
系统自动冷备份
升级前静默完成冷备份，无需人工干预。如果备份失败会提前提示。
4
点击「一键升级」
确认后开始升级。过程中不要关闭页面或断网。
5
升级完成 / 失败回滚
成功 → 页面自动刷新，显示新版本号。失败 → 系统自动回滚，旧版继续运行。

⚠ 限制

轻量集群节点仅支持 Linux

KPanel 的轻量集群管理功能仅支持 Linux 节点，不支持 macOS 或 Windows 节点。这意味着多节点集群环境下，所有被管理节点必须是 Linux 系统。

GLOSSARY

术语表

本文出现的技术术语通俗解释。

Compose
Docker Compose，一种用 YAML 文件定义多容器应用的工具。一个配置文件管多个容器，方便批量启停。
数据卷（Volume）
Docker 用来持久化存储数据的机制。容器删了数据卷还在，相当于给数据单独建了一个仓库。
secrets
敏感信息，如密码、API Key、数据库凭证。在 docker run 命令中打码（隐藏显示）防止泄露。
冷备份
对系统或数据进行完整复制的备份方式。区别于增量备份，冷备份保存的是某一时刻的完整数据。
rc 版本
Release Candidate，发布候选版。功能基本完成，等待社区测试后再正式发布。
断点续传
文件传输中途中断后，从已传输的部分继续，而不是从头开始。节省时间和带宽。
分块校验
大文件分成多个块传输，每块单独校验完整性，确保没有数据损坏或截断。
回滚
升级或变更失败后，取消当前操作，恢复到之前的状态。
轻量集群
KPanel 提供的多节点管理功能，可同时管理多台服务器的容器。仅支持 Linux 节点。
opt-in
用户主动选择开启的功能。opt-in 告警 = 你主动订阅后才会收到通知。
