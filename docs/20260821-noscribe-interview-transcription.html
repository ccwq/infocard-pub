Limitations · 已知局限
⚠ 购买/部署前需了解
首次下载模型约数 GB，需稳定网络连接
一小时录音在普通机器上需约三小时转录，慢机器时间更长
音频质量差时转录准确率显著下降
自动转录永远需要人工核查，不能完全替代人工整理
Windows/macOS/Linux 均可，但需安装 Python 环境
✓ noScribe 优势
完全本地运行，受访者隐私有保障
自动说话人分离，无需手动标注
多语言支持，约60种语言
内置编辑器，边转边核查修正
多格式导出（Word/TXT/JSON）
✗ 需注意的局限
首次需下载数 GB 模型文件
转录速度依赖硬件配置
差音频效差，必须人工核查
自动转录永远不等于完美文字稿
v0.7 版本，仍在活跃开发中
