一、为什么 VulcanBench 值得关注

VulcanBench 是 xAI 发布的全新编程能力基准测试，特点是：

  • 使用真实软件工程任务，而非 LeetCode 风格算法题
  • 涵盖 Python、Rust、Go 等5种主流语言
  • 每题需要真实代码编写、调试和测试通过
  • 对现有主流评测基准（如 HumanEval）有显著覆盖差距

四、生态集成进展

  • Grok Build CLI：Grok 4.5 成为默认模型，新增 session summaries（会话摘要）和性能优化
  • SuperGrok & X Premium+：已向付费用户推送
  • Grok API：已开放，$0.32/task 的定价显著低于主流竞品

五、Elon Musk 暗示更强版本

Elon Musk："Grok keeps winning." 同时暗示 2T（2万亿）参数版本即将完成训练，若实现将成为参数规模最大的语言模型。

六、关键分析

  • benchmark 水分问题：VulcanBench 由 xAI 自建，Grok 4.5 在自有基准登顶不意外。真正的独立验证需要 SWE-Bench、Terminal-Bench 等第三方基准的复测数据
  • 成本优势是亮点：$0.32/task 的定价若实测质量接近 Claude Fable 5，对价格敏感的开发者和企业有吸引力
  • 参数规模路线：1.5T 到 2T，xAI 延续"大力出奇迹"策略，实际推理效率有待观察
  • 编程 vs 其他能力：基准聚焦编程，不等于通用能力领先。复杂推理、多模态、工具调用等维度需独立评测
