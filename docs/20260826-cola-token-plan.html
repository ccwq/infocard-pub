Token Plan 是什么？

它是 Cola 的月度模型订阅：支付固定月费，获得一组指定模型的 included allowance；额度每天刷新，未使用部分不会结转到下一次刷新。

注意区分Credits

不是全站无限包月

套餐只覆盖 included models。搜索、图像、视频等功能，以及套餐未覆盖的模型，仍可能从 Credits 余额中扣费。

机制Allowance

每天刷新，但不会囤积

  • 官方说明中，Token Plan allowance 每天在 00:00 UTC 刷新。
  • 当天未用完的额度在下一次刷新时过期，不会滚存。
  • 当天额度耗尽后，可以继续使用 Credits；是否自动回退由 Usage 设置控制。
  • 切换到套餐未覆盖的模型时，产品会提示该调用将按 Credits 计费。
购买前要看清：“月费固定”不等于“所有模型和所有功能都包含”。应同时核对套餐覆盖、每日 allowance 和 Credits 兜底逻辑。
使用路径Cola Desktop

怎么开始？

1. 下载并打开 Cola 桌面应用
2. 使用邮箱或 Google 登录
3. 在 Settings → Balance & Usage 查看余额与 Token Plan
4. 选择 Breeze / Wander / Flow
5. 在模型选择器查看当前套餐可用模型
6. 需要套餐外模型或功能时，再充值 Credits
适合

希望控制月度预算、持续使用一组模型、又不想每次调用都单独估算成本的个人用户和轻量 Agent 使用者。

不适合

需要固定使用某个未被套餐覆盖的模型、频繁使用搜索/图片/视频功能，或要求未使用额度长期结转的用户。
