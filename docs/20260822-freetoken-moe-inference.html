Core Tech

四大核心技术特性

1
q* Policy · 带宽自适应调度
CPU-GPU 协同执行策略，根据实时带宽动态分配计算负载，笔记本和台式机自适应，无需手动调参。
2
全局 LRU 专家缓存 + FTW 量化
专家参数全局 LRU 缓存 + FTW 快权格式（Fast Token-wise Weight），减少重复加载，降低显存占用。
3
语义感知 KV + 专家缓存
KV Cache 与专家缓存联动，增量重算支持 thinking / tool-call 边界的语义切分，降低首 token 延迟。
4
弹性 VRAM 内存管理
运行时动态在专家缓存和 KV 内存之间重分配显存，无需重启引擎，显存利用率最大化。
