00CORE JUDGMENT · 核心判断
AI 驱动开发的风险不在“写不出代码”，而在“没有共享理解就开始写”。 Matt Pocock 的 skills 把 Agent 从一次性聊天，拉回工程团队熟悉的节奏：术语先对齐、证据先缓存、原型先验证、需求写终点、工单拆竖切、实现跑 TDD、QA 再回环。

一句话用法

无代码库的纯构思，用 /grill-me 逼清楚问题；有代码库的真实变更，用 /grill-with-docs 同步挑战术语、压测边界、对照代码、即时写入 CONTEXT/ADR。

01SEVEN-STAGE LOOP · AI 驱动开发七阶段
01

Grill

把模糊想法变成共享理解；逼问范围、失败条件、真实用户场景。

产出：问题陈述 + 对齐
02

Research

缓存难探索的外部信息，避免每轮对话重新搜索、重新解释。

产出：research.md
03

Prototype

用可玩代码验证设计、状态机或 UX，不污染主分支。

产出：可丢弃原型
04

PRD

描述终点，而不是替 Agent 规定路径；约束验收而非微管理实现。

产出：需求文档
05

Issues

拆成可并行执行的垂直切片，明确依赖、范围、测试口径。

产出：工单 DAG
06

Implement

Agent 执行，优先 TDD、Ralph 等小步反馈流，持续保持可运行。

产出：可运行代码
07

Review

人工 QA 发现问题，再回到 Issues/PRD/Grill，不把 review 当终点。

产出：QA 计划 + 新工单
02GRILL-WITH-DOCS · 有代码库时的升级版 Grill

/grill-with-docs 的定位

它是 /grill-me 的代码库版本：不是只问“你想要什么”，而是拿现有代码、术语、边界、历史决策一起审讯。目标是把会话中的临时理解固化到仓库文档里。

与 /grill-me 的分工

  • 有代码库：用 /grill-with-docs，读代码、挑战术语、更新 CONTEXT/ADR。
  • 无代码库：用 /grill-me，例如悼词、纯产品构思、单次写作方向。

CONTEXT.md：领域语言

来自 DDD 的 ubiquitous language。CONTEXT.md 是术语表，不是 spec，也不是实现笔记。例：materialization cascade 比“lesson 被 real 化时文件系统里占坑”更省 token、可搜索、命名一致。

docs/adr/：只在三条件同时满足时写

  • 决策难逆转；
  • 没有上下文会令人惊讶；
  • 存在真实 trade-off。
03SESSION ACTIONS · 会话中的四类动作

1. 对照 glossary 挑战用词

当用户说“lesson real 化”“生成文件”这类含混表达时，要求选择或新增统一术语，避免同一个概念在不同 issue 里换名字。

2. 用具体场景压测边界

拿真实路径、权限、失败输入、并发场景去压测“看起来懂了”的需求，逼出隐藏约束。

3. 对照代码发现矛盾

不是只听需求描述，还要读现有实现，找出需求和当前行为之间的断裂。

4. 决策即时写入 CONTEXT

不要批量攒“会后整理”。术语和决策在会话内落盘，下一轮 Agent 才能继承上下文。

04SKILL MAP · 16 个工程技能如何落位
/grill-with-docsGrill

有代码库时的需求对齐入口：挑战术语、压测边界、读代码找矛盾，并把决策写入 CONTEXT.md / docs/adr/。

/grill-meGrill

无代码库时使用，适合纯构思、写作、个人决策；通过有限轮追问把模糊想法变成可执行问题。

/prototypePrototype

用可丢弃代码验证 UI/UX、状态流或技术路线，证明方向后再进入 PRD / Issues。

/to-prdPRD

把已对齐的会话上下文整理为“终点描述”，强调用户价值、验收标准和非目标，不预设实现路径。

/to-issuesIssues

把 PRD/计划拆成可并行执行的垂直切片，形成带依赖的工单 DAG。

/tddImplement

强制红-绿-重构；让 Agent 每次只推进一个小切片，先写失败测试，再修复，再重构。

/diagnoseReview Loop

当 Review 发现 bug 或性能回退，进入复现、最小化、假设、埋点、修复、回归验证的调试循环。

/triageIssues

对新工单做分诊：优先级、阻塞、范围、标签；适合把 Review 发现的问题重新送回队列。

/improve-codebase-architectureArchitecture

对照 CONTEXT.md 和 ADR 发现“泥球化”迹象，寻找 deep module 与边界收缩机会。

/handoffHandoff

把会话压缩为可交接上下文，适合阶段切换或换 Agent 继续执行。
