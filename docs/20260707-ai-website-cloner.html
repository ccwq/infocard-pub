项目简介

一个可复用的开源模板，通过 AI 编码代理将任意网站逆向工程为干净、现代的 Next.js 代码库。

指向一个 URL，运行 /clone-website <url>，AI 代理即会检查网站、提取设计令牌与资源、编写组件规格，并行构建每一个区块，最终组装成完整页面。

推荐使用 Claude Code（Opus 4.8）以获得最佳效果。

快速上手
# 1. 从模板创建自己的仓库（不要直接 clone） # 点击 GitHub 页面上的 "Use this template" → Create a new repository # 2. 克隆并安装依赖 git clone https://github.com/YOUR-USERNAME/YOUR-NEW-REPOSITORY.git cd YOUR-NEW-REPOSITORY npm install # 3. 启动 AI 代理（推荐 Claude Code） claude --chrome # 4. 运行克隆技能 /clone-website https://example.com
克隆管线
STEP 01
Reconnaissance
截图、设计令牌提取、交互扫描（滚动/点击/悬停/响应式）
STEP 02
Foundation
更新字体、颜色、全局样式，下载所有资源文件
STEP 03
Component Specs
在 docs/research/components/ 下生成详细规格文档（含精确 CSS 值、状态、行为）
STEP 04
Parallel Build
在 git worktree 中并行调度构建代理，每个 section/component 一个
STEP 05
Assembly & QA
合并 worktree、接入页面、与原站进行视觉 diff 对比
每个构建代理都接收完整组件规格：精确的 getComputedStyle() 值、交互模型、多状态内容、响应式断点和资源路径。无需猜测。
