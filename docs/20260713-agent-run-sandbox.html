agent-run：用 bwrap 把 Coding Agent 装进沙箱

把 Codex、Claude Code、OpenCode、Pi 等主流 Coding Agent 套进 Linux 沙箱，系统文件默认只读、项目目录可写、TOML 配置、一键隔离运行。

Rust bwrap 沙箱 GPL-3.0 单文件 <1MB 13 GitHub Stars
Claude Code Codex OpenCode Pi Agent TOML 配置 JSON Schema
核心价值：减少权限弹窗，降低 Agent 误改本机文件的风险

bwrap 默认将整个文件系统设为只读，仅允许项目目录和显式配置的路径可写。适合"防止 Agent 误操作"而非"防御恶意代码"场景。

权限隔离 bwrap 沙箱 单二进制
01
核心价值

减少弹窗，防止误改本机文件

Coding Agent 运行时需要写缓存、写临时文件、写配置文件——直接给权限太危险，不给又弹窗。agent-run 用 TOML 声明"哪些路径可写"，其余全只读。

权限弹窗归零

无需 Agent 向用户申请写权限，配置文件声明即可。

零弹窗 声明式

误操作防护

系统目录、SSH key、密码文件等默认不可写，Agent 写不进去。

bwrap 只读系统

轻量部署

单文件二进制，x86_64 仅 ~666KB，无需安装依赖，放入 PATH 即用。

<1MB 零依赖
02
支持的 Agent

Claude Code / Codex / OpenCode / Pi

命令行直接指定要运行的 Agent 类型，agent-run 自动套上对应沙箱配置。

Claude Code

需挂载 ~/.claude 和 ~/.claude.json（workspace trust 配置）。

Anthropic

Codex

挂载 ~/.codex 缓存目录。

OpenAI

OpenCode

需 /tmp/opencode 可写（OpenTUI 库解压路径）以及 TMPDIR 环境变量。

OpenCode

Pi Agent

需挂载 ~/.pi 和 /tmp（Pi bash 日志输出路径）。

Pi
运行方式：在项目目录下运行 agent-run <pi|opencode|codex|claude> 即可，配置从最近的 .agent-run/config.toml 自动读取。
03
配置方式

TOML 声明式配置，网络/环境变量/可写挂载

全局配置 + per-tool 覆盖，支持网络开关、环境变量继承或覆盖、路径只读/可写切换。

[global]
mount = [
    "~/.cache",   # 缓存可写
    "..",          # 项目目录可写（相对于配置所在位置）
]

[tools.claude]
mount = [
    "~/.claude",
    "~/.claude.json",   # 必须存在，workspace trust
]

mount

显式声明可写路径；未声明的路径默认为只读。支持 ~ 路径展开。

只读默认

network

布尔开关，控制沙箱内是否允许网络访问。

可关闭

env / inherit_env

选择继承宿主环境变量，或仅传递显式声明的变量（如 TMPDIR）。

细粒度控制
JSON Schema：仓库内置 schema.json，配合 Taplo 等支持 Schema 的编辑器可获得配置补全和类型检查。
04
威胁模型

防止误操作，非绝对安全隔离

README 明确说明：agent-run 主要用于捕获 Agent 的误操作，不保证完全防御恶意代码。

1

✅ 能防护的

Agent 误写系统文件、SSH key、密码文件、其他人目录。

2

⚠️ 不能防护的（已知限制）

整个文件系统以只读暴露，网络开启时仍可向外发送数据（如读取 /etc/hosts 再外传）。

3

🔒 绝对隔离需求

若威胁模型含恶意代码或数据窃取，建议使用 microVM 级隔离方案。

05
安装使用

Nix / Mise / 手动下载，三种方式

无额外运行时依赖，仅需 Linux + unprivileged user namespaces（bwrap 内嵌在二进制内）。

Nix（推荐）

nix run github:sin-ack/agent-run -- <command>

Flakes

Mise

mise use github:sin-ack/agent-run@latest

版本管理

手动下载

从 GitHub Releases 下载二进制，chmod +x 后放入 PATH。

x86_64 / aarch64
前提条件：Linux 系统 + unprivileged user namespaces 已启用。bwrap 二进制已内嵌在 agent-run 中，无需单独安装。
