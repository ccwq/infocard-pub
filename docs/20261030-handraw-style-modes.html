02 / 关键开关

文字是否参与画面？

🎨 纯图模式 · 默认

主题决定画面内容，但不要求主题文案入画。适合文章插图或标题在排版工具中后加的场景。

纯图模式，041号风格，主题：秋天的第一杯奶茶

✍️ 图文模式 · 显式切换

保留主题原文，让文字参与构图；适合金句、节日海报和社媒卡。同一编号无需重选。

切换为图文模式。
267号风格，主题：有很多事你当时想不通，别着急，过段时间你可能就忘了。

模式是对提示词和构图的要求，并非文字准确率保证；最终成图仍需逐字检查。

03 / 操作路线

从图鉴到一张可用的图

  1. 安装与浏览：项目 README 建议将仓库地址交给 Codex 安装。安装后可在仓库内打开 skills/handdraw-style-prompter/gallery/index.html 浏览风格，layouts.html 浏览排版，colors.html 浏览颜色；路径相对仓库根目录。
  2. 组合输入：记下喜欢的风格编号，按需加图型和主题色。例如官方示例：图型：SC-001，风格：FB-006，主题色：C-01，主题：秋天的第一杯奶茶。
  3. 指定模式：需要画中文字时追加“切换为图文模式”；回到正文插图可说“切换为纯图模式”。不指定时默认纯图。
  4. 取得输出：项目说明默认生成中英双语提示词；复制到自己的生图工具。若希望直接生成，需要明确提出，并有可用的生图能力。
  5. 检查并调整：对照主题、文字、画幅和风格。需要修改时说明具体问题，例如“背景改为象牙白纸面，保留原文”。公众号展示过类似修正，但本文未重复实测。
04 / 参考图与限制

先用文字，不够再参考图

项目对已标定模型描述了分层策略：先尝试作者名与风格名，再补充核心特征，仍难激活时才使用参考图；未标定模型则采用参考图兜底。参考图可能带入主体或构图，提示时应说明只参考线条、质感与配色。

小测试：固定一个主题、一个风格编号，分别尝试纯图与图文；检查主题是否一致、文字有没有漏字、参考图主体是否被复制。记录模型和提示词，便于比较。此为建议的测试方法，不是本文实测结果。

不同模型、版本和生成参数会影响结果，编号不保证跨模型画风一致或文字无误。使用参考作品时还需核对适用授权；编号不是授权凭证。
