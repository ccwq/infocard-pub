技术架构

基于 RustVMM 的高性能沙箱

CubeSandbox 由腾讯云开源，采用 Rust 编写的轻量级虚拟机监控器（RustVMM）与 KVM 虚拟化技术构建。支持单机部署和集群扩展，兼容 E2B SDK，单机可并发运行数千个 AI Agent。

⚡
CubeAPI
高并发 REST API 网关（Rust），兼容 E2B。换 URL 即可无缝迁移。
🎯
CubeMaster
集群编排器，接收 API 请求并调度到对应 Cubelet，管理资源与集群状态。
🔀
CubeProxy
反向代理，兼容 E2B 协议，将请求路由到对应沙箱实例。
🖥️
Cubelet
计算节点本地调度组件，管理节点上所有沙箱实例的完整生命周期。
🔗
CubeVS
基于 eBPF 的虚拟交换机，提供内核级网络隔离和安全策略执行。
🛡️
CubeEgress
OpenResty 出向安全网关：L7 域名过滤、凭证注入、访问审计。

核心能力

四大能力详解

📦

极致轻量

单沙箱内存占用 <5MB，采用激进裁剪策略，内存开销几乎不随实例规格增长。单机可运行数千个沙箱，实现前所未有的部署密度。

轻量级设计
⚡

毫秒级启动

冷启动平均 <60ms，在单并发场景下稳定；在 50 并发创建时，平均 67ms，P95 90ms，P99 137ms，始终保持亚 150ms。

60ms 冷启动
🔒

硬核防翻车

每个沙箱拥有独立 Guest OS 内核，无 Docker 共享内核逃逸风险。基于 eBPF 的 CubeVS 提供内核级网络隔离，安全策略硬件级执行。

硬件级隔离
💰

省钱利器

支持闲置自动挂起（AutoPause/AutoResume），空闲沙箱自动暂停，接收请求时秒级唤醒。配合高部署密度，大幅降低 AI Agent 运行成本。

自动挂起

竞品对比

CubeSandbox vs E2B

CubeSandbox 完全兼容 E2B SDK，只需修改一个 URL 环境变量即可无缝切换。同时在性能和成本上有显著优势。

指标 CubeSandbox E2B
启动速度 ⚡ <60ms ~200ms+
内存占用 📦 <5MB/实例 ~50MB+/实例
隔离级别 🔒 硬件级（独立内核） 容器级（共享内核）
部署密度 🏆 数千实例/节点 数十实例/节点
SDK 兼容性 ✅ 原生 E2B 兼容 —
自动挂起 ✅ AutoPause/Resume ❌ 不支持
快照/克隆 ✅ 百毫秒级快照 ⚠️ 部分支持
出向安全 ✅ CubeEgress + 凭证保险库 ⚠️ 基础过滤
许可证 📄 Apache 2.0 专有/商业
成本 💰 开源免费 按调用计费

适用场景

这些场景最适合

🤖

Agent 自动化测试

为 AI Agent 提供安全隔离的代码执行环境，测试 Agent 生成的代码不会影响主系统，支持并发测试加速。

💻

代码执行隔离

运行 AI 生成的不可信代码，每个请求在独立沙箱中执行，通过硬件级隔离防止恶意代码逃逸和数据泄露。

🏢

多租户沙箱服务

构建 SaaS 化的代码执行平台，为不同客户提供完全隔离的运行环境，支持秒级创建和销毁。

🔐

CI/CD 安全执行

在 CI 流水线中安全执行第三方插件或自动化脚本，即使脚本被恶意污染也无法突破沙箱边界。

安装与示例

1

安装 CubeSandbox

在 Linux x86_64 + KVM 环境中一键安装

# 一键安装 curl -fsSL https://get.cubesandbox.com | bash # 验证安装 cubesandbox --version
2

使用 Python SDK（兼容 E2B）

只需修改 API URL 即可从 E2B 迁移

import cubesandbox as e2b # 替换 E2B URL 为 CubeSandbox import os os.environ["E2B_API_KEY"] = "your-api-key" sandbox = e2b.Sandbox() # 执行代码 result = sandbox.run("python3", args=["-c", "print('Hello from CubeSandbox!')"]) print(result.stdout)
3

使用 REST API

通过 HTTP API 直接控制沙箱

# 创建沙箱 curl -X POST https://api.cubesandbox.com/v1/sandboxes \ -H "Authorization: Bearer $API_KEY" \ -H "Content-Type: application/json" \ -d '{"template": "ubuntu-22.04", "timeout": 300}' # 运行命令 curl -X POST https://api.cubesandbox.com/v1/sandboxes/$ID/run \ -d '{"cmd": "echo hello"}'
