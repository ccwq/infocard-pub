诗泉：高性能中国古诗词 API 服务

Go 语言编写的高性能中国古诗词 REST/GraphQL API，海量数据（近40万首）+ 简繁切换（~300ns/op）+ Docker 一键部署。1963⭐️，开源协议 GPL-3.0。

核心功能

海量诗词数据

覆盖唐诗、宋词、元曲等，数据库存储简体+繁体中文，通过 ?lang=zh-CN 或 ?lang=zh-TW 实时切换。

高性能 Go 实现

Go 语言编写，支持并发处理，简繁转换约 300ns/op，性能优化到位。Go Report Card 评分良好。

全文搜索

支持按标题、内容、作者、朝代、诗词类型多维度搜索，结果精准。

限流保护

内置 IP 限流机制，防止 API 被滥用，保障服务质量。

爬虫练习场

提供爬虫练习场景，适合开发者练手。

GraphQL 接口

除 REST 外，还支持 GraphQL 查询，灵活满足不同调用方式。

快速部署

# Docker 一键启动（推荐） docker run -d -p 1279:1279 palemoky/chinese-poetry-api:latest # 查看帮助 make help # 本地构建 make build make run-server

API 示例

端点说明
GET /poetry/random随机获取一首诗
GET /poetry/search?q=李白&author=1按标题/作者搜索
GET /poetry/author/:id获取某作者全部作品
GET /poetry/dynasty/:name按朝代筛选（如"唐"）
GET /poetry/type/:type按类型筛选（如"诗"）
