# Yao Expert Skill：把陌生行业快速拆成可学习、可复述、可导出的专家报告

## 一句话结论
Yao Expert Skill 不是一个普通的“行业问答 Prompt”，而是一套结构化专家学习工作流：先定边界，再拆价值链、竞争结构、政策与风险，最后输出专家报告、关键词教学卡、费曼自测题，以及 Markdown / Word / PDF / HTML 四种导出成品。

## 这条分享在讲什么
X 作者姚金刚（@yaojingang）公开分享了一个 `yao-expert-skill`，强调“如何快速了解一个行业”的核心不在于搜到更多资料，而在于能否在短时间内建立一套可解释、可验证、可迁移的行业认知结构。

## 为什么值得看
- 它不是只给一份综述，而是给一套标准化学习框架。
- 它要求把 `fact / inference / hypothesis / unknown` 分层，能降低伪确定性。
- 它把“学会一个行业”这件事做成了可复用资产，适合新人 onboarding、团队培训和结构化预研。

## 它产出什么
根据 README 与 SKILL.md，主要产出包括：
- source-backed 专家学习报告
- reader-facing 导读摘要
- 边界、分类、价值链、参与者、生命周期、竞争、政策、风险、机会分析
- 50–100 张关键词教学卡
- 专家学习教程
- 10 个费曼自测题及参考答案
- Markdown / DOCX / PDF / HTML 四种导出格式

## 方法论骨架
1. 规范主题、地区、用途、时间范围、深度和排除项
2. 先定边界，再收集事实，避免相邻概念混淆
3. 按结构拆解：分类、价值链、参与者、需求、供给、竞争、生命周期、政策、技术、资本信号
4. 区分 `fact / inference / hypothesis / unknown`
5. 生成关键词教学卡、教程路径和费曼问题
6. 统一导出并校验 HTML / PDF / Word / Markdown

## 为什么比“直接问 AI”更强
- 它固定了章节合同，输出更稳定
- 它把教学设计前置，而不只是堆砌内容
- 它把导出与验收考虑进工作流，天然适合复用与传播

## 最适合谁用
- 进入新行业的新人
- 产品 / 内容 / 销售 / 战略团队
- 创业与投资预研人员
- 想设计知识型 Skill 的 Agent / Workflow 作者

## 边界
- 它强在“快速建立结构化认知”，不等于替代一手访谈和深度尽调
- 上游来源质量仍然决定最终判断质量
- 它能约束研究姿势，但不能魔法般替代研究本身
