SEC 01引入

本地 AI 零碎一堆，折腾到崩溃？

跑本地 AI 通常要装一堆独立工具：模型服务器（ollama / llama.cpp）、聊天 UI、图像生成器、语音栈、agent 无头浏览器。每个工具配一套配置，互相之间没有关联，显存也不知道怎么分配。

LumaBrowser 想做的是：用一个 Chromium 系浏览器，把上面所有东西打包进来，统一管理，统一调度。

npx lumabrowser start Node 18+ 即可，无需手动安装依赖
SEC 02LumaBrowser 是什么

浏览器 + 本地 AI 栈一体化应用

一个跑在你机器上的 Chromium 系浏览器，内置 GPU 感知的 LLM 运行时、聊天与 agent 界面、本地图像/视频/音乐/语音生成，以及浏览器自动化接口，供 Claude Code / Codex / Cline / OpenCode 直接驱动。

SEC 03GPU 感知模型管理

下载前知道能不能跑 · 直挂已有缓存不重下

Models 页面读取你的硬件配置，在每个模型前显示 ✓ FIT 或 ✗ NO 徽章，同时预测 token/s 速度。不用猜显存够不够，下载之前就告诉你。

  • fit 徽章 + 预测速度：下载前预判能否运行、跑多快
  • 直挂已有模型：LM Studio / Ollama / Hugging Face 缓存直接链接，不用重新下载
  • llama.cpp 多运行时：CPU / CUDA 12 / CUDA 13 / Vulkan / Apple Silicon MLX
  • 显存智能分配：按显存定 KV cache 尺寸；选 full / partial / CPU offload；MoE 专家更快时移 CPU
  • 多 GPU / 多机拆分：单模型跨多 GPU，或经 llama.cpp RPC 跨机器拆分（❓多机延迟数据未实证）
npx lumabrowser start # → 打开 Models 页面 # → 搜索 Hugging Face 模型或链接 LM Studio/Ollama/HF 缓存 # → 每个模型显示 fit 徽章 + 预测 token/s
SEC 04agent 标签页隔离

agent 开自己的标签页读网页 · 你的标签页不受影响

当 agent（Claude Code / Codex / Cline / OpenCode）通过 MCP 驱动浏览器时，它只能看到自己创建的标签页，永远看不到用户的标签页。这是安全设计，不是 bug。

✅ 你的登录态、Cookie、书签——外部 agent 一律不可见

示例任务：

搜 llama.cpp 最新 release 告诉我改了什么

→ agent 开自己的标签页读取网页，解析内容，回答你的问题。操作过程对你的标签页零干扰。

  • 用户标签页隔离：MCP/WebDriver/CDP 客户端只见自动化创建的标签页
  • 选择器容错：页面元素变化导致选择器失配时，可让 LLM 重新解析（❓具体 prompt 格式未实抓）
  • Dashboard：聊天与扩展的实时 widget 网格，可同时观察 agent 行为
SEC 05MCP / WebDriver / CDP 三路接入

MCP（Settings 自动写入）/ WebDriver 9515 / CDP 9222 / REST 3000

本地 API 同时说 OpenAI 和 Anthropic 两种格式，无需来回切换适配器。

接口端口默认说明
MCP3000需开启Settings 一键写入 Claude Code / Cline / Codex / OpenCode 配置
WebDriver9515关Selenium 驱动，W3C 协议
CDP9222关Puppeteer / Playwright 原生协议
REST API3000无 key默认无认证，暴露前须设 key
本地模型 API8317可选OpenAI + Anthropic 双格式，同时兼容 LM Studio / Ollama / vLLM

MCP 配置示例（Settings 自动写入，也可手动配置）：

{ "mcpServers": { "luma-browser": { "command": "node", "args": ["<install dir>/resources/app.asar.unpacked/mcp-server.js"], "env": { "LUMA_API_PORT": "3000" } } } }

WebDriver 示例（Selenium）：

driver = webdriver.Remote("http://127.0.0.1:9515", options=options)

CDP 示例（Puppeteer）：

const browser = await puppeteer.connect({ browserURL: 'http://127.0.0.1:9222' });
⚠️ REST API 默认无 key：暴露到局域网/互联网前务必在 Settings 中设置 API key

SEC 08隐私与安全实账

什么数据离开你的机器 · 怎么关

离开机器的内容发往默认关闭方式
用量 ping（版本/平台/机器 ID）lumabyte.com开Settings → About → Privacy
更新检查lumabyte.com开Settings：关闭自动更新检查
扩展目录lumabyte.com仅打开 Extensions 时—
广告拦截列表Ghostery按需—
运行时 / 模型下载GitHub / Hugging Face / 模型托管站按需—
✅ 浏览 / 聊天 / 模型 / 生成媒体 / 文件：100% 本机，零外传
⚠️ 自动化风险：浏览器自动化 = 把浏览器交给 agent。MCP/WebDriver/CDP 客户端能看到的模型数据，背后的 agent 都能看到。只连信任的 agent，保持 API / WebDriver / CDP 端口在 localhost（默认）。
⚠️ 3000 端口 REST API 默认无 key：暴露到不信任的网络前，必须在 Settings 中设 API key。

无 feature 依赖用量 ping，关闭后功能完全不受影响。

术语表

术语含义
webview操作系统自带的浏览器渲染组件（WKWebView/WebKitGTK/WebView2），web 前端方案的基础
llama.cpp本地运行 LLM 的主流推理引擎，支持 CPU/CUDA/Vulkan 等多种后端
MLXApple Silicon 专用的机器学习框架，Mac 上跑 LLM 的高效路径
KV cacheLLM 推理时缓存的键值张量，显存占用的主要变数之一，需按显存定尺寸
offload（full/partial）模型层放到 GPU 还是部分/全部回落 CPU 运行的策略
MoE 专家混合专家模型中的子网络，可单独调度到 CPU 以省显存
MCPModel Context Protocol，Claude Code/Codex 等外部 agent 驱动工具的标准协议
CDP / WebDriver浏览器自动化协议；CDP 是 Chrome DevTools 协议（Puppeteer/Playwright 用），WebDriver 是 W3C 标准（Selenium 用）
AGPL-3.0强 copyleft 开源协议，修改后提供网络服务也需开源
noVNC浏览器里的 VNC 客户端，Docker 部署时用它访问远程桌面
