01 · 项目定位

PocketTTS 是 Kyutai Labs 开源的轻量级文本转语音（TTS）模型，专为 CPU 运行设计，无需 GPU 或云端 API。一行命令即可安装，一行代码即可生成语音。

核心理念

装进 CPU 口袋的 TTS

Forget about the hassle of using GPUs and web APIs. 一行 pip install，一次函数调用，直接生成音频。

性能亮点

超低延迟 · 极速合成

  • MacBook Air M4 仅用 2 核 CPU
  • 生成速度 6 倍于实时播放
  • 首音频块延迟仅 ~200ms
  • 支持无限长文本输入
02 · 核心功能
🎤 声音克隆

20 秒音频即克隆

上传任意 wav 文件作为参考，生成对应音色的语音。推荐提前降噪处理以获得最佳效果。

🌍 多语言支持

6 种语言原生支持

  • English · Français
  • Deutsch · Português
  • Italiano · Español

非英语语言可选用 24 层高质量变体（更大模型，速度略慢）。

🔒 隐私本地运行

数据不出本机

纯本地运行，无网络请求。适合对数据隐私有严格要求的场景（如企业内部应用、医疗、客服等）。

📡 音频流式输出

边生成边播放

支持流式输出，可在首帧音频生成后立即开始播放，无需等待完整合成完成。

🎭 预设音色库

28+ 预置音色

内置 alba, estelle, giovanni, lola, juergen 等多音色，覆盖英/法/德/意/西/葡语。

🖥️ 多端部署

Python / CLI / Server

Python API、CLI 命令、本地 HTTP 服务多模式，支持 Docker、WASM、ONNX Runtime 等多平台。

03 · 快速上手 SOP
pip install
→
CLI 生成
→
播放音频
安装（推荐 uvx）
uvx pocket-tts generate

# 或 pip 安装
pip install pocket-tts
pocket-tts generate

要求：Python 3.10~3.14 + PyTorch 2.5+，无需 GPU 版 PyTorch。

Python API
from pocket_tts import generate_audio

# 基础生成
generate_audio("Hello world", "output.wav")

# 指定音色
generate_audio("Bonjour le monde", "output.wav",
               voice="estelle")
CLI 完整用法
# 指定文本和音色
pocket-tts generate --text "你好世界" --voice alba

# 指定语言（24层高质量模型）
pocket-tts generate --language italian_24l

# 克隆自定义声音
pocket-tts generate --voice ./my_voice.wav
本地 HTTP 服务
# 启动服务
pocket-tts serve

# 访问 http://localhost:8000
# 使用 Web 界面实时合成

服务模式保持模型常驻内存，响应更快，适合频繁调用的应用。

05 · 适用场景
💼 企业内部

私有化 TTS 部署

  • 客服机器人语音播报
  • 内部通知语音化
  • 文档朗读辅助
  • 无外网访问的安全环境
🏥 医疗 / 隐私敏感

数据不离院/本地

  • 患者病历朗读
  • 医疗记录语音转写
  • HIPAA 合规场景
  • 心理咨询 / 隐私对话
🎙️ 内容创作

个人 / 小团队 TTS

  • 播客 / 有声书制作
  • 短视频配音
  • 游戏角色语音
  • 无 GPU 的创作者
✓ 适合 PocketTTS

轻量 / 隐私 / 无 GPU

  • 不需要顶级音质的场景
  • 需要本地离线运行
  • 成本敏感，不想付云 API 费
  • 资源受限的边缘设备
✗ 可能不适合

追求极致音质

  • 专业广播 / 电影配音（需更高保真）
  • 超多语言覆盖（当前仅 6 种）
  • 超大规模并发（考虑云服务）
