# Memos 发布报告

## 结论

`usememos/memos` 是一个开源、自托管、Markdown-native 的快速记录工具。它的核心不是复杂的层级知识管理，而是把随手记录、时间线回看、开放接口和自托管部署压成一个轻量闭环。

## 关键判断

- **定位**：timeline-first 的快速记录层，不是重型知识库系统。
- **核心能力**：Markdown-native、self-hosted、zero telemetry、REST / gRPC API、Docker / binary / Kubernetes 多路径部署。
- **适用场景**：个人速记、临时日志、小团队记录、可回看的轻量知识入口。
- **边界**：如果需要复杂层级、审批流、强协作工作流或深度标签治理，它不是最合适的主系统。
