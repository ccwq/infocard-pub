12个工具补充信息

tool notes
Jellyfish
开源王炸 / 全链路
01
原帖定位

适合从剧本、角色、镜头到成片的一站式折腾，尤其适合想自己搭工作流的人。

补充信息

重点看：社区活跃度、安装门槛、显存/算力需求、角色一致性稳定性。

Kling AI
中文视频生成 / 短剧首选
02
原帖定位

更适合中文语境、对话场景和中式短剧表达，原帖把它放在“丝滑”这一档。

补充信息

重点看：额度、成本、镜头控制、长视频连贯性与地区可用性。

Runway Gen-3
电影级运镜 / 高质感
03
原帖定位

适合要画面质感、运动控制和镜头语言的创作者，偏“高质感成片”。

补充信息

重点看：订阅成本、生成次数、稳定性，以及复杂动作的可控程度。

Luma Dream Machine
奇幻 / 创意短片
04
原帖定位

更适合脑洞型表达、幻想风、视觉想象力强的短片。

补充信息

重点看：创意爆发力与可重复性之间的平衡，别把“惊艳”误当“稳定”。

Pika 2.2
唇同步 / 角色控制
05
原帖定位

原帖强调它适合对话戏和角色控制，特别适合口型、对白和人物动作场景。

补充信息

重点看：角色稳定、口型对齐、复杂动作下的抖动和穿帮。

Viggle AI
照片动起来 / 整活
06
原帖定位

把静态人物、照片变成会动的角色，适合轻量整活和入门实验。

补充信息

重点看：输入照片质量、动作迁移是否自然、风格偏娱乐还是偏实用。

Hedra
数字人口播 / 说话视频
07
原帖定位

更偏口播号、数字人、说话头像这类内容，强调“自然”和“像人”。

补充信息

重点看：口型自然度、表情控制、音画同步与商业使用约束。

Haiper AI
批量产出 / 速度优先
08
原帖定位

适合追求速度、批量尝试和快速迭代的生产型流程。

补充信息

重点看：批量生成的稳定性，以及在速度快的同时是否牺牲画面一致性。

CapCut + AI
后期一条龙 / 剪辑整合
09
原帖定位

适合把前面生成的素材快速剪成可发版本，承担后期、字幕、特效和节奏调整。

补充信息

重点看：版本更新后的 AI 能力差异，以及模板化内容会不会太像“套壳”。

ToonCrafter
开源 / 二次元动画
10
原帖定位

原帖把它定位为卡通动画专攻，适合二次元、漫画风、风格化动画。

补充信息

重点看：风格统一、线条稳定、角色变形控制，以及开源方案的上手成本。

LTX Studio
剧本→分镜→视频
11
原帖定位

适合工作流型创作者：先搭结构，再做分镜，再往视频推进。

补充信息

重点看：是否真能减少沟通成本，而不是只是把流程搬到另一个平台。

Leonardo AI + Motion
图像生成 + 动画模块
12
原帖定位

适合先做图再做动效，用组合拳补足单一工具的短板。

补充信息

重点看：两段式工作流是否顺手，以及图像风格能否稳定迁移到运动层。

适合直接收藏的判断

  • 想零成本先跑通短剧概念。
  • 想把单一工具改成组合工作流。
  • 想找“角色一致性 / 口型 / 后期”分别对应的工具。

使用提醒

  • 免费不等于稳定，先测一致性、额度、导出质量。
  • 先做 15~30 秒样片，不要一上来做长片。
  • 如果要做商业项目，先确认版权、账号和商用条款。
