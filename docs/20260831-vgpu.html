它是什么

不是素材截图，是可运行的 shader 工程

官方定位是 TypeScript WebGPU library，支持 typed shader imports、GPU-first API，以及浏览器、headless Node 和测试中的同一套代码路径。

它解决什么

从“看到效果”到“拿到源码”

交互 examples 可以在浏览器中运行，Agent 通过 CLI 搜索、查看并拉取完整 example 源码，减少凭截图猜实现的过程。

它的姿态

Agent-ready，而不是 Agent-only

文档、examples gallery 和 shader validation 都有 CLI 入口；人可以看效果，Agent 可以读取文档和复制工程素材。

性能默认值

工程接口

Agent 入口

vgpu.sh 提供 agents.md、llms.txt、Examples API 与只读 MCP 入口，便于工具发现资料。

REUSE MAP

从 demo 到产品视觉：适合拿来做什么

✓ 适合

  • 网站首屏的 GPU 背景、光照或粒子效果
  • 视频背景与动态海报的视觉原型
  • 学习 WebGPU / WGSL 的可运行样例
  • 让 Agent 在已有 example 上继续改造

✗ 不要直接假设

  • 不是自动生成完整网站的工具
  • 不是所有浏览器、GPU 和移动设备都能稳定运行
  • example 的效果不能替代性能、可访问性和降级方案
  • 不要未经授权复制受版权保护的品牌或素材
视觉效果 ≠ 生产就绪WebGPU 支持、显卡性能、功耗、移动端限制、shader 编译失败和 fallback 都要在目标设备上验证。拉取源码只是起点，不是部署保证。
