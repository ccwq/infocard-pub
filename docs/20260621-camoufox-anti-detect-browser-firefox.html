Hermes 用户的价值
Hermes Agent 的 browser_navigate / browser_click / browser_snapshot 底层是 Playwright。对于需要绕过反爬检测的大规模抓取或登录态页面操作，Camoufox 是完美的下沉层：只需把浏览器初始化替换成 Camoufox，API 零改动，Hermes 的 Playwright 工具链直接受益。
Hermes Agent 集成方式
🤖 方式一：MCP 浏览器工具层（原生，无需额外代码）
Hermes 内置的 browser_navigate / browser_snapshot / browser_click 等工具底层使用 Playwright。配置 Camoufox 作为底层浏览器引擎后，这些工具全部自动获得反检测能力：
# 配置 Camoufox 为 Hermes browser tools 的底层引擎 # 修改 Hermes 配置 ~/.hermes/config.yaml 或 MCP server 配置： # 方式 A：在 MCP browser 配置中指定 camoufox browser: provider: "camoufox" args: headless: true fingerprint_preset: "v149" # 使用 Firefox 149+ 真实指纹 os: "macos" # 模拟 macOS 设备 ad_block_level: 2 # 屏蔽广告提升加载速度 # 方式 B：CDP 端口接管（高级） # 1. 先用 Camoufox 启动带调试端口的浏览器 python -m camoufox server --cdp-port 9222 --headless # 2. Hermes 连接到 Camoufox 的 CDP 端口 browser: cdp_url: "http://localhost:9222"
💡 效果：配置完成后，Hermes 的所有 browser_navigate、browser_snapshot、browser_click、browser_type 工具在反检测环境下运行，无需改任何任务代码。
🐍 方式二：Hermes Script 中直接调用（精细控制）
在 Hermes 的 execute_code 或 terminal 工具中直接使用 Camoufox API：
from camoufox.sync_api import Camoufox # 在 Hermes execute_code 中运行：反检测 + 指纹随机 + 住宅IP轮换 with Camoufox( fingerprint_preset="v149", os="macos", proxy="http://username:password@proxy.example.com:8080", headless=True, ad_block_level=2 ) as browser: page = browser.new_page() page.goto("https://target-site.com") content = page.content() # 配合 browser_vision 截图让 Hermes 做视觉验证 # 异步版本（配合 Hermes 异步工作流） from camoufox.async_api import AsyncCamoufox async def fetch_with_camoufox(url): async with AsyncCamoufox(fingerprint_preset="v149") as browser: page = await browser.new_page() await page.goto(url) return await page.content()

💡 为什么是 Camoufox 而非 undetected-chromedriver / Stealthbot：Camoufox 基于 Firefox C++ 层注入（JS 检测代码完全不可见），后两者基于 JS 注入（可通过 Object.getOwnPropertyNames(window) 等底层 API 检测到）。
指纹注入清单（C++ 层）
Navigator 属性 Canvas 反指纹 WebGL 参数 WebRTC IP 欺骗 屏幕 / viewport 尺寸 时区 / locale / Intl 字体列表 spoofing AudioContext 参数 鼠标轨迹（类人） Battery API User-Agent 匹配 navigator.webdriver 修复 headless 指针检测修复
Firefox ≥ 149 版本加载 bundled presets：67 个 macOS / 180 个 Windows / 65 个 Linux 真实指纹，每次运行随机分配，融入真实设备统计分布。
竞品对比
✅ Camoufox（Firefox）
  • C++ 层指纹注入，JS 检测代码不可见
  • Playwright / Puppeteer 零改动接入
  • 312 个真实设备指纹（v149+）
  • 每次运行全新身份，随机轮换
  • headless 模式不可被识别
  • WebRTC IP 欺骗，类人鼠标轨迹
❌ undetected-chromedriver
  • JS 注入层，可被底层 API 检测
  • 仅 Chrome，Firefox 不支持
  • Chromium 内核检测面更窄
  • 指纹固定，关联风险高
  • 维护状态不稳定
  • 无原生 Playwright 支持
核心反检测机制
🛡️
main world 隔离
所有 page agent JavaScript 被沙箱隔离，避免注入脚本泄露给目标页面。
🦊
修复 headless 检测
修复 navigator.webdriver 和 Firefox headless 指针类型检测，headless 模式不可被识别。
🎯
指纹随机分布
未指定值由 BrowserForge 按真实设备统计分布自动填充，融入正常流量而非暴露异常。
🚫
广告屏蔽 + 性能优化
内置广告拦截（可调级别）、CSS 动画禁用、内存优化去膨胀，提升抓取速度。
安装与配置
① 安装 Camoufox
推荐使用 cloverlabs 分支获取最新补丁，兼容性更好。
pip install camoufox # 或获取最新补丁版（推荐 v149+） pip install cloverlabs-camoufox # 同步更新预发布版浏览器 python -m camoufox sync
② 获取真实指纹 preset
Firefox ≥ 149 内置 312 个真实指纹，首次使用建议运行 sync 获取最新版本。
python -m camoufox fetch # 拉取最新浏览器版本 python -m camoufox list # 列出可用指纹 preset
③ 基本使用（同步 / 异步）
API 与 Playwright 完全兼容，只需替换浏览器初始化一行代码。
from camoufox.sync_api import Camoufox # 替换 playwright.sync_api with Camoufox( fingerprint_preset="v149", os="macos", ad_block_level=2 ) as browser: page = browser.new_page() page.goto("https://example.com") print(page.title()) # 异步版本（配合 Hermes 异步工作流） from camoufox.async_api import AsyncCamoufox async def main(): async with AsyncCamoufox() as browser: page = await browser.new_page() await page.goto("https://example.com")
④ CDP 调试模式（高级）
启动带调试端口的 Camoufox，供外部工具（如 Hermes CDP 工具）通过 Chrome DevTools Protocol 控制。
python -m camoufox server --cdp-port 9222 --headless # 然后在 Hermes 配置中指向该端口 # browser.cdp_url: http://localhost:9222
典型 Hermes 工作流
🌐 场景一：绕过登录态 + 反爬页面抓取
登录态页面、含验证码、有反爬检测的站点。用 Camoufox 初始化浏览器后，Hermes 工具链全部在反检测环境中运行。
# Hermes execute_code 中：登录态 + 反检测抓取 from camoufox.sync_api import Camoufox with Camoufox( fingerprint_preset="v149", os="windows", headless=True ) as browser: page = browser.new_page() page.goto("https://example.com/login") # 填入账号密码（Hermes browser_type 工具配合） page.fill("#username", "user@example.com") page.fill("#password", "password123") page.click("button[type=submit]") page.wait_for_load_state("networkidle") # 抓取登录后的数据 data = page.inner_text("body") browser.close()
🖼️ 场景二：配合 browser_vision 做视觉验证
Hermes 的 browser_vision 可对 Camoufox 渲染的页面截图做 AI 识别，判断渲染结果是否正确（绕过 JS 动态加载的验证码等）。
# Camoufox 渲染页面 + Hermes browser_vision 截图验证 with Camoufox(fingerprint_preset="v149") as browser: page = browser.new_page() page.goto("https://captcha-page.com") page.screenshot(path="/tmp/hermes_vision_input.png") # → Hermes browser_vision 分析截图内容 # → 判断是否为验证码，决定是否继续或换 IP # 反向：用 browser_vision 确认登录成功，跳过后续验证 page.screenshot(path="/tmp/login_result.png") # → Hermes vision 分析，确认是否到达目标页面
代理 IP 配合
指纹伪装 + 住宅 IP 轮换 = 反检测双重保险。单独使用任一效果都会打折扣。推荐代理类型：住宅 IP（Residential Proxy），不要用数据中心 IP。
with Camoufox( fingerprint_preset="v149", proxy="http://username:password@residential-proxy.example.com:8080" ) as browser: page = browser.new_page() page.goto("https://target-site.com") # 推荐代理服务商（赞助商代理，非背书） # Scrapfly / Crawlbase / Proxy-Seller / MangoProxy / NodeMaven
边界与局限
⚠️ 开发中警告：项目标注"under development"，不适合追求稳定生产使用的场景。
限制项 说明 Hermes 用户建议
生产稳定性 标注"开发中"，API 可能有 break change 开发测试阶段优先使用；生产环境加 fallback 逻辑
PyPi 版本延迟 稳定版有延迟，最新补丁需用 cloverlabs 分支 生产环境用 pip install cloverlabs-camoufox
单独指纹效果有限 成熟反爬系统可能仍能检测运动轨迹、IP 模式 必须配合住宅 IP 轮换使用
合规性 禁止用于账户劫持、非法登录绕过 仅用于公开数据抓取、AI Agent 自动化、合规研究
Firefox only 仅支持 Firefox 内核 Chrome 站点需评估是否适配；大部分站点 Firefox 均可访问
