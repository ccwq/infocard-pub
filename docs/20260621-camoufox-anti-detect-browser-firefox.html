📖 为什么值得看

普通浏览器跑爬虫脚本，一访问就触发检测：navigator.webdriver、Canvas 指纹、WebGL 参数、鼠标轨迹——反爬系统把这些信号串起来，就能把你认出来。

Camoufox 是 Firefox 内核，专门解决这个问题。它把指纹注入做到 C++ 层（而不是 JS 注入），Playwright API 完全兼容，pip install 后改一行代码就能跑，GitHub 9.4K ⭐。

每次运行拿到一个全新身份，模拟真实设备统计分布，融入正常流量而不是暴露自己。
一句话

Camoufox 是一个基于 Firefox 的反检测浏览器：把指纹注入做到 C++ 内核层（JS 检测不到），Playwright API 完全兼容，让爬虫和 AI Agent 在不被认出的情况下规模化运行。

🔄 两种方案对比
❌ 普通 Playwright / Selenium
  • navigator.webdriver = true
  • Canvas / WebGL 留下自动化指纹
  • headless 模式可被检测
  • 指纹参数固定，容易被关联
  • 鼠标轨迹像机器
  • 每次运行身份一致
✅ Camoufox
  • navigator.webdriver 已修复
  • C++ 层注入，JS 检测不到
  • 无头模式不可被识别
  • 指纹随机轮换，模拟真实分布
  • 类人鼠标轨迹
  • 每次运行全新身份
⚙️ 底层原理：C++ 层指纹注入

Camoufox 的指纹注入发生在 C++ 实现层，数据修改在浏览器内核完成，JavaScript 无法通过检测代码发现异常——这是它和 JS 注入方案的本质区别。

未指定的值由 BrowserForge 自动填充，模拟真实设备统计分布。也可指定真实采集的指纹 preset：

# 使用真实指纹 preset（推荐 v149+ 版本）
with Camoufox(fingerprint_preset=True, os="macos") as browser:
    page = browser.new_page()
    page.goto("https://example.com")
Firefox ≥ 149 版本加载 bundled presets（含 312 个真实指纹：67 macOS / 180 Windows / 65 Linux）。

含最新补丁，推荐 v149+ 使用。

💻 使用示例
同步 API（与 Playwright 完全兼容）
from camoufox.sync_api import Camoufox

with Camoufox() as browser:
    page = browser.new_page()
    page.goto("https://example.com")
异步 API
from camoufox.async_api import AsyncCamoufox

async with AsyncCamoufox() as browser:
    page = await browser.new_page()
    await page.goto("https://example.com")
只需把 Playwright 的浏览器初始化换成 Camoufox，API 完全兼容。

🛡️ 反检测机制
  • 避免 main world execution leaks，所有 page agent JavaScript 被沙箱隔离
  • 避免 frame execution context leaks
  • 修复 navigator.webdriver 检测
  • 修复 Firefox headless 模式指针类型检测
  • 移除可能泄露的 anti-zoom / meta viewport 处理
  • 使用非默认 screen / window 尺寸
  • 重新启用 fission content isolation
  • 重新启用 PDF.js
  • 类人鼠标移动轨迹
  • 屏蔽并绕过广告
  • 禁用 CSS 动画（提升性能）
  • 内存优化 / 去膨胀
🌐 代理集成

Camoufox 建议配合轮换代理（推荐住宅 IP）使用。支持赞助商代理服务：Scrapfly / Crawlbase / SerpApi / Talordata / Thordata / ProxyEmpire / BirdProxies / Proxy-Seller / RapidProxy / Swiftproxy / MangoProxy / 9Proxy / NodeMaven。

指纹 + 住宅 IP 轮换 = 反检测双重保险；单独使用任一效果都会打折扣。
📌 边界说明
  • 开发中警告：项目明确标注"under development"，不适合追求稳定生产使用
  • 合规使用：用于公开数据抓取、AI Agent 自动化和反爬绕过研究；不应用于账户劫持、非法登录绕过或违规数据采集
  • Proxy 依赖：指纹伪装需配合真实住宅 IP 才能发挥最佳效果，单独使用可能对成熟反爬系统效果有限
  • 版本延迟：PyPi 稳定版有延迟，最新补丁需用 cloverlabs-camoufox
