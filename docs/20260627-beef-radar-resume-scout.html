一句话结论

牛肉项目雷达不是项目链接合集，而是"项目筛选 + 源码验证 + 简历表达"的完整工作流。

它解决的核心问题是：很多求职者不是找不到开源项目，而是不知道什么项目真的值得写进简历、经得起面试官追问源码、链路和异常处理。

核心判断：如果你在找"能真正基于源码说清楚技术难点"的项目，而不是按 star 排行的链接列表，这个 Skill 值得看。
它解决什么问题
不按 star 选项目 淘汰 demo / 浅 CRUD 源码证据优先

README 明确列出五类常见失败模式：按 star 数找项目、误把 demo 当项目、不知道哪些模块有技术难点、简历写法容易虚、AI Agent 项目缺乏业务闭环。

不替代经历：Skill 会告诉你哪些是原项目已有能力、哪些适合二次改造、哪些改造后可写简历——但最终动手的仍是你自己。
01
核心能力一览
把 README 里的能力拆成七块可决策的功能，而不是只剩"找项目"三个字。
能力 具体做法
项目搜索 从 GitHub / Web 搜索当前可用的后端项目和业务型 AI Agent 项目，覆盖电商交易、CRM / ERP、协作办公、工单客服、知识库、Agent 工作流等方向。
反热门陷阱 不迷信 star 数，主动覆盖中等热度和细分领域项目，避免同质化和过热赛道。
浅层项目淘汰 默认排除 demo、薄封装、纯框架、浏览器插件、简单聊天机器人和浅层 CRUD。
源码证据验证 最终入选项目必须拉取本地源码验证。不能只靠 README、网页描述或模型记忆来判断。
简历写法生成 输出项目简介、源码验证摘要、负责功能 / 技术难点、建议改造方向和面试可追问点。
双格式交付 默认生成 Markdown 和 PDF 两个版本的项目简历包。
工作流完整闭环 用户画像 → 联网搜索 → 候选池筛选 → README probe → 短名单确认 → 源码拉取 → 证据提取 → 输出简历包。
02
五种推荐模式
找项目前必须先选模式——这是 Skill 强制的前置门控，不会默认开始搜索。
模式 说明
agent-only 只推荐完整业务型 AI Agent 项目。
backend-only 只推荐传统软件后端项目，默认排除 IoT / 硬件接入类项目。
mixed 推荐一个 Agent 项目 + 一个传统软件后端项目。
safe-mode 推荐容易落地、依赖少、部署成本低的项目。
challenge-mode 推荐更难、更有差异化、更适合深度改造的项目。
Use $backend-agent-project-selector 推荐模式：mixed 帮我找 1 个业务型 Agent 项目和 1 个传统软件后端项目， 并生成简历写法。

设计原则

• 先选方向，再找项目——Skill 不会默认替用户选模式

• 源码证据优先——README 只能做前置筛选

• 建议改造不冒充已完成——区分已有能力和可写建议

05
适合谁 / 不适合谁
把使用边界说清楚，不把工具吹成万能。
适合

• 想找后端实习 / 校招项目的学生。

• 想从普通 CRUD 项目升级到业务闭环项目的后端候选人。

• 想把 AI Agent 项目写进简历，但不知道怎么选题的人。

• 想准备 Java / Python / Go / Node.js 等后端项目亮点的人。

• 想知道如何回答"你看过源码吗？""异常怎么处理？""状态怎么流转？"这类追问的人。

不适合

• 完全不打算自己动手部署、阅读和改造源码的人。

• 只想拿到一份可以直接 Copy 进简历的现成描述、不愿核实内容的人。

• 对技术选型方向完全不明确、连想找什么类型的项目都没有概念的人。

• 期望 Skill 替你伪造经历、不愿意承担项目真实性核查后果的人。

适用边界：Skill 会告诉你哪些是原项目已有能力、哪些适合二次改造、哪些改造后可写简历。但最终写进简历前，仍然需要你完成对应阅读、部署、改造或实现。
06
安装方式
把 Skill 目录复制到 Codex 的 Skills 目录即可，无需构建。
# macOS / Linux mkdir -p ~/.codex/skills cp -R backend-agent-project-selector ~/.codex/skills/ # Windows PowerShell New-Item -ItemType Directory -Force "$env:USERPROFILE\.codex\skills\" Copy-Item -Recurse -Force .\backend-agent-project-selector "$env:USERPROFILE\.codex\skills\"
# 使用示例 Use $backend-agent-project-selector 推荐模式：mixed 帮我找项目。
