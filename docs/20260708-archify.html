ARCHIFY · MIT · DIAGRAM SKILL

一句自然语言，直接长出架构图

tt-a1i/archify 把“画架构图”这件事压缩成自然语言描述：装进 Claude、Codex CLI 或 opencode 后，你只要说明系统结构或流程，它就能生成自包含 HTML 架构图，并支持明暗切换、剪贴板复制以及高分辨率导出。

01
WHAT IT DOES

它不是画图网站，而是 Agent 技能

README 直接把 Archify 定义成一个 agent skill，面向 Claude、Codex CLI 和 opencode。核心产物不是截图，而是一个自包含 HTML 文件：可打开、可切换主题、可复制 PNG、可导出 PNG / JPEG / WebP / SVG。

一句话：它把“自然语言 → 技术图”变成了可复用的命令型工作流，而不是手工拖组件。
02
OUTPUT TYPES

不止架构图，还覆盖 5 种技术图

Archify 当前主打五种输出：Architecture、Workflow、Sequence、Data Flow、Lifecycle。也就是说它不只是画系统模块，还可以讲清审批链、调用链、数据流和状态生命周期。

Architecture系统组件、边界、数据库、缓存、云资源
Workflow审批流、CI/CD、runbook、工具调用
Sequence接口调用顺序、鉴权链、缓存回退
Data Flow数据管线、PII 边界、ETL/ELT
Lifecycle状态机、重试、取消、终态
03
WHY IT'S INTERESTING

它把“好看”和“可交付”绑在了一起

README 强调了几个关键点：明暗主题切换、复制 PNG 到剪贴板、最高 4× 光栅导出、SVG 跟随系统明暗、验证循环内建、自包含 HTML 零依赖。也就是说它同时考虑了审美、分享和工程可靠性。

和普通 Mermaid 的差异

  • 不是只吐一段 DSL
  • 内建导出与主题切换
  • 更偏技术沟通成品，而非草图
  • 有 schema / layout / artifact 校验环

适合谁

  • 用 Claude / Codex 做系统设计的人
  • 要写方案、PRD、架构说明的人
  • 想把聊天结果直接变分享资产的人
  • 不想手动画图但又要保留结构感的人
04
HOW TO USE

最小路径：安装技能 → 描述系统 → 让 Agent 生成

README 的 Quick start 结构很清晰：先安装 skill，再用自然语言描述你的系统或流程，再让 Claude 使用这个 skill。后续通过聊天继续迭代，比如加 Redis、移动认证模块、换配色。

支持入口

Claude、Codex CLI、opencode 都在 README 首段被列为直接支持对象。

适合场景

系统设计、技术分享、请求生命周期、数据边界、架构评审、交付文档配图。

05
BOUNDARY

边界：它解决“表达架构”，不替你做架构决策

Archify 可以把口头描述变成图，但前提是你已经有较清晰的系统结构。它更像架构表达放大器，而不是自动架构师：需求含糊时，输出图也会跟着含糊。
