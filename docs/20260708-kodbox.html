04 快速上手
# Docker 一键部署（推荐）
docker run -p 8888:8888 -v /your/data:/var/www/html/data kodbox/kodbox
# 或手动安装（Nginx + PHP）
git clone https://github.com/kalcaddle/kodbox.git
cd kodbox && chown -R www-data:www-data data/
🏠 访问地址
http://localhost:8888
🔑 默认账号
admin / admin（首次登录请立即修改）
💾 挂载存储
设置 → 存储管理 → 添加 S3/WebDAV/OSS
🌐 公开分享
右键文件 → 分享 → 生成链接或密码保护
