输入一个域名，SpiderFoot 自动摸清这家公司暴露在公网上的全部资产。

SpiderFoot 把子域名枚举、DNS 查询、端口扫描、banner 抓取串成一条自动化流水线——模块之间用发布订阅方式互相喂数据，一个模块挖到的域名自动变成下一个模块的输入，跑完直接导出 CSV 或 JSON。它自带 YAML 关联规则引擎，能把散落的线索自动串成同一条结论，Nmap、WhatWeb、CMSeeK 等外部工具也能挂进来一起跑。工具本身中立，是否授权扫描是使用者自己的事。

01 核心能力
STEP 01

子域名枚举

被动/主动发现目标关联的所有子域名，为后续流水线提供入口数据。

STEP 02

DNS 查询

自动解析 IP、MX、TXT、NS 记录，构建域名→IP 映射表。

STEP 03

端口扫描

对每个 IP 执行端口枚举，识别暴露服务和潜在攻击面。

STEP 04

Banner 抓取

获取服务指纹（Web 服务器、数据库、中间件版本），辅助漏洞研判。

所有步骤由发布订阅引擎自动串联，一个模块的输出自动流向下一个模块。

事件总线驱动

数据导出

CSV / JSON / 图表

支持结构化导出，便于后续分析、整合到 SIEM 或生成可视化报告。

03 关联规则引擎

YAML 关联规则 · 自动化结论生成

SpiderFoot 内置 YAML 规则引擎，可将零散线索自动串联成有意义的结论，例如将某 IP 的开放端口 + 检测到的 SSL 证书 + 历史 DNS 记录关联为"存在风险的外网服务"。

YAML 规则

声明式关联

用 YAML 描述"如果 X 和 Y 同时出现，则推断 Z"的逻辑，无需写代码。

外部集成

Nmap · WhatWeb · CMSeeK

主流安全工具可作为外部模块接入，扩展 SpiderFoot 的数据采集能力。

可视化

内置 Web UI

提供 Web 界面实时查看扫描进度和结果图表，无需命令行操作。

05 适用边界
⚠ 工具中立 · 使用者自担授权责任

SpiderFoot 是中立的自动化工具，可用于授权的安全测试、资产自查、红蓝对抗训练。扫描谁、是否在授权范围内进行，是使用者自己的责任。建议在获得明确书面授权后对目标执行扫描。

✓ 适用场景

授权安全测试

对自有资产做安全自查、渗透测试前的信息收集、应急响应中的暴露面梳理。

✗ 风险场景

未授权扫描

对未获授权的目标执行端口扫描或主动探测可能违反当地法律法规。
