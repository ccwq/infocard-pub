工作原理
how it works
职责清晰roles

每个 agent 只负责自己的 domain，并有明确的升级路径和质量门，不再一个会话兼任所有角色。

流程命令化skills

从设计系统到故事落地、从平衡检查到回归测试，全部变成 slash command 驱动的显式流程。

自动验证hooks

在 commit / push / asset change / session lifecycle 上做验证与审计，减少“做完才发现错了”。
