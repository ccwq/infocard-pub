为什么值得看

AI 编程工具每次调用 git status、cat、pytest 等命令时，原始输出动辄数千 token。RTK 在命令和 LLM 之间插入一层透明代理，用四种策略压缩输出：一个 30 分钟的 Claude Code 会话从 ~118,000 token 降到 ~23,900，节省 80%。支持 14 种 AI 编程工具的 Hook 自动改写，安装后零侵入。

工作流

一句话 → 压缩后的精准输出

你照常写 git status，RTK 自动拦截 → 过滤 → 压缩 → 只返回 LLM 需要的核心信息

01
核心机制

四种压缩策略

RTK 针对不同命令类型应用不同策略组合，在保留 LLM 所需上下文的前提下最大化压缩率。

① 智能过滤

移除注释、空白行、样板文本等噪声内容。例如 ls -la 的权限/用户/时间列被剥离，只保留文件名和结构。

② 分组聚合

将相似条目合并。文件按目录分组、错误按类型聚合，减少重复结构。

③ 截断保留

保留相关上下文，裁剪冗余段落。测试输出只保留失败项，构建日志只保留错误行。

④ 去重合并

合并重复日志行并附计数。docker logs 中 100 行重复变为 ×100 一行。

失败兜底：当命令失败时，RTK 自动保存完整未过滤输出到 ~/.local/share/rtk/tee/，LLM 可直接读取，无需重新执行。配置项 tee.mode 可选 failures（默认）/ always / never。

05
上手指南

安装与快速开始

四种安装方式，Homebrew 最快。安装后一条命令初始化 Hook，重启 AI 工具即可自动生效。

安装
# Homebrew（推荐）
brew install rtk

# Linux/macOS 快捷安装
curl -fsSL https://raw.githubusercontent.com/rtk-ai/rtk/refs/heads/master/install.sh | sh

# Cargo
cargo install --git https://github.com/rtk-ai/rtk

# 验证
rtk --version    # rtk 0.28.2
rtk gain         # 查看节省统计

⚠️ crates.io 上存在另一个同名包 "rtk"（Rust Type Kit）。如果 rtk gain 失败，说明装错了，请用 cargo install --git 方式安装。

初始化 Hook
# Claude Code / Copilot（默认）
rtk init -g

# 其他 AI 工具
rtk init -g --gemini          # Gemini CLI
rtk init -g --codex           # Codex (OpenAI)
rtk init -g --agent cursor    # Cursor
rtk init -g --agent windsurf  # Windsurf
rtk init --agent hermes       # Hermes
rtk init -g --auto-patch      # 非交互（CI/CD）

# 重启 AI 工具后测试
git status  # 自动改写为 rtk git status

初始化后必须重启 AI 工具才能生效。卸载：rtk init -g --uninstall

06
配置 & 隐私

精细控制与数据安全

RTK 的配置文件位于 ~/.config/rtk/config.toml，支持命令排除、失败兜底等选项。遥测默认关闭，需显式 opt-in。

配置文件

[hooks]
exclude_commands = ["curl", "playwright"]

[tee]
enabled = true
mode = "failures"  # failures / always / never

排除特定命令不经过 RTK 改写。失败时自动保存完整原始输出供 LLM 读取。

隐私与遥测

  • 默认关闭，需 rtk telemetry enable 显式同意
  • 仅收集匿名聚合数据：命令计数、token 节省量、OS/版本
  • 不收集：源码、文件路径、命令参数、密钥、环境变量
  • 支持 rtk telemetry disable 撤回 / rtk telemetry forget 删除
  • 环境变量 RTK_TELEMETRY_DISABLED=1 强制阻断
07
场景 & 边界

什么时候用，什么时候不用

RTK 不是银弹。了解它的适用场景和边界，才能最大化收益。

✓

适合用

日常 AI 编程会话中大量调用 git、cat、grep、test、build、lint 等命令。中型以上项目的 token 成本敏感场景。多 Agent 并行会话的 token 爆炸问题。

!

注意限制

Hook 仅作用于 Bash 工具调用。Claude Code 内置 Read/Grep/Glob 不经过 Hook，需手动 rtk read。Windows 原生不支持 Hook（需 WSL）。

×

不适合

需要原始完整输出的调试场景（可 rtk proxy <cmd> 透传）。非 LLM 驱动的纯人工 CLI 操作。需要精确控制输出格式的管道脚本。
