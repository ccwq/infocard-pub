AUK-FLASH / SPEECH MODEL FIELD GUIDE1.5B · 4-STEP · TTS / EDIT / SEPARATE
TENCENT HUNYUAN · DISTILLED SPEECH MODEL · MIT

4 步语音生成只是入口，先把任务、权重、显存和许可证对齐

AuK-Flash 是 Tencent AuK 1.5B foundation model 的 distilled variant，固定 4 个时间步、CFG=0，使用统一的自然语言指令接口处理语音生成与编辑。它可以做 zero-shot / instruct TTS、内容和声学编辑、情绪/音色/口音转换、增强与人声/音乐分离；但“支持任务”不等于每个输入都无需参考音频、无需指定时长或无需 GPU 适配。

先做任务路由

你要生成、改写，还是只保留某一类声音？

生成：无参考音频的 Instruct TTS，或带参考音频的 Zero-shot TTS。
编辑：内容、歌词、音调、速度、音量、情绪、音色、口音、非语言声音和耳语。
清理：去噪、去混响、语音分离、音乐分离、目标说话人提取。

00

一张架构图：输入音频、自然语言指令与模型输出

把统一接口拆开看，才知道一个任务缺哪项输入、输出是否应等长。

INPUT / 输入

  • 自然语言 instruction（始终需要）
  • 参考/源音频（按任务需要）
  • 目标时长 gen_seconds（TTS/内容/速度等任务常需）
  • AuK-Flash checkpoint + Qwen2.5-Omni-3B

CORE / 4-STEP ENGINE

  • 1.5B AuK foundation model 的蒸馏变体
  • 4 fixed time steps
  • CFG=0
  • 统一 ChatML-style messages
  • CLI / Python / Gradio / ComfyUI

OUTPUT / 输出

  • 语音生成或编辑 WAV
  • 同长度：音调、音量、情绪、增强、分离等
  • 变长度：TTS、速度、增删非语言声音
  • 按任务检查音色、内容、时长和残留噪声

跑一条 CLI

先用短音频/短文本验证输出，再接 Prompt Enhancer。

# 官方代码仓库 git clone https://github.com/Tencent-Hunyuan/AuK cd AuK # uv：核心推理 uv venv --python 3.10 source .venv/bin/activate uv pip install -e . # 仅按需安装 uv pip install -e ".[gradio]" uv pip install -e ".[comfyui]" uv pip install -e ".[train]" # 下载 AuK-Flash 与运行时编码器 pip install -U "huggingface_hub[cli]" hf download tencent/AuK-Flash --local-dir ./ckpts/AuK-Flash hf download Qwen/Qwen2.5-Omni-3B --local-dir ./ckpts/Qwen2.5-Omni-3B
权重关系：模型卡说明 checkpoint 含 diffusion transformer 与 layer-fusion 权重；MLLM encoder 和 VAE 在运行时从独立文件加载。加载时缺少 text_encoder.* keys 可能是预期现象。
02

最小 CLI 路径：先做一次内容编辑，再判断是否需要 4 步 Flash

所有任务都用 instruction；是否带 audio、是否指定 gen_seconds，取决于任务。

# 内容编辑：replace / insert / remove auk-infer \ --audio assets/demo-input-audio/content-edit/content.wav \ --instruction "Replace 'but accepting what we cannot have' with 'and living well with dreams unmet'." \ --output out_content_edit.wav \ --gen_seconds 7.0 # Zero-shot TTS：参考音频 + 目标文本 auk-infer \ --audio assets/demo-input-audio/zero-shot-tts/ref.wav \ --instruction "Say the following with the same voice: 'Welcome to the demo.'" \ --output out_tts.wav \ --gen_seconds 3.0 # AuK-Flash：固定 4 步、CFG=0 auk-infer \ --ckpt ckpts/AuK-Flash/auk_flash.safetensors \ --audio assets/demo-input-audio/zero-shot-tts/ref.wav \ --instruction "Say the following with the same voice: 'Welcome to the demo.'" \ --output out_flash.wav \ --gen_seconds 3.0
任务audiogen_seconds输出/验收
Instruct TTS可省略必须给正时长或 gen_text按声音描述生成文本内容
Zero-shot TTS需要参考音频指定目标时长内容正确、音色相似、无明显断裂
内容编辑需要源音频通常指定替换/插入/删除成立，前后语音连续
音调/音量/情绪需要源音频通常省略，输出等长目标属性变化，内容和说话人保留
速度/增删非语言声音需要源音频按目标长度指定长度变化符合指令，无额外内容漂移
增强/分离需要源音频通常省略，输出等长保留对象正确，噪声/其他声源减少
03

统一指令接口的真正用法：把“想怎么改”写成保留条件

一句“变清晰”不够；要同时写清保留谁、去掉什么、长度是否保持。

保留内容

“保持说话人音色与文本不变，将情绪改为平静。”

指定对象

“只保留第 2 个开始说话的人，去掉其他说话人。”

指定长度

“输出等长的纯净语音。”或明确 --gen_seconds。

# 语音增强：保留所有说话人，去除噪声与混响 auk-infer \ --audio assets/demo-input-audio/se/se-zh-1-input.wav \ --instruction "Preserve all speakers, remove noise and reverberation, and output clean speech of the same length." \ --output out_enhance.wav # 目标说话人提取：用内容识别对象 auk-infer \ --audio assets/demo-input-audio/ss/en-1-input.wav \ --instruction 'Keep only the speaker who says "get what" and remove all other speakers.' \ --output out_tse.wav

显存与运行方式：A800 测量值只能帮助你做第一轮预算

官方 README 提供 CPU offload 开关与 A800-SXM4-80GB bf16 测量；实际使用必须按输入长度、dtype、硬件和版本复测。

模型/输入offload 关闭offload 开启解释
AuK / text only / 1.5s24.78 GiB16.75 GiB约省 8.03 GiB；官方 A800 测量
AuK / 5s reference25.00 GiB16.98 GiB参考音频会改变占用
AuK-Flash / text only24.77 GiB16.75 GiB4 步不等于零显存
AuK-Flash / 5s reference24.97 GiB16.98 GiB约省 7.99 GiB；非通用保证
# CUDA 推理降低峰值显存（默认关闭） auk-infer --cpu_offload ... # 运行前至少确认 nvidia-smi python -c "import torch; print(torch.cuda.is_available())" # ROCm / AMD 请按官方环境与设备参数配置，不要复制 CUDA 旗标。
05

Gradio、Prompt Enhancer 与 ComfyUI：便利入口会带来新的依赖和数据路径

交互式 demo 不是更安全的默认值；先判断本地 ASR、云端 ASR 和 LLM 调用是否符合数据边界。

Gradio

auk-gradio 可加载 Base/Flash；默认 dtype bf16、host 0.0.0.0、port 7860，模型可按 GPU 分配。

Prompt Enhancer

使用 OpenAI-compatible LLM 环境变量；音频任务可调用 Tencent Cloud ASR，缺少配置时使用本地 SenseVoiceSmall fallback。

ComfyUI

安装 .[comfyui]，把节点放进 custom_nodes；官方 guide 说明 source+target 共享 30 秒限制。

# Gradio：仅 Flash auk-gradio \ --flash_ckpt ckpts/AuK-Flash/auk_flash.safetensors \ --flash_device cuda:0 # Prompt Enhancer 的云端依赖（示意占位，不要提交真实密钥） export LLM_API_KEY="[REDACTED]" export LLM_BASE_URL="https://example.invalid/v1" export LLM_MODEL_NAME="your-model" # 真实使用前阅读 .env.example 与官方安全说明
隐私边界：Prompt Enhancer 可能把任务指令/音频相关内容交给配置的 LLM 或云端 ASR；本地 fallback、GPU offload 与 MIT 许可证都不能替你确认第三方数据处理条款。
06

故障排查：把“生成失败”拆成权重、设备、输入、时长四类

先确认最小事实，再加功能；不要一上来同时启用 Gradio、Prompt Enhancer 和 ComfyUI。

现象第一检查下一动作
找不到模型文件checkpoint/config/VAE/encoder 目录按模型卡目录结构重新下载，确认路径参数
显存不足GPU、dtype、输入长度、reference audio短音频/短文本 → --cpu_offload → 降低并发
输出时长不对任务是否需要 gen_seconds按 Cookbook 对 TTS/速度/增删任务设置目标长度
内容编辑漂移instruction 是否写保留条件与原文锚点用更短源音频，明确 replace/insert/remove
分离对象错误说话顺序/目标内容是否明确先做短片段，人工听辨，再扩大输入
云端调用失败LLM URL、模型名、ASR credentials先关闭 PE，直接跑本地 CLI；不要把密钥写进仓库
07

许可证、版本与适用边界

模型卡和代码仓库都写 MIT；下载权重、代码、第三方依赖和外部模型仍应分别留意其条款。

代码与权重

AuK 代码仓库 LICENSE 与 AuK-Flash 模型卡 LICENSE 均声明 MIT；分发时保留版权与许可文本。

版本事实

HF 模型卡把 AuK-Flash 标为 4-step distilled variant；代码仓库当前无 GitHub Release/Tag，使用 main 时应锁定提交或记录下载日期。

适合 / 不适合

适合语音生成、编辑、增强、分离实验与应用原型；不等于声音身份授权、商用合规、无偏差结果或所有语言/设备的质量保证。
