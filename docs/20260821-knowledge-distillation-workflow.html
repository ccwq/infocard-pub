1
文章存档
找到博主的文章页面，将文章正文复制保存为 .md 文件。保留原始链接，便于溯源。
# 手动操作示例 # 复制文章正文 → 保存为 .md # 文件命名建议：博主名_文章标题.md
✓ 最简单路径
✓ 保留原始链接
2
短视频采集
使用 Get笔记（现名「得到大脑」）CLI，批量采集该博主所有短视频口播文字稿。
# 安装 Get笔记 CLI npm install -g deepli NOTE # 批量采集博主视频文字稿 deepli batch-crawl --author 博主ID --output ./transcripts/
⚡ 批量自动化
✓ 支持多平台
3
长视频 + 字幕
长视频使用 yt-dlp 下载，有字幕时直接对字幕文件做 AI 处理，无需转文字。
# yt-dlp 下载视频 yt-dlp -o "%(title)s.%(ext)s" https://... # 有字幕时，直接 AI 处理 # 将 .srt/.vtt 字幕文件输入 AI 分析
✓ 零转录成本
✓ AI 直接消化
📝 文章 → .md 存档 → 🎬 视频 → Get笔记 CLI → yt-dlp → 文字稿 → 🤖 AI 处理 → 🗃️ 知识库

短视频采集
专注于短视频口播文字稿批量采集的 CLI 工具，支持多平台博主内容批量抓取。

长视频下载
开源视频下载工具，支持 YouTube、B 站等 1800+ 平台；下载后可配合转文字工具使用。
yt-dlp -o "%(title)s.%(ext)s" URL
