AI 编程 多 Agent 协同

Claude Vibe Squad

让 Claude Code、Gemini CLI 和 Codex 协同开发的多 Agent 本地框架——Chrono 协调者自动拆解任务，各 Agent 在独立 Git Worktree 中隔离修改、验证通过后合并，本地 CLI 直连无需第三方中转服务。

🤖 4 模型家族 🧩 68 专业角色 🌳 Git Worktree 隔离 ⚡ 本地直连
01
Chrono 协调者
核心调度

任务自动拆解与分派

Chrono 作为中央协调者，将复杂需求拆解为有边界的 Markdown Task Packet，精准分发给各专业 Agent，避免上下文混乱。

任务分派 Markdown Packet Chrono
02
Git Worktree 隔离
代码安全

本地代码不打架

每个 Agent 在独立 Git Worktree 中修改代码，彼此完全隔离，验证通过后再合并，从根本上杜绝代码冲突。

Worktree 隔离修改 安全合并
03
4 模型家族
多模型

Codex / Claude / Gemini / Kimi

支持 4 个前沿模型家族，共 68 个角色型专家 Agent，跨家族 Review Gate 把控质量，本地直连无需中转。

4 模型 68 角色
Codex Claude Gemini Kimi
04
本地优先
无服务器

本地 CLI 直连

直接调用本地现有 CLI 工具，无需配置第三方中转服务，无服务器依赖，日均自用验证。

本地 CLI 零中转 隐私优先

💡 vs 其他方案

传统多 Agent 方案依赖远程 API 中转（延迟高、费用累积、数据隐私问题）。Claude Vibe Squad 通过 Git Worktree 实现本地隔离、通过 Chrono 实现任务分派，通过 Markdown Task Packet 实现上下文结构化——三件套组合实现零额外成本的本地多 Agent 协作。
