MCP × 3D 工作流

mcp-for-blender：把 AI 客户端接进 Blender

第三方 MCP 集成，让 Claude、Codex、Cursor 这类 AI 客户端直接在 Blender 里建对象、改材质、写并执行 Blender Python。

一条命令装完客户端配置和 Blender 插件；插件在 Blender 内建一个 socket server 接收命令，MCP Server 负责把协议翻译过去。AI 能自己多角度看渲染结果来检查做过的事。

MIT 许可 Python 30696 star 2776 fork 建仓 2025-03-07 最近推送 2026-10-06 Blender 3.0+ Python 3.10+

注意第三方集成，不是 Blender 官方出品。仓库原名 blender-mcp，现改名 mcp-for-blender，PyPI 包同步改名。

A

它是什么

一个 MCP Server 加一个 Blender 插件的组合，装完之后 AI 客户端就能操作 Blender。

原名 blender-mcp，现名 mcp-for-blender；PyPI 包同步改名。旧的 uvx blender-mcp 仍能运行，老配置不需要改。

局限先说清：它是第三方项目，不是 Blender 官方出品；AI 写并执行的 Blender Python 会真实运行，等于把脚本执行权限交给模型。

B

两个组件怎么连

Blender Addon（addon.py）：在 Blender 内建一个 socket server 接收并执行命令。

MCP Server（src/blender_mcp/server.py）：实现 MCP 协议的 Python 服务，连到上面的 addon。

AI 客户端→ MCP Server
uvx mcp-for-blender→ socket→ Blender Addon→ Blender
C

能做什么

  • 双向通信：通过 socket server 把 Claude AI 接到 Blender。
  • 对象操作：创建、修改、删除 3D 对象。
  • 材质控制：应用与修改材质和颜色。
  • 视觉自检：多角度、相机、线框、X-ray、动画条视图，加渲染。
  • 代码执行：AI 直接写 Blender Python。
  • 资产与模型生成：Poly Haven / Sketchfab / Poly Pizza / Tripo / Hyper3D Rodin / Hunyuan3D。
01

先做这一步

唯一需要你手动敲的命令
1

macOS / Linux：一条命令装完

macOS · Linux复制即用
curl -LsSf https://www.mcp-for-blender.com/install.sh | sh

脚本会按需装 uv，自动探测本机已有的 MCP 客户端（Claude Desktop、Claude Code、Codex、Cursor、VS Code、Devin Desktop/Windsurf、OpenCode、Antigravity），让你挑选要配哪个，然后安装并启用 Blender 插件。

已有配置会保留，只加一条 blender 条目，且改动的文件都会存 .bak。

2

Windows：用 PowerShell

Windows复制即用
powershell -ExecutionPolicy ByPass -c "irm https://www.mcp-for-blender.com/install.ps1 | iex"

Windows 上退出 AI 应用要从系统托盘退出，否则配置不会重新加载。

3

已经装过 uv：走 uvx 的 setup

已有 uv复制即用
uvx mcp-for-blender setup

装完之后完全退出并重开你的 AI 应用，打开 Blender，然后直接让 AI 建东西。插件在 Blender 打开时启动 server。

02

核心机制

两个组件 + 资产链路
1

Blender 侧：Addon 建 socket server

addon.py 在 Blender 里开一个 socket server，接收并执行命令。

它是命令真正落地的地方：最终的 Blender 操作和 Python 执行都发生在这一层。插件在 Blender 打开时启动 server，在 3D viewport 按 N 就能看到 MCP for Blender 页签，没跑就点 Start MCP Server。

2

客户端侧：MCP Server 讲协议

src/blender_mcp/server.py 是一个实现 MCP 协议的 Python 服务，连到 addon 的 socket server。

日常用 uvx mcp-for-blender 启动它，客户端配置里写的也是这个命令。它不直接操作 Blender，只负责把 MCP 调用翻译成 addon 能执行的命令。

链接方式：一次只开一个实例

只跑一个 MCP server 实例（要么 Cursor 要么 Claude Desktop），不要两个一起开——多客户端会互相抢同一个 socket server。

3

资产与模型生成：三条来源

Poly Haven：发布约 2400 个 HDRI、贴图与模型，全部 CC0，靠捐赠维持。没有 API key、没有账号、也不需要担心限流，在 3D View 侧栏勾选 Poly Haven 就是全部设置。搜索按含义理解而不是关键词匹配，couch 能找到沙发，且任意语言可用。previews=3 先给缩略图再花带宽。

免费模型库：Sketchfab 模型、Poly Pizza 低模。

AI 生成 3D 模型：Tripo、Hyper3D Rodin、Hunyuan3D。Premium 可以在 Blender 里直接生成 AI 3D 模型而不用自己带 API key；Premium 之外需要自己带 key。

4

Poly Haven 调用长什么样

例：「用一个阴天下午的 HDRI 打光，给墙加个生锈金属贴图」。

search先搜
search_assets(
  source="polyhaven",
  query="overcast afternoon",
  asset_type="hdris"
)
import一次调用下载并应用
import_asset(
  source="polyhaven",
  id="...",
  asset_type="textures",
  apply_to=["Wall"]
)

CC0 不等于没有要求：来源要标明

所有 Poly Haven 资产都是 CC0，商用与否都不必署名。但 Poly Haven 的 API 服务条款要求基于其实时 API 构建的软件说明资产来源，所以搜索与导入响应会标明来源并链接资产页；导入时保留 polyhaven_id 等字段。

M

手动路径：四步

1

装 uv

macOS 用 brew install uv；Linux 用 curl -LsSf https://astral.sh/uv/install.sh | sh；Windows 用 powershell -c "irm https://astral.sh/uv.ps1 | iex"。

README 明确警告：要用 uv 官方安装器，不要 pip install uv。

2

把 MCP server 指给客户端

Claude Desktop 在 Settings → Developer → Edit Config 写下面这段；Claude Code 用 claude mcp add blender uvx mcp-for-blender；Codex 用 codex mcp add blender -- uvx mcp-for-blender。

Claude DesktopSettings → Developer → Edit Config
{
  "mcpServers": {
    "blender": {
      "command": "uvx",
      "args": ["mcp-for-blender"]
    }
  }
}
3

装 Blender 插件

install-addon复制即用
uvx mcp-for-blender install-addon

然后在 Blender 的 Edit → Preferences → Add-ons 里启用 Interface: MCP for Blender。

4

连接

在 3D viewport 按 N，打开 MCP for Blender 页签；没跑就点 Start MCP Server。

P

前置条件

项要求
Blender3.0 或更新
Python3.10 或更新
包管理器uv

Blender 下限是 3.0，不是 4.2。uv 必须用官方安装器装，README 明确警告不要 pip install uv。

连接检查清单

1. Blender 已打开（插件在 Blender 打开时启动 server）。
2. 3D viewport 按 N → MCP for Blender 页签 → 看 server 是否在跑。
3. 没跑就点 Start MCP Server。
4. 只开一个客户端，别 Cursor 和 Claude Desktop 同时开。

Codex 用户要手动加插件

Codex 插件还没上插件目录，需要从仓库手动加：先 git clone 仓库，再执行下面的命令。

Codex需要先 clone 仓库
codex plugin marketplace add ./blender-mcp/integrations/codex
04

预期现象

按顺序核对，缺哪一步就知道卡在哪
I

安装脚本跑完

  • uv 按需装好，不需要你先手动准备。
  • 脚本列出探测到的 MCP 客户端（Claude Desktop、Claude Code、Codex、Cursor、VS Code、Devin Desktop/Windsurf、OpenCode、Antigravity），等你挑选。
  • Blender 插件被安装并启用。
  • 已有配置被保留：只加一条 blender 条目，改动的文件存 .bak。
II

重开应用 + 打开 Blender 之后

  • AI 应用完全重启（Windows 从系统托盘退出）后能看到 blender 这个 server。
  • Blender 一打开，插件就把 server 启动起来。
  • 3D viewport 按 N 出现 MCP for Blender 页签，可以点 Start MCP Server。
  • 接下来可以「直接让 AI 建东西」：对象增删改、材质与颜色、以及视觉自检。
III

AI 干活时你能看到什么

  • 对象在视口里出现、被改、被删——对应「在 Blender 里创建、修改、删除 3D 对象」。
  • 材质和颜色变化——对应应用与修改材质。
  • AI 自己出渲染图自查——多角度、相机、线框、X-ray、动画条视图，加渲染，都是为了让 AI 检查自己做的事。
  • Poly Haven 资产直接进场景——在 3D View 侧栏勾选之后，约 2400 个 CC0 的 HDRI、贴图与模型可搜可导；previews=3 会先返回缩略图，再决定是否花带宽下载。

已知限制与边界

7 条，装之前先读
边界一条条列出来，避免装完才发现踩到。
#边界说明
1第三方项目不是 Blender 官方出品。
2单实例只跑一个 MCP server 实例，多个客户端会互相抢。
3版本下限Blender 下限 3.0（不是 4.2），Python 下限 3.10，且必须先装 uv；README 明确警告不要 pip install uv。
4Codex 插件尚未上插件目录，要从仓库手动加。
5第三方生成服务AI 生成 3D 模型的部分（Tripo / Hyper3D Rodin / Hunyuan3D）是第三方服务；Hunyuan3D 官方 API 模式要按账号所在区域选腾讯云服务；Premium 之外需要自己带 key。
6改名遗留仓库原名已改，旧链接与旧 PyPI 包名仍在但已废弃。
7脚本执行权限AI 会直接写并执行 Blender Python，等于把脚本执行权限交给模型。

风险：把脚本执行权限交出去

AI 直接写并执行 Blender Python，这在能力清单里叫「代码执行」，在边界清单里叫「等于把脚本执行权限交给模型」。同一个机制，两种读法。要不要给，取决于你在这台机器上跑什么。

边界：一次只开一个客户端

要么 Cursor 要么 Claude Desktop，不要两个一起开。多客户端会互相抢同一个 socket server，表现是命令时有时无。
