WINDOWS INSTALL

Windows 安装流程

双击 start.bat，无需管理员权限，模型自动下载

  1. ①

    下载仓库

    访问 GitHub 页面，下载最新 ZIP 或用 git clone 克隆仓库

  2. ②

    运行安装脚本

    双击 start.bat，等待 uv 自动创建 installer_files/ 环境并下载依赖（首次约需 10-20 分钟，视网络而定）

  3. ③

    启动 WebUI

    安装完成后自动打开浏览器 http://localhost:7860 ，所有模型首次使用时会自动下载

  4. ④

    故障排除

    大多数问题删除 installer_files/ 文件夹后重新运行 start.bat 即可解决（AI 模型保存在 model/ 目录，会保留）

git clone https://github.com/abus-aikorea/voice-pro.git
# 双击运行 start.bat，或命令行：
.\start.bat

Voice-Pro vs. 主流商业/开源语音方案

Voice-Pro

免费；本地运行无隐私风险；Whisper + 多克隆引擎 + 翻译 + 配音全链路；Gradio WebUI 易用

顶级克隆质量；丰富声音市场；API 计费；不本地运行，数据上传云端

开源本地 · 需训练

开源本地 · 单一引擎

克隆质量好；XTTS v2 支持多语言；主要是 API 方式，本地部署文档较少

无完整工作流整合

选择 Voice-Pro 的理由： 开源免费 + 全链路整合（识别→翻译→克隆→配音）+ Windows 一键安装 + 无需联网。对于视频创作者和播客制作者，一站式解决配音需求，无需在多个工具间切换。
