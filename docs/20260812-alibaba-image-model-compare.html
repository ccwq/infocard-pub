⚠️ 重要坑：历史模型未退场，别被模型名绕晕

百炼当前模型目录同时存在：qwen-image / qwen-image-plus / qwen-image-max / qwen-image-2.0 / wan2.1 / wan2.5 / wan2.6 / wan2.7 等大量版本共存。很多是版本兼容和老 API 遗留，新项目优先用当前旗舰（3.0 / 2.7 / Turbo）。Z-Image-Edit 官方 GitHub 标注"To be released"，当前云端接口不支持修图。

📌 置信度说明

功能边界：高（基于百炼官方API文档）；产品定位：高（基于阿里官方选型表）；绝对画质高低：中（未做同Prompt L3实测，主观"谁更漂亮"不在本卡范围）。

三句话记型：Qwen=内容要对 · Wan=流程要控 · Z=快便宜出图
