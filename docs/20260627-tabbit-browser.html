核心使用链

一句话 → 浏览器自动执行

用户描述目标，Tabbit 自动拆解步骤、打开网页、提取数据、填表并交付结果，全程无需手动操作。

用户输入 "帮我把 Boss 直聘上所有产品经理岗位都投一遍"
Agent 规划 自动拆解：搜索 → 筛选 → 打开 JD → 填表 → 提交
浏览器执行 在独立标签组内自动操作，全程可见可中断
结果交付 汇总投递状态，生成报告

核心能力：AI + 浏览器 = 执行中枢

FEATURES
⚡

多模型聚合调用

内置 DeepSeek GLM / Kimi / Minimax 等 10+ 款国内主流大模型，可按任务类型自由切换模型，无需在各 App 间跳转。

跨网页 Agent 执行

在独立标签组内自动打开网页、提取信息、填写表单并跨平台整合数据。Agent 成功率从公测初的 53.1% 提升至 91.8%。

沉浸式双语翻译

打开任意英文页面，头顶全文双语对照翻译，支持分段划词和截图翻译，零门槛读英文文献。源自被指抄袭的开源项目争议（已获正式授权）。

💬

三合一入口

首页大对话框同时支持 AI 对话、网页搜索和链接粘贴。侧边栏支持在浏览任意页面时实时 AI 对话，无需切换标签。

📋

妙招 & 脚本系统

将常用提示词保存为"妙招"一键调用；支持一句话生成浏览器脚本，自动完成重复操作，无编程门槛。

🗂️

智能标签管理

一键为标签页分组，支持全部展开/收起和撤销整理结果。移动端侧边栏支持网页搜索、标签管理与桌面端数据同步。

🎯

妙招广场

分享社区预设脚本与自动任务：一键投递全平台岗位、Github 高速下载器、B 站视频下载等，大幅降低上手成本。

🔒

隐私承诺

官方明确承诺：你的数据属于你自己，不将用户数据用于训练。浏览器始终相信用户有完全的自由选择权。

关键区分：订阅 ≠ API

Tabbit 的 Pro 订阅是面向终端用户的用量扩容，与大模型 API 定价是两回事。官方尚未发布面向开发者的 API 接口文档或独立 API Key 体系。如果需要程序化调用大模型能力，需直接对接各模型提供商的 API。
