02
模块二 · 数据处理

数据准备

将原始问答数据转换为标准 JSONL 格式，90% 训练 / 10% 测试，max_length=512 截断与补齐。

JSONL 格式 prompt / completion 90% / 10% max_length=512
数据格式示例：
{"prompt":"问题内容","completion":"答案内容"}
分词截断函数：
def tokenize(example, tokenizer, max_len=512): prompt = tokenizer.encode(example["prompt"], truncation=True, max_length=max_len//2) completion = tokenizer.encode(example["completion"], truncation=True, max_length=max_len//2) input_ids = prompt + completion attention_mask = [1]*len(input_ids) pad_id = tokenizer.pad_token_id or 0 padding = [pad_id]*(max_len - len(input_ids)) input_ids += padding attention_mask += [0]*len(padding) return {"input_ids":input_ids,"attention_mask":attention_mask}

模块三 · 模型量化

8位量化（QLoRA）

采用 bitsandbytes NF4 量化压缩模型体积，QLoRA = 4bit NF4 + LoRA，使 7B 模型显存占用降低 60%+，7B 约需 7–10G 显存，24G 显存足够。

显存占用对照：
模型规模FP16 显存QLoRA 8bit 显存
7B~14 GB~7–10 GB ✓
14B~28 GB~14–18 GB
32B~64 GB~24–30 GB
量化加载代码：
from transformers import AutoModelForCausalLM, AutoTokenizer, BitsAndBytesConfig bnb_cfg = BitsAndBytesConfig( load_in_4bit=True, bnb_4bit_quant_type="nf4", bnb_4bit_compute_dtype="float16", bnb_4bit_use_double_quant=True ) model = AutoModelForCausalLM.from_pretrained( "deepseek-ai/DeepSeek-R1-Distill-Qwen-7B", quantization_config=bnb_cfg, device_map="auto" )

模块四 · LoRA 配置

PEFT LoRA 参数设置

冻结原模型 99.94% 参数，仅微调约 0.06% 的 LoRA 适配器权重，显存友好且效果显著。

参数推荐值说明
r8 或 16LoRA 秩，性价比最高
lora_alpha2 × r（如 16/32）缩放因子，控制影响权重
target_modules["q_proj","v_proj","k_proj","o_proj"]Attention 层全挂载
lora_dropout0.05防过拟合
task_typeCAUSAL_LM因果语言模型任务
PEFT LoraConfig：
from peft import LoraConfig, get_peft_model lora_cfg = LoraConfig( r=16, lora_alpha=32, target_modules=["q_proj","v_proj","k_proj","o_proj"], lora_dropout=0.05, bias="none", task_type="CAUSAL_LM" ) model = get_peft_model(model, lora_cfg) model.print_trainable_parameters() # 输出：trainable params: 1.6M || all params: 6.7B || trainable%: 0.024%

模块五 · 训练管理

训练与参数配置

TrainingArguments 控制训练行为，根据数据量选择 epochs，根据显存调整 batch_size，开启 FP16 加速。

参数推荐值说明
output_dir"./deepseek-lora-output"输出路径（含 checkpoint）
num_train_epochs少数据 10 / 多数据 1–350条≈10轮，数万条≈1–3轮
per_device_train_batch_size4（OOM 时调 2 或 1）单卡批次大小
gradient_accumulation_steps4梯度累积扩大有效批次
fp16TrueFP16 混合精度，显存砍半
learning_rate1e-4LoRA 默认学习率
warmup_ratio0.03预热步数比例
logging_steps10日志输出频率
save_strategy"epoch"每轮保存 checkpoint

⚠ 硬约束：必须搬运至 GPU
模型从内存加载后，必须显式搬运至 GPU 显存：model = model.to("cuda")
离线或无独显环境（Mac / 轻薄本）虽能用 CPU 跑，但速度极慢，强烈建议使用云端 GPU。

完整训练代码入口：

from transformers import Trainer, TrainingArguments from peft import LoraConfig, get_peft_model model = model.to("cuda") trainer = Trainer( model=model, args=TrainingArguments( output_dir="./deepseek-lora-output", num_train_epochs=10, per_device_train_batch_size=4, gradient_accumulation_steps=4, fp16=True, learning_rate=1e-4, warmup_ratio=0.03, logging_steps=10, save_strategy="epoch" ), train_dataset=train_dataset ) trainer.train()
