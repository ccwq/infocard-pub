4–8 means shots

The default is a planned shot list, not 4–8 finished images from one model call. Each image gets its own generation call.

Bring real image capability

Installation does not grant a model, account access or credits. Verify the Codex host and its image tools before promising output.

03 / publishing

Review before release

Chinese labels, physical actions, factual anchors and style need checking. Open-source licensing does not remove service costs or publishing responsibility.

Quick decision: choose the task first, request a planning-only trial, then verify the host and budget before generating. You can stop here; below are the actual visual differences, installation paths, a reusable planning prompt and a release checklist.

01 / evidence & selection

Two repositories, two jobs—not a forced upgrade

The author calls Illustrations “1.0” and Scenes “2.0.” They remain separate repositories with different task orientations. There is no evidence here that 1.0 is deprecated or that Scenes replaces every explanatory diagram.

Choose Illustrations for a cognitive mechanism

For Chinese articles, posts, blogs, Notion content, screenshots or a rough topic, extract the judgment or turning point before inventing an image. Its vocabulary includes workflows, system fragments, before/after comparisons, character states, conceptual metaphors, method layers, route maps and short comic sequences. A black solid character with white-dot eyes, thin legs and a blank expression must perform the core action—not sit on top as a sticker.

The target is a 16:9 white-background body illustration: slightly irregular black lines, sparing red/orange/blue annotations and generous whitespace. It is not a brand key visual, polished commercial illustration, conventional slide infographic or an entire manual crammed into one picture. Removing Xiaohei should weaken the explanation.

Choose Scenes for a concrete situation

Scenes uses realistic objects, one core physical action, 2–4 short Chinese labels and restrained blue, pink, yellow, green or red accents. Standard images lock a quality master from examples 01–06 and require at least three meaningful variations; swapping labels on an old composition is not sufficient. This makes situations such as meeting friction drawable without pretending they are flowcharts.

Choose the long scroll only for a connected journey

The optional Scenes scroll is approximately 2.6:1–3:1, with 5–8 connected narrative nodes, a curved path and a near-white background; example 07 is its core master. Its default plan starts with one scroll. Those nodes are not 5–8 independently generated images, and the scroll specification is not the standard body-image specification.

02 / mechanism

A shot list is a production plan, not a batch promise

Production path02 / output contract
Read text → identify the cognitive anchor / situation
↓
Plan shots → choose structure → reinvent the metaphor
↓
Generate each image separately → inspect → repair → deliver PNG

Both skills default to 4–8 planned shots. Illustrations allows 1–3 for short pieces and advises not casually exceeding nine for long ones. Each plan should specify its topic, core meaning, structure, Xiaohei action and proposed short Chinese labels. One image should carry one core action.

For example, “our approval process is stalled” can become a blocked mechanism rather than a generic person next to a chart. This is an editorial suggestion, not a tested model result. The useful intermediate deliverable is the action and metaphor; generating more images does not prove the article has more visual ideas.

When the user explicitly requests generation, the official instructions say not to stop just to await confirmation at every stage. Planning remains necessary internally, and Scenes still requires master selection before generation. A planning-only request, however, is a deliberate way to inspect the concept before using image resources.

03 / implementation

Install the matching subdirectory, not the repository root

Prerequisite: an appropriate Codex host with actual image-generation capability. The official installation targets ${CODEX_HOME:-$HOME/.codex}/skills/; a pasted prompt in an arbitrary chat interface is not proven equivalent. The following reproduces the documented installation pattern; it was not executed for this review.

git clone https://github.com/helloianneo/ian-xiaohei-illustrations.git
cd ian-xiaohei-illustrations
mkdir -p "${CODEX_HOME:-$HOME/.codex}/skills"
cp -R ./ian-xiaohei-illustrations "${CODEX_HOME:-$HOME/.codex}/skills/"

For Scenes, use the repository helloianneo/ian-xiaohei-scenes and copy its inner ian-xiaohei-scenes directory to the same skills destination. The repositories contain instructions and references, not an independent generation engine, provider SDK or billing configuration.

A practical planning-only request

$ian-xiaohei-illustrations
Read the article below. Planning only: do not generate images
or call any image tool. Propose a shot list with an insertion
point, cognitive anchor, structure, Xiaohei action, short Chinese
labels and a reason for every shot. Use fewer shots if the text
has fewer independent visual ideas. Flag factual uncertainty.

Article: [paste the article here]

For situation-based work, invoke $ian-xiaohei-scenes instead and ask for each scene’s real object, core physical action, master reference and at least three proposed variations. Ask separately for a long scroll only when the article supports a connected journey.

04 / cost & capability

The free part is the source—not a guaranteed image allowance

Illustrations explicitly refers to built-in image_gen. Scenes does not lock a particular image-tool name or model version. Both depend on a host that can actually generate images; installing the skill supplies neither that capability nor a particular subscription entitlement.

The reviewed documentation gives no fixed Codex version, required image-model release, account tier, quota or per-image price. Whether an actual call is charged, which allowance it consumes and how much revisions cost depend on the host and service. No installation, paid generation, latency test, Chinese-text accuracy test or end-to-end Codex run was performed here. Hermes/Claude compatibility is not established by these files.

Before a real runCheck tool availability, account eligibility, model/service terms and the current allowance or price. Then try one representative image and inspect it before scheduling a full article. This is an editorial recommendation, not a feature implemented by the repositories.
05 / boundaries & action

Make the first image earn its place

  • Language: inspect every Chinese character and label. Shorten labels and regenerate when errors are serious; do not promise error-free text.
  • Visual logic: verify a readable physical action, intended background, whitespace, composition and an active Xiaohei. Avoid unnecessary type headings; the official sample itself has a title, so “no sample ever has a title” is not a valid absolute claim.
  • Scenes gate: view the master first, then inspect the candidate. The first generated image is not automatically the final deliverable. Correct severe issues by editing or regenerating.
  • Originality and facts: do not reproduce the old example composition mechanically. Check factual labels against the article. The skill’s agent QA is not an automatic copyright check or a mandatory human approval module.
  • Editorial responsibility: for public publication, check the words, facts and image yourself. This is a publishing recommendation beyond the repositories’ agent QA.
  • License: both repositories use MIT, copyright © 2026 Ian. Preserve the copyright and permission notice when copying or redistributing substantial software portions. NOTICE also requests the project name or Ian attribution in derivative documentation. This does not guarantee that every generated image, brand or third-party character is cleared for every use.
