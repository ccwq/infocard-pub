L1 / input

读懂文章

输入可以是中文文章、帖子、博客、Notion 页面、截图或一个模糊主题。第一步不是生图，而是抓住文章真正要讲的事情。

L2 / anchor

抽认知锚

每张图只选一个核心判断、流程、状态或隐喻。它的价值在于把长文里最值得记住的那一下，缩成一个能一眼看懂的动作。

L3 / metaphor

重新发明隐喻

不是照抄旧模板，而是把认知锚点换成新的物理隐喻。小黑必须参与核心动作，不只是贴在角落里的装饰。

L4 / deliver

交付 shot list + PNG

默认会产出 shot list 与最终 PNG，保存到 workspace 的 assets 目录。成品强调白底、留白、中文标注和可复用的内容识别度。

这张卡最值得记住的地方 · 它把“配图”从审美外包，变成认知动作设计：先理解文章，再提炼锚点，再发明隐喻，最后交给图像模型。 适合方法论、AI 工作流、知识型文章；不适合想要商业海报、品牌 KV 或极简 PPT 风的人。
