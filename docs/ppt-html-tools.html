01
TOOL · HTML 派标杆

html-ppt-skill · 硬核基础设施

让 Claude Code / Cursor / OpenClaw 真正理解「好看的幻灯片」长什么样。

硬核基础设施Claude Code

html-ppt-skill

GitHub 5.4K⭐。把 Claude Code / Cursor / OpenClaw 训练成 PPT 美学专家：36 套主题、15 套完整 deck 模板、31 种页面布局、47 个动效（27 个 CSS + 20 个 Canvas FX）。纯静态 HTML/CSS/JS，零构建。Speaker Mode 提供像素级预览 + 逐字稿 + 计时器，讲稿和版面同步对齐。

  • 36 套主题色板 + 字体对，覆盖工程 / 商务 / 教育 / 暗色多种语境
  • 15 套完整 deck 模板直接套用：Pitch / Review / Roadmap / Report / 培训等
  • 31 种页面布局：标题页 / 大数页 / 双栏对比 / 时间线 / 矩阵 / 引言页
  • 47 个动效：27 CSS 动效 + 20 Canvas FX（粒子、网格、滚动视差）
  • Speaker Mode：提词器 + 计时器 + 翻页映射，单屏全流程
5.4K⭐ 零构建 Speaker Mode 31 布局 47 动效
INSTALL

安装命令

# 一次性安装，给 Claude Code / Cursor / OpenClaw 装技能 $ npx skills add lewislulu/html-ppt-skill

装好后对 AI 说「做一个关于 X 的五页演示，工程风」，它会自动套用 36 套主题 + 15 套 deck 模板生成单文件 HTML。

02
TOOL · 全栈 HTML 演示文稿

frontend-slides · AI 一把梭出动画演示

用 AI 把文字 / 旧 PPT 直接生成零依赖单文件 HTML 动画演示文稿。

工具库全栈零依赖

frontend-slides

GitHub 19K⭐（MageByte-Zero/frontend-slides fork 修复版）。核心场景：把 Markdown / 旧 PPT / 一段话直接喂给 AI，让它生成零依赖单文件 HTML 动画演示文稿。浏览器全屏放映，不需要 Canva、不需要 MasterGo、不需要模板抠色。

  • 输入可以是 Markdown 大纲、PDF 抽取文本、旧 PPTX 内容
  • 输出单个 .html 文件，含 CSS 动画 / 翻页逻辑 / 字号系统
  • MageByte-Zero fork 修复了原版依赖冲突与 Node 版本问题
  • 不强制绑定特定 AI：用 Claude / GPT / Gemini / 本地模型都行
  • 导出 HTML 后可继续微调：改字号 / 换字体 / 加 SVG 配图
19K⭐ 零依赖 动画演示 全栈
INSTALL

安装命令

# 安装 fork 修复版（处理依赖与 Node 版本） $ npx skills add MageByte-Zero/frontend-slides

建议使用 MageByte-Zero fork 版；原版在某些 Node 版本上 npm install 会失败。

03
TOOL · 瑞士设计风

guizang-ppt-skill · 归藏 PPT 一页搞定

瑞士设计风高控制力单文件 HTML 演示文稿，设计师 / 讲者首选。

瑞士风高控制归藏

guizang-ppt-skill

基于瑞士设计风（Swiss / International Typographic Style）构建单文件 HTML 演示文稿。控制力极强——可精确控制网格、字号、配图数量、留白比例。适合需要「风格统一 + 高度定制化」的演讲，如设计评审、品牌宣讲、技术分享。

  • 瑞士设计风：Akzidenz / Helvetica 字体族 + 大留白 + 强对齐网格
  • 精确控制网格列数（4 / 8 / 12 列）、字号阶梯（10/12/14/18/24/36/60）
  • 配图数量、配图比例均可配置，避免「满屏图」破坏版面节奏
  • 适合设计师、技术讲者、品牌团队；不适合「随手出片」场景
  • 上手成本中，但出片质感天花板级
瑞士风 极强控制 网格化 归藏
INSTALL

安装命令

# git clone 到 ~/.claude/skills/ $ git clone https://github.com/op7418/guizang-ppt-skill.git \ ~/.claude/skills/guizang-ppt-skill

直接 git clone 到 Claude Code skills 目录即可，无需 npx；归藏仓库更新频繁，建议偶尔 git pull 一次。

04
TOOL · 本地化开源首选

Presenton · 本地模型 + 风格学习

开源 AI 演示文稿生成器，可上传 PPTX 学习设计风格并保持品牌 DNA 一致。

本地优先开源风格学习

Presenton

开源 AI 演示文稿生成器。支持 OpenAI / Gemini / Claude / Ollama 本地模型；最关键——可上传 PPTX 学习设计风格（颜色 / 字体 / 间距），后续所有页面保持一致品牌 DNA；导出 PPTX / PDF 双格式可继续编辑。

  • 支持 OpenAI / Gemini / Claude API，也支持 Ollama 本地模型
  • 上传品牌 PPTX → 自动提取配色 / 字体 / 间距 → 所有页面继承品牌 DNA
  • 导出 PPTX（可继续在 PowerPoint / Keynote 改）和 PDF（分享用）双格式
  • 本地部署 Docker 一行起，数据不出企业内网
  • 适合数据敏感团队（金融 / 政企 / 法务）的对外汇报
本地化 品牌 DNA PPTX/PDF Ollama 开源
REPO

仓库地址

# 仓库 https://github.com/presenton/presenton # Docker 本地启动（官方推荐） $ docker run -d -p 5000:5000 \ ghcr.io/presenton/presenton

无 npx / 无 git clone，Docker 是官方推荐部署方式；Ollama 模型需单独安装并配置 endpoint。

TOOL · 中文场景模板库

WorkBuddy · 中文场景模板库

模板库覆盖工作汇报 / 产品介绍 / 培训课件 / 趋势报告，新手上手最快。

场景丰富中文零基础

WorkBuddy

模板库覆盖工作汇报 / 产品介绍 / 培训课件 / 趋势报告四大中文高频场景。结构化内容生成 + 智能匹配模板 + 一键导出。中文场景适配最深——不只是翻译字体，连版式习惯都为中国职场调过。

  • 工作汇报：Q1/Q2/Q3 季报模板 + OKR 进度页 + 数据图表适配
  • 产品介绍：竞品对比页 + 用户画像 + 路线图模板
  • 培训课件：知识点拆解 + 案例插入 + 课后测试模板
  • 趋势报告：行业大盘 + 头部玩家 + 预测图表
  • 中文场景适配最深：字体（思源黑体 / 阿里巴巴普惠体）/ 字号阶梯 / 行业话术
中文优先 新手友好 一键导出 场景库
REPO

访问入口

# WorkBuddy 任务管理 → 幻灯片类型 WorkBuddy 任务管理 - 幻灯片类型 # 进入 WorkBuddy 后： # 1. 选择「幻灯片」任务类型 # 2. 选模板（汇报/介绍/课件/报告） # 3. 填内容 → 一键导出 PPTX/HTML

WorkBuddy 是任务管理工具内的「幻灯片」功能模块，不是独立 skill；适合零基础用户从中文模板入手。

使用步骤 · 4 步从 0 到讲稿

STEP 01

装 Skill

用 npx skills add <repo> 或 git clone 把 skill 装到 ~/.claude/skills/。

STEP 02

提需求

直接对 AI 说：「帮我做一个关于 X 主题的演示，五页，风格 Y」。

STEP 03

看预览

HTML 单文件浏览器全屏，方向键 ←/→ 翻页，Speaker Mode 看提词器。

STEP 04

微调

让 AI 改字号 / 加图 / 换风格即出新版，几轮迭代即可定稿。
