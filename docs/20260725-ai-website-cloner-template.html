核心价值

不是爬虫，不是截图工具——而是一个语义级逆向工程框架。输入 URL，AI agent 理解页面结构、样式和交互，生成语义和视觉近似、代码清晰可维护的 Next.js 项目。

技术栈
Next.js 16 React 19 TypeScript strict shadcn/ui Tailwind CSS v4 Lucide React
适用场景

平台迁移 — 从 WordPress/Webflow/Squarespace 重建为现代 Next.js 代码库。

源码找回 — 网站在线但仓库消失、开发者离职、遗留技术栈，快速重建代码。

学习 — 通过真实代码解构生产级网站的布局、动画和响应式实现。

使用方式
步骤操作
1在 GitHub 点击 Use this template 创建自己的仓库
2npm install 安装依赖
3npx claude --chrome 启动 Claude Code
4运行 /clone-website <target-url>
