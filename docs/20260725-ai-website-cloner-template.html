安全边界

学结构，不冒充原作者

仓库明确禁止钓鱼、冒充、照搬他人设计和违反站点条款。目标网站的版权、品牌资产和原创文案仍归原作者所有。

THE FIVE-PHASE PIPELINE

把“复刻一个网站”拆成五个可检查阶段

每个阶段都有明确产物，减少 Agent 直接开写后反复返工。

01 / RECON侦察截图、提取设计 token，扫描滚动、点击、悬停和响应式状态。
02 / FOUNDATION基础更新字体、颜色和 globals，下载目标页面使用的资源。
03 / SPECS组件规格写出组件 CSS 值、状态、行为、内容和断点的详细规格。
04 / PARALLEL并行构建按区块/组件分派 builder agents，分别实现页面片段。
05 / QA组装检查合并组件，运行页面，并对原站做视觉差异检查。
为什么先规格、再并行？每个 builder agent 拿到同一份精确组件规格，减少“各写各的”导致的字体、间距、状态和资产漂移。

QUICK START

先创建自己的仓库，再让 Agent 开始

官方 Quick Start 的第一步不是直接改模板仓库，而是使用 GitHub 的 Use this template 创建自己的项目。

# 1. 在 GitHub 页面点击 Use this template，创建自己的仓库 # 2. 进入你自己的仓库后 npm install claude --chrome /clone-website <target-url1> [<target-url2> ...] # 也可以用自然语言触发 Clone using the clone-website workflow
不要直接克隆官方模板做目标网站项目按仓库说明，先用模板创建自己的副本，再在自己的仓库中工作；生成的网站代码不要回传到模板仓库或提交无关 PR。
TECH STACK / USE CASES

产出的是普通前端工程，不是封闭的设计文件

工程栈

  • Next.js 16 App Router
  • React 19 + TypeScript strict
  • Tailwind CSS v4
  • shadcn/ui + Radix primitives
  • Lucide React 图标（克隆时可替换为提取的 SVG）

适合场景

  • 把自有 WordPress / Webflow / Squarespace 页面迁移到现代栈
  • 线上还在、源码丢失或技术栈老旧时找回工程起点
  • 通过真实页面学习布局、动画和响应式实现
  • 快速制作可继续开发的视觉原型
