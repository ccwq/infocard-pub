AI Website Cloner Template

用一条命令，把任意网站逆向重建为干净的 Next.js 代码库。由 AI coding agent 驱动，生成结构化、可维护的现代前端项目。

核心价值

不是爬虫，不是截图工具——而是一个语义级逆向工程框架。输入 URL，AI agent 会理解页面结构、样式和交互，生成一套语义和视觉近似、代码清晰可维护的 Next.js + shadcn/ui + Tailwind v4 项目。

技术栈

Next.js 16 React 19 TypeScript strict shadcn/ui Tailwind CSS v4 Lucide React

五阶段管道

Phase 1
Reconnaissance
截图、设计令牌提取、交互扫描（滚动/点击/悬停/响应式）
Phase 2
Foundation
更新字体、颜色、全局样式，下载所有资产文件
Phase 3
Component Specs
生成详细组件规格文档，含精确 computedStyle 值、状态、行为
Phase 4
Parallel Build
在 git worktree 中并行调度 builder agent，每个组件独立重建
Phase 5
Assembly & QA
合并 worktree、接入页面、与原始网站进行视觉 diff

支持平台

推荐 Claude Code（Opus 4.8）
支持 Codex CLI · OpenCode · GitHub Copilot · Cursor · Windsurf · Gemini CLI · Cline · Roo Code · Continue · Amazon Q · Augment Code · Aider

适用场景

平台迁移 — 从 WordPress/Webflow/Squarespace 重建为现代 Next.js 代码库。

源码找回 — 网站在线但仓库消失、开发者离职、遗留技术栈，快速重建代码。

学习 — 通过真实代码解构生产级网站的布局、动画和响应式实现。

使用方式

步骤操作
1在 GitHub 点击 Use this template 创建自己的仓库
2npm install 安装依赖
3npx claude --chrome 启动 Claude Code
4运行 /clone-website <target-url>

禁止用途

Not Intended For

  • 钓鱼或冒充 — 不得用于欺骗性目的、冒充或任何违法活动
  • 将他人的设计冒充为自己的 — Logo、品牌资产和原创内容归原作者所有
  • 违反服务条款 — 部分网站明确禁止抓取或复现，使用前请先检查
