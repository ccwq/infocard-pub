frontend-design Skill：让 AI 前端不再像模板

Anthropic 官方 Skills 仓库里的这个 SKILL.md，不教你套某个 CSS 组件库。它教 AI 先像设计负责人一样做选择：确定主体、建立视觉身份、冒一个可解释的审美风险，然后再写代码。

Subject-first Hero = Thesis Typography carries personality One real risk Critique before build
一句话判断

这个 Skill 的价值不是“让页面更漂亮”，而是把 AI 从模板化默认值里拉出来：每个颜色、字体、结构、动效和文案，都必须回答“为什么适合这个 brief”。

它是一套设计决策协议，不是一套 UI 皮肤

核心流程是：先定位 subject，再写设计计划；先自查是否 generic，再开始实现；最后用截图与自我批判继续修。

01
核心定位

它反对的是“AI 默认审美”，不是反对某种风格

Skill 先把 AI 常见的三个默认外观点名：奶油底 + 高对比 serif + 陶土色、近黑底 + 酸绿/朱红、报纸式密集分栏。它承认这些风格可用，但要求：只有当 brief 真的需要，才能使用。

Anti-template

模板感不是视觉问题，是决策缺席

页面像模板，往往不是因为颜色错，而是因为颜色、字体、布局和动效都没有从 subject 中长出来。

Studio mindset

先像小型设计工作室负责人

Skill 要求 Claude 扮演“每个客户都有不可混淆视觉身份”的设计负责人，而不是组件拼装工。

One risk

必须冒一个可解释的风险

不是乱炫技，而是在 palette、type、layout 或 signature element 上做一个能说明理由的大胆选择。

02
设计原则

Hero、字体、结构、动效都必须服务于 subject

这个 Skill 的重要性在于，它把“好看”拆成了可执行判断：hero 是论点，字体承载人格，结构编码信息，动效只在能服务主题时出现。

Hero = thesis不是大数字模板

首屏必须说出这个主题最有特征的东西

大数字 + 小标签 + 渐变强调不是禁用项，但只有它确实是最佳表达时才该用。否则 hero 应从 subject 的材料、工具、场景和语言里找。

Type carries personality

字体不是中性容器

Skill 要求 display / body / utility 字体有明确分工，字号、字重、字宽、间距都要形成性格，而不是所有页面都用同一套默认组合。

Structure is information

编号、眉题、分割线不能只是装饰

如果内容不是流程或时间线，01 / 02 / 03 这种编号可能就是假秩序。结构设备必须编码真实关系。

Motion deliberately

动效要少而准

页面加载、滚动 reveal、hover micro-interaction、环境氛围都可以用，但分散动效会强化“AI 生成感”。一个被编排的瞬间通常更有力。

03
工作流

真正的流程是：brainstorm → plan → critique → build → critique again

它要求 Claude 在写代码之前先产出 compact token system：颜色、字体、布局、signature。然后用“是否像任何同类页面都会给出的默认答案”来审查计划。

关键机制：不是先生成页面再修细节，而是先让 AI 明确视觉判断，再用自我批判过滤 generic default，最后才开始实现。

Design plan 必须包含四件事

  • 4–6 个有名字的 HEX 色值
  • 2+ 字体角色：display / body / utility
  • 一句话布局概念 + ASCII wireframe
  • 一个能代表 brief 的 signature element

Build 前先审一次

如果计划里的任何部分像“任何类似 prompt 都会产出的方案”，就要先改，并说明改了什么、为什么改。这个要求本质上是给 AI 加了一道审美回归测试。

04
文案也是设计材料

它把 copy 从填充物提升为界面结构

Skill 后半段强调文字不是装饰，而是帮助用户理解和操作。界面文案应该从用户视角命名动作，使用主动语态，让错误和空状态提供方向，而不是情绪。

Plain terms

从用户认识的事物命名

用户管理 notifications，不是 webhook config。用系统实现命名会让产品变成工程暴露。

Active voice

按钮说清楚会发生什么

“Save changes” 比 “Submit” 更具体。动作名在流程里应保持一致，让用户学得会。

Failure as direction

错误和空状态要指路

错误不道歉，也不模糊；空状态不是 mood board，而是邀请用户采取下一步行动。

05
落地价值

这份 Skill 最适合成为前端 Agent 的“审美门禁”

它不是替代设计师，而是给 AI 生成 UI 前加上判断框架：别先写组件，先证明设计为什么属于这个主题。

适合

  • 新产品 landing / dashboard / prototype
  • 已有页面 retheme / reshape
  • 需要摆脱 SaaS 模板感的 AI 前端生成
  • 团队把视觉规则沉淀成可复用 Skill

不适合

  • 只想快速套组件库的低风险后台页
  • 已经有完整设计系统且要求严格复刻
  • 需要像素级实现但没有截图/设计稿
  • 把“大胆”误解成装饰堆满
Recommended agent loop:
1. Pin subject / audience / single job
2. Draft token system: color + type + layout + signature
3. Critique against generic AI defaults
4. Build with intentional CSS specificity
5. Screenshot, remove one accessory, refine
