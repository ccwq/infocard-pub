03 · 6 个 Skill 详情
Skill核心功能关键特性
🥇 coding-principles改前强制自查5 大原则 + 🍞面包屑预扫描 + 3 陷阱拦截（||吞0 / select假选中 / POST硬编码字段）+ 多技术栈检测（Python/Rust/Go）
🛡️ safe-terminal-executor安全终端执行所有 curl/wget 包裹成 Node 脚本，超时保护 + 强制退出 + 日志留存，网络命令永不裸跑
🔍 self-check改后 28 条规则扫描3 级信任轨道（Tier0 观察 / Tier1 软规则 / Tier2 硬规则）+ 🛑完整性阻断点 + 🍞面包屑自动播种
🧪 web-testing自动化回归测试DOM 断言（元素存活性）+ 截图对比（布局崩坏检测）+ OCR 文字验证
📝 changelog变更日志自动生成记录改动文件 + 新增依赖 + 自检通过率 + 规则生长事件（观察池 → 硬规则自动晋升）
🚀 pipeline-init新项目一键初始化对话式问答（项目名/技术栈/类型/自动测试），1 分钟搭好全部质量基础设施

改前扫描

打开文件先读 🍞 头部，了解耦合关系和历史坑位，避免误改联动文件。

改后播种

改完自动更新 🍞，下次 AI 不再失忆。四环闭环：改代码 → 自检 → 更新文档 → 播种面包屑。

置信 ≥ 3 晋升

"I don't know how to code. Not a single line."
