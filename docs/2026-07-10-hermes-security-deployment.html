部署步骤
  1. 1
    准备云服务器
    Oracle / AWS 香港等均可，普通 VPS 够用，需能访问 GitHub。
  2. 2
    SSH 连接服务器
    推荐 Termius（支持密钥管理），配置 IP / 用户名 / 端口（默认22）。
  3. 3
    更新系统环境
    切换 root，提权后更新系统，安装基础依赖。
    sudo su && apt update && apt upgrade -y
  4. 4
    安装核心依赖
    curl / git / tmux / htop 等常用工具链。
    apt install -y curl wget git vim nano unzip tar tmux htop build-essential ca-certificates sudo
  5. 5
    一键安装 Hermes
    官方提供一键脚本，安装后进入首次配置向导。
    curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
  6. 6
    Full Setup 配置
    选择 Provider → 输入 API Key → Base URL（默认）→ 选择 deepseek-v4-flash → Backend 选 local → 按需勾选工具能力。
  7. 7
    配置 Telegram Bot
    通过 @BotFather 创建 Bot，获取 Token后在 Hermes 配置中填入，实现手机端实时交互。也支持 QQ Bot。
  8. 8
    多模态能力补齐
    DeepSeek 主模型短板：图像识别、语音输入/输出。通过调用其他专用模型 API 补齐，形成完整多模态工作流。
关键说明
主模型 DeepSeek-v4-flash（性价比高、速度快）
短版 图像/语音需其他模型补齐
核心价值 逆向、安全分析、授权测试
工具链 Termius / tmux / htop
