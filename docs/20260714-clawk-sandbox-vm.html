Clawk

为 AI Coding Agent 提供独立、可销毁的 Linux VM，Agent 在虚拟机中拥有较高权限，同时宿主机的文件、密钥和系统环境完全隔离。

Go Apache-2.0 Deny-All 网络 364 Stars Disposable VM
别再 `--dangerously-skip-permissions` 了。

`clawk` 让 Claude Code / Codex 在独立的沙箱 VM 里工作，宿主机文件、Keychain、API Token 全在 VM 外面。任务结束 VM 销毁，不留痕迹。

How it Works

clawk run = 沙箱会话

每次运行全新 VM · 代码目录挂载进 VM · VM 内 root 权限 · 宿主机完全隔离

🖥️ 启动 VM
clawk 初始化Disposable Linux，macOS 用 Apple Virtualization，Linux 用 Firecracker
📁 挂载代码目录
当前 repo 目录以只读/读写模式挂载进 VM，代码对 Agent 可见可改
🚫 Deny-All 网络
默认拒绝所有出站连接，Agent 尝试泄漏数据到未知服务器时 clawk 直接拦截
✅ 完成任务
Agent 完成后 VM 可销毁或挂起，代码从 VM 写回宿主机，密钥仍在 VM 外
✦ 核心亮点

🗑️ Disposable VM

每次任务运行在全新的隔离 Linux 环境，任务结束可销毁 VM，不留进程、不留痕迹、不污染宿主机。

一次性环境

🚫 Deny-All 网络策略

默认拒绝所有出站网络连接。Agent 崩溃或被恶意注入手动，也无法把密钥、Token 或代码发送给未知服务器。

网络安全

🍎 macOS + 🐧 Linux

macOS 使用 Apple Virtualization Framework（无需 Virtualization.app），Linux 使用 Firecracker 微虚拟机，单二进制部署。

双平台

🔐 宿主机隔离

Keychain、SSH Key、.env、API Token 全部在 VM 外部。Agent 即使执行 `rm -rf /` 也影响不到宿主机。

完全隔离

📦 单二进制运行

Go 编写，静态编译，`brew install` 或 `curl` 一条命令安装，无运行时依赖。

零依赖

🔌 兼容主流 Agent

Claude Code、Codex、OpenCode、任意 shell 会话。clawk 是平台无关的 VM 容器，Agent 无需感知沙箱存在。

🎯 适用场景

🧪 高风险代码执行

运行来源不明的代码、`npm install` 未知包、`pip install` 不熟悉库。VM 隔离防止恶意代码访问宿主机文件或外泄数据。

🔑 API Token 安全

在 .env 中配置了 GitHub Token、OpenAI Key 或数据库凭证。clawk 确保 Agent 在 VM 里操作，Token 永不进 VM。

🐛 破坏性测试

跑 `dd`、`mkfs`、`iptables -F` 等破坏性命令测试工具行为，不怕误删系统文件。

☁️ 多租户沙箱

同一个宿主机上运行多个互不干扰的 Agent 会话，每个会话有独立 VM、独立网络策略。

核心理念：Agent 应该拥有自己的机器，而不是你的。 Clawk 解决的不是"是否给 Agent 权限"的问题，而是"如何安全地给 Agent 完整权限"的问题。
