Webify MCP

Adaptive web research for AI coding agents.

极低成本上下文压缩MCP工具。它不是把整页网页硬塞进上下文，而是先搜索、再抽取结构、最后只把真正相关的子树交给模型。

Pain Point

why it matters

网页研究的主要成本，不在“搜索结果列表”，而在“把网页读进上下文”。当模型看到的是整页 HTML / 纯文本，大量 token 会浪费在无关导航、页脚、广告与重复结构上。

Webify 把网页先拆成结构图，再用 BM25 + BFS 找到相关节点，最后用 Haiku Synthesis 产出紧凑结论。目标不是“读更多”，而是“读得更省”。

Workflow

text flowchart
Step 01
Search
Brave Search / DuckDuckGo Lite 负责找到候选页面。
Step 02
DOM Graph Builder
把页面转成结构化节点图，保留可检索层级。
Step 03
BM25 + BFS
先打分，再沿结构展开，抓到最相关子树。
Step 04
Haiku Synthesis
把检索片段压成可直接用于推理的短答案。
TEXT PIPELINESearch → DOM Graph Builder → BM25 + BFS → Haiku Synthesis
Input query ↓ Search candidates ↓ DOM structural graph ↓ BM25 ranking + BFS traversal ↓ Relevant subtree (80–300 tokens) ↓ Haiku synthesis for the agent

Two Tools Comparison

一个负责“找问题”，一个负责“找页面里的关键片段”。二者都围绕上下文压缩工作，但入口不同。

Tool When to use What it does Approx cost
web_findmulti-source research 你只有问题，没有具体网页。 搜索多个候选来源，做结构化检索与合成。 ~$0.003 / query
web_lookupsingle-url precision lookup 你已经知道 URL，只想抓相关片段。 从单页中提取相关子树，避免整页灌入上下文。 ~$0.0005 / query
