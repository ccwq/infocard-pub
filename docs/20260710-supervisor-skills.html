01
THE PROBLEM · 核心问题

科研「最后一公里」困境

研究生和年轻学者面临的信息差与经验差，比任何教科书能填补的都更深。

🔬

理论与实践脱节

教科书讲方法论，顶会论文讲具体打法——中间没有桥梁。知道怎么做，却不知道怎么在真实审稿环境中胜出。

👨🏫

导师资源稀缺

导师往往繁忙或方向不完全吻合。学生独自面对：选题对不对？实验够不够？讨论怎么写？

📄

投稿前迷茫

论文写完了，但不知道离顶会标准还有多远。哪个 section 最薄弱？Reviewer 最在意什么？

🤖

AI 能力鸿沟

通用大模型可以润色文字，但无法给出「为什么这样组织引言」的判断——那是十年积累的隐性知识。

05
VS PROMPT LIBRARY · 对比

隐性知识 vs 显性提示词

为什么 Supervisor-Skills 不是又一个 Prompt 集合？

❌ 普通 Prompt 库

  • 本质：显性指令 + 示例，依赖用户自己判断何时用、怎么改
  • 覆盖：通用场景，难处理边界情况
  • 迭代：需要大量人工调优
  • 知识：只传递「说什么」，不传递「为什么这样说」
  • 适用：简单任务：翻译、摘要、格式转换

✅ Supervisor-Skills

  • 本质：十年顶会经验蒸馏，包含判断标准 + 决策树 + 避坑清单
  • 覆盖：每个论文环节都有经过验证的方法论
  • 迭代：上下文感知，多轮对话逐步逼近顶会标准
  • 知识：隐性知识显性化——不只是「写什么」，更是「为什么这样写」
  • 适用：高复杂度、高风险任务：顶会论文全流程
