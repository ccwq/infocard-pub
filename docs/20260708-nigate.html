WARNINGS · 重要注意事项
⚠ 使用前必读
  • 写限制（GUI）：Electron GUI 版不支持原地修改文件本体（缺少内核写权限），建议使用 VS Code 等支持 Atomic Write 的编辑器，或先复制到本地编辑后再拷回
  • 高速启动冲突：如果 U 盘对应 Windows 开启了快速启动，挂载可能失败；建议完全关机（非休眠）后再试，或关闭 Windows 快速启动
  • U盘品质：劣质 U 盘可能导致读写错误或设备识别失败，推荐使用正规高速 U 盘
  • 管理员权限：挂载操作需要管理员权限，系统会弹出密码输入框
  • 设备名：U盘名称不能包含空格或非法字符
🛠 Ninja Tools 可绕过写限制
  • GUI 版受 macOS 沙盒限制，/ninja/kamui.sh 脚本支持真正的原地写，适合需要直接修改文件的场景
  • 支持 ext4/btrfs/xfs/zfs/LUKS/RAID 等多种文件系统，Linux/macOS 双平台
