🚀 解决的问题

Problem
1
痛点

现代框架（Next.js 等）默认全量 hydrated JS，博客/Doc 站性能浪费严重，首屏白屏时间不可控。

2
解法

Astro 默认零 JS 输出，仅在需要交互的组件上启用 client:* 指令，页面可接近纯 HTML 性能。

3
机制

Island Architecture：页面被拆为静态岛屿（零 JS）与交互岛屿（选择性 hydrate），通过 client:load/idle/visible/offline 控制加载时机。
