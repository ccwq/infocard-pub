01
vs. vanilla tmux

相对原生 tmux 提供了什么

tmux 自身只给出一个最小可用的状态栏和默认绑定。Oh my tmux! 在不替换 tmux 本身的前提下，补齐了视觉、复制粘贴、面板、会话、SSH、扩展几乎全部"日常会用到"的能力。

原生 tmux 默认体验

  • 只有 C-b 一个前缀键，与终端常用快捷键冲突频繁
  • 裸默认状态栏，无电池/负载/SSH/主机名/时钟
  • 复制需手动配 vi-mode；选区与系统剪贴板隔离
  • 面板分割键不直观（"、%）
  • 无内建主题，需要自己写大量 set -g status-*
  • 新会话/窗口/面板不会自动继承当前工作目录或 SSH
  • 没有"最大化单个面板到新窗口"概念，只有 zoom

Oh my tmux! 加成

  • C-a 作为第二前缀，C-b 保留，迁移零成本
  • Powerline 风格状态栏：电池、负载、SSH 主机名、用户名、时钟、运行时长
  • copy-mode-vi 默认开启，y 直接拷到系统剪贴板（xsel/xclip/wl-copy）
  • vim 风格面板导航 h j k l、调整 H J K L、交换 < >
  • 把任意面板"最大化到新窗口"<prefix> +，比 zoom 更灵活
  • 新窗口/面板可保留当前路径、SSH 自动重连到远端服务器
  • 内建 TPM 支持，并提供 4 位十六进制 Unicode、Urlscan/PathPicker 集成
  • 所有可调项集中在 .tmux.conf.local，主配置不可改，升级不会丢自定义
02
core features

核心增强功能一览

这些是 Oh my tmux! 默认就开启或随手可启用的能力。它不是简单的"换皮"，而是把 tmux 当成一个可编排的会话内 OS 来配置。

prefix

C-a 双前缀

C-a 作为第二前缀，C-b 仍然可用，与 GNU screen 习惯兼容，且不破坏 tmux 默认体验。

theme

Powerline 状态栏

开箱即用的 Powerline 主题，可配电池条 / 百分比 / 充放电、负载、运行时长、SSH 主机、用户、天气 (wttr.in) 等。

pane

最大化到新窗口

<prefix> + 把当前面板"提升"成新窗口，可继续在里面分割面板；再按一次还原，比 resize-pane -Z 灵活。

copy

系统剪贴板复制

copy-mode-vi 默认启用：v 选区、C-v 切块选、y 复制到 paste-buffer，并自动通过 xsel/xclip/wl-copy 同步到系统剪贴板。

mouse

可切换的鼠标模式

<prefix> m 一键开关鼠标：调整面板、切换窗口、自动进 copy-mode 选文本，需要纯键盘时再关掉。

ssh

SSH/Mosh 感知

状态栏 #{username} / #{hostname} 自动识别 SSH/Mosh；新面板/窗口可自动重连到远端服务器，不必再手动 ssh。

path

保留当前路径

新窗口、新面板可配置继承当前 pane 的工作目录，避免每开一个面板都要 cd 回项目根目录。

url

URL / 路径提取

集成 Urlscan（首选）/ Urlview 抓取终端可见 URL，Facebook PathPicker 抓取文件路径，分别用 <prefix> U 和 <prefix> F。

tpm

内建 TPM 支持

直接 set -g @plugin ... 启用插件即可，不需要再添加 TPM 自身或 run '~/.tmux/plugins/tpm/tpm'；安装/卸载/更新绑定也被改造过。

03
install

安装方式

可装到三处之一：~、$XDG_CONFIG_HOME/tmux、~/.config/tmux。安装脚本会自动备份已有 tmux 配置，再把仓库 clone 到 ~/.local/share/tmux/oh-my-tmux，并 symlink 主配置、复制 .local 自定义文件。

⚠️ 前置条件：tmux ≥ 2.6，awk / perl（含 Time::HiRes）/ grep / sed；终端 TERM 应设为 xterm-256color。安装前建议先 备份现有配置，并且 tmux 当前没有 client/server 在运行（脚本本身也会检查）。
curl -fsSL .../install.sh | bash
自动安装（推荐）：完整命令 →
curl -fsSL "https://github.com/gpakosz/.tmux/raw/refs/heads/master/install.sh#$(date +%s)" | bash
脚本会备份 ~/.tmux/、~/.tmux.conf、.local 等旧文件为 *.YYYYDDMMSS 后缀，再 clone 到 $XDG_DATA_HOME/tmux/oh-my-tmux 并 symlink 主配置。
manual @ ~
手动安装到 ~：
cd && git clone --single-branch https://github.com/gpakosz/.tmux.git
ln -s -f .tmux/.tmux.conf
cp .tmux/.tmux.conf.local .
manual @ $XDG_CONFIG_HOME/tmux
git clone --single-branch https://github.com/gpakosz/.tmux.git /path/to/oh-my-tmux
mkdir -p "$XDG_CONFIG_HOME/tmux"
ln -s /path/to/oh-my-tmux/.tmux.conf "$XDG_CONFIG_HOME/tmux/tmux.conf"
cp /path/to/oh-my-tmux/.tmux.conf.local "$XDG_CONFIG_HOME/tmux/tmux.conf.local"
注意：XDG 路径下文件名没有前导点（tmux.conf 而非 .tmux.conf）。
manual @ ~/.config/tmux
git clone --single-branch https://github.com/gpakosz/.tmux.git /path/to/oh-my-tmux
mkdir -p ~/.config/tmux
ln -s /path/to/oh-my-tmux/.tmux.conf ~/.config/tmux/tmux.conf
cp /path/to/oh-my-tmux/.tmux.conf.local ~/.config/tmux/tmux.conf.local
🚨 永远不要修改主配置 .tmux.conf / tmux.conf。所有自定义都写在 .tmux.conf.local / tmux.conf.local 里；这是这个项目能"平滑升级"的根基，破坏它就只能自负其责。
04
uninstall / restore

卸载与还原

项目本身没有提供 uninstall.sh；卸载等于"把 Oh my tmux! 留下的 symlink、clone 目录和复制出来的 .local 撤掉"。如果安装时让脚本做过备份，可以直接还原。

第一步：先彻底退出 tmux server，避免被运行中的 server 占用
tmux kill-server
对象清理动作
~/.tmux.conf (symlink)删除：rm ~/.tmux.conf
~/.tmux.conf.local删除或备份：rm ~/.tmux.conf.local
$XDG_CONFIG_HOME/tmux/tmux.conf*同上，包括 tmux.conf 与 tmux.conf.local
~/.config/tmux/tmux.conf*同上
~/.local/share/tmux/oh-my-tmux删除 clone 目录：rm -rf ~/.local/share/tmux/oh-my-tmux
~/.tmux/plugins/*如果之前装过 TPM 插件想一并清理：rm -rf ~/.tmux/plugins
恢复你原来的 tmux 配置：自动安装脚本会把旧文件改名为带时间戳后缀（形如 .tmux.conf.YYYYDDMMSS、.tmux.YYYYDDMMSS/、oh-my-tmux.YYYYDDMMSS）。卸载后逐个把它们 mv 回原名即可。
# 1) 关掉所有 tmux server $ tmux kill-server # 2) 移除 Oh my tmux! 留下的入口 $ rm -f ~/.tmux.conf ~/.tmux.conf.local $ rm -rf ~/.local/share/tmux/oh-my-tmux # 3) 如果用的是 XDG 路径 $ rm -f "$XDG_CONFIG_HOME/tmux/tmux.conf" \ "$XDG_CONFIG_HOME/tmux/tmux.conf.local" # 4) 还原安装脚本备份过的旧配置 $ ls -1 ~/.tmux* ~/.config/tmux/* 2>/dev/null $ mv ~/.tmux.conf.YYYYDDMMSS ~/.tmux.conf $ mv ~/.tmux.conf.local.YYYYDDMMSS ~/.tmux.conf.local
05
all keybindings

全量快捷键手册

从 .tmux.conf 提取的所有 bind 命令，按功能分组。<prefix> = C-a 或 C-b（双前缀）。-r 标记表示可重复按。

配置管理

键位动作
<prefix> C-a发送第二前缀键（GNU-Screen 兼容）
<prefix> e在 $VISUAL / $EDITOR（默认 vim）里打开 .tmux.conf.local
<prefix> r重新加载配置文件
C-l（无前缀）清屏 并 清除 tmux 滚动历史

会话管理

键位动作
<prefix> C-c新建一个 session
<prefix> C-f按名字查找并切换 session
<prefix> Shift+Tab切回最后活跃的 session（switch-client -l）

窗口管理

键位动作
<prefix> C-h上一个窗口（替代原生 <prefix> p，-r 可重复）
<prefix> C-l下一个窗口（替代原生 <prefix> n，-r 可重复）
<prefix> Ctrl+Shift+H把当前窗口与前一个交换位置（-r 可重复）
<prefix> Ctrl+Shift+L把当前窗口与后一个交换位置（-r 可重复）
<prefix> Tab切回最后活跃窗口（last-window）

面板管理

键位动作
<prefix> -垂直分割当前面板（split-window -v）
<prefix> _水平分割当前面板（split-window -h）
<prefix> h向左切换面板（-r 可重复）
<prefix> j向下切换面板（-r 可重复）
<prefix> k向上切换面板（-r 可重复）
<prefix> l向右切换面板（-r 可重复）
<prefix> H向左调整面板大小，每次 2 格（-r）
<prefix> J向下调整面板大小，每次 2 格（-r）
<prefix> K向上调整面板大小，每次 2 格（-r）
<prefix> L向右调整面板大小，每次 2 格（-r）
<prefix> >与下一个面板交换位置（swap-pane -D）
<prefix> <与上一个面板交换位置（swap-pane -U）
<prefix> +把当前面板最大化到新窗口，可在新窗口内继续分屏；再按一次还原
<prefix> m切换鼠标模式（开关 mouse 选项）

工具集成

键位动作
<prefix> U启动 Urlscan（若可用）/ Urlview 抓取终端可见 URL
<prefix> F启动 Facebook PathPicker（若可用）抓取文件路径

缓冲区与复制模式

键位动作
<prefix> Enter进入 copy-mode
<prefix> b列出 paste-buffers（list-buffers）
<prefix> p粘贴最顶的 paste-buffer（paste-buffer -p）
<prefix> P从指定 paste-buffer 粘贴（choose-buffer）
06
copy-mode-vi & TPM

copy-mode-vi 键位 与 TPM 行为差异

复制模式默认是 vi 风格。TPM 已内建，但绑定和官方略有不同。

copy-mode-vi 键位动作
v开始选区 / 进入 visual 模式（begin-selection）
C-v在 blockwise visual 与 visual 模式间切换（rectangle-toggle）
H跳到行首（start-of-line）
L跳到行尾（end-of-line）
y复制选区到 paste-buffer 并退出 copy-mode（copy-selection-and-cancel），尝试同步系统剪贴板
Escape取消当前操作，退出 copy-mode（cancel）
TPM 键位（已修改）说明
<prefix> + I安装插件（注意是大写 I）
<prefix> u更新插件
<prefix> + Alt + u卸载插件
⚠ set -g @plugin 'tmux-plugins/tpm'不要写，TPM 已内建
⛔ run '~/.tmux/plugins/tpm/tpm'不要写，会造成冲突
如果你需要 保留原生 tmux 的全部默认绑定，可以在 .tmux.conf.local 里设置 tmux_conf_preserve_stock_bindings=true。Oh my tmux! 不会再覆盖原生的 <prefix> n、<prefix> p 等。

Custom Variables · 自定义变量（示例）

在 .tmux.conf.local 的 # EOF 和 # "$@" 之间定义 POSIX shell 函数，即可在状态栏中使用 #{函数名} 调用。以下是内置示例：
变量名调用方式作用
weather()#{weather}调用 wttr.in 获取一行天气预报，15 分钟刷新一次

wan_ip_v6()#{wan_ip_v6}通过 ifconfig.me 获取公网 IPv6 地址，5 分钟刷新

limits & troubleshooting

边界、坑点与故障排查

Oh my tmux! 适合大多数日常 tmux 用户，但有几件事需要你提前知道。

不要修改主配置：所有自定义只能写到 .tmux.conf.local / tmux.conf.local。直接改主 .tmux.conf 不被支持，升级时会丢失。
本地 set/bind/unbind 被覆盖：在 .local 里加 set / bind / unbind 时，行尾追加 #!important，否则会被主配置覆盖。例：bind c new-window -c '#{pane_current_path}' #!important。
Windows：作者不推荐 Cygwin（fork 太慢，本配置 run-shell 频繁）；推荐 WSL + Windows Terminal，或 wsltty。
状态栏字符串错位 / 行重复：多见于 Linux 上 glib 已升级 Unicode 9.0 但 glibc 没升级（glib ≥ 2.50.1 而 glibc < 2.26），或 iTerm2 的 "Unicode 9 character widths" 开关；样本 .local 现在已经避开 8.0→9.0 间变宽的字符与 emoji。
怀疑行为异常：先 tmux -f /dev/null -L test 启动一个不加载任何配置的纯净 tmux，确认问题是 tmux 自身还是本配置。
Powerline 看不到符号：你不需要装 Powerline 整个包，只要：① 用 Source Code Pro 或 ② Powerline patched 字体 或 ③ 单独装 PowerlineSymbols.otf；然后把 tmux_conf_theme_*_separator_* 设成 \uE0B0~\uE0B3。
