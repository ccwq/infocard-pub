01
背景 · Timeline
Vue 开发者三年的眼馋史

2023 年，shadcn/ui 带火了一种新思路：组件库不发 npm 包，直接把源码复制进你的项目。代码归你，想改就改。

紧接着 Magic UI、Aceternity UI 在这个模式上叠了动效：渐变边框、粒子背景、3D 卡片，落地页质感上限被直接抬高。代价只有一个——全是 React 组件。

一个常见剧本：你在 Dribbble 刷到一张渐变光晕背景的作品集首页，顺着评论摸到 Aceternity，兴冲冲复制代码——.tsx。转头去 GitHub 搜 Vue 版，结果往往不尽人意。

这种事，写 Vue 的多半经历过不止一次。而且在国内尤其明显——Vue 的用户基数摆在这里，眼馋的人比英文圈看起来多得多。

shadcn-vue 已经把基础组件补齐了，但动效这一层，长期是空的。想在 Vue 项目里复刻那种「贵」的质感，基本靠手写 CSS 动画，或者去 CodePen 捡碎片。

这就是 nxui 填的位置。

定位 · Positioning
核心定位：componentry.fun 的 Vue 移植版
原文：This is an EXACT Vue replica of componentry.fun

nxui 把 React 侧 shadcn/ui 生态里的动效组件完整搬到了 Vue 3。

技术栈：Vue 3 script setup + TypeScript、Tailwind CSS v4、motion-v（Framer Motion 的 Vue 移植版）、VueUse、reka-ui。没有一个是实验性的东西。

关键：不是 npm 包，是源码复制进项目。没有对 nxui 的运行时依赖。

亮点组件原文描述：

  • Dynamic Island Header：把 iPhone 灵动岛搬进网页顶栏
  • Split Flap Display：机场翻牌显示屏，做倒计时和数字展示气质拉满
  • GitHub Calendar：GitHub 风格的贡献格子，多种配色方案，直接嵌进个人主页
  • Variable Proximity：鼠标靠近时文字字重变化，作品集标题神器
  • Lanyard：一根 3D 挂绳吊着工卡，鼠标一甩它就跟着荡，About 页几乎必被截图
  • Aurora：极光背景，十分钟内让页面气质完全不同
  • Curved Drawer、Elastic Slider、PlayStation Navbar：官方标着 new，更新节奏肉眼可见地快

安装 · Install
安装方式

方式一：CLI（推荐）

npx shadcn-vue@latest add "https://nxui.geoql.in/r/hyper-text.json"

# 更多组件 URL 格式：
# https://nxui.geoql.in/r/spotlight-card.json
# https://nxui.geoql.in/r/aurora.json
# https://nxui.geoql.in/r/dock.json

方式二：直接复制——官网每个组件页面有完整源码和 live demo，参数可以现场改着看效果，直接复制粘贴。

shadcn-vue 首次使用会引导初始化，跟着提示走即可。安装完成后组件源码在项目中，无运行时依赖。

价值 · Value
源码归你的价值

npm 包型组件库一旦作者弃坑，你的选择只有锁死版本或者整体迁移。

源码在你手里的组件，就算官方不再维护，你也能自己修、自己改，甚至提个 PR 反哺回去。

对一个还在早期的开源项目来说，这一点比组件数量更重要。
风险npm 包型nxui 源码复制
作者弃坑锁死版本或整体迁移自己修、自己改
升级风险breaking changes 影响全项目按需决定是否升级
定制能力受 API 约束改动画曲线/参数/样式完全自由
peerDeps 冲突可能不存在

边界 · Limits
三个边界：哪种情况别碰
情况原因替代方案
中后台全部面向展示型页面Element Plus 等完整设计系统库
性能敏感页Paper Shaders（Hyperspeed 等）低端设备有真实渲染成本上生产前拿目标机型测试
装完不管源码归你，升级和修 bug 也归你；早期 API 变动是常态官方标 new 的组件升级时注意参数变化
只讲好处不讲边界的推荐都是耍流氓。
