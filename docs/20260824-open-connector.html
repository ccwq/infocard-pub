Echo Agent OPC 工具链 桌面 Agent

典型使用：把 MCP Server 接入 Agent

  • 1. 自托管 OpenConnector：Docker / Cloudflare Workers / Fly.io 任选其一
  • 2. 配置 OAuth Apps：在 Web Console 创建 Provider（如 GitHub），填入 client_id / client_secret
  • 3. 用户授权账户：前端引导用户走一次 OAuth 流程，凭据加密入库
  • 4. MCP 接入 Agent：把 http://localhost:3000/mcp 添加到 Claude Code / Codex / Cursor 的 MCP 配置
  • 5. Agent 调用 Action：无需接触凭据，MCP 返回 normalized response

本地启动

docker run -p 3000:3000 \ -e DATABASE_URL=sqlite://data/openconnector.db \ -e OAUTH_STORAGE_KEY=your-encryption-key \ oomol/open-connector:latest
