03 Method · How It Works

评测设计

30 个任务：21 个 Terminal-Bench + 9 个 DeepSWE，覆盖软件开发与终端操作。

固定变量：同一模型（Kimi K3 via Fireworks）、相同任务、同一运行时，消除变量干扰。

确定性验证：基于 verifier 的 pass/fail 评分，客观可复现。

一次尝试：每个配置 × 任务 cell 仅运行一次，不重复。

统一网关：所有 harness 通过同一网关连接，同时支持 OpenAI Responses API 和 Anthropic Messages API。

环境一致性

每次评测均从 golden checkpoint 拉起全新的干净环境，消除脏状态干扰。这是保证结果可比性的关键。

⚠ Cache Hit ≠ Cost Saving

缓存命中率（Cache Hit）衡量的是重复运行时的缓存复用率，不等于任务成本。Exo Harness 缓存命中率仅 70.3% 但成本最低，Claude Code 缓存命中率 67.8% 但成本最高。

⚠ Completion ≠ Cheap

完成任务和任务便宜是两种能力。通过率最高（Codex 66.7%）不等于成本最低，成本最低（Exo Harness $1.05）不等于质量最高。

04 Attribution Boundary · Limitations
归因边界

Harness-Model Pairing

结果描述的是完整 harness-model 配置的表现，不能单独归因于 harness 本身。同一 harness 搭配不同模型，结果可能完全不同。

例如：Codex + Kimi K3 的数据不等于 Codex + GPT-4o 的数据。

评测范围

v1.0 限制

FrontierHarness v1.0 仅覆盖 软件开发与终端任务，不代表 harness 对其他知识工作的普适能力排名。

这是快照，不是最终答案。官方会持续更新评测结果。

05 How to Use

操作入口

打开 FrontierHarness 官网排行榜，查看 12 个配置在 4 个维度的完整排名：

1. 按 Pass Rate 排序 → 找质量最优
2. 按 Median Cost / Pass 排序 → 找性价比最优
3. 按 Cache Hit 排序 → 找缓存策略最优
4. 按 Median Time 排序 → 找速度最优

根据你的质量/成本/速度目标，将候选 harness 与排行榜数据对照，找到适合你的配置。

复测与验证

想用自己的 harness 在 Runta 上复测？通过 Runta 执行层提交你的配置，选择目标任务和模型，即可获得与排行榜一致的评测结果。
