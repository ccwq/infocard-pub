MkAgent

本地优先、由 Pi Agent 驱动的 AI Agent 工作台。Desktop / WebUI / CLI 三端共享同一运行时；订阅、API Key、本地 Ollama 模型均可接入。是 Craft Agent 的精简版，也是桌面 Agent 产品的开源模板。

Electron · Bun · React Pi Agent Runtime Local-First 跨平台
01
三端同源
Desktop · WebUI · CLI

同一个 Runtime，三种界面

Electron 桌面、Bun 服务化 WebUI、CLI 客户端共享同一套会话协议与 Pi 后端。会话、技能、模型配置跨端同步。

Electron Bun RPC 协议
02
Pi 单后端
不依赖 Claude Agent SDK

Pi 是唯一的 Agent Runtime

MkAgent 不携带 Claude Agent SDK / GitHub Copilot 后端；只基于 Pi agent 实现 session、tools、skills、provider 路由。

Pi agent single-runtime 精简
03
模型灵活接入
ChatGPT Plus / Claude Pro / Ollama

支持 ChatGPT / Claude 订阅、API Key、本地模型

通过 Pi 后端统一接入 ChatGPT Plus / Claude Pro·Max 订阅、OpenAI 与 Anthropic 兼容端点、API Key 以及本地 Ollama 模型。

订阅 BYOK Ollama
04
本地优先
数据不出本机

持久化本地 Workspace

会话、技能、配置均存于本机 Workspace；浏览器、附件、文档工具集成在统一桌面端。中文 / 英文双语产品体验。

本地优先 Workspace i18n
05
可二次开发
产品命名 / 路径 / 主题

桌面 Agent 产品的基础模板

所有产品标识符、路径、package 与桌面构建配置均可改名重用，便于 fork 出你自己的桌面 Agent 应用。

fork 友好 产品化 白标
06
MCP / Skill / Browser 内置
桌面 Agent 全套工具

开箱即用的桌面 Agent 工具集

内置 Browser、Attachment、Document、Skill 加载机制；权限、更新、签名、i18n、单元测试已串通。

Skill Browser 权限

快速启动

  • 克隆仓库：git clone https://github.com/MkThingsHQ/mkagent.git
  • 安装依赖：bun install --frozen-lockfile
  • 启动桌面端：bun run electron:dev
  • 启动 WebUI：bun run server:prod
  • CLI 客户端：bun run apps/cli/src/index.ts --help

启动命令

git clone https://github.com/MkThingsHQ/mkagent.git cd mkagent bun install --frozen-lockfile bun run electron:dev
