01为什么需要 Claude Pet

Claude Code 在终端里跑，你在浏览器里摸鱼——不知道它卡在哪一步了。Claude Pet 把 Claude Code 的状态直接映射到桌面角落的卡通机器人：正在读文件时有专属动画、正在执行 bash 有声音提示、遇到错误有失败表情。你不需要切回终端，只看屏幕角落就知道进展到哪里了。

实时状态感知

11 种情绪动画 + 声音，覆盖 Claude Code 所有状态：阅读、编辑、bash 执行、成功完成、失败报错、等待输入。

本地图记忆

SQLite 图数据库存储每个项目的决策、约定、修复记录、踩过的坑。新 Session 开始时自动注入 ≤800 tokens 精炼上下文。

自动生成 SKILL.md

重复出现的模式会被提升为 Claude Code 技能文件（~/.claude/skills/），跨项目共享积累的经验。

GitHub 仓库监听

监听新 commit、PR、code review、release、CI/deploy 状态，用 toast 弹窗即时提示。不再需要来回切换 GitHub 页面确认进展。

人体工程学教练

根据实际编码时间提示护眼、护颈、护腕微休息。宠物本身演示休息动作——看动画的同时也完成了健康提醒。

03工作原理
层级技术实现作用
Hook 监听Claude Code 的 SessionStart / ToolUse / TaskComplete 等 hook 事件实时捕捉 Claude Code 状态变化
情绪渲染PySide6 跨平台 GUI，桌面右下角浮窗卡通机器人动画 + 声音反馈
图数据库SQLite 存储项目级别的决策/约定/修复记录跨 Session 持久化项目记忆
上下文注入SessionStart hook 触发，自动注入 ≤800 tokens新 Session 无需重复读文件
Skill 生成模式识别 → ~/.claude/skills/ 文件将项目经验跨项目复用
GitHub 监听轮询 GitHub API / WebSocket 推送toast 通知 commit/PR/release/CI 状态
