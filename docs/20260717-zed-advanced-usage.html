01 · 效率

多光标与命令面板

Zed 原生多光标，无需插件。结合命令面板与 Tree-sitter 语义感知，编辑速度远超传统逐字操作。

  • Alt-点击添加光标
  • Ctrl-D选中下一个相同词
  • Ctrl-Shift-L全文件相同词
  • Ctrl-P命令面板 / 跳转文件
  • Ctrl-Shift-P全局命令搜索
02 · 自定义

settings.json 与 keymap.json

完全可编程的配置体系。所有 UI 偏好、格式化规则、LSP 行为均通过 JSON 声明，无需 GUI 点选。

  • Ctrl-,打开 settings.json
  • Ctrl-Shift-K打开 keymap.json
  • vim_mode启用 Vim 模拟层
  • base_keymap切换基础快捷键
  • format_on_save保存时自动格式化
03 · 扩展

zed.dev 扩展生态

主题、语言、调试器、AI 工具均通过扩展系统接入。扩展即 Git 仓库，发布需提交 PR 至官方 extensions 仓库。

  • Cmd-Shift-X打开扩展市场
  • dev ext本地开发扩展
  • Rust + WASM扩展开发语言
  • extension.toml扩展清单文件
  • auto_install自动安装扩展
04 · 远程

Remote Development over SSH

本地 UI + 远程语言服务器/终端，延迟感知几乎为零。支持 WSL 端口转发与多跳 SSH 配置。

  • Cmd-Shift-P→ Remote: Connect
  • ssh_connections配置 SSH 连接
  • port_forwards本地端口转发
  • upload_binary无网环境上传服务端
  • WSL nativeWindows 直接开 WSL 目录
Vim 模式深度

Vim mode：不只是模式切换

Zed 的 Vim 模式由 Zed 团队原生实现，非第三方插件。融合了 Tree-sitter 语义、多光标、Zed 命令体系，是目前最佳的非 Neovim Vim 体验。

motions

语义感知 motions：]m / [m 跳方法，]c / [c 跳 Git diff，]x / [x 跳 Tree-sitter 节点

text objects

if / af 函数体，ic / ac 类/定义，gc 注释切换，ys / cs / ds 包裹操作

visual block

块选择使用 Zed 原生多光标，任何插入操作实时同步到所有行，比原生 Vim 块操作更灵活

insert-mode shortcuts

Ctrl-X Ctrl-O 触发补全，Ctrl-X Ctrl-A 唤起 AI 助手，Ctrl-X Ctrl-L 代码行为菜单

寄存器 & 宏

使用 Zed 录制系统，支持复杂操作（自动补全等），比传统 Vim 宏更强大

helix_mode

除 Vim 外 Zed 还支持 Helix 的 modal editing，可与 Vim 模式二选一开启，keybind 系统完全独立。

Keymap Editor

Zed 提供可视化 Keymap Editor（Ctrl-Shift-K → Change Keybinding），点击铅笔图标即可修改，无需记忆 JSON 语法。

扩展开发

创建你的第一个 Zed 扩展

extension.toml

扩展清单：id、name、version、authors、description、repository。id 必须唯一且不含 zed/extension 字样。

本地开发

Extensions 页面 → Install Dev Extension → 选目录。Rust 扩展需 rustup 安装 Rust（不支持 homebrew 版）。

Rust + WASM

扩展代码编译为 WebAssembly。依赖 zed_extension_api，通过 zed::register_extension! 宏注册。

发布

Fork zed-industries/extensions，子模块加入 extensions/，更新 extensions.toml，提交 PR。

主题 themes/ 语言 languages/ 调试器 debuggers/ 图标 icon-themes/ 片段 snippets/ MCP 服务器
Remote SSH 配置

settings.json 完整示例

ssh_connections[ { "host": "192.168.1.10", "username": "me", "port": 22, "args": ["-i", "~/.ssh/id_file"], "projects": [{ "paths": ["~/code"] }], "upload_binary_over_ssh": true, "nickname": "dev-server" } ]
port_forwards[ { "local_port": 8080, "remote_port": 80 } ]
无网络环境

设置 upload_binary_over_ssh: true，Zed 会将服务端二进制从本机通过 SSH 上传，适用于远程服务器无法访问互联网的场景。

三个设置位置

本地设置（~/.config/zed/settings.json）= UI 偏好；服务端设置 = 语言服务器/LLM 路径；项目设置（.zed/settings.json）= 缩进/LSP/格式化。
