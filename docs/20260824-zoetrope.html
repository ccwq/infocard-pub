开源工具 Rust · MIT · v0.1.0

zoetrope

把 Claude Code 的 JSONL 日志实时渲染成动态流程图——主 Agent、子 Agent、工作流、工具调用及执行结果一目了然，支持终端和浏览器，纯本地不联网。

Rust + ratatui 终端 + 浏览器 纯本地不联网 MIT
01
动态流程图
实时渲染

Agent + Subagent 全链路图

每个 Agent（主会话、子 Agent、工作流组）渲染为一个节点，显示当前工具、工具调用次数、输出 Token。节点之间用动态连线表示派生关系。

节点图 子 Agent 工作流
02
时间旅行
拖动进度条

按事件索引的时间轴

时间轴按事件密度而非真实时钟推进——繁忙时段自动撑开，空闲时段压缩。拖动进度条回溯，节点会"逆运行"：Agent 取消完成、工具计数下降。

时间旅行 拖动回放 跳到实时
03
终端 + 浏览器双端
ratatui + WASM

同一内核，两种前端

终端用 ratatui 渲染，浏览器通过 ratzilla 编译为 WebAssembly，运行同一引擎。无须安装：直接访问 zoetrope.furkankly.dev/app 即可。

无安装 WASM ratatui
04
纯本地 · 隐私优先
不联网

Read-only，无网络请求

只读取 Claude Code 已写入的 JSONL 文件，不写、不上传、不连网。小地图帮助在大图超出屏幕时定位当前视口位置。

纯本地 小地图 隐私
05
工具调用详情
bash / read / edit

每个工具的调用与结果

工具调用以芯片形式显示在 Agent 节点下方（`⚒ bash ×5`），显示耗时与执行结果（✓ 成功 / ✗ 失败）。点击 Agent 可查看完整调用链、Prompt 上下文与推理过程。

工具链 耗时 inspect
06
安装方式
cargo / 预编译

一行安装或零安装

Rust 环境：`cargo install zoetrope`（二进制名为 `zoe`）。macOS/Linux/Windows 均有预编译包。也支持从源码构建或直接浏览器访问。

cargo 预编译 浏览器

核心命令

  • 跟踪当前项目：zoe
  • 跟踪另一项目：zoe <dir>
  • 回放已有记录：zoe <file.jsonl>
  • 回放并跟踪新内容：zoe <file.jsonl> --follow
  • 调整回放速度：zoe <file.jsonl> --speed N（默认 8.0）
  • 纯文本树状输出（无需 TTY）：zoe inspect <file.jsonl>
  • 浏览器零安装：访问 zoetrope.furkankly.dev/app

安装命令

cargo install zoetrope
