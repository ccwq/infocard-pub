Universal Skills MCP
把 Skills 交给 MCP Agent

一个把 Anthropic 风格 Skills 通过 MCP 暴露给 AI coding agent 的适配层。它不替 Agent 工作，而是把可按需加载的 Markdown 知识目录接到多个客户端。

MITShell181 starsGitHub 未发现正式 Release
一句话结论：适合需要在多个 Agent 间复用 Skills 的开发者

官方 README 同时提醒：多数 Agent 已经支持某种 Skills，优先评估原生实现；Universal Skills 更像兼容层，而不是所有项目的必选基础设施。

01
WHAT IT DOES

已核实能力：发现、优先级、按需暴露

以下内容来自 canonical repo 的 README；社媒帖子只作为发现线索，不替代官方事实。

DISCOVERY

自动发现四类目录

按优先级搜索：

  • 项目 .agent/skills/
  • 项目 .claude/skills/
  • 用户 ~/.agent/skills/
  • 用户 ~/.claude/skills/
RESOLUTION

同名 Skill 先匹配优先

README 说明：目录按优先级解析，前面的同名 Skill 会覆盖后面的版本，允许项目级配置覆盖全局配置。

EXTEND

自定义目录与安装

可用多个 --skill-dir 追加搜索目录，也可用 npx universal-skills install 从 GitHub 仓库下载指定 Skill。

02
OFFICIAL SETUP

官方安装方式：优先用 npx 接入 MCP

下列命令是 README 明确给出的配置示例；本卡未在宿主机执行这些命令。

CODEX
codex mcp add skills -- npx universal-skills mcp
CLAUDE CODE
claude mcp add \
  --transport stdio skills \
  -- npx universal-skills mcp
OPENCODE · opencode.json
"skills": {
  "type": "local",
  "command": ["npx", "universal-skills", "mcp"],
  "enabled": true
}
关于“npm install”说法

npm Registry 可查到 universal-skills 包（当前查询到版本 3.1.0），但官方 README 的 MCP 接入主路径是 npx universal-skills mcp。因此不要把“必须手动 clone + npm install + 填本地绝对路径”当成唯一安装结论。
