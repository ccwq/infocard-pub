02CORE CONSTRAINTS / 为什么 AI 想画歪都难
4–7 基础形状上限

一个主体轮廓只由 4 到 7 个大基础形状拼成，远低于普通 AI 生成的复杂路径数。

3 语义颜色

两个 IP 主体色 + 一个背景色，无渐变、无百分比光影描述，prompt 干净稳定。

75–85% 裁切比例

近景特写，角色从左下或右下露出，保留配对特征（双耳、对称眼等），防止 AI 画歪。

关键设计决策：每张图只生成一次并原样返回，不做透明度检查、自动拒绝或静默重试。生成即交付，保留随机性带来的多样性。

其他硬约束

  • 粗圆线条，无尖锐或脆弱细节
  • 近景裁切从左下或右下露出
  • 极简可爱风格，去除非必要线条
  • prompt 不出现 logo / brand-mark / app-icon 字眼
03WORKFLOW / 生成流程

用户给定主题时

skill 提出该主题的 3 种受控设计处理方向，用户选方向后生成 6 个独立候选图（A1 A2 / B1 B2 / C1 C2）。

  • 当方向为 3 个时，每方向 2 个变体
  • 当用户选单一方向时，6 个变体全部来自该方向
  • 用户明确授权时直接生成，否则等用户同意

开放主题时

默认提案 熟悉动物 mascot，每个绑定一个产品属性或品牌承诺。近开放批次中，95-100% 为熟悉动物，非动物主体须有直接产品关联。

  • 大型批次通过品种、比例、表情、裁切创造多样性
  • 钟表、锁具、工业工具等不是默认公司 mascot

06DESIGN PRINCIPLES / 设计原则总结

极简轮廓

4-7 大基础形状构建主体，高识别度、可规模化。禁止细碎线条和复杂路径。

三色语义

IP 主体两色 + 背景一色 = 三色体系。prompt 直接写颜色名称，不用 opaque / alpha / transparency 等可能干扰图生模型的术语。

圆润可爱

粗圆线条，无尖角细节，接近婴儿般可爱风格。非必要线条全部移除。

近景特写构图

75-85% 裁切，角色从左下或右下露出，配对特征（双耳、眼等）必须保留，防止 AI 变形。

One-pass 忠实交付

每个候选只生成一次，原样返回。不做透明度检查、自动拒绝或静默重试。随机性保留多样性，用户可主动要求再抽或微调。
