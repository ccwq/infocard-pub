这不是素材库，
而是选择入口

它不托管所有素材，也不替你保证每个站点的许可。它做的是把分散的站点、类型和使用条件整理成一张目录，减少“搜到才发现不能用”的返工。

素材这件事本来就该是查表，不该是碰运气。— 先定位类别，再核对具体资源的当前许可

01目录里有什么

一份长期维护的混合型资源索引，覆盖从视觉素材到声音的多个入口。

视觉素材

摄影、插画、矢量图、视频、图案与纹理，适合先解决“去哪里找”的问题。

  • 摄影：Unsplash、Pixabay、Pexels
  • 视频：Coverr、Mixkit、Videezy

设计零件

字体、图标、配色和 HTML 模板，适合做演示文稿、落地页和产品原型。

  • 字体：Google Fonts
  • 图标：Font Awesome、Bootstrap Icons、Heroicons、Lucide

听觉与付费

声音、音乐和付费素材被单独列出，避免免费与商业服务混成一张不清楚的清单。

  • 声音与音乐：按项目需求筛选
  • 付费：Adobe Stock、Shutterstock、Stocksy

02摄影许可分组

README 将摄影资源按公开声明的使用条件分组；这只是筛选线索，具体页面的现行条款仍是最终依据。

CC0

资源方明确声明 CC0 或等价的放弃权利安排。

自定义许可

各站点自行规定用途、限制和授权方式。

公有领域

以公共领域或相近条件提供，但仍需看来源说明。

要求署名

使用时可能需要按要求标注作者或来源。

未注明许可

没有清楚的统一许可声明，风险最高，需谨慎。

重要边界：仓库自身采用 CC0-1.0，不等于目录中每一个被收录站点或素材都采用 CC0。人物肖像、商标、品牌元素、商用限制和二次分发规则，都要回到具体资源页面确认。

04项目快照与正确用法

仓库快照

截至 2026-09-03 读取：约 14.4k stars、808 forks、65 个 open issues；主要语言 Ruby；仓库许可为 Creative Commons Zero v1.0 Universal。

四步决策

不要因为“免费”就直接使用。先按目录筛选，再打开站点许可页；确认个人/商用、署名、人物肖像、商标与再分发条件，最后保存许可证据。

适用边界

它适合做发现与初筛，不是法律意见，也不是单项素材的版权担保。项目维护者也提醒用户反馈失效链接或新增资源。
