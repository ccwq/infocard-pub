它解决什么问题？

同一篇文章发布到不同平台，通常要反复调整标题、构图和视觉比例。Punk-skill 把文章内容转成可选择的视觉方案，再批量产出封面。

核心能力风格化输出

不是简单加一张图

它强调从文章主题和语气出发做视觉转译，支持极简、拼贴、杂志、科技、建筑等不同表达方向，而不是所有内容套同一个模板。

工作方式批量生成

一套内容，多种视觉版本

  • 极简：用留白、标题和单一视觉重点压缩信息。
  • 拼贴：把多个概念、素材和层次组织成一张封面。
  • 杂志：强调版式、栏目感和编辑设计。
  • 科技 / 建筑：用结构、网格和材质强化主题气质。
  • 平台适配：根据目标平台的比例和阅读场景导出图片。
实际边界：视觉风格越多，越需要人工筛选。生成多个版本不等于每个版本都适合直接发布。
输入

一篇文章或主题 brief

提供正文、标题、关键词、目标平台和偏好的视觉方向。内容越明确，生成结果越容易保持主题一致。

输出

可复用的封面资产

官方仓库中的核心能力是 punk-cover（文章/笔记/推文封面）和 punk-avatar（人物、宠物、物品头像与纪念卡）；输出形式以 Skill 生成的提示词和视觉任务结果为主。

推荐工作流

1. 准备文章正文与目标平台
2. 让 Agent 提炼主题、关键词和视觉方向
3. 指定：极简 / 拼贴 / 杂志 / 科技 / 建筑等风格
4. 生成多个封面候选
5. 检查文字、比例、可读性和平台裁切
6. 选择通过人工审查的版本并导出
使用边界需要人工审查

适合什么场景？

适合公众号、社交媒体、知识内容和个人品牌运营中，需要围绕同一篇文章快速尝试多种封面方向的创作者。

不适合把生成结果视为无需检查的成品：中文标题、品牌元素、人物和版权素材仍应逐张核验。
