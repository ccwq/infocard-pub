OPEN SOURCE IMAGE GENERATION + EDITING

Boogu-Image研究型统一图像生成与编辑模型家族

Boogu-Image-0.1 是一个 Apache-2.0 开源的图像生成与编辑模型家族，包含 Base、Turbo、Edit 等变体，主打高质量文生图、快速生成、图像编辑以及中英文本渲染。仓库明确强调：这是研究项目，不是官方商业 API，也不是官方付费服务。

一句话看点

Boogu-Image 的核心卖点不是“单点特效”，而是把图像生成、编辑、文本渲染、产品图、海报、风格化等能力放进一个统一的开源模型家族里，并用自己的 Boogu Arena 和场景化对比去证明它在开源阵营里有竞争力。

它做什么

01

文生图 / 快速生成

Base 和 Turbo 两条线分别负责稳态生成与 4-step 快速推理。

02

图像编辑

支持对象插入、替换、移除、属性修改、背景替换、风格迁移等编辑任务。

03

文本渲染

强调中英双语文本、海报、文档、界面、品牌图等密集排版场景。

04

产品与海报

适合商品渲染、海报版式、品牌视觉与复杂构图。

为什么值得看

不是单点 demo

Boogu 同时把 Base、Turbo、Edit、FP8 版本组织成一个系统，而不是只展示单一效果图。

中文文本能力明确

README 直接把中英文本渲染、海报、文档、界面作为重点能力，这比“会画图”更适合实用场景。

研究边界说清楚

仓库明确声明不提供官方付费 API 或商业服务，能减少用户把研究项目误当产品服务的风险。
