01

先理解：它解决的不是“生成”，而是连续性

POSITION

角色一致性

有参考图时，锁定五官、发型、气质和身份；没有参考图且未指定国籍时，默认创建原创中国成年女性角色。

首帧构图

默认中央大人物 + 四个悬浮完整人物贴图，先把五套造型和位置关系说清，再进入视频换装。

时间连续性

输出逐段时间轴、精简视频提示词、负面约束和声音节点，避免只写一句“她开始换装”。

读者决策：如果你只想要一张穿搭图，它可能过重；如果你要同一角色、多套造型、明确卡点和换装动作，它才有价值。

04

M1 消耗式贴图：一次换装的状态机

MECHANISM
01

点击目标贴图

选择一个悬浮的完整人物造型，不直接改中央人物。

02

复制飞入

复制完整人物抠像作为副本，原位置的小人物立即移除并留空。

03

对齐触发

副本向中央快速放大，与头、肩、腰和动作姿态对齐。

04

清除重影

副本与白色虚线轮廓同时消失，中央只保留换装后人物。

为什么强调“原位消耗”？它把换装前后状态说成可检查的变化：已用贴图不再留在画面，中央不出现两个重叠人物，导演和后续模型都有明确的负面约束。
05

第一次使用：用最小需求跑一遍导演闭环

FIRST USE

给清楚的输入

  1. 是否有参考图
  2. 角色必须是成年女性
  3. 造型数量与服装方向
  4. 画幅、时长、镜头
  5. 音乐与卡点要求

检查参数锁定

确认 Agent 没把 5 套造型、8 秒、9:16 当作不可修改的硬规则。用户明确指定的时长、比例、数量、动作和音乐始终优先。

检查输出分层

  • 首帧图片提示词
  • 逐段视频时间轴
  • 精简视频提示词
  • 负面提示词
  • 声音节点
06

验证与排障：不要把“提示词写完”当成成功

CHECKLIST

结构验证

  • 同一人物的五套造型是否在角色特征上保持一致？
  • 四个悬浮人物是否都是完整可用的贴图？
  • 时间轴是否覆盖 0 到目标时长？
  • 每次换装是否有明确触发动作与声音节点？

常见排障

  • 人物漂移：补充头/肩/腰姿态对齐约束。
  • 换装重影：强调副本和虚线轮廓同时消失。
  • 贴图不一致：先确认参考图和角色锁定描述。
  • 节拍不准：给出具体卡点时间，不只写“跟着音乐”。

生成服务边界

仓库只提供提示词导演工作流，不包含第三方图像或视频生成服务。最终画面质量、模型能力、人物一致性和音乐版权需要在外部工具中单独验收。

07

隐私、成年角色与许可边界

BOUNDARIES
角色边界：README 的默认角色是成年女性；卡片不把人物生成扩展到未成年人或真实人物身份复制。使用参考图时，确保你拥有使用和处理该图像的授权。

素材边界：项目本身不提供第三方图像/视频生成服务；服装图片、人物参考图、音乐和生成模型的输出分别受各自许可和平台条款约束。

许可：仓库为 MIT，可复制、修改和再分发仓库代码；这不自动授予你使用第三方人物图像、品牌服饰、音乐或生成平台内容的权利。

最小验收：先用原创或已授权参考图，先做 3 套 / 8 秒小样，再扩到 5 套和复杂换装；将角色一致性、贴图消耗、卡点、声音和负面约束逐项检查。
