05 HOW TO USE · QUICK START

Step 1：安装 Skill

  • 下载 architecture-diagram.zip（GitHub Release 或仓库根目录）
  • Claude.ai：Settings → Skills → + Create skill → Upload zip
  • Claude Code CLI：unzip architecture-diagram.zip -d ~/.claude/skills/
  • Project Knowledge：上传 zip 到项目知识库

Step 2：获取架构描述

  • A 让 AI 分析代码库：Analyze this codebase and describe the architecture
  • B 自己写：列出组件与连接关系
  • C 问 Claude 要典型架构参考

Step 3：生成架构图

在 Claude（已安装 Skill）中发送：

Use your architecture diagram skill to create an architecture diagram from this description: [PASTE YOUR ARCHITECTURE DESCRIPTION HERE]

Step 4：迭代与导出

  • 对话式修改：加组件、换配色、调布局
  • HTML 底部有 Copy / PNG / PDF 按钮
  • 直接打开浏览器即可查看，无依赖
