01 / 一图速览

哪些作品是“新剧情”，哪些只是影院重剪？

结论先行：若只追完整主线且避免重复，观看结构是 TV 立志篇 → 无限列车（二选一）→ 游郭 → 刀匠村 → 柱训练 → 无限城电影三部曲。2019、2023、2024 的特别上映/世界巡回片均以既有内容重剪或先行放映为主，不必单独补。

05 / 完结判断

漫画已经结束；动画进入最后阶段

事实 · 已可确认

故事结局早已存在

吾峠呼世晴原作漫画连载于 2016-02 至 2020-05，单行本全 23 卷。动画的最终承载形式为《无限城篇》三部剧场版；这不等于已完结，而是已确定最终制作路线。

漫画：已完结动画：未完结第一章：已上映第二、三章：待定档

关键边界 · 不要误读

“三部曲”不等于每部已定档

官方已确认三部结构；截至 2026-08-31，第二、三章没有公开的正式上映日。网络流传的具体月份或年份，除非可追溯至官方公告，否则只能视为猜测。

06 / 时间推算

什么时候能看见动画真正结局？

以下不是官方档期，而是依据第一章已上映、后续未定档及院线电影制作节奏作出的区间推断。

非常乐观
2028

第二章 2027、第三章 2028；需要较快制作与排期衔接。

较合理判断
2029

第二章最早较可能 2027，第三章 2028–2029；这也是当前最稳妥的完成窗口。

保守情形
2030

若第二章延后至 2028，第三章可能落在 2030 左右。

最终一句话：现在可以把《鬼灭之刃》理解为“63 集正式 TV + 2 部已上映主线电影”；漫画已完结，但动画还剩《无限城篇》第二、三章。以现有公开信息推断，2028–2029 年是较合理的全动画完结窗口。
