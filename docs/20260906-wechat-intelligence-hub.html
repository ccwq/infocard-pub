03
PRIVACY BOUNDARY

隐私边界与风险

本地数据处理是核心承诺，但存在需要注意的边界条件。

✓

数据本地处理

所有微信数据提取后仅在本地存储与分析，不上传任何云服务。

⚠

本地 LLM 调用

LLM API（如 Ollama）需本地部署；第三方 API（如 OpenAI）会发送数据至外部。

!

只读约束

仅支持数据提取与分析，无自动化消息发送功能；不支持群发或自动回复。
