abtopAI Agent 的 htop

abtop 是一个面向 Claude Code、Codex CLI、OpenCode 的终端监控器：把会话、token、上下文窗口、速率限制、子进程、开放端口和 Git 状态放进同一个 TUI 面板里。

为什么值得看

01

多 Agent 一屏总览

同时跑多个 Claude / Codex / OpenCode 项目时，用一个终端面板看清每个会话状态。

02

token 与上下文窗口

显示 token 使用、上下文窗口百分比，并在窗口接近上限时给出可见预警。

03

速率限制可观测

通过 setup hook 收集限额信息，让等待、排队、quota 变化不再靠猜。

04

端口与子进程

发现 agent 拉起但忘记关闭的服务进程和孤儿端口，适合本地开发现场。

工作台结构

发现层

从本地进程、文件状态、配置目录和 OpenCode SQLite 数据库发现会话；支持多个 Claude profile。

观测层

读取 token、上下文、限额、Git 状态、子进程、开放端口；默认只读，不需要 API key 或认证。

动作层

在 tmux 内按 Enter 可跳转到对应 agent pane；也支持 kill selected session 和清理孤儿端口。

安装与运行

curl --proto '=https' --tlsv1.2 -LsSf https://github.com/graykode/abtop/releases/latest/download/abtop-installer.sh | sh
cargo install abtop
abtop --json # 一次性 JSON 快照
abtop --theme dracula
