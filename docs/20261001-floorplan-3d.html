01
2D PLANE · 平面布置

先在平面图上把家想清楚

原始户型按 1:60 / 1:100 比例显示，尺寸单位 mm——可以直接对照装修图纸。

FURNITURE

63 件家具随便搬

左侧家具库六大类（卧室/客厅/餐厨/卫浴/家电/书房休闲）拖入即可；拖动移动、旋转（Shift 进自由角度）、调整尺寸，靠墙自动吸附。现实里不敢乱买的家具，先在虚拟房子里随便摆。

MEASURE

测量与拆改

测量工具靠近墙面自动吸附，Shift 锁定水平/垂直；非承重墙可以直接拆改，承重墙单独标示不怕误拆。图层开关控制尺寸标注、房间名、家具、网格、承重墙的显隐。

02
3D SCENE · 立体漫游

Three.js 里的未来之家

一键切 3D：既能上帝视角通盘看，也能钻进去以第一人称走一遍。

VIEWS

三种视角 + 房间飞行

鸟瞰、斜视、俯视随切；点房间列表镜头直接飞到对应房间，检查每一间不用手动转视角。

WALK

第一人称漫游

桌面 WASD + 鼠标自由走动，触屏设备给虚拟摇杆；走到门边点一下就开门——像玩游戏一样验收动线。

LIGHT

日照与夜景

日照时间滑块拉一天光影，夜景灯光看氛围；全高墙 / 剖切墙切换，室内外观感两相宜。

细节控狂喜：家具有柜门分缝与拉手、软包床头、带环境反射的金属与陶瓷材质——不是色块盒子。而且在 3D 里也能直接选中拖动家具，与 2D 方案实时同步。
03
COST & SAVE · 造价与存档

预算心里有数，方案不会丢

装修最怕预算失控和方案丢失，这两件事工具都替你想到了。

MATERIALS

8 种地面材料实时估价

橡木地板 320 / 胡桃木地板 380 / 800 地砖 220 / 600 地砖 160 / 大理石 650 / 300 防滑砖 140 / 水磨石 280 / 满铺地毯 200（元/㎡）；每个房间独立选材，按面积自动加 5% 损耗估算造价。房间面积与套内使用面积也自动统计。

PERSIST

方案存档与导出

撤销/重做齐备；方案自动保存在浏览器 localStorage——关掉网页再开还在。需要分享就导出 JSON 给家人导入，或导出 PNG 发群里讨论。界面中英切换（默认中文，选择会记住）。

05
CUSTOMIZE · 换成你家

把示例户型改成你自己的

示例自带 13 个房间（主卧/主卫浴/小孩房/客卫浴/洗衣阳台/子女房/厨房…）。户型数据全写在 index.html 里，改数据就换户型。

DATA

五个数据结构

ROOMS：房间多边形、名称、默认地面材料；WALLS / WINS：墙体与窗洞；MATS：地面材料名称与单价；LIB：家具库（类型/名称/默认尺寸/颜色）；buildFurniture()：各类家具的 3D 模型。

START

两种跑法

在线版打开即玩：wy51ai.github.io/floorplan-3d（首次进 3D 需联网拉 Three.js CDN）。本地部署：git clone 后浏览器直接打开 index.html，或 python3 -m http.server 8000 起静态服务。

06
BOUNDARIES · 边界与技术栈

用之前该知道的四件事

1

无 license 标注

仓库未附开源协议——个人自用没问题，商用/二次分发前先联系作者确认。

2

首次进 3D 要联网

Three.js r160 走 jsDelivr CDN；2D 平面部分离线可用，3D 场景首次加载需网络。

3

数据只存本地

方案在浏览器 localStorage——清浏览器数据会丢方案，重要方案记得导出 JSON。

4

示例户型是写死的

换自家户型需要手动改 index.html 里的 ROOMS/WALLS 数据；适合愿意动手的人。

TECH STACK

技术栈

原生 HTML/CSS/JavaScript，无框架无构建；2D 用 SVG 绘制；3D 用 Three.js r160（OrbitControls、PointerLockControls、RoundedBoxGeometry、RoomEnvironment、CSS2DRenderer）；数据存 localStorage。
