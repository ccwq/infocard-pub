FACT 01

事实 1

服务器独立于应用进程运行，可创建项目、控制生命周期、代理 Dev MCP 并搜索文档。

FACT 02

事实 2

工具面会随扩展增删变化，文档要求在扩展变化后重新发现工具。

FACT 03

事实 3

支持 Claude Code、VS Code/Copilot、Cursor、Windsurf、JetBrains 等配置路径；前置条件包括 Java 21+。

BOUNDARY 01

BOUNDARY 02

边界 2

BOUNDARY 03

边界 3
