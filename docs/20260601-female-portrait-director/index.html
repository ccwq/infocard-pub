01 · 一句话判断
Core Take
core definition

Female Portrait Prompt Director Skill 是一个结构化提示词导演系统：输入短参数（场景 / 服装 / 情绪），输出锁定的摄影级人像提示词 + 负向约束，兼容 Codex / Claude Code。

核心价值
不是堆砌词库，而是建立扩写逻辑：保留用户指定参数，填充缺失视觉细节，融合成摄影导演意图的自然段落。
锁参数 单风格路由 负向约束 扩写引擎
一句话总结
给 AI 绘图一个"摄影导演"：它知道怎么处理 facial / body / outfit / scene / camera / lighting / filter 的组合，而不是机械重复输入。
关键判断V1.4.1 最重要的变化是：每个请求都经过单风格文件路由，避免风格关键词冲突；成人女性主体是安全边界，不是内容限制。

03 · 四大核心能力
Capabilities
锁参数扩写
锁定用户指定的参数（场景 / 服装 / 情绪），只填充缺失的视觉细节，不机械重复输入。
单风格路由
每个请求只经过一个 on-demand 风格文件，避免多风格关键词冲突，保证输出风格统一。
模块解析
自动解析 facial / body / outfit / scene / camera+pose / lighting / filter 7 个模块，填充连贯摄影细节。
安全边界
curve-focused 风格有明确安全边界；电商服装展示优先；自拍身份 / 产品核心视觉可锁定用于 reference-image 生成。
04 · 输出格式
Output Format
1. Locked parameters # 用户指定参数的锁定版本 2. Module analysis # 7个模块的展开分析 3. Final prompt # 摄影导演意图的自然段落，可直接复制 4. Negative constraints # 负向约束，控制生成质量
扩写示例
Style: Gufeng xianxia beauty portrait Scene: Traditional courtyard + misty mountains Outfit: Moon-white Tang-inspired fantasy robe Mood: Cool, distant, ethereal Facial: Classical East Asian beauty Camera: Slight side-facing, half-body framing Lighting: Cool soft light Filter: Cool ethereal gufeng filter
扩写结果
扩写后输出完整摄影级提示词，包含：主体描述、场景细节、光影方向、相机角度、负向约束词，可直接粘贴到 Stable Diffusion / Midjourney 等工具。

Structure

路由目录
skill/routes/ 下分 6 个路由方向：
commercial/
电商服装类，强调服装展示优先与稳定的商品视觉输出。
curve/
曲线类，有明确安全边界，避免越界扩写。
fantasy/
幻想类，覆盖古风 / 仙侠等高戏剧化视觉方向。
fashion/
时尚类，处理都市时尚、法式松弛、港风等风格。
lifestyle/
生活类，偏清爽、旅行、运动、自然纪实场景。
oriental/
东方类，承接新中式、东方韵味、古典审美等方向。

✗
不需要结构化提示词如果只是随手一写，不需要导演逻辑的精确控制。
