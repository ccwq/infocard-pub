Zvec：进程内向量数据库，把检索装进应用里

Zvec 是阿里巴巴开源的进程内向量数据库，主打轻量、低延迟和最小化接入成本。 它把 稠密向量、稀疏向量、全文检索、结构化过滤 放进同一个查询面， 适合 RAG、语义搜索、应用内检索与混合召回。

L1 / embed

进程内嵌入

Zvec 不是传统服务型数据库，而是直接嵌进应用的库。没有单独 server，就少一层网络和部署负担。

L2 / retrieval

FTS + 向量 + 过滤

支持稠密向量、稀疏向量、多向量查询、字符串全文检索和结构化过滤，适合把召回面一次做全。

L3 / index

DiskANN + WAL

新一代磁盘索引降低大规模场景内存压力，WAL 保证写入持久性；多进程可并发读，写入保持单进程独占。

L4 / ecosystem

多语言 SDK 与生态

官方覆盖 Python、Node.js、Go、Rust、Dart/Flutter；同时提供 Zvec Studio、Linux / macOS / Windows 支持与 RISC-V 路线。

发布判断 · 这类卡片的主结论不是“又一个向量库”，而是“把混合检索前移到应用进程”。 对需要本地嵌入、低延迟召回、避免额外服务运维的团队，这比单纯堆模型或堆索引更重要。 0.5.0 版本新增 FTS、Hybrid Retrieval、DiskANN 与官方 Go / Rust SDK。
