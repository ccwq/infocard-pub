02

落地时不要混淆

把工具能力、项目自述和可验证边界分开。

BOUNDARY 01

边界 1

跨会话通信不是无限并发，也不是自动形成可靠协议。

BOUNDARY 02

边界 2

消息投递失败必须能显式报错；该版本同时修复了“假装已发送”的问题。

BOUNDARY 03

边界 3

真正进入生产前仍需定义消息格式、幂等性、超时和回执。
