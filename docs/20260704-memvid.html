AI Memory · Vector DB · Rust

Memvid

视频编码 AI 记忆层 · 单文件 · 亚毫秒语义检索 · Apache 2.0

01

核心定位

单文件 AI 记忆系统，将数据、向量嵌入、搜索结构与元数据打包进一个 .mv2 文件。无需运行数据库或 RAG 管道，直接对文件进行高速检索。模型无关、基础设施无关。

model-agnostic · serverless · portable
02

Smart Frames 架构

从视频编码获得灵感——以"智能帧"（Smart Frames）作为不可变存储单元。帧内含内容、时间戳、校验和与元数据，支持追加写入、时间旅行调试和高效压缩。

.mv2 capsule · append-only · crash-safe
03

语义搜索

支持两种检索模式：BM25 全文搜索（lex，基于 Tantivy）和 HNSW 向量相似度搜索（vec）。延迟低至 P50 0.025ms / P99 0.075ms，吞吐量是标准方案的 1372 倍。

P50 0.025ms · P99 0.075ms · 1372x
04

本地嵌入模型

启用 vec 特性后使用 ONNX 本地 embedding 模型（BGE-small 384维 / BGE-base 768维 / GTE-large 1024维）。也可通过 api_embed 接入 OpenAI 云端 API。

BGE · ONNX · zero external deps
05

Living Memory Engine

跨会话持续追加、分支与演进记忆。Capsule Context（.mv2）内含规则与过期策略，可共享给他人或 AI agent。Codec Intelligence 自动选择并升级压缩策略。

append · branch · evolve · shareable
06

Time-Travel 调试

回溯、重放或分支任意记忆状态。以帧为单位做 timeline 风格检查，观察知识如何演进。内置 WAL（1–64MB）确保崩溃恢复，无任何 .wal/.lock/.shm 侧文件。

rewind · replay · branch memory state
07

PDF 导入与清理

内置 pdf_extract 纯 Rust PDF 文本提取；symspell_cleanup 自动修复 PDF 提取常见乱码（如"emp lo yee"→"employee"）。支持将 PDF 内容分段写入记忆文件。

pdf_extract · symspell cleanup
08

加密胶囊 .mv2e

通过 encryption 特性支持 AES-256-GCM + Argon2id 密码保护，生成 .mv2e 加密胶囊文件。锁/解锁通过 lock_file() 和 unlock_file() API 完成。

AES-256-GCM · Argon2id · .mv2e
09

Rust 核心库

Rust 核心库 memvid-core 2.0：cargo add memvid-core。支持 lex（全文）、vec（向量）、temporal_track（自然语言时间解析）、parallel_segments（多线程写入）。

memvid-core 2.0 · Rust 1.85+
10

多语言 SDK

官方提供 Python SDK（pip install memvid-sdk）、Node.js SDK（npm install @memvid/sdk）、CLI（npm install -g memvid-cli）和 Rust 库。

Python · Node.js · CLI · Rust
11

LoCoMo 基准超 SOTA 35%；多跳推理提升 76%，时序推理提升 56%。LoCoMo 含 10×约 26K token 对话，开源可复现评估，LLM-as-Judge 评测。

+35% LoCoMo · +76% multi-hop · +56% temporal
