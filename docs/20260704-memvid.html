Memvid

视频编码 AI 记忆层 · 无数据库服务器 · 亚毫秒语义检索

01

核心定位

Memvid 是一个单文件 AI 记忆系统，将数据、向量嵌入、搜索结构与元数据打包进一个 .mv2 文件。无需运行数据库或 RAG 管道，直接对文件进行高速检索。

model-agnostic · serverless · portable
02

Smart Frames 架构

从视频编码获得灵感——以"智能帧"（Smart Frames）作为不可变存储单元。帧内含内容、时间戳、校验和与元数据，支持追加写入、时间旅行调试和高效压缩。

.mv2 capsule · append-only · crash-safe
03

语义搜索

支持两种检索模式：BM25 全文搜索（lex）基于 Tantivy 实现，以及 HNSW 向量相似度搜索（vec）。延迟低至 0.025ms（P50）/ 0.075ms（P99），吞吐量是标准方案的 1372 倍。

P50 0.025ms · BM25 + HNSW
04

本地嵌入模型

启用 vec 特性后使用 ONNX 本地 embedding 模型（BGE-small 384维 / BGE-base 768维 / GTE-large 1024维）。也可通过 api_embed 特性接入 OpenAI 云端嵌入 API。

BGE-small · ONNX · zero external deps
05

PDF 导入

内置 pdf_extract 纯 Rust PDF 文本提取；symspell_cleanup 特性自动修复 PDF 提取常见的乱码（如"emp lo yee"→"employee"）。支持将 PDF 内容分段写入记忆文件。

pdf_extract · symspell cleanup
06

完全离线运行

无网络依赖，不依赖外部数据库进程。可在浏览器（Node.js SDK）、Python CLI、Rust 库中使用。加密胶囊（.mv2e）支持 AES-256-GCM + Argon2id 密码保护。

offline-first · no server · encrypted
07

多语言 SDK

官方提供 Python SDK（pip install memvid-sdk）、Node.js SDK、CLI（npm install -g memvid-cli）和 Rust 核心库（cargo add memvid-core）。v2.0+ 为当前主版本。

Python · Node.js · CLI · Rust
08

基准性能

LoCoMo 基准超 SOTA 35%；多跳推理提升 76%，时序推理提升 56%。文件结构内嵌 WAL（1–64MB）确保崩溃恢复，无任何 .wal/.lock/.shm 侧文件。

+35% LoCoMo · +76% multi-hop
