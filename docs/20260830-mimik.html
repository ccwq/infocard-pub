01 / RECORD ONCE · EXPLAIN FOREVER

Mimik：录一次操作，自动生成带截图标注的浏览器指南

点下开始录制，像平常一样完成一遍网页操作；Mimik 把点击路径整理成带截图和标注的分步指南。

输入
一次真实浏览器操作

不需要先写脚本或准备复杂流程。

输出
截图 + 标注 + 步骤

把“怎么做”变成可复用说明。

边界
本地优先，发布前脱敏

录制内容可能包含敏感信息。

02
它解决什么问题
FROM DEMO TO SOP

很多网页流程只能靠“看我操作一遍”传递：新人不知道该点哪里，客服排障难以复现，内部系统的操作手册也容易过时。Mimik 的思路是先录制一次正常操作，再把操作过程变成带视觉上下文的指南，降低写 SOP 的门槛。

传统方式

边操作，边手写说明

需要人工截屏、裁剪、编号、描述按钮位置，流程变更后还要重新维护。

Mimik 方式

先做一遍，再自动整理

操作者专注完成任务，扩展记录步骤并生成截图标注，最后只需检查和编辑。

03
录制流程：五步把操作变成指南
CAPTURE PIPELINE
开始录制点击扩展按钮
→
正常操作像平常一样完成任务
→
捕获步骤记录点击与页面状态
→
生成标注截图对应操作位置
→
检查指南编辑、脱敏、分享
关键变化：记录“动作”而不只是记录“结果”截图提供视觉上下文，步骤文字解释下一步应该做什么；两者结合比一张最终结果图更适合交接和培训。
04
能力矩阵：它能记录什么
CAPABILITY MAP
能力卡片结论证据边界
浏览器扩展✓ 在浏览器内启动和停止录制原帖明确；具体浏览器支持以仓库文档为准
操作捕获✓ 把一次点击流程转为步骤原帖明确描述
截图标注✓ 每一步带截图与标注项目公开描述与原帖一致
账号依赖✓ 原帖称无需账号按原帖称呈现，不扩展为身份/权限保证
云端依赖✓ 原帖称不依赖云端具体网络请求仍应由读者审阅代码确认
追踪✓ 原帖称没有追踪隐私判断应以当前版本代码和权限为准
05
适用场景：把一次演示变成团队资产
WHEN IT PAYS OFF
SOP

内部操作手册

录制后台、报销、部署等固定流程，减少手写截图工作。

ONBOARDING

新人培训

用真实页面截图解释按钮和路径，比抽象文字更容易跟做。

SUPPORT

客服与排障

把复现步骤整理成指南，降低“你再点一下那里”的沟通成本。

06
快速上手：不写脚本，先录一遍
FIRST RUN
# 安全的首次使用流程（界面操作） 1. 安装 Mimik 浏览器扩展 2. 打开要演示的网页流程 3. 点击“开始录制” 4. 像平常一样完成一遍操作 5. 停止录制，检查截图、步骤和标注 6. 脱敏后再分享指南

本卡不假设具体商店入口、浏览器名称或导出格式；这些信息以项目当前 README、扩展清单和发布版本为准。

!
隐私与适用边界
REVIEW BEFORE SHARE
录制内容可能含敏感信息密码、Token、个人资料、内部域名和客户数据都可能出现在截图或步骤描述中。分享前必须逐步检查并脱敏；同时审阅扩展权限、当前版本代码和仓库权限。

✗ 不要把“本地完成”理解为自动安全：本地文件仍可能被同步、备份或误提交。
✓ 动态网页、登录态、权限页面和 A/B 变化都需要人工复核，不能只凭一次录制当作永久准确。
