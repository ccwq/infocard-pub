01
DIMENSION 01

浏览器启动与连接

控制浏览器启动模式、CDP 连接方式、Profile 管理、设备模拟与云 Provider。

连接模式（互斥）

  • --cdp <url> / AGENT_BROWSER_CDP：连接已有浏览器的 CDP WebSocket URL
  • --auto-connect / AGENT_BROWSER_AUTO_CONNECT：自动发现并连接运行中的浏览器
  • -p/--provider <name> / AGENT_BROWSER_PROVIDER：云浏览器 provider（browserbase / steel / ios）
⚠ 注意

--cdp、--provider、--auto-connect 三者互斥，不能同时指定。

启动参数

  • --headed / AGENT_BROWSER_HEADED：有头模式（非 headless）
  • --executable-path <path>：自定义 Chrome/Chromium 路径
  • --profile <name>：命名 Chrome profile 目录
  • --state <path>：浏览器 state 目录路径
  • --args <flags>：额外 Chrome 启动参数（逗号分隔或重复）
  • --user-agent <string>：自定义 User-Agent
  • --device <name>：设备模拟（如 iPhone 14）
  • --webgpu：WebGPU 预设参数
  • --engine <name>：指定浏览器引擎
02
DIMENSION 02

扩展与脚本注入

加载 Chrome 扩展、注入 JavaScript 脚本、启用特性开关。三者均支持重复指定，自动累加拼接。

Chrome 扩展

--extension <path>

Config Key: extensions

Env: AGENT_BROWSER_EXTENSIONS

可重复指定多个路径（逗号分隔），各层之间累加拼接。

Init Scripts

--init-script <path>

Config Key: initScripts

Env: AGENT_BROWSER_INIT_SCRIPTS

页面加载前注入 JS，各层累加拼接。常用于注入 polyfill 或 mock。

特性开关

--enable <feature>

Config Key: enable

Env: AGENT_BROWSER_ENABLE

启用 Chrome 实验性特性，可重复指定，各层累加。

03
DIMENSION 03

网络与代理

HTTP/SOCKS 代理、请求头注入、TLS 证书处理、域名白名单。

代理配置

  • --proxy <url> / AGENT_BROWSER_PROXY
  • --proxy-bypass <hosts> / AGENT_BROWSER_PROXY_BYPASS

支持 http://、https://、socks5://、socks5h://

请求与安全

  • --headers <json> / AGENT_BROWSER_HEADERS
  • --ignore-https-errors / AGENT_BROWSER_IGNORE_HTTPS_ERRORS
  • --allowed-domains <domains> / AGENT_BROWSER_ALLOWED_DOMAINS

--headers 传入 JSON 字符串，如 '{"X-Custom":"value"}'

DIMENSION 08 · ENV ONLY

超时与生命周期

以下三个配置项仅支持环境变量，无对应 CLI flag。

空闲超时

AGENT_BROWSER_IDLE_TIMEOUT_MS

daemon 空闲超时（毫秒）。设为 0 禁用自动退出。

CLI 对应：--idle-timeout 支持 10s / 3m / 1h 格式

默认超时

AGENT_BROWSER_DEFAULT_TIMEOUT

所有 wait 族命令的默认超时（毫秒）。覆盖所有 wait-* 命令的默认行为。

禁止 Xvfb

AGENT_BROWSER_NO_XVFB

Linux 无显示器环境下禁止自动启动 Xvfb 虚拟显示器。手动管理显示环境时使用。

COMMAND EXAMPLES

常用命令示例

# 有头模式 + 自定义 profile + 截图
agent-browser screenshot \ --headed \ --profile my-project \ --screenshot-format png \ --screenshot-quality 95 \ https://example.com
# CDP 连接已有浏览器 + 代理 + 自定义 UA
agent-browser \ --cdp ws://127.0.0.1:9222 \ --proxy socks5://127.0.0.1:1080 \ --user-agent "Mozilla/5.0 ..." \ navigate https://example.com
# 自动发现浏览器 + init script + verbose
agent-browser \ --auto-connect \ --init-script /path/to/polyfill.js \ --enable vaadin-details \ --verbose \ click "#submit-btn"
# 云 Provider + 环境变量 + 会话恢复
BROWSERBASE_API_KEY=xxx \ AGENT_BROWSER_SESSION=my-session \ agent-browser \ --provider browserbase \ --restore my-session \ --restore-check-text "Dashboard loaded" \ navigate https://app.example.com

SECURITY NOTES

安全注意事项

CDP 安全

--cdp 直连本地浏览器时，CDP 端口不应暴露到公网。生产环境优先使用 --auto-connect 或云 Provider。

加密密钥存储

AGENT_BROWSER_ENCRYPTION_KEY 应通过 secrets manager 注入，不要硬编码在脚本或配置文件中。

扩展权限

--extension 加载未审查的 Chrome 扩展存在安全风险。只加载可信来源的扩展，并验证其 manifest.json 权限声明。
