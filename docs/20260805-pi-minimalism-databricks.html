AI Agent Harness 设计 成本优化

Pi 极简主义：Harness 设计决定 AI 成本与质量

Databricks 实测：同一模型换不同 harness，每任务成本相差超过 2 倍，质量却相同。Pi 用刻意极简超越臃肿工具链。

核心论点
"模型被调用的 harness 戏剧性地影响成本和质量。在许多情况下，像 Pi 这样简单的 harness 在我们的工作负载上表现最好。" — Databricks 研究《在 Databricks 百万行代码库上基准评测编码 agents》
上下文纪律

Pi 每 turn 发约 3× 更少 context，更好地管理上下文，保持更紧凑的工作集，更少不必要抽象。

极简工具集

Pi 开箱只有 4 个工具，system prompt + 工具定义低于 1,000 token，不挡模型的路。

可扩展性

极简不意味着不灵活。Pi 是第一个为可扩展性和自可编辑性创建的广泛使用的 agentic 基础设施。

Databricks 案例研究：每任务成本对比

Databricks 基于工程师团队定期执行的真实任务创建基准，避免外部基准偏见。

Harness Pass Rate 每任务成本 质量评价
Pi（极简） 最高 基准 与复杂 harness 相同
Claude Code 较高 显著更高 与 Pi 相同
Codex — 最高 与 Pi 相同
"用他们的话说，'模型被调用的 harness 戏剧性地影响成本和质量'，以及'每任务成本显著不同（某些情况 >2x），而质量保持相同'。" — yibie @X 2026-08-05，基于 Databricks 公开研究
Shopify 案例研究：pi-autoresearch 扩展

Shopify 直接作为 Pi 扩展构建 pi-autoresearch，只需问"Pi，为 Autoresearch 创建一个扩展……"。Pi 读它自己的扩展文档，从那里开始构建新工作流。

Autoresearch 是什么

用编码 agents 优化的自主循环。当要求一个改变时，运行实验找出什么有效、什么导致回归。只要目标是可测量的，它能丢弃这些回归并保持自我改进。

Shopify 报告的成果
  • 单元测试运行 快 300 倍
  • React 组件挂载 快 20%
  • 跨多个项目减少构建时间
  • pnpm 性能改善
为什么极简现在赢
Anthropic 的信号

Anthropic 最近把 Claude Code 的 system prompt 砍掉 80%。这表明前沿模型现在通常非常擅长理解终端编码环境，harness 的原生性优势已变弱。

本地模型适配

Pi 的上下文纪律对本地模型尤为重要：更低上下文窗口、prefill 耗时，pi 的稳定 prompt 前缀避免分钟级重新 prefill。

"更强、更贵的模型配高性能 harness 可以比反过来的组合更便宜。我们同意必须考虑端到端工程经济，而不仅仅是每 token 价格。" — yibie @X 2026-08-05
