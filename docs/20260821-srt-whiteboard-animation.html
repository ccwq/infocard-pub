6步工作流
1解析SRT字幕，按25–35秒建议时长拆分为多幕
2确认分镜后生成统一风格的线稿草图
3结合字幕和原图创建标注（annotation.json），载入预览台
4在预览台调整区域、叙事顺序、时序，保存标注
5确认后逐幕渲染MP4（流式笔迹：先ink后color）
6多幕项目合并为完整视频导出
核心能力
字幕驱动编排
按字幕事件而非画面坐标建立绘制顺序，每步完成后等待确认
分区遮罩（Mask）
每个元素跟随字幕依次出场，配合 protectedRegions 防止遮挡露馅
流式笔迹
先输出 ink 线稿，再 color 添彩；笔尖贴近当前笔迹，支持 skeleton 加速
本地预览台
assets/preview.html 可视化编辑区域、顺序、时间和字幕关联
暖米黄纸张背景
默认 #F5EBD7，深灰线条，红/橙/蓝仅作点缀，极简干净
断点续做
每步人工确认后进入下一步，避免在分镜未定时浪费渲染成本
典型应用场景

适合把知识讲解、故事口播、课程字幕或短视频文案（如天涯神贴）制作成暖米黄色纸张底的手绘动画。可结合AI配音（如Edge TTS）做完整短视频，或接入 CodeX + AI视频模型批量生产。

安装命令
python scripts/prepare_env.py --check
python scripts/prepare_env.py
# 输出 ENV_PY=<路径>，后续渲染使用该解释器

# 解析字幕生成分镜
python scripts/parse_srt.py <字幕.srt> --target-sec 30

# 渲染单幕
<ENV_PY> scripts/render_stream_whiteboard.py <图> <标注.json> output.mp4 assets/drawing-hand.png --ink-path grid --color-fill contour-wipe

# 合并多幕
<ENV_PY> scripts/merge_scenes.py --inputs 幕1.mp4 幕2.mp4 --output final.mp4
