📋 6步工作流

字幕驱动
① 解析字幕
python parse_srt.py <字幕.srt> --target-sec 30
按25–35秒拆分多幕
② 生成线稿
确认分镜后生成统一风格线稿草图
③ 创建标注
annotation.json 关联区域、时序、字幕
④ 预览台调整
assets/preview.html 编辑区域/顺序/时序
⑤ 逐幕渲染
流式笔迹：先 ink 线稿，再 color 添彩
⑥ 多幕合并
merge_scenes.py --inputs 幕1 幕2 --output final.mp4

⚡ 核心能力

6项
字幕驱动编排
按字幕事件而非画面坐标建立绘制顺序，每步确认后进入下一步
分区遮罩（Mask）
protectedRegions 防止遮挡露馅，元素跟随字幕依次出场
流式笔迹
先 ink 线稿再 color 添彩，支持 skeleton 加速渲染
本地预览台
assets/preview.html 可视化编辑区域、顺序、时间和字幕关联
暖米黄纸张背景
默认 #F5EBD7，深灰线条，红/橙/蓝仅作点缀，极简干净
断点续做
每步人工确认后进入下一步，避免分镜未定浪费渲染成本

环境准备

独立的 Python 虚拟环境，无需全局安装依赖。

Terminalbash
# 检查环境 python scripts/prepare_env.py --check # 准备虚拟环境 python scripts/prepare_env.py # 输出: ENV_PY=<路径> # 解析字幕生成分镜 python scripts/parse_srt.py <字幕.srt> \ --target-sec 30 --min-sec 25 --max-sec 35 # 生成区域检查图 python scripts/render_annotation_preview.py \ <图片> <标注.json> <预览图输出>
Terminalbash
# 渲染单幕（流式笔迹） <ENV_PY> scripts/render_stream_whiteboard.py \ <图片> <标注.json> output.mp4 \ assets/drawing-hand.png \ --ink-path grid --color-fill contour-wipe # 使用 skeleton 加速（线稿清晰时） <ENV_PY> scripts/render_stream_whiteboard.py \ <图片> <标注.json> output.mp4 \ assets/drawing-hand.png \ --ink-path skeleton # 合并多幕为完整视频 <ENV_PY> scripts/merge_scenes.py \ --inputs 幕1.mp4 幕2.mp4 幕3.mp4 \ --output final.mp4
