02架构：为什么 121M 能干 1B+ 的活

Needle 3 = Laddered Simple Attention Network，四个非常规选择：Monarch Hadamard MLP 替代 FFN、GQA 注意力加 causal conv taps、engram n-gram 记忆（gather 读取——参数大头在这里，所以 121M 模型只做 50M 量级的算术）、multi-lane hyper-connections。关键创新是阶梯化训练：2 到 20 层的每个深度都是可独立部署的模型——设备差就砍层，2 层子网就能跑。

A置信度是"扣下"不是"瞎说"——低于 0.1 的调用进 suppressed_calls 而非直接执行；ungrounded field 校验拒绝输入里找不到依据的参数值（含日期推理）；官方给的门槛模式：≥0.7 直接执行、之间就向用户确认、没有调用就明确拒绝。
B微调决定置信度头在不在——本地 LoRA 微调（4-bit，JAX）不动置信度头，导出后 confidence=None；平台微调（2-bit 全量）重训并重校准。DroidCall 微调让每个子网升 18–36 分，4 层起（29M 参数）过 DeepSeek V4 Flash（官方数据）。
C>5 个工具自动上检索——内置检索头每轮只把 top-5 工具渲染进语法约束，工具再多也不爆上下文。

03上手：五分钟跑通

  1. 安装：pip install cactus-needle（浏览器可先玩 cactuscompute.com/needle；权重与全平台引擎在 HF Cactus-Compute/needle3）。
  2. 装饰一个函数——函数签名就是参数类型，docstring 就是工具描述：
    import needle

@needle.tool
def get_weather(city: str):
    "Get the current weather for a city."
    return {"city": city, "temp_c": 27, "sky": "clear"}

agent = needle.Needle(tools=[get_weather])
print(agent.run("what's it like in Lagos right now?")["results"])
# [{'city': 'Lagos', 'temp_c': 27, 'sky': 'clear'}]
  3. 读响应 JSON：每轮固定返回 function_calls（语法保证匹配 schema）+ reasoning（每个参数的来源推导）+ confidence（0–1 校准分）+ prefill_tps/decode_tps（本机速率，示例 4300/850）。离题请求返回空列表——答案就是工具执行结果，没有自由文本。
  4. 部署到设备：needle build --platform macos-arm64（或 linux-arm64 等，--layers 8 砍层）；每平台引擎 <1MB，启动时加载 needle3.cact；--serve 起本地服务。仓库 environments/ 还带 smart_home/wearable/media_player/kitchen_appliance/productivity 五个现成工具面练手。
别踩的坑（官方 Common mistakes 精选）：别指望它答自由文本问题（离题=空列表，要自己接）；复用同一个 Needle 实例跑多轮对话（新实例丢上下文，新工具才建新实例）；weights= 只吃 .cact 不吃 .safetensors；checkpoint/adapter 只认 safetensors，pickle 直接 ValueError。

04冷静面与判断

四个折扣点：① 基准全是指令跟随类（工具调用/抽取），通用对话与知识问答被刻意牺牲——这不是通用小模型；② "打过 10 倍大模型"是官方基准图自述，未第三方复测（但任务定义收窄到 exact-match 工具调用，可信度尚可）；③ 本地微调导出的模型没有校准置信度，生产上要么接受 None 要么走平台微调（数据上 Cactus 云）；④ 无 release/tag，遥测默认开（虽透明但需手动关）。

判断：Needle 把"模型不一定要越做越大"变成了一个可复制的工程范式——砍掉聊天、语法约束输出、阶梯化砍层、置信度门控，四件事叠出来一个 8MB 就能上岗的"手指头模型"。适合：智能家居/可穿戴/车载/机器人的本地指令层、隐私敏感的表单抽取、离线设备的意图路由。不适合：需要对话、需要知识问答、需要流利文本生成的场景。观察点：阶梯微调生态（每个产品微调自己的 2 层小网）如果跑通，"一人一模型"的成本会低到离谱。
