OVERVIEW · 一句话概述

x64dbg MCP Server 是什么

定位调试器 MCP 插件

x64dbg 的 MCP 协议插件

x64dbg 是 Windows 平台最流行的开源 x64/x32 调试器。本项目为其编写原生 MCP Server 插件，通过 HTTP 接口将调试器完整能力暴露给 AI Agent，让自然语言操控调试成为可能。

技术栈Zig

Zig 构建 · 零依赖 · 单文件

使用 Zig 语言编写，编译产出单一可执行文件，无需运行时依赖。Windows x64 平台开箱即用。

CAPABILITIES · 调试能力

x64dbg 调试能力全开放

MCP Server 暴露 x64dbg 调试器的完整功能集，AI Agent 可通过 MCP 协议调用。

能力域 能力标签 说明
断点控制 breakpoint-control 设置断点 条件断点 硬件断点 内存断点
执行控制 execution-control 单步执行 步进 运行 / 暂停 跳过函数
内存操作 memory-operations 读取内存 写入内存 Dump 内存区段 搜索内存
寄存器 & 标志位 registers-flags Dump 寄存器 读取标志位 修改寄存器值
模块 & 符号 modules-symbols 列出模块、导入/导出表、符号解析、调用栈
适用人群：逆向工程师、恶意软件分析师、安全研究员、CTF 选手，以及希望用 AI 辅助理解程序行为的开发者。

INSTALL · 安装与使用

安装方式

需要 x64dbg 调试器本体（单独下载）+ MCP Server 可执行文件。

前置x64dbg 调试器

x64dbg 本体

先安装 x64dbg 调试器（x64dbg.com）：

https://x64dbg.com

下载 x64dbg_snapshot*.zip，解压后备用。

方式一GitHub 下载

MCP Server 单文件

git clone https://github.com/duty1g/x64dbg-mcp-server
cd x64dbg-mcp-server
# 下载或编译 release 版本
./x64dbg-mcp-server.exe
MCP 集成Claude Code

Claude Desktop 配置

{
  "mcpServers": {
    "x64dbg": {
      "command": "/path/to/x64dbg-mcp-server.exe",
      "args": ["--port", "8080"]
    }
  }
}
源码编译Zig

从源码构建

zig build release
# 或
zig build -Drelease-safe
