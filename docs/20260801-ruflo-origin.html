核心定位
What ruflo actually is
ruflo 是"元框架"层面的 Agent 编排引擎——它不替代 Claude Code 或 Codex，而是让它们成为同一个 swarm 中的节点。
传统 Agent 工具是独立运行的：一个 Claude Code 实例、一个 Codex 会话，各自为战。ruflo 的思路是：把这些工具当作"可调度的能力节点"，通过统一的编排层让它们共享记忆、协作任务、自动路由。

它的核心创新是"Adaptive Memory"（自适应记忆）——每个 Agent 的经验会积累到共享记忆池，后续任务自动复用，不需要每次重新上下文。"Self-learning Intelligence"（自学习智能）则让 swarm 越用越聪明。

快速上手
Get started in minutes
# 安装 ruflo
npm install -g @ruflo/cli

# 初始化项目
ruflo init my-swarm
cd my-swarm

# 定义 swarm 配置（swarm.yaml）
nodes:
  - name: claude-node
    type: claude-code
    memory: adaptive
  - name: codex-node
    type: codex
    memory: shared
tools:
  - name: file-ops
    adapter: universal

# 启动 swarm
ruflo start

# 或作为服务运行（REST API）
ruflo serve --port 8080
