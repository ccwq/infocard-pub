03

每课结构：Build It → Use It → Ship It

每课遵循 6 步循环：问题 → 概念 → 数学直觉 → 从头实现 → 对比框架用法 → 产出 artifact。

MOTTO · 问题

每课以一句核心格言和具体痛点开场，明确这课要解决什么问题。

CONCEPT · 数学直觉

图表 + 推导，先理解原理。不依赖框架——手写矩阵乘法、求导过程、注意力公式。

BUILD IT · 徒手实现

纯 Python / Rust / TypeScript / Julia，从零实现同一算法。无任何框架依赖。

USE IT · 框架对比

用 PyTorch / sklearn / HuggingFace 运行相同任务，理解框架内部发生了什么。

SHIP IT · 产出 Artifact

Prompt / Skill / Agent / MCP Server——带走一个可直接使用的生产级组件。

QUIZ · 验证理解

每个 lesson 结尾测验，确保真正掌握而非走马观花。
