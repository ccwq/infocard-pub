④ 核心原理：分布式推理

24,576 个专家如何分配到你的硬件

Strata 将 MoE 专家按访问频率分层调度，每生成一个词（Token）只需调用其中 10 个活跃专家：

🟢
GPU — 高频专家
最频繁调用的专家常驻显存，延迟最低，每次推理必经。
最低延迟
🟡
RAM — 全量专家
所有专家镜像保存在内存，随时可交换到 GPU，64GB+ 内存推荐。
按需交换
🟠
CPU — 低频专家
访问频率低的专家下沉到 CPU，降低显存占用。
备用层
🔵
SSD — 查找表
极少访问的专家元数据存 SSD，内存溢出时的最终兜底层。
查找表
✅ 关键技术：每词仅需 10/24,576 专家
MoE 架构天然稀疏，Strata 精确调度让你用 12GB 显存跑了原来需要 250GB 才能放的模型。
⚡ MTP 加速（Guess-Then-Check）
小模型"猜测"下一个词 → 大模型并行验证正确性 → 1.6–1.8× 生成速度提升。
开启方式：下载 mtp-q2_0.gguf（~0.89GB）+ strata/rt（~824MB），Strata 自动启用。

⑨ 术语表

核心概念一览

MoE
混合专家架构（Mixture of Experts）：1250 亿参数拆成 24,576 个"专家子网络"，每次推理只激活其中少量几个，大幅降低计算量。
MoE 专家
每个专家是一个小型神经网络；路由器（Router）决定每个 Token 该调用哪些专家。Strata 中每词仅激活 10 个。
GGUF 量化
将 FP16/BF16 权重压缩为低精度整数（Q2/Q3/Q4 等），体积缩小 2–4 倍，显存占用大幅降低，精度损失可控。IQ=Improved Quants，优于传统 Q 量化。
MTP 加速
Multi-Token Prediction：先用小模型猜测下一个 Token，再用大模型并行验证，1.6–1.8× 加速。Strata 通过 mtp-q2_0.gguf + strata/rt 模块实现。
IQ2_XS / IQ3
Improved Quant 量化级别：IQ2_XS ≈ 2.2-bit，IQ3_S ≈ 3.5-bit；比 Q2/Q3 精度更好，显存占用适中，主流推荐配置。
Abliterated
移除了模型内置的内容安全过滤层（即"审查"机制）；用户需自行承担合规责任。
Distributed Inference
分布式推理：GPU/RAM/CPU/SSD 各层按访问频率存储专家，减少显存需求，实现消费级硬件跑大模型。
SWE-bench
软件工程基准测试，衡量 AI 模型解决真实 GitHub Issue 的能力。Coder 变体达原版 91%。
