AGENT SKILL · LOCAL-FIRST WRITING TOOL

易创（easy-writing）
把网文创作流程搬进本地桌面

这不是普通文本编辑器，而是面向网文作者的本地写作工作台：作品、设定和写作记录都留在你电脑上，AI 只是你可选的辅助手段，榜单风向和竞品拆书也都被收进同一个工作流里。

本地优先AGPL-3.0小说创作AI 辅助榜单风向

FIRST DECISION

适合“长期写书”
而不是临时拼一个 AI 对话框

如果你要的是章节管理、自动保存、历史版本、参考资料和本地数据控制，它比单纯聊天式写作工具更像一个真正能落地的创作系统。

但它也不是“打开就自动出书”：AI Key、模型配置、术语和内容审校仍然要你自己把关。

01 / IDENTITY

它解决的是“怎么持续写一本书”，不是“怎么多打几句字”

WHAT IT IS

纯本地的网文写作桌面软件

1

作品和设定在你本机

README 明确写了：作品、设定和写作记录存在你自己的电脑上；基础写作功能可离线使用。

2

面向网文作者的流程

从小说创作、码字统计到 AI 辅助创作、排行榜风向，核心是围绕长期连载与章节推进来设计。

3

开源且可自持

项目采用 AGPL-3.0，代码公开；如果你更重视自托管和数据归属，这一点很重要。

核心输入

书名、章节、角色、设定、时间线、故事线

它把创作所需的“资料五件套”放进同一个工作台，而不是散落在多个文件夹里。

核心输出

可持续写作，而不是一次性灵感卡片

历史版本、自动保存、统计和导出能力，都是为了让长篇写作能持续推进、而不是写丢了。

02 / FIRST RUN

先装好，再把你的模型和提示词接进来

1INSTALL从 Releases 下载桌面包，打开后直接新建作品即可开始写作；基础写作不要求先配 AI。
2AI / BYOK到“模型管理”选择服务商预设，填入你自己的 API Key，再测试连接并设为默认模型。
3PROMPTS“提示词管理”里每个场景都能改；提示词是本机 md 文件，可视化改，也可直接改文件。
4WRITE从写作台、角色关系图、时间线和灵感速记开始，把一本书真正跑起来。

桌面入口

Windows 和 macOS 都有安装包；桌面端是整个工作流的主场，尤其是榜单风向和本地数据管理。

AI 入口

支持 DeepSeek、通义千问、智谱、Kimi、OpenAI 以及其他 OpenAI 兼容服务；Ollama、LM Studio 等本地模型也能接。

提示词入口

提示词是独立的本机文件，意味着你可以把“写作习惯”沉淀成可复用配置，而不是只留在记忆里。

03 / WORKFLOW

它的价值不在单点功能，而在把整条写作链打通

模块做什么为什么重要
写作台富文本编辑、卷/章目录树、拖拽排序、全书搜索、查找替换。适合长篇连载，不只是在一个输入框里堆字。
参考资料五件套大纲、角色、设定、时间线、故事线。避免人物和世界观在长篇里越写越散。
书架多作品管理、分组、封面、TXT/JSON 导入导出、回收站。适合同时跑多本书，切换成本低。
码字统计今日字数、趋势图、码字日历、连续天数、每日目标；手写与 AI 产出分开记账。让写作节奏可见、可追踪、可复盘。
灵感速记首页快记 + 素材库 + 写作台面板，一份数据三处可用。灵感不会因为没及时记住而丢掉。
竞品拆书TXT 整本导入，逐章拆解节奏与卖点。适合做选题分析和结构拆解。
AI 封面 取名器 简介生成 AI 调用账本
04 / BATTLE MAP

榜单风向不是噱头，是给选题和内容结构找信号

风向

抓起点、番茄、七猫等 80+ 源

桌面版内置爬虫，用你自己的网络抓排行榜，数据只存本机。

用途

看趋势、看标签、看竞品

适合选题判断、热门方向扫描和写作方向校准。

边界

它是参考，不是自动答案

榜单只是信号，真正的内容决策仍然要看你的题材、节奏和受众。

05 / CONFIG

几个真正影响运行的配置点

配置项作用边界
模型服务商预设快速切换 DeepSeek、通义千问、智谱、Kimi、OpenAI 等。要配的是你自己的 Key，不是项目自带密钥。
OpenAI 兼容服务兼容一类接口，就能接入。兼容性取决于具体服务商实现。
本地模型Ollama、LM Studio 等可直接接。API Key 可留空，但你的本机服务得可用。
提示词文件按场景调整温度和写法。提示词会影响结果风格，别把默认值当真理。
自动备份txt + json 备份，便于整本导出。备份位置是“文稿”目录，不是云端同步盘。
06 / OUTPUTS

适合什么人，不适合什么场景

适合

  • 写长篇网文、持续连载的人。
  • 想把资料、设定和章节一起管理的人。
  • 愿意用自己的模型和 Key 做 BYOK 的人。
  • 需要本地数据和离线基础写作的人。

不适合直接依赖

  • 只想要一个极简聊天框的人。
  • 完全不想管模型配置的人。
  • 把“AI 自动写完”当目标的人。
  • 没有桌面环境、只想网页轻量使用的人。

最小验收

  • 能新建作品并持续写入。
  • 能在模型管理里连上一个服务。
  • 能改提示词并看到结果变化。
  • 能把历史版本、统计和导出串起来。
