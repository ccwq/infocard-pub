一句话结论
34.5M 的 medium 档在 OCR 本职任务上，官方评测超过 235B VLM；它适合把图片文字提取出来，但不等于能替代文档理解、问答和结构化解析的大模型路线。
速览：先决定走哪条路

纯文字提取

本地三行代码跑 PP-OCRv6；权重首跑从 HuggingFace 或 ModelScope 自动下载。

版面与语义

要 Markdown / JSON、表格理解或问答，转向 VL / PP-StructureV3 线；官方配有 PP-ChatOCR 方案。

不想装环境

先用官网体验中心/API；Windows 用户也可试 Umi-OCR 离线 GUI。

设备分档

tiny 1.5M 面向边缘，small 7.7M 面向移动，medium 34.5M 面向服务器。

§02 / “超 GPT-5.5”到底超在哪里

官方发布说明写的是“超过主流 VLM（Qwen3-VL-235B、GPT-5.5）”，这里的比较范围是 OCR 本职：定位文字并输出文字。它不是对文档语义理解、跨页问答或复杂推理的总评。

选型边界：识字用 PP-OCRv6；理解“这份合同的风险是什么”、从版面生成结构化数据，走 VLM / PP-StructureV3。6 月旧卡《ocr-model-inventory》已做过横向盘点，本卡补的是单工具落地。
§03 / 语言覆盖：50、109、100+ 不是一回事
口径范围该怎么说
PP-OCRv6 单模型50 语言中、英、日 + 46 种拉丁语系；工业字符也有专门增强
PP-OCRv5 主模型5 种简中、繁中、拼音、英、日；只说这一条会遗漏多语言线
PP-OCRv5 多语言模型109 语言、2M官方于 2025-10 另发，部分语种较上代 +40%
仓库整体100+ 语言项目全仓口径，不等于 v6 单模型
§04 / 分层落地：从三行代码到推理后端
pip install paddleocr
from paddleocr import PaddleOCR
ocr = PaddleOCR(); result = ocr.predict("test.png")

§05 / 不写代码的路径与坑

官网 / Umi-OCR

官网体验中心免安装。Umi-OCR 是免费开源离线 GUI，正式版 v2.1.4 停在 2024-08-31；其 Paddle 引擎插件是否跟进 v6 需自行确认。

CPU 指令集

Umi-OCR 的 Paddle 插件版 CPU 须支持 AVX，不支持奔腾、赛扬、凌动；出现 0xc0000142 或 OCR init fail，按官方提示换 Rapid 版。

风险面板：最近提交为 2026-09-16，3.7.0 后暂无新版；在意节奏时认准 3.7.0。PaddlePaddle 依赖体积可能是部署负担，可评估 ONNX 替代路径。Dify、RAGFlow、Cherry Studio 的采用属于 README 自述，未逐一独立验证。
边界与行动 / 20 分钟验证
  1. 安装：pip install paddleocr，运行 ocr.predict("test.png")。
  2. 找一张中文手写与印刷混排图片，记录识别文字。
  3. 与系统自带识别结果对比，再确认 predict 输出含坐标。
  4. 失败先查 Paddle 版本与 CPU 指令集；Umi-OCR 则先查 AVX 和插件版本。

一句话选型：纯文字提取用 PP-OCRv6；版面到 Markdown / JSON 的结构化任务，走 VL / PP-StructureV3。
