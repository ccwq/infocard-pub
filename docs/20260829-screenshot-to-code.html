🎯 一句话理解

把截图、Figma 设计稿、甚至网站操作录屏，转换成可继续修改的功能代码。支持 React / Vue / Bootstrap / Ionic，输出 HTML + Tailwind 干净代码。

01 支持的框架

⚛️ React + Tailwind

生成 React 组件，Tailwind CSS 样式，可直接集成到现有项目

💚 Vue + Tailwind

输出 Vue 3 组件，结构清晰，适合 Vue 技术栈团队

🌐 HTML + Tailwind / CSS

纯 HTML 输出，无需框架，最灵活的静态页面方案

📱 Bootstrap / Ionic

移动端优先框架，适合快速原型和响应式页面

02 核心能力
输入类型说明
🖼️ 截图 / 照片任何截图直接上传，生成对应代码
🎨 Figma 设计稿导出 Figma 截图后上传，保留布局细节
🎥 录屏模式网站操作录屏转代码（需 Gemini API）
🔗 URL 直接输入填入 URL，自动抓取页面截图再转换

⚠️ 本地部署门槛
不是零门槛。本地部署需要：
  • 至少一个 API Key（OpenAI / Anthropic / Gemini 任选）
  • 同时运行 React/Vite 前端 + FastAPI 后端
  • 视频模式需要 Gemini API
有 API Key 的开发者，推荐 Docker 一键启动。
