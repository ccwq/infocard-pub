❗ 本项目 ≠ 以下项目（显式区分）
AgentKey ≠ AgentKit
AgentKit 是 Coinbase 推出的"Every AI Agent deserves a wallet"加密钱包工具包，与 AgentKey 完全不同。
AgentKey ≠ Agent-Reach
Agent-Reach 是国内独立开发者 Panniantong 的免费开源本地 CLI工具链项目；AgentKey 是 chainbase-labs 的商业项目（Credits 计费）。
AgentKey ≠ OneKey
OneKey 是硬件钱包品牌；OneKey MCP Router 与 AgentKey 无任何关系。
AgentKey ≠ agentgateway
agentgateway 是 Rust 写的 L7 网络代理（流量层），AgentKey 是 Agent 应用层的数据/工具层。
AgentKey ≠ manuscript-core
manuscript-core（690⭐）是 chainbase-labs 下的区块链数据流框架，与 AgentKey（204⭐）是不同的项目。
AgentKey ≠ Chainbase 代币 CBT
AgentKey 与 Chainbase 主网代币 CBT 无直接关联，README 未提及任何代币或空投。
