项目概述
LobsterAI 是网易有道推出的全场景办公助手 Agent，也是国内大厂首个完全开源的桌面级 AI Agent。基于 OpenClaw 框架构建，通过 Cowork 协作模式连接真实桌面环境：文件系统、终端、浏览器、本地项目均可直接操作，所有敏感操作均需用户审批。内置 30+ Skills，支持 MCP、IM 接入、手机远程控制。
Electron 桌面 OpenClaw 引擎 Cowork 协作模式 MCP 支持 IM 远程控制 定时任务 本地优先 永久记忆
01
核心优势
🔓 完全开源

100% 开源代码，权限、数据、执行流程全透明可审计。MIT 协议，商业可用。

🖥 桌面级 Agent

直连文件、终端、浏览器和本地项目，在真实环境中执行，而非沙盒对话。

🧩 OpenClaw 生态

基于 OpenClaw 框架，持续获取新 Skills、工具、MCP 服务器和模型。

📱 手机远程控制

通过微信、企业微信、钉钉、飞书、QQ、Telegram、Discord 远程驱动桌面 Agent。

🔒 本地数据优先

会话、配置、记忆全部本地存储；每次工具调用均有审批确认。

⚡ Cowork 协作

Cowork 是核心工作模式：AI 自主完成数据分析、文档生成、信息检索等复杂任务。

📅 定时任务

对话创建或 GUI 创建 Cron 定时任务，每日新闻摘要、周期报告自动执行。

🤖 自定义 Agent

创建专属 Agent（股票研究、内容写作、备课助手），各配独立身份、Skills、IM 渠道。

05
快速安装
macOS / Windows 下载
https://github.com/netease-youdao/LobsterAI/releases
源码安装（Node.js >= 24 < 25）
git clone https://github.com/netease-youdao/LobsterAI.git
cd LobsterAI && npm install

# 首次运行需构建 OpenClaw 运行时（约数分钟）
npm run electron:dev:openclaw

# 后续启动（复用已构建的运行时）
npm run electron:dev
macOS Intel + Apple Silicon Windows x64 Linux AppImage + deb Electron 打包 SHA256SUMS 校验
06
典型使用场景
从零构建系统

"我开小店还在用 Excel 记账。帮我建一个库存系统：记录进销存，自动算利润，支持本地打开。"

数据分析与可视化

"用 product-growth.xlsx 的数据，帮我做一个可视化页面。"

每日定时新闻

"每天早上 9 点发昨天 AI 领域重要新闻摘要（OpenAI / Anthropic / Google / 国内大厂）。"

深度研究与 PPT

"调研全球 AI Agent 市场格局，把 traffic-report.pdf 转成汇报 PPT。"

简历筛选

"把文件夹里 50 份简历整理成筛选表，标记缺 JD 硬性要求的，列出 Top 10。"

浏览器自动化

"每天打开我的广告后台，检查 spend / 转化 / CPA 是否有异常，并总结原因。"

永久记忆

"以后给我写的文档都保持清晰、逻辑、简洁。" — 自动保存到长期记忆。

定时周期报告

Cron 表达式驱动（分/时/日/周/月），触发 Cowork 会话，结果推送到手机。
