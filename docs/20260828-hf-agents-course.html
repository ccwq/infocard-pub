FRAMEWORKS · 三大框架

三套框架都带你走一遍

不绑定单一生态，smolagents、LlamaIndex、LangGraph 各有优劣，学会按场景选择。

Hugging Face 原生轻量

smolagents

Hugging Face 官方推出的轻量 Agent 框架，代码简洁，适合快速原型。课程用此框架讲解 Agent 核心概念。

LlamaIndexRAG 优先

LlamaIndex

以知识检索增强为核心，适合构建基于私有数据的 Agent 应用。课程覆盖 Agentic RAG 模式。

LangGraph图结构

LangGraph

LangChain 旗下的图结构 Agent 框架，适合复杂多步推理、循环和分支逻辑的工作流编排。

选框架建议：快速实验用 smolagents；知识库场景用 LlamaIndex；需要复杂流程编排用 LangGraph。课程不偏袒任何一方，教会你按场景判断。
