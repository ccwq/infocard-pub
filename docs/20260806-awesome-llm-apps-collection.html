这是一个面向开发者的开源合集，不是“概念演示”。仓库内收录了 100+ 个能直接运行的 AI Agent / RAG 应用，覆盖从单文件入门到生产级多 Agent 团队，再到记忆、语音、GUI 生成、MCP 集成等实战场景。

一眼能跑的起点

示例启动流程
场景起步方式复杂度价值
单文件 Agentclone 项目后直接 requirements + 运行低最快交付，适合验证思路
RAG 应用选固定模板 + 配置向量库与数据源中可快速验证检索价值
多智能体协作先选 2-3 个 Team 应用，按职责拆分中高业务流程自动化明显收益
Agent Skills一条技能安装命令接入现有助手低减少重复开发和接口重复劳动

仓库 README 官方示例命令：
git clone .../awesome-llm-apps.git && pip install -r requirements.txt && streamlit run ...，以及技能安装命令 npx skills add .../agent_skills/...。

学习者

探索者
