# 这 9 种诡辩最常见：先锁定义，再拆证据，再给第三选项

## 调查简报

**主题**：最常见的诡辩方式、逻辑错误与反驳逻辑速查
**结论**：多数“看起来很有道理”的诡辩，错误都不在情绪强，而在于偷换定义、偷换命题、偷换举证责任、偷换样本边界。

## 核心判断

1. **先看对方有没有换题**：把原命题换成更弱、更极端、或更容易攻击的版本。
2. **再看对方有没有跳步**：从“可能”直接跳到“必然”，从“个案”直接跳到“整体”。
3. **最后看对方有没有转移举证责任**：让你证明“没有”，而不是他证明“有”。

## 常见诡辩类型

- **偷换概念**：同一个词在不同地方用不同意思。
  - 错误：定义漂移。
  - 反驳：先把定义锁死，再比较前后是否还是同一个概念。

- **稻草人**：先把你的观点改弱、改歪、改简单，再攻击这个“假观点”。
  - 错误：攻击对象不是原命题。
  - 反驳：要求对方复述你的原话，再逐句回应。

- **假两难**：只给两个选项，故意抹掉第三、第四种可能。
  - 错误：把连续光谱伪装成非黑即白。
  - 反驳：直接列出第三种方案、条件分支、时间维度或例外情况。

- **人身攻击**：攻击人，不回答论证。
  - 错误：命题真假与说话者身份无关。
  - 反驳：把人和命题拆开，只讨论证据。

- **诉诸权威 / 多数**：因为“专家说了”或“大家都这么想”，所以结论就真。
  - 错误：权威和多数都可能错。
  - 反驳：问证据链、方法、样本和可重复性。

- **以偏概全 / 幸存者偏差**：拿少数样本代表整体，或只看活下来的例子。
  - 错误：样本边界失真。
  - 反驳：问样本量、抽样方式、分布是否代表总体。

- **举证责任转移**：不是证明自己主张成立，而是让对方证明自己无罪。
  - 错误：谁主张谁举证被倒置。
  - 反驳：直接要求提出证据，不接受“你先证明没有”。

- **循环论证**：结论偷偷当了前提。
  - 错误：论证没有新增信息。
  - 反驳：把结论遮住，再看前提是否还能独立成立。

- **滑坡谬误**：把一个小动作一路推到最坏结局，中间链条却没证据。
  - 错误：连续环节缺失，只剩恐吓。
  - 反驳：逐段问“中间一步怎么发生？”“概率有多大？”“有没有替代路径？”

## 通用反驳模板

### 四句够用
1. **先定义**：你这里的词是什么意思？
2. **再还原**：你现在回应的是我的原命题，还是你改写后的版本？
3. **要证据**：你的结论中间链条是什么？
4. **给第三项**：除了你说的两个选项，还有没有第三种解释？

### 最稳的发问顺序
- 这是不是换了概念？
- 这是不是偷换了命题？
- 这是不是把个案当总体？
- 这一步的证据在哪里？
- 还有没有第三种可能？

## 使用边界

- 这张卡不是教你“赢辩论”，而是教你**识别错误推理**。
- 真正有效的反驳不是抬杠，而是把命题、证据和结论重新对齐。
- 遇到高情绪争论，先拆结构，再回到事实。

## 结论

大多数诡辩都有同一个毛病：**把看起来像逻辑的东西，伪装成已经成立的逻辑。**
真正的反驳，不是更响，而是更准：锁定义、拆命题、查证据、补第三项。
