⚠ 关键坑点
1
白底残留：背景移除模型常误删元素内部的白色内容
→ 需要后处理蒙版修正，半透明区域建议用 RGBA 原生工具
2
半透明边缘：rembg 类工具只做二值蒙版，玻璃/烟雾/头发边缘质量差
→ 用 OmniPSD RGBA-VAE 或 Qwen-Image-Layered 原生支持
3
图层顺序漂移：GPT Image 2 Prompt 方法层级容易错位
→ 加自检句："请检查最终 PSD 预览是否避免图层偏移、顺序错误"
4
VAE 压缩失真：传统 VAE 处理半透明区域时丢失边缘细节
→ OmniPSD 用 RGBA-VAE 重训练解决，Qwen-Image-Layered 原生 RGBA
5
显存门槛：Qwen-Image-Layered 推荐 RTX 4090（24GB），OmniPSD 需要 Flux 生态 GPU
→ Web 路线（Lovart / Canva）零门槛绕过
