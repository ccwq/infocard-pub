核心要点

  • 时间锚：模型卡预计训练于今天（2026-10-28）北京时间 15:30 结束；FP16、数据集与评测报告仍在待发布清单。这是作者计划，不是完成通知。
  • 能与不能：输入文字，输出自包含 HTML / JavaScript，由浏览器渲染 Three.js 场景；不直接交付 CAD / Blender 可编辑模型文件。

如果目标是把文字想法变成可在浏览器打开的场景，可以从 GGUF 小样本试起；如果需要可编辑建模文件，或要凭公开评测做选型，当前材料还不能支撑决策。今天的预计结束时间只决定何时回看发布页，不保证届时材料齐备。

02 / 输出与使用机制

代码交给浏览器执行

模型基于 Qwen/Qwen3.5-4B，由 CCORE 独立微调。模型卡将其定位为小模型兼做通用代码与 3D 场景生成的可行性实验。

“生成 3D”的具体链路是：文字描述 → HTML / JS 场景代码 → 浏览器渲染。单个自包含 HTML 是示例要求的交付形态，不等于已经生成可编辑的 CAD / Blender 文件。

模型卡示例涵盖大象栖息地、运河船闸、塔台雷达，也列有建筑、花园、体素、家具与机械场景；这些是示例范围，不是成功率证明。

03 / 本地试跑条件

先关 MTP，再调采样

下载 Q4_K_M 或 Q8_0 GGUF 并在 LM Studio 加载。模型标称 4B，元数据为 4.2B，架构为 qwen35。

模型卡明确要求关闭 multi-token prediction（MTP）。LM Studio 默认开启此项；按模型卡说明，开着时模型不能正常工作。

GGUF 提供本地试跑入口，但材料未给出硬件门槛或运行速度；不能把“4B”直接换算成任意设备都能流畅运行。

模型卡建议采样参数

参数建议值使用提醒
Temperature0.6–0.8在建议范围内试跑
Top P0.90–0.95记录实际使用值，便于复现
Repeat penalty1.0不要凭重复声明错误直接调大此值
Top K20–40与其余参数一并记录

数值来自模型卡；记录配置与保留样本是本卡建议，不是作者公布的测试结论。

系统提示词：保留三个硬约束

  1. 仅使用 cdnjs 的 three.js 0.160.0 core ES module。
  2. 禁止 addons，也不使用 legacy examples/js。
  3. 相机控制直接在 HTML 内实现。

以上是模型卡系统提示词要点，非逐字全文。建议从仓库复制完整原文，不自行补写模块路径。自包含 HTML 在这里仍使用指定 CDN 模块，不应理解为保证断网可运行。

示例 prompt 形态（依据模型卡题材改写，非原文）：

请用单个自包含 HTML 文件生成一个大象栖息地 3D 场景，

边界与行动：给预览版 20 分钟

下面是建议验证任务，不是本卡已完成的实测。目标只验证一条本地生成链路，不测排名，也不代表完整能力评估。下载耗时受网络影响；可在 GGUF 就绪后开始计时。

1加载权重Q4_K_M / Q8_0 在 LM Studio 打开
2关闭 MTP模型卡要求；LM Studio 默认开启
3生成单页按 system prompt 输出自包含 HTML
4浏览器检查渲染、交互、报错分开记录
  1. 0–5 分钟：在 LM Studio 加载 Q4_K_M，确认 MTP 已关闭，填入上表建议范围内的采样值。
  2. 5–10 分钟：从模型卡复制完整 system prompt，输入上面的大象栖息地示例请求；保存实际配置与输出。
  3. 10–15 分钟：把生成代码保存为 scene.html 并用浏览器打开。观察场景是否渲染、相机控制是否响应，并检查浏览器控制台。
  4. 15–20 分钟：记录控制台是否出现重复声明报错。失败时首查 MTP；确认关闭后，再检查是否使用重传前权重、是否违背模块约束，以及代码中是否重复声明变量。

判断标准是把“能打开、能交互、报什么错”分开记录；单个样例成功只证明这次链路走通。用于项目选型前，仍需核对许可证，并等待或自行补充符合自己任务的评测。
