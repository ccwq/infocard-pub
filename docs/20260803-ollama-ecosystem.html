01

一句话定位

Ollama 是目前最简的开源大模型本地部署工具：一行命令拉起模型，REST API 即开即用，数据完全留在本地。

v0.32.5 (2026-07-27)

最新版本支持 macOS ARM64 GPU 加速、Linux AMD/NVIDIA ROCm、Windows WSL2，原生支持 llama.cpp 后端，内存管理优化。

03

API：OpenAI 兼容 + 原生

OpenAI 兼容端点（推荐）

# 基础对话 curl http://localhost:11434/v1/chat/completions \ -H "Content-Type: application/json" \ -d '{"model":"llama3.1","messages":[{"role":"user","content":"解释 Ollama 是什么"}],"stream":false}' # Python SDK from openai import OpenAI client = OpenAI(base_url="http://localhost:11434/v1", api_key="ollama") resp = client.chat.completions.create(model="llama3.1", messages=[{"role":"user","content":"Hi"}])

原生 API

curl http://localhost:11434/api/generate -d '{"model":"llama3.1","prompt":"Why is sky blue?","stream":false}' curl http://localhost:11434/api/chat -d '{"model":"llama3.1","messages":[{"role":"user","content":"Hi"}]}' curl http://localhost:11434/api/tags # 查看已下载模型

Modelfile 与横向对比

Modelfile 自定义

# Modelfile 示例：中文助手 FROM llama3.1 SYSTEM """你是一个专业的中文助手。回答简洁有条理。""" PARAMETER temperature 0.7 PARAMETER num_ctx 8192 # ollama create my-chinese -f Modelfile # ollama run my-chinese

选型结论

快速上手 / 有 API 需求 → Ollama。
非技术用户 / 可视化探索 → LM Studio。
需要深度定制 → llama.cpp。

⚠️ 注意事项
⚡ 性能上限
本地推理速度取决于硬件，7B 模型在 Mac M3 上约 30-50 tok/s，405B 模型需要专业工作站。
🔒 隐私边界
Ollama 默认仅本地运行，但 OLLAMA_HOST=0.0.0.0 会暴露到网络，需配合防火墙。
