WHAT IT IS

Independent CarPlay Receiver — Installed on Car, Not iPhone

Core Function

Replaces proprietary projection systems with open CarPlay on BYD Android head units running DiLink. Package: com.shihab.diplay (release) / com.shihab.diplay.hudtest (test).

Supported Connections

  • Wired USB: Android 9+, data-capable cable + USB port
  • Wireless Wi-Fi Direct: Android 10+, no router needed
  • Car Hotspot: Android 10+, phone joins car's Wi-Fi automatically
  • No jailbreak, dongle, Mac, or authentication server
Core CarPlay Requires Zero ADB

Basic wired/wireless CarPlay works without ADB. Optional dashboard, battery gauge, wheel-speed display, and parked-video features require authorized network ADB on supported firmware.

03
CONNECTION MODES

USB / Wi-Fi Direct / Car Hotspot — Three Paths to CarPlay

USB Wired

  • Android 9+ required
  • Local VPN carries USB network link (not internet VPN)
  • Approve USB, Trust/CarPlay + local VPN prompts
  • Charge-only ports/cables cannot work

Wi-Fi Direct

  • Android 10+ required
  • No external router needed
  • v0.2.11: preferred channel save (2.4/5 GHz)
  • Stutter not confirmed fixed by channel choice

Car Hotspot

  • Android 10+, car hotspot 5 GHz preferred
  • Phone auto-joins after Bluetooth handshake
  • No manual Wi-Fi joining or ADB needed
  • Optional auto-start car hotspot (off by default)

EXPERIMENTAL IDENTITY

Non-Apple-Certified MFi Accessory — Bundled Identity Is Extractable

PRO

Works without Apple MFi certification process; no provisioning server needed; public preview invites community testing.

CON

APK bundles experimental accessory identity from Carlinkit firmware; bundled private key is extractable; future iOS updates may break acceptance; not an Apple-certified product.

⚠ Not Apple-Certified — Identity Risks

The APK bundles an experimental accessory identity recovered from public Carlinkit firmware, not a newly provisioned MFi identity for DiPlay. The bundled private key is extractable by recipients. Acceptability after future iOS updates is unresolved. This release invites community testing, not a guarantee of universal compatibility.

⚠ Signing Key Warning

Different signing keys cannot update an existing project-signed installation. Do not uninstall until you have saved any diagnostic reports you need. Never commit keystore credentials or the keystore itself.

08
PRIVACY

Local-Only Diagnostics · No Auto-Upload · User-Initiated Export Only

What DiPlay Does NOT Do

  • No account, no remote auth server
  • No automatic diagnostic upload
  • No protocol payload recording
  • No audio/video/packet payload in reports
  • No tracking or analytics on static website

What Diagnostic Reports Include

  • App/device versions, display settings, negotiation
  • Connection transitions, Wi-Fi band/channel, state
  • Decoder recovery events
  • Protocol payloads + credentials auto-filtered
  • Review before posting publicly

Diagnostic Export Paths

PlatformPrimary PathFallback
Android 10+Downloads/DiPlay/Android/data/com.shihab.diplay/files/diagnostic-reports/
Android 9Document picker → user selects locationSame app-private fallback
No Auto-Upload

Diagnostic export is always user-initiated. Sharing grants read access to the selected report only. Uninstalling removes app-private data; exported reports in Downloads remain until manually deleted.
