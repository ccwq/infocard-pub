01
核心功能

独立 CarPlay 接收器 — 安装在车上，而非 iPhone

核心功能

用开源 CarPlay 替代比亚迪 DiLink 车机的专有投影系统。包名：com.shihab.diplay（正式版）/ com.shihab.diplay.hudtest（测试版）。

支持的连接方式

  • 有线 USB：Android 9+，需数据线 + USB 接口
  • 无线 Wi-Fi Direct：Android 10+，无需路由器
  • 车载热点：Android 10+，手机自动连接车载 Wi-Fi
  • 无需越狱、外接转接器、Mac 或认证服务器
核心 CarPlay 功能完全无需 ADB

基础有线/无线 CarPlay 无需 ADB。选配仪表盘、电量显示、轮速显示和驻车视频功能需要在支持的固件上授权网络 ADB。

03
连接方式

USB / Wi-Fi Direct / 车载热点 — 三种 CarPlay 连接路径

USB 有线

  • 需要 Android 9+
  • 本地 VPN 传输 USB 网络连接（非互联网 VPN）
  • 批准 USB、信任/CarPlay 及本地 VPN 提示
  • 充电线/充电口无法使用

Wi-Fi Direct 直连

  • 需要 Android 10+
  • 无需外部路由器
  • v0.2.11：新增首选信道保存（2.4/5 GHz）
  • 信道选择未确认能修复卡顿

车载热点

  • Android 10+，车载热点 5 GHz 优先
  • 蓝牙握手后手机自动连接
  • 无需手动连接 Wi-Fi 或使用 ADB
  • 可选自动启动车载热点（默认关闭）

v0.2.11 新增：Wi-Fi 首选信道

设置行为
自动（默认）自动选择信道，跨重连保持有效
手动 2.4/5 GHz保存支持的信道；遭拒绝或不匹配的信道会报错
活动会话持续到手动重连；切换信道不触发重连
卡顿修复信道选择未确认能解决卡顿——需要硬件证据

05
功能地图

核心 CarPlay / HUD 导航 / 车辆数据 / 诊断 — 四层功能体系

功能层级要求功能说明
第一层：核心 CarPlay无需 ADB有线/无线 CarPlay，本地认证，无服务器
第二层：HUD 导航已验证的比亚迪固件DiLink 5.1 仪表盘显示箭头 + 距离 + 路名
第三层：车辆数据网络 ADB + 支持的读取项电量百分比、轮速、驻车视频、仪表盘卡片
第四层：诊断用户手动导出有界诊断报告：版本、设置、连接事件，不含载荷

可选功能逐项分解

比亚迪 HUD / 仪表盘导航

  • DiLink 5.1 上显示箭头、距离、路名
  • 需要文档中的地图元数据要求
  • DiLink 5.0：有限支持；其他固件未验证
  • 无需运行时 ADB 启动器

车辆数据（DiLink 5.0 默认）

  • 默认 DiLink 5.0 模式——兼容性最佳
  • 传统模式需主动启用：有界只读检测
  • 仅接受运行时确认的字段
  • 不写入车辆设置，也不承诺支持所有车机
06
实验性身份

非苹果认证的 MFi 配件 — 捆绑身份可被提取

优势

无需苹果 MFi 认证流程；无需配置服务器；公开预览版邀请社区测试。

劣势

APK 捆绑了来自 Carlinkit 固件的实验性配件身份；捆绑的私钥可被提取；未来 iOS 更新可能破坏兼容性；不是苹果认证的产品。

⚠ 非苹果认证 — 身份风险

APK 捆绑了从公开 Carlinkit 固件恢复的实验性配件身份，而非为 DiPlay 新配置 MFi 身份。捆绑的私钥可被接收者提取。未来 iOS 更新后的兼容性尚未确定。此版本邀请社区测试，不保证普遍兼容性。

各构建类型的身份处理

构建类型是否含身份？如何添加
源码 / CI 构建否——不含身份默认输出，安全用于 Git/CI
本地正式构建是——若设置了 DIPLAY_AUTH_ASSETS_DIR提供 offline-mfi/identity.pk8 + certificate.p7b
独立车测 APK是——强制要求必须设置 DIPLAY_AUTH_ASSETS_DIR，缺失则拒绝构建
合成测试身份运行时生成无测试私钥文件纳入 Git 版本控制

⚠ 签名密钥警告

不同的签名密钥无法更新已签名的现有安装。在卸载前务必保存所需的诊断报告。切勿将密钥凭据或密钥库本身提交到 Git。

08
隐私

本地诊断 · 无自动上传 · 仅用户手动导出

DiPlay 不做的事

  • 无需账号，无远程认证服务器
  • 无自动诊断上传
  • 无协议负载记录
  • 报告中无音视频/数据包负载
  • 静态网站无追踪或分析

诊断报告包含的内容

  • App/设备版本、显示设置、协商过程
  • 连接切换、Wi-Fi 频段/信道、状态
  • 解码器恢复事件
  • 协议负载 + 凭据自动过滤
  • 发布前请审查内容

诊断导出路径

平台主要路径备用路径
Android 10+Downloads/DiPlay/Android/data/com.shihab.diplay/files/diagnostic-reports/
Android 9文档选择器 → 用户选择位置相同的应用私有备用路径
无自动上传

诊断导出始终由用户手动触发。分享仅授予对所选报告的读取权限。卸载移除应用私有数据；Downloads 中的导出报告需手动删除。
