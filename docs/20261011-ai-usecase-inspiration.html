CASE STRUCTURE · 用例结构

每条用例三要素：用途 + 效果 + 可复制 Prompt

标准化结构让每条用例都能快速上手。

要素一

具体用途

这个用例解决什么问题？描述要具体到可操作的程度（如"给产品描述加上 SEO 优化提示词"）。

要素二

最终效果

执行后达到什么效果？帮助判断这个用例是否值得参考（如"生成的文章点击率提升 30%"）。

要素三

可复制 Prompt

完整的、可直接粘贴到 AI 工具里使用的 prompt。博主评价："直接复制就行"。

博主补充（推文视频画面）：想玩视频生成的可以看他的提示词写法。上传自己照片直接生成配音视频效果（有截图）。Grok Bot 后端换成 Opus 5.5（博主实测）。

CAUTIONS · 注意事项

涉钱 / 账号权限用例建议人工复核

使用时的风险边界与核实建议。

⚠

涉钱用例需复核

涉及付费、订阅、API 费用的用例，案例中的效果描述未必适用于你的场景和用量。

⚠

账号权限用例需复核

涉及第三方账号登录、数据授权、API Key 的用例，自动整理的数据可能过时或有安全风险。

⚠

自动整理需核实

数据来源为"扫描全网自动整理"，非人工审核。来源可靠性、时效性须自行判断。

博主原话：「建议把它当灵感库，别直接当成操作手册。涉及钱/账号权限的一定人工复核。」

GLOSSARY · 术语表

关键词速查

本文涉及的核心术语解释。

AI 用例灵感库

Use Case Library

收录真实 AI 应用案例的参考库，展示 AI 在各种场景下的具体用法，供用户参考和模仿。

Agent 分类

Agent Taxonomy

按 AI Agent 类型（如写作 Agent、代码 Agent、客服 Agent 等）对用例进行分类的组织方式。

可复制 Prompt

Copyable Prompt

可直接粘贴到 AI 工具中使用的完整提示词，含任务描述、约束条件和输出格式。

灵感库 vs 操作手册

Inspiration vs SOP

灵感库提供参考思路，不保证直接可用；操作手册是可直接执行的标准化流程。

扫描全网自动整理

Web Scraping + Curation

通过自动化工具扫描互联网收集 AI 用例，再经过分类整理的数据采集方式。

人工复核

Human Verification

对自动整理的数据进行人工检查，确认涉钱/账号权限等敏感用例的准确性和安全性。

Agent

AI Agent

能自主执行任务的 AI 系统，可调用工具、规划步骤、记忆上下文（如 Grok Bot、Muse、Hark）。

用例结构三件套

Case = Use + Effect + Prompt

每条用例包含：具体用途（做什么）、最终效果（达到什么）、可复制 prompt（怎么做）。
