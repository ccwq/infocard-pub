技术手册 · MapLibre / HyperFrames

china-antique-maplibre：把中国历史地图做成可录制的古卷场景

一个面向 MapLibre GL JS 的 agent skill：在线调参、导出 JSON，再把相机、地形、图层与古卷 CSS 迁移到 HyperFrames 或自己的生产宿主。

MIT code/docsMapLibre GL JSTerrarium DEMHyperFrames-ready
核心路径：调参器只是设计台，最终帧必须在生产宿主渲染

打开在线 Demo → 调整卫星、山影、水系、CSS 和城池 → 复制/下载 JSON → 在 HyperFrames MapLibre 场景中应用 → 用 jumpTo 设置镜头并等待 idle。

no file://encoding: terrariumjumpTo + idle
一句话结论：它不是一套打包好的地图瓦片，而是一份可调、可迁移、强调数据边界的古卷地图生产 Skill。
仓库将 MapLibre GL JS、EOX Sentinel-2 cloudless 默认底图、AWS Terrarium DEM、古卷 CSS 调色、可选水系接口和 HanCity3D 城池分级组合成工作流。卫星与 DEM 均运行时请求；水系不随仓库分发，需自行准备并确认许可。
01
INSTALL · START

安装：克隆仓库，复制 Skill，或直接打开 Demo

公网调参无需安装；要本地运行则必须通过 HTTP 服务提供 tuner。

最快

在线 Demo

打开 在线调参器 ↗，无需安装；EOX 与 Terrarium 需要联网。

  • 调参后复制或下载 JSON
  • 适合先确认画面方向
Unix

克隆 + 安装 Skill

git clone https://github.com/hopechen067/china-antique-maplibre.git，再将 china-antique-maplibre/ 复制到宿主 skills 目录并重载。

  • 不要提交 API key
  • 更新用 git pull
本机调参

HTTP 才是正确入口

进入 china-antique-maplibre/tuner，运行 python -m http.server 8765，打开 http://127.0.0.1:8765/。

  • 可选：node verify.mjs
  • 不要用 file://
安装边界：MapLibre / Three.js 的许可证、瓦片供应商条款和展示媒体权利都要分别遵守；仓库的 MIT 不等于授予底图或商业地图权利。
02
TUNER · PARAMS

调参器：先理解五个面板，再锁定预设

默认预设是 antique v2；启动时优先读取 localStorage，其次读取默认 JSON，最后才用内置默认值。

01 / SATELLITE

栅格底图

调 opacity、saturation、contrast、brightness、hue。

默认 EOX Sentinel-2 cloudless；个人端点写入 gitignored 的 map-tiles.config.local.js。

02 / HILLSHADE

地形与山影

exaggeration、光照方向、shadow / highlight / accent。

Terrarium DEM 必须正确解码，否则高程和山影都会错。

03 / WATER

水系颜料

湖泊 + river level 3 → 2 → 1 + highlightRiver。

只有在本地水包存在且 enabled 时才有数据层。

04 / CSS + UI

古卷包装

sepia、暖调、暗角、brightness，以及 showWater / showCities。

CSS 作用在 canvas wrapper 外层，不混入 MapLibre paint。

03
EXPORT · JSON

导出：五个根节点就是迁移合同

点击“复制 JSON”或“下载 JSON”，检查导出对象是否保留 camera、maplibre、css、ui、cities。

cameraproduction

镜头与录制确定性

默认中国概览中心点约为 [104.0,35.5]、zoom 4.2、pitch 28。生产路径用 map.jumpTo(...)，不要用 easeTo / flyTo。

maplibrepaint

地图颜料与地形

迁移 backgroundColor、terrainExaggeration、satellite、hillshade、water；地形源设置 encoding:'terrarium'，并通过 map.setTerrain 应用 exaggeration。

csswrapper

古卷外层

把 sepia、saturate、contrast、brightness、hueRotate、warmTint 和 vignette 作为 canvas 外部 DOM filter / overlay。

ui / citiesoptional

显示开关与城池

showWater、showHighlight、showCities 控制可见性；cities.dataFile 指向站点 JSON，HanCity3D 按 capital / large / medium / small / pass / station / ordos 分级。

04
MIGRATE · MAPLIBRE

迁移到 HyperFrames：按层、按时序、按边界落地

导出的 JSON 是设计结果，不是直接可播放的视频；生产宿主仍需负责资源、镜头和等待条件。

A

创建场景

在 HyperFrames 或自己的 MapLibre 宿主建立 scene；应用导出的 paint、terrain exaggeration、layer visibility 和 CSS 外层。

B

设置镜头

用 jumpTo 或初始 center / zoom / pitch / bearing；可在跳转后预热视口和瓦片。

C

等待 idle

等待 MapLibre idle，必要时结合 sourcedata / 自定义 tile wait，再捕获帧，避免机器间动画时序差异。

推荐伪代码：
map.jumpTo({center,zoom,pitch,bearing});
map.once('idle',()=>captureFrame());
05
LAYER ORDER · TERRARIUM

图层顺序：底色在下，城池与叙事高光在上

顺序决定古卷画面是否清楚，也决定水系是否会被底图和城市挤掉。

01 → 03

地基与地形

background → hillshade（启用 terrain 时）→ optional satellite raster。

Terrarium raster-dem source 必须带 encoding:'terrarium'。

04 → 06

水系与高光

lakes fill → lake outline → river level 3 → 2 → 1 → highlight rivers。

高光受 ui.showHighlight 控制，推荐 highlightRiver / highlightWidth。

07

城池与标签

city fill-extrusion / custom 3D + HTML labels 位于最上层；CSS antique filter、warm tint、vignette 在 canvas wrapper 外。

06
WATER · COPYRIGHT

水系与版权边界：能加载，不代表仓库替你授权

水系是可选接口，不是随仓库交付的数据资产；默认 enabled=false，避免 Demo 请求缺失的大包。

Bring your own

本地水包结构

创建 gitignored 的 tuner/assets/water-data.js，写入 window.CHINA_WATER_DATA；包含 riverLevel1/2/3、chinaLakes，可选 highlightWaterSystems。再将 water-pack.json 的 enabled 设为 true。

Compliance

三条不可混淆的授权线

EOX 公共演示 WMTS、AWS Terrarium / CDN、自备水系和展示图片各自遵守条款。MIT code/docs 不等于商业图商权利，也不覆盖保留权利的展示媒体。

07
SHOWCASE · HEXI

示例：河西走廊 · 河西四郡

仓库用真实地图叙事片展示结果：武威绿洲 / 石羊河、酒泉地形与水系、走廊镜头和城站近景。

镜头

从全国到走廊

先用中国概览确认整体色调，再切到河西区域，结合 hillshade、河流高光与城池分级做叙事镜头。

实片

在线 Demo 视频

播放河西四郡低清片段 ↗；仓库还提供约 36 秒 map clip 与静帧。

验证

把“好看”变成可重放

导出预设，迁移 camera 与 paint，固定 layer order，jumpTo 后等 idle，再在 HyperFrames 产出确定性帧。
