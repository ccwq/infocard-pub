AI Agent · Knowledge Platform

开箱即用的 AI Agent 构建平台

FastGPT 是基于大语言模型的知识问答构建平台，提供开箱即用的数据处理、RAG 检索与可视化工作流编排能力，无需复杂配置，即可快速上线生产级 AI 应用。

RAG 检索引擎 可视化编排 多模型支持 OpenAPI 私有化部署 MCP 双向
GitHub 28.5K Stars · Labring 组织核心项目
技术栈 TS TypeScript + Next.js + RAG + MCP
模型 MCP OpenAI / Claude / DeepSeek / Qwen / 硅基流动
部署 3 种 云服务 / Docker / Sealos 一键
FastGPT 的核心价值：把 AI 应用从"写 Prompt 调 API"的原始阶段，推进到可视化编排 + 知识库 + OpenAPI的全套工程化能力——一条命令完成私有化部署。

六大核心能力：从数据到生产级应用

Core Capabilities
01 应用编排

可视化 Flow 引擎

规划 Agent 模式 · 对话工作流 · 插件工作流 · RPA 节点 · 双向 MCP 集成。

  • 规划 Agent 模式
  • 插件工作流（含 RPA 节点）
  • 双向 MCP 支持
02 知识库

RAG 检索与向量化

多库复用 · chunk 精确管理 · 混合检索 & 重排 · 支持 10+ 文件格式 · URL 读取 · CSV 批量。

  • 手动/自动分段 + QA 拆分
  • 混合检索 + 重排（ReRank）
  • txt, md, html, pdf, docx, csv, xlsx
03 应用调试

完整链路调试工具

知识库单点搜索测试 · 对话引用反馈 · 完整调用链路日志 · 应用评测。

  • 引用来源可修改与删除
  • 完整调用链路日志
  • 应用评测体系
04 OpenAPI

GPT 接口级兼容

completions 接口对齐 GPT · 知识库 CRUD · 对话 CRUD · 自动化 OpenAPI 接口。

  • Chat 模式完全对齐 GPT
  • 知识库 / 对话 CRUD
  • 无登录分享窗口
05 运营能力

企业级运营支持

免登录分享窗口 · Iframe 一键嵌入 · 统一对话记录 · 数据标注 · 应用运营日志。

  • 免登录外部访问
  • Iframe 嵌入任何系统
  • 对话记录标注
06 AI Plus

语音与智能提示

可视化模型配置 · 语音输入/输出 · 模糊输入提示 · 模板市场。

  • 可视化模型配置面板
  • 语音输入 + 语音回答
  • 模板市场快速上手
OpenAPI 说明：FastGPT 的 completions 接口与 GPT 接口完全对齐，可直接替换 OpenAI 的 API 调用地址，实现零代码迁移现有应用。

# Docker 一键部署（推荐）
bash <(curl -fsSL https://doc.fastgpt.cn/deploy/install.sh)
docker compose up -d

# 启动后访问 http://localhost:3000
# 默认账号：root  密码：1234

# API 调用示例（OpenAI 兼容）
POST https://your-fastgpt.com/api/chat/completions
Headers: { "Authorization": "Bearer your-api-key" }
Body: 与 OpenAI completions 接口完全兼容
