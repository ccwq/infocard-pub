快速判断

先看任务，再看数字

处理长PDF或很多文件
看上下文窗口、检索和文件工具。

容量决定能否放下，工具决定能否有效找到相关内容。

分析复杂问题
看模型档位和推理强度。

窗口大只代表能读很多，不代表一定更聪明。

生成长报告或代码
看最大输出，并给推理留预算。

推理和可见答案会共同消耗生成额度。

查询最新信息
看搜索工具，不只看知识截止。

价格、法律、新闻等信息应联网核验。

接入业务系统办事
看函数调用和结构化输出。

它们让模型可靠地填单并交给程序执行。

大批量低成本处理
看Luna、缓存、TPM/RPM和价格。

规则明确的任务未必需要最强模型。

05
AI员工工作台

Token、上下文与输出，共用一张桌子

Token
像材料计量单位。 它不是固定的字数。中英文、代码、标点、图片和工具返回内容都会换算成Token。
上下文窗口
像桌面总面积。 系统指令、历史对话、问题、文件、图片、工具结果、推理与答案都可能占用1.05M空间。
最大输出
像一次交稿额度。 128K是生成上限，不是承诺长度；API还可以设置更小的本次预算。
放上工作台指令、对话、PDF、图片和工具结果
→
内部打草稿分析、规划和核验使用推理Token
→
交付答案最终看见的文字、代码或数据
输入 Token + 推理 Token + 可见输出 Token ≤ 1,050,000
实际生成上限 = min( max_output_tokens, 模型上限 128,000, 上下文剩余空间 )
06
AI员工大脑

读得多、想得深、知道得新，是三件事

读得多

由上下文窗口决定。它描述容量，不直接代表聪明程度。

想得深

由模型能力和推理强度影响，通常会增加延迟和消耗。

知道得新

由知识截止和联网工具共同决定，最新事实应搜索核验。

none改写、分类、抽取
low低延迟明确任务
medium默认；质量速度平衡
high复杂编码与方案
xhigh疑难问题与核验
max最难任务质量优先
推理Token
像交稿前的草稿纸。 若生成预算20K，推理使用15K，可能只剩约5K可见答案。预算耗尽时，响应可能不完整。
知识截止
像培训资料日期。 GPT‑5.6官方截止为2026-02-16；这不代表之前全部知道，也不代表之后无法通过搜索获得。
07
AI员工感官和工具

会思考，不等于拥有执行工具

输入输出模态

可接收文本和图片，基础模型输出文本。能看图不等于直接生成图片。

搜索与文件

搜索补充新信息，文件搜索定位相关段落；工具结果同样占上下文。

电脑与代码

支持环境可调用代码、Shell或Computer Use；产品权限仍决定能否执行。

Function Calling

模型按接口规则填写“任务单”，再由程序调用订单、库存或CRM系统。

Structured Outputs

按指定结构交付严格JSON，便于自动抽取和连接后续流程。

产品层限制

API支持不代表ChatGPT、Codex或第三方平台一定开放同一项能力。

08
AI员工成本和产能

能完成，还要看是否划算、是否跑得动

输入 / 输出价
像阅读材料费和撰写报告费。 两者分开计价，输出通常更贵，高推理任务还可能产生更多计费Token。
缓存输入
像熟悉的固定手册。 重复长前缀可降低后续费用，但缓存不扩大1.05M工作台。
TPM / RPM
像每分钟材料吞吐量和接单次数。 Context限制单次容量；TPM限制每分钟Token；RPM限制每分钟请求数。
长上下文价格
像超大型项目加价。 输入超过272K后整次请求进入更高费率，因此技术上放得下不代表经济上应全部塞入。

10
常见误区

看到大数字，先排除这些误解

105万上下文＝能输出105万错误。上下文是总空间；最大生成128K，推理也占生成预算。
上下文越大，模型越聪明错误。容量、推理能力和知识新旧是不同维度。
最大输出128K就会写满错误。它只是上限，模型可自然结束或被更小预算限制。
知识截止后什么都不知道不准确。可借助搜索获取新信息，但仍要核验来源。
支持图片就能生成图片错误。图片输入和图片生成是两种能力。
缓存扩大模型记忆错误。缓存优化费用和处理，不改变上下文上限。
11
边界与行动

实际选型，只做四步

1. 描述任务

材料多少？答案多长？是否要最新信息？是否调用外部系统？

2. 选择模型

质量优先选Sol；多数任务从Terra开始；规则明确的批量任务评估Luna。

3. 设置预算

设置输出和推理强度，观察输入、缓存、推理与可见输出Token。

4. 真实验证

比较正确率、延迟和成本，不因单个大数字直接下结论。

最终记忆

上下文是工作台，最大输出是交稿上限，推理是草稿预算，知识截止是培训日期，工具是办公设备，TPM/RPM是每分钟产能。先问任务需要什么，再看哪项参数真正决定结果。
