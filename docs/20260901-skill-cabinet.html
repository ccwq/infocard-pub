Skill Cabinet
一命令管理本机所有 AI Skills

Ralph-TUI 作者 Ben 的新开源工具。运行 npx skill-cabinet 即可启动本地网页，一站式浏览、搜索、查看和删除本机所有 AI 编程工具的 Skills——Claude Code、Codex、Cursor 等，统一管理，无须逐个翻目录。

快速启动

# 推荐方式
npx skill-cabinet
# 指定端口
PORT=4000 npx skill-cabinet
# 不自动打开浏览器
SKILL_CABINET_NO_OPEN=1 npx skill-cabinet
# 从 GitHub 直接运行
npx github:subsy/skill-cabinet

启动后访问 http://127.0.0.1:3781（仅绑定本地地址）。需要 Node 20+。

扫描目录（Drawer）

Claude Code~/.claude
Codex~/.codex
Agents~/.agents
Cursor~/.cursor
其他 Skills 目录~/.*/skills

按抽屉（Drawer）筛选，或用 / 搜索名称、描述、路径和 frontmatter 内容。

功能一览

功能说明
浏览 / 阅读查看每个 Skill 的完整正文（渲染版或源码）和 YAML frontmatter
搜索过滤按 Drawer 分类 + 搜索名称 / 描述 / 路径 / frontmatter
删除技能单删或批量删除，直接从磁盘移除，无撤销（Builtin Cursor 技能可能恢复）
换肤Theme 菜单切换界面主题（Carbon 为默认主题）
键盘导航j/k 移动，/ 搜索，x 标记，d 删除

与同类工具对比

工具定位界面同步分发
Skill Cabinet本地 Skills 目录浏览与清理本地 Web—
Skill Vault多设备同步 + 统一分发本地 AppGit 同步
Skills Manager跨 15+ 工具统一管理桌面 AppGit 备份
Skill Stationagentskills.io → 各客户端分发本地 Web推送分发
Skill SyncCodex Skills Git 同步本地 WebGit 同步

Skill Cabinet 的核心价值在于轻量——不追求跨设备同步，只做本地 Skills 目录的一站式可视化。适合 Skills 堆积后想清理盘点的用户。

适合谁用

Claude Code / Codex / Cursor 等工具的重度用户，Skills 目录已积累数十个以上的技能；想快速浏览每个 Skill 的内容、按工具分类、或批量清理过时技能。轻量无需安装任何服务端，直接 npx 运行，零配置。

不适合需要跨机器同步 Skills、或在团队间分发 Skills 的场景（请用 Skill Vault / Skills Manager）。
