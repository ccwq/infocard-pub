GCT 架构：三个核心模块

ANCHOR CONTEXT · 锚点坐标
坐标锚定模块

建立帧间统一的 3D 坐标系，为每帧提供空间基准锚点，确保多视角几何一致性。

POSE-REFERENCE WINDOW · 姿态窗口
姿态参考窗口

动态维护相邻帧的姿态约束窗口，结合历史参考帧估计当前相机位姿，抑制快速运动下的位姿跳变。

TRAJECTORY MEMORY · 轨迹记忆
轨迹记忆模块

长期维护全局轨迹上下文，在回环（loop closure）时自动纠正累积漂移，确保长距离路径精度不衰减。

快速上手：4 步跑通实时 3D 重建

①

创建 conda 环境

conda create -n lingbot-map python=3.10 && conda activate lingbot-map

②

安装 PyTorch 2.8 + FlashInfer

pip install torch==2.8.0 torchvision==0.23.0 cu128 && pip install flashinfer-python

③

安装并下载模型权重

pip install -e . && 从 HuggingFace / ModelScope 下载 .pt 权重文件

④

运行 Demo 开始建图

python demo.py --model_path /path/to/model.pt --image_folder /your/video/ --mask_sky

QUICK START · 交互式 Demo 一行命令
# 基本用法：交互式 3D 可视化
$ python demo.py \
    --model_path /path/to/lingbot-map-long.pt \
    --image_folder example/courthouse \
    --mask_sky

# 启动后浏览器访问 http://localhost:8080 查看实时 3D 重建

# 长视频模式（>3000 帧）：使用窗口推理
$ python demo.py \
    --model_path /path/to/lingbot-map-long.pt \
    --image_folder /your/long/video/ \
    --keyframe_interval 32 \
    --backend flashinfer

# 编译加速（首次 JIT 编译后有效）
$ python demo.py --compile --backend flashinfer --dtype bf16

# 离线批量渲染（长视频，25K+ 帧）
$ python demo_render/batch_demo.py --model_path lingbot-map-long.pt --input_dir /data/

FAQ

常见问题

Q: LingBot-Map 和传统 SLAM 方法有什么区别？
传统 SLAM 需要迭代优化（Bundle Adjustment 等），计算量随轨迹长度增加而累积。LingBot-Map 是纯前馈架构，固定计算量每帧，~20 FPS 实时推理，无迭代开销，且通过轨迹记忆模块实现长期精度。
Q: 需要什么硬件配置才能运行？
推荐 NVIDIA GPU（CUDA 12.x）。FlashInfer 后端支持 paged KV Cache，显著降低长序列显存占用。CPU 模式下可使用 SDPA 后端（PyTorch 原生），精度一致但速度较慢。
Q: 三个模型版本怎么选？
长序列（10K+ 帧）选 lingbot-map-long，户外大场景推荐；一般视频选 lingbot-map（均衡性能）；研究用途需要双向推理才选 stage1。long 版本对长距离漂移抑制效果最好。
Q: 视频分辨率有限制吗？模型输入是 518×378？
518×378 是官方评测分辨率（速度和精度平衡）。代码支持任意分辨率自动 resize 到该尺寸处理，输出结果按原分辨率插值。不需要深度相机，RGB 视频即可。
Q: 可以商用吗？Apache-2.0 许可证有什么限制？
Apache-2.0 是非常宽松的开源许可证，允许商业使用，只需保留版权声明和许可证文本。不要求开源衍生代码，但建议注明基于 LingBot-Map。
Q: 25,000 帧超长视频能跑吗？速度如何？
可以。官方已发布 13 分钟室内行走视频（约 25K 帧）的评测示例。使用 lingbot-map-long + FlashInfer 后端 + --compile，~20 FPS 实时推理，长序列无性能衰减。
