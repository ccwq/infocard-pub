Rare UI：让 AI 参考具体动效，而不是猜抽象描述

Rare UI 是 rareui.com 提供的免费开源 React 动效组件集合，按真实交互场景提供可参考的过渡原型，并通过 shadcn registry 单文件接入。

官方入口：https://www.rareui.com/components

01 / 先看定位与边界

01

定位

不是常规通用组件库，而是面向文件夹、导航、数字、二次操作和通知等场景的动画参考原型。

02

目录

官方当前可见分类包括 New releases、Display、AI kit、Navigation、Inputs、Feedback。

03

代表组件

Folder、Code Block、Gravity Letters、Fluid Orb、Grid Reveal、Proximity Sidebar、Scroll Progress、OTP Input、Emoji reaction 等。

04

安装入口

官方示例：npx shadcn@latest add swamimalode07/rare-ui/fluid-orb；具体依赖以对应组件页和 registry 为准。

05

AI 工作流

先找一个相似交互原型，再让 AI 读取结构、触发条件和视觉反馈，最后按产品语义改写。

06

边界

不要把同名 rareui.in / Codewithswappy/RareUI 混入；每个组件的性能、可访问性和降级策略仍需项目自行验收。

02 / 最短上手路径

01按交互场景找原型
02查看组件页与 registry
03复制并改写到项目
04检查性能、可访问性与降级
