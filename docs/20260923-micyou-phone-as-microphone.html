Field Notes · 文章没讲的坑

三条实测补充：开箱不会"直接响"

文章说"电脑端启动后系统里就会出现一个新的麦克风设备"——实际上三大平台都要先装第三方虚拟声卡驱动，这是 README 和 FAQ 里写得最详细、也最容易劝退新手的一步：

01

Windows：需装 VB-Audio Virtual Cable，且确认 CABLE Input（输出设备）和 CABLE Output（输入设备）都处于"已启用"状态，缺一个就没声音。

02

Wi-Fi 连不上：大概率是防火墙——官方 FAQ 给了 PowerShell 命令放行 TCP 6000（控制）+ UDP 6001（音频）；路由器开了 AP 隔离也会失败。

03

macOS：BlackHole 装完要重启；首跑 Gatekeeper 拦截需 sudo xattr -r -d com.apple.quarantine /Applications/MicYou.app；未装 switchaudio-osx 时异常退出后输入设备不会自动还原。

USB 模式需开 USB 调试并装 ADB（winget install -e --id Google.PlatformTools），多设备时用 adb -s <序列号> reverse tcp:6000 tcp:6000 指定转发。

License 划重点

不是随便的 MIT——GPLv3 + MicYou Plugin Exception 1.0：本体传染 GPL，但插件开发豁免。二次分发注意合规。

性能提示（issue #262 实测）

Windows 端串流主进程约 15-17% CPU（i7-9700，ONNX 降噪开），Android 端约 14-18%——老机器长时间挂机要留意。RTT 1-2ms、丢包 0% 说明链路本身很稳。

Technical Stack

Android：Kotlin + Jetpack Compose + Material 3。
桌面：Tauri 2 + Rust + Vue 3。传输/DSP/虚拟设备为 Rust 共享 crates。
