03广告不会告诉你的三个机制

A计费已从"每 2 小时 N 条"改为"每周共享池"——2026-06 起，付费档的全部用量（Chat、Imagine、Voice、Build）从同一个周池扣。Heavy 生成视频和你问"今天天气"花的是同一笔额度：一个下午烧完 Imagine，晚上连普通对话都要充值。社区报告 Heavy 日视频配额从约 100 条降到约 30 条，价格未变。
B订阅与 API 是两个完全独立的钱包——$300 的 Heavy 不送一分 API credit，API 消耗也不占订阅池。要脚本调用就是第二张账单。官方 API 定价（docs.x.ai 实测）：grok-4.6 输入 $2.00/1M、缓存输入 $0.50、输出 $6.00；prompt 超 200K 后整个请求翻倍（$4/$1/$12，不是超额部分累进）；fast 变体双倍价；RPS 150、TPM 50M；reasoning 档位 low→xhigh 默认 high；Batch API 不支持。
C"升级"的实质是用量池与 agent 数，不是新模型——$30/$100/$300 三档跑的都是 Grok 4.6 系；$30→$100 买到的是 Grok Bot 与更大池，$100→$300 买到的是 16-agent 多智能体模式与最宽池。grok.com 的 Heavy 订阅墙文案"SuperGrok Heavy subscription required"也证实 multi-agent 模式不单独售卖。

04怎么选（按真实场景）

  1. 轻度试用：Free 每周池够用；要 Imagine 就别留恋免费档（已被移除）。
  2. 日常主力：SuperGrok $30——旗舰模型+Build CLI+DeepSearch 全都有；$300/年约合 $25/月。
  3. 重度 X 用户：X Premium+ $40 才有意义（要的是 X 权益，不是更强的 Grok）。
  4. $30 不够用：先看 Plus $100（Grok Bot+1080p+峰值优先），别直接跳 Heavy；若本来就想买 Cursor Ultra $200（同样授予 Grok Bot），Heavy 的边际成本只有约 $100。
  5. 写代码走 API：订阅帮不到你——grok-4.6 $2/$6，200K 以上翻倍条款先算清楚；缓存命中率高的负载才划算。
核查方法说明：API 侧全部一手实测（docs.x.ai / x.ai/news 可访问）；订阅价目因 x.ai/pricing 与 grok.com/pricing 均拦截自动访问（Cloudflare），$10/$30/$100/$300 为 5+ 独立来源交叉一致的报告值，付款前请在结账页确认。xAI 全年多次调档（Lite 3 月、Plus 8 月、4.6 上位），这页数字有保质期。

05判断

四个折扣点：① "5× longer" 无基线不可验证，真差异在周池；② Heavy 的"near-unlimited"承诺已从价目页消失，配额却在社区报告里缩水（视频 100→30）；③ 计费模式一年内两改（2 小时→周池、免费档砍生成），付年费锁价不锁体验；④ 最贵档的 Grok Bot 限额数字从未公开——你买到的是"比 $100 多"，但没人知道多多少。

一句话：这条广告推文的每一句话都"不算假"，但真正的信息都在它没说的地方——$30 是价值档、$100 是 agent 门槛、$300 买的是多智能体深度而非聊天体验、以及订阅与 API 永远是两本账。把它当"升级理由"看会失望，当"价目表索引"看才值回这张卡。
