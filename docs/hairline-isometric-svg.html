CORE MECHANISM

工作原理

Hairline 不是 GIF，也不是 Canvas 动画——是纯 SVG + Pointer Events，每个图示在 DOM 元素内自包含渲染。

指针事件驱动

每个图示绑定 pointermove，读取指针坐标，通过数学变换（等距投影）计算出线条位移。无需 Canvas 或 WebGL。

SVG pointer events isometric math

共享 RAF 循环

页面上所有图示共享一个 requestAnimationFrame 循环，off-screen 或静止时循环暂停，不浪费渲染资源。

one RAF off-screen idle zero waste

SSR 安全

SSR 时组件渲染为空盒（固定 5:4 宽高比），hydration 后才启动动画。Server Component 可直接渲染，无需 "use client"。

SSR safe 5:4 aspect no "use client"

Shadow DOM 兼容

图示可挂载在 Web Component 的 Shadow Root 内，自包含样式，不污染主文档 CSS，也不被主文档样式干扰。

Shadow DOM scoped styles

统一选项 API

intensity

0 ~ 1

交互强度，默认 0.5，范围外自动 clamp

theme

"auto" | "light" | "dark"

跟随页面或手动指定，auto 读取祖先 .dark

label

string

无障碍标签，React 版渲染为 aria-label

onRead

fn(text)

图示状态变化时回调，如显示 "gap 28.0"

CORE FIGURES

六大核心图示

首发即完整的六种交互模式：升起、展开、跟随、减速、旋转、悬停。每一类对应不同的数据类型可视化场景。

riffle — 卡片翻查

一叠八张卡，指针悬停时卡牌站立，方向键在卡片间切换。适合时间线、多选项对比、目录浏览。

"The card under the pointer stands up"

terrain — 地形隆起

8×8 = 64 根柱子从基座升起，围着指针形成山峰。适合数据密度、频率分布、地图热点的可视化。

"Eighty-one pillars rise around the pointer"

exploded — 分层展开

一个窗口四层结构，左右移动展开层间隙，上下移动切换聚焦层。适合系统架构、文档折叠、功能模块。

"Moving across opens the gap"

phosphor — 磷光轨迹

点阵循环播放，指针经过留下磷光余晖并渐渐消退。适合路径追踪、访问历史、动画时间轴。

"Fades like phosphor where the pointer paints"

slow — 传送带减速

箱子沿传送带走，悬停时光阴变慢但不停。适合实时数据流、速率控制、暂停/恢复交互。

"Hovering slows the clock without stopping it"

turntable — 转盘定位

方块在转盘上，鼠标滑动旋转，释放后停在最近的四分位。适合状态切换、档位选择、角度校准。

"A flick spins it; it settles on nearest quarter turn"

THEME TOKENS

5 行 CSS 定制主题

图示通过 CSS 自定义属性读取颜色，页面只需在祖先元素设置变量，无需重写 SVG。

主题变量

.figures {
  --hairline-plate: #101014; /* 底板填充色 */
  --hairline-hi: #fafafa; /* 高亮线条 */
  --hairline-edge: #a1a1aa; /* 轮廓线 */
  --hairline-mid: #52525b; /* 中间层线条 */
  --hairline-lo: #27272a; /* 远景线条 */
  --hairline-stroke: 0.9; /* 线宽（CSS px） */
}

Accessibility

图示是带描述的图像，Riffle 例外（支持焦点导航、方向键浏览、实时 ARIA 播报）。prefers-reduced-motion 下磷光轨迹保持静止，但指针响应不变。

性能基准

所有图示共享一个 RAF 循环，静止时自动停止，off-screen 不渲染。Shadow DOM 隔离，无样式泄漏，无 specificity 冲突。
