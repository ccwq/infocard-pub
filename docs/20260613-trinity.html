为什么 Trinity
problem → solution
问题：Saas 会把数据带出安全边界；自研要 6–12 个月；普通 framework 又缺少治理与审计。
答案：Trinity 是部署在你自己基础设施上的 agent orchestration runtime，默认支持 observability、cron 调度、delegation、tamper-evident audit trail 与 cost tracking。
Fleet management Audit trail Cost tracking Self-host
