"Local-first AI Image Workbench"

「解压即用，像 ComfyUI 一样简单。」— GPT-image-2 的专属工作台，Codex + API 双模式，内置图库与并发队列。
官方 API 方式

每次生成都要写 prompt → 调 API → 存结果，缺少预览、参考图管理和批量任务能力。历史记录靠手动。

iLab GPT Conjure

WebUI 一站式：参考图库、Chip 快捷引用、提示词模板、多图并发、本地 SQLite 历史库，打包成解压即用。

核心功能
features
  • 文生图 + 图像编辑 — 面向 GPT-image-2 的完整工作流
  • 双 API 模式 — Codex Responses / OpenAI 兼容 API
  • 多任务并发 — 本地队列、分页历史、缩略图归档
  • Chip 快捷引用 — 公用图库、颜色、提示词片段
  • 提示词模板 — 预置模板 + 自定义保存
  • 多语言 WebUI — 中文 / English 一键切换
安装方式
install
免安装一键包

下载对应平台 zip → 解压 → 双击启动脚本 → 浏览器打开 http://127.0.0.1:8787/

源码安装

git clone → python3 -m venv → pip install -r requirements-webui.txt → uvicorn 启动

# 源码安装 git clone https://github.com/kadevin/ilab-gpt-conjure.git cd ilab-gpt-conjure python3 -m venv .venv && .venv/bin/pip install -r requirements-webui.txt .venv/bin/python -m uvicorn codex_image.webui.app:app --host 127.0.0.1 --port 8787

稳定集成、团队共享、公开服务推荐此模式。配置 Base URL + API Key 即可。

⚠️ Codex OAuth

高级本机模式，复用本地 OAuth 登录态。只面向个人本机，不适合生产。

不要提交：OAuth 文件、API Key、输入图、生成结果、SQLite 数据库或调试日志。
