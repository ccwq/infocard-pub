01
问题场景

让 AI 整理笔记，为什么越整越乱？

AI 不懂 Obsidian 的原生语法，写出来的只是普通 Markdown——链接、属性、callout、Canvas 全部出错。

✗ 不用 Skill 的 AI

  • 链接断了一一 AI 写普通链接，不写 wikilinks
  • 属性乱了一一 frontmatter 格式不正确
  • callout 写错了一一 用 > 代替 callout 语法
  • Canvas 不能打开一一 JSON 格式不合规
  • 知识库越来越脏

✓ 用了 Skill 的 AI

  • 正确的 wikilinks 和 embeds
  • 规范的 frontmatter properties
  • 原生 callout 语法
  • 可打开的 .canvas 文件
  • 知识库保持干净、可链接、可查询
02
核心能力

5 个 Skill 详解

每个 Skill 覆盖 Obsidian 的一个开放格式或操作场景，组合起来覆盖完整的知识管理流程。

① obsidian-markdown

教 AI 写 Obsidian 风格 Markdown。包括 wikilinks、embeds、callouts、properties 和其他 Obsidian 专有语法。

适合：整理读书笔记、项目笔记、日记、知识卡片

.md wikilinks callouts properties

② obsidian-bases

教 AI 创建 .base 文件，把笔记变成类似数据库的视图。支持 table、cards、list、map 四种视图，以及 filters、formulas、summaries。

适合：任务列表、读书清单、项目状态表、内容选题库、资料索引

.base table cards map filters formulas

③ json-canvas

教 AI 创建 Obsidian Canvas（.canvas 文件）。处理节点、连线、分组和布局，输出的是标准 JSON Canvas 格式。

适合：读书脑图、产品结构图、项目路线图、文章框架、研究关系图

.canvas nodes edges groups

④ obsidian-cli

教 AI 通过命令行操作 Obsidian vault。可以读笔记、创建笔记、搜索内容、追加 daily note、设置 properties、查 tags 和 backlinks。

关键场景：把 Codex / Claude Code 接进自己的 Obsidian 工作区

CLI read write search tags backlinks

⑤ defuddle

把网页抽成干净 Markdown。去掉导航、广告和页面噪声，减少上下文浪费。适合把文章、文档、博客保存进 Obsidian。

来源：基于 kepano 自己的 defuddle 项目，专门做网页正文提取。

web → md 去广告 去导航 token 友好
03
.base 深度

把笔记变数据库：.base 能力矩阵

obsidian-bases 是 5 个 Skill 中信息密度最高的一个。它让 AI 能把散落的笔记变成结构化、可筛选、可计算的数据库视图。

视图用途AI 能做什么
table表格视图把笔记按属性列展开，类似 Notion 数据库
cards卡片视图生成可浏览的卡片网格，适合读书清单
list列表视图简洁列表，适合任务和索引
map地图视图按地理位置展示带坐标的笔记

Filters

按 tag、属性、路径筛选笔记。AI 能根据需求自动生成筛选条件。

Formulas

在视图中做计算。求和、计数、平均值——让笔记库变成可分析的数据源。

Summaries

分组汇总。按状态、日期、分类等维度自动聚合，一眼看到全局。
