一句话定位：FastClaw 是一个 Agent 工厂——它创建、管理并运行 AI Agent，每个 Agent 有自己的灵魂（SOUL.md）、记忆、Skills 和工具。

支持 OpenAI / Anthropic / Ollama / OpenRouter / Groq / DeepSeek / Mistral 等任意 LLM，提供 Web 管理界面 + CLI，支持 Telegram / Discord / Slack 渠道接入。

Showcase · 管理界面
Platform Admin / 平台管理
Dashboard · 管理员
Agents、Models、Skills、Users、API Keys 统一管理；运行时配置（沙箱、存储）；多租户权限体系。
Per-Agent Management / 单 Agent 管理
Dashboard · Agent Owner
每个 Agent 的独立面板：Chat 对话、SOUL.md 编辑、Skills 配置、Model 覆盖、渠道接入（IM 机器人）、Cron 调度、Session 历史。
02
Architecture · 架构
  • ~/.fastclaw/数据根目录（含 SQLite 数据库 + skills/ + agents/）
  • fastclaw.dbSQLite 默认存储 — 用户、Agent、Session、API Key、配置、agent_files 全部在此
  • skills/共享 Skills（内置 + 后续安装）；ClawHub 或 GitHub 安装源
  • agents/<id>/agent/skills/Agent 私有 Skills（文件系统隔离）
  • StorageSQLite 默认；`FASTCLAW_STORAGE_DSN` 切换 PostgreSQL，支持多 Pod 部署
  • 无 fastclaw.json引导配置全通过 `FASTCLAW_*` 环境变量；用户级配置存 DB，通过 UI/CLI 管理
# 安装到 ~/.local/bin 并写入 PATH
$ curl -fsSL https://raw.githubusercontent.com/fastclaw-ai/fastclaw/main/install.sh | bash
03
Features · 核心能力
LLM Providers / 多模型支持
🔌 LLM

OpenAI · Anthropic · Ollama · OpenRouter · Groq · DeepSeek · Mistral 及任意 OpenAI 兼容 API；Per-agent 模型覆盖。

Channels / 渠道集成
📱 IM Bot

每个 Agent 可绑定 Telegram / Discord / Slack 机器人；会话按 channel + chatID 隔离；Token 保存前验证。

Sandbox / 沙箱隔离
🔒 安全

E2B Cloud Sandbox 或 Docker Sandbox；自动 Skill + Workspace hydrate；文件每次工具调用后同步回持久存储；MCP Server + Plugin 系统。

Skills / 技能生态
🛠️ 扩展

内置 Skills：code-runner / image-gen / data-analysis / translation / web-search / skill-creator；从 ClawHub 或 skills.sh 安装；Agent 私有或全局共享。

Memory / 记忆系统
🧠 上下文

MEMORY.md 长期事实（心跳自动更新）；Session 上下文完整保留；Thinking / reasoning 内容保留用于记忆提取。

API / OpenAI 兼容
🌐 接口

OpenAI 兼容 `/v1/chat/completions`（流式）；Web 聊天 `/api/chat/stream`（SSE）；Live Push `/api/chat/subscribe`；全 RESTful API。

05
CLI Quick Start · CLI 快速上手
$ fastclaw # 启动安装向导 → 配置 LLM → 创建默认 Agent
$ fastclaw agents init alpha --provider openai --model openai/gpt-4o-mini --api-key-env OPENAI_API_KEY
$ fastclaw agents config alpha set temperature 0.7
$ fastclaw agents config alpha set sandbox.enabled true
$ fastclaw agents files put alpha SOUL.md ./SOUL.md
$ fastclaw agents ls
$ fastclaw daemon start # 后台运行

⚠️ CLI 写入直接操作 SQLite（不依赖 Gateway）；热更新通过 SIGHUP 生效。
