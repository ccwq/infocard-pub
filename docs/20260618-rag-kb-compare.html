知识库怎么搭？GitHub 上有一批开源 RAG / 知识库工具，分工已经挺清楚了：
FastGPT（28k+ stars）：基于 LLM 的知识库平台，工作流、问答、数据集管理比较完整，适合想快速搭企业知识库的人。
LLM Wiki（11k+ stars）：桌面端把文档整理成可互联的知识库，适合个人笔记、资料归档、本地查阅。
llm-wiki-agent（2.9k+ stars）：丢资料进去，让 Claude / Codex / Gemini 自动读、整理、维护个人知识库，更像会自己更新的 wiki。
OpenKB（2k+ stars）：开源 LLM 知识库项目，偏轻量搭建，适合先跑一个最小可用版本。

选型决策路径：从需求到工具

Decision Path
Step 1 · 评估你的需求
1 规模：企业/团队（FastGPT） 还是 个人（LLM Wiki / llm-wiki-agent / OpenKB）
2 自动化：想自己维护（FastGPT / LLM Wiki / OpenKB）还是让 Agent 自动更新（llm-wiki-agent）
3 界面：需要可视化工作流（FastGPT）还是图形化知识网络（LLM Wiki + Obsidian）
4 API：需要对外提供 API（FastGPT 唯一选择）还是内部使用（四者皆可）
Step 2 · 按阶段选型
① 快速验证 RAG 概念 → OpenKB（最小可用，Python 安装即跑）
② 搭建生产级知识库平台 → FastGPT（Docker 一键，生产功能完整）
③ 个人知识本地管理 + Obsidian → LLM Wiki（wikilink 交叉引用，Obsidian 直接打开）
④ 不想手动整理，想 AI 自动维护 → llm-wiki-agent（Claude / Codex / Gemini 自动读资料整理）
演进路径：OpenKB（轻量验证）→ FastGPT（生产平台）或 LLM Wiki（个人管理）→ llm-wiki-agent（自动化升级）。工具之间不是互斥的，可以根据不同场景组合使用。
