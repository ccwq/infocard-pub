01
CHAPTER · 安装

pip / uv / npm 三种入口

Python CLI（pip/uv）、TypeScript SDK（npm），按需选择。

pip install
# Python 包 + CLI（推荐） pip install "headroom-ai[all]" # 粒度可选 pip install "headroom-ai[proxy]" # 代理模式 pip install "headroom-ai[mcp]" # MCP server pip install "headroom-ai[code]" # 代码压缩 pip install "headroom-ai[memory]" # 跨 Agent 记忆
uv / npm
# uv 全局工具（隔离环境） uv tool install --python 3.13 \ "headroom-ai[all]" # npm TypeScript SDK（仅库，无 CLI） npm install headroom-ai # import { compress } from 'headroom-ai'
02
CHAPTER · 四种部署模式

Library · Proxy · Agent Wrap · MCP

按场景选择入口，无需全量安装。

Library

Python / TypeScript

from headroom import compress(messages)，内联到任何应用。

Proxy

零代码改动

headroom proxy --port 8787，透明拦截所有 LLM 请求。

Agent Wrap

一键封装

headroom wrap claude，自动配置 Serena + Proxy。

MCP Server

通用 MCP 工具

headroom_compress / headroom_retrieve / headroom_stats。

Cross-agent Memory

跨 Agent 共享记忆

Claude、Codex、Gemini、Grok 之间共享上下文，自动去重。

Output Shaper

输出 token 优化

HEADROOM_OUTPUT_SHAPER=1 减少模型的冗余输出（5× 成本优势）。

08
CHAPTER · 注意事项

关键约束

避免把官方 benchmark 覆盖范围扩展到所有场景。

⚠ Benchmark 覆盖范围

15–20% ≠ 全部场景

Coding agents 节省 15–20% 是官方 benchmark 结论。

JSON 数据 60–95% 是另一独立 benchmark。

真实工作负载实测最高 92%，最低 47%，不可外推。

⚠ Serena 默认安装

wrap 时自动安装 Serena

headroom wrap claude 会安装 Serena 到 ~/.claude.json（user scope）。

--code-memory none 可跳过。

⚠ Python 版本

需要 Python 3.10+

pip install 和 uv tool install 均要求 Python 3.10 及以上。

⚠ npm 无 CLI

npm 包是 SDK，非 CLI

npm install headroom-ai 只能 import compress()，不提供 headroom 命令行。

CLI 功能需 pip install 或 uv tool install。
