GitHub Action 每日自动更新
# .github/workflows/openwiki-update.yml
name: OpenWiki Update
on:
  schedule: cron: "0 8 * * *"  # UTC 8:00
jobs:
  update:
    steps:
      - name: Install OpenWiki
        run: npm install --global openwiki
      - name: Run OpenWiki
        run: openwiki --update --print
        env:
          OPENROUTER_API_KEY: ${{ secrets.OPENROUTER_API_KEY }}
          OPENWIKI_MODEL_ID: z-ai/glm-5.2
      - name: Create PR
        uses: peter-evans/create-pull-request@v7

每天自动检查代码库变更，开 PR 更新 openwiki/ 文档。配置 secrets.OPENROUTER_API_KEY 即可。

关键设计
1Agent 专用
不是给人写的 wiki，是给 coding agent 读的文档系统。文档格式和组织方式以 agent 检索为第一优先。
2自动追加提示
首次运行后自动在 AGENTS.md / CLAUDE.md 末尾追加提示，让 Claude Code / Codex 等知道去读 openwiki/。
3增量更新
openwiki/ 目录存在时做增量刷新，不存在则从头创建。不覆盖已有内容，只追加变更。
4LangSmith 追踪
可选配置 LangSmith API key，追踪 OpenWiki 运行过程，方便调试 prompt 效果。
