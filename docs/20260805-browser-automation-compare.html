🎯 Playwright 适用场景

跨浏览器兼容性测试（需 Firefox/WebKit）

CI/CD 流水线自动化（多语言 SDK）

截图 / PDF 生成 / 性能监控

移动端设备模拟（iOS / Android）

🎯 Puppeteer 适用场景

Node.js 项目内部浏览器自动化

Chrome 特定操作（PDF 渲染、DevTools）

轻量爬虫（无反爬目标）

快速原型验证

🎯 Camoufox 适用场景

需要绕过反爬 / UA 检测的爬虫

登录态页面抓取（电商/社交/金融）

社交媒体数据采集

任何 Playwright/Puppeteer 被拦截的场景

🔀 快速选型决策树

Q1
需要多浏览器支持（Firefox/WebKit）？
→ Playwright
Q2
仅需 Chrome + Node.js 生态？
→ Puppeteer
Q3
需要强反检测能力（爬虫/登录态）？
→ Camoufox

⚠️ 注意事项

Stars 数据：GitHub API 2026-08-05 读取。Camoufox Stars 较低但增长快。

Puppeteer 官方仅支持 JS/TS，社区有 Python 封装。Camoufox 是 Python-first。

反检测能力基于各工具 README 声明；实际效果因网站防御策略而异。

✓ Hermes Agent agent-browser 属于独立工具链，不在本卡对比范围内

选型原则：需求多样性选 Playwright · Node 生态选 Puppeteer · 反检测选 Camoufox
