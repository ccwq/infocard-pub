KEY CAPABILITIES · 核心能力

五大核心能力，覆盖研究到执行全流程

上下文引用 · Agent 模式 · 妙招 · 标签管理 · 隐私保护

上下文引用 @

全能输入框输入 @，即可引用当前标签页、标签组、网页截图、收藏夹甚至本地文件，告别反复复制粘贴。

@标签组 · 引用所有打开的标签页内容
@截图 · 截取当前屏幕区域注入对话
@文件 · 引用本地 PDF/文档结合分析

妙招（Miaozhao）

把常用提示词存为快捷指令，或用一句话生成脚本：净化页面、批量提取资源、改造网页风格，随叫随到。

跨境电商用户写了8个妙招覆盖整条经营链路——数据抓取、比价分析、经营看板解读全部自动化。

Agent 自主执行

用自然语言下达复杂指令，Tabbit 自主阅读页面、提取信息、填写表单、跨平台操作，在独立标签组中交付结果。
