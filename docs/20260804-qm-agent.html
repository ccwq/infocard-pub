YC 开源

qm: 团队 AI Agent 平台

多用户隔离工作空间 · Slack + Web 双端 · 权限审批 · 安全沙箱 · 完整操作审计

YC 开源 MIT 9.4K ★ TypeScript
v0.1.4 Slack 原生集成 多 Harness 支持
一句话：为创业公司设计的团队 Agent OS。每个员工拥有独立隔离工作空间，可协作共享，支持权限审批、安全沙箱与完整操作审计。已支持 Pi Agent、OpenCode、Codex、Claude Code 四大主流 Agent 引擎。
01
CORE FEATURES

核心功能

每个人和每个房间都有独立的：记忆、文件、KeyChain、权限、Crons、Web Apps 和持久化沙箱。

作用域记忆

🧠 独立记忆系统

每个人和每个房间拥有独立记忆，Agent 理解上下文而不泄露其他用户数据

权限审批

🔐 企业级权限

管理员设置组织级安全策略，命令限制与操作审计，所有敏感行为可追溯

安全沙箱

🏖️ 持久化沙箱

每个作用域拥有独立沙箱，文件、工具和已登录服务持久化，不干扰他人

Slack + Web

💬 双端协作

同一身份和配置在 Slack 和 Web App 间无缝切换，协作体验一致

共享 Skills

⚙️ 技能共享

Skills 归作用域所有，支持按权限授予；管理员可将技能推广至全组织，支持 git 导入

后台任务

⏰ 后台自动化

Crons 和 Watches 在无人值守时持续运行：定时摘要、邮件分类、CI 监控

02
ARCHITECTURE

架构

每次对话经过中央核心，核心可使用不同模型和 Harness 生成响应。

# qm 核心架构
┌─────────────────────────────────────────┐
│  DB (Postgres)                         │
│  sessions · memory · queue              │
└───────────┬─────────────────────────────┘
            │
  ┌─────────┴─────────┐
  │  Headless Core    │
  │  API · Identity   │◄──── Pi / OpenCode
  │  Policy · Sched  │◄──── Codex / Claude Code
  └─────────┬─────────┘
            │
  ┌─────────┴─────────┐
  │  Per-Scope        │
  │  Sandbox          │
  │  files · tools ·  │
  │  logged-in services│
  └───────────────────┘
            │
  可选插件: Web UI / Admin Panel / Slack
Postgres 持久层保存用户数据、会话历史和其他持久状态。Agent 拥有固定的小型工具集，其中 execute 工具在作用域的隔离沙箱中运行命令。Web UI、管理面板和公开门户是基于核心 HTTP API 的可选插件；Slack 是可选的进程内集成。

04
QUICK START

快速部署

# 安装 qm CLI
npm install -g @yc/qm
# 或
brew install yc-software/tap/qm
# 初始化项目
qm init
# 选择 Harness
# (Pi / OpenCode / Codex / Claude Code)
# 配置模型 API Key
# 启动服务
qm start
# 默认 http://localhost:3000
# Slack Bot 需要 SLACK_BOT_TOKEN
邀请成员

邀请团队成员

通过 Web UI 或 qm invite 添加成员，设置角色和权限。Slack Bot 需要 workspace admin 权限。

06
NOTES

注意事项

1

数据安全

企业部署需配置 Postgres TLS 连接和 VPC 网络隔离，默认配置适合内部网络而非公网暴露

2

早期版本

v0.1.4 仍为早期版本，API 和配置格式可能在后续版本中变更，生产环境使用前请评估

3

Slack 权限

Slack Bot 需要 workspace admin 权限才能创建 channel 并配置事件订阅
