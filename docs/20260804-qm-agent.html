一句话结论

为创业公司设计的团队 Agent OS。 每个员工拥有独立隔离的工作空间，可协作共享，支持权限审批、安全沙箱与完整操作审计。已支持 Pi Agent、OpenCode、Codex、Claude Code 四大主流 Agent 引擎。

核心理念

大多数 Agent 被设计为个人助手，让整个公司共用一个会迅速变得混乱。qm 从零设计为多用户协作：员工各自拥有隔离的工作空间，独立工作互不干扰，同时可以在频道、项目中与 Agent 协作。

每个人和每个房间都有独立的：记忆、文件、KeyChain、权限、Crons、Web Apps 和持久化沙箱。

核心功能

🧠 作用域记忆
每个人和每个房间拥有独立记忆，Agent 理解上下文而不泄露其他用户数据
🔐 权限审批
管理员设置组织级安全策略，命令限制与操作审计，所有敏感行为可追溯
🏖️ 持久化沙箱
每个作用域拥有独立沙箱，文件、工具和已登录服务持久化，不干扰他人
💬 Slack + Web 双端
同一身份和配置在 Slack 和 Web App 间无缝切换，协作体验一致
⚙️ 共享 Skills
Skills 归作用域所有，支持按权限授予；管理员可将技能推广至全组织，支持 git 导入
⏰ 后台任务
Crons 和 Watches 在无人值守时持续运行：定时摘要、邮件分类、CI 监控

架构

DB[(Postgres
sessions · memory · queue)]

subgraph CORE[Headless Core]
  API[API · identity · policy · scheduler]
  LOOP[Agent Loop
(Pi · OpenCode · Codex · Claude Code)]
  API <--> LOOP
end

SBX[Per-scope Sandbox
files · tools · logged-in services]

DB <--> API
LOOP <--> SBX

每次对话经过中央核心，核心可使用不同模型和 Harness 生成响应。Postgres 持久层保存用户数据、会话历史和其他持久状态。Agent 拥有固定的小型工具集，其中 execute 工具在作用域的隔离沙箱中运行命令。

Web UI、管理面板和公开门户是基于核心 HTTP API 的可选插件；Slack 是可选的进程内集成。

支持的 Agent 引擎

Pi Agent
官方推荐引擎，YC 系嫡系
OpenCode
OpenClaw 开源版，浏览器/终端自动化
Codex
OpenAI Codex CLI，与 OpenAI API 集成
Claude Code
Anthropic Claude Code CLI，代码能力突出
引擎无关：同一核心可切换不同 Harness 和模型，部署不绑定单一供应商。

典型使用场景

  • 搜索内部笔记、邮件、文档、数据库和网络，一站式检索公司知识库
  • 构建内部 Web Apps，发布给指定人员，实时更新数据
  • 学习过往写作风格，定时分类邮件、生成回复草稿
  • 在已有代码仓库中运行测试、打开 PR、监控 CI、检查系统日志
  • 在共享频道跟踪项目进度，自动推送更新和跟进通知

快速部署

1
安装 qm CLI
npm install -g @yc/qm
# 或
brew install yc-software/tap/qm
2
初始化项目
qm init
# 选择 Harness（Pi / OpenCode / Codex / Claude Code）
# 配置模型 API Key
3
启动服务
qm start
# 默认 http://localhost:3000
# Slack Bot 接入需配置 SLACK_BOT_TOKEN
4
邀请团队成员
通过 Web UI 或 qm invite 添加成员，设置角色和权限

注意事项

⚠️ 数据安全 企业部署需配置 Postgres TLS 连接和 VPC 网络隔离，默认配置适合内部网络而非公网暴露
ℹ️ 早期版本 v0.1.4 仍为早期版本，API 和配置格式可能在后续版本中变更，生产环境使用前请评估
ℹ️ Slack 权限 Slack Bot 需要 workspace admin 权限才能创建 channel 并配置事件订阅
