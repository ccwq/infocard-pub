Structured SVG Validator — 4 项结构性检查
✓
XML 解析完整性 — 检查 SVG 根元素存在、命名空间正确、语法树可解析，渲染器不崩溃
validate_svg.py 第 1 阶段：xml.etree.ElementTree.parse() 全文件解析
✓
marker-start / marker-mid / marker-end 引用完整性 — 所有箭头端点引用的 marker ID 必须在 中有定义，缺则箭头无端
扫描所有使用 marker 属性的 path/line/polyline 元素，交叉验证 defs 中对应 id
✓
Path 碰撞检测（M/L/H/V/Q/C/S/T） — 路径段之间的包围盒若有重叠，箭头线会穿入节点框
提取所有 M 起点坐标，计算每段路径的 bounding box，交叉检测碰撞区域
✓
Transform 链叠加检测 — 嵌套 transform (translate/scale/rotate/matrix) 累积后可能导致节点被推离视图外
解析 transform 属性，展开矩阵链，计算综合偏移量是否超出 viewBox
ℹ
虚线节点冲突（Dashed Nodes） — 虚线边框节点（如短期记忆）若与实线节点重叠，在视觉上无法区分层级
辅助检测：扫描 stroke-dasharray 节点之间的间距，警告间距 < 4px 的密集虚线区域
4
Visual Review Gate — PNG 回读感知验证
ℹ
PNG 回读（Pixel Readback） — 导出 1920px PNG 后重新读取像素数据，检查图像是否非全黑/全白，渲染器是否正常工作
脚本：generate-diagram.sh → cairosvg png_export → PIL/Pillow pixel sampling
✓
穿框检测（Arrow-Card Penetration） — 检测箭头路径是否穿过节点卡片区域（通过像素差分或 bounding box 交叉测试）
视觉检查：箭头端点与节点边框的 x/y 坐标偏移是否在有效范围 [border_padding, border_padding] 内
✓
裁切检测（Clipping / Overflow） — 节点文本或连接器是否超出 viewBox 边界被截断
检查每条 text 元素 y + font-size 是否 > viewBox height，或 x + textWidth > viewBox width
✓
标签挤压检测（Label Squeeze） — 文本标签宽高比是否异常（过扁/过窄 = 被压缩），节点间距是否过小
计算 getBBox() 或 textLength / lengthAdjust 比率，警告 ratio < 0.5 或 > 1.5 的标签

cairosvg 安装 — PNG 渲染器配置
推荐渲染器：cairosvg（最佳 CSS 支持） pip install cairosvg python3 -c "import cairosvg; print(cairosvg.__version__)"

备选：rsvg-convert（系统包；可能丢失 CSS / <foreignObject>） brew install librsvg # macOS sudo apt install librsvg2-bin # Ubuntu/Debian

最高保真：puppeteer（真实 Chromium；需 Node + ~150MB） npm install puppeteer

常见问题：PNG 空白/全黑 — 原因：SVG 含 @import url() 外部字体，cairosvg/rsvg 无法抓取。
边框或文字缺失：— 使用 rsvg-convert 处理含 CSS / <foreignObject> 的 SVG 时会丢内容，切换 cairosvg。
