DEFENSIVE AUTOMATION / 01安全工具链的职责分层
AGENT + SECURITY TOOLCHAIN

先划范围，
再谈自动化。

把 Agent 接到安全工具，不是把侦测结果变成结论。安全链路的价值在于帮助已获授权的团队整理线索、保持审计记录并提高复核效率；它不能替代范围控制、人工判断与负责任披露。

明确授权人工复核最小影响
首屏结论Subfinder、httpx 与 Nuclei 分别服务于资产线索、服务信息和模板化检测。它们的输出是待核验信号，不是漏洞成立证明，更不是对未授权目标的操作许可。
01 / ASSET LEADS

Subfinder

官方将其定位为子域名发现工具，侧重使用被动在线来源返回有效子域名线索。

边界：子域名出现仅表示值得在授权范围内确认归属与范围，不等于可以继续主动探测。

02 / SERVICE SIGNALS

httpx

官方将其描述为可探测服务、Web 服务与有价值元数据的 HTTP 工具包。

边界：服务响应与指纹是复核输入；频率、敏感接口、第三方服务与数据留存均需受范围约束。

03 / TEMPLATE SIGNALS

Nuclei

官方将其定位为模板驱动的安全扫描工具；模板体系是检测能力的重要输入。

边界：模板命中可能误报，也不能替代证据收集、影响判断与人工确认。

三个环节，不是一键结论
A

收集线索

在书面授权、目标清单与时间窗内，整理可被复核的资产线索。

B

限定探测

按频率、协议、路径和数据规则执行；自动化始终服从范围。

C

人工定性

由负责人复核归属、影响与证据，再进入报告、修复或负责任披露。

必须保留的安全边界

  1. 仅对获得明确书面授权的资产执行操作，并遵守目标范围、时间窗与频率限制。
  2. 不把子域发现、服务指纹或模板命中表述为漏洞事实；所有结果需要人工复核。
  3. 不把自动化编排表述为对人工研判、风险接受、数据处理规则或披露流程的替代。
  4. 对生产敏感接口、第三方资产及可能造成扰动的行为，默认停止并请求负责人的明确判断。

适合交给 Agent 的事

  • 把批准范围转为可审计的任务清单
  • 归并重复线索，标注来源与时间
  • 为人工复核准备结构化证据包
  • 检查报告是否包含范围与限制说明

不能交给 Agent 自行决定的事

  • 扩大目标、提高频率或触碰未授权资产
  • 将工具输出定性为真实漏洞
  • 处理敏感数据、决定披露对象或发布时间
  • 绕过审批、变更控制或人工签核
