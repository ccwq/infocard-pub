SKILL 01

eli5 — 像跟5岁小孩解释一样讲清楚任何概念

anthropics/claude-plugins-community 出品，触发词 /eli5，用极简图片和少量文字解释复杂概念。

AI 解释小白友好

核心能力

用 HTML artifact 输出一张"大字报"式图片，配合极少文字，把任何技术概念讲得像跟5岁小孩说话一样简单。

使用方式

触发方式

用户输入 /eli5 或请求"用简单的话解释 X"。Agent 自动切换到 ELI5 模式，生成直观的图文 artifact。

  • 支持任意技术主题
  • 输出为 HTML artifact
  • 图片优先，文字极少

show-me — 用代码和截图快速呈现界面原型

humanlayer/skills 出品，通过 MCP 工具直接在对话中生成界面截图，适合边写代码边展示 UI 效果。

界面原型MCP

核心能力

在对话中直接生成代码对应的界面截图，无需切换工具或手动截图。适合边开发边展示 UI 的工作流。

实时展示

工作流

描述 UI → show-me 生成代码 → MCP 渲染截图 → 对话中直接呈现。循环迭代直到满意。

  • 无需切换窗口
  • MCP 工具链集成
  • 支持多轮迭代

unslop — 大模型调参与风格控制

cursor/plugins 出品（pstack/skills/unslop），用于对大模型的输出风格、温度、max_tokens 等参数进行精细化控制。

LLM 调参风格控制

核心能力

精细化控制大语言模型的输出风格、温度、max_tokens、top_p、frequency_penalty 等参数，适配不同场景需求。

适用场景

典型用途

在 Agent 工作流中，根据任务类型动态调整模型参数，如创意任务用高温、精确任务用低温。

  • 温度（temperature）控制
  • 最大 token 数限制
  • 输出格式约束
