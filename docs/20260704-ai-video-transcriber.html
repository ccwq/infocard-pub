Docker 部署
$ git clone https://github.com/wendy7756/AI-Video-Transcriber.git
$ cd AI-Video-Transcriber
$ cp .env.example .env  # 可选：设置 OPENAI_API_KEY
$ docker-compose up -d  # 一键启动
# 访问 http://localhost:8000
本地安装脚本
$ git clone https://github.com/wendy7756/AI-Video-Transcriber.git
$ cd AI-Video-Transcriber
$ chmod +x install.sh && ./install.sh  # 自动安装依赖
$ python3 start.py --prod  # 生产模式（长视频推荐）
环境变量配置
# .env 文件
OPENAI_API_KEY=sk-your-api-key-here
OPENAI_BASE_URL=https://openrouter.ai/api/v1  # 可选：自定义端点
WHISPER_MODEL_SIZE=base  # tiny/base/small/medium/large
UPLOAD_MAX_MB=200  # 本地上传文件大小限制
HOST=0.0.0.0
PORT=8000

FAQ

常见问题

需要准备什么？

Python 3.8+、FFmpeg、一个 OpenAI API Key（或其他兼容端点如 OpenRouter）。API Key 可在 UI 设置，无需服务器端环境变量。

支持哪些本地文件格式？

支持 .mp3/.mp4/.m4a/.wav/.webm/.mkv/.ogg/.flac 音视频，以及 .txt 纯文本。默认最大 200MB，可通过 UPLOAD_MAX_MB 调整。

长视频如何处理？

系统支持任意长度视频，但处理时间随长度增加。建议使用较小 Whisper 模型（tiny/base）处理长视频；生产模式 `python3 start.py --prod` 避免 SSE 断连。

内存占用多少？

Whisper 模型内存：tiny~150MB / base~250MB / small~750MB / medium~1.5GB / large~3GB。Docker 容器空闲约 128MB，处理时 500MB-2GB。

字幕提取失败怎么办？

无字幕平台会自动回退到 Whisper 转录模式。确保网络稳定，或切换 VPN 后重试。
