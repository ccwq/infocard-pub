从合弓纲的余晖，到新生代的繁盛。DeepTime Mammalia 基于 Mammal Diversity Database (MDD) v2.3 分类系统，将 167 个科、上千个演化节点，通过 3D 双螺旋画廊 + D3.js 动态演化树 双视图呈现，是兼具科学严谨性与沉浸式体验的生物演化可视化作品。
Features · 核心特性

🌌 沉浸式 3D 序幕

基于 Three.js (CSS3DRenderer) 构建 DNA 双螺旋画廊，象征生命遗传密码。WebGL 粒子系统随鼠标流动，营造深邃的时间感。影院级相机过渡动画，实现从微观到宏观的无缝切换。

Three.js WebGL CSS3DRenderer

🌿 D3.js 交互式演化图谱

高性能渲染，支持从"纲"到"科"的逐级展开/收起。全手势支持（滚轮、双指捏合、拖拽漫游）。底部集成动态地质时间轴，实时显示 MYA（Million Years Ago）。

D3.js v7 双向缩放 地质时间轴

🌐 中英文国际化

一键切换界面语言，节点名称、描述、UI 元素自动适配当前语言。中文/拉丁学名实时搜索与高亮定位。

i18n 中文/EN 拉丁学名搜索

🥚 溯源彩蛋 (Easter Egg)

隐藏的"溯源"模式：寻找并点击界面中的"溯源"按钮，呈现穿越大灭绝的幽灵线框路径——致敬生命韧性。
