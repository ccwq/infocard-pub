默认路径

技能家族

Implementation skills 负责输出代码；image-generation skills 负责输出设计图，不同家族承担不同环节。

frontendsdesign directionimage-first

什么时候用

当项目已经知道方向但还没学会“有品”，或者你希望 AI 先出设计参考再落代码时，它最合适。

02
Mechanism

它怎么工作

把仓库或帖子背后的工作流拆成可复用步骤，而不是只说“很强”。

STEP 1

安装

npx skills add https://github.com/Leonxlnx/taste-skill

STEP 2

选择

默认 skill 是 design-taste-frontend；需要旧行为可以 pin v1。

STEP 3

分流

image-to-code / imagegen-frontend-web / brandkit 各负责不同任务。

STEP 4

校正

通过 which one should I use? 的分流表把抽象审美变成具体入口。

03
Fit & Boundaries

适合谁 / 不适合谁

把边界说出来，卡片才像决策辅助页，而不是宣传页。

适合

适合

  • 前端 UI 提升
  • 设计感不足的 AI 产物
  • 想要 image-first 工作流的团队
不适合

不适合

  • 只想要静态网站模板
  • 没有设计判断标准的纯功能开发
