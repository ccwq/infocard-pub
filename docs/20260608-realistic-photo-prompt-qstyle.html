🧩 真实抓拍里常见的摄影失误术语

下面这些术语适合补到“反写真写实抓拍”类提示词里。它们和已有的 失焦、拖影、杂色、白平衡失败 不重复，更偏向真实抓拍里经常见到的细节失误。

对焦 / 清晰度类
focus / sharpness
虚焦：焦点偏离主体，人物脸部不够清楚。
跑焦：相机对到背景或前景，主体反而模糊。
浅景深误判：景深太浅，只有局部清楚，比如只清楚头发或衣服。
轻微抖糊：手持拍摄导致整体有轻微模糊。
边缘画质劣化：画面边缘发软、不锐利。
压缩糊感：手机或社交软件压缩后细节变糊。
运动 / 快门类
motion / shutter
运动模糊：人物动作中产生局部模糊。
快门速度过低：导致手抖或主体运动痕迹。
动态残影：移动人物边缘出现拖尾感。
滚动快门畸变：快速移动时画面产生轻微拉斜或变形。
瞬间冻结失败：动作没完全定住，像随手抓拍失败的一帧。
曝光 / 光线类
exposure / light
过曝：高光区域太亮，皮肤或窗户细节丢失。
欠曝：整体偏暗，暗部细节不足。
高光溢出：亮部变成一片白，没有层次。
暗部死黑：阴影区域完全黑掉。
逆光灰雾：逆光导致画面发灰、对比度下降。
眩光：强光进入镜头形成白雾或光斑。
鬼影：强光源反射产生重复光斑。
频闪条纹：室内灯光下出现横向明暗条纹。
色彩 / 白平衡类
color / white balance
偏色：整体偏绿、偏黄、偏蓝或偏红。
混合光色温冲突：室内灯光和自然光混在一起，肤色不稳定。
肤色失真：人物皮肤偏灰、偏黄、偏红。
色彩断层：渐变区域不自然，出现色带。
饱和度溢出：颜色过浓，像手机自动增强过度。
噪点 / 画质类
noise / quality
高 ISO 噪点：暗光环境下颗粒明显。
彩色噪点：暗部出现红绿蓝杂点。
亮度噪点：画面有灰黑颗粒感。
锐化过度：边缘出现不自然的硬线。
降噪过度：皮肤和细节被抹平，有塑料感。
JPEG 压缩痕迹：边缘出现块状、蚊噪或马赛克感。
构图 / 取景类
composition / framing
构图偏移：主体不在理想位置，像随手拍歪了。
水平线倾斜：画面轻微歪斜。
切头 / 切脚：人物头顶、脚部或手部被裁掉。
边缘遮挡：前景物体挡住部分主体。
主体出框：人物部分离开画面边界。
背景穿帮：杂物、路人、反光、奇怪物体进入画面。
视觉重心失衡：画面一侧太空或太挤。
镜头 / 手机拍摄类
lens / smartphone
镜头污渍：画面局部发雾、发白。
指纹雾化：手机镜头有指纹导致光线扩散。
镜头边缘暗角：四角发暗。
广角畸变：边缘人物或物体被拉伸。
近距离透视变形：鼻子、手、腿等近镜头部位被放大。
自动 HDR 失败：亮暗关系怪异，局部像被硬拉亮。
手机算法涂抹：细节被 AI/降噪算法处理得不自然。
更适合提示词的精简组合

允许轻微摄影失误：虚焦、跑焦、手抖模糊、运动模糊、动态残影、轻微过曝、轻微欠曝、高光溢出、暗部死黑、逆光灰雾、镜头眩光、频闪条纹、偏色、混合光色温、肤色失真、高 ISO 噪点、JPEG 压缩痕迹、构图偏移、水平线倾斜、切头切脚、边缘遮挡、主体轻微出框、镜头污渍、广角畸变、自动 HDR 失败。

🕵️ 抓拍、观察式与隐秘视角

摄影里这种“像偷拍、隐秘观察、被摄者没意识到镜头存在”的感觉，常见说法不是只有一个词。更安全、专业的表达通常是：抓拍感、观察式摄影、非介入式纪实风格。

Candid photography
抓拍摄影 / 自然抓拍
最常用。强调人物没有刻意摆拍，表情、动作自然；适合街头、生活纪实、婚礼现场、日常感照片。
Observational photography
观察式摄影 / 旁观式镜头
更偏纪实和艺术表达，像摄影师在旁边安静观察，而不是主动干预；适合距离感、旁观者视角、生活切片。
Fly-on-the-wall style
墙上苍蝇式拍摄 / 隐形观察视角
纪录片和影视中常用：摄影机像墙上的苍蝇一样存在，但不干扰现场。很适合表达“隐秘感”“不像摆拍”。
Surveillance aesthetic
监控影像美学 / 监控视角
适合远距离、模糊、压缩感、低清、监控式构图；但它更冷、更不安，不一定适合温暖生活感照片。
Voyeuristic framing
窥视感构图 / 隐秘观察视角
更强烈，像从门缝、窗外、远处偷偷看；有伦理和不适感，不适合所有场景，提示词中应谨慎使用。
Long-lens candid
长焦抓拍 / 远距离观察感
长焦会压缩空间，让摄影师看起来离主体很远；人物不看镜头时，容易产生远处观察的真实感。
Street photography
街头摄影 / 街头纪实
如果场景在街道、公共空间、咖啡馆、车站等地方，可归入街头摄影，通常包含 candid、observational、unposed 特征。

中文提示词 · 隐秘观察抓拍感
非摆拍抓拍感，观察式摄影，像摄影师在远处安静记录，人物没有看向镜头，自然动作，生活切片，长焦压缩感，轻微遮挡，真实街头摄影，隐秘观察视角。
candid photography, observational documentary style, fly-on-the-wall perspective, unposed moment, subject unaware of the camera, natural body language, long-lens candid shot, slight foreground obstruction, realistic street photography, quiet voyeuristic framing
画面特征
  • 人物不看镜头，而是在走路、聊天、低头、吃饭、发呆。
  • 构图有遮挡：门框、窗户、树叶、车窗、墙角、路人前景。
  • 镜头距离较远，像从街对面、咖啡馆外、楼梯口拍到。
  • 画面不完美：轻微虚焦、运动模糊、高 ISO 颗粒、构图偏一点，反而更真实。
  • 光线自然，不要太影棚，不要太精致。
  • 动作有“中途感”：刚回头、刚抬手、刚走出画面，而不是摆好姿势。
