这类照片的重点不是完美构图，而是真实可信。

🎬 画面核心特征（8条）
  • 人物不正面对镜头硬笑，表情像自然发生
  • 构图可以略微不完美——轻微偏移、裁切、歪斜均可接受
  • 光线接近日常自然光，而非影棚光
  • 场景保留生活细节：街道、咖啡杯、衣服褶皱、杂物背景
  • 可以有轻微运动模糊、噪点、压缩感或手机摄影质感
  • 人物处于动作过程中：走路、回头、低头、整理头发、看窗外、喝咖啡
  • 整体像真实照片，而不是AI精修海报
  • 纪实写实感 + 生活方式摄影 + 手机原相机感三者融合
