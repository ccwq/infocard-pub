mlx-vlm 部署

通过 mlx-vlm 在 Mac M 芯片上快速部署本地 API 服务器。

mlx-vlm · Apple Silicon
# 步骤一：升级 mlx-vlm
pip install -U mlx-vlm

# 步骤二：下载 4-bit 权重
hf download orcarouter/Qwen3.8-27B-Uncensored-MLX \
  --include "4-bit/*" \
  --local-dir ./Qwen3.8-27B-Uncensored-MLX

# 步骤三：一键拉起本地 API 服务器（兼容 OpenAI 接口）
python -m mlx-vlm server \
  --model ./Qwen3.8-27B-Uncensored-MLX/4-bit \
  --port 8080
