11 个做科普动画的 Skill，怎么选

有的用模型画帧，有的用代码画帧。模型画得快、够像，但改一遍需要再花一遍积分；代码画得慢一点，但改个数字重跑，不花钱。先把这条主线定下来，再按任务挑工具，能省下不少试错时间。原文作者替读者逐个确认了产出结果，工具好坏更多在于使用人的创意。

1 说产出 一张图还是一条视频？分辨率多少、要不要批量，先定下来。
2 定主线 经常要改的选代码画帧；一次成型不回头的选模型画帧。
3 查门槛 Node/FFmpeg、Python + 整套 LaTeX、四件套，装不动就绕开。
4 算成本 vox 一条 60 秒约 3 到 8 美元；whiteboard 四件套齐全，最贵最慢。
5 避坑 中文小字上糊、上屏文字会飘、内置版式有 PPT 味，各是一条已知的坑。

SINGLE IMAGE · ENGINE

只出一张图，外加一个引擎

01

visual-explainer-skill

单张信息图图像模型画帧API Key · 最低

丢一段文字进去，出来一张能直接当配图的信息图：内容切成区块，编号、箭头连接，像一页印好的海报。原理是内容先拆成概念、关系和版面，写成一段很长的提示词丢给图像模型。风格、信息密度都能调，能切成多帧递进，或套进手机、电脑框里。运行速度非常快。选它：快速出一张能直接用的配图。

坑 图上别放中文小字，这类模型写字十有八九是糊的，英文也常缺笔画。
02

anatomy

SVG / HTML / PDF代码画帧 · 等轴测零依赖 · 很慢

擅长把抽象概念具象化：令牌桶被做成一台机器，罐子、令牌、进料口、出料口、右下角读数。从后往前一层层堆。零依赖，但非常慢，需要表述得很清楚。选它：重要选题的主图。

03

hyperframes

MP4代码画帧 · HTML→帧Node / FFmpeg

一个把网页渲成 MP4 的引擎，官方那句 It's just HTML 就是它的世界观：让 Agent 写一个网页，引擎一帧一帧截图，合起来就是视频。效率非常快，改动不耗模型积分。后面好几个 Skill 就跑在它上面，把它当底层引擎用。

CODE-DRAWN VIDEO · MATH

代码画帧 · 出视频与公式

04

knowledge-explainer-skill

1280×720 MP4代码画帧 · RemotionNode / FFmpeg · 低

写一份 Markdown，一行命令直接出 720p 成片：它自己拆场景、生成 React、调 Remotion 渲出来，比较省事。选它：要一句命令出片的省事路线。

坑 内置六种版式（标题页、知识点卡、双栏对比、几何题、前后对比、收尾大字），只用内置的会带点 PPT 味；想好看，得让它往 custom 目录里写组件。
05

AI-Animation-Skill

HTML 演示页代码画帧 · 纯 CSS无 · 零成本

能全屏播放的演示动画，深色科技风：左边分层列表逐条进场，右边浮一张立体卡片。纯 CSS 加 3D transform，成本几乎为零。选它：不要积分、不要渲染环境的零成本演示。

边界 模板感比较重。
06

animated-explainer-skills

HTML（可录屏）代码画帧 · GSAP会编排才行

Kurzgesagt 那一挂，深蓝夜空加手绘小角色。给的不是模板，是一套编排模式：挤压拉伸的落体、物体变形的转场、带暗角和颗粒的镜头、分景深的视差推轨。换内容，不换骨骼。选它：想要成体系的科普动画质感，且自己能编排。

07

whiteboard-explainer

MP4插画模型 + 蒙版四件套齐全 · 高

一只手拿马克笔，说到哪个词就画到哪一笔：纸、马克笔、照片级的手、半画完的引导线。它不描 SVG 笔画，描边画出来的上限就是火柴人；走白板工具的老路子，先出成品插画，再用蛇形蒙版一点点揭开，一只手跟着笔尖走。节奏来自 Whisper 的词级时间戳，说到哪个词笔落到哪一笔，不用估时长。选它：就要这种手绘白板讲解的观感。

坑 要图像模型、TTS、Whisper、HyperFrames 四样齐全才跑得动；白板里最贵也是最慢的一个。
08

manim_skill

MP4 / 图片代码画帧 · ManimPython + LaTeX · 最高

3Blue1Brown 那一套：近黑底、细线、金色曲线、LaTeX 公式。公式是真排的，曲线是真算的，中间那几步变换在数学上对得上。它其实是两套规则集，ManimCE 和 ManimGL 各一套，管的是让 Agent 写 Manim 的时候别犯低级错。选它：讲数学公式和几何变换。

坑 Python、FFmpeg、整套 LaTeX，光装环境就能劝退一半人；它的输入是题目或概念，不是文案。

MODEL-DRAWN VIDEO · BATCH

模型画帧 · 出视频与批量

09

explainer-video-skills

MP4，可批量代码 · 五条产线中等 · 工具齐全

五条产线打成一包：脚本分镜配音对齐、年度报告风、图表逐节点揭示、白板、等轴测，一个仓库里五个技能。最有用的叫 wrapped-video：一个模板配一张数据表，能出几百条 9:16 的短片。它把视频从作品变成了批处理，另外十个都没这能力。选它：要批量。

10

vox-explainer-skill

60 秒 MP4模型画帧 · 图像 + 视频约 $3–8/条

一句话，输出一条 Vox 风纪录片：撕纸边、半调网点、压缩体大字、红黑米白。脚本、配音、关键帧、微动、配乐、拼装，全自动。画面靠约束收敛：先定一张风格锚帧，后面每张拿它当参考改，再禁掉镜头推拉和 3D 旋转，只留拼贴式的微动。一条 60 秒大概 3 到 8 美元，钱主要花在动画上。选它：要的主要是那股老照片加剪贴画的味道。

坑 文字上屏会飘，中文尤其，标题字有时候会错一个。
11

higgsfield-video-explainer

MP4（10s 块）模型画帧 · 图像 + 视频CLI + 额度

整条片拆成一个个 10 秒块，一块配一句旁白：黄昏手绘感的叙事画面，字幕烧在片上，右上角标着第几块。流程是先锁风格、再写脚本，然后一口气把所有配音生成出来，最后才出画面；每块十秒，画面和旁白一对一，不会出现画面太短配不完这句话的事。风格不用描述，从预设库里看缩略图挑。装 CLI 登录，不难。选它：要按旁白节奏出片的叙事画面。

边界 用一次消耗一次积分，改动成本随次数走。

COMBOS · 作者组合建议

怎么搭配着用

公众号配图

visual-explainer 出常规配图，重要选题拿 anatomy 做主图。

长视频分工

hyperframes 做片头，animated-explainer 做主体，公式丢给 manim。

高级效果

走 vox 或 higgsfield，尽量表述好需求，避免二次改动花更多积分。
