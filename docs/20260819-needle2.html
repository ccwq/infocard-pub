02
三大核心能力

Tool Calling · Confidence Gating · Bounded Memory

JSON 结构化输出 / 置信度自动决策 / 256 token 滑动窗口恒定 28MB 内存

Tool Calling

工具调用 · JSON 结构化输出

Simple Contract: text in, JSON out——工具调用以结构化数据返回
字节级语法编译器，按你的 schema 约束每一个 token。Tool Retrieval 内置检索头，每个回合只返回 Top-5 相关工具。
Confidence Gating

置信度门控 · 阈值自动决策

Calibrated Score: 每个回复都携带学习得到的置信度分数
设置阈值，高于阈值执行，低于阈值上报。无需人工判断，自主决策。
Bounded Memory

256 token 滑动窗口 · KV Sinks

工具永远 pin 在 KV sinks，内存永远是 28MB 上限
不管对话多长，内存恒定。确定性资源占用，适合嵌入式实时场景。

安装使用

pip install · 一条命令跑起来

Python 一条命令安装，离线场景（气隙设备）同样适用

Python 一条命令
# 安装
pip install cactus-needle

# 离线场景（气隙设备）
pip install cactus-needle
# 推理引擎从 HuggingFace 缓存一次，无网络依赖

# 下载 .cact 文件（可选）
needle download /models/needle.cact

# 指定 HuggingFace repo
NEEDLE_HF_REPO=Cactus-Compute/needle2 needle --upload

# 二进制文件 14MB，可直接拷贝到设备
ls -lh *.cact
