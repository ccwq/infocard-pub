02
三大核心能力
Tool Calling

工具调用 · JSON 结构化输出

Simple Contract
text in, JSON out——工具调用以结构化数据返回
字节级语法编译器，按你的 schema 约束每一个 token
Tool Retrieval
内置检索头，每个回合只返回 Top-5 相关工具
大型工具目录也可扩展，语法约束只在子集上生效
Confidence Gating

置信度门控 · 阈值自动决策

Calibrated Score
每个回复都携带学习得到的置信度分数
设置阈值，高于阈值执行，低于阈值上报
Bounded Memory
256 token 滑动窗口，工具永远 pin 在 KV sinks
内存永远是 28MB 上限，不管对话多长

适用设备
✅ 已在这些设备上实测

❌ 传统方案的问题
几百万参数的模型放不下
联网调 API 不安全（指令/数据外传）
每次回答还要调云端大模型，成本高
需要管理多个模型文件
04
安装使用
Python 一条命令
# 安装
pip install cactus-needle

# 离线场景（气隙设备）
pip install cactus-needle
# 推理引擎从 HuggingFace 缓存一次，无网络依赖

# 下载 .cact 文件（可选）
needle download /models/needle.cact

# 指定 HuggingFace repo
NEEDLE_HF_REPO=Cactus-Compute/needle2 needle --upload

# 二进制文件 14MB，可直接拷贝到设备
ls -lh *.cact
