AI 视频 · Agent Skill

Video Shotcraft

把 Claude Code / Codex 变成动态分镜工作室——106 个镜头配方、162 种风格、161 个动态预览，用 Remotion 生成电影级产品宣传片。

Apache-2.0 1542 ★ 124 Fork Remotion TypeScript 多语言文档
106镜头配方卡片
162视觉风格
161动态预览 GIF
1内置完整模板（Ink Press）

核心价值

01

AI 分镜 + 代码生成

输入产品描述或指定镜头名称，Agent 自动完成分镜、动画和音效设计，输出 Remotion 可执行代码。

  • 真实页面捕捉（浏览器截图）
  • 2.5D 摄像机运动
  • 节拍同步剪辑
  • 电影级 SFX

核心数据

02

资源规模

镜头配方

106 个可独立调用的分镜卡片，含运镜路径、节奏和音效说明

风格库

162 种视觉风格，覆盖复古、极简、科技感等方向

动态预览

161 个 GIF 预览，上线 Gallery 可实时搜索和筛选

Gallery 交互预览

「Gallery 在线地址：vincentwei1021.github.io/video-shotcraft/」
可搜索、筛选、对比风格变体，直接复制镜头卡片名称用于提示词。

搜索过滤

按风格、类型或镜头名称过滤，快速定位目标分镜

变体对比

同一分镜不同风格的侧滑对比，直观判断选型

即取即用

点击卡片名称，复制到剪贴板直接作为 Agent 提示词
