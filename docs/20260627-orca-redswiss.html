01 核心定位
一个人开五个 AI Coding Agent 并行干活，不乱套吗？ Orca 说：完全可以。
Orca 是专为 AI 编码代理设计的 ADE 平台（Agent Development Environment），支持同时运行多个编码代理，每个代理在独立 Git Worktree 中工作，统一管理、对比结果、合并代码。
STEP 1

输入一个提示

描述任务目标，一次输入

STEP 2

分发 5 个 Agent

每个独立 Git Worktree，并行执行

STEP 3

对比结果

在一个界面里横向比较各分支产出

STEP 4

合并最优结果

选取最佳方案，合入主分支

02 核心功能
🌴

并行 Worktree

同一提示分发给多个 Agent，每个独立 Git Worktree 运行，便于实验与合并，彻底解决多 Agent 协作混乱问题。

📱

移动端 Companion

iOS App Store / Android APK 远程监控 Agent 进度、接收完成通知、发送后续指令，随时随地掌控舰队状态。

🖥️

WebGL 终端

Ghostty 级终端渲染，支持无限拆分，滚屏历史重启后依然保留，流畅处理大量 Agent 输出。

🎨

Design Mode

点击任意 Chromium 窗口 UI 元素，直接将 HTML/CSS/截图注入 Agent Prompt，实现所见即所控。

🔗

GitHub / Linear 原生

内置 PR/Issue/看板浏览，从任意任务直接创建 Worktree，无需切换上下文，适合团队协作。

🖥️

SSH Worktree

在远程高配机器上运行 Agent，支持完整文件编辑、Git 操作和终端，自动重连和端口转发。

🔍

AI Diff 批注

文件拖拽进 Agent Prompt，AI 差分批注代码变更，支持图像直传，代码审查效率大幅提升。

⚙️

Orca CLI

用 orca worktree create、snapshot、click、fill 等命令脚本化所有工作流。

🔔

通知系统

Agent 完成后通知、Unread 状态管理，随时标记待处理线程，专注当前任务不怕遗漏。

🤖

Computer Use

让 Agent 操作桌面应用和可见 UI，当工作流需要真实交互时，直接控制宿主机程序。
