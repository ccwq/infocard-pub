Anthropic Harness Design

让长时 Agent 交付得更稳

Anthropic 公开文章介绍 planner、generator、evaluator 三智能体架构，以及结构化 handoff 和外部评估。

核心判断：当任务长、上下文会膨胀且质量需要独立判断时，结构化产物和外部评估比单个 Agent 自我表扬更可靠。

三角色分工

Planner

把短提示扩展为产品规格和可交付目标，避免过早锁死实现细节。

Generator

按一个功能一个 sprint 实现，并在交接前自检。

Evaluator

用独立、偏怀疑的标准检查功能、视觉、可用性和代码质量。

Artifact handoff

通过文件交接上下文，而不是把所有历史重新塞回一个会话。

什么时候值得用

长时、复杂、可拆分且能定义验收标准的任务更适合；短任务或已有强自动化测试的任务，额外编排可能只是开销。

来源与边界

这是方法论文章与公开实验总结，不是所有 Agent 任务都需要三智能体；文章也明确指出编排会增加复杂度、token 开销和延迟。
