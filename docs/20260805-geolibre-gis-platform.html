03 · 技术架构

核心依赖栈

Tauri v2
原生桌面容器，无 Electron，体积小、安全、沙盒化运行。
React + TypeScript
现代化前端框架，保证多端 UI 一致性。
MapLibre GL JS
开源矢量/栅格地图渲染引擎，支持 3D Tiles 和自定义样式。
DuckDB-WASM Spatial
浏览器内嵌入式分析型数据库，支撑大规模空间查询和联接。
deck.gl
GPU 加速大规模地理数据可视化：热力图、飞线、3D 挤出。
Whitebox WASM 工具
1000+ 地理处理工具从 Whitebox Next Gen 移植到 WebAssembly。

07 · 判断

评估结论

✅ 核心价值
把专业级 GIS 能力（1000+ 地理处理工具、3D 可视化、太阳系行星地图）装进浏览器，无需安装、无需服务器、数据完全本地——这是真正的云原生 GIS 革新。
✅ 差异化定位
唯一的 WASM 原生 GIS 平台，唯一同时覆盖 Web / 桌面 / 移动 / Jupyter 四大平台的开源 GIS，唯一支持太阳系多天体地图的工具。5441 ⭐ 证明社区认可度。
⚠️ 适用边界
超大规模遥感影像处理仍需 GDAL/PostGIS 等服务端工具；复杂网络分析功能相比 QGIS/ArcGIS 有限；企业级权限管理目前非核心方向。
