核心功能一览
🔍 全局搜索 ⌘⇧F — 跨项目即时搜索，直达具体消息，搜索结果由 Rust 后端 trait dispatch 驱动
💬 应用内对话 — 内置 Chat：启动或续聊会话，支持实时切换模型 / 推理强度（含 Opus Ultracode）/ 权限模式，无需切到终端
▶ 一键 Resume — 在内嵌终端或外部 Terminal.app / cmux / iTerm2 / Ghostty / Warp 中恢复会话
📊 Token & 成本统计 — 按项目 / 模型 / 工具维度聚合，支持每日活动图表、Token 用量趋势
📤 灵活导出 — 单会话或批量导出为离线可读的 Markdown / HTML / 无损 JSON
🗂️ 共享回收站
📡 实时追看 — 打开的会话自动追踪 CLI 追加的新消息，「Live」指示灯 + N new ↓ 提示
🌐 菜单栏统计 — 各 Agent 花费与 Token 概览

开发背景：三天 Vibe Coding 实战
js-bridge.com · Vibe Coding 实战
五月那个周末，我同时挂着 Claude Code、Codex、Gemini CLI 三个窗口。想翻一段两天前调通的 prompt，结果在 ~/.claude、~/.codex、~/.gemini 三个目录里 grep 了二十分钟。写个桌面应用，统一翻这三家的会话。

Day 1：给定 JSONL 文件，能在 Tauri 窗口里把对话渲染出来。Day 2：接入第二个 Agent，统一数据 schema。Day 3：把 Claude Code 专属逻辑全部抽到 trait 后面，让架构能扩展到新 Agent。
