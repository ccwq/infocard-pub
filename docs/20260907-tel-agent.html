Tel-Agent：把电话线路接入可自托管的 AI 助手

Tel-Agent 是一个 self-hosted、BYOK 的 AI phone assistant：连接电话线路与 AI 模型，支持来电路由、转接、留言、日历和通话转写。当前处于 Milestone 0，尚不适合直接接入生产电话。

官方入口：https://github.com/Dpro-at/Tel-Agent

01 / 先看定位与边界

01

当前状态

Milestone 0；官方尚无正式 release。规划中的渠道和能力不能写成已实现。

02

电话链路

SIP/PBX → agent → STT / LLM / TTS；API 提供 REST/WebSocket，Redis 承载实时状态。

03

核心动作

按来电规则转人工、拦截或交给 AI；AI 可转接、留言、查日历和调用 HTTP 工具。

04

安装路径

Python 3.11+、ffmpeg、SIP/PBX 测试线路与 STT/LLM/TTS 密钥；官方 README 提供 Docker Compose 启动路径。

05

上线边界

不要暴露公网；使用 VPN/Tailscale/HTTPS，限制拨号权限并保护 .env，避免通话与电信欺诈风险。

06

许可证

AGPL-3.0；CLA 允许 Dpro GmbH 对贡献再许可，商业/托管边界需结合 LICENSE 与 CLA 判断。
