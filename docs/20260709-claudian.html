核心定位

Claudian 是 Obsidian 第三方插件，将多个 AI 编程 Agent（Claude Code / Codex / OpenCode / Pi）嵌入 vault 侧边栏，让 vault 直接成为 Agent 的工作目录。

Obsidian 插件 Claude 默认 Provider Codex 可选 Provider Pi / OpenCode 侧边栏原生对话

解决什么问题

传统方案的割裂体验

Obsidian 用户想要 AI 编程能力，通常需要在 Obsidian 编辑器和 Claude Code 终端之间来回切换——体验割裂、上下文丢失、窗口横跳。

Claudian 的原生整合

Claudian 把 Agent 完整嵌进 Obsidian 侧边栏，vault 成为 Agent 的工作目录，所有操作在笔记库内一步到位，不再需要切换窗口。

核心能力

  • 侧边栏原生对话：在 Obsidian 侧边栏直接与 Agent 对话，无需额外终端窗口
  • Vault 成为工作目录：Agent 直接读写 vault 内的文件，无需路径配置
  • 文件读写：Agent 在 vault 内读取、创建、修改 Markdown 与其他文件
  • 全文搜索：Agent 可搜索 vault 内所有内容
  • Bash 执行：在 vault 上下文中执行终端命令
  • 多步工作流：复杂任务通过多步骤在 vault 内闭环完成
  • 选中文本操作：选中笔记内容，直接让 Agent 处理或解释

多 Provider 架构

Provider 模型

Claudian 基于多 Provider 架构设计：Claude 是默认全功能 Provider；Codex 是可选 Provider，通过 Conversation.providerId + providerState 接入同一 conversation model。多 Provider 共享同一会话上下文，可在同一对话中切换。

支持的 Agent

Claude Code（默认） Codex（可选） OpenCode Pi

安装与配置

前提条件

  • 已安装 Obsidian
  • 已安装 BRAT（Beta Reviewers Auto-update Tools）插件
  • 已安装 Claude Code / Codex / OpenCode / Pi 其中之一
  • 或已配置兼容模型（DeepSeek / GLM 等）

安装步骤

  • Obsidian → 设置 → 第三方插件 → 搜索并启用 BRAT
  • BRAT 设置 → Add Beta plugin → 填入 YishenTu/claudian
  • 重启 Obsidian，在第三方插件列表找到 Claudian 并启用
  • 配置 Claude CLI 路径（或兼容模型 API）

风险与边界

文件操作权限 本地 CLI 依赖 社区插件稳定性 模型配置复杂度 Obsidian 版本兼容性 隐私与安全边界

Claudian 在 vault 内执行文件读写和 bash 命令，Agent 权限边界取决于 Claude Code 自身的安全设置。建议明确 vault 内哪些目录可被 Agent 修改，避免误操作重要笔记。
