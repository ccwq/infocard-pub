01
What

这是什么

Monid Search + Fetch 是 AI Agent 专用的网页搜索与内容抓取工具，通过自然语言指令让 Agent 自主搜索网页并提取信息，完全免费。

🔍 搜索 + 抓取

输入自然语言查询，Monid 自动搜索相关网页并提取内容，返回结构化结果给 Agent。

💸 完全免费

无订阅、无配额、无钱包要求。即使账户余额为 $0 也能正常使用，真正零门槛。

⚡ Claude Code 原生

以 Skill 形式提供，Claude Code 用户直接 @ 调用，融入现有工作流，无需额外配置。

02
How

如何使用

安装后，Claude Code 对话中直接 @ 引用即可，支持搜索和网页抓取两种模式。

搜索模式

@monid-search "Hermes Agent 最新功能"

返回相关网页列表和摘要，Agent 进一步抓取。

抓取模式

@monid-fetch "https://monid.ai/docs"

直接抓取指定 URL 的全文内容，供 Agent 分析。

Skill 安装 @monid-search @monid-fetch 无需 API Key 无需信用卡
