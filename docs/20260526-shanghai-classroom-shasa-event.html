上海二工大"课堂喊杀"事件
舆情调查报告 · 2026.05.26
事件时间线
  • 5月19日
    上海第二工业大学，一大四男生迟到进教室后睡觉，被老师提醒"不要睡觉"，当场情绪失控
  • 5月19日
    男生冲出教室砸坏走廊消防器材（灭火器），返回后站上讲台质问老师"为何折我面子"，连吼三声"杀！杀！杀！"
  • 5月19日
    老师主动道歉安抚，男生不依不饶称"最讨厌事后道歉"，老师宣布提前下课，辅导员介入
  • 5月20日
    现场视频在微博/抖音传播，登多个平台热搜，引发全网热议
  • 5月20日
    上海第二工业大学发布官方通报：涉事学生为大四重修生，有心理方面问题，从高中起药物治疗，已联动家长和专业机构
  • 5月21日
    后续：当事老师请该男生吃汉堡道歉，两人和解，男生已被家长接走接受治疗
核心发现
事件性质

高校学生情绪失控极端事件，非暴力袭击但言语具攻击性

校方定性为心理问题引发，未给该生任何处分

涉事学生背景

大四重修生，原定5月20日参加毕业答辩

高中时期即有情绪障碍，长期服用精神科药物

多门核心课程需重修，学分未修满，面临毕业压力

起因极小

迟到进教室 → 坐第二排 → 上课睡觉 → 老师随口一句"不要睡了"

触发链路：被提醒"丢面子" → 要求老师道歉 → 老师道歉 → 反而更狂躁

舆情走向

初始：全网一边倒指责学生"无理取闹"

反转：身份扒出后（重修生+心理问题），舆论分化，支持者认为"病了该治不是罚"
