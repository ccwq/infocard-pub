LOCAL LLM · MODEL SELECTOR

SpecJudge：根据项目复杂度推荐「够用」的本地模型

读取 SDD artifacts，本地 Ollama 判断项目复杂度，输出 good/overkill/fair/poor 四级评级与性价比推荐，避免模型太弱做不出来或旗舰模型做简单任务。

Open Source Local First MIT License
⭐⭐⭐ v0.1.4 37 个模型 Python 3.11+
核心机制

读取 .specify/ 目录 → 本地 Ollama judge 评估推理复杂度 → 对比 37 个模型 capability × 定价 → 推荐「刚好够用」的模型

适合需要为项目匹配本地模型的开发者；完全本地运行、隐私零泄漏，但仅支持 Ollama backend。

SpecJudge 是由 JoaquinRuiz 开发的开源工具（MIT，v0.1.4），通过读取项目中的 SDD artifacts（constitution / specs / tasks）并调用本地 Ollama judge 评估推理复杂度、工作规模和领域专业化程度，再与内置 37 个模型的 capability 评级和定价对比，输出四级推荐评级。规范文件永不离开本地机器。

ARCHITECTURE

架构与机制

读取 SDD artifacts → Ollama judge → 模型匹配

核心

SDD Artifacts 读取

读取 .specify/memory/constitution.md、.specify/spec/*.md、.specify/tasks/*.md 三类规范文件，提取领域特征、任务规模和设计约束。

  • 数据充足 → sufficient
  • 内容单薄 → scarce（警告）
  • 无 tasks → insufficient（不输出推荐）
核心

模型匹配引擎

将推理复杂度与 37 个模型的 capability 评级（low / medium / high / top）和 USD/1M tokens 定价交叉匹配。

  • good：刚好够用，甜区
  • overkill：能力过剩，多花钱
  • fair：略有不足
  • poor：能力不足

05
SETUP

部署流程

pip install · Ollama · specjudge

Windows / Linux / macOS

安装步骤

# 1. 安装
pip install specjudge

# 2. 安装 Ollama judge 模型
ollama pull llama3.1:8b

# 3. 运行（当前目录）
specjudge .
注意

前提条件

  • Python 3.11+ 环境
  • Ollama 已安装并运行（ollama serve）
  • 项目根目录有 .specify/ 规范文件
  • 推荐 judge 模型：llama3.1:8b
不支持 llama.cpp / vllm

Issue #4 为 OpenAI-compatible endpoint 功能请求，当前版本仅支持 Ollama
