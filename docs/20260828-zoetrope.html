01
OVERVIEW · 一句话概述

zoetrope 是什么

Agent 可观测性Claude Code

多 Agent 并行执行可视化

Claude Code 的 subagent 机制强大，但执行过程不透明。zoetrope 读取 Claude Code 本地 JSONL 会话记录，将每个 Agent 的创建关系、工具调用、耗时、token 消耗实时渲染为流图。

MIT · Rust只读设计

无 HTTP client · 隐私优先

zoetrope 只读取本地 JSONL 文件，依赖树中没有 HTTP client，不会向外发送任何数据。README 明确标注"只读设计"——适合关注数据隐私的开发者。

KEY FEATURES · 核心功能

Agent 执行过程全透明

从实时追踪到历史回放，zoetrope 提供完整的 Agent 可观测性视图。

功能 标签 说明
终端实时跟踪 实时 终端窗口直接渲染正在运行的 Claude Code Session，实时显示 Agent 节点、调用关系和状态变化
会话回放 Replay 已完成的任务可随时回放，支持沿时间轴前进/倒退，精确定位每个决策点的输入输出
Agent 详情查看 Detail 点开任意 Agent 节点，查看完整 prompt、所选 model、工具调用链与每步耗时
浏览器运行模式 Browser 同一套引擎可在浏览器运行，会话文件保留在本地，无需上传到任何服务器
只读设计 Privacy 依赖树中无 HTTP client，不发送任何数据，JSONL 文件完全本地读取，隐私优先
JSONL 格式解析 Core 读取 Claude Code 内部 JSONL 会话记录（未公开格式），展示 agent 创建关系和工具调用
token / 耗时统计 Metrics 每个 Agent 的输出 token 数量、总耗时、工具调用次数均可见，方便性能分析

INSTALL · 安装方式

Homebrew 一键安装

Homebrew推荐

macOS / Linux

brew install furkankly/tap/zoetrope
zoe

运行命令为 zoe，启动后自动检测本地 Claude Code JSONL 文件。

GitHub源码

手动构建（Rust 环境）

git clone https://github.com/furkankly/zoetrope
cd zoetrope
cargo build --release
./target/release/zoetrope
⚠ 兼容性限制：zoetrope 读取 Claude Code 未公开的内部 JSONL 格式，后续 Claude Code 版本变化可能导致解析异常。项目会跳过未知记录而非报错，不保证与未来版本永久兼容。建议用于日常调试，遇到版本问题时关注 GitHub issues 更新。
04
USE CASES · 适用场景

什么情况下值得用

调试长任务

定位 subagent 卡点

多 Agent 并行跑代码重构、批量文件处理等长任务时，某个 subagent 卡住不知道原因。用 zoetrope 一眼看到哪个 Agent 在等待、哪个已超时。

复盘执行

Agent 执行过程复盘

任务完成后回放全流程，对比不同 prompt、不同 model 下的 Agent 行为差异，找到最优的 agentic 工作流配置。

成本分析

token 消耗可视化

每个 Agent 的输出 token 和耗时清晰可见，方便分析 Claude Code 使用成本，识别消耗异常高的 subagent。
