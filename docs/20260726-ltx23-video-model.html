01模型概述
LTX-2.3（Lightricks）

开源多模态音视频生成模型，Diffusion-Transformer 架构，支持文生视频、图生视频、音视频同步生成。2026年发布，完整开源权重+代码。

Wan2.1（阿里巴巴）

阿里巴巴开源大规模视频生成模型，DiT 架构，14B/1.3B 双版本，支持文生视频、图生视频、中英文文字特效。VBench 榜单第一（86.2分）。

03各自优势
LTX-2.3 优势
  • 音视频同步生成（业界稀缺能力）
  • ComfyUI 生态完整（LTXVideo + VideoHelperSuite）
  • 官方 LoRA trainer，定制灵活
  • 消费级显卡可本地部署
  • 社区有"质量领先 Wan2.1"反馈
Wan2.1 优势
  • VBench 86.2分，SOTA 性能
  • 唯一支持中英文文字特效的视频模型
  • 14B/1.3B 双版本，硬件适配广
  • 1.3B 仅需 8GB 显存，门槛最低
  • Wan-VAE 编解码速度快 2.5 倍
  • Hugging Face 6天下载量破百万
04社区反馈
  • 质量领先共识

    用户社区普遍反馈 LTX-2.3 在生成画质、动作流畅度方面明显领先 Wan2.1，有"把 Wan2.1 甩得车尾都看不到"的说法。

  • 中文生态优势

    Wan2.1 凭借中文文字特效和阿里云生态，在中文创作者群体中普及率更高，CSDN 教程生态活跃。

05本地部署
STEP 1

安装 ComfyUI

下载 ComfyUI 官方版本，安装 python 3.10+ 环境。

STEP 2

LTXVideo Node

git clone ComfyUI-LTXVideo 和 VideoHelperSuite 到 custom_nodes 目录。

STEP 3

下载模型权重

通过 ModelScope 下载 LTX-Video 权重，安装到 ComfyUI/models/checkpoint。

# LTX-2.3 模型下载（ModelScope） modelscope download --model AI-ModelScope/LTX-Video \ ltx-video-2b-v0.9.safetensors --local_dir ComfyUI/models/checkpoint # Wan2.1 T2V 1.3B（消费级显卡推荐） modelscope download --model AI-ModelScope/Wan2.1-T2V-1.3B \ # 仅需 8GB 显存，RTX 4090 生成 5秒 480P 约 4 分钟
06总结
选 LTX-2.3 如果…
  • 需要音视频同步生成能力
  • 追求更高画质和动作流畅度
  • 使用 ComfyUI 工作流
  • 需要 LoRA 深度定制
选 Wan2.1 如果…
  • 需要中文字特效生成
  • 硬件显存有限（8GB 可跑 1.3B）
  • 追求 VBench SOTA 评分
  • 偏好阿里云/国内生态
