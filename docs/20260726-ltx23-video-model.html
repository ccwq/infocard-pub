01模型概述
LTX-2.3（Lightricks）

开源多模态音视频生成模型，DiT 架构，2024年3月首发 v0.9.7，2024年12月升级至 v0.9.1，2026年迭代至 2.3。全球首个可实时生成高质量视频的 DiT 模型（30 FPS / 1216×704），支持文生视频、图生视频、音视频同步。完整开源权重+代码+推理包+LoRA trainer。

Wan2.1（阿里巴巴）

阿里巴巴开源大规模视频生成模型，DiT 架构，14B/1.3B 双版本。支持文生视频、图生视频、中英文文字特效、视频编辑（VACE）、文生图。VBench 86.2分，全球第一。Hugging Face 6天下载破百万。

07本地部署步骤
STEP 1

安装 ComfyUI

下载官方版，安装 Python 3.10+，配置 NVIDIA 驱动 + CUDA。

STEP 2

安装插件节点

git clone ComfyUI-LTXVideo 和 VideoHelperSuite 到 custom_nodes 目录。

STEP 3

下载模型权重

ModelScope 下载 LTX-Video 权重，安装到 ComfyUI/models/checkpoint。

# LTX-2.3 模型下载（ModelScope） modelscope download --model AI-ModelScope/LTX-Video \ ltx-video-2b-v0.9.safetensors \ --local_dir ComfyUI/models/checkpoint # Text Encoder（T5xxl） modelscope download --model Comfy-Org/stable-diffusion-3.5-fp8 \ text_encoder/t5xxl_fp16.safetensors \ --local_dir ComfyUI/models/text_encoder # 低显存优化：int8 量化（节省 75% 显存） # 官方提供原始版 / FP8 量化版 / 精简版三个版本 # 8GB 显存推荐 FP8 量化版，兼顾速度与画质
08总结与选型建议
选 LTX-2.3 如果…
  • 需要音视频同步生成能力
  • 追求更高画质和动作流畅度
  • 使用 ComfyUI 节点工作流
  • 需要 LoRA 深度定制
  • 需要原生竖屏 9:16 输出
  • 有 RTX 3060 12GB+ 显卡
选 Wan2.1 如果…
  • 需要中文字特效生成
  • 硬件显存有限（8GB 可跑 1.3B）
  • 追求 VBench SOTA 评分
  • 偏好阿里云 / 国内生态
  • 需要文生图 + 视频编辑（VACE）
