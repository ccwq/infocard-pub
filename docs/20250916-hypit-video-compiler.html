01 PAIN POINT — VIDEO AI IS A BLACK BOX
Why existing tools fail agents

🎰 Black Box = Change One Word = Regenerate Entire Video

Video models are black boxes: you get one MP4 output. Want to change a single word or subtitle? You must regenerate the entire video. Expensive, slow, unpredictable — and impossible to automate reliably.

🕐 Timeline Software Is Built for Humans, Not Agents

Traditional video editors (Premiere, JianYing, CapCut) are built for humans dragging tracks on a timeline. Agents can't automate timecode alignment, layer management, or clip repositioning — no standard API for programmatic editing.

The core problem: Video editing is timestamp-based. Agents work with text/code. These two paradigms don't mix — until now.

03 HOOK MECHANISM — EFFECTS ANCHORED TO WORDS
The core innovation

The insight: Traditional video = timeline. Hypit = word index. Instead of time=00:01:23, you write hook="changing one sentence". The Hook mechanism tracks which words appear where and auto-realigns all attached effects.

hypit.config.ts — Hook mechanism pseudo-code
// Define your video as a text script const script = `Welcome to our product launch... The all-new X1 changes everything. Here is what makes it special.`; // Attach Hooks to WORDS, not timestamps export default { scenes: [{ hooks: { "X1": { effect: "highlight", broll: "product_shot.mp4" }, "special": { effect: "slowmo", subtitle: "Key highlights" }, } }] } // Change one word → ALL effects auto-realign // "X1" moves → b-roll follows // "special" timing changes → subtitle re-syncs // No manual timecode adjustment needed

What the Hook mechanism handles

• Subtitle timing and positioning
• B-roll clip insertion
• Visual effects (slow-mo, zoom, highlight)
• Transitions between scenes
• Audio cue synchronization

What changes auto-realign

• Edit script text → subtitles shift with it
• Swap person → B-roll re-anchors
• Change language → all text tracks update
• Reorder sentences → entire scene restructures
