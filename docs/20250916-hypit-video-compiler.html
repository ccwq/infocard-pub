01 痛点 · 视频 AI 是个抽卡黑盒
为什么现有工具对 Agent 无效

🎰 抽卡黑盒：改一个字就要重新生成整条视频

视频模型是个黑盒，只给你一段写死的 MP4。想改一句话或字幕？必须整条重新抽。贵、慢、不可控——无法可靠自动化。

🕐 时间线软件是给人手拖的，Agent 无法自动化

传统剪辑软件（Premiere、剪映、CapCut）是为人类在时间线上拖轨道设计的。Agent 无法自动化时间码对齐、图层管理或片段重排——没有标准 API 支撑程序化剪辑。

核心问题：视频剪辑基于时间码。Agent 工作在文本/代码层面。两种范式无法融合——直到 Hypit 出现。

特效、B-roll、字幕锚定到词，而不是时间码。改一句话，后面所有内容自动重新对齐。

03 Hook 机制 — 特效锚定到词
核心创新

核心思路：传统视频 = 时间线。Hypit = 词索引。不再写 time=00:01:23，而是写 hook="changing one sentence"。Hook 追踪每个词出现的位置，自动重新对齐所有附加特效。

hypit.config.ts — Hook 机制伪代码
// 用文本脚本定义视频 const script = `Welcome to our product launch... The all-new X1 changes everything. Here is what makes it special.`; // 把 Hook 锚定到词，不是时间码 export default { scenes: [{ hooks: { "X1": { effect: "highlight", broll: "product_shot.mp4" }, "special": { effect: "slowmo", subtitle: "Key highlights" }, } }] } // 改一个词 → 所有特效自动重新对齐 // "X1" 位置变了 → b-roll 跟着动 // "special" 时间变了 → 字幕重新同步 // 无需手动调整时间码

Hook 机制处理的内容

• 字幕时间与位置
• B-roll 片段插入
• 视觉特效（慢放、缩放、高亮）
• 场景转场
• 音频提示同步

哪些改动会自动对齐

• 改脚本文字 → 字幕跟着动
• 换人物 → B-roll 重新锚定
• 换语言 → 所有字幕轨道更新
• 调整句子顺序 → 整个场景重构

04 /HYPIT CLONE — 爆款视频反向工程
一条命令 → 100 个变体

核心用法： /hypit clone this video 下载并把任意爆款视频反向工程成可编辑代码。然后换人物、产品、语言、文案——一条命令批量跑出 100 个变体。

1. Clone/hypit clone [url]
2. 提取Transcript + B-roll + 时间
3. 编辑换文案/人物/语言
4. 批量生产 N 个变体

🎬 Clone 典型场景

• A/B 测试不同标题
• 本地化 20+ 语言
• 换产品演示视频素材
• 批量生产用户证言变体

⚡ 批量生产

一个脚本 → 100 条不同 Hook 的视频。完美适配创作者经济、电商和广告投放场景。无需人工拖时间线。

🔬 反向工程原理

Hypit 分析源视频：提取语音转文字、检测场景边界、识别 B-roll 位置——再生成可编辑代码。

05 成本模型
~$0 到 ~$1 每条视频

$0 · 纯代码渲染

基于 ffmpeg 的 Hook 场景渲染。不需要 API 调用，完全确定性输出。

~$1 · 使用付费素材

使用 AI 生成图片/音频（ElevenLabs、DALL·E 等）时，每条完整视频约 $1 API 费用。

先预览 · 素材复用

所有付费素材先用占位符预览，满意再调 API。修改时旧素材 100% 缓存复用，零浪费。

预览流程 — 占位符优先，API 在后
// 第 1 步：用占位符起草（免费） const scene = { voiceover: "PLACEHOLDER: narration.mp3", broll: "PLACEHOLDER: product_visual.mp4", subtitle: "The X1 changes everything", } // 第 2 步：预览布局（免费）—— 不调用 API // 第 3 步：满意后 → 替换占位符 await resolveAssets(scene, { voiceover: "elevenlabs", broll: "dalle" }) // 费用：约 $1 每条完整视频 // 第 4 步：修改内容时，未改动的素材自动复用 // 脚本改动 → 未变的素材不再产生新 API 调用
