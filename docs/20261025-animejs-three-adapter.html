核心判断：Anime.js v4.5.0 通过一次副作用导入，让 Three.js 成为一级动画目标——实际意义是 DOM 与 WebGL 动画可以共用同一套时间线 API。

Anime.js v4.5.0 由 juliangarnier 于 2026-06-22 发布。这个版本内置 Three.js 适配器，从 'animejs/adapters/three' 以副作用方式导入即可启用；同时提供通用的 registerAdapter() 机制，把 animate() 和 utils.set() 扩展到非 DOM 目标。据发布说明，适配器可驱动 Object3D、材质、灯光、相机、音频节点、UniformNode（TSL）和实例化网格。

为什么重要：v4.5.0 之前，用 Anime.js 驱动 Three.js 场景意味着手写渲染循环、逐个映射属性。v4.5.0 之后，Anime.js 4 的同一套 Timeline / Stagger / Scroll / 弹性缓动 / Draggable 原语，可以在一条时间线上同时编排 DOM 元素和 WebGL 场景对象。适配器把 Three.js 的嵌套路径压平成 Anime.js 属性——据原文评测，mesh.position.x、mesh.rotation.y、mesh.material.opacity 分别变成 x、rotateY、opacity。

02 三项能力详解
副作用导入

一次导入，七类目标

import 'animejs/adapters/three' 即完成适配器注册。据发布说明，可驱动 Object3D、材质、灯光、相机、音频节点、UniformNode（TSL）和实例化网格。底层 registerAdapter() 是通用机制：把 animate() 和 utils.set() 扩展到 DOM 之外的目标。

属性扁平化

嵌套路径变成 Anime.js 属性

据原文评测：mesh.position.x → x，mesh.rotation.y → rotateY，mesh.material.opacity → opacity。旋转单位是角度而非弧度；颜色接受 CSS 颜色语法。另据 v4.5.0 修复记录，颜色混合改为在伪线性空间混合 RGB 通道——中间过渡色与旧版本略有差异。

3D 交错

网格布局有了深度轴

Stagger 自动网格通过 {x,y,z} 坐标或显式 grid: [columns, rows, depth] 支持 3D 布局。axis 接受 'z'。新增 jitter 参数，接受单个数字或 [start,end]；新增 seed 参数，让 jitter 和 from:'random' 可复现。

03 典型用法

启用适配器、驱动网格、同步渲染

// 最小可用模式 —— 导入与调用方式见发布说明 / 原文评测
// animejs + three 导入
import { animate, createTimer } from 'animejs';
import * as THREE from 'three';
import 'animejs/adapters/three';  // 注册适配器

// 用扁平化属性驱动网格（旋转单位为角度）
animate(mesh, {
  rotateY: { to: 360 },
  x:       { to: 2 }
});

// 用 createTimer 同步渲染
createTimer({
  onUpdate: () => renderer.render(scene, camera)
});
