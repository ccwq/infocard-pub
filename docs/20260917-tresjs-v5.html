基础组件

Vue 风格的 3D 场景

TresJS 将 Three.js 对象封装为 Vue 组件，模板中直接写 3D 场景，无需手动管理 WebGL 上下文。

  • TresCanvas — 画布容器，自动初始化 Renderer
  • TresMesh — 3D 物体，支持嵌套子组件
  • TresBoxGeometry — 几何体（盒子）
  • TresMeshBasicMaterial — 基础材质
// TresCanvas + TresMesh 基础模板
<!-- App.vue -->
<TresCanvas alpha="true">
  <TresMesh :position="[0, 0, 0]">
    <TresBoxGeometry :args="[1, 1, 1]" />
    <TresMeshBasicMaterial :color="'#d80018'" />
  </TresMesh>
</TresCanvas>

// main.js
import { TresCanvas } from '@tresjs/core'
createApp(App)
  .component('TresCanvas', TresCanvas)
  .mount('#app')

// WebGPURenderer 初始化
// 渲染链：Vue → TresJS → Three.js → WebGPU

const renderer = new WebGPURenderer({
  antialias: true,
  powerPreference: 'high-performance'
})
renderer.setPixelRatio(window.devicePixelRatio)
renderer.setSize(window.innerWidth, window.innerHeight)
document.body.appendChild(renderer.domElement)

// TSL (Three.js Shading Language) 支持
await renderer.init()
const scene = new Scene()
const camera = new PerspectiveCamera(75, 16/9)
renderer.render(scene, camera)

Composable System

v5 Composable 全面重构：从工具函数到真正的 Vue Composable

useLoader / useLoop / useTres / useGLTF / useGraph — 每一个都经过重构，带来完整的响应式状态、TypeScript 类型安全和自动资源清理。

useLoaderv5 核心

从 Promise 到响应式状态

v4 返回 Promise，v5 返回完整响应式对象。loader 不再是异步工具函数，而是真正的 Vue Composable。

  • state — 加载完成的资源（Ref）
  • isLoading — 加载中布尔值（Ref）
  • error — 错误信息（Ref<Error|null>）
  • progress — 进度对象 {loaded, total, percentage}
  • load(path) — 手动触发加载任意路径
  • execute(delay) — 延迟重新加载
// useLoader v5 响应式模式
// ❌ v4 — 返回 Promise
const gltf = await useLoader(GLTFLoader, '/model.glb')

// ✅ v5 — 响应式状态对象
const { state: gltf, isLoading, error, progress } =
  useLoader(GLTFLoader, '/model.glb')

// 监听加载状态
watch(isLoading, (loading) => {
  if (loading) console.log('加载中…')
})

// 监听进度
watch(progress, (p) => {
  console.log(`进度: ${p.percentage}%`)
})

// 模板中直接使用
<primitive v-if="gltf" :object="gltf.scene" />
useLoop

渲染循环 useLoop

替代旧版 useRenderLoop。新 API 提供 onBeforeRender / onRender / onAfterRender 三个钩子，精确控制渲染阶段。

  • onBeforeRender — 物理更新、输入处理
  • onRender — 默认渲染逻辑
  • onAfterRender — 后处理、截图
  • 参数：delta（帧间隔）/ elapsed（总耗时）/ deltaRatio
// useLoop 渲染循环
import { useLoop } from '@tresjs/core'

const { onBeforeRender, onRender, onAfterRender } = useLoop()

// 每帧之前：更新物理/输入
onBeforeRender(({ delta, elapsed }) => {
  meshRef.value.rotation.y += delta
  updatePhysics(delta)
})

// 每帧之后：后处理
onAfterRender(() => {
  captureFrame()
})

Breaking Changes

v4 → v5 完整迁移对照表

v5 包含多个破坏性变更。逐项对照，迁移不走弯路。

ESM-only

ESM-only 构建

v5 移除了所有 UMD 构建。仅支持 ES Module。Node.js 需 14+。

// package.json 需添加
{
  "type": "module"
}

// ❌ v4 CommonJS — 已移除
const { TresCanvas } = require('@tresjs/core')

// ✅ v5 ESM
import { TresCanvas } from '@tresjs/core'
Events

事件系统重写

基于 @pmndrs/pointer-events，遵循 DOM 原生命名，仅首触元素触发。

// ❌ v4 短横线命名
<TresMesh @pointer-down="handle">
<TresMesh @click="handle" @pointer-up="handle">

// ✅ v5 DOM 原生命名
<TresMesh @pointerdown="handle">
<TresMesh @click="handle" @pointerup="handle">

// 重叠元素：改用父级处理
<TresGroup @click="handleGroup">
  <TresMesh>…</TresMesh>
</TresGroup>
废弃移除

已移除的 Composable

以下 Composable 在 v5 中已移除或迁移：

  • useTresReady → @ready 事件
  • useSeek → useGraph
  • useTresEventManager → 新事件系统
  • useRaycaster → 原生 Three.js Raycaster
  • useRenderLoop → useLoop
  • useLogger → 移除（调试简化）
  • useCamera → useTres().camera
  • useTexture → @tresjs/cientos
useRenderLoop

useLoop 替代 useRenderLoop

// ❌ v4 useRenderLoop
const { onLoop } = useRenderLoop()
onLoop(({ delta, elapsed }) => {
  mesh.rotation.y += delta
})

// ✅ v5 useLoop
const { onBeforeRender } = useLoop()
onBeforeRender(({ delta, elapsed }) => {
  mesh.rotation.y += delta
})

camera 从实例改为状态对象，支持多相机管理。

const { camera } = useTres()

// 高级用法：多相机管理
const activeCam = camera.value.current

动画系统与后处理：从 GLTF 动画剪辑到 Bloom 发光效果

useAnimations

GLTF 动画剪辑

从 GLTF 模型提取动画剪辑，控制播放/暂停/切换。

import { useGLTF, useAnimations } from '@tresjs/cientos'

const { state } = useGLTF('/robot.glb')
const animations = computed(
  () => state.value?.animations ?? []
)
const model = computed(() => state.value?.scene)

const { actions } = useAnimations(animations, model)

// 播放动画
watch(actions, (acts) => {
  const idle = acts['Idle']
  idle?.play()
})

// 切换动画
const walk = acts['Walk']
walk.play()
actions['Idle'].fadeOut(walk, 0.5)

TSL

Three.js Shading Language (TSL)

WebGPU 下 Three.js 使用 TSL 而非 GLSL，语法更接近 JavaScript，类型安全。

// TSL — WebGPU 着色器（替代 GLSL）
import { color, vec3, normalView } from 'three/webgpu'
import { nodeProxy } from 'three/examples/jsm'

// 创建 TSL 函数
const myMaterial = nodeProxy(MeshStandardMaterial, {
  color: color('#d80018'),
  roughness: 0.5
})

// GPGPU — GPU 通用计算
// 用于粒子系统、噪声生成等
slim

createTresApp slim：Tree-shaking 优化

v5 新增 slim 入口，不自动 extend 全量 THREE 命名空间，按需注册。

// @tresjs/core/slim — 不 extend 全量 THREE
import { createTresApp } from '@tresjs/core/slim'
import { Mesh, BoxGeometry, MeshStandardMaterial } from 'three'

const app = createTresApp(canvas, {
  windowSize: true
})
app.extend({ Mesh, BoxGeometry, MeshStandardMaterial })
app.render(MyScene)

// bundle 大幅减小：仅打包使用的 Three.js 类
Rapier 固定步长

Rapier 物理时间步长

Rapier 使用固定时间步（1/60s）模拟，与渲染帧率解耦，防止长间隙导致物理爆炸。

// 物理逻辑放入 onBeforeStep，非渲染循环
import { useRapier } from '@tresjs/rapier'

const { world, rapier, timeStep, onBeforeStep } = useRapier()

onBeforeStep(() => {
  // 每物理子步运行一次，不是每渲染帧
  // 施加力、检测碰撞等
  applyPlayerForce()
})

API Reference

TresCanvas 完整属性参考

所有 TresCanvas 可用属性：WebGL 上下文初始化参数（必须在创建时设置）和可动态修改的渲染参数。

上下文初始化

必须在创建时设置的参数

WebGL 上下文一旦创建无法更改，修改需重建整个渲染器，因此这些属性须使用静态值。

  • alpha — Canvas 透明背景（布尔）
  • antialias — 抗锯齿（布尔）
  • powerPreference — 性能偏好：'high-performance' | 'low-power' | 'default'
  • preserveDrawingBuffer — 保留绘制缓冲区（截图用）
动态参数

可动态修改的渲染参数

以下参数可以在运行时通过响应式 ref 动态修改。

  • clearColor — 背景清除色（Color 实例或字符串）
  • shadows — 阴影投射（布尔）
  • windowSize — 跟随窗口大小（布尔）
  • toneMapping — 色调映射（ACESFilmicToneMapping 等）
  • toneMappingExposure — 曝光值（数值）
  • outputColorSpace — 输出色彩空间
  • shadowMapType — 阴影贴图类型
  • renderMode — 渲染模式（默认/手动）
  • dpr — 设备像素比（数值）
// 静态初始化参数（仅在创建时生效）
<TresCanvas
  :alpha="true"
  :antialias="true"
  power-preference="high-performance"
  :preserve-drawing-buffer="true"
>
  <!-- 场景内容 -->
</TresCanvas>
// 动态参数（响应式修改）
import { ACESFilmicToneMapping } from 'three'

const shadowsOn = ref(true)
const toneMapping = ref(ACESFilmicToneMapping)
const exposure = ref(1.0)

<TresCanvas
  :shadows="shadowsOn"
  :tone-mapping="toneMapping"
  :tone-mapping-exposure="exposure"
  :clear-color="'#1a1a2e'"
>
  <TresMesh :cast-shadow="shadowsOn">…</TresMesh>
</TresCanvas>

// 运行时修改（自动响应）
watch(toneMapping, (v) => console.log('tone changed to', v))
@loop

TresCanvas 事件

所有 TresCanvas 可绑定事件：

  • @ready — Canvas 就绪，参数为上下文对象
  • @render — 每帧渲染时触发
  • @before-loop — 渲染循环开始前
  • @loop — 渲染循环每帧触发
  • @after-loop — 渲染循环结束后

import { PointerLockControls,

const { camera } = useTres()
const { onBeforeRender } = useLoop()

// 键盘映射
const keyboard = new KeyboardControls()
keyboard.addEventListener('keydown', (e) => {
  if (e.code === 'KeyW') camera.value.position.z -= 0.1
  if (e.code === 'KeyS') camera.value.position.z += 0.1
  if (e.code === 'KeyA') camera.value.position.x -= 0.1
  if (e.code === 'KeyD') camera.value.position.x += 0.1
})
Raycasting

射线检测：鼠标拣选 3D 物体

用 Three.js Raycaster 检测鼠标指向的 3D 对象（点击选中等交互）。

import { Raycaster, Vector2 } from 'three'

const { camera, scene } = useTres()
const mouse = new Vector2()
const raycaster = new Raycaster()

function onMouseMove(event) {
  mouse.x = (event.clientX / window.innerWidth) * 2 - 1
  mouse.y = -(event.clientY / window.innerHeight) * 2 + 1
  raycaster.setFromCamera(mouse, camera.value)
  const intersects = raycaster.intersectObjects(
    scene.value.children, true
  )
  if (intersects.length > 0) {
    console.log('Hit:', intersects[0].object.name)
  }
}
window.addEventListener('mousemove', onMouseMove)

Troubleshooting

排错清单：v5 高频报错与解决方案

基于 GitHub Issues 和官方 Discord 整理的常见错误诊断路径。

Error 1

"Component is not instantiated"

原因：v5 强制使用 extend() 注册组件，不支持全局自动注册。

// ❌ 错误：组件未注册
// Uncaught Error: Component not instantiated.

// ✅ 正确：先 extend
import { Mesh, BoxGeometry, MeshNormalMaterial } from 'three'
const app = createTresApp()
app.extend({ Mesh, BoxGeometry, MeshNormalMaterial })
Error 2

"Cannot read property '...' of undefined"

原因：在 Suspense 异步加载完成前就访问了 useGLTF 返回值。

// ❌ 错误：直接访问异步加载结果
const { scene } = useGLTF('/model.glb')
console.log(scene.value) // 可能为 undefined

// ✅ 正确：用 computed 或 watch 等待
const { scene } = useGLTF('/model.glb')
const modelReady = computed(() => !!scene.value)

// 在模板中用 v-if
<Suspense>
  <Robot v-if="modelReady" :model="scene" />
  <template #fallback>
    <div>Loading 3D model...</div>
  </template>
</Suspense>
Error 3

性能下降 / FPS 低于 30

诊断路径：先定位瓶颈来源，再针对性优化。

  • ① 开启 Stats.js，确认瓶颈类型（GPU/CPU）
  • ② 检查 Draw Calls 数量：目标 <100
  • ③ 几何体是否重复创建？（放在组件外）
  • ④ 纹理分辨率是否过大？（>2K 需压缩）
  • ⑤ 阴影是否过于复杂？（改用 contactShadows）
  • ⑥ 移动端是否开启了抗锯齿？（关闭 antialias）
Error 4

useLoader 加载无响应

原因：URL 路径错误或跨域 CORS 阻止资源加载。

  • ① 检查 public/ 目录放置：Vite 静态资源必须放在 public/
  • ② GLTF 模型引用其他资源（纹理）时注意相对路径
  • ③ DRACO 压缩模型需要 DRACOLoader
  • ④ CORS：本地开发用 pnpm dev（Vite 自带服务器）
  • ⑤ 确认 URL 前缀：本地 /model.glb 对应 public/model.glb
Error 5

物理模拟不稳定 / 物体穿模

原因：Rapier 固定步长与渲染帧率不同步。

// ✅ 正确：物理放入 onBeforeStep
const { onBeforeStep } = useRapier()

onBeforeStep(() => {
  // 固定 1/60s 步长更新
  // 在这里施加力、检测碰撞
  playerBody.value.applyImpulse({
    x: 0, y: 0, z: -0.5
  }, true)
})

// ❌ 错误：在 onBeforeRender 中更新物理
Error 6

SSR 场景渲染错误 / window undefined

原因：Three.js 依赖 WebGL/Navigator 等浏览器 API。

// ✅ 正确：Nuxt 中使用 <ClientOnly>
<template>
  <ClientOnly>
    <TresScene />
    <template #fallback>
      <div>Loading 3D...</div>
    </template>
  </ClientOnly>
</template>

// 或在 setup 中守卫
if (process.client) {
  const { scene } = useTres()
}
