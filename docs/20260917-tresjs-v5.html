Vue + Three.js

组件式 3D 场景基础写法

用 TresCanvas / TresMesh / TresBoxGeometry / TresMeshBasicMaterial 组合出第一个 3D 场景。

基础组件

Vue 风格的 3D 场景

TresJS 将 Three.js 对象封装为 Vue 组件，模板中直接写 3D 场景，无需手动管理 WebGL 上下文。

  • TresCanvas — 画布容器，自动初始化 Renderer
  • TresMesh — 3D 物体，支持嵌套子组件
  • TresBoxGeometry — 几何体（盒子）
  • TresMeshBasicMaterial — 基础材质
// TresCanvas + TresMesh 基础模板
<!-- App.vue -->
<TresCanvas alpha="true">
  <TresMesh :position="[0, 0, 0]">
    <TresBoxGeometry :args="[1, 1, 1]" />
    <TresMeshBasicMaterial :color="'#d80018'" />
  </TresMesh>
</TresCanvas>

// main.js
import { TresCanvas } from '@tresjs/core'
createApp(App)
  .component('TresCanvas', TresCanvas)
  .mount('#app')
02
WebGPU

v5 最大升级：WebGPU 支持

Three.js WebGPURenderer 封装进 TresJS，渲染链延伸至 WebGPU，支持 Compute Shader / GPU 粒子等前沿场景。

WebGPU 场景

WebGPU 适配场景

  • Compute Shader / GPGPU 通用计算
  • GPU 粒子系统（百万级粒子）
  • 大规模实例渲染（InstancedMesh）
  • 自定义 Shader 特效
  • 实时后处理（Post-processing）
  • VFX 可视化效果
// WebGPURenderer 初始化
// 渲染链：Vue → TresJS → Three.js → WebGPU
import { WebGPURenderer, Scene, PerspectiveCamera } from 'three'

const renderer = new WebGPURenderer({
  antialias: true,
  powerPreference: 'high-performance'
})
renderer.setPixelRatio(window.devicePixelRatio)
renderer.setSize(window.innerWidth, window.innerHeight)
document.body.appendChild(renderer.domElement)

// TSL (Three.js Shading Language) 支持
await renderer.init()
const scene = new Scene()
const camera = new PerspectiveCamera(75, 16/9)
renderer.render(scene, camera)

More v5 Features

CLI / 响应式 / 事件 / Nuxt 4 / Devtools

v5 其余核心能力：create-tres 脚手架、useLoader 响应式、DOM 风格事件系统、Nuxt 4 适配、Devtools 升级。

CLI

create-tres CLI

全新脚手架命令，快速初始化 TresJS 项目，支持多种模板与技术栈。

  • npx create-tres my-3d-app
  • Vue + Vite 模板
  • Nuxt 3 / 4 模板
  • TypeScript 支持
  • Cientos 组件库
  • Post-processing 后处理
Composable

useLoader 响应式重构

资源加载返回完整响应式状态：state / isLoading / error / progress。

  • state — 加载状态
  • isLoading — 加载中布尔值
  • error — 错误信息
  • progress — 0-100 进度
Nuxt

Nuxt 4 官方适配

v5 全面适配 Nuxt 4，提供 TresJS Nuxt 模块，SSR/CSR 双模式支持。

  • Nuxt 模块自动注入

  • 组件懒加载
Events

统一事件系统

v5 事件命名与 DOM 对齐：@click / @pointerenter / @pointerleave，替代旧版 on-click。

<TresMesh
  @click="onClick"
  @pointerenter="onHover"
  @pointerleave="onLeave">
</TresMesh>

// 与 DOM 事件命名完全对齐
