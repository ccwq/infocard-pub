一眼结论

Ponytail 不是“让 AI 少说话”，而是把“先别写、先确认有没有现成答案”固化成一套可安装、可复用、可验证的规则层；真正省掉的是过度工程，不是安全、验证和无障碍。

WHAT IT IS
定位
给 AI Agent 的 YAGNI 规则层 + 安装器

尽量复用 stdlib、原生能力、现有依赖
把“能一行就别十行”落实到日常编码决策。
底线
安全、无障碍、校验、数据边界不裁剪
懒是效率，不是偷工减料。

AI INSTALLER LOOP — 采访式安装与验证
1
FETCH
让 Claude Code 读取 INSTALL playbook，而不是让用户手改碎片配置。
2
INTERVIEW
问主题、style、segments、layout、时钟与字体，自动锁定安装策略。
3
WRITE
生成 statusline 脚本、theme conf 与 settings.json 片段。
4
WIRE
把 statusLine command 接进 Claude Code / 其他宿主。
5
VERIFY
用真实 sample input 跑脚本，确认渲染和布局都可用。
纠正后的 agentic benchmark：真实任务、真实 diff、真实安全约束
旧版单次 benchmark：保留为历史对照，不再作为主指标

WHAT IT SHOWS

12 个状态片段

dir / project / git
目录、仓库名、分支、dirty、ahead/behind。
model / ctx / limits
模型、上下文窗口、5h 与 7d 限额、成本和时间。
cost / lines / duration
本次 session 成本、增删行、持续时间、stash、clock。
WHY IT IS FAST

零 token 的状态计算

本地 Bash 脚本
不打网络，不调用模型，不消耗 token。
一次 jq + 一次 git status
尽量把字段抽取收敛成单次解析。
每秒刷新
refreshInterval: 1，但不把 CPU 变成烟雾机。
CONFIG SURFACE

一份 bash 配置控制外观

VL_STYLE / VL_LAYOUT
pill 或 lean；fixed 或 auto responsive。
VL_SEGMENTS*
控制每一行显示哪些片段，最多三行布局。
VL_BG_* / VL_FG_*
256 色或 RGB，自定义主题就是改 conf。
