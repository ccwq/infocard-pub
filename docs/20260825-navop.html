01
安装

支持 Windows / macOS / Linux，提供安装包和便携版。

macOS — Homebrew
brew install navop
Linux / macOS — 一键脚本
curl -sL https://navop.dev/install.sh | bash
Windows — 下载地址
# 官网下载 .exe 安装包
https://navop.dev/download
Docker（可选）
docker pull navop/navop:latest
02
初步使用

启动后，在左侧栏选择要连接的服务类型，填入连接参数即可开始使用。

启动命令
navop

启动后界面左侧展示支持的模块入口：数据库、SSH 终端、SFTP 文件管理、远程桌面、AI 助手。

首次连接数据库示例：
1. 点击「数据库」→「新建连接」
2. 选择 MySQL / PostgreSQL / Redis 等类型
3. 填入 Host、端口、用户名、密码
4. 点击「连接」，即可在图形界面中执行查询

03
配置参数

配置文件位于 ~/.navop/config.yaml，支持以下核心参数：

参数 说明 默认值
host Navop 服务监听地址 127.0.0.1
port 服务端口号 7687
theme 界面主题（light / dark / auto） auto
ssh.timeout SSH 连接超时（秒） 30
db.pool_size 数据库连接池大小 10
ai.provider AI 助手 Provider（openai / gemini / claude） openai
ai.model AI 模型名称 gpt-4o
log.level 日志级别（debug / info / warn / error） info
启用 AI 助手：在配置中设置 ai.api_key 和 ai.provider，Navop 可在终端操作时自动调用 AI 生成建议。
04
支持特性一览

Navop 内置 8 类核心能力，统一入口，无需切换多个工具：

MySQL PostgreSQL Redis MongoDB Oracle ClickHouse SSH SFTP Terminal Remote Desktop AI 助手 服务器监控

支持同时管理多个连接，数据源之间可快速切换，适合运维人员管理多台服务器的场景。

05
适用场景
✅ 适合
  • 运维人员管理多台 VPS / 数据库
  • 需要同时操作多种数据库
  • SSH + SFTP + 终端一体化需求
  • 服务器监控 + 远程桌面
  • 希望用 AI 辅助运维命令
❌ 不适合
  • 仅需要单一数据库 GUI 工具
  • 需要 Web 界面 / 团队协作
  • 大规模集群管理（需专业 CMDB）
  • 移动端远程运维
