01项目概述

专为死磕视觉冲击和交互细节的偏执狂准备的高级动效组件库。像素级动画、流体文字特效、动态背景粒子、3D翻转卡片、鼠标交互特效，基于 React + Tailwind + Framer Motion 纯代码构建。

轻量 深度可定制 实时参数面板 一键复制 纯代码
02特效类型
💬 文字动画流体文字特效、逐字动画、渐变填充、3D文字
🌀 背景特效动态粒子场、光晕、呼吸灯、波纹背景
🧩 UI 组件3D翻转卡片、悬停效果、点击反馈、进度动画
🖼️ 背景库渐变流、噪声纹理、网格动画、星空特效
