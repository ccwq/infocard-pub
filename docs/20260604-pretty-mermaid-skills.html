Pretty Mermaid 是一个 Mermaid 图表渲染 Skill，支持 SVG（网页/文档）和 ASCII（终端）双输出。适用于 Claude Code / Cursor / Gemini CLI / OpenCode 等 AI 编程环境。
⚡ 安装
一键安装
npx skills add https://github.com/imxv/pretty-mermaid-skills --skill pretty-mermaid
验证安装：cd Pretty-mermaid && node scripts/themes.mjs（依赖自动安装）
📜 三大脚本
render.mjs
渲染单张图，支持 SVG / ASCII
# SVG 输出 node scripts/render.mjs \ --input diagram.mmd \ --output output.svg \ --theme tokyo-night # ASCII 终端输出 node scripts/render.mjs \ --input diagram.mmd \ --format ascii \ --use-ascii
batch.mjs
批量多线程渲染
node scripts/batch.mjs \ --input-dir ./diagrams \ --output-dir ./output \ --format svg \ --theme dracula \ --workers 4
themes.mjs
列出所有可用主题预览
node scripts/themes.mjs

🔧 高级选项
自定义颜色（覆盖主题）：--bg "#1a1b26" --fg "#a9b1d6" --accent "#7aa2f7"
透明背景：--transparent
自定义字体：--font "JetBrains Mono"
高级自定义（Enriched Mode）：--accent --muted --line --surface --border
ASCII 选项：--use-ascii（纯 ASCII 无 Unicode）· --padding-x 5 --padding-y 5
