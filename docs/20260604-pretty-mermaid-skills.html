⚡ 安装与起步

先装进 Skill，再用最少步骤跑起来。

一键安装必做
npx skills add https://github.com/imxv/pretty-mermaid-skills --skill pretty-mermaid
首次运行会自动安装依赖，只要机器上有 Node.js ≥ 14 即可。
验证安装检查
cd Pretty-mermaid node scripts/themes.mjs
这一步会列出全部主题，能跑通就说明 Skill 已可用。

02

📜 三大脚本怎么用

这就是 Skill 的“日常操作面板”。

render.mjs 单张渲染
给一张 Mermaid 图，输出 SVG 或 ASCII。
# SVG node scripts/render.mjs \ --input diagram.mmd \ --output diagram.svg \ --theme tokyo-night # ASCII node scripts/render.mjs --input diagram.mmd --format ascii --use-ascii
batch.mjs 批量渲染
适合把一个目录里的多张图一次性批量输出。
node scripts/batch.mjs \ --input-dir ./diagrams \ --output-dir ./output \ --format svg \ --theme dracula \ --workers 4
themes.mjs 主题预览
先跑主题预览，再决定用哪种风格。
node scripts/themes.mjs
暗色优先：tokyo-night / dracula亮色优先：zinc-light / github-light
