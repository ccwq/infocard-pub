🎯一行命令渲染图表
node scripts/render.mjs \
  --input diagram.mmd \
  --output diagram.svg \
  --format svg \
  --theme tokyo-night

支持从文件或标准输入渲染，自动识别图类型并应用主题。

SVG 格式网页、文档、演示稿，适合 Web 集成与高清输出。
ASCII 格式终端输出、日志、纯文本，零依赖任何渲染器。

🎨15+ 内置主题

深色模式推荐 tokyo-night、dracula、nord；浅色模式推荐 github-light、catppuccin-latte。

node scripts/themes.mjs   # 列出全部 15 个主题
⚡批量渲染 + 多线程
node scripts/batch.mjs \
  --input-dir ./diagrams \
  --output-dir ./output \
  --format svg \
  --theme dracula \
  --workers 4

一次性处理整个目录，支持多 worker 并行加速，适合大规模文档生成管线。

🔧高级选项
  • 透明背景：--transparent 导出 PNG/SVG 无背景色
  • 自定义颜色：--bg / --fg / --accent 覆盖主题色
  • 自定义字体：--font "JetBrains Mono"
  • 纯 ASCII：--use-ascii 输出 Unicode-free 纯文本图
✨什么时候用它
  • 用户说“画一个流程图 / 时序图”
  • 用户提供 .mmd 文件或 Mermaid 代码块
  • 用户想为文档批量生成图表
  • 用户说“应用一个主题”或“美化图表”
  • 用户提到“ASCII 图”或“终端友好图表”
