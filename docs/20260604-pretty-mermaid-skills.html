Pretty Mermaid

Render stunning Mermaid diagrams as beautiful SVGs or ASCII art — one command, zero DOM. 15 themes, 5 diagram types, batch parallel rendering, designed for the AI era.

🖼 SVG + ASCII 🎨 15 主题 📊 5 图类型 ⚡ 批量渲染 🤖 Claude Code / Cursor / Gemini CLI 📦 npx skills add
01

⚡ 安装

一键安装，自动解决依赖。

# 一键安装 npx skills add https://github.com/imxv/pretty-mermaid-skills --skill pretty-mermaid # 验证安装（列出所有主题） cd Pretty-mermaid && node scripts/themes.mjs
前置依赖：Node.js ≥ 14，首次运行自动安装依赖。
02

📜 三大核心脚本

render.mjs / batch.mjs / themes.mjs 覆盖全部场景。

render.mjs
渲染单张 Mermaid 图，支持 SVG / ASCII 双输出
# SVG 输出 node scripts/render.mjs \ --input diagram.mmd \ --output diagram.svg \ --theme tokyo-night # ASCII 终端输出 node scripts/render.mjs \ --input diagram.mmd \ --format ascii \ --use-ascii
batch.mjs
批量多线程渲染，适合大量图表
node scripts/batch.mjs \ --input-dir ./diagrams \ --output-dir ./output \ --format svg \ --theme dracula \ --workers 4
🎨 themes.mjs 列出所有可用主题预览： node scripts/themes.mjs

05

🔧 高级选项

自定义颜色、透明背景、自定义字体、丰富模式。

自定义颜色（覆盖主题）：--bg "＃1a1b26" --fg "＃a9b1d6" --accent "＃7aa2f7"
透明背景：--transparent　自定义字体：--font "JetBrains Mono"
Enriched Mode（丰富模式）：--accent --muted --line --surface --border 完整控制
ASCII 选项：--use-ascii（纯 ASCII，无 Unicode）· --padding-x 5 --padding-y 5
