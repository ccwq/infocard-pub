🧵 Skill Card · Pretty Mermaid

Pretty Mermaid

一个面向 AI 助手的 Mermaid 图表渲染 Skill：一键安装、单图渲染、批量渲染、主题切换、ASCII 终端输出。适合 Claude Code、Cursor、Gemini CLI、OpenCode、Codex 等环境。

🖼 SVG + ASCII 🎨 15 主题 📊 5 图类型 ⚡ 批量渲染 📦 npx skills add 🤖 AI 编程助手
01

⚡ 安装与起步

先装进 Skill，再用最少步骤跑起来。

一键安装必做
npx skills add https://github.com/imxv/pretty-mermaid-skills --skill pretty-mermaid
首次运行会自动安装依赖，只要机器上有 Node.js ≥ 14 即可。
验证安装检查
cd Pretty-mermaid node scripts/themes.mjs
这一步会列出全部主题，能跑通就说明 Skill 已可用。
仓库记忆长期记忆
  • 仓库：imxv/Pretty-mermaid-skills
  • 安装命令：npx skills add ... --skill pretty-mermaid
  • 模板目录：assets/example_diagrams/*.mmd
  • 官方文档：SKILL.md / README.md
02

🧠 这个 Skill 怎么被调用

不是教你跑脚本，而是告诉你：什么场景该让 Agent 触发它。

触发信号 什么时候该用
  • 用户明确要 Mermaid 图美化、导出 SVG、换主题
  • 要把流程图 / 时序图 / ER 图做成可嵌入文档的成品
  • AI 助手需要从 .mmd 模板快速生成一张成图
  • 终端里要看 ASCII 版 Mermaid，而不是浏览器预览
Claude CodeCursorGemini CLICodex
适合对象 谁会高频用
  • 做技术文档、架构说明、接口流程的人
  • 需要把自然语言需求快速落成 Mermaid 图的 AI 编程助手
  • 想把默认 Mermaid 样式升级成可发布视觉的人
  • 需要把同一类图表在多主题间快速切换的团队
边界条件 什么时候别用
  • 如果你要的是手工排版海报，不是 Mermaid 渲染器
  • 如果输入不是 Mermaid 语法，它不会替你发明图结构
  • 如果只要最原始默认 Mermaid 效果，这个 Skill 价值不高
  • 它强在“成图”和“风格化”，不是通用图形编辑器
