查看可用模板 ls assets/example_diagrams/ # flowchart.mmd sequence.mmd state.mmd class.mmd er.mmd # 复制并修改模板 cp assets/example_diagrams/flowchart.mmd my-workflow.mmd # 编辑 my-workflow.mmd # 渲染 node scripts/render.mjs --input my-workflow.mmd --output my-workflow.svg --theme github-dark ``` ### 图类型速查 **Flowchart** — 流程图、决策树、工作流 ```mermaid flowchart LR Start([Start]) --> Input[/Input Data/] Input --> Process[Process Data] Process --> Decision{Valid?} Decision -->|Yes| Success[Success] Decision -->|No| Error[Error Handler] Error --> Input Success --> End([End]) ``` **节点形状**：`[矩形]` `([圆角])` `[[子程序]]` `[(圆柱)]]` `((圆形))` `{菱形}` `{{六边形}}` `[/平行四边形/]` `[\\梯形\\]` **连接线**：`-->` 箭头 `---` 实线 `-.->` 虚线 `==>` 粗线 `-->|文字|` 带文字 **方向**：`LR` 从左到右 `TB` 从上到下 `BT` 从下到上 **Sequence** — API 调用、交互时序、消息流 ```mermaid sequenceDiagram participant User participant Client participant Server participant Database User->>Client: Request Data Client->>Server: API Call Server->>Database: Query Database-->>Server: Result Server-->>Client: Response Client-->>User: Display Data ``` **消息类型**：`->>` 实线箭头 `-->>` 虚线箭头 `-x` 实线加叉 `--x` 虚线加叉 **State** — 应用状态、生命周期、FSM ```mermaid stateDiagram-v2 [*] --> Idle Idle --> Loading: Start Request Loading --> Success: Data Received Loading --> Error: Request Failed Success --> Idle: Reset Error --> Idle: retry Error --> [*]: Abort ``` **Class** — 对象模型、架构、类关系 ```mermaid classDiagram class User { +String id +String name +String email +login() +logout() } class Post { +String id +String title +publish() +delete() } class Comment { +String id +edit() +delete() } User "1" --> "*" Post: creates Post "1" --> "*" Comment: has User "1" --> "*" Comment: writes ``` **ER** — 数据库 Schema、数据模型 ```mermaid erDiagram USER ||--o{ ORDER : places USER { string id PK string name string email date created_at } ORDER ||--|{ ORDER_ITEM : contains ORDER { string id PK string user_id FK decimal total date created_at } ORDER_ITEM }o--|| PRODUCT : references ORDER_ITEM { string id PK string product_id FK int quantity } ``` ### 从用户需求创建 **Step 1：判断图类型** - 流程 / 决策 / 步骤 → Flowchart - API / 交互 / 时序 → Sequence - 状态 / 生命周期 → State - 对象模型 / 类关系 → Class - 数据库 Schema → ER **Step 2：写出 Mermaid 代码** ```bash cat > user-diagram.mmd << 'EOF' flowchart LR A[Start] --> B{Decision} B -->|Yes| C[Action] B -->|No| D[End] EOF ``` **Step 3：渲染并迭代** ```bash node scripts/render.mjs --input user-diagram.mmd --output preview.svg --theme tokyo-night # 用户审阅，如需修改则编辑 user-diagram.mmd 后重新渲染 ``` --- ## 主题 ### 列出所有主题 ```bash node scripts/themes.mjs ``` ### 主题速查 | 主题 |
