Filee：按住 Ctrl 拖到格式上，263 种格式离线互转
桌面工具 离线 MIT @KnifeLemon

开源桌面文件转换器：按住 Ctrl（macOS 为 Option）拖文件，光标处弹出格式环，只列出对当前文件有意义的格式，松手即转，全程本机完成不上传。文档、表格、图片、HEIC、相机 RAW、HWP、电子书、音视频、字幕、压缩包、CAD、字体、3D、地理数据都在范围内；PDF→DOCX、HWP→DOCX 这类转换不要求预装 Office、Hancom 或 LibreOffice。数字口径：仓库自述 263 种格式（README 内文另有一处写 270，两处不一致，本卡取 description 口径的 263）。

  • 格式环只给能用的选项。拖的是什么文件，环上就只出现对它有意义的格式；Tab 或滚轮翻到背面，才是小众格式和工具（裁剪、拆分、合并）。
  • 复杂转换不依赖 Office。PDF→DOCX/XLSX（表格）、HWP→PDF/DOCX/Markdown、Keynote/Numbers/Pages 读入，全都不需要 Office、Hancom 或 LibreOffice 预装；只有带脚注标记的 5 类格式按需下载 Ghostscript、LibreOffice、Pandoc、calibre 或 FFmpeg 之一。
  • 入口不止一个。除拖拽外还有右键菜单、快捷键、拖放区、filee 命令行和 watch 文件夹；也能直接从 Chrome/Edge/Firefox/Safari 把图片或文件链接拖出来转，链接下载不借用浏览器登录态。
  • 联网范围写得很窄。转换离线、无遥测；联网只发生在查新（api.github.com，设置里可关）、下载更新、下载你点名的引擎和 OCR 语言包这几件事上，且下载源固定在 engines.json / ocr-languages.json。

01
格式环怎么工作：触发、过滤、翻面README「A donut at the cursor」一节与 Features 清单
1
按住 Ctrl 拖文件（macOS 是 Option）。不需要先打开 Filee 窗口，操作发生在你原本的文件管理器或桌面里。
2
光标处弹出格式环，环上只出现适用于所拖文件的格式；拖三张 PNG 和拖一个 DOCX，看到的选项不同。
3
Tab 键或滚轮翻面。环有正反两面，背面放小众格式和工具（如 Crop 裁剪切片），常用的留在正面。
4
松手落在目标格式上即转换，结果默认存原文件旁边。多文件并行处理；HWP→HWPX→DOCX 这类需要中转的路由由 Filee 自动补链。

浏览器直拖：从 Chrome、Edge、Firefox 或 Safari 里把一张图片或一个文件链接拖出来放进环，Filee 先把它存进 Downloads（可设置为只保留转换结果）再转；下载链接不经过浏览器的登录态，所以需要登录才能拿的文件不适用这条路径。

批量排队模式：General 设置里打开「Collect dropped files in a list」后，拖到 Home 的文件不再弹环，而是先进清单；用 Alt+↑/Alt+↓ 调顺序、Delete 移除，再按「Choose action」按这个顺序一次性转完，清单随之清空。watch 文件夹则是反向：凡是落进该文件夹的文件自动按预设转换，命令行版对应 filee watch。

# Windows：winget 一行安装；ARM64 设备换装 win-arm64-Setup.exe（原生运行，不走 x64 模拟） winget install KnifeLemon.Filee # 静默安装用 Inno Setup 开关；Portable 版解压即用，数据存应用旁边
# macOS：解包后跑 install.sh（自带 filee 命令），或 .dmg 拖入 Applications ./install.sh # 未公证：首次启动到 系统设置 → 隐私与安全性 → Open Anyway 放行

# 命令行与应用共用同一套引擎和预设（Setup 或 install.sh 会装上 filee 命令） filee convert photo.heic --to jpg filee convert *.png --to webp --quality 80 -o converted filee watch D:\Inbox --to pdf --move-originals # 全部命令与选项：filee help 或 filee.sh/cli

自行构建需要 .NET 10 SDK：clone 后用 pwsh build/fetch-engines.ps1 -Only rhwp,pandoc 拉指定可选引擎，然后 dotnet run --project src/Filee.App，测试是 dotnet test。README 还给了三条入口：Architecture、Engines、Adding a converter 三篇开发文档，接受 PR。

联网边界：离线转换，四件事例外README「Privacy policy」逐项

转换在本机完成、不上传文件，不收集使用数据、无遥测。README 明确列出全部联网情形，逐条如下：

查新
启动后不久及之后每隔数小时访问 api.github.com 检查新版本；在 Settings → About 关闭「Check for updates automatically」即可停用。
更新下载
只有你点 Update 时才下载，来源是 GitHub；Windows 上 GitHub 无响应时回退到 dl.filee.sh 的同一文件。
引擎与 OCR 语言包
下载你选择安装的转换引擎（engines.json 固定官方源）和预设用到的 OCR 语言（ocr-languages.json 固定）。此为 README 所述，两个清单文件本体本卡未读取。
点击链接
点击应用内链接时打开系统浏览器。除此之外 README 未列出任何其他联网行为。
