§1 引入
PAGE 01

任务管理器都是 Electron 套壳？

主流系统监视工具（Windows 任务管理器 / macOS Activity Monitor / Linux htop/top）要么是系统自带 UI，要么大量依赖 Electron/Chromium，体积臃肿、启动慢、内存高。

5MB 的 Go 原生方案——Pulse 用 MyGo 框架编写，GPU 直接渲染 UI，不嵌入 WebView，不依赖系统 webview，仅含一个 Go 二进制。窗口显示期间 CPU 占用约 3%（单核），对比 Electron 动不动 15–30% 单核占用，差距明显。

这一差距的根本原因在于渲染路径：Electron 每次启动需要初始化完整的 Chromium 进程（约 50MB+ 二进制），同时运行 JS 引擎处理 UI 渲染事件；Pulse 走 MyGo GPU 绘制路线，UI 渲染直接走显卡驱动层，中间没有 JavaScript 引擎和 DOM 树维护开销。

⚠ 数据来源5MB 安装包 + 3% 单核数据均来自 egoist 推文自述，官网未列具体数字，实测数据暂无；Pulse 未开源，无法独立复现。
§2 Pulse 是什么
PAGE 02

一台电脑在发生什么，一个平静窗口看全

Pulse（pulse.egoist.dev）是 egoist 出品的系统监视器。官网标语：「what your computer is doing」——用最少的视觉噪音，呈现最关键的运行状态。

①
进程：按 app 排序 / 搜索 / 分组，各带图标（node / claude 等），退出 / 强退 / 查看历史 + 父子进程树
②
处理器：逐核用户 / 系统时间，P 核（Performance）与 E 核（Efficiency）分开，负载与温度
③
内存与压力：Apps / Wired / Compressed / Cached 占用，内存压力指数，谁占最多 RAM
④
GPU · 磁盘 · 网络：GPU 及引擎使用率 / 每卷读写 / 每接口流量 / 谁移数据最多
⑤
能耗与热：电池健康与循环数 / 整机功耗 / 按 app 能耗 / 温度 / 谁阻止睡眠
⑥
菜单栏常驻：CPU / 内存 / 网络 / 温度一眼看，不占 Dock

三平台：功能边界不一样

🍎
macOS：全功能——电池健康 / 循环数 / 能耗传感器 / GPU 引擎，完整支持 Apple Silicon（M 系列芯片 P/E 核分离）

§4 MyGo 框架
PAGE 04

两种窗口模式，可混用

🌐 Web 模式

  • 使用 OS 自带 WebView
  • macOS：WKWebView
  • Linux：WebKitGTK
  • Windows：WebView2
  • 前端用任意 Web 工具
  • Go 代码生成 TypeScript client

⚡ 原生 UI 模式

  • 纯 Go package ui
  • MyGo 自己 GPU 绘制
  • 无 HTML / JS / WebView
  • 窗口秒开，内存极小
  • view = 状态函数（声明式）
  • Liquid Glass 玻璃效果

两者可在一个应用内混用：web 页面放在原生窗口的菜单和对话框之下。Pulse 属于原生 UI 模式。

§6 代码长什么样
PAGE 06

两个极简示例

WEB 模式：Go bind 结构体

type Greeter struct{} // Greet returns a greeting. func (Greeter) Greet(name string) string { return "Hello, " + name } func main() { mygo.Bind(Greeter{}) mygo.App.WhenReady(func() { mygo.NewWindow(mygo.WindowOptions{Title: "Hello", URL: "/"}) }) mygo.App.Run() }

原生 UI 模式：view = 状态函数

type counter struct{ n int } func (s *counter) view(c *ui.Context) { ui.Column(c).Fill().Center().Gap(12).Children(func() { ui.Text(c, fmt.Sprint(s.n)).FontSize(40).Bold() if ui.PrimaryButton(c, "Increment").Clicked() { s.n++ } }) } mygo.NewWindow(mygo.WindowOptions{ Title: "Counter", Content: ui.View(s.view), })

原生 UI：view 是带状态 receiver 的 Go 函数，ui.Column / Text / PrimaryButton 链式调用构建视图树。

§9 术语表
PAGE 09

关键词速查

WebView / WebView2
OS 内置浏览器组件，macOS WKWebView / Windows WebView2 / Linux WebKitGTK。MyGo web 模式调用它，而非内嵌 Chromium。
cgo
Go 调用 C 代码的机制。MyGo 标榜「纯 Go 无 cgo」，因此可从任意平台交叉编译到所有目标平台，无需配置 GCC 交叉工具链。
Typed IPC
MyGo 的进程间通信机制：Go 端 bind 服务，TypeScript client 自动生成类型，调用方有 IDE 自动补全和类型检查。
P 核 / E 核
Apple Silicon（M 系列）和 Intel 12 代+ 的 CPU 架构：Performance 核（高性能）/ Efficiency 核（低功耗）。Pulse 在 Mac 上分开显示两类核心的负载。
webview 压力
指 WebView 在内存受限 / 频繁刷新场景下的性能问题。Pulse 选择原生 UI 绕开此问题。
Sparkle
macOS 经典的开源自动更新框架，支持增量更新（delta update）和更新窗口控制。MyGo 发布流水线对标 Sparkle 体验。
Liquid Glass
MyGo 原生 UI 工具包提供的玻璃模糊效果插件，在全平台（macOS / Windows / Linux）提供统一的毛玻璃视觉风格。
hwmon
Linux 内核硬件监控接口（/sys/class/hwmon/），Pulse Linux 版通过它读取温度传感器数据。
