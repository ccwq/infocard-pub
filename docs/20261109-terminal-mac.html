一句话结论
terminal-mac 在 Apple Silicon Mac 的终端里跑出一个完整的 macOS，让 AI Agent 在这台虚拟机里操作桌面：宿主的鼠标、键盘、屏幕、剪贴板、麦克风和摄像头不被占用。方向可用，但它还是 early release candidate，安装走 curl|bash 且发布物自签名、未过 notarization，这三道门槛要先弄清再决定装不装。
核心要点

解决什么

Agent 要做 GUI 任务时，常和用户抢宿主的鼠标键盘。它给 Agent 一台独立虚拟 Mac，宿主的 home、项目目录、剪贴板、麦克风、摄像头不挂进虚拟机（README 自述）。

上手三道门槛

硬件限 Apple Silicon 且 macOS 14+（公众号文章没写）；安装是 curl|bash，自签名未公证；首次要在 guest 内装 TerminalMacGuest.app 并授予两项权限。

适合谁

有 Apple Silicon Mac、需要让 Agent 跑桌面级任务、能接受早期软件、磁盘有余量的人。只要命令行任务的话，更轻的方案就够。

代价

默认 64 GiB 逻辑盘，稀疏分配但随用随长；首次要下载镜像并安装 macOS，README 承认这段时间省不掉；多跑一套系统就多占处理器、内存、存储（公众号口径，磁盘部分 README 印证）。

阅读分流

到这里，装不装的第一层判断已经有了。下面逐项展开：隔离边界到底划在哪、安装脚本的具体风险口径、部署四步、Agent 接入命令，以及资源代价的边界。要动手的人重点读 §02 和 §03。

§01 / 隔离边界：Agent 在哪干活，你的东西留在哪

Agent 的点击、输入、截图动作都发生在 guest（虚拟机）里。录屏和辅助功能两项权限也在虚拟机内部授予，分别用于获取桌面画面、执行点击和输入（公众号文章口径，与 README 一致）。

README 原文口径：宿主的 home、项目目录、剪贴板、麦克风、摄像头均不挂载（Host home, project folders, clipboard, microphone, and camera are not attached）；宿主的输入与屏幕 API 不用于 Agent 动作。

guest 里的 helper 程序只在硬件型号以 VirtualMac 开头时运行。作者自述这是防止误操作物理宿主，也明说这不是“宿主已被攻破时的防线”。

归因：本节三条均为 README 自述；本轮环境不是 macOS arm64，未实测。

§02 / 上手前必知的三件事

① 系统要求（公众号缺失，本卡补齐）

README 原文：Apple silicon Mac, macOS 14 or later。安装脚本会硬性检查架构是 arm64、系统主版本 ≥ 14，不满足直接退出；打包还需要 Virtualization entitlement。Intel 机器与老系统不必尝试。

② 安装方式的真实风险

官方安装是 curl|bash，等于直接执行远程代码。README 自述 releases 为自签名、未过 Apple notarization，首次运行的 Gatekeeper 提示属预期。观察到的缓解项：脚本固定下载地址并内置 SHA-256 常量（对应 v0.2.0-6 产物），校验通过才解压；装到 ~/.local，无需 sudo，不触碰虚拟机数据目录。信任根仍在作者与 GitHub 通道。

③ 首次运行的两项授权

在虚拟机的共享目录 /Volumes/My Shared Files/tools（只读）打开 TerminalMacGuest.app，它会装进 guest 的 ~/Applications；用它的两个按钮在 guest 内部授予 Screen Recording 与 Accessibility。权限授在虚拟机里，不是宿主系统设置。

curl -fsSL https://github.com/govijr/terminal-mac/releases/latest/download/get.sh | bash

§03 / 部署概貌：一条 up 命令到首次可用
1 / 安装
get.sh 下载 zip，SHA-256 校验后装进 ~/.local
2 / 首次 up
下载 macOS 恢复镜像并安装、初始设置；README 承认这段耗时省不掉
3 / 授权
guest 内装 TerminalMacGuest.app，授予录屏＋辅助功能
4 / 复用
之后走已有 VM：数据落盘固定目录，镜像缓存与断点续传复用

“下次连接仍是同一台 Mac”是公众号说法；依据是 README 写明的持久化机制：VM 数据存放在 ~/Library/Application Support/terminal-mac/machines/NAME/，已装应用与配置的环境跨重启保留。

边界与行动 / 该不该用

满足这些条件再看

  • Apple Silicon Mac，macOS 14 或更高；
  • 需要 Agent 做桌面级任务，不只是命令行；
  • 接受自签名、早期软件，愿意先审一遍安装脚本；
  • 磁盘有余量，不介意首次下载等待。

不需要硬上的理由

  • Intel 芯片或系统低于 14：硬性检查过不去；
  • 只跑命令行任务：轻量沙箱或 CLI 方案成本更低，不必起一台完整 macOS；
  • 磁盘紧张或对未公证软件敏感：等它过 notarization、版本成熟再说。
  1. 确认硬件与系统：uname -m 返回 arm64，sw_vers 主版本 ≥ 14。
  2. 先打开 get.sh 读一遍，确认版本与哈希，再决定是否执行安装命令。
  3. 装完在终端运行 terminal-mac up，观察镜像下载与安装提示。
  4. 在 guest 内完成 Guest app 两项授权，再用 §04 的 MCP 命令接 Agent。
