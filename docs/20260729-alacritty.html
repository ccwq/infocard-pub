01 FEATURES

GPU 加速渲染 · Rust 安全底座

GPU

OpenGL 渲染管线

告别 CPU 文字渲染，用 GPU 绘制每个字符。大幅降低 CPU 占用，滚动和重绘速度提升数倍。支持平滑滚动与 Delta Row Rendering 优化。

RUST

内存安全 + 高性能

Rust 语言编写，无 GC 停顿，无运行时开销。编译为本地二进制，启动即达峰值性能，内存占用远低于 Electron 方案。

ZERO

无内置多标签/分屏

刻意不做内置 tab 或 split。专注做好一件事：渲染终端。你可以用 tmux、zellij 等外部工具实现窗口管理，保持极简设计边界。

SANE

合理默认值

开箱即用，无需配置。但所有选项（字体、颜色、快捷键、窗口参数）均可通过 alacritty.toml 完全定制，支持 live reload。

03 INSTALLATION

多平台安装

macOS

brew install --cask alacritty

# 或从源码编译
cargo build --release
./target/release/alacritty

Linux

# Arch
sudo pacman -S alacritty

# Debian / Ubuntu
sudo apt install alacritty

# Fedora
sudo dnf install alacritty

cargo

cargo install alacritty

# 需要 Rust 工具链
curl --proto '=https' \
  --tlsv1.2 -sSf \
  https://sh.rustup.rs | sh

Windows

# winget
winget install Alacritty.Alacritty

适合谁用 Alacritty？

追求极致终端性能、已在外部管理多标签（tmux/zellij）、想要完全掌控配置的开发者和运维工程师。如果你需要开箱即用的多标签和主题，选 Kitty 或 Ghostty。
