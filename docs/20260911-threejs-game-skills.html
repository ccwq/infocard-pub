01

它交付的不是一个库，而是一套游戏生产系统

POSITION

自包含 Skill

每个 Skill 自带 SKILL.md、references、checklists、prompt templates、helper scripts 和 scaffold，不依赖仓库根目录的隐藏资源。

内置游戏脚手架

Vite + TypeScript + Three.js scaffold，包含 deterministic test hooks、seeded RNG 和 smoke/visual-regression/bot-playtest 模板。

Director 路由

先加载 threejs-game-director，再按需求拉入 gameplay、graphics、UI、debug、QA、3D/image/audio specialists。

02

安装：两个 Agent 运行器，一套技能包

INSTALL

Codex

npx skills add majidmanzarpour/threejs-game-skills --skill '*' -a codex -g -y

如果本机 skills CLI 不支持目标参数，改用仓库内 ./install.sh --codex。

Claude Code

npx skills add majidmanzarpour/threejs-game-skills --skill '*' -a claude-code -g -y

也可以用 ./install.sh --claude 或 ./install.sh --all。

覆盖与清理

./install.sh --codex --force ./install.sh --all --prune-managed

默认跳过同名 Skill，不删除无关用户 Skill；force 和 prune-managed 应明确使用。

第一次不要手动运行所有 helper：打开空项目或现有 Three.js 项目，直接让 Agent 使用 threejs-game-director，让它按任务加载专家。

可选 AI 资产：没有 Key 也能继续

ASSETS

Tripo · 3D

TRIPO_API_KEY。文本/图片/多视角到 GLB/FBX，适合英雄模型、车辆、道具、建筑、武器、纹理、绑定和动画。

Gemini · 图像

GEMINI_API_KEY。概念图、纹理参考、贴图、天空、背景、图标、Logo、GUI 和标题图。

ElevenLabs · 音频

ELEVENLABS_API_KEY。SFX、环境循环、UI 声音、播报、TTS、声音转换与清理。

安全规则：API key 只放 Agent 本地环境，不提交到仓库，不放进浏览器端游戏代码。没有 Key 时，Director 应输出 credential probe 结果并回退到 procedural/local assets，而不是伪造生成成功。

07

边界：Skill 集不替你解决素材权利和真实体验

BOUNDARIES
不要把静态场景叫成游戏：README 要求 active playable loop、交互、移动端、性能和 QA 证据；placeholder cubes、generic stat-card HUD 或未经验证截图不能证明 AAA。

API 与版权：Tripo、Gemini、ElevenLabs 是可选外部服务，Key、额度、输出权利和服务条款分开核对；生成资产与音频要留下来源 ledger。

许可：仓库 MIT；这不自动授予第三方模型、图片、声音、字体或生成服务输出的版权。

最小试行：先安装全部 Skill，在空目录让 Director 建一个小型可玩循环；跑通 build、浏览器、截图、canvas pixel、移动端和 console gate，再逐步引入生成资产和高级 polish。
