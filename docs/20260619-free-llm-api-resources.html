free-llm-api-resources

这个仓库不是单个 API 文档，而是一张按服务商整理的选型地图：README 把入口分成 Free Providers 与 Providers with trial credits 两大层，明确排除不合法或逆向聊天机器人类服务。适合在真正接入前先判断“哪家能用、限额多少、要不要手机号验证、是否会共享配额”。

目录结构13 个免费入口 + 13 个试用额度入口，刚好对半。
维护方式README 由 `src/pull_available_models.py` 生成，避免手工漂移。
适用范围模型 / 网关 / 预算前的第一轮筛选，而不是大规模滥用清单。

这不是“白嫖地图”，而是“可用性地图”

README 明确提醒：别滥用这些服务，否则可能失去配额；而且它排除了不合法的服务，意味着这份清单的价值在“可信入口”而不是“灰色捷径”。

适用判断
PAGE 06

什么时候该看“trial credits”而不是 free tier

01
验证集成

如果你只是验证 SDK、模型调用、路由逻辑或 prompt 效果，试用额度通常够用。

02
短周期项目

Fireworks、Baseten、Nebius、Novita、AI21、Upstage、NLP Cloud 等更适合短期实验，不适合把“免费”误解成“无限长期可用”。
