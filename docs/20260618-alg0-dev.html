interactive algorithm canvas

把算法知识做成可播放、可导航、可双语切换的交互画布

alg0.dev 不是一页静态“算法百科”。它把算法学习做成一个可操作的播放器：左侧是可搜索的算法目录，顶部是逐步播放控制，中间是算法舞台，顶部还带 EN / ES 双语切换。它更像一个针对算法概念的交互运行时，而不是文章集合。

定位

它不是“算法文章站”，而是算法交互运行时

从首页 DOM 就能看出，它的主视图不是长文正文，而是一个全屏播放器布局：左侧算法目录、上方播放控件、中间主舞台。这说明它的核心价值是“让算法状态被播放和步进”，不是简单堆文档。

交互面

搜索、步进、速度、语言切换都在首屏暴露

  • Search algorithms侧边栏输入框直接做算法检索入口。
  • Step backward / forward算法状态可以像时间轴一样前后推进。
  • Play / Pause支持自动播放，不只是单步演示。
  • Speed速度滑条说明它把节奏本身也做成学习变量。
可访问性

不是只顾动画，也照顾键盘和 SEO

首页有 `Skip to main content`、`aria-label`、`progressbar`、`canonical`、`og:image`、`twitter`、`structured data`、`sitemap` 和 `hreflang`。这表明它不是只做 demo，而是把教育站点的可达性和分发能力一起考虑了。

多语言

不是翻译按钮，而是独立西语站点

`/` 对应英文首页，`/es/` 对应西语首页；head 中同时声明 `hreflang=en`、`hreflang=es` 与 `x-default`。这不是浏览器翻译外挂，而是有明确站点结构的双语教育产品。

公开信号站点 meta 写的是：A modern, interactive algorithm visualizer. Learn algorithms through beautiful step-by-step visualizations.
技术信号

首页是 Astro 驱动的单页交互外壳

页面源码直接暴露了 `meta generator="Astro v6.4.8"`，并能看到 Astro island hydration、CSS 资源和客户端组件加载逻辑。换句话说，它不是静态截图站，而是一个真正的前端应用壳，算法内容在这个壳里被组织、切换和播放。

学习体验

算法不是按章节读，而是按状态走

顶部的 step counter、range slider、playback controls、language switch 和 code panel toggle 共同说明：alg0.dev 试图把“理解算法”转化为一种状态机式的学习体验。你不是看解释，而是在观察状态如何推进。

一句话结论

它把算法学习做成了一块带播放器的知识画布

alg0.dev 最有意思的地方，不是把多少算法搬上网页，而是把算法目录、播放节奏、代码展开、语言切换和可访问性整合成一个统一交互面。对于算法教育产品，这种“可操作知识画布”比普通题解页更像产品。

为什么值得做卡
内容编排把算法目录组织成左侧导航 + 分类树，而不是长列表。
状态控制播放、速度、步进把“教学节奏”显式化。
双语结构独立 `/es/` 路由说明它有真正的国际化意图。
分发层OG、Twitter、canonical、sitemap 把它从 demo 提升为可被分享和索引的产品。
