Univer Office SDK · 22.3K ★ · 6 products · Apache-2.0

The Office Harness for AI Agents

把电子表格、文档、演示文稿、画板、PDF 变成 AI Agent 可编程的工作空间——浏览器和 Node.js 同构运行。

不是在线编辑器，也不是浏览器里的 Office。
Univer 是把 Office 能力封装成 SDK 的基础设施：自研 Canvas 渲染引擎（无 iframe）、插件架构（按需组合 60 个包）、Excel 兼容公式引擎，以及让 AI Agent 能直接读写单元格和文档的统一 Facade API。与 Google Sheets API 或微软 Graph 的定位不同：Univer 控制的是渲染层和数据层，不是远程 REST 调用。

插件架构

60 个包按需组合，不绑定固定 UI。每个包独立安装、按场景裁剪，适合精确控制包体积的场景。

Canvas 渲染引擎

自研渲染引擎，无 iframe 嵌入。直接在 Canvas 上绘制单元格、图形和文本，支持高精度自定义样式。

公式引擎

支持 Excel 兼容公式计算，覆盖常用函数和运算符，单元格引用、命名范围、条件逻辑均已实现。

Facade API

统一编程接口，浏览器和 Node.js 同构运行。Agent 通过 API 直接读写单元格、文档块和幻灯片，无需模拟用户操作。

Plugin Mode

完全控制，按需选择包和配置，适合需要精确组合的集成场景。

Preset Mode

预设快捷安装，适合 Sheets / Docs / Node 标准场景，开箱即用。

Headless Mode

Node.js 服务端处理，无 UI，用于自动化和批处理任务。

AI Agent 集成能力

SDK Skills：dream-num/univer-sdk-skills 提供 AI Agent 编程接口指令集，Agent 可通过自然语言调用 Office 操作。

Univer CLI：本地命令行工作空间，Agent 创建 / 编辑 / 检查 / 交付 Office 内容。

Univer Workspace：开源自托管工作空间，人和 AI Agent 共同编辑 Office 内容。

单元格绑定：指标、图表、控件绑定到单元格，支持数据读写和协作更新。

DeepSeek Harness 集成

Univer 已集成 DeepSeek Harness，Agent 可通过 AI 生成基于电子表格的 mini-app：

· 决策仪表板

· 交互报告

· 商业仪表板

AI 生成的图表和数据控件可直接绑定到单元格，形成数据驱动的动态视图。
