Supabase 是一个开源的 Firebase 替代方案，为开发者提供构建产品所需的全部后端功能。 每个项目提供运行在独立服务器上的专属 Postgres 实例，无需管理基础设施，只需调用 API。 支持自托管或使用托管云服务。

🗄️
数据库 Database
完整的 Postgres 数据库，支持 Realtime 实时功能、数据库备份、扩展等。提供专属独立服务器。

认证 Auth
邮箱密码、无密码登录、OAuth 以及移动端登录。支持 20+ 身份提供商。

存储 Storage
存储、组织、处理和分发大型文件。与 Postgres 无缝集成，支持行级安全（RLS）访问策略。

监听数据库变更，在客户端之间同步用户状态，将数据广播给订阅频道的客户端。

最短使用方式 · 一行代码接入
bash / javascript — 安装
# 安装 Supabase 客户端 npm install @supabase/supabase-js # 或使用 Supabase CLI（本地开发） npm install -g supabase
javascript — 初始化连接
// 最短接入代码 import { createClient } from '@supabase/supabase-js' // 填入你的项目 URL 和 anon key（在项目设置中获取） const supabase = createClient( 'https://your-project.supabase.co', 'your-anon-key' ) // 读取数据 const { data, error } = await supabase .from('users') .select('*') // 认证用户 const { user, session } = await supabase.auth.signInWithPassword({ email: 'user@example.com', password: 'password' })
