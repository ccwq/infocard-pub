把 LLM 训练全链路代码摊开，模块掰碎了讲给学习者

02 · 核心模块拆解
01 · FFN

前馈网络

两层全连接网络 + GeLU 激活。每个 Transformer Block 的核心计算单元，手写实现，不调用现成库。

02 · Embedding

词嵌入层

将 token ID 映射为向量。位置编码（RoPE）同期实现，模型输出前与词嵌入相加。

03 · 残差连接

Residual

每层子网络的输入直接加到输出上，解决深层网络梯度消失问题，代码中显式可见。

04 · Layer Norm

层归一化

均值为 0、方差为 1 的归一化 + 可学习仿射参数 γ、β。训练/推理行为一致，稳定梯度。

05 · Attention

多头自注意力

Query/Key/Value 分头，RoPE 旋转位置编码加到 Q/K 上，支持因果 mask（训练）和 KV-Cache（推理）。

06 · Transformer Block

组装模块

Attention → Add & Norm → FFN → Add & Norm。一个标准 Decoder Block，所有组件拼起来。

07 · GPT 模型

完整模型

Embedding → N × Block → Layer Norm → LM Head。统一接口，配置驱动，支持不同模型规模。

08 · 生成

自回归采样

greedy / temperature / top_p / top_k 采样。推理复用训练核心代码，行为完全一致。

04 · 训练阶段
阶段 目标 数据 关键配置
Base Pretrain 学习语言建模 The Pile（HDF5） n_embed、n_blocks 可配置

05 · 快速上手（Colab / Kaggle T4）
最小模型快速验证

13M 参数配置

  • n_embed = 256（Embedding 维度）
  • n_blocks = 6（Transformer 层数）
  • n_heads = 8（注意力头数）
  • Colab T4（15GB VRAM）即可训练
  • 约 1 天可见语法拼对、句子连贯
模型规模扩展路径

配置驱动，一行改模型大小

  • 小模型：n_embed=256, blocks=6（13M 参数）
  • 中模型：n_embed=512, blocks=12（~110M 参数）
  • 大模型：n_embed=768, blocks=16（~350M 参数）
  • 加 --compile 开启 torch.compile 加速
  • 加 --use_flash_attention 开启 Flash Attention
常用命令
# 预训练
python scripts/train_base.py --config configs/base.json

# SFT
python scripts/train_sft.py --config configs/sft.json

# RLHF（DPO）
python scripts/train_dpo.py --config configs/dpo.json

# 与模型对话
python scripts/chat.py --ckpt models/sft.pt --prompt "What is 13 + 29?"

# 启动可视化控制面板
pip install -e ".[ui]"
streamlit run ui/app.py
