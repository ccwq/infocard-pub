01 / IDENTITY

这个项目为什么值得做成卡

公开仓库资料显示，它已经不只是一个 extract_pdf_text 小脚本。

仓库状态

SylphxAI/pdf-reader-mcp 公开资料显示 MIT License、TypeScript/Rust 混合实现，最近发布线为 3.x。

定位

项目自称是面向 Claude、Cursor、VS Code 等 MCP client 的 PDF intelligence layer。

与旧式解析器差异

重点从“抽文本”扩展到 Agent Document Twin、证据优先、视觉 crops 与 trust reports。

02
02 / CAPABILITIES

Agent 真正会用到的能力层

把工具按“输入—证据—输出”看，比罗列函数名更有用。

可选文本

自动识别和读取 selectable text，减少把整份 PDF 直接塞入模型的浪费。

区域与视觉

支持页面渲染、区域/表格/图表/公式等 provider-ready 能力；是否启用取决于环境配置。

信任报告

项目文档提到隐藏文本、近不可见几何、off-page text 等检查，用于提示文档可能存在的证据风险。

03
03 / SECURITY

“文件不出本机”不是完整安全结论

本地优先降低了上传面，但不能替代进程、路径和 URL 安全。

本地边界

stdio MCP 仍然是本地进程；客户端配置、工作目录和权限决定了它能读什么。

URL 风险

项目资料提到 host、private-IP、size 与 HTTP policy controls；远程 URL 入口要单独审计。

版本纪律

仓库公开说明中出现 withdrawn 版本提示；生产部署应锁定明确版本并核对 release notes。
