tmux-workbench

终端工作台记忆管理器 — 索引本地与远程 tmux 会话，记住项目上下文，一键恢复开发环境

★ 10 Stars MIT License Rust tmux SSH
记忆终端工作台
Remember Your Terminal Workspaces
不替换 tmux，而是让 tmux 工作区更易查找、检查和恢复
「 SSH + tmux 很健壮，但当工作分散在多台机器和多个项目时，它记不住足够多。」
tmux-workbench 在 tmux 之上添加本地记忆层：服务器连接信息、会话快照、项目路径、git 状态、笔记、标签、归档状态……

Installation 
# Install Script (推荐)
$ curl -fsSL https://raw.githubusercontent.com/LeON-Nie-code/tmux-workbench/master/install.sh | bash

# Homebrew
$ brew tap LeON-Nie-code/tmux-workbench https://github.com/LeON-Nie-code/tmux-workbench
$ brew install LeON-Nie-code/tmux-workbench/ws

# Cargo
$ cargo install --git https://github.com/LeON-Nie-code/tmux-workbench ws
CLI Usage 
# 服务器管理
$ ws servers                    # 列出服务器
$ ws add-server prod --ssh "ssh prod"  # 添加远程服务器
$ ws add-server local-dev --local    # 添加本地服务器

# 扫描与列表
$ ws scan                         # 扫描所有服务器
$ ws list                         # 列出工作区
$ ws list --server prod             # 按服务器筛选
$ ws list --status active           # 按状态筛选
$ ws list --json                    # JSON 输出

# 工作区操作
$ ws attach prod/api               # 附加到工作区
$ ws note prod/api "使用 uv"       # 添加笔记
$ ws tags prod/api work backend     # 设置标签
$ ws status prod/api archived       # 归档工作区

FAQ

常见问题

Q: tmux-workbench 和 tmux 是什么关系？

tmux-workbench 不是 tmux 的替代品，而是 tmux 的上层工具。它索引 tmux 会话并添加元数据层，让工作区更易查找和恢复。

Q: 支持哪些平台？

支持 macOS、Linux 等 Unix-like 系统。需要 tmux、git 和 ssh（用于远程服务器）。

Q: 如何管理远程服务器？

使用系统 ssh 命令，因此现有的 ~/.ssh/config、密钥、ProxyCommand 等配置可以直接使用。

Q: 数据存储在哪里？

配置文件在 ~/.config/ws/config.yaml，数据库在 ~/.local/share/ws/workspaces.db（SQLite）。

Q: TUI 搜索支持哪些过滤器？

支持 server:prod、status:active、tag:backend、git:dirty、git:clean 等过滤器。
