# 阿斯巴甜“致癌”说法调查报告

**调查对象**：无糖可乐 / 阿斯巴甜“致癌”说法  
**调查时间**：2026-05-30  
**调查类型**：舆情核查 / 风险解释 / 传播溯源  
**结论一句话**：这条说法的真实起点是 2023-07-14 IARC 把阿斯巴甜列为 **2B 级“可能致癌”**；但这一分类并不等于“已证实致癌”。同日 FDA 明确表示 **IARC 的结论不代表阿斯巴甜与癌症已被证实存在关联**，且 **JECFA 没有下调现行 ADI**。因此，社媒常见的“无糖可乐=致癌”是把“危害分级”误读成“现实风险已确认”。

## A. 调查简报

### 1) 这条说法从哪来
- 2023-07-14，IARC 与 JECFA 围绕阿斯巴甜同时发布评估结果。
- IARC 把阿斯巴甜列入 **2B（possibly carcinogenic to humans）**。
- 这类表述在传播时很容易被压缩成“致癌”，尤其在短视频、标题党和社媒转述里。
- 同期 FDA 公布的公开说明与这一“直接等同”的说法并不一致：FDA 明确写出，IARC 的分级**并不意味着**阿斯巴甜实际上与癌症有关。

### 2) 这条说法为什么会爆
- “致癌”是高恐惧词，天然具有传播优势。
- “无糖”自带健康联想，反转感更强，冲突更容易扩散。
- “可能致癌”这一术语本身就容易被误解成“已经证明有害”。
- 公众常把 **hazard（危害）** 和 **risk（现实风险）** 混为一谈。

### 3) 关键判断
- **“2B”不是“已证实致癌”**，而是“证据有限、存在研究信号”的危害分级。
- **危害分级 ≠ 现实暴露风险**：是否真的构成风险，要看剂量、频率、日常摄入、个体情况。
- 对普通消费者而言，真正该问的是：**日常饮用是否会超过监管认可的安全摄入范围**。FDA 的公开立场是：**在批准条件下使用，未见安全担忧**。

### 4) 容易混淆的三件事
- **分类**：IARC 在做“致癌危害”分级。
- **阈值**：JECFA / FDA 在看“人会不会在现实摄入下出问题”。
- **传播标题**：自媒体常把分类直接写成结论，删掉了“可能”“分级”“现行条件”等关键限定词。

### 6) 传播路径（简化时间线）
1. **2023-07-14**：IARC/JECFA 发布评估结果。  
2. **当日及随后**：主流媒体报道“possible carcinogen”与监管分歧。  
3. **中文平台转述**：标题常被简化为“阿斯巴甜致癌”。  
4. **社媒再传播**：与“无糖可乐”“代糖”“减脂饮料”等关键词绑定，形成二次放大。

### 7) 核心证据链
1. **FDA 官方说明**：明确写出——IARC 将阿斯巴甜标为“possibly carcinogenic to humans”**并不意味着它实际上与癌症相关**；FDA 不同意 IARC 的分类；JECFA 未改变 ADI。  
2. **IARC 分级逻辑**：2B 只表示“存在一定研究信号”，不等于“现实风险已被证实”。  
3. **监管分工**：IARC 负责危害识别，JECFA/FDA 更关注摄入条件、暴露剂量与现实风险管理。  
4. **社媒传播机制**：把“危险分类”直接翻译成“致癌事实”，再配合“无糖可乐”标签，形成高传播、低精度的二次叙事。

## B. 核查清单（逐条拆解）

### 主张 1：阿斯巴甜“致癌”
- **判断**：❌ 不能直接这么说
- **原因**：IARC 的表述是“可能致癌”，不是“已证实致癌”
- **更准确表述**：阿斯巴甜被列入 2B 级别，意味着存在一定研究信号，但证据强度不足以直接下“致癌”结论

### 主张 2：无糖可乐喝了就会得癌
- **判断**：❌ 证据不足，属于夸大
- **原因**：风险取决于摄入量、频率与个体情况，不是见到成分表就自动推出疾病结果
- **更准确表述**：普通摄入量下，监管机构并未宣布其现行使用条件失效

### 主张 3：官方已经明确“阿斯巴甜有害”
- **判断**：❌ 不成立
- **原因**：FDA 原文明确表示未见安全担忧，且 JECFA 未改 ADI
- **更准确表述**：存在争议与研究信号，但监管结论仍是“按现行用法可用”

### 主张 4：只要有“可能致癌”字样就该完全禁用
- **判断**：❌ 不成立
- **原因**：很多物质在某种研究条件下都可能进入危险分类；真正的风险判断还要看暴露量、使用场景和监管阈值
- **更准确表述**：应看“现实使用是否超出安全边界”，而不是只看一个危险标签

## C. 溯源报告

### 1) 传播结构
**IARC/JECFA 公告（2023-07-14）** → **主流媒体报道** → **中文平台二次翻译成“致癌”** → **社媒把“无糖可乐”与“癌症风险”绑定**。

### 2) 为什么会被越传越硬
- **标题压缩**：长句被压成两个字的结论。
- **语义坍缩**：把“可能”“条件下”“未改变 ADI”删掉，只留“致癌”。
- **健康焦虑**：无糖饮料本来就容易被放进“是否健康”的讨论场域。
- **确认偏差**：原本就对代糖持怀疑的人，更容易接受“证实了”的版本。

### 3) 这次调查最重要的边界
- 已证实：IARC 确实给了 2B 级别；FDA 确实公开反驳了“等于致癌”的理解；JECFA 确实没有调 ADI。
- 未证实：普通人日常喝无糖可乐会显著增加癌症风险。
- 不能从分类直接推出疾病结果。

### 4) 常见误区
1. **把“可能致癌”当“已经致癌”**  
2. **把危险分级当实际暴露风险**  
3. **把监管评估当成单一结论**  
4. **把“成分表里有它”当“喝了必出问题”**  
5. **把社媒转述当原始出处**

### 5) 如果你要继续查，下一步最值得补的三个点
- 具体饮料产品的阿斯巴甜含量与每日摄入上限对照
- IARC “2B” 在历史上常见有哪些物质，避免把它神秘化
- 各监管机构对阿斯巴甜的 ADI / 安全阈值原文对照

## D. 结论

### 结论一句话
**“无糖可乐、阿斯巴甜致癌”这句话过度简化了事实：IARC 只是把它列为 2B 级‘可能致癌’，而 FDA 仍认为在批准条件下使用没有安全担忧，JECFA 也没有调整现行摄入限值。**

### 给用户的实用判断
- 如果你想要严谨表述：说“阿斯巴甜被列入 2B 级可能致癌，而非已证实致癌”。
- 如果你想要日常判断：目前公开监管口径并没有把“正常饮用无糖饮料”定义为必然高风险行为。
- 如果你想保守一点：可以减少对高频甜味剂的依赖，但不要把“看见阿斯巴甜”直接等同于“喝了会得癌”。
- 如果你要给别人解释：重点讲“可能致癌≠已证实致癌”，这是整件事最核心的误解点。
