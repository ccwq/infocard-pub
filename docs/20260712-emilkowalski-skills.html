ease-in ≠ ease-out：最常见的动画陷阱

❌ 错误示范（Agents 常见）
transition: all 0.3s ease-in;
animation: slide 0.5s ease-out;（混合用）
cubic-bezier(0.8, 0, 0.2, 1)（无意义参数）
transform: scale(1.1);（无 transition）
✅ 正确用法（Design Engineer 级）
ease-in：元素进入视图（从无到有）
ease-out：元素离开视图（从有到无）
cubic-bezier(0.33, 1, 0.68, 1)（标准 decelerate）
transform + explicit transition（始终声明）

improve-animations：8 个优化类别

Category 1

Easing Curve

自动纠正错误的 ease-in/ease-out 混用，替换为语义正确的曲线。

Category 2

Duration

判断动画时长是否合理，过快（<100ms）或过慢（>500ms）自动建议调整。

Category 3

Property

识别非 GPU 加速属性（如 left/top）的动画，建议改用 transform。

Category 4

Stagger

列表项入场动画添加 stagger delay，避免同步爆炸感。

Category 5

Scale

hover/focus 使用 scale 而非 font-size/width 变化，保持布局稳定。

Category 6

Border / Shadow

规范边框和阴影的动画方式，避免闪烁和不连贯的过渡效果。
