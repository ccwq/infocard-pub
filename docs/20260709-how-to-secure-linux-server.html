02 SSH Server Hardening · SSH 加固核心步骤
步骤内容重要性
SSH 公私钥 生成 Ed25519 密钥对，禁用密码登录，公钥写入 authorized_keys 必做
AllowGroups 白名单 创建专用 SSH 用户组，限制仅该组成员可通过 SSH 登录，禁止 root 直接登录 必做
sshd_config 加固 禁用空密码、禁用 X11Forwarding、限制 MaxAuthTries、修改默认端口、禁用 UserKnownHostsFile / StrictHostKeyChecking 推荐
移除短 DH 密钥 删除 1024-bit 以下弱 Diffie-Hellman 密钥组，强制使用 ECDHE 等强密钥交换 推荐
2FA / MFA 配置 Google Authenticator 或 TOTP，SSH 登录强制二次验证，防暴力破解 推荐 
# 1. 生成 Ed25519 SSH 密钥对
ssh-keygen -t ed25519 -C "your_email@example.com"

# 2. 复制公钥到服务器
ssh-copy-id -i ~/.ssh/id_ed25519.pub user@your-server-ip

# 3. 创建 SSH 白名单用户组并加入你的用户
sudo groupadd sshusers
sudo usermod -aG sshusers your_username

# 4. 编辑 /etc/ssh/sshd_config 启用白名单
sudo nano /etc/ssh/sshd_config
AllowGroups sshusers
PermitRootLogin no
PasswordAuthentication no

# 5. 重载 SSH 配置（保持当前连接！先测试新窗口登录）
sudo systemctl reload sshd
03 The Basics · 系统基础安全

🔒 Limit sudo / su

限制谁可以用 sudo（wheel 组），禁止普通用户 su 到 root，防范权限升级攻击。

🧱 FireJail 沙箱

用 FireJail 沙箱化运行不可信应用，网络隔离、文件系统只读、限制资源配额。

🕐 NTP 时间同步

配置 NTP 客户端确保系统时间准确，审计日志时间戳正确，防时间戳混淆攻击。

🔐 强制安全密码

配置 pam_cracklib 或 libpwquality，强制密码长度、复杂度、过期策略，定期改密。

⚡ 自动安全更新

配置 unattended-upgrades（Debian/Ubuntu）或 dnf-automatic（RHEL/Fedora），自动打补丁不发愁。

🚨 Panic Kill Switch

紧急情况下一键切断所有 SSH 会话、锁定用户账户、记录证据的应急处置脚本。

04 Ansible Playbook Support · Ansible 自动化支持

git clone https://github.com/moltenbit/How-To-Secure-A-Linux-Server-With-Ansible.git

# 编辑 inventory 配置服务器 IP
nano inventory

# 一键自动化部署所有安全配置
ansible-playbook -i inventory site.yml --ask-become-pass
