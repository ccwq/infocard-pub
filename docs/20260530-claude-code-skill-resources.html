资源补充信息

12+2 picks
Anthropic 官方 Skills
官方入口 / 基础认知
01
原帖定位

包含 skill-creator、Office 三件套等官方 Skill，是理解整个生态的起点。

重点看

官方在定义什么、如何组织 Skill、以及哪些场景已经被标准化。

skills.sh
Skill 超市 / Trending
02
原帖定位

适合快速找热门 Skill，偏“先看榜，再决定看谁”。

重点看

榜单质量、筛选维度、以及热门 Skill 的实际可用性。

skillsmp
8w+ Skill / 检索库
03
原帖定位

数量非常多，更像资源检索仓库，而不是单个作者仓库。

重点看

搜得到什么、分类是否清晰、以及重复/低质量内容的比例。

YouMind Skills
学习 / 写作 / 创作
04
原帖定位

偏学习、写作、内容创作和个人简报类工作流，属于“更像真实日常”的技能集合。

重点看

是否适合内容型用户，以及是否能减少整理和复述成本。

Figma 官方 Skill
设计系统 / 设计工作流
05
原帖定位

偏设计系统和设计工作流，说明 Skill 不只是写代码，也能进入设计协作链路。

重点看

设计资产、组件化工作流与设计到交付的链路打通方式。

Superpowers
完整软件开发方法论
06
原帖定位

一套可配置 Skill + 初始说明的完整开发方法论，偏工程执行。

重点看

它怎么把需求、任务、约束和上下文串成稳定流程。

everything-claude-code
大赛冠军配置 / 工作流参考
07
原帖定位

作者把它当作 Claude Code 工作流配置样板，适合看“别人怎么组织系统”。

重点看

工作流编排、习惯设计、和如何把 Claude 用到极致。

gstack
开发工作流 / Skill 集
08
原帖定位

偏开发流程的一组 Skill，适合关注工程效率的人。

重点看

它在开发节奏、分工和任务拆解上的组织方式。

GSD / Get Shit Done
实干导向 / 反 spec 过度化
09
原帖定位

作者强调要把东西做出来，而不是被复杂流程困住。

重点看

如何在“规范”和“执行”之间保持平衡。

MiniMax Skills
前端 / 全栈 / 多端 / Shader
10
原帖定位

覆盖面很广，说明 Skill 也可以按平台与开发方向做成大合集。

重点看

跨端覆盖和项目实用性，而不是只看数量。

李继刚 Skills
卡片 / 论文 / 学习 / 写作
11
原帖定位

偏内容整理与表达能力，适合需要持续输出的人。

重点看

文本处理、知识卡片化和写作流的具体做法。

宝玉 Skills
翻译 / 配图 / 发布
12
原帖定位

更接近内容生产与发布场景，尤其适合要落地的人。

重点看

从处理到发布的完整链路是否足够省心。

frontend-design
审美方向 / 大胆配色
13
为什么单独看

它强制跳出 AI 式安全美学，先选风格再选字体和配色，适合做设计表达升级。

重点看

它如何阻止页面变成“Inter + 灰白安全模板”。

claude-mem
长期项目 / 上下文记忆
14
为什么单独看

解决长期项目里“每次开新会话都重讲一遍”的问题，对持续项目很关键。

重点看

如何把项目结构、约定和上下文变成可持续记忆。

适合直接收藏的判断

  • 想快速建立 Claude Code Skill 生态认知的人。
  • 想找“官方入口 + 开发者方法论 + 创作者资源”的人。
  • 想把 Skill 当成工作流工具而不是目录收藏的人。

使用提醒

  • 别只看仓库名，最好再看 README、示例和工作流说明。
  • 先找最适合自己的 1–2 个，再决定要不要扩展。
  • 长期项目优先考虑上下文连续性和可维护性。
