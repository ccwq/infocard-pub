① 引入：多 agent 并行的痛点§01
  • 三四个 AI 编程 agent 并行跑，各自开一个终端窗口
  • 切来切去看「谁卡住了」「谁在等你审批」「谁跑完了」
  • 一个任务要等另一个 agent 完成才能继续，窗口切换变成瓶颈
  • 远程机器上的 agent 怎么管？用 tmux 记 session ID？
② tuios 是什么§02
  • 终端里的窗口管理器（tiling WM），内置 daemon 持久化会话
  • 内置 agent 感知层：识别面板里跑的 agent 并报告状态
  • 一个 Inbox 汇总所有会话 + 所有机器上等你处理的事
  • 支持 19 个 harness（Claude Code、Codex、Gemini CLI、opencode 等）
  • GitHub 实抓：5,135★ / 235 forks · MIT 协议 · Go 1.26.6+
  • 创建于 2025-09-06，持续活跃更新
③ 核心能力一览§03
  • 平铺面板：BSP 自动平铺 + master-stack / scrolling 模式
  • 9 个工作区：独立隔离，瞬时切换
  • vim 模态：WM 模式 / Terminal 模式 / Copy 模式
  • 命令面板：Ctrl+P 模糊搜索所有动作
  • Session Rail：侧栏显示会话 + 终端 + 文件 + git + agent 状态
  • 面板缩放：z 默认占 95% 屏，zoom_size=100 全屏
  • 应用启动器：Alt+Space 搜索 $PATH 及桌面应用
④ agent 状态感知：面板里跑的 agent 状态一目了然§04

运行 agent 的面板标题会显示形状，Session Rail 也有一行状态：

✅

  • tuios integration install：接入 19 个 harness（Claude Code、Codex、Gemini CLI、opencode 等）
  • 检测 24 个 agent CLI：按进程名 + 屏幕内容自动识别 ❓

  • tuios status working --app build --progress 40：手动上报进度
⑤ Inbox：所有会话所有机器等你处理的事，一处汇总§05
1Prefix+i 打开 Inbox，列出所有会话 + 所有机器上的审批/提问/错误/完成事件
↓Prefix+o 直接跳转到最老的待处理项
2在 Inbox 里直接回答 prompt，无需切换到那个面板
↓回复被标记为 verified，agent 知道你本人确认过
3[agents.approvals] 配置节：一键批准 Claude Code / opencode / Kilo / Qwen Code 的权限请求
agent 间通信
  • tuios ask-human：向 Inbox 提固定选项问题
  • tuios send-agent-message：agent 之间互发消息
  • tuios ask-agent：向指定 agent 提问并等待回答
Pane Grants 权限分层
  • read / write / fan / respond / admin：细粒度控制 agent 面板能做什么
  • --grants：给助手更少的权限
⑥ Fleets 与多机管理：一个 prompt 发给多个 agent / 远程 SSH 会话§06

🚀 tuios fan · 并行舰队

  • 一个 prompt 同时发给多个 agent（可混 harness）
  • 每个 agent 在独立 git worktree 里运行
  • tuios start-agent 启动单个助手（TUI 或 headless ACP）
  • 选择器如 group:fan/retry needs:you 可对整组操作

🖥 Machines · SSH 远程会话

  • tuios hosts add <name> 添加远程机器（SSH）
  • tuios hosts tailnet 列出 Tailscale 网络上的机器
  • tuios attach --host build api 把远程会话拉到本地显示
  • Global Sessions：一个会话跨多台机器

🔗 跨机 agent 操作

  • tuios fan --host build 在远程机器上启动舰队
  • tuios start-agent -s build:api 远程启动单个 agent
  • 远程 Inbox 项会出现在本地 Inbox
  • tuios worktree pull 把远程 worktree 拉回本地
⑦ 会话存活与布局模板§07

🛡️ daemon 模式

tuios 默认 attach 到 daemon 会话，断开终端窗口会话依然存活。tuios new mysession 创建命名会话。

tuios attach mysession
tuios ls · tuios kill-session mysession

🔄 重启复活

daemon 重启或机器重启后，会话带着结构和工作目录复活。Inbox 会提示恢复正在运行的 agent 对话。

📐 布局模板

Ctrl+B, L, s 保存当前窗口布局（含工作目录和启动命令）。

Ctrl+B, L, l 加载
tuios layout list
tuios layout export mysetup

⑨ 术语表§09 · glossary
平铺 WM自动分割屏幕，不重叠。tuios 默认 BSP（Binary Space Partitioning）。
daemon后台守护进程，终端窗口关闭后会话继续存活。
PTYPseudo-Terminal，tuios 为每个面板创建的虚拟终端。
BSPBinary Space Partitioning，二叉树结构递归划分屏幕区域的平铺算法。
harnessagent 的执行框架（如 Claude Code、Codex），tuios 通过 integration 与之对接。
worktreeGit 概念，tuios fan 让每个 agent 在独立 worktree 里隔离开发。
OSC 7501程序状态报告协议，任意程序可向终端/tuios 广播自身进度。
ACPAgent Communication Protocol，agent 间通信协议（tuios ask-agent/send-agent-message）。
Prefix组合键前缀，默认 Ctrl+B（可自定义）。
Session Railtuios 侧栏，汇总会话/终端/文件/git/agent 状态。
