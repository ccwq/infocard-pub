核心定位

不是通用提示词模板，每个智能体都有独立人设、专业工作流程和明确交付物。例如安全工程师会按 OWASP Top 10 逐项审查代码；小红书运营专家会输出完整种草笔记策略和达人合作方案。

搭配 agency-orchestrator 编排器，一句话即可让多个专家按 DAG 自动协作。

# 一句话激活多智能体协作 npm install -g agency-orchestrator # 或下载桌面客户端（macOS/Windows/Linux） # https://github.com/jnMetaCode/agency-orchestrator/releases

268 AI 专家 18 种工具 53 中国原创 MIT 编排器 DAG

四类代表角色：人设 → 工作流 → 交付物

安全工程师

人设：应用安全审查者。工作流：按 OWASP Top 10 逐项检查、做威胁建模、输出风险优先级。交付物：代码审计结果与修复建议。

前端开发者

人设：现代 Web 实现者。工作流：围绕 React/Vue、UI 实现与性能优化拆任务。交付物：可运行的 Web 界面与性能改进清单。

小红书运营专家

人设：平台内容策略师。工作流：种草策略 → 笔记产出 → 品牌调性把关 → 数据复盘。交付物：内容策略、达人合作方案与复盘报告。

上位机工程师

人设：工业 HMI 专家。工作流：Qt/QML 界面配合 QSerialPort、Modbus/CAN 与 QChart。交付物：工业上位机方案与通信/可视化实现。
