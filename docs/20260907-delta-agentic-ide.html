■ 五大核心能力

01 · 对话即上下文

Thread-as-Context

DeltaDB 将聊天与代码永久绑定，每行代码可追溯当时的 Prompt 和 Agent 推演过程，推理链路不再断档。

02 · 多人实时协作

Multiplayer Threads

发送链接，同事即可围观 Agent 写代码，实时评论、接管任务。浏览器端是 Rust→Wasm→WebGL 全量渲染，无需安装。

03 · 外部 Agent 接入

External Agent Bridge

支持直接接管 Claude Code 等外部 Agent，终端会话实时同步到 Delta 线程，实现工具链无缝串联。

04 · 云端持续运行

Cloud Runner

Agent 可在云端独立运行，关闭笔记本后对话与代码仍保持同步，随时随地接续工作流。

05 · 评论锚定演进

Contextual Comments

评论直接附加到对话或代码行，随着代码演进评论自动跟随，不丢失关联，协作反馈始终精准。

■ 核心优势

可追溯 Code Review

不再从冷 diff 开始，Agent 推理全程可追溯，每行代码都能还原当时的决策过程。

协作前移到编写中

团队协作从 Commit 后提前到编写中，实时围观、评论、接管，无需等待 Pull Request。

第三方 Agent 无缝衔接

与 Claude Code / Codex / Grok 等第三方 Agent 无缝衔接，工具链不割裂。

Git 工作流零侵入

队友无需使用 Delta，正常 Git 工作流不变，Delta 只在协作层叠加价值。
