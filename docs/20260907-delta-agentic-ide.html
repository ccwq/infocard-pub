01核心能力定位
持久态 Agent 上下文

与每次对话重置的 Copilot 不同，Delta 在整个项目周期内保持 Agent 状态，代码生成带项目记忆，不丢上下文。

内置工具调用

Agent 可直接调用浏览器、搜索引擎、文件系统等工具，不需要手动复制粘贴工具输出；结果自动回注到对话上下文。

双向人机协作

Agent 提出方案后暂停等待人工审核；用户可以批准、修改或重定向，Agent 根据反馈继续执行。

自演进 Skill 系统

安装 Marketplace 技能或自定义技能，Agent 自动学习并在后续任务中调用，类似"学会使用工具"的能力积累。

精细化代码理解

使用针对代码理解微调的模型，理解项目结构、依赖关系和架构模式，不是通用 LLM 的粗粒度代码补全。

本地优先 Privacy

项目数据默认保存在本地设备，不强制上传云端；企业场景可配置私有部署。

04典型使用场景
大型重构任务

需要跨多文件、跨多层依赖的修改，Agent 有完整项目上下文，不需要每次手动说明背景。

新成员 onboarding

把项目交给 Delta，新成员通过 Agent 问答理解架构和逻辑，Agent 回答带项目真实上下文。

自动化测试生成

Agent 理解代码后生成测试用例，在 Checkpoint 人工确认覆盖范围，持续迭代。

文档自动维护

代码变更后 Agent 自动更新 README、API 文档和 Changelog，保持文档与实现同步。

代码审查辅助

Agent 预审 PR，标注潜在问题、重构建议和安全风险，审查者聚焦业务逻辑判断。

AI Agent 工具

作为其他 AI Agent 的工具，提供持久态项目理解和代码执行能力。

05许可证与边界

许可证：专有 / Freemium 模式；具体授权条款需查阅官方最新文档。

数据边界：本地优先不代表数据永不离开——确认企业部署方案的数据流和合规要求。

Skill 安全：自定义 Skill 可执行任意代码，来源可信才安装；避免执行来路不明的 Skill 脚本。

模型选择：Delta 默认使用自微调代码模型，也支持接入外部模型 API；不同模型能力有差异，验收时需确认。
