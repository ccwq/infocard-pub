01先选哪条路径：精修还是快出
一句话判断

Subtitle Edit 适合要“校得准、调得细、翻得多”的情况；PotPlayer 适合要“装好就跑、快速出 SRT”的情况。前者像字幕工作台，后者像播放器里的快捷工厂。

Subtitle Edit 负责什么

准备工作、引擎配置、波形频谱、时间轴校对、导出多种字幕文件，适合把字幕做成可复查的成品。

PotPlayer 负责什么

播放器里直接下载 Whisper 引擎和模型，选择输出语言，一键生成字幕并拖进视频预览，适合快产出。

02两套工具的职责分工

Subtitle Edit：校对台

1
定位字幕编辑 / 校对 / 翻译工作台。
2
优点波形、时间轴、翻译、导出控制更细。
3
适合场景精修长视频、多人校对、批量翻译。

PotPlayer：快出稿

1
定位播放器内快速字幕生成。
2
优点操作轻、门槛低、出 SRT 快。
3
适合场景临时出稿、快速预览、轻量本地处理。
最佳实践：先用 PotPlayer 快速跑通“有字幕”，再把需要精修的片段丢进 Subtitle Edit 做时间轴与翻译校对。这样效率最高。
03Subtitle Edit 详细 SOP

准备工作

1
GitHub 下载最新版先拉最新发行版，避免旧版本菜单路径不同。
2
安装 FFmpeg 组件用于音视频解码与频谱处理。
3
切换中文界面先把界面语言改成中文，后续操作更稳。

模型配置

引擎Whisper XXL
模型选择按 GPU 显存下载对应体积，显存越小越要保守
下载阶段首次联网，下载完即可离线工作

执行步骤

A
生成波形频谱图先看波形与噪声位置，方便判断分句边界。
B
导入视频转文本用 Whisper 引擎先出初稿，再补人工校对。
C
校对时间轴对齐句首句尾、断句和停顿，修正错位字幕。
D
导出文件可导出 SRT / ASS 等标准格式，便于平台或剪辑软件继续使用。
Subtitle Edit 的价值：不是“能生成”，而是能校准。如果你在意时间轴、翻译质量、字幕格式兼容性，这条路径更稳。

PotPlayer 的优势在于少点几步就能得到可用字幕，适合临时出稿、快速验收、或者先把视频上的字幕“跑出来”。

PotPlayer 的价值：是“够快、够轻、够本地”。如果你不想开独立字幕编辑器，它是最短路径。
05应用场景与最佳实践

绕过限制

把导出的 SRT 导入剪映的“本地字幕”，即可免费使用特效，不必依赖在线字幕服务。

平台发布

标准字幕格式可直接上传到 YouTube 等平台，适合公开分发。

多语翻译

Subtitle Edit 内置自动翻译功能，适合把一条母语字幕扩成多语种版本。

最佳路径建议

先看硬件：GPU 显存决定你能下多大的模型；再看网络：首次配置必须联网下载；最后看流程：音频全程本地处理，别把素材交给第三方云端。

使用顺序建议

如果目标是“尽快可用”，先 PotPlayer；如果目标是“上线前把字幕做准”，再把成品丢给 Subtitle Edit 复核、翻译、导出。

06约束与注意事项

硬件匹配

必须根据电脑 GPU 显存选择模型体积，显存太小容易崩溃或卡死；不要盲目上最大模型。

网络要求

首次安装引擎与模型要联网，模型下载完以后，后续字幕处理可完全离线进行。

隐私安全

音频全程本地算力处理，不上传第三方云端；这也是这套 SOP 的最大价值之一。

导出格式

优先保持 SRT 作为通用交换格式；如果后续要保留样式或多轨信息，再考虑 ASS 等格式。
