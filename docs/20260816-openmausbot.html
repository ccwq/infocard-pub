01它解决的不是“多开窗口”

模型按 Bot 选择

官方 README 描述了按 Bot 切换模型的 provider rail；默认模型与不可用 provider 在界面中区分。

权限变成决策卡

Shell 命令、文件编辑和问题会以 Allow / Deny / answer 卡片出现，用户保留最后审批权。

工具连接复用

通过 Composio Connect 连接 Gmail、Slack、GitHub、Notion、Linear 等应用；具体目录与账号条款需单独核对。

02架构：App 不直接承载 Agent 协议
01React App聊天界面、模型选择、computer panel
02Harness注册驱动、管理实例与统一事件总线
03Drivers把不同 CLI / JSON-RPC / ACP 归一化
04Approval把高风险动作返回给人确认
03能力与边界
维度官方资料确认不要直接推断
平台macOS、Windows；Ubuntu 24.04 x64 为 beta不等于所有原生能力在 Linux 都可用
电脑操作支持云端 Linux desktop；本地 Mac 能力有描述不要把“可连接 computer”写成完全无人值守
数据harness、transcript、keys 以本地优先为设计目标第三方 Composio / Box 仍有独立账号和条款
成熟度README 明确标注 Early but real，并列出 rough edges不应包装成稳定企业平台
04快速上手：先确认前置条件
git clone https://github.com/milind-soni/OpenMausBot
cd OpenMausBot
pnpm install
pnpm dev:server
pnpm dev
pnpm dev:desktop
官方要求 Node 24+、pnpm，以及至少一个已登录的 Agent CLI。命令仅作为卡片说明，不在本机代执行。
