验证召回，再扩大

Khoj 的价值是把长期积累的资料变成可问答的知识层，不是又一个通用聊天框。

可以云端试用，也可以 Docker/Pip 自托管；实际召回质量、成本和隐私边界仍需用自己的资料集验收。

01 / IDENTITY

它把“我以前写过什么”变成可检索、可追问的上下文

资料

官方 README 列出 PDF、Markdown、Org-mode、Word、Notion 等文档来源，也支持从互联网获取答案。

模型

可以连接本地或在线 LLM，包括 Llama、Qwen、Gemma、Mistral、GPT、Claude、Gemini、DeepSeek 等。

入口

官方列出 Browser、Obsidian、Emacs、Desktop、Phone 和 WhatsApp 等访问方式。

02 / FIRST RUN

三条路径：先体验，再决定是否自托管

CLOUD打开官方云端应用，先确认问答和资料组织方式是否适合自己。
DOCKER按官方 setup 文档下载 compose 文件，配置管理密码和服务密钥后启动。
PIP / PIPX需要 Python 环境时使用 Pip；依赖冲突场景官方建议考虑 pipx。
VERIFY看到官方日志中的 ready 信号后，用非敏感资料验证同步、召回和模型配置。

Docker 路线

mkdir ~/.khoj && cd ~/.khoj wget https://raw.githubusercontent.com/khoj-ai/khoj/master/docker-compose.yml docker-compose up

以上命令来自官方 Setup 文档；版本和镜像细节以当前文档为准。

默认访问

官方文档说明默认 Web 地址为：

http://localhost:42110

远程访问、反向代理和自定义域名需要额外配置。

首次运行边界

官方建议首次运行后重启服务，确保设置生效。不要把本卡中的占位路径直接用于生产环境。

03 / KNOWLEDGE + MODELS

资料进入系统后，还要完成两件事：同步知识、配置模型

层官方确认的能力你需要自己验收的事项
知识输入文件、文件夹、Notion、拖放文件；Desktop、Obsidian、Emacs 客户端可帮助同步。同步是否完整、增量更新是否及时、表格和图片是否可检索。
聊天模型支持 OpenAI、Anthropic、Gemini 及 Offline 模型路径。模型上下文、费用、延迟、隐私和 provider 配置是否适合你的资料。
兼容接口官方文档说明可设置 OpenAI-compatible base URL，对接 Ollama、vLLM 或 LM Studio。实际模型 schema、vision 能力、tokenizer 和 max prompt size 是否匹配。
知识边界可从自己的文档与互联网内容中寻找答案。引用是否可追溯、召回是否遗漏、敏感资料是否进入不该去的 provider。
04 / AGENTS

从“问资料”继续向上：自定义 Agent 与研究自动化

Custom agents

README 明确支持自定义 knowledge、persona、chat model 和 tools。可以为研究、写作或项目资料配置不同角色。

Semantic search

官方将 advanced semantic search 列为核心能力。它能按意义找资料，但实际召回质量必须用自己的问题集评估。

Scheduled automation

官方 README 列出重复研究自动化、个人 newsletter 和 smart notifications；具体调度方式以当前文档为准。

工程化用法：先建立一批可复现的问题和期望证据，再比较不同模型、索引策略和资料范围；不要只凭一次“回答看起来不错”扩大数据授权。
05 / PRIVACY + LICENSE

自托管给你控制权，也把运维和许可证责任带回来

隐私

官方把隐私列为自托管收益：数据可以留在私有网络，甚至在个人电脑上离线使用。实际边界仍取决于你配置的模型 provider、日志和备份。

安全配置

官方 Setup 要求设置安全的管理密码和 Django secret key。密钥应通过环境变量或安全配置注入，不能写入仓库、卡片或日志。

06 / FIT CHECK

适合谁，以及不该直接交给它什么

适合

  • 长期积累笔记、论文和项目资料。
  • 想把本地模型和云端模型放在同一知识入口比较。
  • 需要自定义 Agent、研究任务和通知。
  • 愿意维护部署、索引和权限边界。

不适合直接承诺

  • 没有任何人工复核的医疗、法律或高风险决策。
  • 期望零配置、零运维、零成本的企业知识库。
  • 还没有明确资料授权和 provider 数据边界。
  • 把语义搜索当成完整事实核查。

最小验收

  • 用 20 个真实问题测召回与引用。
  • 分别测本地、在线和 OpenAI-compatible 模型。
  • 检查增量同步、删除、备份和权限。
  • 确认 AGPL 和第三方模型许可边界。
