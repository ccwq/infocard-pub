01
FOUR RUNTIME MODES

四种运行模式

Standard（完整工具集）、Code（代码 SDK 编排）、Minimal（仅两工具，专为基准测试设计）、Creator（运行时插件实验）。

order 1

Standard

全量工具集：文件编辑、Shell、Web 搜索、技能、规划、子 Agent、工作流。

  • 完整编码 Agent 体验
  • 多轮对话 + 工具调用
  • 默认生产使用
order 2

Code

通过 Code Mode SDK 生成代码来编排多轮工具调用，比 Standard 更结构化。

  • run_code 是唯一的底层工具
  • 模型自生成执行计划
  • 适合复杂代码生成任务
⭐ 官方基准

Minimal

仅持久化 Bash + 文件编辑器两工具 — 这正是 DeepSeek V4-Pro-0813 官方代码 Agent 基准测试的框架。

  • BENCHMARK.md 记录的评估路径
  • 零干扰，最纯模型能力测试
  • 可复现官方基准
order 4

Creator

内置运行时检查插件，可在内存中测试 Cordis 插件组合，并创作自定义预设（preset）。

  • 运行时插件调试
  • 内存中插件实验
  • 自定义模式创作
02
MULTI-PLATFORM INSTALL

多平台安装方式

支持 npx 零配置、Web UI 源码构建、Python SDK、Docker 等多种入口，覆盖 Node/Python/Docker 环境。

npx · 最快

npx 零配置（无需 Node 环境）

npx @deepseek-ai/dsh web

安装最新发布包，直接打开 http://127.0.0.1:3080。无需 clone 源码，无需本地 Node.js。

pnpm · 源码开发

源码构建（开发者）

git clone https://github.com/deepseek-ai/deepseek-harness.git
cd deepseek-harness
pnpm install
pnpm run build
pnpm dsh web

克隆源码后需先 pnpm run build（社交媒体上流传的命令缺少此步）。默认分支是 master，非 main。

pip · Python

Python SDK（程序化调用）

pip install deepseek-harness-sdk

python -c "
from deepseek_harness import DeepSeekHarness
with DeepSeekHarness(provider='deepseek-official', model='deepseek-v4-flash') as h:
    r = h.run('写一个快速排序')
    print(r)
"

通过 stdio JSON-RPC 驱动，默认注入 DeepSeek 适配器。环境变量 DEEPSEEK_API_KEY / DEEPSEEK_BASE_URL 继承。

CLI

Python CLI（命令行调试）

pip install deepseek-harness-cli
dsh doctor       # 验证环境
dsh chat         # 交互 REPL
dsh chat -r      # 开启 thinking 模式
dsh validate msgs.json  # 离线合约校验
dsh estimate msgs.json  # 离线缓存命中率估算

CLI 版带 doctor（环境自检）、validate（离线消息校验）、estimate（缓存命中估算）等调试命令。

MCP

MCP Server（Claude Desktop / Cline 等）

npx -y @deepseek-harness/mcp

提供 deepseek_chat、deepseek_chat_stream、validate_message_history、estimate_cache_hit 四个工具。

Anthropic Skill

Anthropic Skill（Claude Code）

git clone https://github.com/HenryZ838978/deepseek-harness
cp -r packages/skill ~/.claude/skills/deepseek-harness

将 deepseek-harness 插件打包为 Claude Code SKILL.md，包含 10 条协议规则和 16 个协议发现点。

插件生态与市场

发布首日 GitHub 即获 27k+ Stars，#dsh-plugin 话题下 400+ 仓库。官方仅提供 GitHub 话题发现，第三方市场已自发形成。

第三方静态注册表，从 #dsh-plugin 话题中筛选真实 Cordis 插件，提供静态 install 命令，支持搜索引擎抓取。

包含 in-app 插件商店（plugin-manager）、DSh 插件脚手架（create-dsh-plugin）、兼容性 CI 和可搜索目录。

第三方桌面客户端（deepseek-harness-desktop），无需安装 Node.js 即可运行 Harness，集成插件市场、移动端控制、IM 频道。

04
CACHE OPTIMIZATION

缓存优化机制

DeepSeek V4 原生支持对话前缀缓存（Cache-aware Prefix）。Harness 通过 MCP 工具模式和会话日志进一步减少重复 token 消耗。

✅ 已支持

对话前缀缓存（Prefix Caching）

DeepSeek API 原生支持 cache-aware prefix，相同系统提示和对话前缀在多轮调用中只计费一次。Python SDK 可通过 estimate_cache_hit() 离线估算命中率。

  • 环境变量 DEEPSEEK_BASE_URL / DEEPSEEK_API_KEY 继承
  • SDK 内置 estimate_cache_hit 工具
  • CLI dsh estimate msgs.json 离线估算
✅ 已优化

MCP 工具目录缓存（rc.9）

dsh-mcp-lens v0.1.0-rc.9 新增不可变目录索引和策略视图缓存。在 10,000 工具构造下，冷启动中位数 49.7ms / 热启动 4.4ms，每次结果与未缓存基准逐字节相等。

  • 大工具列表场景（1000+ MCP 工具）显著降低 schema 序列化开销
  • 实测：1,000 工具 schema 从 674KB → 27KB（工具路由后）
  • 需安装 dsh-mcp-lens 插件
✅ 架构支持

Append-only Session Log

所有运行记录在 append-only 会话日志中，支持 resume、fork、search、replay。相同会话上下文可复用，减少重复 token 传递。

💡 建议

Claude Code 对比

Composio 横向测试（30 硬工作流，DeepSeek V4 Flash）：Claude Code 缓存命中率仅 1.5%，中位成本 $0.195/成功任务；DeepAgents 成本 $0.045，OMP 缓存 57%，Pi Agent $0.028。

已知问题

Day-1 反馈：状态层问题

2026-08-14 多个用户报告：Heavy 并发负载下，UI 渲染延迟可达 50 分钟（显示 5/9 完成，实际 9/9 已完成）。官方 Discussion #483 已记录此问题。

  • 会话持久化采用 200ms 定时器批量写入后端（JSONL/SQLite）
  • Heavy 并发时写缓冲窗口扩大
  • 异常关闭时内存尾部未 flush，历史可能丢失
  • GitHub Issues #477 / #479 已追踪
已知问题

过度验证循环 Bug

Agent 策略默认对所有非零 exit code 进行调查。grep 返回 exit code 1（无匹配）会触发自我强化的过度验证循环。

  • 实测：相同任务 61 次请求 vs 预期 32 次
  • 成本 $0.17 vs 预期 $0.05
  • 建议：使用 Standard 模式并配置 exit code 策略
