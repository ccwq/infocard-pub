05 目录使用边界

收录不等于以下

  • 背书或质量保证
  • 功能完整性声明
  • 官方推荐或排名
  • 许可或价格确认

使用前需核验

  • 工具当前状态（活跃/维护/归档）
  • 许可证（开源/免费/商业）
  • 价格与订阅模式
  • 平台支持（Web / macOS / Win / Linux）
  • 当前版本号

目录可能发生变化

  • 新增工具随时加入
  • 现有工具可能移出或重分类
  • 建议以官网 designengineer.tools 为准

关于 AI Code 工具

  • AI Code 栏为设计工程师高频使用的 AI 编程工具，不代表全部
  • 各工具对设计工程师场景的具体适用程度需自行测试
  • Claude Code / OpenAI Codex 等面向更通用场景
