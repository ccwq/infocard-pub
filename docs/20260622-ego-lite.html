01ego lite 是什么 — 不是"又一个浏览器自动化框架"

ego lite 是一个浏览器，人和 Agent 共享同一个浏览器，但各自拥有独立的工作空间（Space）。

关键区别：Browser-Use 和 agent-browser 是浏览器自动化框架——它们需要额外驱动一个浏览器，登录状态无法干净传递，你和 Agent 还会争抢同一标签页。ego lite 从设计之初就是一个让两个人共同使用的浏览器。

为什么这很重要

  • Agent 在后台的 Space 中跑任务，你的标签页不受影响
  • Agent 继承你的 Chrome 登录、Cookie、扩展和书签——无需额外登录
  • 你可以随时接管或停止任何 Agent 的 Space
  • 浏览数据完全保存在本地设备上
02六大核心特性

代码式（非 CLI）执行

能力以 JavaScript 函数暴露给 Agent，Agent 直接编写代码调用 snapshot / fill / click / wait / navigate / capture，一次输出完成多步任务，而不是"调两个命令 → 看结果 → 再调两个"的循环。复杂工作流比 CLI 方案快 2.5×，成功率更高，工具调用更少。

每个 Agent 一个独立 Space

每个 Agent 获得完全隔离的 Space。你在前台浏览，Agent 在后台工作，互不干扰。你可以随时看到哪个 Space 有 Agent 在运行，随时接管或停止。

并行多任务

每个 Space 独立运行一个 AI Agent 或一个任务，全部同时进行。Claude Code 在 10 个 Space 中并行处理 10 条线索，Codex 在另外 5 个 Space 中抓取 5 个竞品网站。它们不会碰撞，也不会偷走你的标签页。

市面上最强的页面快照

内核级定制让 ego lite 产出最高质量的页面快照（文本模型用来"看"网页的数据）。可靠处理深度嵌套 iframe 等棘手场景——这正是其他方案持续崩溃的地方。

任何 Agent 都能通过 ego-browser 驱动

ego-browser 是连接层，连接任何 Agent CLI（Claude Code、Codex、Cursor 或自定义）与 ego lite。它把浏览器暴露为一组页面内 JavaScript 工具：snapshot、fill、click、wait、navigate、capture。Agent 编写一段调用这些工具的 JS 片段，ego-browser 一次性在页面上执行。

经验积累（即将推出）

Agent 在浏览器任务上的大部分时间花在试错上。ego lite 的官方 Skill 把每次成功操作提炼为可复用工具和工作流，让后续类似任务运行速度提升最多 5 倍。

04Quick Start — 安装与首次运行

三种安装方式

1. 下载 macOS App

Apple Silicon .dmg · Intel .dmg
安装后 ego lite 自动把 ego-browser skill 添加到本机每个 Agent 的 skills 目录。

2. npx 安装 Skill

npx skills add citrolabs/ego-lite

Agent 首次运行浏览器任务时，会引导你安装 ego lite 应用。

3. 让 Agent 自己设置

// 粘贴到你的 Agent 中
Set up ego lite for me:
https://github.com/citrolabs/ego-lite
Read skills/ego-browser/references/
install.md and follow the steps.
系统支持与配置
平台
当前正式支持 macOS。Windows 和 Linux 已在路线图中，但 README 明确写的是“on the roadmap”，不是现成可用版本。
macOS 可用
配置项
最关键的配置是安装 ego lite、把 `ego-browser` skill 加入 Agent skills 目录，以及首次启动时决定是否迁移 Chrome 数据；浏览器任务通过 `/ego-browser` 触发。
技能 + Space
API Key
通常不需要单独配置 API key 才能使用 ego lite 本体；它依赖的是你已经在用的 Agent CLI / 账户体系。若你的 Agent CLI 本身需要模型 API key，那是上游 CLI 的要求，不是 ego lite 额外要求。
一般不需要
卸载
卸载通常分两层：删除 ego lite App；若只想停用浏览器能力，再把 `ego-browser` skill 从 Agent skills 目录移除即可。Chrome 数据迁移是一次性选择，不会持续上传。
App / Skill 分离
首次启动：迁移 Chrome 数据
Chrome 迁移
首次启动时 ego lite 会问你是否迁移 Chrome 数据。选择"是"，Agent 即可继承你已经登录的网站、Cookie、扩展和书签。
无需额外登录
隐私
浏览数据完全保存在本地设备上。ego lite 仅记录你是否在设置过程中选择了 Chrome 迁移。
本地优先

首次任务

// 在 Agent CLI 中输入 /ego-browser 后跟一个空格和任务描述
/ego-browser follow @ego_agent on x.com for me

Agent 拾取 ego-browser skill，在独立 Space 中打开页面，读取快照，执行操作，然后报告结果——你的标签页保持不变。
