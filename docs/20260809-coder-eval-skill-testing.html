Coder Eval：别只测模型，先测你的 Skill 是否真的被触发

UiPath 开源的评测框架：让真实 Claude Code、Codex 或 Gemini 在沙箱任务中执行，并检查 Skill、工具与工作流是否产生了结果。

01

已确认的核心事实

按官方文档、Release 或仓库 README 逐条落地。

FACT 01

事实 1

支持声明式 YAML 任务、沙箱执行、加权 0–1 评分与阈值。

FACT 02

事实 2

提供 skill_triggered 激活检查，可做 Claude、Codex、Gemini 配置的 A/B 实验。

FACT 03

事实 3

支持 Token、工具调用与成本遥测，并可接入 GitHub Actions 作为质量门禁。

02

落地时不要混淆

把工具能力、项目自述和可验证边界分开。

BOUNDARY 01

边界 1

Skill 评测的关键不是“文件存在”，而是任务运行时是否激活了它。

BOUNDARY 02

边界 2

tempdir 不是安全边界；执行不可信任务应使用容器驱动。

BOUNDARY 03

边界 3

项目要求 Python 3.13+，生产 CI 应固定版本。
