02 核心优势
  • 🌐
    跨平台聚合，根治孤岛效应
    一条管道打破兴趣孤岛。在 B 站看三年机械键盘，小红书完全不知道——OpenBiliClaw 让画像跨平台流动。
  • 🔮
    主动探索，而非被动匹配
    协同过滤永远推"没人走过的路"。它会。猜测你可能喜欢却从未接触的领域，猜对升级为正式兴趣，猜错安静退出。
  • 🔐
    100% 本地私有
    行为数据、推荐数据、对话数据全部留在本机 SQLite，配置与凭据只存本地文件。无云端账号，画像只有你自己能看。
  • 🧬
    五层灵魂画像
    事件→偏好→觉察→洞察→灵魂。深入分析行为背后的人格特质与深层心理需求，理解"你为什么喜欢"而非"你看过什么"。
  • 🧩
    DeepSeek Harness 插件
    注册 22 个 Agent Bridge 工具。边用 DSH 干活边刷跨平台内容，边干活边发现灵感。
