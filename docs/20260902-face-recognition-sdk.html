Face Recognition SDK

把人脸处理留在本地

面向 Windows/Linux 的 Python 人脸检测、关键点、特征提取与相似度比较 SDK。

核心判断：本地处理降低数据外传面，但不消除生物特征数据的合规、误识别和留存风险。

能力清单

检测

从图像中定位人脸并返回边界框。

关键点

提取面部关键点，支持后续对齐或分析。

特征与比对

生成 embedding 并计算两张脸的相似度。

运行环境

Windows/Linux，Python 3.9+，GPU 可选，README 提供 Anaconda 与 requirements 安装路径。
