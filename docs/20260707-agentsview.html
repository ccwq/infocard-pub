All-in-One AI Coding Agent 会话管理与成本分析平台

AgentsView 是一个本地优先的会话搜索、分析与 Token 消耗统计工具，支持 Claude Code、Codex、OpenCode 等 20+ 主流 AI 编码 Agent。一个二进制文件，无需账号，无需联网，数据全留本地。

PG · DuckDB可选后端
Web UI本地访问

Agent 管理 会话搜索 Token 成本 本地优先 跨平台 Self-Hosted Tauri 桌面 Docker 部署
01 CORE FEATURES · 核心功能
🔍
跨 Agent 会话搜索
FTS5 全文索引，一次搜索覆盖所有已接入 Agent 的历史会话，支持正则与模糊匹配。
📊
Token 消耗统计
按日/周/月/项目维度拆分 Token 使用量与估算成本，告别月末账单惊喜。
💰
多 Agent 成本对比
Dashboard 直观对比不同 Agent 的使用频率与费用占比，辅助选型决策。
🗂️
20+ Agent 支持
Claude Code / Codex / OpenCode / Forge / Devin CLI / Goose / GooseFX / Continue / Aider / Cursor / Tabnine / Augment / Sourcegraph Cody / CodeCraft / Zed AI / LlamaAgent 等。
🏠
本地优先架构
SQLite 本地归档，零账号、零云依赖。S3 兼容存储可用于团队共享。
🐳
多后端存储选项
SQLite（默认）、PostgreSQL（团队共享）、DuckDB（分析镜像）、Quack（远程 DuckDB 协议）。

03 QUICK START · 快速上手
// Install · 安装
# macOS / Linux
curl -fsSL https://agentsview.io/install.sh | bash

# Windows
powershell -ExecutionPolicy ByPass -c "irm https://agentsview.io/install.ps1 | iex"

# Homebrew
brew install --cask agentsview

# Docker
docker run --rm -p 127.0.0.1:8080:8080 \
  -v agentsview-data:/data \
  -v "$HOME/.claude/projects:/agents/claude:ro" \
  -e CLAUDE_PROJECTS_DIR=/agents/claude \
  ghcr.io/kenn-io/agentsview:latest
// Serve & Use · 启动与使用
agentsview serve               # 启动前台 Web 服务 → http://127.0.0.1:8080
agentsview serve --background  # 后台守护进程
agentsview serve status       # 查看运行状态
agentsview serve stop         # 停止服务
agentsview session list      # 列出所有会话
agentsview usage daily        # 每日成本摘要
agentsview token-use          # Token 使用明细

# 首次运行自动发现本机所有 Agent 会话，同步至 SQLite 数据库
