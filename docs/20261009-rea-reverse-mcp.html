FAQ · 常见问题
任何 agent 都能用？
任何支持本地 MCP 协议的 agent 均可，包括 Claude Code、Codex、Cursor、Gemini CLI 等。
原生分析需要什么？
需要 Hopper / Ghidra / IDA 之一。setup 时 REA 可自动安装 Hopper（macOS 首跑可能弹 license 对话框），Ghidra/IDA 用已有安装即可。
JS / .NET 分析需要引擎？
不需要。静态 JS 和 .NET 程序集分析只读文件、不运行应用，无需任何逆向引擎。
数据安全吗？
⚠️ 应用从不离开你的机器。全在本地分析，agent 模型 provider 自有数据政策适用。
更新方式？
rea update 或 npx rea-agents@latest setup
