Agent Harness

LazyCodex 将 OmO（oh-my-openagent）打包为 Codex 插件，提供完整的 AI Agent 编排能力：项目记忆、规划、执行、验证完成。

⚡

零配置体验

一行命令安装，无需全局 npm，没有复杂配置。始终使用 npx，始终保持最新。

🔧

技能系统

内置丰富的技能库：代码审查、AI 残留清理、UI/UX、严格编程规范、LSP、AST 结构搜索等。

COMMANDS

核心命令（以 $ 开头调用）

命令 语法 功能
$init-deep $init-deep 生成层次化项目记忆（AGENTS.md），为未来 Agent 提供代码地标。
$ulw-plan $ulw-plan "要构建的内容" Prometheus 战略规划器，将计划写入 plans/<slug>.md，不触碰产品代码。
$start-work $start-work [plan-name] [--worktree <path>] 执行计划直到每个复选框完成，打印 ORCHESTRATION COMPLETE。
$ulw-loop $ulw-loop "任务" [--completion-promise=TEXT] [--strategy=reset|continue] 自引用循环，直到 Oracle 验证完成。Ultrawork 模式上限 500 次，普通模式 100 次。

MODEL ROUTING

多模型智能路由

OmO 不盲目使用最强模型。根据任务类型自动选择最合适的模型，实现配额纪律。

模型 定位 适用场景 成本
GPT-5.2 (xhigh) 前沿推理 复杂逻辑、深度推理、代码审查、bug 发现 💰💰💰
GPT-5.3-Codex Codex 优化 SWE-Bench Pro、Terminal-Bench 2.0、OSWorld 验证任务 💰💰
GPT-5.4-mini 高效日常 小型编辑、计算机使用、子 Agent 任务 💰
