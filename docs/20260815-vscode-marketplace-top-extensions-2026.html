01 市场总览 Market Overview · VS Code Marketplace
VS Code Marketplace — 全球最大开发者扩展生态
📦 60,000+ 扩展 🌍 marketplace.visualstudio.com 📊 extensionstats.dev / vsx-pulse.org 🔄 数据截至 2026-08

VS Code 的扩展生态是开发者工具市场的晴雨表。Marketplace 聚合了 GitHub、OpenAI、Anthropic、Google、Microsoft 等头部厂商的 AI 编码助手，以及 Prettier、ESLint、GitLens 等经典开发工具。截至 2026 年 8 月，仅 VS Code 扩展安装量就已超过 7.7 亿次（仅统计有公开安装数的扩展）。

除官方 Marketplace 外，Open VSX（Eclipse 基金会托管的开源替代注册表）也提供了大量 extensions，支持 VS Code 及 VSCodium 等兼容编辑器，两个生态合计覆盖 16,600+ 扩展。
