MCP SERVER · MOBILE AUTOMATION

Mobile MCP：让 AI 助手直接操控你的手机

Mobile Next 出品的 MCP 服务器：给 Claude Code、Codex、Gemini、Copilot 这类 AI 助手装上"手"，直接操作 iOS 模拟器/真机、Android 模拟器/真机。优先读无障碍树而不是截图，省 token、输出结构化。

官方入口：github.com/mobile-next/mobile-mcp · Apache-2.0 · npx 一行接入 · 6.4k stars（2026-09-08）

01 / 解决什么问题

AI 没有"手机的手"

LLM 能写代码，但验证一个 App 的真实流程要人手点。Mobile MCP 把设备操作暴露成 MCP 工具，让 Agent 自己完成。

截图方案太烧 token

默认优先读平台无障碍树拿结构化 UI 信息，截图只做兜底——输出确定性强，成本还低。

本地设备不够用

接 Mobile Next Cloud 可以远程租真机：iOS/Android 实体设备独占使用，本地零环境配置。

一行接入

stdio 模式 npx 直接跑；也可 --listen 起 SSE 服务器共享给团队，配 Bearer 鉴权。

02 / 平台支持

目标支持前置条件
iOS 模拟器✅Xcode + 已启动的模拟器（xcrun simctl）
iOS 真机✅USB 连接并信任设备
Android 模拟器✅Android SDK + 运行中的模拟器（adb）
Android 真机✅adb + USB 调试已授权
云端真机✅Mobile Next Cloud 账号，远程独占租用

03 / 能干什么

设备管理

列出可用设备、读写屏幕方向、设置 GPS 模拟位置、读写剪贴板。

App 操作

列出/启动/终止 App，从 .apk/.ipa 等文件安装、按包名卸载。

屏幕交互

截图、列出屏幕元素及坐标、点击/双击/长按/滑动、屏幕录制存视频。

输入导航

输入文本、按系统按键（HOME/BACK/音量）、在设备浏览器打开 URL。

04 / 接入配置

{
  "mcpServers": {
    "mobile-mcp": {
      "command": "npx",
      "args": ["-y", "@mobilenext/mobile-mcp@latest"]
    }
  }
}

Claude Code、Codex、VS Code、Windsurf 等主流 MCP 客户端按同样结构配置即可；SSE 共享模式加 --listen，鉴权设 MOBILEMCP_AUTH。

隐私提示：默认收集匿名使用遥测（PostHog）。介意的话一行环境变量关闭：
MOBILEMCP_DISABLE_TELEMETRY=1 npx @mobilenext/mobile-mcp@latest
使用边界：它能真操作你的设备和账号——在真实设备上跑自动化前想清楚授权范围；云真机是独占租用，涉敏感账号自担风险。
