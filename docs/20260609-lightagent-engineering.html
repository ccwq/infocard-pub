LightAgent · 工程模块

Skill、MCP、记忆与多智能体协作引擎

LightAgent 是一个模块化 AI Agent 框架，核心工程能力：可组合 Skill 系统、MCP 协议集成、长期记忆管理和 LightSwarm 多智能体编排。

Skill 系统 MCP 协议 记忆管理 LightSwarm
Langfuse RAG 向量检索 多智能体
一句话：把 AI Agent 拆成可插拔的工程模块

LightAgent 不只是"调用 LLM"，而是通过 Skill、MCP、Memory 的组合，让 AI 具备长期上下文、工具调用和多智能体协作能力。

01
SKILL SYSTEM

Skill：可组合的工具技能

Skill 是 LightAgent 的核心执行单元，每个 Skill 包含 prompt、工具和执行逻辑，可独立运行或组合成流水线。

核心能力

Skill 定义

Skill = prompt + tools + execution logic，可独立运行或组合。

  • 结构化 prompt 模板
  • 可插拔工具集
  • 执行状态管理
复用性

Skill 市场

社区共享 Skill，涵盖搜索、代码、图像、数据分析等场景。

  • 开箱即用
  • 版本管理
  • 按需组合
编排

Skill 流水线

多个 Skill 可串联成流水线，实现复杂任务的分工与协作。

  • 串行执行
  • 条件分支
  • 结果传递
02
MCP PROTOCOL

MCP：模型上下文协议集成

MCP（Model Context Protocol）是 LightAgent 与外部工具/数据源交互的标准协议，实现工具调用的标准化。

协议层

MCP Server

每个 MCP Server 对应一个工具集，支持文件系统、API、数据库等外部资源。

  • 标准化接口
  • 动态发现
  • 安全沙箱
关键价值：MCP 让 AI Agent 可以"即插即用"外部工具，不需要为每个工具单独写适配代码。

对比传统方式：传统 API 调用需要硬编码；MCP 则是声明式工具发现与调用。
03
MEMORY SYSTEM

记忆：长期上下文管理

LightAgent 内置多层次记忆系统，支持短期会话、长期向量检索和结构化知识图谱。

01 / 短期

会话记忆

当前对话上下文，自动管理历史消息窗口。

基于 Token 窗口限制的动态截断与压缩。

02 / 中期

向量检索

RAG 架构，支持语义相似度检索历史经验。

可配置嵌入模型和向量数据库。

03 / 长期

结构化记忆

知识图谱 + 实体关系，支持复杂推理。

可导出为配置文件，实现跨会话持久化。

04 / 可观测

Langfuse 集成

全链路追踪：prompt 版本、Token 消耗、延迟。

支持问题追溯和性能优化。

04
LIGHTSWARM

LightSwarm：多智能体编排

LightSwarm 是 LightAgent 的多智能体编排引擎，支持角色分工、信息路由和协作决策。

1

角色定义

每个 Agent 有独立 Skill 集和 prompt，可扮演专家、助手、审核等角色。

2

信息路由

支持广播、点对点、层级汇报等多种消息路由模式。

3

协作决策

多 Agent 可投票、共识或委托的方式做出群体决策。
