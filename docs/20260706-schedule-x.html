核心技术点

Temporal API · 零依赖 · 暗色模式 · 国际化 · Premium 扩展

T
Temporal API 底层驱动 v3 起全面切换到 ECMAScript Temporal，替代传统 Date，支持 ZonedDateTime、PlainDate、Instant 等精确类型，跨时区计算零误差。
0
零依赖核心包 @schedule-x/calendar 无任何运行时依赖，体积紧凑，Tree-shaking 友好，按需加载视图插件。
◑
一键暗色模式 calendar.setTheme('dark') 即可切换深色主题，也支持跟随系统自动切换。
中
开箱即用中文国际化 内置 zh-CN 语言包，配置 translations 字段即可，无需手动翻译所有标签。
★
Premium 扩展功能 Resource View（资源调度视图）、Scheduling Assistant（智能排程助手）、iCal 导入，付费解锁，详细定价见官方。
📅
内置拖拽缩放（无需插件） 事件拖拽移动、边界调整等交互均为内置功能，无需额外安装拖拽插件。

快速上手

安装 → 配置 → 渲染，三行代码出日历

安装
# 核心包（零依赖） npm install @schedule-x/calendar @schedule-x/theme-default
基础用法
import { createCalendar, createViewDay, createViewWeek, createViewMonthGrid } from '@schedule-x/calendar' import '@schedule-x/theme-default/dist/index.css' const calendar = createCalendar({ views: [createViewDay(), createViewWeek(), createViewMonthGrid()], events: [{ id: 1, title: '项目评审', start: '2026-05-24 10:00', end: '2026-05-24 12:00', }], }) calendar.render(document.getElementById('calendar')) // 一键暗色模式 calendar.setTheme('dark')
Vue 3 示例
import { createCalendar, viewMonthGrid } from '@schedule-x/vue' // <ScheduleXCalendar :config="config" />

Premium 扩展

付费功能解锁，定价见 schedule-x.dev

Resource View

垂直资源视图 + 时间网格，会议室、设备、人员等多资源可视化调度，支持拖拽分配与冲突检测。适合 OA、HR、物业管理等场景。

import { createViewResource } from '@sx-premium/resource-scheduler' import '@sx-premium/resource-scheduler/index.css' const resourceView = createViewResource({ resources: [ { id: 'room1', label: '会议室A', color: '#4285F4' }, { id: 'room2', label: '会议室B', color: '#34A853' }, ], })
Scheduling Assistant

AI 辅助排程助手，智能推荐可用时间段，自动规避冲突，快速生成多人会议时间表。

iCal 导入

支持 .ics 文件一键导入，将外部日历事件同步到 Schedule-X，支持 Google Calendar / Outlook 导出格式。
