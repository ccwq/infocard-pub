核查发现
✗ 夸大部分

"八成"数字来自特定低端项目或国产芯片场景，不能代表整体。全国880万机架仍在高速扩张，上架率62%+，并非全面闲置。

✓ 真实部分

企业级通用算力中心利用率确实只有10%-15%；部分智算中心国产芯片闲置率高达80%；结构性闲置问题真实存在，并非谣言。

✓ 头部效应

西安昇腾智算中心利用率98.5%；中卫集群上架率77%；国家级/头部大厂智算中心接近满负荷，与"八成闲置"说法形成鲜明对比。

王记者结论

"中国算力中心八成已闲置"是夸大其词的结构性误读。

真实情况是：存在严重的结构性分化——企业级/中小型/低端智算中心利用率极低（10%~30%），而国家级枢纽节点和头部大厂智算中心基本满负荷。"八成"数字来自部分低端项目或特定国产芯片场景，不能代表整体。

算力闲置的本质是：政策驱动下的超前建设 + 国产替代生态不完善 + 应用场景培育滞后，而非中国算力整体失败。
