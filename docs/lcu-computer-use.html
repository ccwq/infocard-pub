LCU — 把 Codex 的 Computer Use 运行时解耦出来，任意 Agent 工具都能用

无需 Codex 账号，直接复用本机 ChatGPT 桌面版的 CUA 运行时，通过 MCP 接入 Claude Code、Pi、Codex CLI 等主流 Agent 工具。

Codex 的 Computer Use 运行时被锁在 Codex App 里。
LCU 把它解耦出来：只要本机装了 ChatGPT 桌面版，模型就能通过 cua 对象操作桌面——任何支持 MCP 的 Agent 工具都能接入，无需 OpenAI 账号，也无需运行 Codex App。

MODEL TOOLS模型只用两个工具：写 JS + 必要时重置

工具 1 js — 执行 JavaScript

模型在 cua 对象上调用方法写代码：cua.getState() 获取状态、cua.click(selector) 点击、cua.typeText(text) 输入、cua.pressKey(key) 按键、cua.getScreenshot() 截图。一次调用可组合多个操作并读取返回值。

工具 2 js_reset — 重置 JS 环境

清空 JavaScript 执行环境，变量全部清除，cua 对象重新初始化。运行时出错或状态异常时使用。

CUA OBJECTcua 对象可用方法

getState() getApp(appName) click(selector) typeText(text) pressKey(key) getScreenshot()

运行时不出 LCU 的适配层。截图、无障碍访问、输入事件全部由官方 CUA 运行时处理，LCU 只做设置和协议转发。

⟳

状态持久化：一次 js 调用中定义的变量会保留到下一次 js 调用。调用 js_reset 后清空。

PLATFORM支持与不支持的平台

✓ 支持

  • macOS Apple Silicon需 ChatGPT 桌面版 + 辅助功能权限 + 屏幕录制权限
  • Linux ARM64 / x86-64Ubuntu 24.04 兼容 glibc + X11 桌面 + D-Bus

✗ 不支持

  • Windows 11候选功能，未完成
  • Intel Mac不支持
  • Wayland 桌面不支持
  • musl Linux不支持

APPROVAL操作审批与安全机制

Native Approval 面板

运行 lcu setup --agent claude-code 安装 lcu-approve 小插件，在 Claude App 内展示原生 Computer use approval 面板。

只有用户本人能响应批准提示；模型无法看到、点击或伪造该面板。

lcu apps 查看已批准应用 lcu apps allow <app> Touch ID 授权 lcu apps revoke <app> 撤销授权

Chrome 浏览器支持

需开启 OpenAI 官方 Chrome 扩展，每个网站需单独批准授权。

前提条件：Chrome 扩展权限 + per-site approval。模型无法绕过用户审批。

INSTALL三种安装方式

方式一：Claude Code 插件

通过 Claude plugin marketplace 安装，自动配置 MCP 适配层。

claude plugin marketplace add amontlabs/lcu
claude plugin install lcu@lcu

方式二：Agent 引导安装

把一段提示词贴给 Agent，Agent 读取 docs/INSTALLATION.md 完成配置。

# 参考 docs/INSTALLATION.md
# Agent 读取后自动执行配置步骤

方式三：手动下载

从 GitHub releases 下载平台对应 tar.gz，并做 sha256 校验。

curl -LO https://github.com/amontlabs/lcu/releases/latest/download/lcu-linux-x86_64.tar.gz
sha256sum -c lcu-linux-x86_64.tar.gz.sha256
