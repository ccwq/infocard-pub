一句话判断：vibe-coding-cn 不是零散资料，而是一套从想法到产品的 AI 结对编程工作流标准：把 AI 编程拆解为 Prompt / Skill / Workflow / Context / Quality Gate 五层，每层有明确的定义、作用和门禁。
01 · 五层核心框架
Core Layers
💬 01 Prompt 一次性指令
解决单次对话的表达问题
⚡ 02 Skill 可复用能力
解决高频任务的稳定执行
🔄 03 Workflow 可执行流程
解决复杂项目的推进问题
🧠 04 Context 可持续上下文
解决长期协作的信息丢失
🚫 05 Quality Gate 测试 / CI / 脚本 / 类型 / 清单
解决 AI 输出不可验证问题
关键判断这五层不是并列关系，而是递进依赖：没有 Prompt 质量就没有 Skill 基础，没有 Skill 积累就没有 Workflow 可执行，没有 Workflow 就没有 Context 管理需求，没有 Context 就没有 Quality Gate 的意义。
