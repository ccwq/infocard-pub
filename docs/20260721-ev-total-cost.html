04

成本拆解：行驶成本看边际，使用成本看年度预算

折旧是低里程家用车的最大单项；高里程运营车折旧被摊薄但维修频率上升

日常通勤 · 中位

行驶 0.14 · 使用 1.15元/km

行驶成本：能耗0.058 + 保养0.035 + 耗材0.05 = 0.14元/km。
使用成本：再加保险0.200 + 折旧0.77 = 1.15元/km。

关键：折旧是最大单项，固定成本在低里程时被放大。

高频运营 · 中位

行驶 0.17 · 使用 0.57元/km

行驶成本：能耗0.067 + 维修0.044 + 耗材0.06 = 0.17元/km。
使用成本：再加运营保险0.100 + 折旧0.27 = 0.57元/km。

关键：高里程摊薄折旧，但轮胎和维修消耗速度同步上升。

运营场景：低成本不等于高利润

本文按车辆成本，不计算司机收入与平台账

网约车数据只能作量级参照

公开司机案例给出6年60万km约0.53元/km车辆成本；另有案例给出日均300–400km、运营保险约1万元/年、电费与维修预算。但这些不是统一行业统计，且可能遗漏空驶、平台抽成、停车、违章、租金和司机劳动价值。

计入本文

  • 夜间谷电
  • 高里程折旧
  • 运营保险
  • 保养、轮胎、小修预留

明确排除

  • 停车、过路费、洗车
  • 平台抽成与空驶率
  • 贷款/租车利息
  • 司机时间与社保
06

尾部风险：动力电池不能平均摊成一个“必然成本”

过保后可能是数万元级支出，但不应无证据年年计入

公开汽车之家及行业内容对比亚迪动力电池更换费用的说法从1–3万元到4.5–5.3万元不等；2026年公开报道列出元PLUS 51kWh整包约4.5–5.3万元，但尚未取得比亚迪官方全国统一价目表核验。

处理方式：不把换电池费用平均摊入本文四个基准场景；若车辆过保、发生严重电池故障，应以授权服务中心按电池版本、故障范围、质保条件报价。

核心判断
