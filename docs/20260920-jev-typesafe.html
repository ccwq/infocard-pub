Jev是 TypeSafe AI 出品的新型 AI 模型，用 RLCD（Reinforcement Learning for Calibrated Decisions）训练，专注于毫秒级判断而非对话生成。与传统 LLM 不同，Jev 不生成自由文本、不写代码、不写文章——它只做决策。

01 · RLCD：Jev 的核心创新

维度RLHFRLCD（Jev）
优化目标 人类偏好（subjective preference） 概率校准度（Calibration）：模型说 70% 有把握时，实际正确率也约 70%
训练信号 人类评分 / 偏好对比 输出答案之间的对比反馈（comparative feedback）
模型输出 自然语言（自由生成） 固定 Schema（调用者预定义结构，无法返回非法值）
延迟量级 3–329 秒（逐 token 生成） 70–500ms（并行输出所有答案）
适用任务 对话 / 生成 / 创意 判断型任务（判断 → 执行）

RLCD 技术细节

• 并行生成：不是逐 token 预测，而是在单次查询中并行输出所有候选答案

• 固定 Schema：调用者预定义输出结构，模型无法返回非法值，输出可直接驱动程序执行

• confidence 计算：选项数为 n 时，confidence = 最高概率与均匀分布的距离（1/n）

• 自动化路由：低置信度 → 自动 Escalation；高置信度 → 自动执行

Calibrated 的含义：概率校准（Calibration）≠ 准确率。模型可以在低校准下高准确，也可以在高校准下低准确。RLCD 训练模型对自身置信度诚实，使置信度值可以直接用于决策路由。

02 · System One：Kahneman 认知框架

⚡ System One（直觉系统）

快速、自动、低认知负荷的直觉判断——看见数字 2+2 即知等于 4，无需推理。Jev 定位：AI 领域的 System One，毫秒级完成判断。

🧠 System Two（推理系统）

慢速、审慎、逻辑推理——用于复杂计算、规划与创造性问题解决。传统 LLM（GPT-4、Claude）属于 System Two 类。

Jev = System One for AI 传统 LLM = System Two for AI Jev 指导 LLM 执行操作 Computer Use 操作判断层

04 · 适用场景 vs 不适用场景

✓ Computer Use 判断层 ✓ 实时快速决策 ✓ AI MapReduce ✓ AI 输入验证 ✓ Agent 判断节点 ✗ 生成自由文本 ✗ 写代码 ✗ 写文章 ✗ 开放式对话

✓ Computer Use

Jev 作为 AI 操作判断层，指导模型快速操作电脑。Codex 任务实测：速度提升 10 倍，节省大量 token。

✓ AI MapReduce

对大规模语料库进行并行分类判断。Jev 的并行输出 + 固定 Schema 使其天然适合批量判断任务。

✓ AI 输入验证

在 AI Agent 流水线中作为前置校验层，低置信度自动拒绝，高置信度放行，确保后续生成质量。

✓ Agent 判断节点

AI Agent 流程中的决策节点：判断下一步行动、路由到哪个工具、是否需要人工介入。

当前局限性：Jev 不生成自由文本、不写代码、不写文章。Early Access 阶段，需要排队申请。暂无独立第三方发布的带 ground truth 的校准可靠性图表。
