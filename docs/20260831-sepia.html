先说结论：改词为什么不够

StoryScope 论文研究的关键不是“某个词像 AI”，而是故事在更高层面做出了系统性选择：主题被 narrator 讲透、因果链过于整齐、人物选择的道德含混不足、情绪只剩身体感受、时间结构过于线性、缺少真实世界参照和读者存在感。sepia 的定位，是在动词句之前先诊断这些架构层信号。

证据边界：下方数字是 StoryScope 论文实验结果，不是 sepia 的独立检测率或“保证去除 AI 痕迹”。sepia README 声称将这些研究转化为修订协议；实际效果仍取决于文本、模型与人工判断。
01

StoryScope：论文给出的结构性证据

数据规模

10,272 个写作 prompt；每个由人类与 5 个 LLM 写作，共 61,608 篇故事，平均约 4,753 词。

结构特征

从 10 个叙事维度抽取 304 个 discourse-level features，覆盖 plot、agents、setting、temporal structure 等。

分类结果

仅使用叙事特征时，人类 vs AI 达到 93.2% macro-F1；六路作者归因达到 68.4% macro-F1。

表层编辑后

论文摘要称 style editing 后仍为 93.9% macro-F1，说明只改表层文风并未消除结构信号。

模型指纹

论文报告不同模型在叙事选择上存在差异；sepia README 将其转化为 Claude、GPT、Gemini、DeepSeek、Kimi 的校准提示。

人类分布

论文观察到 AI 故事聚集在共享叙事空间，人类故事的叙事选择更分散；原则不是机械反转。

02

三层修复流水线：先骨架，后句子

PASS 01 / FICTION
Narrative architecture

停止解释主题；放松单线因果；后置揭示；混合情绪表达；稀疏人物网络；补入真实事物与社会参照。

PASS 02 / DISCOURSE
Discourse flow

打散模板化的段落—问题序列；修复故事中段下坠；改变节奏、段落位置和信息释放顺序。

PASS 03 / SURFACE
Surface style

最后才处理陈词、句法模板、词汇、语域和格式；不把“更不像 AI”当成反向机械化目标。

操作原则：每篇小说只选 3–5 个关键动作，保留松弛度。规则全部应用会制造新的统一指纹。

review

04

专业文档：不是小说规则的复制品

体裁sepia README 的规则方向写作检查
Release notes / announcements用户影响优先；每个 claim 对应 artifact；不做营销膨胀读者能否立刻知道变化和影响？
PR / issue replies先给结论；引用 `file:line`；不反射性夸赞；长度与 stakes 成正比结论、证据、下一步是否可定位？
Postmortems对人宽容、对机制无情；写清时间线、死路和负责人动作是否避免甩锅，同时明确系统缺陷？
Tickets / work orders标题即结果；验收标准可测试；用链接而不是重复上下文别人能否据此执行并判断完成？
Technical articles从问题开篇；保留一个真实死路；给出一个明确立场；数字带条件是否有问题、证据、限制和判断？

06

不能从这些资料推出什么

不是检测器保证

93.2% 是论文数据集与实验设置中的结果，不是 sepia 的实测通过率。

不是“越不像 AI 越好”

机械反转规则会制造新指纹；目标是校准到人类分布。

不是免人工判断

review 只提供诊断；文学质量、原创性和事实责任仍需作者判断。

不是绕过承诺

“De-AI writing”不应表述成规避平台检测、学术审查或作者披露义务。
