01核心定位

  • 两个使命合一：既是可用的终端 coding agent，也是一份完整的学习教材
  • 小而可读：不是生产级巨无霸，而是一个完整但足够小的代码库，适合通读理解全貌
  • 事件驱动 Harness：核心层不依赖 Textual / Rich / 配置文件，前端消费事件，架构干净
  • 流式输出：Tau 在流式传输行为的同时保持持久会话历史

02关键设计

  • AgentHarness：可复用的脑子，与具体前端解耦，可接入 CLI、TUI 或 API
  • CodingSession：coding agent 环境，包含工具注册、会话管理、项目上下文
  • Provider 中立：tau_ai 统一封装各模型 Provider，支持切换不同 LLM
  • Skills 系统：项目级指令（类似 CLAUDE.md），slash commands 支持
  • 磁盘持久化：会话保存在本地，随时恢复
