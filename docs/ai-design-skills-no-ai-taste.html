Impeccable

前端设计黑名单

蓝

Paul Bakaus（前 Google 工程师）出品。不教"怎么写好看"，而是列出 AI 生成页面的廉价感、模板感、AI 味全部黑名单——"不要做什么"比"做什么"更重要。

02

Taste Skill

🍽️ ⭐ GitHub 20.3K

高级感设计约束

绿

把"高级感"拆成可被模型反复执行的审美约束与排版工作流。专门对抗 AI 生成的"千篇一律界面"，让模型理解何时用衬线、何时打破网格。

npx skills add taste-sh/taste-skill
03

design-taste-frontend

🖼️ ⭐ GitHub 高热度

Anti-Slop 前端设计

紫

专门对抗 AI 前端输出的"塑料感"：禁用深色霓虹、居中卡片网格、Inter/Roboto 字体三件套，注入真实项目中的设计判断逻辑。

npx skills add design-taste-frontend
04

web-design-guidelines

📐 Vercel Labs

UI/UX 设计规范

橙

Vercel 官方 Skills 目录收录，涵盖间距系统、色彩对比度、响应式断点、可访问性标准。AI 生成界面时自动套用专业设计规范。

npx skills add vercel-labs/agent-skills --skill web-design-guidelines
05

frontend-design

⚛️ Anthropic 官方

Anthropic 前端设计系统

黄

Anthropic Claude Code 官方 Skills，内置组件库规范、CSS 原子化策略、动画时序标准。让 AI 生成的前端代码与专业设计系统无缝对齐。

npx skills add anthropics/skills --skill frontend-design
为什么 AI 味挥之不去？
  • 配色永远是"深色背景 + 霓虹点缀"
  • 字体永远是 Inter 或 Roboto
  • 布局永远是居中对齐卡片网格
  • 圆角、渐变、阴影按模板堆砌

→ 解决方案：给 AI 装上设计 Skill，把审美规则交给模型
