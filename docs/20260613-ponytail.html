决策阶梯
how it works
1
需要存在吗？

先问这行代码是否真的必要（YAGNI）。

2
标准库有吗？

用 stdlib，不重复造轮子。

3
平台原生？

用浏览器、操作系统内置功能。

4
已有依赖？

用项目中已安装的库。

5
一行能写？

能一行就不写十行。

6
最后：最小可行方案

以上都不行才自己写。

底线：信任边界验证、数据丢失处理、安全与无障碍永不在裁剪范围内。

CSV sum / email validator

简单数据处理：正则或一行 JS，不上库。

countdown / rate limiter

标准库 `Date.now()` 或简单闭包搞定，不引入额外依赖。

安装方式
install
Claude Code

/plugin marketplace add DietrichGebert/ponytail

/plugin install ponytail@ponytail

Codex

codex plugin marketplace add DietrichGebert/ponytail

然后 /plugins 安装，/hooks 授权

Pi agent

pi install git:github.com/DietrichGebert/ponytail

OpenCode

opencode.json 加 plugin 路径，auto-load AGENTS.md

Cursor / Windsurf / Copilot / Cline / Aider / Kiro：直接复制对应 rules 文件即可（.cursor/rules/、.windsurf/rules/、.clinerules/、.github/copilot-instructions.md 等）。
CLI 命令：`/ponytail` 启动，`/ponytail-review` 审查 diff 中需要删除的代码，`/ponytail ultra` 超严格模式，`/ponytail-help` 查看更多。
