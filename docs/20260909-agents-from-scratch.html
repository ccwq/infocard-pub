大多数 LangChain 教程止步于"调用 API"，真正教会你从零构建生产级 Agent 的少之又少。LangChain 官方团队开源的 Agents From Scratch，是一套完整的hands-on教程，手把手带你从 Agent 基础到 Gmail 邮件助手生产部署，每一步都有真实代码。

为什么这是目前最值得跑的 LangChain 教程

这套教程的核心价值在于全链路 + 可跑通：不是碎片化的概念演示，而是从环境配置到生产部署的完整流程。4 个 Jupyter Notebook 循序渐进，每个阶段都有配套 Python 源码（位于 src/email_assistant/），可以直接在本地跑起来。

第一阶段：Agent 基础

LangGraph 核心概念：State、Node、Edge。构建邮件分类与路由（triage），接入 SERP 和 Search 工具。输出：email_assistant.py

第二阶段：Agent 评估

用 LangSmith evaluate API + LLM-as-judge 评估回复质量。Pytest 自动化测试 + eval/email_dataset.py 数据集。输出：可复用的评估流水线

第三阶段：人机协作

关键操作（发送邮件、安排会议）需人工确认。用 Agent Inbox 作为 HITL 界面。输出：email_assistant_hitl.py

第四阶段：记忆机制

LangGraph Store 长期记忆，用户反馈持久化。最终集成 Gmail API，输出生产级邮件助手

技术栈与工具链

  • LangGraph：Agent 编排核心，StateMachine 架构
  • LangChain：工具调用、Prompt 管理
  • LangSmith：评估与可观测性（evaluate API）
  • Gmail API：真实邮件操作（发送/读取/日历）
  • Agent Inbox：人机协作界面
  • Jupyter Notebook + Python：全程可跑

谁适合学习

  • 已掌握 LLM API 调用，想系统学 Agent 开发原理的工程师
  • 想从"调用 API"升级为"构建 Agent 系统"的开发者
  • 需要构建企业内部邮件助手、客服机器人的实际项目负责人
  • 对 LangChain/LangGraph 感兴趣，想通过完整项目学习而非碎片化文档的学习者

如何开始

教程分 4 个 Section，每个 Section 有对应的 Notebook + 配套源码：

  1. Email Triage + Agent：LangGraph 基础，邮件分类路由器 → agent
  2. Evaluation：用真实邮件数据集 + LLM-as-judge 构建评估流水线
  3. Human-in-the-Loop：接入 Agent Inbox，实现关键操作人工审批
  4. Memory + Gmail Integration：长期记忆 + Gmail API → 生产部署

每个阶段结束后，代码都在 src/email_assistant/ 目录可直接查看或修改。最终的 email_assistant_hitl_memory_gmail.py 就是可以直接部署的生产版本。

与官方 Agents SDK 的关系

本教程基于 LangChain 的 LangGraph（底层编排引擎），而非最新的 Agents SDK。教程目的不是推介某款产品，而是系统讲解 Agent 的核心概念：State 设计、Node 逻辑、Edge 路由、评估方法、人机协作模式、记忆机制。掌握这些概念后，切换到任何 Agent 框架都游刃有余。
