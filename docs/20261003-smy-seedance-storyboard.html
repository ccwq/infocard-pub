01 · 先把工具边界讲清楚

它是给大模型执行的制作规范，不是已经接通图像和视频平台的自动化服务。

从故事到施工图，不是从故事到 MP4

仓库的核心是 SKILL.md、references 手册和示例项目。它让兼容的 AI 助手分析故事、拆剧本、定色盘、列资产、写 Seedance 提示词。真正出图、上传参考素材、视频生成、配旁白和剪辑仍在外部平台完成。原文标题中的‘自动生成短剧’应读成自动生成短剧制作文档，不能理解为一键拿到最终成片。

什么人能直接获益

已有故事、但不懂怎样把文学描写转成镜头的人；准备做传统手绘动画气质的神话、寓言、英雄传奇的人；反复因角色长相、色盘、镜头风格不一致而返工的人。它的价值是把制作约束集中写入文档，降低漏项，而不是提供新的生成模型。

什么需求不适合

只想一句话立即拿到可商用视频、没有时间挑资产和剪辑的人；要求写实真人、日漫或随时换风格的人；要求无人值守批量出片的人。平台账号、生成额度、模型版本、素材权利和最终质量都不由这个 Markdown Skill 承担。

02 · 第一次怎么用：先装说明书，再给完整 brief

仓库 README 给出了调用名称，但没有正式安装器。下面区分官方命令与可执行的手工接入建议。

不要只复制 SKILL.md

主文件多次引用 references/上美影风格指南.md，明确它才是风格唯一事实来源；还会按需引用剧本标准、Seedance 手册和分镜修补指南。缺 references 的‘安装成功’只是文件存在，不代表工作流完整。仓库下载后先检查相对目录不变，再在宿主中验证 Skill 被识别；不同宿主的调用语法与发现路径可能不同。

一次给清五个参数

输入故事正文或大纲，附上子风格、集数/时长、画幅、情绪基调和一句话卖点。默认主线是手绘墨线配水粉平涂；想要水墨淡彩、剪纸、敦煌重彩、石蓝淡墨绘本必须显式点名。单剧只用一种子风格，不在不同集之间混用媒介。

把大纲确认设为停点

当前 SKILL.md 内的编剧模板要求先输出一句话卖点、故事简介、人物介绍和分集大纲，确认后再写正式剧本。这一步用于发现集数不够、人物太多、冲突不清等结构问题。不要让一个尚未确认的大纲直接扩成几十条资产提示词，否则错误会在后续每个阶段复制。

03 · 交付物：五类入口，七项完整清单

README 用五类解释用途；SKILL.md 的最终清单拆成七项。二者不是矛盾，而是粒度不同。

① 完整剧本：先定叙事，再写可拍动作

包含核心梗、故事梗概、一句话卖点、人物小传、分集大纲和正文。镜头描述以‘△ ’开头；对白分普通发言、内心独白、画外音，旁白用说书人语气。‘心里绝望’不能直接拍，应该改为表情、动作、环境与声音。源文件同时包含三幕式写作提示和起承转合的大纲展示，不应把它说成唯一固定四幕算法。

② 色盘声明：整部剧只有一份字符串

放在素材清单开头，中文与英文对应。所有资产提示词及每集视频风格首行都引用同一个色盘。不是‘大概用相同颜色’，而是统一颜色名称，避免一集写朱砂红、下一集改成橙红，模型逐次理解出不同世界。

③ 角色、场景、道具资产提示词

完整清单把它拆成三项。角色不仅有标准全身像，还有情节海报和四视图；场景要有正打、反打、侧面全景；道具白底独立展示。异兽仍用 C 编号，但采用异兽场景模板，不能把它当普通人物站姿。

④ 每集分镜提示词

每集包含素材上传映射、固定风格首行、时间轴、声音说明和参考行。编号资产必须映射到实际上传槽位；C01 并不天然等于 @图片1。先写清表格，再复制提示词，避免引用了错误角色或缺少必要背景。

⑤ 尾帧与衔接说明

记录最后一帧的主体、背景、光线、构图、氛围，同时保留色盘和风格词。下一集使用视频延长或尾帧接力时据此核对位置、朝向、状态。‘无缝衔接’是制作目标，不是仅凭文字就能保证的模型效果。

04 · 真正的核心：图片与视频使用两套风格配方

公众号把三层风格锁定说得很直观；当前风格指南增加了关键区别：生图的强硬平涂禁令不能机械套到视频。

图片端：纯平涂加硬约束

中文完整版包含传统矿物颜料纯平涂色块、概括轮廓、不完美笔触、装饰背景纹样、胶片颗粒，并明确主色。结尾保留‘必须纯2D平涂！绝对不要阴影、不要渐变、不要3D体积感！必须大面积留白！’。适用角色、场景、道具、海报与修补分镜图。

视频端：保留手绘肌理，精准反 3D

当前指南 §2.3 v3 恢复手绘墨线、水粉平涂、颜料笔触和手工感，只排除 3D 渲染、写实感、体积光。作者记录的修订理由是过度绝对化的无阴影无渐变会同时杀掉手绘肌理。视频留白随镜头构图选择，不要求每镜同样留白。这里是源文件明确的版本演进，不是本卡自行改写规则。

正文与参考图再锁一次

不能只在首行说风格，后面用长段写实动作把风格稀释。SKILL.md 要求每个时间段至少自然嵌入一个风格词，参考行尾加‘严格保持参考图片的手绘动画画风与色盘’。三层结构是首行约束、时间段强化、参考图锚定，而不是一句品牌词包办所有效果。

发现模板冲突时看谁

风格指南明确自称单一事实来源；随仓库附带的鲁智深 E01 仍有旧版‘无阴影无渐变’视频首行，参考行也缺新画风锁定语。可复用它的剧情和槽位映射，但新项目应换成当前指南 v3，再检查各集一致。这是已看到的源文件差异，不应把‘示例自带’当成最新规则保证。

必须纯2D平涂！绝对不要阴影、不要渐变、不要3D体积感！必须大面积留白！

# 当前视频首行（替换本剧主色与参数）
上海美术电影制片厂经典手绘动画风格，手绘墨线轮廓，水粉平涂上色、保留颜料笔触与手工感，矿物颜料色（本剧主色），概括造型，胶片颗粒感，不要3D渲染、不要写实感、不要体积光

05 · 色盘与造型：让角色跨集仍是同一个人

一致性不只靠名字。把可观察的视觉特征变成资产契约。

主四色与扩展色

基准为青瓷绿、朱砂红、鎏金、墨黑。青瓷绿承载山水和宁静，朱砂红负责冲突与主体强调，鎏金用于神性与宝物，墨黑用于轮廓及强对比。按题材最多加两种扩展色：如赭石表达大地悲壮、藤黄表达烈日灯火、月白表达月光雾气、绛紫表达妖异。点缀色也占扩展色名额。

每个角色一个主色和纹样

人物小传的视觉形象字段写年龄、身材、服装、鞋子、脸型、眼睛、线条粗细、专属颜色与纹样。云纹、回纹、水纹、火焰纹等承担识别作用。只写‘威猛男子’不足以锁定角色；镜头变了仍要保留服装结构、主色和轮廓标记。

比例与标准像

源文件推荐成人 5–7 头身、孩童 3–4 头身、异兽自由夸饰。这是该风格的设计约束，不是所有动画统一标准。标准资产像要求正面全身、纯白背景、中性表情、双手自然下垂且不拿道具；情节海报才使用大动作和环境，避免资产本身把后续镜头锁死。

四视图最后补

先迭代稳定的标准像，再补正面、侧面、背面与脸部特写。推荐角色像 3:4、四视图 16:9 或 21:9、场景随视频画幅、道具 1:1。2K、8K 等在提示词里只是建议或描述，不代表模型实际输出规格，也不能当作分辨率测试结果。

06 · C/S/P 编号：把资产目录变成镜头依赖表

制作前查缺资产，比生成后猜为什么角色漂移更便宜。

C01–C99：角色及异兽

角色标准像、海报、四视图明确版本关系。异兽归 C 类，但要保留典籍特征和神性标记，例如角、足数、头数及鎏金部位；不能让模型随意拼装后再把错误形象拿去做一致性参考。传统题材也要区分原著内容与现代影视造型。

S01–S99：场景三机位

场景图禁止出现人物，重要位置写正打、反打、侧面全景。正反打依据角色站位和对话方向规划，侧面全景交代空间关系。若角色资产已经带场景、场景又带人物，两种参考会争夺身份与构图，难以判断哪里应该修。

P01–P99：道具独立展示

写形状、材质质感、年代、磨损和剧情用途，白底、无人物、无环境。具有身份反转或线索作用的道具应在编号中保留，不要把刀、酒碗、信件只藏进角色描述。它们在不同镜头里可能需要独立近景。

上传槽位不是资产 ID

用一张表写 @图片1 → S01、@图片2 → C01、@图片3 → S02。同一 C01 在别集可能换到 @图片1，因此每集都有自己的槽位映射表。生成前逐行核对实际上传文件名与提示词引用，避免‘表格正确、平台顺序错’。

07 · 15 秒分镜：把动作和声音装进时间轴

先约束时长，再写镜头；文学精彩不等于视频模型能拍出来。

五个时间窗口是组织模板

常用 0–3、3–6、6–9、9–12、12–15 秒分别承担建立、引入、冲突、转折、结尾。SKILL.md 另要求单镜头 2–5 秒、每集 13–15 秒、约 3–7 镜。它们是创作规格，不是平台强制精准执行的承诺。复杂动作应拆镜，不在三秒内塞进奔跑、跳跃、对话和场景切换。

动作慢，信息不能散

源规范建议手绘动画的动作写慢而具体，用 → 连接可见动作。比如‘拿起碗 → 仰头喝酒 → 放下碗’，而不是‘突然领悟命运’。慢速动作不等于剧情缓慢：用冲突前置、景别变化、反应镜头与旁白压缩背景，末尾留钩。

旁白和字幕留后期

剧本正文可以写旁白、对白和【字幕】卡点，但当前 Seedance 提示词【声音】规定只生成明确音效，不生成音乐和字幕。旁白、配乐、字幕在剪辑阶段添加。README 的英文后半仍写 music + SFX + dialogue，与当前主规范不一致，应以 SKILL 和风格指南的当前约束为准。

每段至少一个风格锚点

远景说青瓷绿群山平面层叠，近景说墨黑手绘轮廓，动作段说水粉笔触和装饰性色块。风格词应该融入画面表达，不是机械地在句尾堆十个形容词。参考行明确角色一致性、场景布局和色盘用途，避免模型误把资产图当成要原封照搬的镜头。

08 · 读一个真实仓库案例，而不是虚构测试

鲁智深示例有五集剧本和素材，但示例提示词不等于本卡现场生成了视频。

E01 的实际素材映射

仓库鲁智深 E01 将 @图片1 设为 S01 五台山文殊院远景，@图片2 为 C01 鲁智深标准像，@图片3 为 S02 山脚酒馆。0–3 秒交代群山寺院，3–6 秒进入酒馆，6–9 秒摔碗，9–12 秒醉上山路，12–15 秒消失在转角。能看到景别、动作、色盘、音效与尾帧如何对应。

五集情绪弧线有明确转场

使用指南给出醉归山门 → 怒打金刚 → 大闹禅堂 → 长老叹悟 → 拜别下山。第三集的乱接第四集的静，是动静对比；第四集保留叹息和画外喧闹形成声音留白。值得学的是每集各有情绪功能，不是把故事平均切成五段。

尾帧把下一集入口写清

E01 尾帧描述包括歪倒石经幢、空旷山路、青瓷绿群山、朱砂红墙与藤黄瓦、对角线构图和宁静中的不安；用途标明衔接 E02 的醉汉撞山门。把‘现在人在哪里、将往哪去’写出来，比一句‘继续上一集’更可检查。

先升级风格行再复用案例

案例旧风格行仍写纯2D无阴影无渐变，而当前视频 v3 已分离图片约束。复用时只替换风格首行和参考锁定，不随手改色盘与剧情。作者 README 也提供 Bilibili 测试效果链接，但本卡没有独立测量成功率、成本、耗时或帧级一致性。

09 · 跨集衔接和坏镜头修补

连续性靠参考、状态和验收，不能靠‘同一个名字’幻想它自动延续。

路线 A：延长上一集视频

第二集开始上传上一片段作为 @视频1，在提示词里写‘将@视频1延长15s’；再给本集动作、素材和情绪。这是仓库的推荐路径，是否支持及参数上限以平台当前 UI 为准。不要把它当可调用的仓库 API，也不要在没上传视频时保留引用。

路线 B：抽尾帧接力

把上一片段最后一帧作为下一片段首帧参考。核对角色朝向、道具位置、服装状态、背景大色块与镜头尺度；若新集从远景突然跳到特写，最好有叙事理由。写尾帧描述能帮助发现断点，但仍要检查实际画面而不是只验文字。

坏镜头只修最小单元

源流程为抽帧 → 改图 → 重新图生视频。动作崩坏先减少同镜动作、放慢、改成近景或反应镜头；风格漂移先确认风格块与参考图，不直接重做全剧。对白、音乐、字幕问题能后期解决时，不必因为一次视频生成把整个资产库重新抽一轮。

平台限制需现场复核

README 记录最多 9 张图片、3 个视频且总参考时长 15 秒，以及长提示词跟随不稳定等经验。这些是仓库记录的约束与经验，不是本卡对 Seedance 当前平台的独立验证。实际上传上限、时长、可用模型与审核结果以平台当前界面和文档为准。

10 · 验收清单：文档通过与成片通过分开

不要把提示词写得齐全，误报成已经验证画面。

文字层：交付是否齐

有大纲确认、完整剧本、统一中英文色盘、角色/场景/道具编号、每集素材槽位表、时间轴、声音说明、参考锁定与尾帧。检查所有镜头以△开头、所有资产 ID 能在清单找到、每集时长合计满足目标。文本 lint 只能发现漏项，不能判断画风真的达标。

图片层：先过标准像

检查角色全身与鞋子完整、白底无道具、头身比与纹样正确；场景无人物、三机位一致；道具独立且形状稳定。缩略图看整体是否手绘平面，不只放大看细节。角色标准像未稳定时停止视频生成，否则每集都会继承同一个问题。

视频层：检查真正成片

看身份连续、服装与色盘、实际动作、参考图有没有被错误复制、图层有没有变成立体光影，以及尾帧首帧是否能连接。字幕和配乐是否遗漏属于剪辑层，不让视频提示词硬做文字生成。作者宣称的双端实测只能作为作者报告，本卡没有执行付费生成。

小规模 POC 的停止条件

建议先一角色、一场景、两段短片，确认样式与接力再扩五集。保存实际输入、参考素材、模型选择和输出版本，记录返工原因，而不是只写‘好看/不好看’。不要预设成本或通过率，平台生成额度与抽样次数才是实际支出来源。
