§01
核心定位

不是"在线转语音"，而是"本地私有有声书工厂"

Audiblez 把 epub 电子书转成 .m4b 有声书，使用 Kokoro-82M 开源 TTS 模型，全部本地运行，数据不出本机

性能数据

GPU (T4 via CUDA)：约 5 分钟处理《Animal Farm》(160K 字符)，600 字符/秒。CPU (M2 MacBook Pro)：约 1 小时，60 字符/秒。

🔒 完全私有

本地运行，无需联网，无需云端 API Key，数据完全在本地处理

🎙️ Kokoro-82M

82M 参数 Apache 许可 TTS 模型，训练数据不到 100 小时，自然度高

📚 epub → .m4b

直接输出标准 .m4b 有声书格式，VLC 或任意有声书播放器可直接播放

§03
安装与入口

pip 一键安装，CLI / GUI 双入口

依赖 espeak-ng 和 ffmpeg，pip 安装 audiblez 即可

# Ubuntu / Debian sudo apt install ffmpeg espeak-ng pip install audiblez # macOS brew install ffmpeg espeak-ng pip install audiblez # Windows（建议 venv） python -m venv venv .\venv\Scripts\Activate.ps1 pip install audiblez pillow wxpython

💻 CLI 入口

基础转换：audiblez book.epub -v af_sky

调速（0.5–2.0x）：audiblez book.epub -v af_sky -s 1.5

选章节：audiblez book.epub --pick

🖥️ GUI 入口

audiblez-ui

需要额外依赖：pip install audiblez pillow wxpython

Ubuntu 额外：sudo apt install libgtk-3-dev

§05
适合 / 不适合

本地私有有声书生成 vs 需要实时流式合成的场景

作者 Claudio Santini · MIT License · 2025

✅ 适合

  • 想把 epub 书转成可听的有声书
  • 需要离线、低成本 TTS 方案
  • 注重隐私，数据不能上云
  • 有 GPU 想快速跑大批量转换

⛔ 不适合

  • 需要实时流式 TTS 的在线语音场景
  • Apple Silicon 用户（暂无 MLX 支持）
  • 需要多说话人对话式 TTS
