工作原理：Pinokio 脚本

Pinokio 脚本是 JSON 格式，声明式描述安装/启动步骤，由内置终端执行。示例（安装 Python 依赖）：

"method": "shell.run", "params": { "message": "uv pip install -r requirements.txt", "path": "server", "venv": "venv" } // → 在 ~/pinokio/api/myapp/server/venv 中执行
path 隔离
所有命令在 ~/pinokio/api// 内执行，不污染系统目录。
venv 隔离
Python 依赖装在每个应用自己的虚拟环境里，多版本 Python 共存无冲突。
包管理器集成
内置 Conda / Homebrew / pip / npm，全部默认将包装入 ~/pinokio/，不对系统级包管理器产生副作用。
权限沙箱
应用需要麦克风、摄像头、屏幕录制时，Pinokio 弹出权限提示并提供系统配置指导。
安全机制
🔒
脚本审核流程提交 Discover 市场需经过：个人身份核实 → 加入 Pinokio Factory GitHub 组织 → 仓库冻结 → 管理员代码审查 → 人工测试验证。
📂
隔离存储所有应用装在 ~/pinokio/api/，不写入 /usr/local 或用户 home 根目录。
🔍
脚本开源可查所有脚本从公开 Git 仓库下载，JSON 格式人类和机器均可读，运行前可查看源码。
🧊
沙箱执行world=isolated 时启用隔离模式，脚本无法访问隔离环境外的系统资源。
