已确认的核心事实

FACT 01

事实 1

Agent Plugins 1.0.0 是开放、厂商中立的插件打包规范。

FACT 02

事实 2

最小结构是 plugin.json、skills/ 与 mcp.json；客户端扩展放进反向域名命名空间。

FACT 03

事实 3

v1 只定义打包与加载边界，不定义安装、分发、权限、沙箱或信任验证。

BOUNDARY 01

边界 1

BOUNDARY 02

边界 2

BOUNDARY 03

边界 3
