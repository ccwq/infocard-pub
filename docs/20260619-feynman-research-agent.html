Feynman：把研究流程打包成
可安装的研究工作台

Feynman 不是单个命令，而是一套面向研究任务的工作台：既有独立终端应用，也有可单独安装的 skills-only 路径。它把文献综述、来源比对、同行评审、实验复现、训练 recipe、持续 watch 这些研究动作，统一成可复用的命令与技能包。

20 skills 13 prompts macOS / Linux / Windows LM Studio / LiteLLM / Ollama / vLLM standalone bundle
step 1输入问题

`feynman "what do we know about scaling laws"`

step 2并行搜索

paper / web / code / notes / outputs 协同查证

step 3结构化合成

brief, lit, audit, review, recipe, replicate

step 4产出可复用工件

artifact + skills + prompts + logs

two access paths

双入口：整机应用 / 仅技能包

完整应用

下载独立 bundle，内置自己的 Node runtime 和环境管理。适合直接跑研究任务、会话、输出与本地模型配置。

curl -fsSL https://feynman.is/install | bash # pin 版本 curl -fsSL https://feynman.is/install | bash -s -- 0.2.35

Skills only

只装技能树，不装 terminal app。支持 Codex / Repo / OpenCode 三种投放位，适合把研究能力注入现有 agent。

curl -fsSL https://feynman.is/install-skills | bash # repo-local curl -fsSL https://feynman.is/install-skills | bash -s -- --repo
command atlas

你输入什么，系统怎么接住

/deepresearch

多代理并行研究 + 证据汇总，适合深挖一个主题。

/lit

文献综述式输出：共识、分歧、开放问题、引用链。

/audit /review /replicate

论文 vs 代码审计、模拟同行评审、实验复现与修正计划。

/recipe /compare /draft

训练 recipe、主题对比、论文风草稿，把研究结果变成可执行方案。

/watch /outputs

持续监控主题，查看所有研究工件与历史输出。

CLI examples

`feynman`, `feynman deepresearch`, `feynman lit`, `feynman audit`。

skill matrix

20 个技能，13 个 prompts，按研究任务分层

研究发现search

deep-research、literature-review、source-comparison、watch、session-search。

论文工件paper

paper-writing、paper-code-audit、peer-review、replication、autoresearch。

写作输出draft

modal-compute、runpod-compute、docker、preview，把研究跑到可执行的基础设施上。

model and infra

本地模型与环境接入，不只是一层 CLI

维度事实意义
模型接入LM Studio / LiteLLM Proxy / Ollama / vLLM能接本地或自建 OpenAI-compatible 端点。
应用形态standalone bundle + 自带 Node runtime安装后就是一个完整研究工作台，而不是单脚本。
技能投放Codex / Repo / OpenCode / current repo-local研究能力可以注入现有 agent 环境。
仓库资产AGENTS.md / skills-lock.json / prompts / website / tests说明它是“流程包”，不是单纯的工具库。
why it matters

这份仓库的核心不是“研究助手”，而是“研究流程系统”

输出导向

不是把答案发散成聊天，而是生成 brief、review、audit、recipe、replicate 这类可用工件。

边界清楚

README 把 app 安装和 skills-only 安装分开，适配不同 agent 运行时。

可组合

命令、skills、prompts、outputs 分层明确，适合复用、变体和二次集成。

适用结论：Feynman 更像一个研究工作台发行包，而不是单一研究脚本。 如果要给它做信息卡，重点应放在“研究流程如何被打包、如何被安装、如何被复用、如何被验证”，而不是只写“一个 AI agent”。
