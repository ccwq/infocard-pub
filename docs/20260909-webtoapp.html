手机上第一次打包：三步走

这是一条官方 README 描述的操作路径；本卡没有在本机 Android 设备上执行。

1 / 选择类型

选择 Web URL、HTML/Offline、Frontend、Node.js、PHP、Python、Go、WordPress、Media 或 Multi-Web。

2 / 填基础信息

设置名称、URL 或项目、图标，再按需配置网络、隐私、外观和 runtime。不要先打开所有高级开关。

3 / Build & Share

在设备上构建 APK；完成签名后可以安装/分享，也可以导出面向 Google Play 的 AAB。

03
RUNTIMES

它不是纯 WebView：运行时也能在设备内启动

以下版本来自 README 快照，项目更新后应以官方文档为准。

Node.js / PHP

Node.js 18.20.x 通过 native wrapper 启动；PHP 8.4 搭配 Composer 2.10.x，可承载本地 PHP 应用。

Python / Go

Python 3.14 支持 Flask、Django、FastAPI/uvicorn 等路径；Go 1.26 支持本地 build、run 和 vendor 离线构建。

WordPress

README 描述为 PHP + SQLite 的本地 WordPress，支持主题与插件导入。适合演示和可携带内容包，不等同于生产迁移方案。

Port Manager

多个本地 runtime 需要端口协调。遇到“页面打不开”，先查 runtime 是否启动、端口是否冲突、依赖是否下载完成。

04
APK / AAB

构建、签名、发布是三个不同动作

Build

WebToApp 在设备内处理 Binary AXML/ARSC、资源注入和权限裁剪，生成 APK 架构。

Sign

支持 V1/V2/V3 签名和 keystore 管理。正式发布必须由你控制签名材料，绝不能把密码或私钥提交到项目。

Export

可导出 Google Play 需要的 AAB；商店合规、targetSdk、隐私声明和权限审查仍需单独完成。

安全边界：APK 能安装不代表能上架；签名成功不代表权限合理；AAB 导出成功不代表符合 Google Play 政策。
05
NETWORK / SECURITY

网络能力很强，但不要把它当成绕过授权的工具

README 提到 DoH、代理、PAC/SOCKS5、ECH、TLS fingerprint、CORS bypass 和 GeckoView。它们应服务于你有权控制的应用、测试环境和网络配置。

可配置能力

System WebView 默认；可选 GeckoView；支持 DoH、代理、PAC/SOCKS5、应用级代理和故障切换。ECH 依赖 GeckoView 路径。

敏感能力

TLS 指纹伪装和本地 MITM 会改变网络观测面；CORS bypass 会改变浏览器安全边界。仅用于获得授权的站点和测试环境，不用于规避第三方风控。

隐私与加固

README 描述 50+ 浏览器指纹向量伪装、hosts 广告规则、AES-256-GCM 资源加密、反调试/反 Frida 选项和激活码门控。

不要过度承诺

“有加固选项”不等于绝对安全；设备、密钥、运行时下载、第三方模块和网络配置仍可能泄露数据或扩大攻击面。

06
EXTENSIONS / AGENT

打包后仍能扩展

可注入 JS/CSS，支持 Tampermonkey 风格 userscript 与 GM_* 桥接能力。

可搜索或导入 Manifest V3 扩展，并提供部分 chrome.* polyfill；扩展权限仍需逐项审查。

Agent

README 快照描述为 50+ 工具，覆盖生成、构建、导出、端口、runtime、配置模板等；数量会随版本变化，不作为固定保证。

10 种 UI 语言

中文、English、العربية（RTL）、Português、Español、Français、Deutsch、Русский、日本語、한국어。

资源加密

可对配置、HTML、媒体和背景音乐做 AES-256-GCM 资源加密；密钥和激活服务要由使用者自己负责。

内置工具

README 还列出下载器、分析器、查找、暗色模式、隐私工具、元素阻断和媒体功能等模块。

08
TROUBLESHOOTING

常见问题先看哪一层

症状先查不要直接推断
页面打不开runtime、端口、资源路径、网络配置不是自动等于 WebToApp 构建失败
APK 能装但功能坏权限、URL、CORS、WebView/GeckoView、运行时依赖不是自动等于签名错误
AAB 无法发布签名、targetSdk、权限、商店政策和隐私声明不是自动等于 AAB 文件损坏
本地服务不启动runtime 下载、依赖、端口冲突、架构不要把手机性能问题归咎于代码
09
FIT / BOUNDARY

适合谁，不适合什么

适合

  • 没有电脑但想做 Android 原型和工具。
  • 需要把静态网站、内部工具或课程材料变成可安装包。
  • 希望在设备内测试本地 runtime 和扩展组合。
  • 愿意自己管理签名、权限、数据和发布合规。

不适合直接当成

  • 生产级移动开发 IDE 的完全替代品。
  • 绕过第三方登录、风控、封锁或服务条款的工具。
  • 把线上数据库、密钥和私有资源原样打包的迁移方案。
  • 无需测试即可上架的自动发布器。
