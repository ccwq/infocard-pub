Claude Code

Anthropic 官方 AI 编程 CLI — 无限工具调用 · 原生 Claude

在终端里拥有一个能读代码库、写文件、跑命令、管 Git、连 MCP、派 Subagent的 AI 工程师。区别于 IDE 插件，无工具调用次数限制，支持 200K+ 上下文，Auto-Mode 自动决策执行路径，与 CI/CD 深度集成。

无限工具调用200K+ 上下文MCP 集成SubagentPlugin 系统Auto-ModeGitHub Actions
对比 Cursor / Copilot：Claude Code 没有每轮 25 次工具限制。

Cursor 和 Copilot 的 AI IDE 在复杂任务（如重构大型模块、跨文件修改、跑测试并修复失败）时，会在第 25 次工具调用时强制中断并要求用户确认。Claude Code 的工具调用完全由模型自行决定，不设上限。

Auto-Mode — 让模型自己决定执行路径
claude >帮我把所有图片转成 WebP
→ Auto-Mode 启动，自动分析目录结构
→ 识别 PNG/JPEG 文件列表
→ 生成 cwebp 命令批次
→ 执行转换，报告结果
✓ 完成：24 张图片已转换
Auto-Mode 自动决策流程示意：分析 → 计划 → 执行 → 验证
WHEN TO USE
多步骤、需要判断的复杂任务
如：重构模块 → 跑测试 → 修复失败 → 提交。
AUTO-MODE DEFAULTS
claude auto-mode defaults
查看内置分类器规则，了解哪些任务会触发自动执行。

GitHub Actions / CI 集成
传统 AI IDE 在 CI 中的局限
工具调用 25 次上限，大任务强制中断。
需要 GUI 环境，无法在纯 headless CI 运行。
上下文窗口受 IDE 限制，大型代码库理解不全。
无法生成长期 OAuth 令牌供 CI 脚本使用。
Claude Code CI 优势
claude -p 非交互模式，专为 CI 脚本设计。
setup-token 生成长期令牌，CI 无需人工登录。
200K+ 上下文完整理解 monorepo 规模项目。
无工具限制，复杂多步骤 CI 任务一气呵成。
// CI USAGE EXAMPLE
# GitHub Actions 示例：Claude Code 自动代码审查
- name: Run Claude Code Review
  run: claude -p "Review the changes in this PR for bugs and security issues"
  env:
    ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}

# 本地脚本：非交互式自动修复
claude -p "Fix all ESLint errors in src/"

# 管道输入模式
cat report.json | claude -p "Analyze this test report and suggest fixes"

# 生成 CI 长期令牌
claude setup-token
