OVERVIEW · 一句话概述

Punk Skill 是什么

定位视觉生成 Skill

AI Agent 的视觉提示词库

Punk Skill 包含两个核心 Skill：punk-cover（文章封面生成）和 punk-avatar（头像生成）。通过预设风格库和平台比例适配，减少每次从零写提示词的重复劳动。

核心价值批量生成

一篇文章 → 多平台封面

同一篇文章可批量生成多个视觉版本，覆盖小红书、公众号、X/Twitter 等不同平台的比例和风格需求，适合需要快速试风格的创作者。
