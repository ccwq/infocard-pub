🌀 Fractal & Space-Filling Curves

奇怪的曲线：能填满整个平面，还能无限分

从 Hilbert（1891）开始，数学家造出了一类「长度无限、但能塞进 1×1 方块」的曲线——空间填充曲线。后来又造出了「无限细节、自己和自己长一样」的分形曲线。本卡面向初中生，把 14 条最经典的曲线一次性讲透：每条长什么样、怎么造出来、用在哪。

🧩 14 条曲线 🌀 空间填充 🌿 自相似 📐 无限长度 💾 数据库索引 🎮 计算机图形 🌍 自然建模
01

先分清两类：空间填充 vs 分形

本卡涉及的 14 条曲线，乍一看都「画不完」。但分两类看，思路立刻清楚。

🌀 空间填充曲线（Space-Filling Curve）
一条连续路径（无跳跃、不断开），极限情况下能「走遍」整个平面内部每一点。

🌿 分形曲线（Fractal Curve）
一段曲线，「放大任何局部」都能看到整体的样子——自相似；同时它通常有无限长度，但被装进有限区域里。

🔑 重叠：很多曲线两种都算（如 Hilbert 既是空间填充又是分形；Sierpiński 三角既是经典分形又有空间填充版本）。
Hilbert 2 阶（4×4 网格） 起止点（首尾相接）

14 条曲线 · 一次看齐

Hilbert 曲线

Hilbert curve · 1891
1
最经典的空间填充曲线 · 越迭代越像填满正方形
David Hilbert 1891 年提出；通过 4 个子图按 L 形拼接递归生成。
空间填充分形n 阶：4ⁿ 段

怎么造

把正方形分成 4 份，每个小正方形里画个 U；再把 4 个 U 串起来，每一层「转一下」方向。

用在哪

📍 空间数据库索引（PostgreSQL、Redis GEO）；图像局部加载（Google Maps 切片）。

Moore 曲线

Moore curve · 闭合空间填充
2
Hilbert 的「闭合版」：首尾相接的空间填充
由 E. F. Moore 推广；由 Hilbert 曲线首尾相连后改造而成，递归构造。
空间填充闭合分形

特点

首尾相接 → 天然适合「绕圈填图」、芯片布线、有限元网格的连续遍历。

用在哪

🔌 集成电路布线、连续型区域填充算法。

Morton 曲线 / Z-order

Morton / Z-order · 1966
3
把 2D 坐标「位交错」变 1D 数字 → 缓存超友好
把 (x, y) 的二进制位交错，得到一个长整数 Z。空间相邻的点在 Z 上也相邻。
数据索引空间填充位运算

公式

Z(x,y) = interleave_bits(x) + interleave_bits(y) << 1

用在哪

💾 主流空间数据库：PostGIS、HBase、ClickHouse、Bing Maps 瓦片；GPU 纹理压缩。

Dragon 曲线

Dragon curve · Heighway 1966
4
把纸带反复对折画出来的龙
John Heighway 等发现。把一条纸带对折、再对折……放开后的折痕就是 Dragon 曲线。
分形IFS折纸

怎么造

每一步把当前每条线段「折一下」成 90°；迭代 8+ 次就出现明显「龙身」。

用在哪

📚 分形教学经典；天线路径设计（少占面积）。

Gosper 曲线

Gosper curve · Flowsnake
5
由 7 个相似小段拼成的大段，形状像蛇
Bill Gosper 发现。每个「6 段连杆」被 7 个更小的连杆替换，整体不断变长。
分形等长折线Logo 灵感

特点

由 60° 折线构成，整段永远不交叉，递归后像蛇鳞。

用在哪

🧬 艺术图案、算法可视化教学。

Sierpiński 曲线

Sierpiński curve · 1912
6
穿过 Sierpiński 地毯的连续路径
Wacław Sierpiński 1912 构造。整条曲线走遍 Sierpiński 地毯的每一个点。
空间填充分形1912

特点

由 4 个子图按 3:1 比例缩放拼接，递归生成；可填满 Sierpiński 地毯。

用在哪

🔬 分形维数研究、教学示意。

Osgood 曲线

Osgood curve · 1902
7
「面积非零」的最简单空间填充曲线
William Fogg Osgood 1902 构造。曲线本身是 1 维的，但包围的面积是 1 平方单位。
空间填充反直觉面积曲线

反直觉在哪

数学里「曲线」= 1 维（面积 = 0），但 Osgood 曲线居然能围出非零面积——打破直觉。

用在哪

🧠 测度论、抽象数学的反例。

Schoenberg 曲线

Schoenberg curve · 1938
8
1938 年 Schoenberg 构造的「平滑」空间填充曲线
I. J. Schoenberg 1938 用样条函数（连续可微）构造。比 Peano / Hilbert 原始版本「更光滑」。
空间填充样条1938

特点

用「B 样条」类工具，曲线是连续可微的（不会突然拐 90°）。

用在哪

🖌️ 图形学平滑路径、动画轨迹。

Sierpiński 三角

Sierpiński triangle · 1915
9
把三角形三等分，挖掉中间小三角形，无限迭代
Wacław Sierpiński 1915。面积每次缩小为 3/4，最终面积 → 0；周长每次扩大 4/3 → 无穷大。
分形3 倍对称维数 1.585

公式

每次迭代面积 An+1 = 3/4 × An；分形维数 D = log 3 / log 2 ≈ 1.585。

用在哪

📡 天线设计、网络拓扑模型。

Sierpiński 地毯

Sierpiński carpet · 1916
10
把正方形九宫格化，挖掉中心格，无限迭代
正方形 → 3×3 九宫格 → 移除中心 → 剩下的 8 块再各自九宫格化……
分形2D维数 1.893

公式

每层剩余面积 = 8/9；分形维数 D = log 8 / log 3 ≈ 1.893。

用在哪📐 拓扑学反例（曲线维数研究）。

Cantor 集

Cantor set · 1883
11
把线段三等分，挖掉中间 1/3，剩下两段再各挖一次
Georg Cantor 1883。无限挖下去后，剩下的是「看似很小、但有无穷多点」的尘埃。
分形1D维数 0.631

特点

长度 → 0，但点数 = 2ℵ₀（不可数多）；和 0~1 之间所有数一一对应。

用在哪

🔬 测度论基础、混沌理论。

Mandelbrot 集合

Mandelbrot set · z = z² + c
12
复数 c：迭代 zn+1=zn²+c，不发散就属于
Benoit Mandelbrot 1980 命名。所有不发散的 c 画在复平面上，组成一只「分形甲虫」。
复迭代分形维数 ~2

公式

z₀ = 0, zn+1 = zn² + c

用在哪

🌍 混沌系统、复杂性科学、电影特效。

Barnsley 蕨

Barnsley fern · IFS 仿射
13
4 个仿射变换反复应用，模拟蕨类叶片的自相似
Michael Barnsley 1988 发明。每个变换把当前点压扁、旋转、平移，4 个概率加权 → 长出蕨叶。
分形IFS自然仿真

公式

4 个仿射变换 {f₁, f₂, f₃, f₄}，按概率 pᵢ 反复作用。

用在哪

🌿 自然图形压缩、电影特效树木生成。

Lévy C 形曲线

Lévy C curve · 1938
14a
把两段折线在中点「翻面」一次，就得到 C 形
Paul Lévy 1938 提出。规则只有一条：每步把两条线段在中点成 90° 折一下。
分形自相似折线迭代

特点

无限次折后，曲线趋于一个连续的 C 形路径。

用在哪

🧪 经典教学示例。

Vicsek 分形

Vicsek fractal · 十字交叉型
14b
中心点 + 4 个角点，迭代时再加新「十字」
Tamás Vicsek 1983 提出。是一种「正方格」自相似分形。
分形2D 十字维数 ~1.46

公式

D = log 5 / log 3 ≈ 1.465。

用在哪

📡 城市/网络拓扑模型。

毕达哥拉斯树

Pythagoras tree · 1944
14c
每个正方形的斜边再长出两个小正方形
Albert E. Bosman 1944 发明。把每个正方形的斜边当底，向两侧各画一个等腰直角三角形的正方形。
分形直角三角几何美学

用在哪

🌳 数学美学图案、几何教材封面。

特点

迭代 5~6 层就能长成「圣诞树」；变种能长成「树冠 / 雪花 / 折扇」。

科赫雪花（Koch）

Koch snowflake · 1904
★
三角形每条边中间「凸起一个尖」，无限次
Helge von Koch 1904。三边等分后中间 1/3 段改成两条斜边，迭代。
分形维数 1.262处处不可微

公式

每条边长 × 4/3；周长 = (4/3)n × 3 → ∞；面积收敛到 8/5 × 三角形原面积。

用在哪

🌨️ 雪花模型、海岸线模拟。

Peano 曲线

Peano curve · 1890
★
第一条空间填充曲线：连续路径「扫遍」整个正方形
Giuseppe Peano 1890。第一条证明「1 维曲线可以铺满 2 维平面」的曲线。
空间填充历史第一反直觉

特点

无限次递归后，曲线在极限意义下「经过正方形内每一点」。

意义

🧠 推翻了「维数 = 直观维度」的旧观念，启发了拓扑维数与分形维数的发展。

4 张大图看清核心思想

每张图重点拆解一种「为什么要这样造」。

🌀 Hilbert 3 阶：4×4 网格 = 16 段连成 1 根「不回头」折线
🧩 怎么读这张图
· 起点 = 左下角红点；终点 = 右上角红点
· 路径「不回头、不交叉」，扫过每个小格
· 每一阶 Hilbert 路径把上一阶「放大 2 倍 + 转 4 个 U」

💡 用在哪：把 (x,y) 沿 Hilbert 路径编号，2D 邻居在 1D 上也相邻——这就是空间索引的核心思想。
🔺 Sierpiński 三角 4 次迭代：面积 → 0，周长 → 无穷
🧩 怎么造
· 拿一个大正三角形，连顶点画中位线，分成 4 个小三角
· 挖掉中间那 1 个
· 剩下的 3 个再各自分 + 挖
· 重复无数次

🧮 数字
· 面积：每次 × 3/4，趋于 0
· 边数：每次 × 3；总周长趋于无穷
· 维数：log 3 / log 2 ≈ 1.585（介于线 1 和面 2 之间）
❄️ 科赫雪花 3 阶：每条边都长出新尖刺
🧩 怎么造
· 把一条线段三等分
· 中间那段换成「凸起的等边三角形的两条斜边」
· 4 段都按这个规则无限次迭代

🧮 数字
· 每条边长 × 4/3（边变长）
· 总边数 × 4（边变多）
· 三角 3 条边都迭代 → 周长 → 无穷
· 但「外接面积」有上限（收敛于原三角 × 8/5）
🌀 Mandelbrot 集合：用「z² + c」一行公式生成的「甲虫」
🧩 怎么造（伪代码）
for each (cx, cy) on the plane:
  z = 0
  for step in 0..100:
    z = z*z + (cx + cy·i)
    if |z| > 2: break
  color = step
💡 含义：不被「推走」的 c 画成黑/黄，构成主甲虫；边缘的彩色部分是「接近发散」的速度——它自己又是分形。

公式汇总：分形维数怎么算

分形曲线没有「光滑长度」，但可以算「分形维数 D」。

通用公式：N × rD = 1

Box-counting / self-similarity
D
把图形用 r 倍小单元覆盖，需要 N 个；那么 D = log N / log(1/r)。

常见 D 值速查

  • Koch 雪花 D = log 4 / log 3 ≈ 1.262
  • Sierpiński 三角 D = log 3 / log 2 ≈ 1.585
  • Sierpiński 地毯 D = log 8 / log 3 ≈ 1.893
  • Vicsek 十字 D = log 5 / log 3 ≈ 1.465
  • Cantor 集 D = log 2 / log 3 ≈ 0.631
  • Hilbert / Morton 极限 = 2（填满平面）
D 越大越「占面」，越小越「占线」。曲线 D = 1 上下、面积 D = 2 上下。

Morton 码公式

Z(x, y) = interleave bits
Z
位交错：把 x 和 y 的二进制位按「x₀y₀x₁y₁x₂y₂…」拼起来。

例子

x = 5 = 0b101
y = 2 = 0b010
Z = 0b100110 = 38

特点

2D 坐标变成 1D 数字 → 可以走 B-tree、范围查询比传统 R-tree 快数倍。

05

用在哪？一张表盘清

14 条曲线不是「画着玩」，每一类都有工业级用途。

🗄️ 空间数据库索引

💾
Hilbert / Morton / Z-order

为什么用

把 2D 坐标变成 1D 整数 → B-tree 索引能直接用 → 范围查询比 R-tree 快。

代表产品

PostgreSQL cube、Redis GEO、HBase GeoMesa、Bing Maps 瓦片。

🖼️ 图像处理 / 压缩

🖼
Hilbert 扫描 + Barnsley 蕨类压缩

Hilbert 扫描

比传统「行扫描」更好地保留图像局部结构 → 图像压缩与加载友好。

Barnsley 蕨

用 4 个仿射变换可压缩自然图像（如蕨类叶、羽毛），压缩率比 JPEG 高。

🎮 计算机图形学

🎮
地形生成 · 程序化植物

地形

分形噪声（Perlin、FBM）模拟山脉、海岸、天空噪声——游戏与电影特效底子。

植物

L-system + 毕达哥拉斯树生成程序化树木与灌木。

📡 天线与电路

📡
Koch / Hilbert / Moore

为什么

有限面积里塞下超长电流路径 → 提升天线增益；芯片布线用 Moore 曲线减小层数。

代表应用

智能手机内置天线、RFID 标签、芯片走线。

06

怎么造：通用 4 步法

所有的空间填充 / 分形曲线，套路都是这 4 步。

Step 1 · 找基本单元

1

做什么

挑一个「比整体简单一截」的形状作为种子。比如 Hilbert 选 U 形，Koch 选一条线段。

Step 2 · 写替换规则

2

做什么

把基本单元替换成「多个更小单元」的拼接图（L-system / IFS 规则）。

Step 3 · 迭代

3

做什么

把替换规则再应用到新生成的小单元上，反复做 5~10 次。

Step 4 · 看极限

4

做什么

在「无限次」迭代的极限下，曲线变成什么？长度无穷？面积有限？空间填充？

🎯 一句话总结：这些曲线看着「画不完」，其实是把简单的「替换规则」无限迭代——它们把离散几何的「点」和拓扑的「形」穿在一起，构成了 20 世纪数学里最浪漫的一片风景。
