Codex Redteam Mode
Codex 上的红队对抗编排框架

phase

四层运行时：phase 检测任务阶段 → router 路由决策 → pack 打包子任务 → leaf 执行具体操作。所有中间结果存在 JS 变量里，主 Agent 只看到最终答案。

2

三种模式

默认
Normal
标准 Claude Code 工作模式，适合日常任务
红队
Redteam
显式开启后进入对抗工作流，内置对抗性验证
恢复
Resume
从中断处恢复，进度实时保存，状态不丢失
3

核心特性

规则优先 Phase 检测
任务自动识别当前阶段（规划/执行/验证），规则引擎驱动，非硬编码
分级 Gate 验证
每个阶段设验收门，部分子代理专门找漏洞、互相反驳
JSON 状态管理
所有中间结果以 JSON 格式存在脚本变量，主 Agent 上下文零膨胀
SKILL.md 领域卡
每个子代理领域知识封装在 SKILL.md，主 Agent 按需加载
Session Patcher
会话状态热补丁，支持运行时干预和注入，无需重启会话
幂等安装器
python scripts/install.py，支持 --dry-run / --uninstall / --codex-home
4

与传统模式对比

模式通信方式扩展性状态持久上下文
传统 Subagent主 Agent 中转3-5 实例会话断即丢爆炸风险
Agent Team直接通信有限状态丢失中等
动态工作流JS 变量隔离按需扩展实时保存零膨胀
5

安装方式

$ python scripts/install.py
# 支持参数：
--dry-run 预览安装内容，不实际写入
--uninstall 卸载框架
--codex-home 指定 Codex 主目录
--agents-home 指定 agents 目录
