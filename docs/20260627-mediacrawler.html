它解决的核心问题：绕过平台签名 + 多平台统一接口

传统爬虫要逆向 signature、X-Bogus、xsec_token 等加密参数，成本极高。MediaCrawler 用 Playwright 搭桥，直接从已登录浏览器上下文拿签名，零逆向。

核心技术

Playwright 浏览器搭桥 → 保留登录态 → JS 表达式取签名参数

不需要复现任何加密 JS 代码，也不需要抓包分析算法。只要登录一次，后续所有请求自动带正确签名。

快速上手：四步完成第一次数据采集

Python 3.9 + Playwright + Node.js 16 即可运行，不需要复杂配置。

Step 1
安装依赖
pip install -r requirements.txt + playwright install
Step 2
配置登录
选择二维码或 Cookie 登录，登录态自动缓存
Step 3
运行爬虫
python main.py --platform xhs --lt qrcode --type search
Step 4
数据存储
自动存入 MySQL / Redis / SQLite / CSV / JSON

登录方式

  • 二维码扫码：自动打开浏览器，最简单
  • Cookie 注入：适合服务器端无头运行
  • 登录态缓存后无需重复登录

数据存储

  • MySQL / PostgreSQL
  • Redis
  • SQLite（本地文件）
  • CSV / JSON（零配置）
04

典型使用场景：竞品监控 / 用户调研 / 舆情分析

不是"一次性爬数据"，而是搭建持续数据采集流水线。

值得用的场景

  • 竞品内容监控（持续追踪关键词下的内容）
  • 用户评论分析（了解用户反馈和产品口碑）
  • 舆情监控（定向抓取事件相关帖子和评论）
  • 博主/达人分析（抓取主页了解创作节奏）
  • 数据标注（为 ML 模型收集训练语料）

技术亮点

  • 模块化采集引擎，每个平台独立维护
  • 支持二级评论（评论的回复也抓）
  • IP 代理池自动切换，降低被封概率
  • 评论词云生成（可视化结果）
  • 支持 crontab 定时采集

Pro 版对比：什么时候值得买付费版

MediaCrawlerPro 在开源版基础上做了规模化升级。

MediaCrawlerPro

开源版 vs Pro 版核心差异

  • 去除 Playwright 依赖：Pro 版完全脱离 Playwright，纯后端实现，更适合服务器部署
  • 多账号 + 断点续爬：规模化采集必备，开源版不支持
  • 完整 Linux 支持：Pro 版专为 Linux 环境优化
  • 自媒体内容拆解 Agent：新增 AI 分析能力，解读内容语义
  • AI Agent Skill：支持 OpenClaw / Claude Code / Cursor 一键安装，让 Agent 自动调用爬虫
  • 自媒体视频下载器桌面端：附带全栈开发学习项目
建议先用开源版理解架构。Pro 版代码设计思路同样值得学习，但先理解开源版模块化设计再决定是否付费，是更稳妥的路径。
