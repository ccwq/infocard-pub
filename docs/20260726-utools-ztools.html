01核心定位
uTools

新一代效率工具平台，极简插件化设计，Alt+空格呼出万能搜索框，即装即用即走。内置 3000+ 插件，跨平台 Win/Mac/Linux，轻量无广告，免费使用。

ZTools（ZToolsCenter）

uTools 的开源实现，基于 TypeScript/Vue 3 重写，完全兼容 uTools API，支持 macOS 和 Windows。插件生态仍在建设中，部分 API 未完成适配。

03各自优劣
uTools 优势
  • 3000+ 插件即装即用，生态成熟
  • Alt+空格 + 超级面板，体验完整
  • Everything 本地搜索，速度极快
  • 云端数据同步，多设备无缝
  • Win/Mac/Linux 全平台稳定
ZTools 优势
  • MIT 开源，可自由查看和修改源码
  • 可 fork 深度定制自己的插件
  • TypeScript + Vue 3 现代技术栈
  • 完全兼容 uTools API，减少迁移成本
  • 免费，无任何内购或数据收费
04按场景选型
日常办公 / 效率提升

需要 OCR、翻译、剪贴板管理、Markdown 等开箱即用功能。

→ 选 uTools，插件齐全不用等

开发者 / 需要深度定制

想基于源码 fork、开发自己的插件，或集成到内部工具链。

→ 选 ZTools，开源可控

企业内网 / 插件不上云

公司内部插件不能发布到 uTools 市场，需要私有部署。

→ 选 ZTools，自托管

初次体验 / 小白用户

刚接触效率工具，想要省心省力、快速上手各类插件。

→ 选 uTools，新手友好

05快速上手
安装 uTools

官网下载 v7.8.0 安装包（75MB），安装后 Alt+空格 即可呼出，输入「cj」进入插件中心安装插件。

安装 ZTools

从果核剥壳等站下载 v2.4.1 绿色版，或从 GitHub ZToolsCenter 获取源码自行编译。

# uTools 常用快捷操作 Alt + 空格 → 呼出搜索框（全局） 鼠标中键 → 超级面板（选中内容智能匹配插件） Ctrl + C 复制 + Alt+空格 → 自动识别类型匹配插件 输入 cj → 打开插件中心 输入 jq → 剪贴板历史 输入 g + 空格 → 快速 Google 搜索
06一句话结论
选 uTools 如果…
  • 想要开箱即用、功能齐全
  • 主要在 Windows/Mac 使用
  • 需要云端数据同步
  • 不想折腾，追求稳定
选 ZTools 如果…
  • 重视开源和可定制性
  • 有开发能力，想 fork 源码
  • 公司内网不能用 uTools
  • 愿意给成长中的项目一些时间
