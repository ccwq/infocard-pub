# Qwen/千问品牌全解析：关系、版本与生态

> 2026年7月WAIC期间热点解读：Qwen=千问=阿里大模型品牌（"通义千问"已于2026年3月正式停用），附版本演进时间线、旗舰模型对照表与完整产品生态图解。

## 核心结论

**Qwen = 千问 = 阿里大模型品牌**

阿里巴巴于2026年3月2日正式统一品牌：
- 中文名：**千问**
- 英文名：**Qwen**
- "通义实验室"为集团AI研究机构名称，非产品品牌
- "通义千问"名称**不再使用**
