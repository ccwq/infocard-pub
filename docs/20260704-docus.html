CORE VALUE

核心价值

Docus 是 Nuxt 官方出品的文档框架，解决"如何快速拥有漂亮文档站"的痛点。

零配置

一条命令生成

npx create-docus my-docs 即可创建完整项目骨架，无需手动配置主题、路由、构建工具。

  • 内置 Nuxt UI 4 主题
  • Tailwind CSS 4 样式系统
  • 开箱即用的组件库
Nuxt 4

基于 Nuxt 4 驱动

利用 Nuxt 4 的文件路由、自动导入、性能优化，默认开启 SSR/SSG 双模式。

  • 服务端渲染 (SSR)
  • 静态站点生成 (SSG)
  • 自动代码分割
AI Ready

AI 功能内置

内置 AI Assistant（对话问答）、MCP Server（AI 工具接入）、Agent Skills（技能发现）。

  • 可嵌入 AI 聊天机器人
  • 支持 Cursor / VS Code / Claude
  • 自动生成 llms.txt

MARKDOWN + VUE

Markdown + Vue 组件 (MDC)

MDC（Markdown Components）让你在纯 Markdown 中直接使用 Vue 组件，无需 JavaScript 配置。

MDC 语法

组件即标签

在 Markdown 中用 Vue 组件，无需 import，无需 setup，文件即组件。

  • :callout{type="info"} — 提示框
  • ::Badge — 徽章标签
  • ::CodeBlock — 代码高亮块
// MDC 示例：Markdown 中嵌入 Vue 组件
# 安装指南

用一行命令启动项目：

:::terminal{cmd="npx create-docus my-docs"}
::

在 Markdown 中直接用 Vue 组件：

:::Callout{type="warning"}
需要 Node.js 18+
:::

PROJECT STRUCTURE

项目结构

Docus 项目结构简洁清晰，内容与代码分离，易于维护。

目录结构

核心目录

Docus 采用约定式目录结构，内容与组件分离。

  • content/ — Markdown 文档（自动路由）
  • components/ — 自定义 Vue 组件（自动导入）
  • pages/ — 自定义页面（可选覆盖）
  • assets/ — 静态资源（样式、图片）
  • public/ — 纯静态文件
扩展方式

自定义组件扩展

在 components/ 中添加 .vue 文件即可扩展 Docus，无需配置 import。

  • 组件名即文件名
  • 支持嵌套目录
  • 支持 props / slots / emit

INSTALL SOP

使用 SOP

从零到上线，最快 3 分钟完成。

// Terminal · 一条命令创建文档项目
# 创建新项目（推荐）
npx create-docus my-docs

# 或使用国际化模板
npx create-docus my-docs -t i18n

# 进入目录
cd my-docs

# 启动开发服务器
npm run dev

# 浏览器打开 http://localhost:3000

# 构建生产版本
npm run build

# 预览生产构建
npm run preview

FAQ

常见问题

选自 GitHub Issues 和官方文档的高频问题。

Q: Docus 和 Nuxt Content 是什么关系？

Docus 是基于 Nuxt Content 构建的文档主题/启动器，整合了 Nuxt UI 4、Tailwind CSS 4、SEO 套件和 AI 功能。Nuxt Content 负责内容解析，Docus 负责视觉呈现和交互。

Q: 是否支持自定义域名和 Vercel 部署？

完全支持。Docus 原生支持 Vercel、Netlify、Cloudflare Pages、GitHub Pages 等所有主流部署平台，SSG 模式下无需服务端。

Q: 如何添加自定义组件？

在 components/ 目录创建 .vue 文件，Docus 自动导入。在 Markdown 中用 ::MyComponent:: MDC 语法即可调用，支持 props 和 slots。

Q: Nuxt 4 集成情况如何？

Docus 已在 Nuxt 4 分支稳定维护，2026-06-25 仍有活跃提交，全面支持 Nuxt 4 的兼容性 API 和性能优化特性。
