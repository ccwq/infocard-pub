项目概述
oh-my-openagent · OmO

oh-my-openagent 是为 Claude Code、Codex、OpenCode 等 AI 编程 Agent 打造的全功能 Harness 框架，核心理念是「Orchestrate Them All」——不绑定任何单一模型 Provider，统一编排多引擎协作。

创始人 @code-yeongyu 因高频使用 Anthropic 模型被 OpenCode 封禁，遂全力转向 Codex 生态，并构建了 OmO 作为 Agent 协作控制台。维护者使用同名 AI 助手 Jobdori 实时构建和维护项目，所有变更均公开直播。

65K Stars，使其成为全球最高星的 AI Agent 开源工具之一（截至 2026 年中）。

两个版本
Ultimate Editionomo for OpenCode

完整版 OmO，包含 11 个 Agent、54+ 生命周期 Hook、5 个内置 MCP、全部斜杠命令、Team Mode、ulw-loop、ultrawork、hashline edits。

全功能套件，面向深度定制和复杂代码库场景。

Light Editionomo for Codex CLI

面向 Codex CLI 插件系统的可移植组件：rules、comment-checker、git-bash、lsp、ultrawork、ulw-loop、start-work-continuation、telemetry，以及插件级 MCP。

无 Agent 编排，无 team_* 命令，轻量接入。

核心功能
Team Mode — 多 Agent 并行协作，任务分工与结果聚合
ultrawork — 一句话启动完整工作流，一键自动化执行
ulw-loop — 长任务自动循环，持续推进直到完成
54+ Lifecycle Hooks — 覆盖 Agent 生命周期的每个关键节点
5 内置 MCP — 开箱即用的 Model Context Protocol 服务
Hashline Edits — 精确代码行级编辑，避免上下文溢出
多引擎支持 — OpenCode、Codex、Claude Code、P 多引擎统一接入
Slash Commands — 丰富的斜杠命令集，快速调用各类能力
Start Work Continuation — 中断后自动恢复任务上下文
Telemetry — 实时监控与调试，数据驱动的 Agent 优化
架构亮点
多 Provider 统一编排

不依赖单一模型厂商，通过标准化 Harness 接口接入 OpenCode、Codex、Claude Code、P 等多个引擎，统一调度协作，规避厂商锁定风险。

Token 效率优先

面向「Token 效率至上」用户设计。Hashline edits 减少上下文膨胀；Codex 版专为低成本高频调用优化，绕过 Anthropic 封禁。

实时构建直播

维护者使用同名 AI 助手 Jobdori 实时开发，所有提交、修复、Issue 处理均在 Discord 公开，任何人都可以围观 Agent 构建 Agent 的过程。

活跃社区生态

836 个 open issues 活跃讨论，5,313 次 fork，Discord 社区 2,500+ 成员，大量真实使用案例和用户案例分享。
