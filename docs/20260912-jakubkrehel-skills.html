💅 AI 界面外挂：让 AI 自己盯设计细节

⚡ 安装（两种方式）

方式一：npx 通用安装（任何 AI Coding 工具均可用） 
npx skills add jakubkrehel/skills
方式二：Claude Code 插件市场（推荐，体验最完整） 
/plugin marketplace add jakubkrehel/skills
/plugin install interfaces@interfaces

🗺️ Skill 地图（三组 11 个）

统一入口 · better-interface：同时触发全部 6 个 better-*，收集证据并给出综合评级。喊一句完成全面审查。
🔍 分项审查（better-*）
better-ui
圆角同心 / 光学对齐 / 图标上下文 / 点击区域
better-typography
字号层级 / 字间距 / 可变字体 / OpenType 特性
better-colors
色阶系统 / 语义 token / 对比度检查 / 格式转换
better-accessibility
无障碍标准 / 键盘支持 / 焦点环 / ARIA 标签
better-layout
分组 / 对齐 / 阅读顺序 / 响应式边界
better-writing
产品文案 / 错误提示 / 术语一致性
🔧 主动探索（用户触发）
break
组件全状态渲染，压力测试
variant
一次生成多个方案变体
explain-interface
解析任意 UI 的实现方式
📐 变更评审
interface-review
审查代码变更对界面的影响，区分真实缺陷与设计偏好

✅ 典型使用流程

1

写完页面后，在 Claude Code 里喊 /better-interface

2

它自动路由到 6 个分项 skill，收集界面、排版、配色、无障碍、布局、文案的证据

3

综合评级，输出最多 15 条有证据的发现，按严重程度排序

4

按优先级修复，或用 /break 组件名 单独压力测试某个组件

⚠️ 边界：什么时候不适合用

❌ 不适合
纯逻辑后端界面（无 UI）
游戏 / 3D 界面（技能覆盖范围外）
全新品牌设计（设计偏好非缺陷）
已有成熟设计系统（已过此阶段）
✅ 适合
AI 生成页面的质量审查
设计工程流程标准化
团队代码 review 中的界面检查
组件变体探索与对比
