7.1× 与 2.3× 仅对应官方当前首页所述的 warm benchmark；不要把它们扩展成所有项目、所有缓存状态或所有版本的普遍加速。

一句话概述：Aube 的核心卖点是低迁移摩擦——保留既有锁文件工作流，同时提供新的默认锁文件与脚本入口。

Aube（jdx/aube）是 MIT 许可的 Node.js 包管理器，项目包含 Rust。官方文档确认它可以读写 pnpm-lock.yaml v9、package-lock.json、npm-shrinkwrap.json、yarn.lock 与 bun.lock；新项目默认使用 aube-lock.yaml。官方首页还给出 warm benchmark 的相对结果，但该结果必须与其测试范围一起阅读。

03
SECURITY DISTINCTION · 安全边界

审批默认拒绝，不等于默认开启 jailBuilds

Aube 的依赖生命周期脚本与可选构建隔离是两件事，必须分开说。

生命周期脚本：需审批

依赖的 lifecycle scripts 需要获得批准；这是安装流程中的审批边界。

jailBuilds：额外 opt-in 层

jailBuilds 是可选的额外隔离层，不应被描述为 Aube 的默认沙箱。

当前默认值：false

官方安全文档当前确认 jailBuilds 默认关闭。启用它与脚本审批不是同一个开关。

安全表述：“默认拒绝未批准的生命周期脚本 + 可选 jailBuilds”比“默认沙箱”准确；后者会夸大当前默认行为。
