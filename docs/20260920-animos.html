Keyframes：把模板改成你自己的动画（2026-08-21 官宣）

新功能深用
◇ 怎么用（官网原文口径）

界面底部 Keyframes 面板显示「0 tracks — No keyframes yet」时，点任意滑杆或颜色旁的 ◇ 菱形按钮，该参数立即变成一条可动画的轨道。可加关键帧的参数包括间距 spacing、倾角 tilt、旋转 rotation、卡片尺寸 card size 等——官方原话：「基本上把基础模板变成你自己的自定义动画，不用碰 After Effects」。

Track一个参数 = 一条轨道；同一参数在时间轴上可有多个关键帧点
参数级
取消再点一次 ◇ 移除该参数的轨道（恢复模板默认）
可逆
与 Timing 关系关键帧分布在 Loop duration 时长内；改循环时长后关键帧位置按比例保留
先定时长
Card ratio卡内素材比例可独立设 Auto / 1:1 / 4:3 / 3:4 / 4:5 / 16:9 / 9:16（与导出画框是两回事）
别混淆
⚖️ 边界：它不是剪辑软件

官方在 Product Hunt 明确：无保存状态是刻意取舍——为保证「1 分钟内出片」，每次导出都是全新开始，没有云端项目库（2026-10 时点）。要项目沉淀就导出前把参数截屏记档。模板预设之外的完整自定义时间轴仍以 Keyframes + 参数为准。
