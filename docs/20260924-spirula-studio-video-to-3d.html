为什么它省事：传统 3DGS 三座大山，逐个拆

做过三维高斯泼溅的都懂：环境是第一道墙。Spirula 的解法不是「打包得更优雅」，而是把训练引擎整个用 Vulkan compute 重写——底层是其作者一作、发表于 Eurographics 2026 的 VkSplat 论文，号称首个达到 SOTA 性能的全 Vulkan 3DGS 训练管线。

0

环境依赖清零

传统流程：COLMAP 算位姿 + Python/PyTorch 环境 + CUDA 工具链，配一趟三小时起步。Spirula 解压即用：Windows 包 33-39MB，macOS DMG 45-55MB，双击开 GUI；云端训练走 CLI（spirula train 自带 HTTP 查看器，SSH 端口转发即可盯进度）。

N/AMD/Intel/苹果

显卡解锁

CUDA 生态把 AMD/Intel/苹果用户挡在门外；Vulkan 后端全厂商通吃，macOS 经 MoltenVK 静态链接、零依赖运行。代价也有：论文实测同场景 RTX 3090 跑 575 秒、RX 7800 XT 跑 1201 秒——AMD 慢约 2.1 倍，最大瓶颈在主机→显卡的 loss 数据传输（24s vs 303s）。

10M

8GB 显存训 1000 万 SH3 高斯点

量化训练（quantized training）压显存：论文 Table 2，MCMC 配置下 VkSplat 每场景 285 秒 / 0.93 GiB，CUDA+PyTorch 基线 995 秒 / 1.37 GiB——快 3.3 倍、省 33% 显存，质量持平。鱼眼/360/等距柱状相机模型原生内置，素材不用先去畸变。

推文没讲的边界与坑

  • 许可证三层：本体 GPLv3；GPU 视频解码的 PATENTED 开关带 AVC/HEVC 专利风险（默认关）；AI 遮罩的 SAM 模型不打包——SAM 2.1 是 Apache-2.0，SAM 3 是 Meta 自家非标准许可证，GUI 首次使用时展示条款再下载
  • Defender 误报：issue #92（09-22）报告 v2026.9.20 Windows 包被报 Trojan:Script/Wacatac.H!ml，作者定性误报、已提交微软申诉——下载时安全软件报警先别慌，也别无脑放行
  • 单人项目：10 位贡献者里作者 896/908 commits，README 自述「几乎一个人开发维护」；issue 回复可能慢但都会看
  • 名字由来：Spirula = 深海头足类「旋壳乌贼」，前身项目 spirulae-splat（2024-05 创建）

四步上手

1

下载解压

GitHub Releases 选平台：Windows zip / macOS DMG / Ubuntu zip，双击开 GUI。

2

丢视频或照片

鱼眼、360°、等距柱状直接喂；数据集创建模块自动抽帧 + AI 遮罩 + SfM 算位姿。

3

训练 & 监控

8GB 显存可上 10M SH3；云 GPU 用 CLI，内置 HTTP 查看器 SSH 转发盯进度。

4

导出

splat 可网页查看（Web Viewer）；v2026.9.24 起可编辑模型并导出图像/视频渲染与带贴图网格。
