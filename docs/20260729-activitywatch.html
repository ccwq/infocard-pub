ActivityWatch

不打断工作，持续记录你把时间花在哪里。

06

被动式自动时间追踪

本地存储，配合 Web 仪表盘查看时间分布。

它记录什么

应用时长

无感记录不同应用的使用时间，让时间管理从主观感受转为可回看的数据。

网页使用

结合网页活动记录，观察浏览、开发、会议和娱乐之间的时间分配。

本地优先

开源且本地化存储，适合重视隐私、不希望时间数据上传第三方平台的用户。

使用闭环

安装后建议设置开机自启，让记录持续发生。定期打开 Web 仪表盘，按天、周或项目复盘时间分布，再决定删掉哪些低价值活动。

ActivityWatch 不是替你安排任务的待办工具，它首先提供事实：你实际使用了哪些应用、在什么时间段投入了多少时间。

适合谁

远程工作者

识别会议、沟通和深度工作的真实占比。

开发者

观察 IDE、终端、浏览器和文档之间的切换成本。

效率复盘者

用本地数据校准计划，不只依赖感觉判断是否专注。
