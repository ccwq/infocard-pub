方法论 · 六原则 / 六模式 / 权限五阶段

六原则

原则含义
一 bot 一 job每个 connector 专注单一任务
Context 先于 Personality理解任务上下文优先于角色扮演
输出契约prompt 明确定义输出格式与边界
按动作分级审批只读 / 草稿 / 批准后写入 / 敏感操作逐级审批
证据优于自信重要主张附来源链接，不确定性显式说明
优雅停止模糊时提问，不猜测执行

六种工作流模式

Watcher Researcher Drafter Approval-gated Operator Auditor Human Handoff

Watcher：定时监控状态变化 · Researcher：分解问题+一手来源 · Drafter：源→草稿，发送前等待批准 · Approval-gated Operator：展示确切变更等批准 · Auditor：盘点不改动 · Human Handoff：打包上下文交人决策

权限五阶段

级别Connector 权限典型场景
0无 connector（纯 prompt）通用对话
1只读查询数据、读文件
2准备草稿生成邮件/报告草稿
3批准后写入发送邮件、创建任务
4敏感工作流金融/凭据/健康/生产数据，每步人工批
证据标签体系 · 区分「产品说能做」与「有人真跑通」
Official Capability Community Template Observed Run Integration Note Experimental

每个 connector 标注来源可信度，帮助判断「这是 Meta 官方说的」还是「有人在生产环境真跑通了」。
