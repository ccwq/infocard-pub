一句话结论

VS Code 仍然是“扩展分发平台”而不只是编辑器：Copilot 用分发赢规模，Claude Code 用增速抢心智，开源/可自托管工具在 Open VSX 上持续抬头，而日常开发工具和语言 LSP 仍牢牢占据基础盘。L1 来源来自 extensionstats.dev、vsx-pulse.org、Eclipse Open VSX 公告与 Microsoft/第三方趋势报道。

01市场总览
MARKET SCALE

60K+ 到 100K+：市场已进入超大规模生态

用户提供的快照将 VS Code 扩展生态视为 60,000+ 级别；Microsoft 2025 公开里程碑又把 Marketplace 规模推到 100,000+ 扩展。两者都指向同一件事：VS Code 的竞争力不再只来自 IDE 本体，而是来自“扩展层”的网络效应。L1: 用户核实数据包；L2: getpanto.ai / Microsoft 2025 milestone

MARKETPLACE VS OPEN VSX

一个是 Microsoft 分发，一个是 vendor-neutral 备用通道

Marketplace 负责最大流量与默认分发；Open VSX 则服务于 Theia、VSCodium、云 IDE、AI-native 编辑器等 VS Code-compatible 生态。Eclipse 在 2026 年称其已达 300M+/月 下载，说明它不只是“替代品”，更像基础设施。L1: Eclipse News / Visual Studio Magazine

维度VS Code MarketplaceOpen VSX解读
分发逻辑默认主场、Microsoft 控制台开源治理、可自托管前者赢在流量与安装入口，后者赢在中立性与兼容面。
规模信号100K+ 扩展（公开里程碑）10,000+ 扩展、6,500+ 发布者、300M+/月下载两边都已是平台级市场，不是“插件集合”。
适配场景原生 VS Code 用户云 IDE / AI IDE / 兼容编辑器Open VSX 让 VS Code API 成为“跨编辑器分发标准”。
市场意义Copilot/官方扩展分发优势开源与新锐 AI 工具的外溢通道市场正在从“插件商店”变成“开发工具分发层”。

06趋势分析
TREND 1

增速排行：Claude Code > Codex > Copilot Chat

7 日增长显示代理式编码工具的新增关注正在加速向 Claude Code 倾斜；Copilot 体量仍最大，但增速不再一骑绝尘。L1: extensionstats.dev

TREND 2

Microsoft 的分发优势仍然最强

LinkedIn 追踪显示 Copilot 在 2025 年免费计划后增长加速，说明“默认入口 + 账号绑定 + 商业套餐”是最强护城河。L2: marinelamiclea

TREND 3

开源工具崛起，但更像“第二曲线”

Cline / Continue / Roo / Kilo 已经形成稳定梯队，但还没有把官方大厂拉下马；它们的价值是让团队能选择更可控的工作流。

TREND 4

Open VSX 正在变成 AI IDE 的基础设施

超过 300M/月下载意味着越来越多新编辑器和云开发平台把扩展注册表当作底层能力，而不是附属市场。L1: Eclipse News
