核心痛点：所有 AI 模型都训练在同一批 SaaS 模板上。不加引导，输出永远是：Inter 全家桶、紫蓝渐变、卡片嵌套卡片、灰色文字。Impeccable 通过共享设计词汇表和确定性 audit，让 AI 直接输出具有辨识度的专业级视觉。
01 · 一句话判断
Core Take
the vocabulary you needed

Impeccable 是 Anthropic frontend-design 的进化版，它不仅仅是一套 UI 模板，而是一套设计词汇表（1 Skill + 23 命令 + 27 反模式规则 + 7 领域参考），让 AI 理解"层次、节奏、色彩"的视觉表达，而非仅能生成平庸的 SaaS 模板。

Impeccable 解决什么问题
把"什么是好的前端设计"从主观审美变成可执行、可验证、可比较的确定性规则。AI 生成的每一次渲染，都对应着一条可追踪的设计依据。
关键判断SkillOpt 的价值不在于生成更多文本，而在于让 skill 的改进过程像训练神经网络一样可复现、可比较、可回滚。Impeccable 同样：它的价值不在于给 AI 更多模板，而在于让 AI 学会"为什么这样设计"。
它与 template 有什么不同
Template 是"复制粘贴"，Impeccable 是"词汇学习"。AI 学完这套词汇后，在任何项目、任何风格下都能输出符合设计规范的结果，而不是每次都套同一个壳。
使用建议在项目初期运行一次 /impeccable init，让 AI 理解品牌定位与产品类型，之后所有设计输出都会自动匹配上下文。

04 · 23 条命令详解
Commands Full List
流程控制 Flow Control
init
一次性配置：收集设计上下文，写 PRODUCT.md + DESIGN.md，开启 Live Mode，推荐下一步
craft
完整 shape-then-build 流程，含视觉迭代循环

在写代码之前规划 UX/UI 结构

将可复用组件抽离为设计系统 tokens
pin
将命令固化为快捷指令，如 /impeccable pin audit → /audit
质量保障 Quality Assurance
audit
技术 quality 检查：a11y、性能、响应式（确定性 27 规则，无需 API）
critique
UX 设计评审：层级、清晰度、情感共鸣
polish
发布前最终润色：设计系统对齐、可发布性检查
harden
添加错误处理、i18n、文本溢出、边界情况
设计调制 Design Modulation
bolder
强化平淡设计：增加对比度、层次感、视觉重量
quieter
降低过度激进设计：柔化色彩、减小对比
distill
剥离冗余，还原本质结构和信息层次
delight
增加愉悦感：微交互、动画惊喜、情感化设计
overdrive
增加技术炫酷效果：高级动效、复杂交互
专项增强 Specific Enhancement
animate
添加有意义、有目的的动效，而非装饰性动画
colorize
引入战略性色彩：品牌色、功能色、状态色体系
typeset
修复字体选择、层级关系、字号比例
layout
修复布局、间距、视觉节奏
clarify
改进不清晰的 UX 文案
adapt
适配不同设备和场景
optimize
性能优化：加载、包体积、渲染

首次使用流程、Empty states、激活路径

05 · 反模式与避坑
Anti-Patterns
AI Slop（AI 生成的典型偏差）
每条规则都有对应的确定性检测逻辑，无需 AI 介入即可自动发现：
// 严禁模式： - 紫→蓝渐变背景（AI Slop 标志性视觉） - bounce / elastic 动画（过时感极强） - 深色模式暗角glow（氛围感过度） - 侧边栏边框（AI 常见装饰性边框） - Card 嵌套 Card（结构层次混乱） - 全套 Inter / Arial 字体
注意CLI 的 npx impeccable detect 可在不调用 LLM 的情况下自动发现以上模式。
通用设计质量（12 规则 LLM 纠偏）
不仅针对 AI Slop，也针对普通设计质量问题：
// 质量底线： - 行长超过 75ch（可读性差） - 紧凑间距（touch target < 44px） - 缺少必要的层级标题 - 灰色文字在彩色背景（对比度问题） - 纯黑/纯灰（应始终使用 tinted 版本） - 缺少 disabled / focus state
双重保护确定性规则（CLI）保证无需 API 也能发现问题；LLM 纠偏（12 规则）处理更复杂的上下文感知问题。
06 · 安装与多平台支持
Installation
推荐安装（CLI 自适应）
npx impeccable skills install
自动检测 harness 类型，写入对应路径（Cursor / Claude Code / Gemini CLI / Codex CLI 等），安装后重载 harness。
Claude Code 用户/plugin marketplace add pbakaus/impeccable 或 npx skills add pbakaus/impeccable
平台覆盖
Cursor Claude Code OpenCode Pi Gemini CLI Codex CLI VS Code Copilot Kiro Trae Rovo Dev Qoder
每个平台都有独立编译的 dist 文件（dist/cursor/ · dist/claude-code/ · 等），CLI installer 自动匹配。
独立 CLI（无需 API）
npx impeccable detect src/ npx impeccable detect index.html npx impeccable detect --fast --json .
扫描文件/目录/URL，JSON 输出，可集成到 CI/CD。
浏览器插件
Chrome 扩展：直接在任何网站上运行确定性 27 规则检查，不需要注册账号，不需要 API Key。
Website 下载
访问 impeccable.style，下载对应工具的 ZIP 包，解压到项目即可。
07 · 适用边界
Boundary
适合谁
✓
AI Coding 新手
想让 AI 生成的前端代码更具专业感，而不是套模板
✓
全栈工程师
没有设计背景，需要一套确定性标准来评判 AI 输出
✓
设计系统维护者
想让 AI 严格遵守现有设计系统规范，不擅自改风格
✓
前端团队负责人
需要统一的 AI 设计语言，避免团队内 AI 输出参差不齐
✓
DevOps / QA
需要把 AI 生成代码的设计质量检测纳入 CI 流程
不适合谁
✗
专业设计师领衔
已有完整设计系统且设计师深度参与，AI 只做实现
✗
纯后端项目
没有前端 UI 场景，Impeccable 价值无法体现
✗
非前端领域
目标是后端 API、移动端原生、游戏开发等非 Web UI 场景
