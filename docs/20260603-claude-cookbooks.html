03 CLAUDE.md 关键设计规则 开发者规范
Model ID 规则
始终使用非日期别名（如 claude-sonnet-4-6），禁止使用 claude-sonnet-4-6-20250514 这类日期 ID
Bedrock 模型 ID
Opus: global.anthropic.claude-opus-4-6-v1
Sonnet: global.anthropic.claude-sonnet-4-5-20250929-v1:0
Notebook 规则
保持输出（演示用）+ 每 Notebook 一概念 + 端到端可运行
提交前检查
make check → format + lint + pre-commit hooks + notebook review + model check
API Key 安全规则
永远不要提交 .env 文件
使用 dotenv.load_dotenv() → os.environ / os.getenv() 读取
依赖安装必须通过 uv add 或 uv add --dev，禁止手动编辑 pyproject.toml
分支命名格式：<username>/<feature-description>
Commit 格式（Conventional Commits）：feat(scope): / fix(scope): / docs(scope): / style:
⚡ 快速启动命令
# 克隆 + 安装依赖 git clone https://github.com/anthropics/claude-cookbooks.git cd claude-cookbooks && uv sync --all-extras # 安装 pre-commit hooks（自动检查 notebook / model IDs / links） uv run pre-commit install # 设置 API Key cp .env.example .env # 编辑 .env，填入 ANTHROPIC_API_KEY=sk-... # 质量检查（commit 前必须跑） make check # 或 uv run ruff format . && uv run ruff check .
