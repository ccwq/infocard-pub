安装方式

Plugin Marketplace / npm / Git Clone 三种方式

推荐使用 Plugin Marketplace 安装，也可通过 npm 全局安装或直接克隆仓库。

Claude Code 安装
# 方式一：Plugin Marketplace（推荐）
/plugin marketplace add cathrynlavery/diagram-design

# 方式二：npm 安装
npm install -g diagram-design
cd diagram-design
open skills/diagram-design/assets/index.html

# 克隆到本地
git clone https://github.com/cathrynlavery/diagram-design.git

# 查看图表演示
open skills/diagram-design/assets/index.html
03
使用示例

一句话生成架构图 / 时序图 / SWOT

直接告诉 Claude Code 你要什么图表类型，它会调用对应的 Skill 生成出版级 SVG。

Claude Code 对话示例
# 直接告诉 Claude Code 你要什么图表
"Make me an architecture diagram of my app:
   web server, database, Redis cache."

"I need a quadrant chart for Q2 projects
   by impact vs effort."

"Give me a sequence diagram of a bearer call
   with token refresh on 401."

# 重绘已有的 Mermaid 或 draw.io 图表
"Redraw this Mermaid diagram for my deck"
