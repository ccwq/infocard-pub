使用示例
Claude Code 对话示例
# 直接告诉 Claude Code 你要什么图表
"Make me an architecture diagram of my app:
   web server, database, Redis cache."

   by impact vs effort."

"Give me a sequence diagram of a bearer call
   with token refresh on 401."
