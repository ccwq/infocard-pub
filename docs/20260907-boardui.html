01 · 产品定位

从源代码开始，而不是从黑盒开始

三个核心设计原则

① Source, not a dependency. npx boardui add 把文件复制进你的项目，你可以直接修改任何一行代码，没有黑盒约束。

② Built for agent products. 原生覆盖 chat、thinking indicator、agent log、composer、sidebar，以及 dashboard 常规组件，两套场景用同一套视觉语言。

③ Agent-native. MCP server 让 Claude Code、Cursor、Codex 等 AI coding agent 能直接浏览组件目录、读取真实示例、在项目中写入组件文件。

BoardUI 能做什么

• 5 个 agent blocks（Chat、Thinking、Log、Composer、Limits）+ Dashboard 组件全家桶
• 17 种数据图表（line/bar/area/radar/sankey/scatter 等）
• 62 个免费组件，涵盖 UI 基础件到完整页面模板
• 400+ Figma-first semantic tokens，自动生成 Tailwind v4 类名
• light/dark 双模式，同一套 token 类名切换

BoardUI 不是 Radix UI / Shadcn 的替代品。Shadcn 解决"表单 / 表格 / 导航"等通用界面，BoardUI 专攻"AI 产品"特有的 UI 模式——streaming、tool call 可视化、thinking indicator、agent 任务日志，两者是互补关系。

04 · QUICK START SOP

最短上手路径（四步完成）

Step 1 / 安装 BoardUI 到已有 Next.js 项目

npx boardui@latest init
# 或逐步：
npm install
npx boardui@latest list   # 查看全部 62 项

init 会安装 Tailwind v4、runtime 依赖、theme tokens 和 global styles。

Step 2 / 用 MCP 让 AI Agent 代你安装组件

# Claude Code 添加 MCP
claude mcp add boardui -- npx -y boardui@latest mcp

# Cursor / 其他 MCP 客户端（JSON config）
{
  "mcpServers": {
    "boardui": {
      "command": "npx",
      "args": ["-y", "boardui@latest", "mcp"]
    }
  }
}

添加后直接用自然语言描述需求："Install every free BoardUI component" 或 "Add a data table and stat cards to the dashboard"。

Step 3 / 用 CLI 手动安装特定组件

# 安装单个
npx boardui@latest add agent-chat
npx boardui@latest add data-table
npx boardui@latest add stat-cards

# 一次安装全部 62 项
npx boardui@latest add --all

add 命令同时写入组件 source 文件并安装缺失的 npm 依赖。

Step 4 / 连接 AI 模型（BYOK）

# .env.local
AI_API_KEY=sk-ant-...   # Anthropic（自动识别）
AI_API_KEY=sk-or-...    # OpenRouter
AI_API_KEY=sk-...       # OpenAI
AI_API_KEY=AIza...      # Google Gemini
AI_API_KEY=gsk_...     # Groq
AI_API_KEY=xai-...     # xAI

# 可选：指定模型（默认按 key 类型自动推断）
CHAT_MODEL=gpt-4o

# 自定义 OpenAI 兼容端点
AI_BASE_URL=https://your-ollama.example.com/v1
AI_PROVIDER=openai-compatible

key 只在 app/api/chat/route.ts 服务端读取，从不到达浏览器。

BoardUI 的 agent rules（AGENTS.md 片段 + .cursor/rules/boardui.mdc）会在 init 时安装，让 AI coding agent 始终遵守 BoardUI 的 token 和 type scale 规范。
05 · TOKEN SYSTEM

400+ Semantic Tokens 架构

Token 分层

Primitives（颜色原语）：纯色值，如 --green-500: #15803d，不直接用在组件中。

Semantic Tokens（语义 token）：引用原语，映射到 text/bg/border/foreground/chart 语义。--color-text-primary: var(--green-800)。

Tailwind v4 Classes：semantic token 再包装成 bg-primary、text-foreground 等 Tailwind 工具类，在组件中使用。

Light / Dark 切换

同一套 semantic token 和 Tailwind 类名，通过切换 data-theme="light" / data-theme="dark" 自动对应不同的原语映射，无需重写组件代码。

color tokenstext / background / border / foreground / chart 五组
spacing / radii与 Tailwind v4 一致的间距与圆角 token
shadow tokens多个强度级别的 box-shadow token
type scaleFigma 完整 type scale 作为 Tailwind composite 类名
gradient utilitiesbutton gradient 工具类

07 · 安全部署

公开部署前的必做清单

任何人都能访问你的部署 URL，所有请求会计费到你的 API key。三层防线：

防线一：设置 API Key 消费限额（必做）

  • ✓ OpenAI：项目级 usage limit
  • ✓ OpenRouter：在账户设置中设 credit cap
  • ✗ Anthropic / Google：这些 provider 不支持细粒度限额 → 依赖防线二

防线二：Vercel 部署保护（推荐）

  • ✓ Vercel Dashboard → Settings → Deployment Protection → 启用 Password Protection
  • ✓ 或设置 X-Vercel-Protection-Bypass header 用于你的前端域名白名单

防线三：Rate Limiting（可选但推荐）

  • ✓ 在 app/api/chat/route.ts 前加 Vercel Edge Function 或独立 rate limit middleware
  • ✓ 示例：每 IP 每分钟最多 10 次请求
  • 注意：BoardUI 本身不提供内置 rate limiting，需自行实现。
08 · 适用判断

BoardUI 适合你吗

✓ 适合正在用 Next.js 构建 AI 产品界面（chat、dashboard、agent UI）
希望 AI coding agent 能直接维护 UI 代码
需要 Figma-first、设计师友好的 design token 系统
想要 React Aria 底层保障可访问性
✗ 不适合已有 shadcn/ui 或 Chakra UI，且不需要 agent-native 特性
纯移动端 React Native 项目（BoardUI 只支持 web）
需要服务端渲染的组件状态管理（BoardUI 主要客户端）
非 Next.js 框架（React Router、RSC 以外的 SSR 方案）
09 · 已知局限

选型前必须知道的问题

MCP 生命周期AgentStatus 和 ProgressSteps 暂不支持 MCP 2025-11-25 spec 中的 waiting/input_required 和 cancelled 状态
Token 格式尚未迁移到 W3C DTCG 2025.10 格式，Style Dictionary v4 / Tokens Studio 兼容性暂不可用
MCP lifecycleinput_required 和 cancelled 两个 MCP task state 未实现，详见 MCP 2025-11-25 spec
chart cards17 种图表卡中仅 2 个（orders-chart-card、revenue-chart-card）在免费仓库，其余属 Pro
shadcn 命名BoardUI MCP 通过 shadcn schema 对接时组件名为 @boardui/<name>，需在 components.json 配置额外 namespace
