BoardUI：给 Agent 界面准备的 React 组件源代码

BoardUI 是面向 agentic interfaces 的 React design system：提供可复制进项目的组件、application blocks、tokens 和 type scale，并配套 CLI 与 MCP。

官方入口：https://github.com/BoardUI/boardui

01 / 先看定位与边界

01

免费内容

官方 README 当前口径为 62 个 free items，覆盖基础组件、application blocks、tokens 与 type scale。

02

技术基础

React、Next.js、Tailwind CSS v4、React Aria Components 与 400+ semantic tokens；支持 light/dark。

03

安装方式

npm install；CLI 可用 npx boardui@latest list / add / add --all；MCP 用 npx -y boardui@latest mcp。

04

Agent 工作流

MCP 可浏览目录、读取源码和示例、初始化项目、写入组件、安装依赖及 Agent rules；注册后需重启客户端或新会话。

05

部署安全

BYOK 与 OpenAI-compatible AI_BASE_URL 可用；公共部署必须保护 /api/chat、限制 key 费用，不能把真实 key 写进代码或卡片。

06

许可边界

免费仓库为 MIT；BoardUI Pro 是独立商业层，包含 8 templates 和 23 components，使用 BoardUI License。
