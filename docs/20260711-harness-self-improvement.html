01 RSI：递归自我改进的概念起源
递归自我改进（RSI） 由 I. J. Good（1965）首次提出：一台"超智能机器"能在所有智力活动上超越人类，并设计更好的机器来改进自身。现代 AI 中的 RSI 意味着模型直接重写自己的权重，或更宽泛地改进训练流水线与部署系统。

Harness = 部署基础设施
原始模型与真实世界上下文之间的这层，与模型的原始智能同样重要。Claude Code、Codex 等成功 Agent 的核心使能。
📊
RSI 的双重路径
直接路径：模型重写自身权重。间接路径：改进训练流程和部署系统，使后继模型获得更好表现。
⚡
AI 研发加速
前沿实验室的 AI 研究开发速度已被证明大幅加快。Harness 的改进是重要驱动因素之一。
02 Harness 设计模式：三大核心架构
⚙️
模式 1：工作流自动化
Harness 管理 Agent 与环境的交互流程：任务规划、工具调用、结果处理、错误恢复。Claude Code 的执行循环即此模式。
Tool-use Loop
💾
模式 2：文件系统作为持久记忆
将工作记录以 Markdown/JSON 形式写入本地文件系统，作为 Agent 的外部记忆层。Rowboat、Memex 均属此类。
Local Storage
🔀
模式 3：子 Agent 与后台任务
主 Agent 调度子 Agent 并行处理子任务，后台静默运行。Claude Code 的 parallel mode、Rowboat 的 cron 任务均为此模式。
Parallel + Cron
核心洞察：Harness 不是"让 AI 更强"，而是"让 AI 能在真实任务中稳定运行"。原始模型评测与 Harness 部署后的实际表现之间，存在巨大鸿沟。

04 Harness 优化：五大研究方向
优化方向核心问题典型方法
上下文工程如何将任务上下文转化为 LLM 可用的最优格式MCE、密度链、主动检索
工作流设计如何组织多步骤任务的操作顺序与分支逻辑LLM Compiler、PlanRAG
自我改进Harness 本身如何从历史执行中持续改进RSI、进化式搜索、反思机制
进化式搜索如何在策略空间中进行高效搜索遗传编程、程序搜索
模型权重联合优化如何将 Harness 改进与模型权重更新联合优化Post-Training、RLHF

06 案例研究：编码 Agent Harness
✅ Claude Code / Codex
成功要素：工作流自动化（Tool-use Loop）+ 文件系统持久记忆（项目上下文）+ 子 Agent 并行处理 + 完善的错误恢复机制
Tool-use Loop 文件系统记忆 子 Agent
❌ 早期 Agent 框架
缺失：缺乏持久化记忆、工具调用链断裂、无错误恢复、无 Harness 层设计，模型能力再强也无法稳定完成任务
无记忆 无 Harness
