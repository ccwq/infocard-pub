02
概述

FluentRead 是什么：开源浏览器双语翻译插件

GitHub 8,322 ★ / GPL-3.0 / TypeScript，2023-12-22 创建。与传统翻译工具的差异在于"双语并列 + AI 阅读卡 + 字幕下载"三合一。

一句话定义

一款运行在浏览器中的开源双语翻译插件，支持页面翻译、AI 阅读卡、字幕下载、文档翻译和学习记忆，连接 DeepSeek Harness 会话核心的浏览器适配版。

对比维度 FluentRead DeepL / Google 翻译 普通翻译插件
双语并列 ✓ 原文 + 译文对照 ✗ 纯译文替换 — 不等
AI 阅读卡 ✓ 选文即解读（meaning/句析/用法/练习） ✗ 无 — 不等
YouTube 字幕 ✓ 双语字幕加载 / 下载 ✗ 无 — 不等
DeepSeek Harness 集成 ✓ 阅读卡适配会话核心 ✗ 无 ✗ 无
开源 ✓ GPL-3.0 · 8,322 ★ ✗ 闭源 — 不等
学习记忆 ✓ 生词本 + 语境保存 ✗ 无 — 不等

03
核心功能①

双语页面翻译：原文与译文并列显示

不同于替换式翻译，FluentRead 将原文与译文并排展示，配合多种触发方式和原文还原功能，保证阅读体验流畅。

悬浮翻译

Hover 翻译

鼠标悬停即可触发翻译，无需选中，实时双语对照。

选中翻译

选中文本翻译

选中任意段落后弹出双语对照窗口，译文可复制。

原文还原

还原原文

一键切换回原文，方便对比学习或验证翻译准确性。

自动规则

自动翻译规则

为特定网站设置自动翻译规则，打开页面即自动双语显示。❓ 具体规则数量上限未实证。

❓ 未实证项：自动翻译规则的配置上限数量、最多支持同时启用的规则数，建议查阅 read.thinkstu.com/en/guide/ 确认。
04
核心功能②

AI 阅读卡（DeepSeek Harness 会话核心浏览器适配版）

融合 DeepSeek Harness 会话核心的事件与消息组织组件，在浏览器端实现上下文感知的 AI 阅读辅助。选文即解读，支持五步学习。

Harness 集成说明

AI 阅读卡适配了 DeepSeek Harness 会话核心的事件和消息组织组件，连接到选中文本、允许的段落上下文、模型服务和本地阅读历史。集成范围与上游引用见 integration map 文档（MIT 许可证）。

上下文输入

选中文本 + 段落上下文

不仅翻译选中句，还提供完整段落语境，帮助理解整体逻辑。

模型服务

多种 AI 提供方

支持 DeepL、Ollama 本地模型、免费翻译服务。❓ 具体支持的翻译引擎总数未在 README 中明确列出。

本地历史

阅读历史记录

本地保存阅读历史，随时回顾已解读的文本。

术语表

自定义术语表

配置专业术语对照表，AI 阅读卡在解读时优先使用指定译法。

五步 AI 学习支持（选文即解读）：

1
Meaning（含义）

词义与语境解释，帮你理解这句话在说什么。

2
句析（Sentence Analysis）

语法结构拆解，主谓宾定状补逐层分析。

3
用法（Usage）

这个词 / 句型在真实语境中的常见用法举例。

4
练习（Exercise）

根据当前内容生成练习题，巩固记忆。

5
追问（Follow-up）

支持继续提问，AI 深入解答相关延伸问题。

❓ 未实证项：五步支持是否为所有 AI 提供方（DeepL / Ollama / 免费服务）均可用；DeepSeek 模型具体兼容性（如 deepseek-chat / deepseek-coder 的具体版本支持情况）建议查阅 integration map 文档。
05
核心功能③

YouTube / X 字幕工作流：下载 → Agent 总结

FluentRead 支持加载 YouTube 和 X 的双语字幕，X 视频还支持本地 AI 转录，实现完整的视频内容理解管道。

①
打开 YouTube 视频

安装 FluentRead 后访问任意 YouTube 视频页面，插件自动检测字幕轨道。

②
加载双语字幕

FluentRead 加载原语言 + 目标语言双语字幕轨道，左原右译对照播放。❓ 双语字幕的触发语言对数量未实证。

③
下载字幕文件

一键下载 SRT/ASS/VTT 等格式字幕文件，保存到本地供后续处理。

④
交给 Agent 总结

将下载的字幕文件作为上下文输入给 AI Agent（如 DeepSeek），生成结构化摘要、要点提取或问答。

X 视频

X 视频本地 AI 转录

X（Twitter）视频支持本地 AI 自动转录，无需上传到云端，保护隐私。❓ 转录模型名称未在素材中明确。

字幕格式

SRT / ASS / VTT

支持主流字幕格式导出，兼容多数 Agent 工具和播放器。

❓ 未实证项：YouTube 字幕的字幕语言对具体支持范围；X 视频本地转录使用的具体模型；字幕下载是否有频率限制。
06
核心功能④

学习中心：生词本 + 语境保存 + 复习

在学习过程中即时保存生词、短语和句子，保留原始语境，方便后续复习巩固。配合 AI 阅读卡形成完整的学习闭环。

生词保存

单词 / 短语

在阅读时选中任意单词或短语，一键保存到学习中心，自动附带当前句子作为语境。

语境保留

原文语境快照

保存时自动记录该词在原文中的位置和完整句子，回顾时还原真实阅读情境。

复习模式

间隔复习

❓ 具体复习算法（间隔重复 / 自适应等）未在素材中明确，建议查阅用户指南。

与 AI 阅读卡的协同：通过 AI 阅读卡的"用法"和"练习"步骤学到的词，可在阅读卡内直接保存到学习中心，形成「AI 教学 → 记忆保存 → 复习巩固」的闭环。
07
核心功能⑤

文档翻译：PDF / ePub / DOCX 双语阅读

除网页外，FluentRead 还支持主流文档格式的双语翻译，可编辑译文并导出，方便处理学术论文、技术文档等长文本。

PDF

PDF 双语翻译

导入 PDF 文件后，FluentRead 在原文旁渲染译文，双语对照阅读。❓ 扫描版 PDF 是否支持 OCR 未实证。

ePub

ePub 双语翻译

电子书格式支持，保留排版样式，实现沉浸式双语阅读体验。

DOCX

Word 文档翻译

Word 文档双语翻译，可编辑译文，导出为新文档。❓ 表格、图片内文字是否一并翻译未实证。

可编辑译文

译文编辑

翻译结果可手动调整，确保专业术语准确，符合个人表达习惯。

导出

多格式导出

❓ 导出具体支持格式（PDF/Word/纯文本等）未在素材中明确列出，建议查阅用户指南。

安装与快速上手

从 Chrome Web Store 一键安装，或从 GitHub Releases 手动加载。支持 Firefox 等浏览器。安装后三步开始使用。

安装插件

Chrome Web Store 搜索「FluentRead」安装，或访问 github.com/FluentRead/FluentRead/releases 下载 .crx/.zip 手动加载。

选中文本 → AI 阅读卡

打开任意网页，选中文本，右键或快捷键触发 AI 阅读卡，开始五步学习。

09
术语表

核心概念速查

本卡涉及的关键术语中英对照，方便快速查阅。

双语翻译（Bilingual Translation）
原文与译文在同一视图中并列显示，而非替换原文，方便对照学习与验证准确性。
AI 阅读卡（AI Reading Card）
选中网页文本后弹出的 AI 辅助面板，提供含义解释、语法分析、用法举例、练习题和追问功能，融合了 DeepSeek Harness 会话核心的事件与消息组织组件。
DeepSeek Harness
DeepSeek 的会话框架（会话核心），负责事件和消息的组织与路由。FluentRead 的 AI 阅读卡适配了其浏览器端的集成规范，实现上下文感知与本地历史。
术语表（Glossary / Terminology Table）
用户自定义的专业词汇对照表（如 "algorithm → 算法"），AI 阅读卡在解读时优先使用指定译法，保证专业文档翻译一致性。
本地 AI 转录（Local AI Transcription）
在本地设备上运行 AI 模型（不上传云端）将视频音频转为文字，X（Twitter）视频支持此功能，保护隐私。
原文还原（Restore Original）
双语翻译模式下，一键将译文切换回原文显示，方便在学习过程中对比验证翻译质量。
Ollama 本地模型（Ollama Local Model）
通过 Ollama 平台在本地运行的 LLM（如 Llama、DeepSeek 等），无需 API 费用，数据完全本地处理。
五步学习支持（5-Step Learning）
AI 阅读卡提供的系统化学习路径：Meaning（含义）→ 句析（语法结构）→ 用法（真实语境举例）→ 练习（生成习题）→ 追问（延伸答疑）。
