技术工具 · Agent 上下文层

ktx
给数据仓库加一层可被 AI 复用的业务上下文

把已批准的指标定义、可连接字段、仓库元数据、wiki 和团队知识整理成 agent 能直接调用的上下文，让 Claude Code、Codex 这类工作流更稳定地查数、写 SQL、做分析。
2026.06.21发布
来源：GitHub 仓库
定位：本地工具 / 只读接入
它不是聊天模型，而是把仓库知识组织成 AI 可直接复用的上下文层。
ktx 面向数据与分析 agent，目标是减少“猜指标、猜表关系、重写 SQL”的情况。它会自动汇聚数据仓库元数据、已批准的指标定义、可连接列、wiki 和团队知识，并以 CLI、MCP 等方式接入本地工作流。对于已经在用 Claude Code 或 Codex 的开发者，它更像一个把业务口径固定下来、让 AI 更稳地读懂仓库的中间层。

01核心能力

自动整理业务知识

  • 汇总 wiki、文档、仓库元数据
  • 吸收已批准的指标定义
  • 发现可连接列 / joinable columns

让 agent 更稳定地查数

  • 减少口径漂移
  • 降低“猜表结构”的概率
  • 辅助生成更可复用的 SQL / 分析结果
02适用场景

数据团队

希望把指标口径、数据模型和文档统一进一层上下文，减少反复解释。

Agent 工作流

已经使用 Claude Code、Codex 或本地 agent，希望让它们更懂仓库、更懂业务。
