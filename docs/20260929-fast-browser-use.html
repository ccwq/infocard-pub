Fast Browser Use
把决策变成一次打分

对 Jev 的开源逆向：不再让大模型逐字生成代码来操作浏览器，而是把可见的可交互元素映射成词表 token，用 单步 logits 打分直接选出下一步动作。权重用开源 Qwen3.5-9B / 35B-A3B，全程 100% 本地推理。

30.09 s维基百科任务端到端中位耗时（9B 4-bit，3 次试验）
8.52 s首个浏览器动作下发时间
5.95 GBMLX 4-bit 权重加载后的内存足迹
决策路径
4 次前向
整条实时任务由 4 次单 token 前向传播完成：聚焦搜索框 → 回车查询 → 点主条目 → 确认完成。绕开了自回归代码生成循环，这也是“没有选择器幻觉”的结构性原因。

RLCD 思路用强化学习让模型直接给“有界、带类型的决策空间”打分，而不是自由生成文本；本项目用开源权重在本地复刻这条路径。

边界
05

速度来自范式，不是模型

延迟优势建立在“决策空间有界”这个前提上：一旦任务需要开放式规划，就得回到 System 2 式的推演。另外 30 秒里包含约 2.2 秒/次 的页面稳定等待，这部分是浏览器物理时间，与模型无关。
