Astryx 起源于 Meta 内部最大的设计系统，8 年迭代后成为公司标准，驱动了 13000+ 内部应用。它不要求你引入整套样式框架——样式用 StyleX 编写，但消费端完全透明。

核心差异化在于：主题是一组 CSS 变量覆盖，设计师改皮肤无需 fork 或包组件源码；swizzle 命令能把任意组件完整源码导出到项目里自己接手；API / 文档 / CLI 三位一体，人和 AI 助手用的是同一份参考文档。

01核心特性
无样式锁定

StyleX 对消费端透明

样式内部用 StyleX 编写，但消费者完全无感知。可以用 className 搭配 Tailwind、CSS Modules 或原生 CSS 做任意覆盖。

设计即代码

主题 = CSS 变量覆盖

设计师改皮肤不需要 fork 源码或包一层组件。只改 CSS 自定义属性，Astryx 组件自动响应。

开放内部结构

任意层级拆解 + swizzle

组件在任意层级都可直接引用其 building blocks。需要深度定制时，swizzle 把完整源码导出到项目里。

人机同一参考

API / 文档 / CLI 一体设计

文档、API 约定和 CLI 同步设计，人和 AI 助手从同一份参考出发，减少理解偏差。

02安装
npm
npm install @astryxdesign/core @astryxdesign/theme-neutral
npm install -D @astryxdesign/cli
pnpm
pnpm add @astryxdesign/core @astryxdesign/theme-neutral
pnpm add -D @astryxdesign/cli
yarn
yarn add @astryxdesign/core @astryxdesign/theme-neutral
yarn add -D @astryxdesign/cli

package.json 脚本："astryx": "node node_modules/@astryxdesign/cli/bin/astryx.mjs"，调用 npm run astryx -- component --list。无构建插件、无 PostCSS/Babel 配置，最简设置只需几行 CSS import 加主题 Provider。
