TokenTamer

Drop-in proxy that compresses bloated code context in real-time

TokenTamer 位于 AI 编程代理与 LLM API 之间：拦截 payloads、用 AST 解析代码，把「背景文件」替换为结构骨架，同时保留「活跃文件」的完整内容。节省 50–80% API 费用。

v0.2.0 MIT License Python 3.10+ 5 Clients AST Compression Tool-Aware Anthropic Cache
⚠️ Alpha 软件。

压缩取决于文件重读次数（单次读取无收益）；启发式文件检测可能漏掉特殊 schema；仅 macOS 提供一键证书配置。

ANTHROPIC PROMPT CACHING — ~73% OFF LONG SESSIONS
❌ Without TokenTamer
Turn 5: [sys, tools, msg1-5] $$$$$
Turn 6: [sys, tools, msg1-6] $$$$$$
Turn 7: [sys, tools, msg1-7] $$$$$$$
Turn 50: [sys, tools, msg1-50] $$$$$$$$$$
50-turn Claude Code session ≈ $3.00
✓ With TokenTamer (cache-first)
Turn 5: [prefix cached] [msg4,5] $$ $0.30/M
Turn 6: [prefix cached] [msg4,5,6] $$ $0.30/M
Turn 7: [prefix cached] [msg4,5,6,7] $$ $0.30/M
Turn 50: [prefix cached] [msg4..50] $$ $0.30/M
50-turn Claude Code session ≈ $0.80 · ~73% saved
// CACHE-FIRST DESIGN — WHY ORDER MATTERS
# Anthropic cache 是 exact prefix match
# 如果字节变了 → 整个 prefix cache miss
# Cache miss → pay $3.75/M (write cost) NOT $0.30/M (read cost)

# Broken order (compress-first → then cache):
#   → 压缩后的 bytes 与 Turn 1 不同
#   → $3.75/M × huge prefix = 比不加 cache 还贵!

# TokenTamer 正确顺序 (cache-first → then compress):
1. 先在原始消息上添加 cache_control breakpoints
2. compression 只作用在 cached prefix 之后的消息
3. prefix 字节在 Turn 间完全一致 → 真的 hit $0.30/M
