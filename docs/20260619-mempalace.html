Core Features

本地优先架构

逐字存储，无摘要、无 paraphrase。可插拔后端（Chromadb / SQLite-exact / Qdrant / pgvector），~300 MB 嵌入模型，无 API key 即可运行基准测试。

MCP Server

33 个 MCP 工具

覆盖 palace 读写、知识图谱操作、跨 wing 导航、drawer 管理和 Agent 日记。通过 Docker stdio 接入 Claude Code 等 MCP 客户端。

Auto-save Hooks

自动保存钩子

Claude Code / Codex 在上下文压缩前自动保存，Cursor IDE 额外快照 session-start recall。`mempalace sweep` 做逐消息回填。
