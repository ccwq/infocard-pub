02
QUICK START

三步上手

从安装到跑通第一个自动化任务，只需三步。支持 Python 3.10+，异步架构。

安装

pip install browser-use

一行命令安装，支持 Python 3.10+。可选 Docker 方式运行。

pip install browser-use # Docker（可选） docker run -p 9222:9222 browser-use/cloud
配置

配置 API Key

设置 OpenAI / Anthropic / Google API Key，通过环境变量或代码传入。

export OPENAI_API_KEY="sk-..." # 或在代码中配置 browser = BrowserUse(model="claude-3-5")
运行

编写异步任务脚本

用 Python asyncio 编写任务脚本，Agent 自动完成所有浏览器操作。

import asyncio from browser_use import Agent async def main(): agent = Agent(task="帮我搜索...") await agent.run() asyncio.run(main())
