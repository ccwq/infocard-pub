## 一句话结论

Graphify 不是普通 RAG 封装，而是一层“把任意项目文件夹转成知识图，再让 AI coding assistant 查询这张图”的项目知识层。

## 为什么选 graph-paper

这不是单点工具卡，而是典型的图谱型仓库：
- code + docs + PDF + images + video
- graph.html + GRAPH_REPORT.md + graph.json
- query / path / explain / MCP server / install hooks
- 面向 Claude Code / Codex / Cursor / Hermes / OpenClaw 的跨助手工作流

因此最适合用 `graph-paper` 来表达“节点、连线、索引、知识层”这类结构感，而不是用普通工具海报或工作台风格。

## 这张卡重点强调什么

1. 它把项目的多种输入（代码、文档、媒体、配置）统一压成图谱
2. 它不是一次性可视化，而是持续查询层
3. 它通过 `graphify install` 进入 AI coding assistant 的日常工作流
4. 它更像 graph context / memory layer，而不是普通搜索插件
