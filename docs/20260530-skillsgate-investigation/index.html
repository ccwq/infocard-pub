PRODUCT SHAPE能力拆解

发现与安装

  • 统一搜索技能，不必在 GitHub 里手工找 Markdown。
  • 支持按 agent 安装，或一次发给多个 agent。
  • 适合维护跨模型 / 跨助手的共用技能栈。

编辑与维护

  • 内置编辑器可看渲染结果，也可改原始源文件。
  • 保存到磁盘后即时生效。
  • 更像一个本地技能工作台，而不是单次下载器。

组织与协作

  • Favorites 方便收藏高频技能。
  • Remote servers 支持连接其他机器同步技能。
  • Private skills 适合保留本地私有能力。

产品形态

  • Desktop App：适合图形化浏览和管理。
  • TUI：适合键盘驱动工作流。
  • CLI：`npx skillsgate` 可直接上手。

VERDICT调查结论
如果把 SkillsGate 只当成“技能下载工具”，会低估它。更准确的说法是：它是面向 AI agents 的技能市场与管理器，服务的是“发现—安装—编辑—同步—分发”全链路。

适合什么人

  • 多 agent / 多客户端并行使用的人。
  • 需要统一维护一套技能体系的团队。
  • 需要本地编辑、远程同步、收藏管理的人。

它的边界

  • 它不是通用推理引擎，也不是模型服务。
  • 核心是目录、分发与管理，而不是生成能力本身。
  • 更像技能市场，而不是单机插件合集。
USAGE TIP 如果你要把多个 agent 的技能管理统一起来，SkillsGate 适合作为中控入口；如果只是临时找一个 skill，直接搜与装就够了，不必引入复杂流程。
