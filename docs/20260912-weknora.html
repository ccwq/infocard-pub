■ 三核心模式

RAG · Agent · Wiki

简单问题走检索，复杂问题交给 Agent 自动查知识库、调工具、搜网络，Wiki 模式把文档变成互相链接的知识页。

① 文档入库 飞书 / GitLab / Notion / 语雀 / RSS / 网页
② 切块索引 向量 + 关键词 + 知识图谱四路检索
③ 回答模式 RAG 快速检索 / Agent 推理 / Wiki 生成
④ 接入同事 企业微信 / 飞书 / Slack / 网页嵌入 Widget
⚡
安装部署

Docker 一键部署，或用云服务

方式一：Docker Compose（推荐）

git clone https://github.com/Tencent/WeKnora.git
cd WeKnora/docker
docker compose up -d
需 4GB+ RAM，支持 x86_64 / ARM64

方式二：WeKnora Cloud（免运维）

访问 https://weknora.weixin.qq.com
注册后创建知识库，导入文档即可
有免费额度，适合先试用再决定是否私有部署
三种模式覆盖不同复杂度的知识问答需求

RAG Quick Q&A 适合事实性查询（单轮对话、带出处片段）；ReAct Agent 适合多步推理（查知识库、调 MCP 工具、联网搜，综合结论）；Wiki Mode 把一堆文档自动提炼成互相链接的知识页面，支持手动编辑和版本回滚。

📖 RAG Quick Q&A

上传文档 → 自动切块建索引 → 直接提问 → 答案带出处片段

  • 适合：制度查询、客服问答、文档检索
  • 多知识库隔离
  • 向量 + 关键词混合检索
  • 可上传 FAQ 格式

🤖 ReAct Agent

Agent 自动编排：查知识库、调 MCP 工具、联网搜索，综合推理后给结论

  • 适合：复杂调研、多数据源汇总
  • 内置 MCP 工具调用
  • Docker/E2B 沙箱执行代码
  • Session 持久化记忆

📚 Wiki Mode

Agent 自动把文档整理成互相链接的知识页，自动生成摘要、关系图谱、定期更新

  • 适合：团队知识沉淀、冷启动
  • 交互式知识图谱
  • 支持手动编辑 + 版本历史
  • 一键回滚

⚠️
边界与局限

什么情况不适合用 WeKnora

❌ 扫描件处理

扫描 PDF / 图片型文档需要额外 OCR 处理，官方 v0.8.0 仍未内置；有社区 fork 在做这个。

❌ 实时数据

不是数据库，频繁变更的数据不适合建知识库；Wiki 更新有延迟。

❌ 中小企业轻量场景

部署和运维有一定复杂度；飞书自带知识库已能满足简单需求。

⚠️ License 待核实

⚠️ 数据安全

上传文档到云服务需评估数据合规；敏感文档建议私有化部署。

⚠️ 多语言支持

主仓库文档以英文为主；中文社区支持良好但部分 Issue 回复较慢。
