01

结构：不是一个技能，而是一套运动图形技能体系

仓库不是单点工具，而是 14 个可安装 pack 的总仓库。每个 pack 面向一个明确的内容生产场景，并且以 SKILL.md + references 的形式打包，方便 Agent 理解与复用。

内容类型
短视频、数据动画、解释型视频、品牌动效、网站动画、3D / WebGL、数学动画。
技能格式
每个技能包由 SKILL.md + 参考文件组成，便于 Agent 读取规范与示例。
工作流
生成 → 渲染 → 截图/抽样 → 自检 → 继续迭代。
目标
把 motion 设计从“人肉手工”转成“Agent 可执行的技能”。

04

为什么它不是“素材库”，而是“Agent 技能”

核心差异在于验证闭环。motion 类任务最容易在时间、节奏、范围、帧率上翻车，所以它们把“生成”与“检查”绑在一起。

普通素材库
  • 给你片段，不保证能用。
  • 不检查时序与渲染结果。
  • 更像资源合集。
motion-skills
  • 每个 Skill 讲清楚怎么做。
  • 配套渲染验证流程，自检输出。
  • 更像可执行的 craft manual。
05

适合什么场景

适合任何需要把“motion”变成可复用工作流的团队：营销、内容、电商、教育、前端、数据分析、3D、数学讲解。

短视频 / Reels

节奏、字幕、切点、封面节拍统一。

数据动画 / 信息图

让数字、图表、趋势变化能在屏幕上讲清楚。

WebGL / 3D / 数学动画

把复杂的视觉效果和解释型动画纳入 Agent 流程。
