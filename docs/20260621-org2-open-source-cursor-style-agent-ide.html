ORG-II

Open-source Cursor-style agent IDE — built for reviewability, traceability, and control.

开源的 Cursor 风格 Agent IDE：用 Rust + Tauri 本地运行 < 100MB，支持 Agent 轨迹直播与回放、跨会话记忆、AI blame，配 Issues/Projects 做 org 级对齐。

Rust + Tauri 轨迹回放 跨会话记忆 Org 级对齐 本地优先
不只是另一个 AI 编程工具——而是人/Agent 组织与 org 级对齐的实验

Cursor、Claude Code 把 agent 当外包助手：输出有用，但难以审计、协调、对齐或系统级演化。ORG-II 把 agent 当持久、可观察的同事：Replayable 轨迹、跨会话记忆、AI blame，让人类、agent 和团队围绕共享上下文与对齐目标协作。
