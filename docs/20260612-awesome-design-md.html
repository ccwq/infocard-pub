HOW TO USE — 3 STEPS
// STEP 1: COPY DESIGN.MD → PROJECT ROOT
# 从 awesome-design-md 选一个品牌的设计文件
# 例如：Stripe 的设计 token

# STEP 2: Tell your AI coding agent to use it
Copy DESIGN.md into ./design/ directory

# Prompt example:
# "Build a pricing page that follows the Stripe design language
# "Use the design tokens from ./design/DESIGN.md"
# "The accent color is Stripe Purple (#635BFF), use it for CTAs"

# STEP 3: AI generates UI matching the design
# Result: pixel-consistent UI without Figma exports

# Each DESIGN.md also ships with:
# → preview.html      (light mode visual catalog)
# → preview-dark.html (dark mode visual catalog)

DESIGN.MD vs CLAUDE.MD / AGENTS.MD
❌ CLAUDE.md / AGENTS.md
只描述"怎么构建"，不描述"长什么样"
设计描述靠自然语言，AI 生成的视觉容易漂移
颜色靠"蓝色按钮"这种模糊描述
没有结构化 token，跨品牌一致性无法保证
✓ awesome-design-md
精确的 hex 色值、字号、间距 — AI 生成不走样
结构化 9 维度，Design + Build 都有
Google Stitch 官方格式，工具原生支持
73 个品牌开箱即用，持续新增
