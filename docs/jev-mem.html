Jev-Mem：把记忆管理的快速决策与深度推理分离

System One 控制器组织记忆并引导检索，昂贵 LLM 只在最后一步登场——记忆管理不再需要把所有上下文喂给大模型。

LLM 读取所有记忆才能找到一条——这个模式效率瓶颈明显。
Jev-Mem 引入 System One（轻量级控制器）专职做记忆管理决策：判断关系、路由查询、分配预算、评分候选、评估证据。只在检索完成后，才把整理好的证据交给 System Two（LLM）合成最终回答。

ARCHITECTURE三组件架构

System One

记忆打字、关系判断、查询路由、预算分配、候选评分、证据评估。决策输出 Noul（二元命题）和 Choice（分类决策）。轻量级，无需大模型。

Shared Memory

规范观察记录 + 四种关系图视图（语义 / 时序 / 因果 / 实体）+ 向量和关键词索引。多跳查询通过关系图高效遍历。

System Two

LLM 从选中的证据中合成最终回答。只在证据整理完成后登场，不参与记忆管理决策——减少 token 消耗。

Noul：二元命题决策

System One 输出二元判断，如"这条记忆与当前查询相关 / 不相关"。用于快速过滤候选证据，降低进入 System Two 的 token 量。

Choice：分类决策

在多个候选路径中选择最优检索策略——走语义索引、时序索引还是因果图。每一步都基于本地计算，不调 LLM。

Laya 集成（2026-09-27）：同一 pipeline 可选 Jev 或 Laya（HuggingFace 本地 System-One），无需改变记忆流程。Laya 支持本地模型推理 System One 决策。
