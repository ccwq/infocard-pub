ORCHESTRATION 编排

ORCHESTRATION 编排System One + System Two
CORE System One 控制器

轻量级控制器专职做记忆管理决策：记忆打字、关系判断、查询路由、预算分配、候选评分、证据评估。决策输出 Noul（二元命题）和 Choice（分类决策）。无需大模型。

关系判断→查询路由→候选评分→证据评估
NOULCHOICELOCAL
Noul：二元命题决策

System One 输出二元判断，如"这条记忆与当前查询相关 / 不相关"。用于快速过滤候选证据，降低进入 System Two 的 token 量。

BINARYRELEVANCE
Choice：分类决策

在多个候选路径中选择最优检索策略——走语义索引、时序索引还是因果图。每一步都基于本地计算，不调 LLM。

ROUTINGSTRATEGY
System Two LLM

LLM 从选中的证据中合成最终回答。只在证据整理完成后登场，不参与记忆管理决策——减少 token 消耗。

SYNTHESISEVIDENCE-IN
Laya 集成（2026-09-27）

同一 pipeline 可选 Jev 或 Laya（HuggingFace 本地 System-One），无需改变记忆流程。Laya 支持本地模型推理 System One 决策。

LAYALOCAL MODEL
↓ 检索完成后 System Two 才登场 · 不参与记忆管理⇢ Token 节省 Noul 过滤减少进入 LLM 的 token 量

MEMORY 存储

MEMORY 存储Shared Memory · 四种关系图
规范观察记录

统一格式存储记忆条目：时间戳、实体、事件、上下文标签。可追踪、可检索、可推理的结构化数据。

STRUCTUREDOBSERVATION
四种关系图视图

语义（Semantic）/ 时序（Temporal）/ 因果（Causal）/ 实体（Entity）。多跳查询通过关系图高效遍历，跨维度联想记忆。

4 RELSMULTI-HOP
向量 + 关键词索引

语义相似度检索（向量索引）+ 关键词精确匹配（倒排索引）。双重索引互补，平衡召回率与精确度。

VECTORKEYWORD
↓ 关系图遍历 Semantic / Temporal / Causal / Entity 四路并行⇢ Noul 过滤 快速筛除不相关候选
