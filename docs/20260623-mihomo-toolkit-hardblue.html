核心特性

最新版 README 把功能拆得更完整：节点清洗、地区折叠、分流开关、图标体系、机场标签、DAG 清理和底层防漏都已经写成可配置模块，而不是散落在脚本里的零碎 patch。

清洗去重

先把节点列表从“可见”变成“可用”

README 明确写了深度清洗去重：去冗余广告 / 倍率噪音、拦截纯文本引流节点、保留落地城市，并可按底层组合键做去重。

  • 支持保留落地城市
  • 通过 `enableDedupe` 去掉注水重复节点

  • 小众地区自动折叠

  • 可隐藏垃圾组与未知识别组

配置结构

`USER_CONFIG` 已经从“脚本参数区”升级成一张配置面板

新版 README 的 `配置详解` 展开得比旧卡完整得多，已经按“基础全局 / 节点清洗 / 核心分流 / 专项扩展 / UI 面板 / 底层防漏”六层来组织，而不是只列几个常用开关。

基础全局

enableScript / osType / proxyFirst / defaultProxyMode

决定脚本是否启用、设备类型、代理优先还是直连优先，以及默认策略模式。

节点处理

enableDedupe / removeInfoNodes / keepDestinationCity / showProtocolIcon

控制节点清洗、去重、图标化和地域展示，是“面板可读性”的核心参数层。

分流能力

enableAI / enableGame / enableSystemServices / enableGitHub / enableScholar…

把功能拆成可开关模块，而不是一整套写死规则；适合按自己的常用场景裁剪。

底层防漏

enableProcessDirect / enableTrafficAudit / overwriteTun / overwriteDns / overwriteSniffer

这层才是它和“只是做个策略组”拉开差距的地方：开始管理运行时行为，而不仅是命名和分组。

03
快速上手

真正的使用门槛不高，但前提是你已经在 Mihomo 生态里

README 给出的上手路径很短：获取脚本 → 在客户端给订阅挂上扩展脚本 → 刷新订阅 → 再到 `USER_CONFIG` 做个性化裁剪。

最小使用步骤

  • 从 Releases 下载最新版 `mihomo-toolkit.js`
  • 在 Clash Verge Rev 的订阅上使用“编辑拓展脚本”挂载
  • 刷新订阅即可生效
  • 若要复用到所有订阅，可改挂到全局拓展脚本

最适合谁

  • 多个机场 / 多订阅合并，节点列表已经开始失控的人
  • 需要 AI / 游戏 / 流媒体 / 回国模式分流的人
  • 在意 DNS、TUN、Sniffer、防 BT 泄漏这类运行时细节的人
  • 已经在 Mihomo 生态客户端中稳定使用脚本功能的人

如果你只想临时切个节点，这套方案会显得偏重；但如果你已经在长期维护面板，它的价值就会非常明显。
