01 · 它到底做什么
IDENTITY

不是“录制鼠标回放”

A
抽象意图Copilot 把一次操作整理为总体目的与有序步骤，而不是保存像素坐标。
B
优先原生工具生成内容优先使用 gh CLI、web_fetch 等 Agent 工具，不强制重放 UI 点击。
C
从一次到一类官方示例的目标是：录一次提交表单，Agent 可理解为处理同类表单的流程。

04 · 数据流
PRIVACY

本地录制 ≠ 数据永不上传

录制、存储、帧提取与可选旁白转录均在本机。只有用户主动按下 Analyze，才会把用于分析的数据发送到 GitHub 云端给 Copilot 处理。

Analyze 会发送的主要类别

窗口/文档标题和时间线、macOS 浏览器 URL、提取的低帧率屏幕图像、剪贴板短预览、可选旁白文本。

05 · 安全门槛
DO NOT SKIP

没有自动脱敏，就不要录秘密

高风险操作

不要在会话中展示、输入、粘贴、复制或口述密码、access token、API key、凭据与其他机密信息。官方也在每次录制前提醒此边界。

?
企业使用前先确认云端处理、屏幕内容、剪贴板预览与合规要求；不要把“local recording”误读成端到端离线。
06 · 使用决策
FIT

适合教流程，不适合录一切

+
适合有稳定重复流程、能用原生工具泛化、且可把演示环境清理为非敏感数据的任务。
−
不适合依赖私密页面、机密数据、一次性 UI 状态或精确坐标交互的流程。
→
推荐试法先用合成数据录一个小流程；审阅 Analyze 步骤；验证生成 Skill 能否在相邻任务中泛化。
