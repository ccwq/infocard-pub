JUDGMENT

文章漏了最大的点：作者权重。Kamran Ahmed 是 roadmap.sh 作者，driver.js 最初就是给 roadmap.sh 做引导抽出来的。

月下载 400 万+ 且仍在活跃维护（v1.8.0），选它基本不用赌维护风险。

CORRECTION · 文章代码已过时

文中示例用的是 v0 老 API（new Driver() + driver.highlight('#id')）——直接复制会报错。

v1（2023 重写后）是工厂函数：import { driver } from "driver.js"，单点用 driverObj.highlight({element, popover})。

TENSION

"5kb"是营销口径。

实测 JS+CSS 合计 10.3KB gzip，仍属第一梯队，但做性能预算时应按 10KB 计，别按 5KB。

03

04
键盘全控制
README 明确 everything controllable by keyboard——无障碍要求高的后台可以直接引用这条。
v1 正确用法 · 官网原文 API
// product tour — 多步导览
import { driver } from "driver.js";
import "driver.js/dist/driver.css";

const driverObj = driver({
  showProgress: true,
  steps: [
    { element: "#search",
      popover: { title: "Search",
        description: "Find anything." } },
    { element: "#profile",
      popover: { title: "Your account",
        description: "Settings & billing." } },
  ],
});
driverObj.drive();
// single highlight / hints
const d = driver();
d.highlight({
  element: "#new-feature",
  popover: {
    title: "New: Dark Mode",
    description: "Toggle in toolbar.",
  },
});

// 常驻提示是独立入口：
import { hints } from "driver.js/hints";
import "driver.js/dist/hints.css";
hints({ hints: [...] }).show();
