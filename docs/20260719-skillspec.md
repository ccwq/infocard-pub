# SkillSpec：让 Agent Skill 可测试、可证明

**⭐ Stars:** 993 | **许可证:** Apache-2.0 | **版本:** v0.1.8 (2026-07-05)

**GitHub:** https://github.com/modiqo/skillspec

## 概述
将自然语言 SKILL.md 转换为可诊断、可测试、可证明执行的 Agent 技能契约

## 核心特性
- Doctor 风险评分
- skill.spec.yml 契约
- 规则优先级检测
- 依赖声明
- 进度追踪
- Alignment 证明

## 快速上手
```
curl -fsSL https://skillspec.sh/install.sh | sh
```
