深度补充 ① Stagehand v3 · deterministic scripts

Stagehand v3 新增 deterministic scripts 功能，将 CUA 不稳定输出转化为可重复执行的确定性脚本。结合 browserbase 云端 stealth Chrome 使用，兼顾灵活性与稳定性。

★23k · MIT · browserbase/stagehand
核心价值
  • CUA → 确定性：AI 决策一次，脚本永久复用
  • browserbase 联动：云端 stealth Chrome + session replay
  • vs OpenAI Operator：本地可控，支持 self-host
  • skill 沉淀：.ts 脚本 → SKILL.md，零额外成本

深度补充 ② Midscene.js v1.6 · 原生 CDP connect

Midscene.js v1.6 支持原生 CDP 直连，无需 Playwright wrapper。对抖音视频号后台、wujie 结构等 shadow DOM 友好场景，是 Stagehand 之外的最佳视觉标注选择。

MIT · web-infra-dev/midscene
核心价值
  • 原生 CDP connect：v1.6 直接连 Chrome，不依赖 Playwright
  • 视觉标注：截图 + 自然语言描述，零 DOM 选择器维护
  • shadow DOM 友好：对嵌套 iframe / 虚拟 DOM 稳定
  • skill 沉淀：截图 + YAML 描述文件，可版本化

深度补充 ③ Chrome DevTools MCP

Chrome 148 后 DevTools Recorder 官方淡出，取而代之是 Chrome DevTools MCP。把 CDP 完整包成 MCP server，让 Claude / Codex / Hermes 直接通过 MCP 协议操作 Chrome，call log 可导出为 SKILL.md。

Apache-2.0 · ChromeDevTools/chrome-devtools-mcp
核心价值
  • 原生 CDP：Page / Runtime / Input / Network 全暴露
  • MCP 协议：每次调用 JSON-RPC，有日志可追溯
  • vs Recorder：MCP 让 AI 在录制中实时参与决策
  • skill 联动：MCP call log → SKILL.md，比 Recorder 多"AI 推理"
Chrome DevTools MCPMCP 协议Recorder 替代
