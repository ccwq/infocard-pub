它能做什么
capabilities
  • Sources支持 URL、YouTube、PDF、Markdown、Word、EPUB、音频/视频、图片、Google Drive、粘贴文本导入。
  • Chat & Notes可发问、保存回答、记录对话、创建/重命名/删除 notes。
  • Research提供 web / drive research agents，支持 fast / deep 模式。
  • Sharing管理 public/private 链接、viewer/editor 权限与可见级别。
  • Outputs可导出 Audio Overview、Video Overview、Slide Deck、Quiz、Flashcards、Infographic、Data Table、Mind Map、Report。
推荐工作流
pipeline
01登录
先用 notebooklm login 完成账号授权，然后在 CLI / Agent 中复用会话。
02导入
把网页、文档、视频、Drive 文件批量导入 NotebookLM 作为 source。
03生成
按需产出播客、报告、幻灯片、思维导图或问答卡片。
04下载
把结果导出为 MP3 / MP4 / PDF / PNG / CSV / JSON / Markdown / PPTX。
05接入
通过 Python / MCP / REST 让 Claude Code、Codex、OpenClaw 等 Agent 直接调用。
安装命令

uv tool install "notebooklm-py[browser]"
然后执行 notebooklm login。浏览器依赖默认会自动拉取 Chromium。

定位一句话

这不是单纯的 Python 封装，而是把 NotebookLM 变成“研究自动化 + 内容生产 + Agent 调度”的综合技能包。
