# 36章可运行的 AI Agent 全栈课程：技术分享报告

## 结论

`Callous-0923/agent-study` 不是零散笔记，而是一套**面向求职的 AI Agent 全栈课程包**。它把 Agent 学习拆成 36 章、7 层递进，并且把大量章节做成可运行的 `.py` 文件，适合按章节学习、按面试题复盘，也适合拿来补工程化和协议理解。

## 关键信息

- **定位**：AI Agent 全栈学习课程，面向求职与系统学习。
- **规模**：36 章、22000+ 行代码、60+ 可运行示例、28 个主题、7 层递进。
- **内容范围**：ReAct、LangGraph、多智能体、Claude Code、RAG、MCP、A2A、Tool Calling、FastAPI、SQLite、MemGPT、Computer Use、安全、可观测性、模型路由、缓存、评测与可靠性。
- **使用方式**：绝大多数章节可直接运行；前 1-5 章需要 API Key，后面大量章节仅依赖 Python 标准库。

## 推荐阅读路径

1. Ch0 环境搭建
2. Ch1-3 Agent 基础
3. Ch8 / Ch10 / Ch11 深技与协议
4. Ch13 / Ch14 / Ch19 / Ch24 工程化
5. Ch26 / Ch28 / Ch31 / Ch36 优化、评测、安全
