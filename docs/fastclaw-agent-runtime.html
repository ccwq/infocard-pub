what is it Agent Factory
core definition

FastClaw 是一个Agent工厂——创建、管理、运行AI Agent。每个Agent有自己的 SOUL.md（人格）、MEMORY.md（记忆）、Skills 和 Tools。FastClaw 负责 LLM 通信、工具执行、沙箱隔离、会话管理。

  "maxTokens": 8192,
