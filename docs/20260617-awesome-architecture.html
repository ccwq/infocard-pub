Awesome Architecture

把“写代码之前先想清楚系统长什么样”做成一套中英双语架构图谱：26 章教程、25 个模板、6 个完整案例，核心卖点不是某个技术栈，而是把架构判断训练成可迁移能力。

它把教程、模板、案例和 AI 协同设计收在同一工作台里：先教你怎么想，再给你系统地图，最后用票务、RAG、协同、内容分发和编码 Agent 把推理链走完。

26 章教程 25 个模板 6 个案例 中英双语 VitePress Architecture Copilot
这不是“系统设计八股表”，而是一套架构判断训练器

仓库反复强调：代码能力会被 AI 稀释，但约束拆解、质量属性取舍、系统演进判断不会消失。它因此把内容组织成“教程 → 模板 → 案例 → AI 协同”四层闭环，而不是把一堆链接扔进 awesome list。

学习与设计闭环

Architecture Workflow
1 · 建立判断框架
需求 → 约束 → 质量属性 → 取舍
START

教程前 9 章先把“为什么这么设计”立住，再进入更难的分布式、一致性、韧性与安全。

01–17判断优先
2 · 读陌生系统地图
14 段模板骨架统一复用
MAP

每个模板都回答同一组问题：定位、数据流、关键权衡、瓶颈、反模式、演进路线与参考原型。

25 模板只讲架构
3 · 用案例把推理走完
从 MVP 到规模化
CASE

案例不是再给一张图，而是把量化信号、升级触发点、放弃了什么全部展开，补齐“从图到实战”的最后一段路。

6 端到端案例演进剧本
4 · 交给 AI 协作落地
spec-first / review / eval
AI COLLAB

最后 23–26 章回答“什么时候 vibe，什么时候写规格先行”，把 ADR、review checklist 与 eval 门禁接到 AI 工作流。
