安装方式
一条命令安装（Codex）

ljg-skills -l

# 安装到用户级 ~/.agents/skills/
ljg-skills -g

# 安装到指定 Agent（如 Codex）
ljg-skills -a codex

# Org-mode 版本（默认，master 分支）
