用 8 个可安装 Skill，把"发现未知未知"从一篇文章变成 Agent 工作流中的日常命令。

Neeeophytee/finding-unknowns-skills 是面向 Claude Code 和 OpenAI Codex 的 8 个 Skill 集合，源自 Anthropic 工程师 Thariq Shihipar 的文章《Finding Your Unknowns》。每一行 Skill 指令都是一次低成本干预：在实现变贵之前，把"未知未知"从表格底行搬出来。支持通过 Vercel skills CLI 一键安装（npx skills add Neeeophytee/finding-unknowns-skills），也可手动复制到 .claude/skills/ 目录。

01 动手前 · BEFORE
Skill 用途说明
blindspot-pass 发现

在不熟悉的领域发现你的未知未知，帮你写出更好的提示词。在一头扎进代码前先摸清盲区。
brainstorm-prototypes 构建原型

生成一次性可反应的原型变体，帮你捕捉那些说不清道不明的品味和直觉——这类东西光靠文字描述是拿不到的。
interview-me 一次一问

一次只问一个问题，优先问那些能改变架构的问题。在你已经发散出一些想法但仍有模糊地带时使用。
02 写代码 · DURING
Skill 用途说明
reference-hunt 规格说明书

用现有源码作规格说明书——即使跨语言，也能从真实工作的代码里提炼出规格，比空想更可靠。
implementation-plan 决策先行

生成实施计划，把你最可能改变的部分排在前面。在你准备好动手时使用，让计划本身具有适应性。
implementation-notes 记录偏差

记录每一个与计划的偏差，让下一次尝试从这一次的经验里学习。实现过程中全程运行。
03 写代码后 · AFTER
Skill 用途说明
pitch-packager 说服文档

把规格说明 + 原型 + 笔记打包成有说服力的文档，给评审者或合作者看。做完之后、出合并请求之前使用。
change-quiz 合并测验

一个理解力测验，合并前必须通过。确保改动被充分理解，减少把问题带进主分支的风险。
