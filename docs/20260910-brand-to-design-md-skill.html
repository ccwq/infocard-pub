brand-to-design-md-skill：把品牌 URL 转成 DESIGN.md

输入任意品牌公开 URL，输出含设计 Token、组件规范与品牌边界的完整 DESIGN.md；可选择生成并验证响应式 HTML 演示页面。

MIT 设计 Token 品牌分析 DESIGN.md
⭐ 136 作者：shaom 入口：SKILL.md Codex · Claude Code · Cursor · OpenClaw
定位：不是 CLI，是可移植 Agent Skill

运行于 Codex、Claude Code、Cursor、OpenClaw 等 Agent 环境；输入品牌 URL，输出结构化设计文档，无需额外依赖。

品牌证据采集 设计 Token 提取 DESIGN.md HTML 演示
01
CORE CAPABILITIES

四大核心能力

从证据采集到文档输出的完整流水线，覆盖品牌视觉分析的全生命周期。

采集证据

品牌证据采集

从官网、新闻稿、CSS、SVG、图片和设计案例研究中提取品牌视觉证据。

  • 官方页面截图与源码
  • Press Kit / 品牌指南 PDF
  • SVG / PNG 素材下载
  • 设计案例研究引用
翻译Token

设计 Token 提取

将品牌视觉证据转化为可复用的设计 Token 和实用组件指导。

  • 主色 / 辅助色 / 中性色
  • 字体家族与字号规范
  • 间距 / 圆角 / 阴影系统
  • 图标风格与图像调性
文档边界

DESIGN.md 输出

生成含来源追溯的设计文档，覆盖配色、字体、布局、组件、图片、Logo 边界与 Do/Don't 指导。

  • 来源感知（Source-aware）
  • 颜色 / 字体 / 布局规范
  • 组件用法指导
  • Logo 使用边界
02
USAGE · RISK

安装与使用

两种安装方式（npx 或手动复制），一个 Skill 入口，一条指令完成品牌文档生成。

1

npx 安装（推荐）

通过 skills CLI 一行命令安装，自动拉取完整技能包。

2

手动复制

直接复制 skills/brand-to-design-md/ 文件夹（SKILL.md + 支持文件）到本地。

3

Skill 入口

入口文件为 skills/brand-to-design-md/SKILL.md，在 Agent 环境中直接调用。

03
INSTALL & USAGE

安装命令与典型用法

一行安装，零依赖运行；在 Agent 中直接发送自然语言指令即可。

安装命令

安装命令

// 方式一：npx skills CLI（推荐）
npx skills add https://github.com/shaom/brand-to-design-md-skill --skill brand-to-design-md
// 方式二：手动复制文件夹
cp -r skills/brand-to-design-md/ <your-skills-dir>/
使用示例

典型用法

// 在 Agent 中发送自然语言指令
Use brand-to-design-md to extract https://example.com into a DESIGN.md and demo HTML
// Skill 入口文件
skills/brand-to-design-md/SKILL.md
提示：该 Skill 不是命令行工具，而是运行在 Agent 环境（Codex、Claude Code、Cursor、OpenClaw 等）中的可移植技能。输入品牌 URL，Agent 自动完成从证据采集到 DESIGN.md 输出的全流程。
