01

先分清：你要记住什么？

不同记忆问题，不应共用同一套存储与检索策略。

对话缓存

保留当前会话需要的上下文，先解决“别忘了刚才说过什么”。

向量检索

把文本变成可相似度搜索的表示，适合从资料库找相关片段。

知识图谱

保存实体、关系和变化，适合回答“谁和谁有什么联系”。

情景记忆

记录发生过的事件与经历，让 Agent 能回看具体过程。

语义记忆

提炼稳定事实与规则，减少每次都从原始对话重新推断。

生产级记忆层

把召回、更新、权限、评测和成本放进可维护的系统边界。

04

上生产前，别跳过这条边界

适合用它做什么

学习记忆技术实现、比较框架路线、为 Agent 设计长期记忆层、在选型前快速验证假设。

不要从它推出什么

Notebook 能运行，不代表方案适合生产；模型、数据集、提示词、向量库和评测口径都会改变结论。

风险提示：这是学习与选型资源，不是对所有记忆框架的独立性能排名。部署前仍需自行检查数据权限、隐私、成本、稳定性与真实业务指标。
