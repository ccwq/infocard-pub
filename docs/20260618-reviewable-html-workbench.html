REVIEWABLE HTML WORKBENCH

Review
Inside

Claude Code / Codex CLI 插件——把 HTML 文档评审对话放回文档本身。Agent 生成报告 / 设计稿后，你直接在预览中选中文字加评论，Agent 读取评论、回复、迭代改进，直到文档就绪。

AGENT LOOP评论 → Agent 回复 → 文档改进，循环直到满意。
INLINE REVIEW选中任意文字或图片，评论锚定到文档精确位置。
SELF-CONTAINED导出单个 HTML 文件，内嵌所有 CSS 和图片资产。

WORKFLOW · 评审闭环
PAGE 03

5 步完成评审迭代

1
Agent 生成 HTML 文档包（结构化章节 + 图片）
↓
2
打开预览，选中任意文字或图片添加评论
↓
3
Agent 读取评论、分类（可执行/已解决/待澄清）
↓
4
Agent 更新文档，重新渲染
↓
5
导出单文件 HTML（无评审 UI，资产内嵌）
SKILL · 视觉渲染
PAGE 04

visual-html-renderer

将结构化数据渲染为可评审的视觉 HTML 文档。输出 index.html + 资产副本 + renderer-manifest.json，支持 Mermaid 图表降级渲染。

SKILL · 设计文档
PAGE 05

reviewable-design-doc

构建可直接评审的设计文档，自动将浏览器评论注入 Agent 工作流。评论附带到精确文档范围，JSON 持久化，跨迭代不丢失。

01
Resolution Gate

待澄清线程保留在文档中；解决后才允许更新，避免误改。

SKILL · 计划预览
PAGE 06

plan-preview

Plan Mode 提案生成临时 HTML 预览 URL，团队成员无需进入 Agent 会话即可直接预览计划输出，再决定是否执行。

NEW
Plan → Preview → Decision

预览 URL 有会话作用域，Agent 关闭后自动失效，保证评审范围明确。

REVIEW SERVER · 预览服务
PAGE 09

会话作用域预览

Agent 启动会话作用域的预览服务器，优先使用 Tailscale IPv4，失败时回退 127.0.0.1。明确拒绝绑定 0.0.0.0，安全性明确。

→
Tailscale First

优先远程访问，Agent 关闭后 URL 失效，无需手动清理。
