01控制平面工作流
异步队列

提交任务后立即返回 operationId / workflowId，避免把 MCP 调用挂成长连接。

可恢复执行

支持 restart recovery、thread/turn 追踪、审批恢复和 duplicate prompt 保护。

本地持久化

SQLite 记录 operations、workflows、turns、hooks、diagnostics、leases。

Plan Mode

先计划，再审批，再执行；支持轮询、审批与最终报告读取。

多客户端适配

OpenClaw、Hermes 是一等客户端，也适合任何本地 orchestrator。

安全边界

Local-first，默认不对公网开放；读写权限、沙箱与审批状态可控。

02为什么比薄封装更稳

1. 不阻塞数小时

把长任务拆成可轮询的操作，而不是把 MCP 调用卡死在现场。

2. 重试不重复提交

通过 client_request_id、活跃 prompt 检测和状态持久化避免重复 turn。

3. 可追踪的审批

问答、审批、计划模式状态都暴露为可查询结构，而不是日志里猜。

4. 恢复与修复

诊断、健康检查、修复工具和局部历史都作为一等能力输出。

03支持能力
