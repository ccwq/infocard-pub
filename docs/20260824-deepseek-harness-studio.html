💡 vs DeepSeek Harness CLI

DeepSeek Harness 本身是纯命令行工具，配置和学习成本较高。Studio 版本用 Electron 桌面化补上了缺失的 GUI 层，让本地/自托管模型用户无需记忆复杂命令，即可完成启动、配置和插件管理。

安装

git clone https://github.com/fufankeji/deepseek-harness-studio
cd deepseek-harness-studio
npm install
npm run dev  # 开发预览
npm run build  # 构建安装包
🔗 fufankeji/deepseek-harness-studio @ GitHub

桌面端 → 模型后端 → 工具能力

Windows / macOS Electron UI
  ↓ 本地 Host：启停、模型配置、插件管理
  ↓ Ollama / vLLM / SGLang
  ↓ 插件 + Preset + 应用中心
  ↓ 任务执行与结果回到桌面端

Studio 的定位是补上 DeepSeek Harness 的 GUI 控制面：它不等于新的推理后端，也不自动消除本地模型、插件或宿主进程的运维成本。
