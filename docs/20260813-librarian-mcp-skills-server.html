安装大量 Agent Skills 后，Agent 上下文被大量预置内容塞满，性能反而下降。The Librarian 用语义搜索取代"全量塞入"，让 Agent 在需要时只获取最相关的 Skill。

问题背景

2026-08-05 @AI超元域 AISuperDomain
Skill 装得越多，Agent 上下文被大量预置内容填满，理解任务和选择工具的准确性反而下降——"全量塞入"不是最优策略。

The Librarian 给数千个 Agent Skills 配了一位"图书管理员"。Agent 不再把整个 Skill 库塞进上下文，而是用自然语言描述任务，由 Librarian 通过语义搜索找到最相关的 Skill。

核心机制

语义 Skill 路由 3 步

语义搜索定位 Skill

用自然语言描述任务，Librarian 通过语义匹配找到最相关的 Skill，而非全量加载。

语义匹配

自动避免重复推荐

分析 Skill 库中的相似性和重叠功能，主动过滤掉效果重复的候选 Skill。

去重引擎

历史结果动态调整

根据历史使用数据（成功率、使用频率）调整后续推荐权重，淘汰低效 Skill。

自适应学习

技术实现

本地优先架构

MCP 构建

基于 Model Context Protocol，任何 MCP 客户端均可接入。

Ollama 本地 Embedding

使用 Ollama 在本地生成本地 Embedding，无需上传数据到云端，保护隐私。

SQLite 存储

Skill 元数据、使用记录、推荐权重全部存在本地 SQLite 文件。

Apple Intelligence 二次排序

可选调用 Apple Intelligence 在设备端对候选 Skill 进行二次排序。
