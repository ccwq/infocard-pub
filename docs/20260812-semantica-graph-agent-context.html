发现一个很有意思的开源项目：Semantica，可以理解成给 AI Agent 加上一层"可追溯的大脑"。

它不是普通 RAG，而是把企业数据、Agent 决策、实体关系和因果链构造成 Context Graph / Knowledge Graph，支持知识抽取、冲突检测、实体去重、规则推理、决策追踪和完整 Provenance。

最特别的是：AI 为什么做出某个决定、依据是什么、影响了什么，都可以沿图谱回溯，而不是只剩一条黑盒日志。

支持 Neo4j、Neptune、RDF、向量数据库、MCP、Databricks、Snowflake 等，而且开源、自托管。

很适合金融、医疗、政府等对 AI 可解释性和审计要求高的场景。
