01 · PRODUCT BOUNDARY

它卖的是设计表达，不是运行时

输出是文本 Prompt官网的使用方式是浏览设计、复制 Prompt、粘贴到 Lovable、Cursor、Bolt、Claude、v0 或 Replit，再由这些工具生成和修改实现。
不是网站生成器官方页面的定位是供代码/设计工具消费的 Prompt 资源库，并未提供 CMS、部署托管或可视化页面编辑器。
四类资源Sites 面向完整页面，Sections 面向组件区块，Backgrounds 为动态背景，Apps 面向 Web/移动应用 Prompt。

04 · WHAT THE AGENT ACTUALLY GETS

从“看见好网站”到“获得可执行设计约束”

资源选择

按页面、区块、动态背景或 App 类型挑选参考。

Prompt 上下文

Prompt 可指向 React、TypeScript、Vite、Tailwind、Framer Motion 等设计实现组合；具体内容因条目而异。

Agent 生成

代码 Agent 将 Prompt 作为设计方向，而不是把它当作已验证的产品规格。

人工校验

检查可访问性、响应式、版权与品牌约束，避免只复制视觉表面。

05 · GOOD FIT

适合补“审美输入”短板

快速原型当团队已有代码 Agent，但缺少可明确描述的视觉方向时，可把 Prompt 作为中间层。
设计探索将完整页面和区块拆开请求，先选结构，再要求代码工具实现。
提示词学习配合 Academy 的公开教程，理解动画、3D 和页面叙事如何被表达为约束。
06 · LIMITS & RISKS

有参考，不代表可直接上线

不要跳过三件事
① 500+ 是官网数量声明，不等于每类均有同等覆盖；② 账户与付费资源依赖第三方服务，不能自托管；③ Prompt 可用于 personal/client work 的页面声明不替代你对素材、品牌、代码和授权的审查。
事实边界官方没有把它描述为 CMS、hosting 或 design-to-production 的自动化流水线。
07 · DECISION

把它当作设计资料 MCP

推荐已有 Claude Code / Cursor / Codex 工作流，想让 Agent 获得更具体的网页视觉输入。
不推荐期待零配置建站、离线资源库、私有部署，或将版权判断交给 Prompt 的场景。
第一步先用免费 3 个 Prompt 验证：返回内容是否与你的技术栈、品牌和移动端规范兼容。
