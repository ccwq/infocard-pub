ENGINE · 核心引擎

Rust + Tokio：零成本抽象的并发下载

基于 Rust 和 Tokio 构建，内存安全与最大吞吐量兼得。零开销抽象让每一条连接都充分发挥带宽潜力。

HTTP/HTTPSFTP

HTTP 系列

支持 Range 请求断点续传，多线程分段并行下载，动态调整连接数榨取带宽。FTP 同协议支持。

BitTorrentDHT / Magnet

BitTorrent

内置 DHT、UPnP 端口映射、磁力链接解析。完整 BT 客户端能力，做种与下载并行。

eD2KKad DHT

eD2K / 电驴

支持 eD2K 服务器源 + Kad DHT 双源搜索，MD4 校验，自动选择最快来源。经典电驴链接复活。

HLSDASHAES 解密

HLS / DASH 流媒体

自动识别 .m3u8 / .mpd 流媒体清单，分段下载并解密（AES），合并为完整视频文件后再也不怕网页过期。

02
SEGMENTATION · 智能分段

IDM 风格动态分段 — 比 IDM 更聪明

空闲线程自动接管慢速分段，连接复用避免重建开销。运行时动态拆分，不预设分段数，榨取每一份带宽。

动态分段原理

FluxDown 在运行时监测每条连接的真实吞吐，空闲线程自动抢接慢分段。当某个分段领先其他分段超过阈值时，超前部分会被拆分给落后线程。整个过程无需用户配置。

空闲线程接管 连接复用 运行时拆分

令牌桶限速

基于令牌桶算法的全局带宽控制，精确限制上传/下载速度。即使跑满带宽，后台下载也不会影响浏览或游戏。

精确 MB/s 限制 上传独立控制
03
BROWSER EXTENSION · 浏览器扩展

Chrome / Edge / Firefox 三层拦截引擎

扩展自动捕获浏览器下载请求，支持流媒体资源嗅探（HLS/DASH），域名规则过滤，Alt+Click 绕过，完整的右键菜单集成。

① 页面资源嗅探
拦截页面发出的所有网络请求，自动识别可下载资源（HLS 视频分段、压缩包、可执行文件）。
② 三层拦截引擎
第一层：自动拦截；第二层：按域名/扩展名过滤；第三层：用户手动 Alt+Click 绕过任意规则。
③ 流媒体嗅探
自动检测 HLS .m3u8 和 DASH .mpd 清单，组装分段并解密 AES-128，返回完整视频文件。
④ Native Messaging
通过 NMH（Native Messaging Host）与 FluxDown 引擎通信，本地直连，无云端，数据不离本机。
Chrome 网上应用店 Firefox 官方商店 Edge 附加组件

ARCHITECTURE · 架构设计

Flutter UI ↔ Rust 引擎：Rinf FFI 串联

Flutter 渲染界面，Rust 做所有重活，两者通过 Rinf signals 通信；浏览器扩展通过 Native Messaging Host 直连引擎。

FluxDown Architecture
Flutter UI (shadcn_ui) ↕ Rinf signals hub (FFI adapter) ↕ Native Messaging fluxdown_nmh (Browser Extension) ↓ Rust engine layer ↓ fluxdown_engine ├─ HTTP/HTTPS Engine ├─ FTP Engine ├─ BitTorrent Engine (DHT/UPnP/Magnet) ├─ eD2K Engine (Kad DHT) └─ HLS/DASH Engine (AES 解密) ↓ SQLite WAL ↓ 持久化状态
06
PLUGINS · 插件与托管

JS 沙箱 + 外部工具托管

可选的 JavaScript 插件层在沙箱中安全执行，链接解析器、通知钩子、命令式重试逻辑全部插件化。插件市场一键安装，内容寻址校验全程可验证。

托管组件

按需下载并托管 ffmpeg、yt-dlp 等外部工具。插件在隔离沙箱中调用它们完成合并、转码、抽流，无需手动配置环境变量。

ffmpeg 托管 yt-dlp 托管 沙箱隔离

社区加速网络

来自社区的匿名镜像测速结果汇聚成共享路由图，下载时自动选择最快线路。只记录「哪个地区哪个镜像更快」，不含链接、文件名或身份信息。

匿名测速 去中心化
