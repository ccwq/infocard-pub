工作流 / Agent Operating Layer

Citadel：给 Claude Code 和 Codex 加一层可恢复的操作系统

一个围绕 coding agent 的操作层：路由意图、保存项目状态、协调并行工作，并把验证和交接留下来。

01

已确认的核心事实

按官方文档、Release 或仓库 README 逐条落地。

FACT 01

事实 1

项目定位为 Claude Code + OpenAI Codex 的开源 operating layer，要求 Node.js 18+ 与 Git 仓库。

FACT 02

事实 2

/do 作为自然语言入口，向下连接 workflow、campaign、Fleet 与 operation control。

FACT 03

事实 3

仓库提供持久化状态、worktree 隔离、hooks、成本遥测和恢复交接。

02

落地时不要混淆

把工具能力、项目自述和可验证边界分开。

BOUNDARY 01

边界 1

Citadel 的价值不在替代 Claude Code 或 Codex，而在持续工作需要的操作纪律。

BOUNDARY 02

边界 2

README 明确公开了正向、负向和失败的证据，不应把自测结果直接包装成节省承诺。

BOUNDARY 03

边界 3

它仍以底层 Agent 的权限运行，不能替代代码审查和分支保护。
