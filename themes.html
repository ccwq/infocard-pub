infocard 主题页

这是独立维护的主题说明页：不进入首页索引，不放进 docs/，但可直接公网访问。它集中展示当前正式主题的名称、定位、视觉特征与参考页面，作为后续选主题与维护命名体系的总入口。

独立页 / 不写 sidecar / 不参与 _index.yaml / 直接发布于仓库根目录
返回信息卡首页

当前正式主题

  • infocard-q-style：纸感、手作感、彩色卡片、框架对比。
  • infocard-green-style：青绿 / 翡翠 / editorial，冷静、克制。
  • infocard-black-head-style：黑头、白纸、红色判断、调查拆解风。
  • infocard-main-style：默认主骨架，红黑白主系统，小字高密度模块化。
  • infocard-blue-technical-manual-style：黑头 + 红蓝双强调，技术手册 / workflow 说明。

命名规则

主题统一采用 infocard-***-style 命名，不再把 swiss 放进技能名里。页面层面的瑞士风格、黑头结构、技术手册骨架，属于主题特征，不再写进顶层命名。

infocard-black-head-style

黑头主题 / 调查拆解风

黑色页眉是视觉锚点，白纸正文承载大块说明，红色负责结论与风险，蓝绿仅作辅助。适合调查、论证、workflow 拆解与“先结论再展开”的结构。

infocard-main-style

主要主题 / 默认主骨架 / 小字

MAIN

红黑白主骨架，蓝黄绿辅助状态色，stats / grid / pill / flow / section 齐全。它代表 infocard 的默认主主题：高密度、模块化、说明书感强，但小字必须可读，不能照搬过小字号。

infocard-hardblue-style

硬核蓝手册 / 网格底纹 + 编号块 + 多版式

HARDBLUE

黑头 hero + 暖白纸底 + 红蓝双强调 + 网格底纹与色斑光斑。顶部 hero-bar 三色拼接（左红 / 中黑 / 右蓝），章节用 96px 大数字编号块，搭配 grid-2/3/4、matrix、risk（含 data-accent 顶部色带）等多套版式。比 blue-technical-manual-style 更"硬核手册"：更厚边框、更多 grid 变体、更多色块锚点。

硬核手册 编号块 网格底纹 多 grid
余承东像丁春秋吗？像的是话术，不是内功硬核蓝手册的代表落地卡：hero-bar、编号块、grid-3、matrix、risk 顶部色带齐全
适合"重型多章节技术 / 调查 / 观点拆解手册"；不适合 Q 风、纸感、轻量卡片。版面比 blue-technical-manual-style 更"密、硬、多 grid"。
维护原则：修改主题请编辑 _themes.yaml，然后运行 python3 scripts/rebuild_themes.py 重建本页面；若主题新增或改名，还应同步更新对应 Skill 与 fact_store。本页不写 sidecar，不进入 _index.yaml，但通过 GitHub Pages 正常公开访问。
