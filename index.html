JSON 输出 · 结构详情

三层结构化输出

ModLens 一次解析同时输出 OCR、布局、实体三类信息，无需多次调用。

OCR

文字识别层

高精度光学字符识别，精准提取页面内所有文字内容，保留语义结构。

Layout

布局结构层

完整 DOM 布局树，清晰还原页面元素层级与空间位置关系。

Entities

实体抽取层

自动识别并抽取页面关键实体：人名、地名、机构、产品等结构化信息。
