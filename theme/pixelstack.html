像素堆叠 · 思考者主题

pixelstack 是一套像素插画通用风信息卡主题：复古手作 + 现代中文。 骨架三件套——金字塔堆叠块、像素思考者、消散箭头 + 金句——必须保留为视觉锚点。 每张卡都把核心结论放进顶层方块，把方法论拆成下层堆叠，再用左侧消散箭头承载一句"反直觉金句"。

L1 / base

提示词工程

最贴近"亲手干活"的层。基础块最大、最稳，承载日常提示词技巧、模板与规则。

L2 / context

上下文工程

从一句话提升到一组证据：会话窗口、检索、文件注入与上下文裁剪策略。

L3 / reins

缰绳工程

给 agent 加缰绳：工具、约束、验收、回退路径，决定 agent 不跑偏的边界。

L4 / loop

循环工程

顶层是循环：感知→决策→工具→验收→学习。设计循环的人离干活最远，离系统最近。

使用边界 · pixelstack 适合方法论层级、工程演进、抽象阶梯、AI 工作流梯度类内容； 不适合严肃法律/财务/合规、纯数据报表，也不适合需要工业冷感或极简科技海报的页面。 凡是能画出"金字塔 + 思考者 + 金句"的主题，都能套这套骨架。
