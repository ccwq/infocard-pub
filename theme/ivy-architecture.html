关系方向线型说明
请求调用入口 → 边界 → 编排实线 ↓同步主路径，失败快速返回。
事件触发外部 → 队列虚线 ⇢异步投递，允许延迟与重试。
工具调用编排 → 执行实线 ↓受沙箱与权限约束。
人工审批执行 → 人工橙色 ⇢高危动作挂起等待确认。
数据写入执行 → 持久化实线 ↓结果、日志、状态三类落库。
 
# 层间关系以文字化流向条表达，而非跨层长线
flow: CLIENTS → GATEWAY → ORCHESTRATION → EXECUTION → STATE
trigger: WEBHOOKS ⇢ QUEUE ⇢ DISPATCHER（异步旁路）
approval: DANGEROUS_ACTION ⇢ HITL ⇢ REVIEWER
边界提示

语义色只表达职责类别，不表达健康状态；执行结果必须回读 trace 与日志，不得以“已发送”代替验证。人工审批不是装饰，是高危路径的硬门禁。
