小小容器（Tiny Container）：APK 安装后 5 分钟初始化，在 Android 手机/平板上以 PRoot 容器方式运行完整 Debian 13 Linux 桌面，无需 root。

项目由 Cateners（GitHub）开发，基于 Termux 社区的 PRoot 技术，允许 GNU/Linux 用户空间在非 root Android 设备上运行。提供 XFCE（轻量）和 GXDE（美观）两种预装桌面版本，以及极简版（需手动导入容器）。内置常用软件一键安装按钮、WPS/微信桌面端、星火应用商店，通过 Hangover 兼容层可运行部分 Windows exe。图形加速仅支持 Adreno GPU。Android 12+ 杀后台可能导致桌面崩溃，需手动配置电池优化或 adb 命令解除限制。作者在 README 中明确声明项目"大量使用 AI"辅助开发，可能存在意外 bug。

01
核心功能

有哪些开箱即用的能力

从安装到日常使用，小小容器为 Linux 小白做了大量优化。

桌面环境预装版

两种桌面一键选择

  • XFCE 版：轻量低占用，适合入门用户
  • GXDE 版：界面更美观，占用资源更多
  • 另有极简版（无预装容器，可自行导入）
小白友好一键安装

常用软件点一下就好

  • 内置 WPS、微信桌面端、终端
  • 常用 apt 命令做成了图形按钮
  • 集成星火应用商店，茫茫多应用
  • 支持将 .desktop 添加到安卓启动器
进阶功能极客玩具

内置终端 + 丰富配置选项

  • 内置终端，apt install 直接用
  • 支持音频、麦克风转发（Unix socket）
  • virglrenderer / turnip+zink 图形加速
  • SAF 文件管理器浏览容器文件
02
Windows 兼容

通过 Hangover 兼容层运行 exe

不是万能的，需手动配置，有明确的兼容范围限制。

✅ 可用

基本 exe 程序

非复杂依赖的 Windows 可执行文件可直接双击运行。

⚠ 需配置

开启 Hangover

需在"选项配置 → 杂项"中手动启用 Hangover 并重启容器。

❌ 受限

3D 游戏 / Steam

视频作者亲自测试 Steam 安装失败；3D 游戏需 DXVK，效果有限。

🔧 已知问题

乱码 / Mali GPU

字体乱码可修复；不支持 Mali GPU 加速，仅 Adreno 部分支持。

03
适用边界

不适合什么场景

作者和视频作者双重声明：这是 PRoot 容器，不是虚拟机，更不是原生 Linux。

1

重度生产力

PRoot 效率低于原生系统，长期重度办公不建议当作主力环境使用。

2

Windows 游戏

3D 游戏、DXVK 效果有限；Steam 无法安装；Hangover 并非万能兼容层。

3

Android 12+ 杀后台

桌面可能莫名崩溃；需配置电池无限制；某些系统仍需 adb 命令解除。

4

GPU / 系统级限制

不支持 Wayland、Docker、systemd、GNOME、Mali GPU 加速。

5

AI 辅助开发风险

作者 README 明确声明"大量使用 AI"辅助代码和翻译，可能存在意外 bug。

6

非生产级替代品

原作者定位：轻度日常 / 临时应急 / Linux 学习，不适合当作真实电脑替代品。
