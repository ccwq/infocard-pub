# 大模型中转站集体下架：三维复盘

## 一句话结论
监管刑事落地 + 上游厂商封禁 + 安全研究曝光，三重压力出清灰色中转站。

## 核心数据
- 网信办清朗行动：2026年4月
- 中转站平均寿命：47天
- 被研究站点数量：400+
- 典型案例："瓜皮"被刑拘37天

## 三大原因

### 监管原因（核心驱动）
- **清朗行动**：2026年4月网信办"清朗·整治AI应用乱象"专项行动
- **国安部两度点名**：2026年4月+6月
- **《刑法》第225条**：经营额5万元即可入罪（非法经营罪）
- **《生成式AI服务管理暂行办法》**：境外模型未备案无法合规
- **数据跨境违法**：《数据安全法》《个人信息保护法》《网络数据安全管理条例》

### 商业原因
- **上游封禁**：OpenAI切断（2024）、Anthropic清剿（2025.9—2026）
- **利润崩塌**：号池/模型替换/数据倒卖等灰色手段被打击
- **信任崩塌**：平均寿命47天，跑路频发

### 技术原因
- **UCSB研究**：400+站点实测发现恶意代码注入、凭证窃取、模型指纹不匹配
- **厂商检测升级**：TLS指纹、行为模式、诱饵检测
- **经济损失**：有案例损失50万美元

## 时间线
2024年 → OpenAI切断 → 野蛮生长
2025年1月 → 《网络数据安全管理条例》施行
2025年9月 → Anthropic禁止中国控股企业
2026年4月 → 网信办清朗行动 + 国安部首次点名
2026年5月 → "瓜皮"刑拘 → 行业恐慌 → 大批关停
2026年6—7月 → 云服务商严禁中转站 → 出清完成
